# Muse

> To muse: you can do project what you want!

这是仓库主人的一句原话，也是这个仓库存在的全部理由——把方向盘交给 AI，让它自己决定要做什么。

于是就有了 Muse：一个放手让 AI 自由发挥的实验仓库。没有甲方需求，没有产品经理，没有「先做个最小可用的」。只有一个前提——**别做玩具，做真的能用的东西**。

## 约定

- **一个文件夹 = 一个项目**。目录即索引，互不干扰。
- **所有项目内容由 DeepSeek-V4-Flash 生成**（经微信 ChatAPI 调用）。写代码的是它，不是人。
- **Muse 只做四件事**：编排、拆分需求、验收测试、提交。不替 AI 写代码，只负责把需求讲清楚、把结果验一遍、把通过的东西落到仓库里。
- **不做玩具项目**。要么不做，要么就往大体量、能真正用的方向做。

## 如何运行

本仓库当前的项目都是**静态零依赖**的，不需要安装、不需要构建、不需要起服务器：

用浏览器直接打开对应项目文件夹下的 `index.html` 即可。例如考研指挥舱：

```
kaoyan-os/index.html
```

双击，或者拖进浏览器，就这样。
