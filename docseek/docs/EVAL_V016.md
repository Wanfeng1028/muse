# docseek v0.16.0「同义词表」里程碑评测报告

一句话摘要：v0.16.0 引入仅含 3 组经语料证据确认映射的同义词表，并对 search/searchQuestion 路径补齐疑问词过滤（B-fix1），使 v09 样本评测从 176/200（88.0%）提升至 180/200（90.0%），修复 4 个失败且零新增失败，v07/v08 回归与基线一致。

## 一、改动清单

1. **新增同义词表**：新增 `src/synonyms.cpp` 与 `include/docseek/synonyms.h`，仅收录 3 组经 v09 样本 corpus 证据确认的映射（精确匹配）：「小孩」→{「孩子」}、「破裂」→{「裂」}、「花费」→{「多少钱」}。设计文档 `docs/SYNONYM_TABLE_DESIGN.md` 已存在。
2. **检索路径接入同义词展开**：`search()` / `searchQuestion()` 中，查询 token 命中同义词表时与 expansions 组成 FTS5 OR 组；未命中时行为与原来一字不差。
3. **B-fix1：疑问词过滤对齐**：`search()` / `searchQuestion()` 路径新增 `stripFillerWords(rest)`（新函数，位于 `include/docseek/query_parser.h`），对齐 locate 路径已有的疑问词过滤；引号短语已先剥离不受影响；「不」永不入填充词表（否定语义保护）。
4. **新增测试**：`tests/test_v016_b_fix1.cpp`（2 例：疑问词剥离搜索 + `stripFillerWords` 单测）、`tests/test_v016_b_cases.cpp`（3 例：三个同义词对的红绿回归）。

## 四、已知限制与下轮方向

- **D 类长问句噪音未动**：本轮未对 D 类长问句的噪音处理做任何改动，仍为待办方向。
- **数值型问法桥接为机制级缺口**：数值型问法的桥接属于机制级缺口，非单条同义词映射所能覆盖，需在后续版本从机制层面设计。
- **同义词表明确不扩张**：本版同义词表仅收录 3 组经 v09 样本 corpus 证据确认的映射，明确不扩张；后续若扩张须以语料证据为前提。

## 五、对照 v0.15.0 的结论

v0.16.0 在 v0.15.0 基础上以最小改动面（3 组同义词映射 + B-fix1 疑问词过滤）将 v09 样本评测从 88.0% 提升至 90.0%，修复 4 项失败且零新增失败，v07 保持 100%、v08 与基线一致，新增测试全部通过；存疑对复核更正了 EVAL_V09.md 的原结论，D 类长问句噪音与数值型问法桥接仍为下轮待解方向。
