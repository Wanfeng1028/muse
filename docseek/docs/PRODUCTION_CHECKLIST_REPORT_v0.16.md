1. **同义词表仅 3 组是刻意为之的最小化**，遵循白名单原则：优先保证精确匹配零误伤，而非追求覆盖率。这是设计取舍，**不是覆盖不足**；后续扩展走同一白名单机制。
2. **数值型问法桥接缺口**（如"多少 / 几个"类问法到数值字段的桥接）本轮未覆盖，**排期未定**。
