# 数字与量词：450℃退火7天

"450℃退火7天"这句话里，450 是数值，℃ 是单位符号，退火是动词，7 是数值，天是量词。分词器要正确处理三类边界：数值与单位符号、数值与量词、单位符号与汉字。

常见错误是把"450℃"切成"450"和"℃"两个 token 后丢失单位，用户搜"450度"时命中不到，因为索引里存的是"℃"而不是"度"。解决方式是在索引阶段做单位归一化：℃→摄氏度/度，ml→毫升，kg→千克，并把归一化后的词作为同义词写入。

量词同理，"7天"要额外产出"7日""一周"的别名。数值区间也要处理，"3到5毫米"要能响应"3mm""5mm""4毫米"的查询。

评测时构造材料学文档，写"450℃退火7天""保温2小时""冷却速率10℃每分钟"，查询用"450度""七天退火""10摄氏度"，检查单位与量词归一化是否生效。
