# Python函数定义与参数传递

写代码写到一定量，就会想把重复的逻辑抽成函数。Python用`def`关键字定义函数，函数名后面跟括号和参数列表，最后别忘了冒号。

## 定义与调用

一个最简单的函数：

```python
def greet(name):
    return "你好，" + name
```

调用时传入实际参数：`greet("小明")`。函数体用缩进表示，`return`把结果返回给调用方。如果没有`return`，函数默认返回`None`。

## 参数类型

- 位置参数：按顺序传入，最常用
- 默认参数：定义时给默认值，比如`def power(x, n=2)`
- 关键字参数：调用时写`power(x=3, n=4)`，顺序可以打乱
- 可变参数：`*args`接收任意个位置参数，`**kwargs`接收任意个关键字参数

默认参数有个坑：不要用可变对象做默认值，比如`def add(item, lst=[])`，因为默认列表会在多次调用间共享，导致意外结果。正确做法是默认值写`None`，在函数体内再创建新列表。
