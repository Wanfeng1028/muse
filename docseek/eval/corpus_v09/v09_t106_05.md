# 链表反转的迭代写法

链表反转是面试高频题，也是理解指针操作的好例子。这篇只讲迭代写法，因为它比递归更省空间，也更容易在纸上画清楚。

## 核心思路

用三个指针：prev 指向已经反转好的部分，curr 指向当前待处理的节点，next 临时保存 curr 的下一个节点。每一步把 curr 的 next 指向 prev，然后三个指针整体后移。

## 逐步演示

假设链表是 1 -> 2 -> 3 -> null。初始 prev 为 null，curr 为 1。

第一步：next 保存 2，把 1 的 next 指向 null，prev 移到 1，curr 移到 2。

第二步：next 保存 3，把 2 的 next 指向 1，prev 移到 2，curr 移到 3。

第三步：next 保存 null，把 3 的 next 指向 2，prev 移到 3，curr 变成 null。循环结束，返回 prev。

## 容易错的地方

- 忘记先用 next 保存 curr.next，导致链表断掉
- 循环结束后返回 curr 而不是 prev，curr 此时是 null
- 没有处理空链表的情况

## 代码骨架

while (curr != null) { next = curr.next; curr.next = prev; prev = curr; curr = next; } return prev;

把这段骨架背下来，再自己画图走一遍，基本就不会忘了。
