# 软路由备份与恢复：我踩过的三个坑

软路由用久了，配置越来越多，备份就很重要。我因为没备份，重装过三次，每次都要重新配一遍，烦得很。

## 坑一：只备份了配置

OpenWrt 的备份功能在系统菜单里，可以导出 tar.gz。我一开始只备份了这个，后来发现 Docker 容器的数据不在里面，AdGuard 的过滤记录和规则全丢了。容器数据要单独备份挂载目录。

## 坑二：恢复后网口乱了

备份恢复之后，网口的顺序变了，WAN 和 LAN 对调了，导致上不了网。原因是备份文件里记的是网口名称，但新系统识别出来的名称不一样。解决办法是恢复后进 LuCI 手动改，或者备份前把网口名称固定下来。

## 坑三：固件版本不匹配

有一次从 21.02 的备份恢复到 23.05 的系统，直接起不来了。大版本之间配置格式有变化，不能直接恢复。正确做法是先刷回原来的版本，恢复配置，再升级。

## 我的备份流程

现在每月备份一次。先导出配置，再打包 Docker 目录，两个文件一起存到 NAS 上。备份完还会在虚拟机里恢复一次，确认能用。麻烦是麻烦，但比重新配一遍强。

## 恢复步骤

刷好固件，进系统，先不配网络。上传备份文件恢复，重启。然后检查网口、防火墙、DHCP。都正常了再启动 Docker 容器。有问题就回滚，别硬撑。
