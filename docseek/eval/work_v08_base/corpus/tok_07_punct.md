# 标点干扰：引号括号破折号

中文文本里标点种类多，全角引号""''、书名号《》、括号（）、破折号——、省略号……，分词前如果不归一化，会污染 token。

典型问题：文档写"所谓"全文检索"其实是——倒排索引加打分"，如果引号和破折号被当作 token 的一部分，索引里就会出现带引号的词，用户搜"全文检索"（不带引号）时命中不到。

正确流程是先用 Unicode 类别过滤：标点一律作为分隔符，不作为 token 字符。破折号——要整体识别为一个标点而不是两个—。省略号……同理。书名号内的内容《红楼梦》要保留"红楼梦"作为 token，去掉书名号本身。

评测构造一篇文档，正文里故意写（关键词）"检索"——倒排索引，查询用"关键词检索倒排索引"，检查标点被正确剥离，查询能命中。同时检查《文溯DocSeek用户手册》能被"文溯DocSeek"和"用户手册"分别命中。
