# 代码动画后端 · 调研笔记（2026-10-15 下午）

背景：用户 2026-10-15 下午连续转发 4 条抖音 Claude/Opus5.5 AI 视频到主聊，助理看完逐条点评。
其中 Winhao 学 AI 的《Vibe知识大赏｜Opus5.5视频教程》（7 分钟，6504 收藏）给出了一条与 drama-factory
未来"AI 图片/音乐"轮高度相关的实现路线：**不走文生视频 API，走"LLM 写代码→逐帧渲染→拼视频"**。
用户当时的口径：软件主体优先，这块先记下。
调研人：小白（主 agent），素材来自用户转发的抖音视频，结论未经助理独立验证。

## 核心原理（一句话）

模型不会直接生成视频，只会写代码：每一帧都是代码算出来，再拼成视频。
视频本质是代码动画的渲染产物，提示词的核心是"约束渲染管线 + 画风配方"。

## 7 种画风的提示词套路（照搬清单）

| # | 画风 | 提示词要点 |
|---|------|-----------|
| 1 | 像素风 | 小画布整数放大、关平滑 |
| 2 | 老电视 | 叠一层着色器（CRT 扫描线/噪点） |
| 3 | 手绘 | p5.js + 笔刷库 |
| 4 | 3D | Three.js，给三视图约束 |
| 5 | 产品宣传片 | HTML/CSS/SVG + 弹簧动画 |
| 6 | 知识科普 | 按 BGM 节拍编排 + 联网查证文案 |
| 7 | 随它发挥 | "你是一个很厉害的动效设计师"（给模型最大自由度） |

## 归纳：三条渲染管线

1. **p5.js 管线**：手绘风、知识科普类二维动效。
2. **Three.js 管线**：3D 场景类。
3. **HTML/CSS/SVG 管线**：产品宣传片、排版动效类。

drama-factory 以后加"代码动画"模块时，直接照抄这三条管线的菜单结构即可。

## 与现有管线的关系

- 现有管线：剧本→分镜→AI 视频生成（DashScope wan2.5 / Agnes 降级千问）→ffmpeg 剪辑。
- 代码动画管线是**新增的一条生成腿**，不是替代：适合 MV、知识科普、产品宣传等"动效感"内容；
  真人实拍感、数字人仍走现有视频 API 腿。
