# Drama Factory 设计决策文档

## 1. 概念

把控制台当成深夜剪辑室里的一面场记板墙。

做短剧的人一天里打交道最多的不是漂亮的仪表盘，而是场记板、时间码、镜号、任务进度和成片缩略图。这些东西本身就带着一种手感：板条是斜条纹的，镜号是打印体打上去的，时间码是等宽数字在跳。所以这次重设计不去做"数据可视化"那一套，而是把每个页面都做成墙上的一块板子——一块板子代表一个分镜、一个任务、一集成片。深夜剪辑室的灯光是暗的，面板是近黑的，唯一亮起来的是钨丝灯那种偏橙的暖色，用在进度、卡点、当前选中这些需要你立刻看到的地方。整体基调是"暗房间 + 一块暖光"，不是"科技蓝 + 霓虹紫"。

## 2. 四页形态

### 分镜板 · 场记板卡片墙

- 每张卡片顶部是一条黑白斜条纹板条，直接借场记板的视觉，不用图标代替。
- 板条下方是等宽大字镜号（IBM Plex Mono），字号明显大于正文，是卡片的视觉锚点。
- 景别、运镜做成 badge，紧跟在镜号后面一行。
- 对白用引用样式呈现，缩进加左侧细线，和叙述性内容区分开。
- 时间码用等宽字体，靠卡片底部，和镜号形成首尾呼应。
- 卡片按网格排列，左对齐起排，不留大片空白居中。

### 任务队列 · 任务卡片墙

- 每张卡片是一个任务，形态是"标题 + 进度条 + 状态"。
- 进度条是卡片里最显眼的一条横向元素。
- 生成中的任务，进度条上跑条纹动画，一眼能从静止的任务里分辨出来。
- 状态色沿用统一状态色（成功 / 信息 / 警告 / 危险），不做额外装饰。
- 卡片间距和分镜板保持一致，让两页在视觉上属于同一个房间。

### 成片库 · 海报卡片墙

- 每张卡片是 16:9 的真实海报帧，不是占位图。
- 海报帧来自后端 `GET /media/finals/{id}/poster.jpg`。
- 后端用 ffmpeg 从成片第 1 秒处抽帧生成，保证海报是真实画面而不是黑帧或片头。
- 海报下方是标题、时长等元信息，等宽字体呈现数字。
- 网格排布，卡片之间 gap 16px，形成一面可以扫视的墙。

### 生产看板 · 横向胶片管线

- 整体是一条横向的胶片，上下各一条齿孔带，明确"这是胶片"的形态。
- 每一集占胶片上的一格。
- 卡点的集用暖橙 #E8590C 描边，一眼看出哪几集需要关注。
- 沿胶片横向滚动，符合"一集接一集往下走"的直觉。
- 不做纵向的看板列，避免和常见任务看板撞脸。

## 3. 色彩体系

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 近黑背景 | #0E0E11 | 页面最底层，暗房间的地板 |
| 面板 | #15151A | 顶栏、侧栏等容器面 |
| 卡片 | #1C1C22 | 卡片墙里每张卡片的底色 |
| 描边 | #2A2A32 | 卡片、面板的 1px 边框，不抢戏 |
| 钨丝灯暖橙（主强调） | #E8590C | 进度、卡点、选中、关键动作，全站唯一的主强调色 |
| 米白（主文字） | #F2EDE4 | 标题和主要正文，比纯白柔，不刺眼 |
| 次要文字 | #A8A29A | 说明、副标题、元信息 |
| 弱化文字 | #6E6A62 | 时间戳、占位、最不重要的信息 |
| 成功 | #2FBF71 | 任务完成、渲染成功 |
| 信息 | #3D8BFD | 中性提示、链接态 |
| 警告 | #F0B429 | 需要留意但不阻塞 |
| 危险 | #E5484D | 失败、删除、不可逆操作 |

强调色只有暖橙一个，状态色只在状态相关的地方出现，不拿状态色当装饰用。

## 4. 字体体系

中文用 Noto Sans SC，标题字重 700，正文字重 400，靠字重拉开层级，不靠字号堆叠。

等宽用 IBM Plex Mono，专门给镜号、时间码、数字、标签这类需要对齐和"像打印出来"的内容。镜号用等宽大字是分镜板的核心识别点。

规则：
- 标题用 700，正文用 400，中间不插 500、600 这种模糊档位。
- 所有数字、时间码、镜号一律等宽，不混用中文字体里的数字。
- 标签、kicker 这类小字用等宽大写字母，配字间距。
- 不用衬线字体做大标题，不走 Specimen 那一套。

## 5. 去 AI 味清单

- 禁紫渐变：全站没有一处渐变背景或渐变按钮，暗房间就是暗房间。
- 禁渐变标题：标题只用纯色文字，不做从紫到蓝那种渐变填充。
- 禁一切居中（空状态除外）：所有内容左对齐，包括标题、卡片、表单、空状态以外的任何区块。页面最大宽度 1200px 也是左对齐，不居中。
- 禁 emoji 图标：图标位置一律留白或使用几何形状（如板条、齿孔），不塞 emoji。
- 禁 Unleash / Empower 类文案：所有文案用大白话，说"生成中""失败""重试"，不说"释放创意潜能"。
- 禁"编号段落 + 衬线大标题" Specimen 风：不用 01 / 02 / 03 编号去撑结构，也不用衬线大标题做装饰。
- 用 kicker 眉题代替大标题装饰：每个栏目用小字大写字母间距的眉题，例如"场记板 · CLAPPERBOARD"，让栏目有身份但不靠大标题压场。

## 6. 间距与圆角

- 卡片墙 gap：16px。
- 卡片内 padding：16px。
- 圆角：10px。
- 描边：1px。
- 顶栏高：56px。
- 页面最大宽度：1200px，左对齐，不居中。

这套数值全站统一，不做局部特例，目的是让四页看起来像同一个房间里同一批板子。

## 7. 后续可扩展方向

1. 分镜板卡片支持拖拽换序，顺序变化直接写回后端，让"场记板墙"从只读变成可编排。
2. 成片库海报帧支持多帧预览，鼠标悬停在卡片上时按时间轴切换几张抽帧，方便快速判断成片质量。
3. 生产看板的胶片管线接入实时进度，正在生成的集在齿孔带上跑条纹动画，和任务队列的条纹动画共用同一套动效。
