# 全站国际化（i18n）接入说明

本文件说明 drama-factory 控制台的中英双语机制、key 规范、新页面接入流程与英文文案风格约定。

## 一、总体机制

- 唯一入口：`/i18n.js`，IIFE 全局单例，挂载 `window.DFI18N`。零依赖，无构建步骤。
- 语言偏好双通道持久化：
  - 服务端：`PUT /api/auth/profile { language }`，白名单 `zh-CN` / `en`，非白名单返回 400。
  - 本地缓存：`localStorage['df-lang']`，值为 `'en'` 时视为英文，其余一律 `zh-CN`。
- 页面接入方式：所有页面在各自的业务脚本之前引入 `/i18n.js`。

## 二、DFI18N API

| 方法 | 说明 |
| --- | --- |
| `DFI18N.readLang()` | 读 `localStorage['df-lang']`，返回 `'zh-CN'` 或 `'en'`。try/catch 包裹，不抛错。 |
| `DFI18N.getLang()` | 返回模块内缓存 `currentLang`，初始值等于 `readLang()`。 |
| `DFI18N.tr(key)` | 按字典注册逆序查找（后注册覆盖先注册）。命中取 `entry[currentLang] || entry['zh-CN'] || key`；未命中直接返回 key。任何情况不抛错。 |
| `DFI18N.register(dict)` | 注册字典，形如 `{ 'a.b': { 'zh-CN': '中文', 'en': 'English' } }`。调用前判空：`if (window.DFI18N) DFI18N.register(X)`。 |
| `DFI18N.applyI18n(root)` | 刷新 `currentLang`、设置 `document.documentElement.lang`，扫描 `(root || document)` 下所有 `[data-i18n]`（置 textContent）、`[data-i18n-ph]`（置 placeholder）、`[data-i18n-title]`（置 title）。 |
| `DFI18N.setLang(lang)` | 返回 Promise。next 归一化为 `'en'` / `'zh-CN'`。若与当前一致直接 resolve。否则先调 `Auth.updateProfile(null, null, next)` 落服务端，失败则 reject、UI 保持原语言；成功后写 localStorage、`applyI18n(document)`、依次触发 `onLangChange` 回调、派发 `CustomEvent('df:i18n-change', { detail: { lang } })`。 |
| `DFI18N.onLangChange(cb)` | 订阅语言切换，返回取消订阅函数。cb 非函数时返回空函数。 |

## 三、key 命名规范

格式：`<页前缀>.<小驼峰名>`。小驼峰名首字母小写，语义化、尽量简短。

页前缀列表：

| 前缀 | 页面 |
| --- | --- |
| `ws` | 工作区首页 |
| `chat` | AI 对话 |
| `img` | AI 图片 |
| `mus` | AI 音乐 |
| `mv` | AI MV |
| `ava` | 数字人 |
| `run` | 运行列表 |
| `rund` | 运行详情 |
| `agt` | Agent 机队 |
| `sk` | Skill 市场 |
| `usg` | 用量统计 |
| `qc` | 成片质检 |
| `sb` | 分镜板 |
| `task` | 任务队列 |
| `fin` | 成片库 |
| `pipe` | 生产看板 |
| `tool` | 快捷工具 |
| `set` | 设置 |
| `login` | 登录 |
| `reg` | 注册 |

应用壳（`shell.js`）专用前缀：`nav.` / `navgroup.` / `title.` / `pal.` / `shell.`。

account 页沿用既有无前缀 key（`doc.title` / `page.title` / `profile.*` 等），`account.html` 的 `data-i18n` 属性保持不变。

通用 key 以 `c.` 开头，由 `i18n.js` 自带并注册（`SHARED` 字典），各页直接复用，不得自造同义 key：

`c.save` / `c.cancel` / `c.delete` / `c.edit` / `c.new` / `c.close` / `c.confirm` / `c.loading` / `c.empty` / `c.search` / `c.retry` / `c.back` / `c.refresh` / `c.all` / `c.create` / `c.update` / `c.submit` / `c.view` / `c.download` / `c.upload` / `c.copy`。

## 四、新页面接入 4 步

1. **引入脚本**：在页面本地脚本区最前面加 `<script src="/i18n.js"></script>`，必须早于业务脚本（如 `shell.js`、页面自己的脚本）。
2. **注册字典**：在页面 IIFE 内定义字典并注册，判空保护：
   ```js
   var PAGE_I18N = {
     'sb.title': { 'zh-CN': '分镜板', 'en': 'Storyboard' }
   };
   if (window.DFI18N) DFI18N.register(PAGE_I18N);
   ```
3. **HTML 标注**：静态文案加 `data-i18n="key"`；placeholder 用 `data-i18n-ph`；title 属性用 `data-i18n-title`。保留中文原文作为降级。
4. **动态渲染收尾**：每次动态渲染 DOM 后调 `DFI18N.applyI18n(container)`；页面启动时订阅语言切换：
   ```js
   if (window.DFI18N) {
     DFI18N.applyI18n(document);
     DFI18N.onLangChange(function () { DFI18N.applyI18n(document); });
   }
   ```

语言切换器的标准实现见 `shell.js` 顶栏的 `.lang-switch`（分段按钮，点击调 `DFI18N.setLang`）。

## 五、英文文案风格指南

- 地道产品英文，短、动词开头，不写四字 polished 短语。
- 禁用词：Unleash / Empower / Seamless / Next-generation，以及中文同类词（如「赋能」「一键解锁」「无缝」「新一代」）。
- 按钮用祈使句动词：Save / Cancel / Delete / Submit / Retry / Refresh。
- 空态与错误信息保持中性、可操作，不写营销文案。
- 品牌词不译：AI MV、Agent、Skill、Google / Apple / GitHub 等。
- 标点：英文用半角，句末不加句号（除非是完整句子）；省略号用单个 `…`。
- 中文文案逐字保留：标点全角半角都不动。

## 六、account 页历史实现说明

`account.js` 在 v2.28 之前自带一套本地 i18n 实现（`currentLang` / `readLang` / `tr` / `applyI18n`）。本轮迁移到 `DFI18N` 后：

- 本地 `I18N` 表原文保留、key 不变，启动时通过 `DFI18N.register(I18N)` 注册进字典栈，因此 `account.html` 的 `data-i18n` 属性一个不用改。
- 删除本地 `currentLang` / `readLang` / `tr` / `applyI18n` 定义，统一走 `DFI18N.tr` / `DFI18N.readLang` / `DFI18N.getLang` / `DFI18N.applyI18n`。
- 语言单选按钮的 `change` 处理改为 `DFI18N.setLang(next).then(...)`，保留「先落服务端再切语言」的语义（失败回滚由 `setLang` 内部实现）。
- `reloadMe` 拿到用户后仍写 `localStorage['df-lang']`（保持原逻辑），再调 `DFI18N.applyI18n()`。
- 文件顶部加 `if (!window.DFI18N) throw new Error('i18n.js 未加载')`，fail-fast，避免脚本加载顺序意外导致半残状态。
