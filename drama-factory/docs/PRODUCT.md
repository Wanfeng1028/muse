# drama-factory 产品说明（灵魂一页纸）

## 一句话命题

给一个自然语言目标，Harness 规划并调度一群专用 Agent 干活：编剧 → 分镜 → 视频生成 → 剪辑 → 质检，软件核心是运行（Run）的全生命周期管理。

不是看板，不是工作台。是对标 Codex Cloud / DeepSeek Harness 的 Agent 承载与调度底座，垂直在短剧生产。

## 目标用户

- 有技术背景的个人/小团队：会 `docker compose up`，能填 API Key，想批量试短剧题材，接受 CLI 与日志。
- 无技术背景的个人/小团队：只想要一句"做一部 3 集短剧，题材都市情感"，点确认，等成片。

两类人共用一个入口：自然语言目标 + 确认执行。

## 核心对象：Run

### 新建运行
1. 输入自然语言目标（例：做一部 3 集短剧，题材都市情感）。
2. Harness 调规划 Agent 产出计划预览：Agent 序列、每步输入输出、预计调用模型、预计费用（未知写"—"）。
3. 用户确认 → 执行。确认即执行，第一版不做计划编辑器。

### 运行详情
- Agent 时间线：每步显示状态（待执行/执行中/成功/失败/降级/等待审批）、耗时、输入输出摘要。
- 工具调用可展开：LLM 请求、视频通道调用、ffmpeg 命令，原文与结果都可见。
- 控制：暂停、继续、取消、重试某步、人工审批门。
- 审批门：质检步骤默认人工终审，可配置自动通过阈值（待定）。

### 运行历史
- 每次运行可回放：时间线、产物、日志。
- 改参数重跑：改目标文案或模型/通道选择，生成新 Run，旧 Run 保留。

### Agent 机队（5 个专用 Agent）
每个 Agent 的提示词模板、选用模型、降级策略在 Agent 机队页可查、可改（改后对新 Run 生效）。

| Agent | 职责 | 选用模型 | 降级策略 |
|---|---|---|---|
| 编剧 Agent | 目标 → 分集剧本 | DeepSeek（真实调用） | 失败降级模板 |
| 分镜 Agent | 剧本 → 结构化分镜 | LLM 结构化输出 | 失败降级模板（待定） |
| 视频生成 Agent | 分镜 → 视频片段 | DashScope wan2.5 / Agnes agnes-video-2.5-flash / mock | 拥堵降级到下一通道 |
| 剪辑 Agent | 视频片段 → 成片 | ffmpeg | 无（本地执行） |
| 质检 Agent | 成片 → 质检报告 | LLM + 人工终审 | 人工兜底 |

### 配额与成本
- 按 Run 统计 token 与费用。
- 只记真实数：模型返回的用量与单价可查则记；不可查写"—"。不估算，不编造。

### 产物 Artifacts
- 每次运行归档：剧本、分镜、视频片段、成片、质检报告。
- 存 H2 + 文件系统，路径在运行详情可见。

## 配套能力

- 设置中心：API Key 脱敏持久化（DeepSeek / DashScope / Agnes）；连通性以实际调用为准，不做虚假探测。
- 一键安装：Docker Compose 或 `java -jar`。
- 首次引导：填 Key → 试跑一个示例目标 → 看到第一条 Run。
- 用户手册：安装、Key、跑第一个 Run、读懂时间线、常见降级说明。
- 运行步骤实时日志：轮询增量拉取，时间线内联展示。

## 信息架构（页面清单）

- 运行列表：所有 Run 的状态、目标、耗时、费用。
- 新建运行：目标输入 → 计划预览 → 确认执行。
- 运行详情：Agent 时间线 + 控制 + 产物 + 日志。
- Agent 机队：5 个 Agent 的模板、模型、降级策略。
- 设置：Keys、通道、默认模型、审批门开关。
- 保留既有 7 页：AI 工作区（chat-first 首页）、AI 对话、分镜板、任务队列、成片库、生产看板、质检页。作为底层能力直连入口，Harness 层包在上面，不重写。

## 不做清单

- 工作台式总览看板。
- 内置浏览器。
- 终端。
- 用户账号体系（单机单用户）。
- 云端同步。

## 自查三问

**别人愿不愿意装？**
愿意。`docker compose up` 即用，真实链路已验证：DeepSeek 编剧 → 分镜 → 三通道视频 → ffmpeg 成片 → 人工终审，EP01 真实成片已产出。

**和 Codex Harness 的差异？**
一句话：垂直在短剧生产，Agent 全部是影视工种（编剧/分镜/视频生成/剪辑/质检），不是代码工种。

**第一版砍掉什么？**
多用户、云端、计划编辑器。确认即执行，要改就改参数重跑。
