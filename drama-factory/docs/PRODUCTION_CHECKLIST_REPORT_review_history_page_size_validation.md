# 发版对照报告：审核历史 page/size 参数收紧（drama-factory）

| 验收项 | 结论 | 理由 |
|---|---|---|
| 可靠性 | 改进 | 控制器入口显式校验分页参数，避免超大页返回；校验逻辑不再依赖 `PageRequest` 内部行为，行为更明确可预期。 |
| 可观测性 | 无变化 | 未新增日志/指标；参数非法时抛出的异常经全局处理器统一处理，HTTP 400 响应结构与既有保持一致。 |
| 数据与状态 | 无变化 | 无数据库/缓存/状态机变更；仅前置参数校验，合法请求的 service 调用路径与返回结果一字未动。 |
| 部署与运维 | 无变化 | 无部署脚本/环境变量/健康检查变更；无版本号升级，按常规单元测试流程上线即可。 |
| 安全与健壮性 | 改进 | 新增 `size` 上限（200）与 `page`/`size` 非负/正数校验，拒绝显式非法输入；参数校验前置于归属查询，减少无效数据库访问。 |
| 可维护性 | 改进 | 控制器 Javadoc 明确标注 `page`/`size` 范围；校验逻辑从隐式依赖 `PageRequest` 改为显式声明，降低后续维护理解成本。 |

## 已知限制
- 本轮未运行全量测试套件，仅定向运行了 `ReviewHistoryPaginationValidationTest` 与 `ReviewApiTest`。
- 未做真实服务 HTTP 冒烟验证，HTTP 400 映射依赖全局异常处理器既有行为。
- 无 UI 变更，不适用视觉验收。
