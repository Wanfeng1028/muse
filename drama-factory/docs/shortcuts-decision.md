# 快捷键产品决策（drama-factory）

> 结论先行：**做 6 个**（画布/分镜板 5 个 + 命令面板内提示 1 项）；**不做**全局单字母快捷键与自定义配置。现有 3 个快捷键保留。

## 现状（60c7fad 实测源码）

| 快捷键 | 位置 | 行为 |
|---|---|---|
| `⌘K` / `Ctrl+K` | `shell.js:359` | 全局命令面板（输入框聚焦时不触发，Esc 关闭） |
| `Esc` | `shell.js:366`、`run-detail.js:501` | 关闭命令面板 / 关闭抽屉 |
| `Ctrl+Enter` / `⌘+Enter` | `chat.js:313` | 发送对话 |

画布（canvas.html）、分镜板（storyboard.html）、MV 页当前**零快捷键**。

## 决策：做

### D1 画布页（canvas.html）—— 分镜卡片键盘操作
| 快捷键 | 行为 | 说明 |
|---|---|---|
| `←` / `→` | 选中上/下一张分镜卡片 | 时间轴+网格同步高亮；到头循环或停住（二选一，产品定） |
| `Enter` | 打开选中卡片的编辑器 | 与点击卡片等价 |
| `Delete` / `Backspace` | 删除选中分镜 | **必须二次确认**（toast 撤销或确认弹窗二选一） |
| `Esc` | 关闭编辑器 / 取消选中 | 与现有 Esc 范式一致 |

### D2 分镜板（storyboard.html）—— 同 D1 子集
`←` / `→` 切分镜行选中、`Enter` 编辑、`Esc` 关闭。Delete 在分镜板暂不做（删除是画布职责，避免两处逻辑分叉）。

### D3 空格预览（canvas.html）
- `Space`：预览选中分镜（图片放大 / 视频试播）；再按一次关闭
- **必须加焦点保护**：焦点在 `input`/`textarea`/`select` 或编辑器打开时不触发（复用 `shell.js:362` 的 tag 判断范式）

### D4 命令面板内标注快捷键
- ⌘K 面板每个命令右侧用等宽字体标注快捷键（如 `← → 切换分镜`），等宽字体用 `--mono`（DESIGN_SYSTEM.md §2 已规定快捷键用等宽）

## 决策：不做（及理由）

| 不做项 | 理由 |
|---|---|
| 全局单字母快捷键（如 `j/k` 导航、`?` 帮助） | 与中文输入法冲突风险高；现有 ⌘K 面板已覆盖"不用鼠标"诉求 |
| `g d` 这类序列快捷键 | 学习成本高，短剧工具用户不是 Vim 人群 |
| 自定义快捷键配置页 | 提测前不做；等用户真实反馈再排期 |
| MV/图片/音乐页快捷键 | 表单型页面，Tab 键已够用；ROI 低 |

## 落地约束（写给执行方）

1. 焦点保护是红线：任何快捷键不得在用户打字时触发（`document.activeElement.tagName` 在 `INPUT/TEXTAREA/SELECT` 或 `[contenteditable]` 时全部跳过）
2. 快捷键必须可发现：D4 的面板标注 + 画布页右下角一次性的"← → 切换 · Enter 编辑"弱提示（可关闭）
3. Delete 二次确认不许用 `confirm()` 原生弹窗（风格不统一），用站内 toast 撤销或抽屉确认
4. 不许引入新的全局 keydown 监听冲突：统一收到 `shell.js` 的全局处理器或各页独立命名空间，Esc 关闭顺序为"编辑器 > 抽屉 > 面板"

## 工作量估计

D1+D2+D3：约 0.5 天（含测试）；D4：约 2 小时。建议与 P1 UI 修复同批交付。
