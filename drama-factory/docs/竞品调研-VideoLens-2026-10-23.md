# 竞品调研：VideoLens（videolens.cc）— 2026-10-23

> 目的：为剧坊新增「视频拆解」功能做公开功能面调研。只读其公开落地页/样例页/定价页与公开分发的前端 JS 产物；未登录、未付费、未绕过任何限制，未复制其代码与 UI。

## 产品一句话

VideoLens 是「视频反推提示词」工具：粘贴抖音/TikTok/小红书链接或上传本地视频，一键拆解爆款结构、逐镜分析分镜与运镜、提取逐字稿与屏幕文案，输出适配 Seedance（落地页口径 2.5）的可生成提示词与创作剧本。定价按视频分钟计费，新账号有免费额度。

## 公开功能清单（来源：落地页与各工具页的公开文案、定价页 meta）

### 1. 视频转提示词（核心）
- 输入：抖音/TikTok/小红书分享链接或分享文字；或上传本地视频文件（流程与输出一致）。个别平台暂不支持链接解析，需先下载再上传（FAQ 口径，未点名）。
- 产出：
  - **逐镜提示词**：每镜还原为结构化画面提示词——景别、主体、运镜、光影、调色，可粘贴进任意视频模型生成。
  - **多模型适配导出**：同一套结构一次导出为 Seedance 可直接生成的提示词；定价页口径还含 Sora、Kling、Runway。
  - **逐字稿与屏幕文案**：台词、旁白、屏幕文字带时间轴转写。
  - **深度拆解报告**：剧本概要、全局设定、类型专项分析、创作操盘手册（playbook）、推荐标签、完整时间线——主打「看懂为什么火」。

### 2. 视频文案提取（独立工具页）
- 带时间轴逐字稿（多语种、含中文）、屏幕文字（标题/字幕/花字）识别、按分镜对齐的可复用文案脚本；附带分镜拆解与反推提示词。

### 3. 图片反推提示词（独立工具页 /zh/image-to-prompt）
- 上传图片反推提示词：主体、构图、镜头、色调、光线、风格，中英双语，兼作文生图复现与图生视频提示词。

### 4. 其他公开面
- 样例页（/zh/showcase）：真实热门视频的拆解与提示词示例（页面声明仅作学习演示、可应作者要求移除）。
- MCP 页（/zh/mcp）：对外提供 MCP 接入（细节需登录，未深入）。
- 用户群：短视频创作者、内容运营/MCN、电商带货、AI 视频创作者、编导剪辑师、广告营销策划。
- 商业模式：按分钟计费的额度包（定价页 meta 起价 19 CNY），免费额度试用。

## rea 静态分析结果（如实）

- 对象：落地页公开分发的 Next.js chunks（11 个文件，约 1MB，2026-10-23 下载自 videolens.cc）。
- 全目录分析：分析器对大型共享 chunk 逐个 180 秒超时，零文件保留（与此前混淆/压缩 bundle 的经验一致）。
- 单文件分析（仅落地页 page chunk）：**成功建图**（graph id 前缀 jag_5f28dd62，输出约 1.1MB）。但落地页是纯营销页：图中无 API 端点、无业务调用——真正的应用在登录后，公开产物里拿不到其拆解管线实现。
- 从公开产物可确认的功能级事实（字符串层）：站点路由含 /image-to-prompt、/showcase、/pricing、/mcp、/blog、/faq、/changelog；API 域名为 api.videolens.cc，媒体资产走 r2.videolens.cc（Cloudflare R2）。仅作功能理解，未据此克隆其服务接口。

## 数据口径约定（本功能全程执行）

报告与逐镜数据按三类标注，杜绝把猜测包装成识别结果：
- **实测数据**：ffprobe 元数据、场景切分点、关键帧、时长类指标——真实测量。
- **规则推断**：节奏分类、结构段划分、镜头构成占比、公式提炼——确定性规则，规则写在代码与本文档中。
- **待 AI 增强**：主体、画面描述、景别、运镜、光线、调色——留 `DeconstructionVisionEnricher` 接口与开关，未接入视觉模型前一律显式标注待增强。
