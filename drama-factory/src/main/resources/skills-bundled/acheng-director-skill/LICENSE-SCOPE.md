# AC Director 许可范围

本文件把包内不同材料的许可边界写清楚，避免把一个许可证错误地套到所有文件上。

| 文件或内容 | 默认许可 | 说明 |
| --- | --- | --- |
| `scripts/` 中由 Acheng 编写的脚本、机器合同和校验逻辑 | Apache-2.0，见 `LICENSE` | 允许使用、修改和分发，但必须保留许可证、NOTICE 和修改说明；不授予 AC Director 商标权。 |
| 根 `SKILL.md`、`modules/*/SKILL.md`、`references/` 中由 Acheng 编写的指南、提示词、合同和框架文字 | CC BY-NC-ND 4.0，见 `LICENSE-DOCS.md` | 允许带署名分享原文；禁止商业使用和改编分发。翻译、重写、合并成另一套 skill 都属于需要单独书面许可的改编。 |
| `examples/` 中的原创生产卡、示例提示词和案例说明 | CC BY-NC-ND 4.0，除非文件内另有声明 | 示例里的第三方素材、品牌、角色或参考图不因本包而获得再授权。 |
| `references/sources/`、`references/sources/licenses/` 中的第三方材料 | 各自原许可证 | 必须同时遵守对应来源的许可证、署名和使用限制；不能用 AC Director 许可证覆盖它们。 |
| 用户自己提供的剧本、图片、视频、音频和生成媒体 | 用户或原权利人的权利 | 本包不替用户取得这些材料的版权、肖像权、商标权或模型服务权。 |

当前组合是“代码开放、创作文本受限”的 source-available 发布方案。它适合分享工具和方法，同时保留提示词体系与品牌控制；它不是完整的 OSI 开源发布。如果目标是允许他人商业改编文档，应把文档许可改为 CC BY-SA 4.0 或 Apache-2.0，并同步修改本文件、`LICENSE-DOCS.md`、`NOTICE` 和发布说明。

许可证只解决授权范围，不能自动证明作者身份或第三方来源清洁。发布前仍需保留创作源文件、版本时间线、来源记录、贡献者确认、发布 ZIP 的 SHA-256 和第三方许可证清单。
