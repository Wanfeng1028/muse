# 安全问题报告

请不要在公开 issue、示例生产卡或提示词中提交密钥、访问令牌、私有路径、客户素材、未公开漏洞或付费服务凭据。

如果发现会造成凭据泄露、任意文件写入、供应链篡改、许可证污染或发布包完整性问题，请通过项目维护者的私下联系方式报告，并提供：影响版本、最小复现、受影响文件、可能的修复建议和是否已经公开。没有私下渠道时，先不要公开敏感细节；在发布平台建立私密安全报告入口后再使用该入口。

维护者应在修复前保留原始报告、确认影响范围、撤销泄露凭据、修订受影响包、重新生成 SHA-256，并在公开说明中只披露必要事实。安全修复不能删除第三方许可证、来源证据或把未生成媒体写成已完成。
