# 46｜条件特效家族与世界规则

先选family，后装配适用字段。features.supernatural_vfx沿用旧字段名作为“需要特效合同”的开关，也可用于自然破坏/天气设计；它不是所有效果都超自然的断言。无效果时不创建空vfx对象。

| family | 主体与过程 | 必须锁定 | 不强制添加 |
|---|---|---|---|
| energy_fluid | 喷流、剑气、火焰与能量攻击 | 既有流体主干、作用起点、接触、粒子来源和相位 | 无来源固体碎片 |
| destruction | 裂纹、形变、断裂、坍塌 | 受力点、传播、支撑失效与可用路线 | 魔法辉光或能量主干 |
| weather | 雨、雪、风、沙尘、云 | 来源、方向、遮挡、表面响应与能见度 | 每次都出现冲击和爆点 |
| transformation | 身体/物体形变 | 起态、拓扑允许变化、中间可读过程、终态身份 | 默认流体化或随机增肢 |
| spatial | 门、折叠、重力区、时间表现 | 边界、进入/退出、物体归属、世界能力限制 | 不存在的撞击面 |
| optical | 隐身、幻象、折射、投影 | 背景采样关系、遮挡、阴影/反射是否保留、终止条件 | 粒子与发光描边 |

非energy_fluid对象必填origin、scope、process、end_state、lighting、continuity，以及events[{start,end,cue}]。这些都是可见的具体英文描述；不得把family代号拼进最终提示词。events按局部帧排序，允许效果前后保留安静区，不要求四阶段强制铺满。

隐身例：腰部装置启动，外套轮廓内的背景逐渐连续，接触地面的影子仍存在；杯子因未在作用域中而保持可见。终态描述谁隐去、道具是否仍可见、后续能否被声音定位。这个合同无需流体、碰撞或三态粒子。

空间门例：门面在固定墙口内建立，人物从正面进入后应从已登记出口出现；进出时间、携带道具和身体完整性写入上游事件。视效不能替编剧增加一个从未登记的逃生地点。

OPTIMIZE冻结family、origin、过程、作用域、事件时间/内容与结果。允许改变lighting以及明确独立的表面表现字段；需要改变效果过程时返回主导演修订，不能通过“优化”越权。能量家族保留既有collision/phases冻结规则。

巨构与特效交叉时，先保护尺度证据，再调整局部光与介质；不能为了奇观把基准物、支撑、交通路线全部藏进烟雾。写意媒介把物理关系转成色块/线势/虚实，不强制现实材质参数。
