# 95｜十项基础门、三项条件合同与验收边界

每个适用门 10 分；缺失或违约得 0 分并阻止编译，未适用记 N/A 并说明分母。总分是适用门归一到 100 的结构合同得分，不是艺术排名。任何失败不能被其他门高分抵消；“全球第一”无法用这些脚本客观证明。

| 门 | 机器检查 | 必须另做的内容／成片检查 |
|---|---|---|
| G1 时间闭合 | 整数帧、总时长、连续镜头、Segment覆盖和4–15秒范围 | 台词与动作实际能否演完，剪辑把手是否正确 |
| G2 Previs | 001–132、摄影参数和改编声明 | 运动是否真的符合白模家族，是否观看了源片 |
| G3 物理事实 | 生产描述禁词，保留既有对白 | 用术语空话替代证据仍不合格 |
| G4 表演 | 所选完整五轨/选择性轨道/来源events格式、时窗与可见性声明 | 自然度、可见尺寸、不是全身抽动 |
| G5 七层攻防 | 七字段＋攻应果续 | 接触是否发生、力链是否可读 |
| G6 条件视效 | 能量家族的流体/三通道/四相位；其他家族的来源/作用域/过程/终态/事件 | 来源和材质是否正确、主体是否被光淹没 |
| G7 巨构证据 | 百米角色触发、至少两种证据与位置／深度 | 同深度比较是否真的成立，是否仍像玩具 |
| G8 H3结构 | 模式、真实素材、标签、3／6字段、16格、对白、独立人物／场景／状态描述和代号拦截 | 引用图内容与描述是否相符、任何未定义简称或隐含承接、描述与账本是否一致 |
| G9 声场 | 拟音与配乐分离、低频Hz合理或原因、35Hz不标次声 | 实际音轨与频谱、语音逐字和声画同步 |
| G10 连续性 | 重放事件、before校验、守恒、每镜状态及final | 损伤、道具和环境在生成画面中真的保持 |

没有生成媒体时视觉状态恒为 UNVERIFIED。本任务交付技能和生产范例，不调用付费生成；结构 PASS 的样例不能称“成片已通过”。

追加条件门：narrative_contract检查任意线路、知情重放、伏笔、关系与剧本/镜头覆盖；performance_handoff检查来源锁、十二项信息、相位映射与未消费项；performance_liveliness在启用acting_design时检查人物目标/策略/潜台词、触发—动作—跟随因果、运动弧、对白锚点、切镜声音与段级motion_profile；asset_coverage检查声明的全资产需求、依赖无环、版本、批准文件哈希和逐镜使用。full_production不得跳过叙事和资产门。旧局部样例可N/A，不能据此宣称全剧完整。

图像出口另经post_hooks assets及compile_assets：必须有完整正文、显式无需图／必须图策略、正确上传编号与实际文件。交付前逐条阅读实际`.image.txt`和`.h3.txt`，按[72独立交付合同](72-standalone-prompt-delivery.md)检查生成模型不应依赖的内部简称。两类上传清单及素材副本必须与导出正文一起验收。

最终验收覆盖：主入口与七专业入口路由可解析、各项依赖规范存在、132项索引与源一致、原始100条和新增100条完整、至少八套范例及全部五模式可编译、资产草案与可提交状态分开、资产名称纯净出口、场景/叙事/状态链闭合、非法输入被拒绝、只改特效不触碰剧情、冷档案可恢复且幂等、打包安装文件一致。脚本检查后只做一次当前差异自审；真实失败修复后只重跑受影响部分再执行最终包验收。

适用性由剧情负责，flags不是免责开关。正文写了超常能量却关闭 supernatural_vfx，属于内容审查失败；当前脚本可发现“结构payload存在但flag关闭”，不能从任意自然语言自动证明所有语义。门禁不得靠删掉真实字段绕过。
