# 模型输出：把实际参考消费到正文和上传步骤

执行方式见 [115](../115-directed-decisions.md)。先读已安装 h3-prompt-writing 的对应指南；本指南不更改字段、模式、详细度或最终格式门。生产引用依据 [114](../114-reference-binding-delivery-v4.3.6.md)。

## M0｜工序前置与资产就绪自检门禁（Sequence & Asset Readiness Gate）

宿主 AI 撰写 H3 视频生成提示词前，必须执行以下强制自查：
1. **资产全量就绪问询**：所有资产图提示词（风格母图 `STYLE_MOTHER`、角色四视图 `CHAR_*`、场景设计图 `SCENE_*`、核心道具 `PROP_*`、分段关键帧 `KEYFRAME_*`）是否已全部编写完成并就绪？
2. **绝对前置铁律**：严禁在资产图提示词未完成前抢跑撰写 H3 视频生成提示词！

## M1｜先识别图片的角色，再分配标签

读取当前 Segment 的模式锁、Shot reference_requirements 和资产批准版本。

1. 这张图提供可复用身份／环境／道具，还是某一时刻的整帧构图？前者通常以 Subject 定义内容、Picture 作为来源；后者单独定义 Picture 的首帧／尾帧／关键帧／构图作用。
2. 同一图确实兼任两者时，Subject 管身份，anchor_shot_ids 限定整帧构图作用；不要让第一镜的坐姿在后续奔跑镜头反复生效。多主体图逐个登记实际对象，不按文件数量猜人数。
3. 人物四视图只应还原成一个人物。整张接触表不作为基础模式的单个首尾帧。需要单帧时先由 assets 提供批准的单幅资产；不得通过改模式绕过缺图。
4. 模式未锁定时，按用户所需关系选择：无引用为 T2VA；实际首帧为 I2VA；实际首尾帧为 FL2VA；仅尾帧为 L2VA；多个内容／规划参考按 Ref2VA。已锁模式存在冲突则报告，不静默切换。

写回原 references/subjects，保持真实来源、用途、preserve/exclude、Shot 范围与版本。Subject 不增加上传槽位。

用途和状态有疑问时读[编号实际证明什么 Q31](../inquiries/model.md#q31)。资料库条目、镜头品牌、情绪编号和 .image.txt 都不是可上传图片，不分配 Picture 标签。

## M2｜图片状态会不会在错误时间生效

先找到图中伤势、物件持有、场景破坏与当前 state_in 的差别。若变化已在批准事件发生，限制参考到相应 Shot／帧窗，并按已有 state_guards 表达可计算断言；若变化尚未发生，不把该状态当开场。画面布局等不能由账本证明的内容交主导演看图核对，不填写“机器已确认画面”。

## M3｜参考关系怎样进入 H3

从同一绑定快照生成六字段或基础三字段。逐镜检查重要对象第一次出现处是否写出身份、当前位置、当前动作及适用标签；独立关键帧写清到达或离开的路径。preserve/exclude 的含义保持一致，但不要以引用标签代替完整描写。对白沿用对应 Subject 与实际 speaker，音频仅在真实声明的用途上引用。

只有映射没有角色外观、动作因果或尾态时，回到缺失源字段补足再编译。语法整理不压缩正文；输出达到上限沿原 partial/cursor/commit 机制继续。

独立上下文断开时读[缺哪项事实 Q30](../inquiries/model.md#q30)；长度不足或冗长空泛时读[详细度缺口 Q32](../inquiries/model.md#q32)。定位到 owner 和字段，不用全库素材堆词。材质条目须被改写为本段的具体物件、光源/画法、可见响应和当前状态，不能把条目 ID 直接当正文。

## M4｜用户拿到包之后能否找到每一张图

- 每个 H3 Segment 独立核对正文、绑定快照、媒体副本与上传卡。编号属于当前请求，不照搬上一段。
- H3 包内若附资产 .image.txt，也必须附该提示词自己的参考图、编号、用途与缺项卡；不能只给 reference_count。它们用于先生成资产，并不自动成为每段 H3 的输入。
- 只存在提示词或未批准媒体时交完整草案，保留待绑定项。真实图片和哈希就绪只说明本地可上传；平台上传与生成质量仍分别记录。
- 用脚本核对最终字节及交付映射。不要另写 YAML 自证表复刻时间线或手填 PASS。

## M5｜风格或动画语言尚未落实

先读批准 style_lock、当前 style 和 motion_profile。色彩变化需要依据时读[色彩作用范围 Q21](../inquiries/model.md#q21)；动画曝光/拖影需要选择时读[节拍与帧率 Q19](../inquiries/model.md#q19)。按[视觉库](../116-visual-reference-library.md)筛当前媒介的候选，库内 terms 只路由到原88术语；仍需原 animation_term_evidence 的具体展开，不能以作画师、引擎或器材名代替。

同组条目先比较再采纳，不能默认混合；跨组也检查描述冲突。采纳范围落在 style/motion_profile，身份图、场景几何和锁定动作不被重新设计。

## M6｜环境声、声音桥与配乐的作用不清

只读当前问题：[声源与遮盖 Q27](../inquiries/model.md#q27)、[声音先到/后留 Q28](../inquiries/model.md#q28)、[音乐观看立场 Q29](../inquiries/model.md#q29)。持续底声写 overall_soundscape，配乐写 non_diegetic_music；局部事件交原 shots/performance，最终遵守 H3 全局声音句数与局部说话人规范。跨独立生成请求的声音桥保留后期接力需求，不宣称已经无缝合成。
