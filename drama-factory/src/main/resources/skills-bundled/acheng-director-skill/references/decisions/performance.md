# 表演与动作：用可见条件缩小选择

执行方式见 [115](../115-directed-decisions.md)。先读取 expression_handoff（若有）、当前镜头可见范围、伤势／能力、锁定台词和触发事件。使用 [30](../30-performance-adapter.md)、[31](../31-performance-handoff.md)、[32](../32-liveliness-performance-framework.md)、[40](../40-action-choreography.md) 的已有输出字段。

## P1｜情绪名称还没有变成表演

1. 这次反应由当前哪一个已发生的声音、动作或信息触发？没有新触发时承接上一拍状态，不再完整重演一次惊讶或愤怒。
2. 角色希望对方看见什么、要藏住什么？只从当前目标与锁定来源取值；不知道的动机不编造成事实。
3. 画面实际看见眼、嘴、肩、手中的哪些部位？先排除画外部位和伤势不允许的动作，再选一个主要反应与必要的一个泄漏信号；无需填满五轨。
4. 查 [30](../30-performance-adapter.md) 中与此目的相符的配方，保留适用动作，删除违背身体条件或镜距的部分。收尾写反应停在哪里，下镜从哪里继续。

例：压住怒意继续谈判、镜头只有头肩，可用短暂中断的视线与恢复平稳的声线；画外握拳不能承担本镜关键证据。配方是候选，不能凭命中情绪名就整条复制。

不知道演什么时读[行动策略 Q05](../inquiries/performance.md#q05)；知道动机但不知道怎么让观众察觉时读[可见泄漏 Q06](../inquiries/performance.md#q06)；台词与动作功能冲突时读[信息通道 Q07](../inquiries/performance.md#q07)。三者不是每拍必走的三道手续。

## P2｜动作只有“打中／飞出”的结果

先锁定攻击者、目标、当前支撑、接触或落空、已批准结果。依序补：从哪里启动 → 什么部位沿什么路径到达 → 接触／避开后谁先变化 → 如何传到身体或物件 → 最后在哪里停止。

- 脚下有支撑时可描述蹬地与重心转移；悬空、受伤、机械或非人主体改用其已设定机制，不强套肌群。
- 已批准为落空时，补惯性收势与对方下一拍权限，不虚构碰撞。
- 已批准为接触时，从接触部位先写可见反应，再到支撑变化和道具状态；不新增牛顿数、伤势或胜负。

写回 combat 七层与 chain/timing，长度和阶段仍由原合同检查。

只补具体断口：[启动支点 Q14](../inquiries/performance.md#q14)、[接触前后 Q15](../inquiries/performance.md#q15)、[慢动作多看见什么 Q16](../inquiries/performance.md#q16)。保留原五阶段和整数帧门；资料原文的四阶段与固定帧数不取代它。

## P3｜动作很普通，是否需要改变

先检查原动作是否已清楚表达人物目的；成立即可保留。需要辨识度时，只从已登记的道具握法、惯用动作、受伤限制中选一个改变动作方式的条件。例如同样是阻止对方拿取，可改变接触点或利用现有物件阻挡；不能把道具突然写成新武器能力。新增的变化必须仍得到原定结果。

需要展开具体取舍时读[现有道具如何改变接触方式 Q17](../inquiries/performance.md#q17)，不执行“前两个想法必须推翻”。

## P4｜台词与动作抢同一口气

读逐字台词、停顿和接触时刻。判断说话是否恰逢憋气、猛烈碰撞或遮住口部；将可移动的动作声／表演节拍安排在已有停顿，不能擅自改锁定台词或时间。超容量交给 shots／主导演，不让 model 在编译时删字。

连续重音挤在一起时读[反应/收势/呼吸间隔 Q34](../inquiries/performance.md#q34)，写具体需要被看见或听见的事件；没有事件需求就不造固定空白。

## P5｜动画夸张是否破坏身份和承接

项目允许挤压拉伸、夸张透视时才读[变形与恢复 Q18](../inquiries/performance.md#q18)。先保留身份轮廓、持物和支撑，再限定某部位在哪个相位改变、怎样恢复。曝光节奏交 model 的 M5，碎片与闪光交 effects；作画师资料只提供表现候选，不改变各 owner 的权属。
