# 《Seedance 打斗 Prompt 模板》v5.1 剧情锁定版

> 给 AI 模型读的打斗视频 prompt 生成协议。
> v5.1 目标: 保留原模板的动作密度、因果链、镜头贴附和生成强度, 但取消会改写剧情的重编权限。
>
> 本版适合承接上游已锁定分镜 / 招式单元 / 关键动作链, 把它们细化成稳定视频 prompt。

---

## Part 0 · 一句话总则

AI 的任务是: 根据用户给出的剧本片段或已锁定分镜单元, 扩写出一段可直接喂给 Seedance 2.0 / 即梦 / Sora 的打斗视频 prompt。

默认生成一个 10-15 秒的完整动作单元, 最终 prompt 目标字数 1200-1400 字, 硬上限 1500 字。多场景、长剧情、跨时空内容必须拆成多个 prompt, 不塞进同一段。

执行时只做一件事:

```
读输入 -> 判断是否为锁定分镜 -> 锁定剧情结果/动作顺序/视觉锚点/出口 -> 判结构 -> 判题材 -> 选压力曲线 -> 选动作簇素材 -> 生成连招方向链 -> 逐拍绑定镜头贴附与物理化结果 -> 套字段 -> 按 1200-1400 字目标细化动作因果链 -> 自检 -> 输出 prompt
```

输出时不要解释流程, 不要输出分析, 只输出最终 prompt。

规则优先级:

```
用户剧情与动作锁定 > 用户禁止改写项 > 固定输出格式 > 结构公式 > 当前题材小卡 > 动作连续性 > 动作簇素材 > 风格词 > 附录素材
```

如果用户输入是已锁定分镜、招式单元、镜头表或明确动作链, 其中的剧情结果、动作顺序、关键动作、视觉锚点和转场出口都是硬约束。模板只负责补动作衔接、物理反馈、镜头贴附、音效和生成友好表达。

如果用户只给一句粗略剧情, 可以按原流程主动补动作细节, 但不得改写用户明确指定的剧情结果、胜负关系、角色能力、武器法器和结尾去向。

## Part 1 · 固定输出格式

所有 prompt 默认使用以下字段。字段名固定, 顺序固定。

```
【整体风格】
整体风格: [风格组合 + 动作类型 + 画面质感],
[物理呈现方式 + 主体清晰要求 + 技术约束]

【角色卡】
- @图片1作为[主角/角色身份]: [外观锚点 + 武器/能力 + 动作倾向 + 本段攻守位置]
- @图片2作为[对手/角色身份]: [外观锚点 + 武器/能力 + 动作倾向 + 本段攻守位置]

【场景设定】
[地点 + 时间 + 光源 + 关键物件 + 可被破坏/响应的环境锚点]

【画面坐标】
[1-2 行: 只写开场空间定位。说明主体在画面左/右/中央/前景/深处, 以及主要威胁从哪个方向进入]

【起幅】或【起势】
[对打/形态演化用【起幅】; 单人武学演绎用【起势】]

【过程】
[核心动作展开。战斗类默认 4-6 个连续攻防节点; 变身类 3-4 个阶段; 武学演绎 4-6 个连续招式]

【结尾】
[终段一击接结果爆发 / 转场坠入 / 压制完成, 镜头不断流]

【音效】
[逗号分隔, 只取本题材声音]

【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】
无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

格式保留硬规则:

```
【整体风格】必须保留“整体风格:”开头。
【角色卡】必须使用“- @图片1作为...” “- @图片2作为...”格式。
不要把角色卡改写成“女主：”“敌人：”“主角：”这种普通冒号格式。
即使用户没有上传图片, 也先按 @图片1/@图片2 作为占位写法输出。
```

### 1.1 【整体风格】写法

用紧凑 2-3 行, 不写长篇说明。

```
整体风格: [调性词1] + [调性词2] + [调性词3],
[特效/速度/力量] 通过 [具体物理现象 A]、[具体物理现象 B] 呈现, 不出现 [跨题材污染词]。
主体清晰可读优先于 [炫技/特效/快切], 动作不断流, 命中不定格, 中段镜头稳定跟随, 高帧率流畅。
```

### 1.2 可选字段

默认不输出可选字段。只有在以下情况才加:

```
【特效细节】  适合 T4/T5/T6/T7 或公式 B, 用来约束粒子、装甲、黑雾、光效边界。
【负面提示词】  题材不稳定、用户要求、或主体容易被特效吞没时使用。
```

可选字段必须放在【音效】之前。

### 1.3 字数目标与 1500 字硬限制

默认最终输出目标字数 1200-1400 字, 硬上限 1500 字, 包含所有字段、正文、音效、禁止项和强制声明。

不要把“不得超过 1500 字”理解成“越短越好”。除非用户明确要求极简版, 否则低于 1100 字通常视为信息不足, 需要补足动作因果、环境反馈和镜头反馈。

推荐字段预算:

| 字段 | 字数预算 | 写法 |
|---|---:|---|
| 【整体风格】 | 100-140 | 2-3 行, 写调性、物理呈现、主体清晰约束 |
| 【角色卡】 | 140-200 | 每个角色 1-2 行, 必须包含动作功能 |
| 【场景设定】 | 130-190 | 地点、光源、4-6 个环境锚点 |
| 【画面坐标】 | 50-80 | 独立字段, 只写开场方位和空间轴线, 不嵌入每个动作 |
| 【起幅】/【起势】 | 150-220 | 建空间 + 第一动作/触发 + 初始环境反馈 |
| 【过程】 | 650-780 | 战斗类必须写 4-6 个连续攻防节点; 每个节点改变距离、身位、攻守或空间压力之一 |
| 【结尾】 | 130-190 | 终段动作 + 结果爆发 + 空间位置, 不写慢收势 |
| 【特效细节】 | 0 或 100-140 | 只在 T4/T5/T6/T7 或公式 B/C 必要时使用 |
| 【音效】 | 80-130 | 10-14 个音效, 逗号分隔 |
| 固定末尾 | 约 60 | 原样输出, 不压缩改写 |

压缩优先级:

```
先删修辞 -> 再删重复运镜 -> 再删低价值环境细节 -> 再合并角色描述
不要删 6 变量因果链、题材一致性、末尾固定项。
```

1500 字模式下的数量限制:

```
战斗类通用: 【过程】必须写 4-6 个连续攻防节点, 不得少于 4 个。每个节点至少包含 1 个攻防动作 + 1 个位移/身位变化 + 1 个命中或避开反馈 + 1 个环境/镜头反馈。
对打类: 不再写成 3 个孤立命中点; 可以有 2-3 个关键命中结果, 但必须拆成 4-6 个连续攻防节点, 命中点之间要有衔接动作。
剧本改编类: 【过程】围绕 1 个关键动作结果展开, 写 4-6 个快速攻防节拍, 但不新增第二个剧情锚点。
群战类: 写 2 个群体动作 + 1 个代表性终段, 不逐个敌人。
形态演化: 写 3-4 个阶段, 每阶段 1-2 句。
单人武学演绎: 写 4-6 个连续招式, 用“——”串联, 不拆成过多小段。
音效: 10-14 个, 不写长解释。
可选字段: 【负面提示词】默认不输出, 只有用户明确要求或主体稳定性风险很高时才加; 【特效细节】能并入正文就不单列。
```

素材调用硬规则:

```
每个动作节拍必须至少调用:
1 个动作/武术词 + 1 个环境反馈词 + 1 个镜头词。
不要只写剧情结果。
不要只写“打、躲、反击”这类泛词。
不要让剧本道具连续承担 3 个以上节拍; 道具完成格挡/破坏/封路功能后, 节拍必须回到人物攻防。
```

攻防节点计数规则:

```
1 个攻防节点 = 方向/身位变化 + 攻击或防守动作 + 命中/避开/格挡结果 + 环境或镜头反馈 + 下一招衔接。
只写场景、角色摆姿势、单独特效、单独运镜、慢收势、纯结果描述, 都不计入攻防节点。
4-6 个节点必须在【过程】中明确可读, 不能压缩成“两人高速交手数回合”这类概述。
```

低于 1100 字时的补足顺序:

```
1. 给【过程】补足 4-6 个快速攻防节拍
2. 给环境锚点增加明确物理反馈
3. 给角色卡增加动作功能, 不加外貌废话
4. 给结尾增加终段结果和空间位置, 不加慢收势
5. 音效补到 10-14 个, 但不跨题材
```

### 1.4 【画面坐标】写法

【画面坐标】是独立空间定位字段, 只写一次, 放在【场景设定】之后、【起幅】之前。

它只负责回答:

```
主体开场在画面哪里
威胁从哪个方向进入
空间纵深/退路在哪里
```

正确:

```
女主位于画面中央偏前景, 背后是巷尾卷帘门; 夹克男从画面深处右侧冲入, 左侧墙面和水洼形成狭窄退路。
```

不要把【画面坐标】扩散到每个动作节拍里。除非动作本身需要明确空间关系, 【过程】不强制写画面左/右/前景/深处。

### 1.5 动作连贯性默认规则

打斗类 prompt 默认追求连续性, 不是 MV 式卡点展示。

默认禁止写:

```
0.5 秒定格
子弹时间
慢镜头编号
停顿半拍
命中停半拍
失焦回正
升格细节
时间恢复
画面冻结
悬停半拍
```

除非用户明确要求慢动作、定格海报感、子弹时间或单人美学展示, 否则所有命中、破坏、转场都必须保持动作不断流。

连续战斗应该这样写:

```
命中后借力转向
碎片擦过前景完成遮挡转场
镜头贴身跟随不断切入下一招
对手被击退的同时另一侧攻击接上
环境反馈跟随动作滚动发生, 不单独停下来展示
结尾只负责最后一次结果爆发和空间位置, 不写慢收势、渐熄、恢复平静
```

## Part 2 · 生成主流程

### 2.1 第一步: 剧情锁定层

先判断输入类型。若用户输入是已锁定分镜、招式单元、镜头表或明确动作链, 不得再降维重编; 必须先锁定动作顺序、关键结果、视觉锚点和本段出口, 再进入题材、动作簇和镜头细化。

只有当用户输入是一句话粗略剧情、缺少明确动作顺序时, 才允许使用剧情功能骨架补全打斗过程。

核心原则:

```
锁定分镜输入:
入口 -> 已锁定动作节点 1 -> 已锁定动作节点 2 -> 已锁定动作节点 3... -> 出口

粗略剧情输入:
开场画面 -> 中间关键结果 -> 结尾画面
```

锁定分镜里的连续动作可以直接进入 prompt, 但要被改写成更清楚的动作因果链。动作簇只提供词库、节拍密度、镜头贴附方式和物理反馈, 不能覆盖原动作。

关键区别:

```
锁定分镜限制的是“不能改剧情结果和动作顺序”, 不是“不能增强表现”。
一个已锁定动作节点可以拆成 1-3 个微动作, 让画面有速度和密度。
但微动作必须服务原节点结果, 不能变成第二个剧情事件、第二个道具奇观或第二个转场事件。
```

#### 2.1.1 剧本信息分级

| 等级 | 内容 | 处理 |
|---|---|---|
| S 级 · 功能事实 | 场景题材、主角状态、主要对手、敌方压力、进出场/转场结果 | 必须进入剧情功能骨架 |
| A 级 · 视觉事件 | 共享单车被打穿、灯笼被斩断、巨雷被劈开、无人机蜂群等 | 如果来自锁定分镜, 按锁定顺序保留; 如果来自粗略剧情, 只保留最关键结果, 其余转为气氛残留 |
| B 级 · 动作细节 | 翻滚、蹬墙、跃上栏杆、横挡、连刺、格挡等 | 如果来自锁定分镜, 必须保留动作结果和顺序; 如果只是粗略描述, 可适度优化 |
| C 级 · 分镜指令 | 时间码、镜头标签、慢镜头编号、子弹时间编号、画面骤暗 | 时间码和镜头标签用于锁定顺序; 不稳定生成词可改写 |
| D 级 · 过密细节 | 同一段内连续太多招、太多道具、太多特效、太多切换 | 压缩表达, 但不删除用户锁定的剧情结果 |

#### 2.1.2 剧情保真原则

```
保留剧情功能、结果方向、动作顺序、关键动作路径、转场入口和出口。
细化怎么衔接、怎么受力、镜头怎么贴、环境怎么反馈。
```

例:

```
锁定分镜写: 孙悟空踩筋斗云闯门 -> 金箍棒扫碎云台 -> 二郎神开天眼锁空 -> 悟空脱云翻身下砸 -> 刀棒相撞。

不要改成其他闯门方式, 不要删除天眼锁空, 不要提前写分身或法相。
应细化为:
云尾撕开云海 -> 棒风先压裂云台再扫碎 -> 天眼竖光把弯曲云路钉成中轴 -> 悟空借被锁住的云尾反蹬翻身 -> 棒端与刀尖在中轴相撞。
```

#### 2.1.3 锁定动作卡 / 剧情功能骨架

如果输入已经有时间码、动作节拍、镜头标签、上游单元卡或明确动作链, 先写内部“锁定动作卡”。锁定动作卡不输出给用户, 但生成 prompt 时必须遵守。

| 锁定字段 | 该写什么 | 禁止写什么 |
|---|---|---|
| 场景容器 | 地点、空间结构、主要材质、光源 | 改成另一个场景 |
| 角色与能力 | 角色、武器、法器、能力边界 | 换角色、换能力、换武器 |
| 单元入口 | 本段从哪个画面 / 动作进入 | 提前写上一单元完整过程 |
| 锁定动作节点 | 4-6 个必须保留的动作结果和顺序 | 打散顺序、替换关键动作 |
| 中段关键结果 | 本段最重要的局势变化 | 新增第二个同等级结果 |
| 单元出口 | 本段结束时必须到达的位置、姿态或转场 | 改出口、提前进入下一单元高潮 |
| 必须保留视觉锚点 | 用户或上游指定的视觉锚点 | 删除、替换、挪到无关位置 |
| 禁止新增 | 不许出现的角色、能力、奇观、剧情结果 | 空着不写 |

锁定动作卡硬规则:

```
锁定动作节点必须按原顺序进入 prompt。
动作簇只能作为动作语言和微动作素材, 不能覆盖原动作链。
可以把一个锁定节点拆成 1-3 个微动作, 但微动作必须服务原节点结果。
可以补身位变化、攻防反应、环境反馈和镜头贴附。
不能新增胜负结果、转场结果、法器能力、角色登场或第二高潮。
```

如果输入只是一句话粗略剧情, 才使用剧情功能骨架:

| 骨架字段 | 该写什么 | 禁止写什么 |
|---|---|---|
| 场景容器 | 地点、时代、空间结构、主要材质、光源 | 连续分镜动作 |
| 主角状态 | 主角落点、姿态、弱势/强势、武器或身体状态 | 外貌作文 |
| 压力来源 | 对手类型、人数、威胁方式、主压迫方向 | 每个敌人的逐招动作 |
| 冲突功能 | 这一段本质在演什么: 逃生、破防、围攻、反杀、转场、觉醒 | 无关奇观 |
| 中段功能结果 | 中段必须发生的 1 个局势变化 | 多个连续奇观 |
| 结尾功能结果 | 最终胜负、姿态、转场门、坠落、收势 | 改写用户指定结尾 |

粗略剧情补全时仍然不得改写用户明确指定的关键动作、视觉锚点和结尾结果。

#### 2.1.4 锁定节点抽取表

锁定分镜不再压成三画面锚点。每个 10-15 秒单元保留上游锁定的 4-6 个动作节点, 并把它们写成连续过程。

| 节点类型 | 从输入抽什么 | prompt 里怎么用 |
|---|---|---|
| 开场入口 | 当前场景 + 主角状态 + 主要威胁第一次显形 | 写进【起幅】/【起势】, 建立空间和初始压力 |
| 动作节点 | 已锁定的动作顺序、动作结果、关键视觉锚点 | 按顺序写进【过程】, 用动作簇增强力学和镜头贴附 |
| 中段关键结果 | 本单元最重要的局势变化 | 写成【过程】中最清楚的一次命中、锁定、失控或夺权 |
| 结尾出口 | 转场/胜负/坠落结果 + 终段空间位置 | 写进【结尾】, 保持运动感, 不写下一单元完整剧情 |

未进入锁定卡的内容不能新增为剧情事件。若只是为了顺滑, 可以作为微动作、环境余波、镜头遮挡或音效处理, 但不能改变动作结果。

#### 2.1.5 锁定节点的动作簇写法

“锁定动作节点”不是只写一句结果。它应该写成一条有因果的微动作簇:

| 节拍 | 功能 | 必须调用的素材 |
|---|---|---|
| 节拍 1 | 逼近 / 起手 / 空间压迫 | 动作词 1 个 + 镜头词 1 个 |
| 节拍 2 | 主角防守或借物格挡 | 防守/格挡/步法词 1 个 + 环境反馈 1 个 |
| 节拍 3 | 关键命中或道具破坏 | 载体 + 命中位置 + 反应 + 环境 + 镜头 |
| 节拍 4 | 主角短促反制 | 拳脚/兵器/借物反击词 1 个 + 对手反应 |
| 节拍 5 | 反制失败, 对手压迫升级 | 压迫动作词 1 个 + 镜头恢复/拉回 |
| 节拍 6 | 推向结尾位置或终段姿态 | 位移/撞击/逼退词 1 个 + 结尾环境锚点 |
| 节拍 7 | 可选加压或反制失败 | 二次压迫/短促反击失败/最后距离压缩 |

动作簇规则:

```
可以多招, 但只能围绕一个锁定动作结果。
可以快, 但每个节拍必须有清楚因果。
可以有反制, 但反制不能发展成新的剧情节点。
可以有环境反馈, 但不能新增第二个大型奇观。
每个节拍必须从当前题材小卡取动作/反应/环境/镜头词, 不允许只写剧情概述。
```

镜头链规则:

```
动作簇必须包含一条镜头链:
建空间 -> 跟随动作 -> 命中瞬间转向 -> 遮挡/擦镜/震动 -> 继续接招 -> 揭示结果
```

常用镜头取法:

```
建空间: 低位贴地推近 / 过肩压迫 / 远景缓推
跟随动作: 贴身跟拍 / 横移跟拍 / 环绕半圈 / FPV 贴近
命中瞬间: 急速推镜 / 特写切入后立刻接下一招 / 短促震动不断流 / 借力转向
遮挡反馈: 水花扑镜 / 碎片擦过前景 / 雨雾遮挡 / 火星遮挡
连续揭示: 贴身拉回两人全身 / 反打结果接下一拍 / 甩镜接位移 / 余波中保持运动
```

雨巷例:

```
锁定节点是“单车被打穿”。
动作簇可以写: 对手逼近 -> 女主横车格挡 -> 单车被打穿 -> 女主抛开断车贴身肘膝反制 -> 反制被压回 -> 推向锁定出口。
不能再写成新的独立事件: 消防栓爆水、阳台跳跃、额外上勾拳慢镜头。
```

#### 2.1.6 剧本道具降权硬规则

剧本道具不是动作主体, 只能服务人物攻防。

道具预算:

```
单段 prompt 最多选择 1 个“过程主道具”。
过程主道具最多占用 2 个动作节拍。
【起幅】里允许 1 个一次性起手投掷物, 只用于制造第一威胁, 不进入【过程】反复使用。
如果结尾另有转场道具/奇观, 它只能放在【结尾】, 不得提前侵入【过程】。
其余节拍必须回到人物攻防: 逼近、闪避、格挡、短促反制、压迫升级、身位变化、命中反馈。
```

起手投掷物规则:

```
必须发生在冲刺/追击/逼近中, 不能让角色停下来摆拍。
只能写一次: 抄起 -> 掷出 -> 主角躲开或格挡 -> 物件退场。
物件可以是垃圾桶盖、铁质广告牌、路障、碎木板、车门残片等场景小物。
投掷物不能再被拿来连打、封路或承担中段主轴。
```

正确:

```
共享单车承担“横挡 + 被打穿”两个节拍,
之后必须回到人对人的卡腕、顶膝、肩撞、逼墙、重踢等攻防。
```

错误:

```
共享单车被打穿 -> 断车架反扭 -> 车轮空转 -> 整辆车被压低 -> 破车架继续封路
```

这会让道具成为主角, 人物攻防被挤掉。

另一个错误:

```
对手为了展示力量, 停在原地先打一拳墙或砸一下无关物体。
```

威胁必须藏在进攻里: 猛冲、投掷、撞开、逼近、命中, 不要停下来摆拍。

例外:

```
T5 机甲本体不是道具, 属于角色身体。
T6 恐怖场景里的门、镜子、灯可以高频出现, 但仍必须服务追逃压迫或怪物显形。
公式 B 的触发物只服务变身阶段, 不得延伸成过程主轴。
```

#### 2.1.7 锁定外新增控制规则

一旦确定锁定动作卡, 锁定外内容不得作为新的剧情事件进入正文, 哪怕它很精彩。

```
锁定外内容不能新增胜负、转场、角色能力、法器结果、第二高潮或大型奇观。
只能被吸收为: 微动作、压迫感、节奏感、环境余波、镜头遮挡、音效层。
```

判断标准:

```
如果会改变锁定出口 -> 禁止。
如果会改变动作顺序 -> 禁止。
如果会新增第二个中段结果 -> 禁止。
如果需要额外道具或额外镜头解释 -> 禁止。
如果只是让画面更热闹但不服务锁定节点 -> 禁止。
```

允许:

```
锁定节点“金箍棒扫碎云台”可以增强为:
棒风先压出弧形裂纹 -> 云台碎块擦镜 -> 二郎神身影仍稳在中轴。
```

禁止:

```
在同一节点里新增分身、法相、哮天犬、第三方天兵或额外法器爆发。
```

锁定节点增强优先级:

```
优先增强身体力学。
优先增强接触点物理反应。
优先增强环境验证。
优先增强镜头贴附。
不要新增纯炫技、纯闪避、纯镜头奇观。
```

#### 2.1.8 多场景剧本处理

跨题材剧本必须拆成多个 prompt, 每个场景单独处理。不要把 1 分钟多场景剧本压成一个 1500 字 prompt。

对用户给的穿越类剧本, 先拆单元:

```
场景 1 现代雨巷 -> T2/T1, 单独 prompt
场景 2 古代客栈 -> T3/T4, 单独 prompt
场景 3 云海仙侠 -> T4, 单独 prompt
场景 4 赛博高空平台 -> T2/T7, 单独 prompt
```

每个单元只保留一个明确终点, 例如“被踢入霓虹光门”“跌入黑洞”“被震入云门”“被漩涡吞掉”。

#### 2.1.9 模板可控增强权限

AI 可以主动增强以下内容:

```
动作衔接
微动作数量
身体力学
运镜方式
分镜卡点安排
特效出现频率
环境反馈强度
音效密度
生成友好表达
```

AI 不得改写以下内容:

```
当前场景题材
主角是否进入/离开该场景
关键对手类型
关键奇观结果
用户明确指定必须出现的视觉锚点
锁定动作顺序
锁定招式数量
锁定道具/法器参与方式
锁定转场入口和出口
胜负关系
```

### 2.2 第二步: 清理剧本输入

| 输入情况 | 处理方式 |
|---|---|
| 一句话剧本 | 主动补角色招式、场景物件、光源、物理后果、音效 |
| 含对白 | 去掉对白, 转成表情、情绪、呼吸、嘶吼、动作节奏 |
| 含情绪 | 情绪转成运镜和节奏, 如悲壮 -> 慢推 + 低频环境音 |
| 含演员/IP | 不写真实演员或 IP 名, 转成身形、服装、招式、气质 |
| 群战多人 | 合并群体, 用代表性击倒 + 余波带倒 |
| 多场景跨切 | 拆成多个 10-15 秒单元, 不塞进一个 prompt |
| 静态分镜 | 补成“画面里发生了什么 + 造成什么后果” |

### 2.3 第三步: 判结构

先判结构, 再判题材。结构只有三种:

| 结构 | 适用 | 核心写法 |
|---|---|---|
| A 对打 | 两个或多个主体互相攻击 | 每个命中点写完整 6 变量因果链 |
| B 形态演化 | 变身 / 觉醒 / 异化 / 化神 / 单事件显化 | 起态 -> 触发 -> 分层覆盖 -> 终态完成 |
| C 单人武学演绎 | 剑舞 / 拳路 / 无对手美学展示 | 起势 -> 连续招式用“—”分隔 -> 连续收势 |

混合剧本默认主走 A:

```
变身后打斗 -> 起幅用 B, 过程和结尾用 A
打中觉醒 -> 前半 A, 结尾嵌入 B
化神后接战 -> B 完成终态后, 只写一个短促 A 命中点
```

### 2.4 第四步: 判题材

按顺序判断, 命中更具体题材优先:

| 触发词 | 题材 |
|---|---|
| 恐怖 / 邪典 / 怨灵 / 无面人 / 鬼怪 / Boss / 反生理 | T6 邪典恐怖 |
| 机甲 / 装甲 / 赛博战士 / 变身 / 机械组装 / 粒子装甲 | T5 机甲变身 |
| 极速者 / 超音速 / 闪现位移 / 撞穿墙体 / 残影 / 音障 | T7 极速者 |
| 剑气 / 御空 / 法术 / 灵气 / 化神 / 神识 / 渡劫 | T4 玄幻仙侠 |
| 江湖 / 客栈 / 雨夜屋檐 / 刀剑 / 武林 / 侠客 / 古装真功夫 | T3 低魔武侠 |
| 写实科幻装备 / 赛博朋克 / 短促能量 / 仿生肢体 / EMP / 全息分身 / 局部装备强化 | T2 凡躯超英 |
| 拳脚 / 格斗 / 拳馆 / 街头 / 搏击 / 对打 / 雨巷 / 力量夸张但无装备能力 | T1 现代街战 |
| 无明确题材 | 默认 T1 现代街战 |

T1/T2 边界硬规则:

```
只有“打穿单车、撞凹卷帘门、冲刺撞开障碍、力量异常强”等物理夸张, 但没有装备、科技机制、能量释放、仿生肢体或明确超能力时, 仍归 T1 现代街战, 可写成“强化街战”。
T2 必须有明确能力来源或科幻机制: 局部装备、仿生关节、EMP、全息分身、脉冲、电弧、液压外骨骼等。
都市霓虹、雨夜、力量大、抗打, 不足以单独判为 T2。
```

### 2.5 第五步: 判镜头模式

| 镜头模式 | 用词规则 |
|---|---|
| 一镜到底 | 只写【镜内转向】【镜内推近】【镜内拉远】【镜内甩到】【镜内环绕】, 不写【切镜】 |
| 多镜快切 | 可写【切镜】【特写切镜】【反打切回】【甩镜闪切】 |
| 长镜头穿插 | 少硬切, 多写“镜头持续跟拍, 视角滑到...” |

命中瞬间可用:

```
急速推镜 / 镜头轻震不断流 / 特写切入后接下一招 / 碎片擦镜转场 / 甩镜闪切 / 贴身拉回
```

### 2.6 第六步: 选择题材动作簇

题材小卡决定“用什么词”, 动作簇决定“怎么打”。生成【过程】前必须先选 1 个动作簇。

选择规则:

```
根据锁定动作卡 / 粗略剧情功能骨架 + 题材 + 本段锁定节点 + 主角胜负关系, 从 Part 4.5 选择一个动作簇。
不要把 T1/T2 真人肉搏节拍套到 T3-T7。
如果剧本是混合题材, 以当前场景的主要视觉规则为准。
```

动作簇使用规则:

```
从该动作簇的“可选节拍菜单”中选 4-6 个节拍。
不必全用, 不必固定顺序。
每个节拍必须调用该簇的动作素材 / 环境反馈 / 镜头素材。
不得选用其他题材动作簇, 除非用户明确要求混合风格。
```

#### 2.6.1 连招编排层: 四条规则的调用顺序

动作簇只提供素材, 连招编排层决定这些素材如何连成一条不断流的战斗线。生成【过程】前, 必须先在内部完成以下 4 步; 这张内部表不输出给用户。

```
1. 连招方向链
2. 每拍动作因果
3. 镜头贴附动作路径
4. 装饰词物理化
```

连招方向链:

```
先写 4-6 个方向/身位变化, 不先写华丽形容词。
格式: 切入方向 -> 折返方向 -> 压进方向 -> 横移/纵跃方向 -> 终段方向
```

例:

```
左斜切入 -> 右侧折返 -> 正面压进 -> 贴地横扫 -> 垂直终击
```

每拍动作因果:

```
方向/身位变化 -> 招式/载体 -> 命中或避开的位置 -> 接触点物理化 -> 身体/环境后果 -> 下一招衔接
```

例:

```
战士从蜘蛛左足外侧左斜上撩,
刀锋切入甲壳关节,
接触点冒出白热灼痕,
紫黑雾被高温逼退半米,
她借反作用力反喷折到右侧,
右斜下斩立刻接上裂口。
```

镜头贴附动作路径:

```
镜头不能独立说“快速摇摄/切分/跟拍”。
镜头必须说明它贴着哪个动作、被什么遮挡、如何接到下一招。
```

正确:

```
镜头贴住粒子刀刃横甩, 甲壳碎片擦过前景遮住半屏, 下一瞬甩到战士折返后的右侧身位。
```

错误:

```
镜头快速切分和摇摄, 展现强烈打击感。
```

装饰词物理化:

```
抽象强度词不能直接进【过程】。
必须转换成: 当前题材载体 -> 接触点物理现象 -> 身体/环境后果 -> 边界限制。
每个动作节拍最多调用 2 个物理化结果:
1 个接触点结果 + 1 个身体/环境后果。
```

调用表:

| 想表达 | 不要写 | 物理化调用 |
|---|---|---|
| 强 | 毁天灭地 / 震撼全场 / 极致爆发 | 甲壳凹陷、金属弯折、地面裂纹扩散、对手倒退、碎片被气浪推开 |
| 快 | 快到看不清 / 超高速炫技 | 刀光刚离开左侧, 身体已折返右侧; 雨滴拉成短线; 残影只保留半个身位 |
| 热/能量 | 雷霆灼烧毁灭波动 | 接触点白热灼痕、空气短促扭曲、黑雾被逼退、粒子沿刀口喷出后消散 |
| 压迫 | 压迫感拉满 / 恐怖窒息 | 退路被蛛网封住、前景蛛足压住半屏、尸体和碎片被气浪推开 |
| 华丽 | 炫酷粒子特效 | 粒子只沿刀刃单向流动、命中时短弧残留、不遮住主体轮廓 |

结尾隔离规则:

```
【过程】负责连招展开。
【结尾】只写终段动作 + 结果爆发/转场 + 空间位置。
不得把【过程】的四向连斩、连续劈扫、连刺路线复制到【结尾】。
不得写慢收势、能量渐熄、灯光恢复稳定、残影慢慢消散、主角摆姿态。
```

### 2.7 第七步: 选择动作压力曲线

压力曲线不是固定招式公式, 不是规定第几拍必须试探、第几拍必须破防。它只检查一件事: 每个节拍是否让局势发生变化。

根据剧情功能骨架选择 1 条压力曲线, 再从动作簇菜单里取 4-6 个节拍填进连招方向链。动作可以换, 题材可以换, 但局势不能原地踏步。

| 压力曲线 | 适用 | 局势变化 |
|---|---|---|
| 压迫递增型 | 强者逼弱者、窄巷、墙角、拳台边缘 | 还能躲 -> 勉强挡 -> 被逼退 -> 空间封死 -> 终段命中 |
| 反制失败型 | 弱者有求生反击, 但力量差明显 | 被压制 -> 短暂反击 -> 对手硬吃 -> 主动权被夺回 -> 败退 |
| 诱敌反打型 | 主角冷静、技巧更高、以退为进 | 退让 -> 暴露破绽 -> 借位闪开 -> 反打关键点 -> 收势 |
| 波峰波谷型 | 双方实力接近, 互换主动权 | A 压制 -> B 反压 -> A 改招 -> B 受挫 -> 终段定局 |
| 蓄力爆点型 | 变身、机甲、仙侠大招、终段重击 | 低压铺垫 -> 层层蓄势 -> 环境预兆 -> 单次爆发 -> 余波收束 |
| 群战扩散型 | 多敌围攻、怪物群、机器人群 | 单点威胁 -> 多方向包围 -> 借力连带倒退 -> 包围撕开 |
| 追逃逼近型 | 恐怖追杀、极速截击、走廊逃生 | 远处显形 -> 距离缩短 -> 遮挡失效 -> 近身擦过 -> 尽头/截停 |
| 单人流转型 | 剑舞、拳路、无对手演绎 | 起势 -> 连续变向 -> 速度峰值 -> 细节掠过 -> 终段动作结束在余波中 |

使用规则:

```
同一段只选 1 条主压力曲线。
压力曲线只规定局势变化, 不规定具体动作名称。
连招方向链必须服务压力曲线: 每次切入、折返、压进或跃起, 都要改变距离、身位、攻守或空间压力。
不要把所有对打都写成“试探 -> 破防 -> 终结”。
如果剧本已有动作, 也要按压力曲线重排强弱关系, 不能平铺照抄。
```

### 2.8 第八步: 选择镜头策略

镜头策略不是固定分镜表, 而是镜头立场。它回答“观众站在哪一边感受这段动作”。

生成【过程】前, 必须选 1 个镜头策略。每个动作节拍仍可变化镜头, 但所有镜头要服务同一立场。

镜头策略也从剧情功能骨架选择: 逃生压迫就贴主角, 兵刃破防就贴兵器线, 群战围攻先建空间, 转场奇观只在结尾回收。确定镜头策略后, 每个镜头词必须贴附到连招方向链中的某一拍, 不得独立漂浮。

| 镜头策略 | 适用 | 镜头立场 | 视觉母题 | 信息揭示与回收 |
|---|---|---|---|---|
| 压迫贴身型 | 街战、追杀、弱者被压制 | 贴近被压迫者的呼吸和退路 | 低位水面 / 对手拳头前景 / 墙面逼近 | 先感到逼近, 命中后拉回看见退路变少 |
| 兵刃核心型 | 武侠、仙侠近战、刀剑拆招 | 镜头围绕兵刃轨迹和手腕变化 | 刀锋 / 剑尖 / 火星 / 衣料浅痕 | 先看兵器线, 再揭示身位胜负 |
| 重量仰拍型 | 机甲、巨物、重击、强化肉搏 | 从低位感受重量和压迫 | 脚掌 / 液压关节 / 地面裂纹 / 碎片前景 | 命中震动后拉回, 看清破坏中心 |
| 高速追踪型 | 极速者、追逐、瞬移截击 | 镜头追踪本体, 残像只作辅证 | 雨滴拉线 / 残像路径 / 水痕 / 音障圆环 | 先被甩开, 再贴回本体, 最后揭示运动路径 |
| 恐怖遮挡型 | 怨灵、旧楼、反生理怪物 | 镜头站在逃生者视角, 信息故意不完整 | 门缝 / 镜面 / 顶灯闪黑 / 水渍倒流 | 先遮挡, 突然贴近, 再拉远确认威胁位置 |
| 大场面调度型 | 仙侠对轰、群战、云海、战场 | 镜头先建立空间规模, 再锁回主体 | 云海 / 阵纹 / 包围圈 / 高低层次 | 先看空间关系, 命中后回收主体与余波 |
| 单人演绎流线型 | 剑舞、拳路、变身展示 | 镜头沿身体和兵器运动线流动 | 衣袂 / 发丝 / 剑尖 / 粒子边界 | 先跟动作线, 细节从镜头前掠过, 最后在余波中保持运动 |

镜头策略规则:

```
镜头词可以来自动作簇, 但必须被镜头策略统领。
不要每拍随机堆“推拉摇移、跟拍、慢镜头”。
一段至少有 1 个重复视觉母题, 例如水面、拳头前景、刀锋、门缝、残像路径。
结尾必须回收空间信息: 谁在什么位置, 结果造成了什么变化。
```

## Part 3 · 三种结构的写法

### 3.1 结构 A: 对打

每个核心命中点都必须符合 6 变量公式:

```
[打击者] 用 [载体: 拳脚/兵器/特效/速度] 击中 [对手具体位置]
-> [受击反应]
-> [环境响应]
-> [镜头反馈]
```

示例:

```
女主右脚蹬地转髋, 中段侧踢踢中男主腹部
-> 男主弯腰后退三步
-> 后背撞上便利店玻璃门, 玻璃震出蛛网纹
-> 镜头轻震后立刻贴身跟上女主下一步追击
```

对打类三段:

```
【起幅】建立空间关系 + 第一威胁
【过程】1500 字模式默认 4-6 个连续攻防节点, 其中 2-3 个可作为核心命中点, 每个核心命中点完整写 6 变量
【结尾】终段动作 + 结果爆发 + 空间位置
```

### 3.2 结构 B: 形态演化

用于变身、觉醒、异化、化神、单事件显化。

公式:

```
[起态] -> [触发物/触发情绪] -> [分层覆盖] -> [终态完成, 镜头继续缓推]
```

必须写清楚阶段, 不要直接跳终态:

```
皮肤/衣物/装甲第一层变化
能量/粒子/黑雾第二层覆盖
头部/眼睛/武器/标志物最后完成
环境被触发: 灰烬、雨滴、灯光、碎石、空气波纹
```

### 3.3 结构 C: 单人武学演绎

用于剑舞、拳路、单人武学美学展示。主体不变身, 没有对手。

公式:

```
[起势: 主体登场 + 初式]
-> [过程: 连续招式, 用“—”分隔, 不拆成多段互打]
-> [结尾: 终段一式 + 结果爆发 + 镜头不断流]
```

注意:

```
输出字段用【起势】替代【起幅】
不要写对手
不要写受击反应
重点写衣袂、兵器、脚步、风压、雨幕、落叶、地面介质
特效边界要克制, 主体动作永远清晰
```

此结构实测标杆不足, 使用时优先保守。

#### T4 斗法连锁补充规则

当 T4 场景以雷法、阵法、结界、剑气对轰为主时, 允许斗法大于近身连招, 但法术节拍必须互相咬合, 不要写成一关一关破解。

斗法连锁:

```
上一拍法术不得完全清零。
至少保留 1 个残余元素进入下一拍:
雷光残弧 / 阵纹余亮 / 云海压痕 / 剑气裂缝 / 护体光纹裂口 / 碎石悬浮轨迹。
下一拍必须利用、反转或放大这个残余元素, 形成连锁。
```

正确:

```
雷笼被女主斜挑切开一线, 但断开的雷弧没有消散,
反而沿青玉裂缝爬回她脚下, 修者只抬起两指,
残弧从女主脚下、身后云雾和剑锋侧面同时折返夹击。
```

错误:

```
修者打出掌心雷, 女主躲开。
修者又打出雷笼, 女主破开。
修者再打出巨雷, 女主劈开。
```

高位施法者压迫:

```
强者不靠频繁大动作制造威胁。
优先写: 指尖一点 / 袖袍一振 / 眼神下压 / 掌心翻转 / 双手合十。
法术从平台裂缝、身后云雾、脚下阵纹、剑锋侧面等多个空间位置合围。
表现“人不动, 空间在听他调度”。
```

## Part 4.5 · 题材动作簇库

> 题材小卡解决“词汇正确”, 动作簇解决“节拍正确”。
> 生成【过程】前, 必须先选 1 个动作簇; 再从该簇菜单中选 4-6 个节拍。
> 动作簇不是固定流程, 是可选节拍菜单。不要每次机械套同一顺序。

### 动作簇内部格式

每个动作簇按以下格式理解:

| 模块 | 作用 |
|---|---|
| 适用 | 什么时候选这个簇 |
| 结构适配 | 对应公式 A / B / C, 避免把所有题材写成同一种打斗 |
| 开场锚点 | 这个簇怎样进入第一个画面, 先建立什么空间/状态 |
| 中段任务 | 4-6 个节拍共同完成什么动作逻辑, 不是随便堆招 |
| 结尾锚点 | 这个簇最后留下什么结果画面或物理证据 |
| 可选节拍菜单 | 从中选 4-6 个, 不必全用 |
| 动作素材 | 当前簇可用动作/武术/能力词 |
| 环境反馈 | 当前簇应该触发的物理反馈 |
| 镜头素材 | 当前簇适合的镜头链 |
| 音效线索 | 当前簇应提取的声音 |
| 禁用 | 当前簇不该出现的东西 |

| 环境反馈 | 多处水花同时炸开 / 墙面多点裂纹 / 雨滴轨迹断裂 |
| 镜头素材 | 中景锁本体 / 残像半透明 / 命中点连续追踪 / 拉回主体清晰 |
| 音效线索 | 连续音爆 / 多点重击 / 水花 / 急促呼吸 |
| 禁用 | 残像多到分不清本体 |

### T7 极速者 · 穿墙破坏型

| 模块 | 内容 |

## Part 5 · 写作规则

### 5.1 动作永远写成因果链

不要写:

```
主角爆发出极致力量, 炫目的能量撕裂空间, 震撼全场。
```

要写:

```
主角右拳击中对手胸口, 对手胸口护甲凹陷, 整个人倒飞撞进砖墙,
墙面裂出蛛网纹, 镜头剧烈一震后立刻追上主角下一步压迫。
```

### 5.2 特效是动作副产品

正确顺序:

```
动作 -> 命中 -> 反应 -> 环境 -> 特效/镜头
```

错误顺序:

```
特效铺满屏幕 -> 主体被吞没 -> 不知道谁打了谁
```

### 5.3 群战合并写

群战不逐个写每个敌人。用:

```
三人同时被刀风逼退, 其中一人撞翻后方同伴
残余敌人退成半圈
一名代表性敌人被终段击倒
```

### 5.4 角色卡要有功能

角色卡不是外貌作文, 而是告诉模型动作偏好。

```
- @图片1作为女主: 动作偏低扫、侧踢、快速步法、短促肘击
- @图片2作为男主: 动作偏重拳、近身压迫、膝撞、抱摔
```

角色卡格式必须保留 @ 图片引用:

```
正确: - @图片1作为女主: ...
正确: - @图片2作为黑帽夹克男: ...
错误: - 女主: ...
错误: 女主：
错误: 黑帽夹克男：
```

如果用户没有提供图片, 仍然使用 @图片1/@图片2 作为角色占位, 不要改成普通角色名冒号。

弱势角色也必须有动作功能, 不能只写“被打、后退、摔倒”。除非用户明确要求处刑式碾压, 对打类默认给弱势方至少 1 次有效主动动作:

```
有效闪避: 改变双方距离或让攻击落空
有效格挡: 保住身体核心, 即使道具或护架损坏
有效反制: 让对手偏身、护架散开、重心偏移或节奏被打断
有效换位: 抢到外侧线、墙边空隙或更接近结尾位置
```

有效主动动作不等于反杀。它只需要短暂改变局势, 随后可以被更强对手压回。

### 5.5 音效从画面里提取

先写画面, 再回头“听”画面:

```
拳脚 -> 闷响
格挡 -> 格挡声
脚步 -> 摩擦 / 踩水 / 踩沙
环境 -> 雨滴 / 霓虹 / 风声 / 车流
特效 -> 电弧 / 粒子 / 灵气 / 黑雾, 只在对应题材使用
```

### 5.6 道具必须退到人物之后

道具只能承担三种功能:

```
防守载体: 横挡、缓冲、卡住攻击线
命中载体: 被打穿、被斩断、被砸碎
空间载体: 封路、遮挡、逼出身位变化
```

道具完成以上功能后, 必须退场或变成环境余波。不要让道具连续承担 3 个以上动作功能。

正确:

```
女主横起共享单车格挡, 车架被重拳打穿; 她立刻松手侧移, 用肘击和低扫抢回半步空间。
```

错误:

```
女主继续抓着破共享单车反扭、压低、卡腕、横扫、封路, 整个过程都围绕单车变化。
```

## Part 6 · 输出前自检

生成第一稿后, 内部执行以下条目。自检过程不输出。

### 自检 0: 固定格式

检查字段外形是否符合模板:

```
【整体风格】下方必须以“整体风格:”开头。
【角色卡】必须使用“- @图片1作为...”和“- @图片2作为...”格式。
不得输出“- 女主: ...”“女主：...”“对手：...”这种普通角色名格式。
```

失败时先修正格式, 再检查动作内容。

### 自检 1: 题材一致性

检查音效、特效、环境、调性是否都来自当前题材小卡。

常见错误:

```
T1 写实街战出现“粒子装甲 / 灵气 / 雷霆”
T3 低魔武侠出现“机甲撞击 / 警笛 / 赛博广告”
T6 邪典出现“科幻 UI / 机甲伺服”
只有力量夸张和雨夜霓虹, 没有装备/能力机制, 却误判成 T2
T2 没有任何科技或能力来源, 只是普通人打得很重
```

发现跨题材词, 立刻替换或删除。
T1/T2 摇摆时, 优先判断“能力来源”: 有明确装备/能量/仿生机制才进 T2; 只有物理夸张则回到 T1 强化街战。

### 自检 2: 因果链完整

每个命中点都要有:

```
谁打 -> 用什么打 -> 打哪里 -> 对手怎么反应 -> 环境怎么响应 -> 镜头怎么反馈
```

缺任一项, 必补。

对剧本改编类, 还要检查【过程】是否有 4-6 个快速攻防节拍:

```
逼近 / 防守 / 关键命中 / 短促反制 / 反制失败 / 压迫推进
```

如果只有“一个道具被打坏 + 结尾被踢飞”, 打斗密度不足, 必须补足节拍。

每个节拍都至少改变 距离 / 身位 / 攻守 / 空间压力 之一, 并由上一拍的动作后果自然接出。
如果【起幅】只登场不建立压力, 或【结尾】只展示结果不交代终段动作, 判定节奏过慢。
如果 4-6 个节点只是并列罗列, 没有局势推进, 也判定为失败。

### 自检 2.5: 素材调用

检查【过程】每个动作节拍是否实际调用当前题材小卡素材:

```
动作/武术词 >= 1
环境反馈词 >= 1
镜头词 >= 1
```

失败信号:

```
只写剧情, 没有具体招式
只写“镜头跟拍”, 没有镜头位置、遮挡、拉回或结果揭示
动作没有从题材小卡取词
4-6 个节拍里只有 1 个节拍有镜头反馈
```

修正:

```
回到当前题材小卡, 给每个节拍补 1 个动作词、1 个环境反馈、1 个镜头词。
```

### 自检 2.6: 动作压力曲线

检查【过程】是否只有动作排列, 没有局势变化。

失败信号:

```
4-6 个节拍只是“打一下、挡一下、再打一下”, 强弱关系没有变化
每一击力度差不多, 没有距离、空间、攻守或身体状态变化
所有对打都写成固定“试探 -> 破防 -> 终结”
弱势方从头到尾只被打, 没有任何有效闪避、格挡、反制或换位
反制动作没有改变局势, 只是装饰性挥一下
```

修正:

```
回到 Part 2.7, 选择 1 条压力曲线。
让每个节拍至少改变一个维度: 距离 / 身体状态 / 空间位置 / 攻守关系 / 环境反馈。
弱势方至少保留 1 次有效主动动作, 但可以在下一拍被压回。
```

### 自检 2.7: 镜头策略

检查镜头是否只是随机调用素材词。

失败信号:

```
每拍都有镜头词, 但看不出镜头站在哪一方
只堆“跟拍、推镜、慢镜头”, 没有视觉母题
命中后没有连续跟拍或揭示结果
结尾没有回收空间关系, 不知道双方最后位置
镜头炫技抢过人物动作
```

修正:

```
回到 Part 2.8, 选择 1 个镜头策略。
补上镜头立场、重复视觉母题、信息揭示和结尾空间回收。
```

### 自检 2.8: 画面坐标

检查【画面坐标】是否只承担开场空间定位。

失败信号:

```
缺少【画面坐标】字段
写成动作分镜或镜头说明, 超过 2 行
要求【过程】每个节拍都带画面坐标
坐标和【起幅】空间关系冲突
```

修正:

```
只保留主体开场位置、威胁进入方向、主要退路/纵深。
不要把坐标规则嵌入每个动作节拍。
```

### 自检 2.9: 动作连贯性

检查【过程】和【结尾】是否被慢动作、卡点、冻结画面或慢收势打断。

失败信号:

```
对打类出现“0.5 秒定格”“子弹时间”“停顿半拍”“失焦回正”“升格半拍”
每个命中点都用停顿展示, 导致招式之间断开
结尾写成海报式冻结, 没有连续收势或空间余波
结尾进入慢收势: 单膝落地、插刀、能量渐熄、灯光恢复、残影化为最后一丝、镜头缓慢拉远
环境反馈停下来单独展示, 没有接回下一招
镜头为了炫技频繁断流, 看不到连续攻防
```

修正:

```
把停顿词替换成连续动作词: 贴身追拍 / 借力转向 / 碎片擦镜转场 / 轻震后继续跟随 / 缓慢运动拉远。
命中后必须接下一拍: 对手被击退的同时另一侧攻击接上, 或主角借反作用力换位。
结尾只写“最后一击 -> 结果爆发/转场 -> 空间位置”, 不写慢收势。
终段后最多 1 句结果余波, 必须仍在运动中, 不能写渐熄、恢复平静、摆姿态。
```

### 自检 2.10: 连招编排四件套

检查【过程】是否真正调用了连招方向链、镜头贴附、物理化结果和结尾隔离。

失败信号:

```
只有招式名, 没有方向或身位变化
连续动作之间没有“借力、折返、压进、换位、跃起”等衔接
镜头只写“快速摇摄/快速切分/跟拍”, 没有贴住具体动作路径
抽象装饰词直接进入正文, 如毁天灭地、极致爆发、震撼全场、雷霆灼烧波动
一个节拍塞入 3 个以上物理化结果, 变成特效堆叠
【结尾】复读【过程】里的连斩路线或四向劈扫
```

修正:

```
先写内部连招方向链: 左斜切入 -> 右侧折返 -> 正面压进 -> 贴地横扫 -> 垂直终击。
每拍按公式重写: 方向/身位 -> 招式/载体 -> 命中点 -> 接触点物理化 -> 身体/环境后果 -> 下一招衔接。
镜头句必须绑定动作: 贴住刀刃 / 被碎片遮挡 / 甩到折返身位 / 拉回空间结果。
装饰词只在命中点后转成 1 个接触点结果 + 1 个身体/环境后果。
结尾只保留终段动作和结果爆发/转场, 不复制过程连招。
删除慢收势尾巴: 单膝落地、插刀、能量渐熄、灯光恢复、残影消散、角色摆姿态。
```

### 自检 2.11: T4 斗法连锁

仅当题材为 T4 且【过程】以斗法、雷法、阵法、结界或剑气对轰为主时检查。

失败信号:

```
法术 A 被破解后完全消失, 下一拍换一个新法术重新开始
过程写成“掌心雷 -> 躲开, 雷笼 -> 破开, 巨雷 -> 劈开”的闯关式流水账
高位施法者每拍都大幅挥手、前冲、摆姿势, 压迫感来自肢体动作而不是空间控制
法术只从正前方来, 没有脚下、身后、侧面、云雾或阵纹位置的合围
上一拍的雷弧、阵纹、云海压痕、剑气裂缝没有进入下一拍
```

修正:

```
每拍保留 1 个残余元素进入下一拍: 雷光残弧 / 阵纹余亮 / 云海压痕 / 剑气裂缝 / 护体光纹裂口 / 碎石悬浮轨迹。
下一拍必须利用、反转或放大这个残余元素。
高位施法者少动作: 指尖一点 / 袖袍一振 / 眼神下压 / 掌心翻转 / 双手合十。
让法术从平台裂缝、脚下阵纹、身后云雾、剑锋侧面同时合围。
```

### 自检 3: 末尾固定项

必须原样输出:

```
【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】
无背景音乐,仅保留环境音与人声;画面禁字幕/文字/水印/Logo;禁止可读文字;
```

不要改写成“无 BGM”或“禁止字幕水印”。

### 自检 4: 字数上限

最终 prompt 目标字数 1200-1400 字, 必须不超过 1500 字。低于 1100 字时, 视为动作和环境反馈不足, 需要补足。

如果低于 1100 字, 按顺序补足:

```
1. 补【过程】关键动作的铺垫、命中、余波
2. 补环境物理反馈
3. 补角色动作功能
4. 补结尾结果爆发和空间位置
5. 音效补到 10-14 个
```

如果超过 1500 字, 按顺序压缩:

```
1. 删除重复形容词和画质词
2. 删除重复运镜词, 每段只保留 1 个核心运镜
3. 场景设定只留 3-5 个环境锚点
4. 角色卡每个角色压成 1 行
5. 【过程】保留 2-3 个最关键命中点或 4-6 个连续招式
6. 音效压到 10-12 个
7. 删除【负面提示词】, 非必要时删除【特效细节】
```

不能为了压字数删除【禁止项】和【强制声明】。

### 自检 5: 锁定分镜偏离 / 粗略剧情失控

如果输入是锁定分镜, 检查输出是否偏离用户锁定的动作链。若输入只是粗略剧情, 再检查是否缺少剧情功能骨架。

失败信号:

```
保留了大量时间码
照搬“子弹时间①②③”等编号
锁定动作顺序被打散
锁定动作节点被删除
锁定出口被改变
锁定角色、武器、法器或能力被替换
用户禁止新增的角色、能力或奇观进入正文
为了动作簇好看而新增第二个攻击结果或额外高潮
微动作发展成独立剧情事件
粗略剧情没有建立功能骨架, 直接开始堆动作
同一段出现 5 个以上视觉奇观
动作链没有按当前题材小卡统一词汇和物理规则
为了避免剧本牵引而把打斗压成 1-2 个动作, 缺少速度和密度
过程围绕剧本道具连续展开, 人物攻防退成道具变化说明
同一主道具占用 3 个以上动作节拍
结尾转场奇观提前进入【过程】, 抢走中段打斗主轴
```

修正方法:

```
回到 Part 2.1, 建立锁定动作卡: 入口、锁定动作节点、中段关键结果、出口、禁止新增。
回到 Part 2.1.3, 确认锁定节点顺序没有被改。
如果输入是动作分镜, 按锁定动作卡保留动作链, 不进入二次创作重编。
最终 prompt 必须读取: 锁定动作卡 + 当前题材小卡 + 动作簇素材 + 压力曲线 + 镜头策略。
锁定外内容只能转为微动作、环境余波、镜头遮挡或音效, 不能变成剧情事件。
把过程主道具压回 1-2 个节拍, 其余节拍改成人物逼近、格挡、反制、压迫升级、身位变化和命中反馈。
若动作链与锁定分镜同序, 这是正确结果; 只需要增强力学、环境反馈和镜头贴附, 不得打散。
```

## Part 7 · 五个高危反例

### 反例 1: 形容词堆叠

错误:

```
主角一拳击出, 灼热雷霆撕裂虚空, 能量震撼爆发。
```

正确:

```
主角一拳击中怪物胸口, 怪物胸口内陷后倒退两步,
身后砖墙裂出蛛网纹, 镜头剧烈一震后拉回稳定。
```

### 反例 2: 跨题材污染

错误:

```
低魔武侠音效: 剑鸣, 机甲撞击, 雷霆鸣彻, 警笛。
```

正确:

```
低魔武侠音效: 剑鸣, 刀风啸声, 兵刃碰撞, 雨滴落地, 衣料摩擦。
```

### 反例 3: 特效遮主体

错误:

```
漫天光效铺满屏幕, 主角隐没在巨大冲击波中。
```

正确:

```
主角横劈, 一道剑气擦过对手肩头, 衣料破开浅痕,
对手后退三步, 剑气余光在肩侧消散。
```

### 反例 4: 群战逐个敌人流水账

错误:

```
第一个敌人挥刀, 第二个敌人踢腿, 第三个敌人冲来, 第四个敌人...
```

正确:

```
三名敌人同时扑近, 主角转身横扫逼退前方两人,
其中一人撞翻身后同伴, 残余敌人退成半圈。
```

### 反例 5: 镜头逻辑错误

错误:

```
一镜到底, 切镜到反派, 再切拳头特写。
```

正确:

```
一镜到底, 【镜内转向】到反派, 【镜内推近】到拳头特写。
```

错误:

```
全程剧烈晃动失焦。
```

正确:

```
中段跟拍保持稳定, 命中瞬间短促震动后继续追随动作。
```

## Part 8 · 进阶技巧池

进阶技巧不是必用项。一个 prompt 最多使用 1-2 个。

| 技巧 | 适用 | 写法 |
|---|---|---|
| 命中后连续追拍 | 全题材关键命中 | 命中瞬间短促震动, 镜头立刻追上下一招 |
| 前景遮挡转场 | 一镜到底 / 长镜头 | 水花/灰烬/落叶扑向镜头作前景遮挡 |
| Z 轴冲刺 | 高潮反扑 / T5/T7 | 主体沿 Z 轴向镜头猛冲 |
| 前景遮挡接招 | 反转高潮 | 碎片或水花擦镜, 下一招从遮挡后接上 |
| 武器入鞘收势 | T3/T4 兵器 | 手腕翻刃入鞘, 铁鞘清脆, 镜头缓慢运动 |
| 雨幕/风压偏转 | T1 雨夜 / T3 低魔 | 雨幕被风压向外分开一瞬 |
