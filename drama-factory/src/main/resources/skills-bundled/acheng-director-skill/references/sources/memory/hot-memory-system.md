# 热记忆系统（Hot Memory System）

## 功能概述
三层记忆架构，自动管理从当前会话到长期存储的记忆，实现知识的有效沉淀和检索。

## 核心架构

### 三层记忆体系

#### 1. 热记忆（Hot Memory）
- **位置**：当前会话
- **生命周期**：会话期间
- **内容**：
  - 当前任务上下文
  - 活跃的对话状态
  - 临时变量和中间结果
- **特点**：高速访问，容量有限

#### 2. 暖记忆（Warm Memory）
- **位置**：每日笔记
- **生命周期**：7天
- **内容**：
  - 每日会话总结
  - 重要发现和结论
  - 任务完成记录
- **特点**：定期蒸馏，自动清理

#### 3. 冷记忆（Cold Memory）
- **位置**：长期存储
- **生命周期**：长期保留
- **内容**：
  - 重要知识沉淀
  - 项目关键信息
  - 用户偏好设置
- **特点**：需要归档，容量大

## 蒸馏流程

### 每日蒸馏
1. **会话总结**：提取关键对话要点
2. **信息分类**：
   - 立即使用 → 热记忆
   - 近期使用 → 暖记忆
   - 长期保留 → 冷记忆
3. **归档执行**：自动转移和清理

### 信息流转
```
会话进行 → 热记忆 ←→ 暖记忆 ←→ 冷记忆
              ↓
         每日蒸馏
              ↓
         归档清理
```

## 使用方法

### 自动管理
- 系统自动维护三层记忆
- 无需手动干预
- 智能判断存储层级

### 手动操作
- `查看热记忆`：查看当前会话状态
- `归档到长期`：将暖记忆转入冷记忆
- `清理过期`：清理7天以上的暖记忆

## 记忆模板

### 每日笔记结构
```markdown
# 日期：YYYY-MM-DD

## 今日完成
- [任务1]
- [任务2]

## 重要发现
- [发现1]
- [发现2]

## 待处理
- [事项1]
- [事项2]

## 关键结论
- [结论1]
```

### 长期记忆结构
```markdown
# 主题：XXX

## 概述
[简要说明]

## 详细信息
[详细内容]

## 相关资源
- [链接1]
- [链接2]

## 更新记录
- YYYY-MM-DD: [更新内容]
```

## 优势
1. **智能分层**：根据使用频率自动调整存储位置
2. **自动蒸馏**：每日自动总结，无需手动整理
3. **高效检索**：热记忆快速访问，暖记忆定期整理
4. **长期沉淀**：重要知识永久保存

## 注意事项
- 热记忆在会话结束后自动转为暖记忆
- 暖记忆7天后自动清理或归档
- 冷记忆需要手动归档操作
- 重要内容建议手动标记归档
