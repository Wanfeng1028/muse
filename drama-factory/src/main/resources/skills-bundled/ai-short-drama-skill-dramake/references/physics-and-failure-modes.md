# 物理、解剖与失败模式

## 动作可行性门

把抽象动作改成可见物理原语。每个移动物体动作记录：执行者与身体部位、接近路径、接触点、施力方向、支撑/平衡、物体/身体响应和稳定终态。

要求顺序：`接近 → 接触 → 施力 → 响应 → 结果`。

## 可见物理事件合同

“倒车”“向左偏”“帽子掉落”“发生碰撞”只是意图，不是可拍指令。对每个关键物理事件写清：

- `physical_start_state`：主体、道具、车辆和连接件起始位置/姿态；
- `control_input`：谁通过哪个身体部位、方向盘、踏板、绳索、按钮或外力触发；
- `world_motion_vector`：相对道路、重力和场景的真实方向；
- `screen_motion_vector`：相对画面的左/右/近/远方向，不能只写“左边”；
- `phase_sequence`：准备 → 启动 → 方向变化/脱离 → 峰值 → 可见响应；
- `physical_end_state`：最终位置、朝向、连接/脱落、完好/损坏和谁持有。

例如倒车必须看见车辆从静止进入反向位移、轮胎/车身相对背景向后移动，并在结果帧停在更后的空间位置；转向必须同时定义世界方向和屏幕方向。头盔脱落必须经历连接松开、与头部分离、受重力下落或抛物、碰撞落点并留在新位置，不能消失或下一镜自动复位。

每个生成段只承担一个高风险精确物理事件。若同一段包含倒车、转向、碰撞、头盔飞落和角色反应，拆成有因果连接的动作建立镜头、峰值镜头和结果/反应镜头；必要时使用更短重点段、参考动作视频或局部后期。提示词写了正确方向但成片仍向前，判为失败，不能以“模型大致理解了”通过。

## 解剖与主体能力

- 人：惯用手、关节范围、握持、视线、平衡、脚位、身体支撑和交接；
- 动物：物种合适的步态、爪/嘴能力、重心、尺度、耳尾反应和接触；
- 机器/车辆：铰链、轮胎接地、惯性、制动、转向、载荷和安全空间；
- 液体/布料/毛发：重力、湿度、风向、粘性、拖尾和碰撞；
- 魔法：明确触发、视觉证据、规则、代价和环境响应，不能用“魔法”掩盖随机穿模。

## 动画夸张不等于物理错误

选择 `animated_actor_hybrid` 时，可允许短时拟人站姿、夸张表情、耳尾放大反应、蓄力、过冲、回稳和锁定范围内的 squash/stretch。夸张必须有准备与恢复，并保持同一角色轮廓可识别。

道具世界仍按真实物理验收：食物不能凭空换种类或从封闭容器弹出，盘子不能无交接翻面，夹子接触前不能夹走物体，数量不能增殖，尾巴不能长出出料口。可以夸张“角色如何反应”，不能伪造“物体如何存在和移动”。

## 动物与容器

先确认动物数量、容器尺寸、开口、支撑面、可见身体部位和进入/离开路径。不得让动物凭空复制或从封闭盒子穿出。自然写实模式不得以人体站姿长时间完成不适合的动作；动画演员混合模式只有在角色圣经明确锁定时才可短时拟人站立，且仍需可见支撑、重心与进入/退出姿势。

## 方向与道具

跟踪手机正反面/上下、门开合、车辆世界/屏幕运动方向、道具持有者和朝向。方向变化必须有可见旋转、交接或控制输入。逐帧标注开始、25%、峰值、75% 和结尾位置；观察到的运动向量必须与计划一致。

## 失败级别

- **P0 阻断：**剧情因果错误、角色/产品变了、穿模/额外肢体、错误说话人、严重口型/声音、素材无权使用；
- **P1 严重：**明显服装漂移、道具瞬移、轴线/方向错、接缝或音频突变；
- **P2 可后期：**首尾少量坏帧、可裁切抖动、轻微色差、可替换文字或局部声音。

P0/P1 不得用字幕、音乐或快速剪辑掩盖。
