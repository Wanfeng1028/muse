# 长篇改编与系列记忆

长小说、连续短剧和多集 IP 不能把全文反复塞进每次请求，也不能只靠本轮对话记忆。使用 [story-memory.csv](../assets/templates/story-memory.csv) 保存跨集事实、人物知识、时间线和揭示状态。

## 分层读取

1. **系列层：**世界规则、角色身份、长期关系、不可逆事件、核心秘密；
2. **单集层：**本集目标、起止状态、前情依赖、必须推进的季线；
3. **场景层：**此刻人物知道什么、持有什么、受了什么伤、在哪里；
4. **镜头层：**只加载本段需要的身份、空间、道具和动作状态。

每条事实保留 `source_span` 和有效区间，但生产提示词只带当前相关切片。原文冲突时标记冲突并让改编决策进入正式 canon，不静默拼接两个版本。

## 人物知识与揭示

分别记录观众、每个角色和叙事者何时知道事实。角色不得使用尚未得知的信息；悬念不得被分镜、道具特写或生成提示词提前泄露。每次揭示要改变人物选择、关系或风险，否则只是说明。

## 时间线与不可逆状态

伤势、失物、关系破裂、死亡、公开秘密、道具损坏和地点毁坏等状态必须有 `valid_from/valid_to`。后续若恢复，必须有可见原因。跨集复用造型和地点时，先应用当前时间点的覆盖状态，再引用长期母版。

## 长源文本切分

- 先按因果与场景边界索引，不按固定字数生硬切块；
- 每个片段保存摘要、实体、未决问题、前置事实和后果；
- 单集改编先选本集承诺与闭合任务，再拉取所需源片段；
- 保留改编边界：原作事实、明确改写、压缩、合并、删除和新增分别标记；
- 恢复生产时从 `resume_cursor`、最近正式 canon 和本集状态开始，不重新推断整季。

## 记忆门禁

进入剧本或分镜前检查：身份冲突、时间悖论、知识越权、无原因复位、重复揭示、已关闭伏笔重新出现、当前集没有推进任何关系或季线。关键冲突未解决前不得生成。
