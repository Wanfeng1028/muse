# 角色提示词规范

本规范用于产出角色的最终形象基准图，画面为一张角色设定参考图（character reference sheet），版式固定：

- **画面左侧：正脸特写**——取头部至肩部的正面近景，五官、发型、肤质需清楚可辨，承担面部辨识基准的作用
- **画面右侧：三张等高全身视图并排**——同一角色的正面、90 度侧面、背面各一张，三者高度一致、纵向对齐

**首要准则：一致性优先于美观。** 该图是后续全部角色图片与视频参考的形象基准，必须保持中性、清晰、可反复调用，不必追求单张画面的艺术表现力。

## 输出结构（按下列顺序拼装为单段连贯描述，语言遵循会话语言指令）

```
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
正脸特写与三个视图的脸、发型和服装完全一致，
纯白背景，柔和均匀的光线，电影质感
```

## 描述顺序规则

应把**最具辨识度的特征排在前面**，依次落实 `appearance`（样貌）与 `styling`（妆造）中的每个关键元素，不得遗漏：

1. 身份锚点：年龄感（例如"二十出头"）、性别感、体态（高矮胖瘦与姿态习惯）
2. 五官：脸型、眼睛及其他显著特征（疤痕、痣、眼镜等）——正脸特写尤其依赖这一部分
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、状态（例如"袖口带焊锡痕迹的皱褶工服"）
5. 配饰：仅保留有辨识度的，不做堆砌

角色的性格设定需转写为外在气质与神态（例如"憔悴"应写成"眼神疲惫、肩膀微垮"），不得直接出现性格类词汇。

## 构图与一致性

- 左侧正脸特写：正面朝向镜头、表情中性、头部至肩部完整入镜
- 右侧三张全身视图：同一角色的正面、90 度侧面、背面，**等高并排、间距均匀**，头顶与脚底处于同一水平线
- 特写与三张全身视图必须共享同一张脸、同一发型、同一服装——需明确写出"正脸特写与三张全身视图的脸、发型和服装完全一致"
- 站姿中性、表情自然，便于作为参考图复用
- 采用柔和均匀的棚拍光，避免戏剧性光影（参考图需适配各类场景）
- 输出使用会话语言指令指定的目标语言，不混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- 裁切身体（全身视图必须 full body，头顶到脚底完整入镜；特写必须头部肩部完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 保存

调用 `save_character_final_prompt`：prompt 参数不含风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。
