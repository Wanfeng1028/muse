# 角色提示词规范

本规范产出的是一张角色设定参考图（character reference sheet），画面布局固定成左右两块：

- **左半区：正脸特写**——只取头肩范围的正面近景，五官、发型、皮肤质感都要看得清楚，用来锁定这张脸的辨识度
- **右半区：三视图**——把同一角色的正面、90 度侧面、背面三张全身视图并列摆放，三张高度一致，头顶线与脚底线分别对齐

**优先级明确：一致性优先于美观。** 这张图会成为后续全部角色图片与视频的形象基准，因此画面要中性、干净、可反复调用，不必去追求单张作品的艺术性。

## 提示词组装结构

按下面的次序拼成一段连贯描述，输出语言遵循会话语言指令：

```
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
正脸特写与三个视图的脸、发型和服装完全一致，
纯白背景，柔和均匀的光线，电影质感
```

## 关键元素的排列次序

越容易辨认的特征越要往前放。`appearance`（样貌）与 `styling`（妆造）里的每个关键元素都按这个次序落地，一项都不能丢：

1. 身份锚点：年龄感（例如"二十出头"）、性别感、体态（高矮胖瘦、惯常姿态）
2. 五官：脸型、眼睛，以及疤、痣、眼镜之类的显著标记——正脸特写主要靠这一层撑起来
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、当前状态（例如"袖口沾着焊锡痕迹的皱褶工服"）
5. 配饰：只保留有辨识度的，不做堆砌

人物性格不能直接写成性格词，要转译成外在气质与神态，比如"憔悴"落到画面上应写成"眼神疲惫、肩膀微垮"。

## 构图与一致性约束

- 左侧特写：面朝镜头、表情中性，头顶到肩膀完整入画
- 右侧三视图：同一角色的正面、90 度侧面、背面，高度相等、间距均匀地并排，头顶与脚底各自处于同一水平线
- 特写和三张全身视图必须共享同一张脸、同一发型、同一套服装，因此提示词里要写明"正脸特写与三张全身视图的脸、发型和服装完全一致"
- 站姿取中性、表情取自然，便于当作参考图反复使用
- 用柔和均匀的棚拍布光，避开戏剧性光影，保证参考图放进各种场景都成立
- 输出语言取会话语言指令所指定的目标语言，不掺入无关词汇

## 不允许出现的内容

- 动态姿势、夸张表情、手拿道具、与其他人同框
- 身体被裁切：全身视图必须 full body，头顶到脚底完整入画；特写必须头肩完整入画
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 保存方式

调用 `save_character_final_prompt` 保存。prompt 参数里不写风格词——项目的视觉风格会由该工具自动拼接到最终提示词的最前面。
