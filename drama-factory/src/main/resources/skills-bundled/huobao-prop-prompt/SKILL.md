# 道具提示词规范

本规范用于生成单件道具的白底产品图提示词（product shot）。画面里应当只出现该道具，置于纯白底之上，不引入任何旁杂内容：既无别的物件，也无人物、手部，更不存在场景环境。

## 三条不可动摇的底线

- **比例真实**：道具各部位之间的相对尺寸须与实物一致，禁止夸大、扭曲，也不得为了风格化而拉伸变形。
- **轮廓完整**：道具必须整体进入画面，四周留有空白余量，任何一个部位都不能被画框切掉。
- **背景纯粹**：白色衬底只承担衬托作用，不暗示场景、不携带情节、不添加装饰。

## 提示词组装结构

按下列先后顺序拼成一段连贯描述，语言种类以会话语言指令为准。

```
单品产品图，标准产品摄影视角，[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
物品各部分比例准确，孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切，
背景纯净不承载任何叙事内容，无其他物品、无人物、无场景，
柔和均匀的影棚光，轻淡阴影，高细节
```

## 生成规则

- 核心信息取自道具的 `name`（名称）与 `description`（物品外貌）。材质、颜色、形状、大小、新旧程度、磨损痕迹等物理属性要逐条写清楚，这些细节决定了道具能否被准确辨认。
- 视角采用标准产品摄影方式：一般用微俯视的 3/4 角度，兼顾顶面与侧面，立体感最好；遇到纸张、证件、照片这类扁平物件，则改为正俯视平铺。
- 道具居中摆放，整体呈现，四周留白，比例与轮廓都要符合底线要求，主体不可被裁。
- 光照为影棚式柔光，均匀铺开，投影浅淡，细节丰富。
- 描述范围仅限物品自身，剧情、角色、用途一概不提，背景与画面均不承担叙事功能。
- 输出语言遵循会话语言指令，不掺入无关词句；同时避免“电影质感”一类措辞，因为道具图属于产品图，而非剧照。

## 禁止出现的内容

- 手部持握、人物、其他物品、场景环境
- 包装、底座、展示架（若其本身即为道具组成部分则例外）
- 文字、水印、签名（道具本体上印刷的文字或图案可保留并加以描述）
- 环境反光、彩色光
- 夸张透视、变形、比例失真、边缘裁切

## 保存方式

通过调用 `save_prop_final_prompt` 完成保存。传入的 prompt 参数不包含风格词，项目视觉风格会由工具自动加到最终提示词的最前面。
