# 场景提示词规范

## 一、这份规范产出什么

最终交付的是一张场景空镜图：用广角把一处地点完整交代清楚的建立镜头（establishing shot）。画面里不安排任何角色，只呈现空间本身，并且要把前、中、后三个层次，以及出入口、地面、墙体、核心陈设各自的相对方位一次性讲明白。整块空间要前后对得上、逻辑闭环，后续可以被反复调用。

这张图承担的是"空间锚点"的角色：该场景往后拍的所有镜头，都以它为背景参照。看图和读提示词的模型，都要能凭它判断人从哪儿进、从哪儿出，地面和墙是什么质感，主要物件各自钉在什么方位。因此取景角度不能花哨，必须通用、稳定。

## 二、提示词的组装顺序

按下面的顺序，把内容拼成一段连贯描述，不要拆成多条。语言跟随会话中给出的语言指令。

固定机位广角镜头，清晰的建立镜头，[地点 + 年代质感]，[时间段]，
前景（[前景元素]）、中景（[中景主体空间]）、后景（[后景纵深]）三层分层构图，
出入口（[门/通道的位置与样式]），地面（[地面材质与状态]），墙面（[墙面材质与颜色]），
[主要陈设及其固定相对位置]，
空间结构连续、自洽，
[光源 + 色温 + 明暗对比]，[氛围]，
画面中没有任何人物，空场景，电影质感

## 三、空间必须成立

判断标准很直接：读得懂、对得上、能复用。逐层拆开看——

- **前景**：承担框景或遮挡功能，用来拉开纵深，比如门框、桌角、植物、设备边缘。挑 1 到 2 个具体物件写清楚。
- **中景**：整个场景的主战场，核心陈设落在这里，比如流水线、床铺、柜台。
- **后景**：空间的延续方向，例如远处的墙、窗户、走廊、城市轮廓。
- **出入口**：门、楼梯、通道各自在哪、长什么样，必须点明，比如"画面左侧一扇铁门"。后面调度人物进出，全指望这条信息。
- **地面与墙面**：材质、颜色、当前状态都要落到实处，例如"水泥地面有油渍""墙面石灰斑驳"。
- **主要陈设**：挑 2 到 4 件核心物件，连同它们的固定相对位置一起写，例如"流水线沿墙排开，尽头是吧台"。左右、远近的关系要自洽，光报一串物品名不算数。

## 四、人物相关（最高优先级硬规则）

场景图里不允许出现任何人，画面只保留空间本身。

- 提示词里不写人物，也不提任何与人物沾边的信息。
- 场景描述（prompt）里若混入了人物内容，直接忽略，不写进提示词。
- 提示词收尾必须带上："画面中没有任何人物，空场景"。

场景描述（prompt）中提到的陈设、年代质感、关键视觉元素，一个都不能漏掉；场景光影（lighting）要写具体：光从哪个方向来、色温偏冷还是偏暖、明暗反差如何，例如"头顶灯管发出冷白光，机器下方投下硬阴影"。

## 五、取景与氛围

- 用平视或轻微俯视的广角，保持稳定。极端俯仰、鱼眼、倾斜构图都不要，这张图是要反复复用的。
- 时间段和光线基调由 `location` 配合 `time` 决定——白天、夜晚、黄昏，光线完全不是一回事。
- 氛围词要落到具体画面上：写"压抑"不如写"空气闷热、光线昏暗低沉"，抽象情绪词单独摆着没有意义。
- 输出语种以会话语言指令指定的目标语言为准，别掺进无关词汇。

## 六、明确禁止

- 出现任何人物——场景图里不允许有人的身影，画面只保留空间本身。
- 文字、招牌上可辨认的字、水印、签名。
- 动态模糊、正在运动的物体（场景参考图必须是静止稳定的）。
- 只堆陈设清单却不交代相对方位（空间结构必须前后连贯、自洽）。

## 七、保存

调用 `save_scene_final_prompt` 保存。传给 prompt 参数的内容不要带风格词——项目的视觉风格会由该工具自动拼接到最终提示词的最前面。
