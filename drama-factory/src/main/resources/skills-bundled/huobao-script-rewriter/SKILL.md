# 小说改写剧本

## 改写原则

1. **主线不动**：故事走向与人物之间的关系统统保留，不做情节层面的增删改动。
2. **可拍性优先**：把叙述性文字转成能在画面里直接呈现的场景描写，让人、景、动作可见。
3. **对白为主**：情节推进尽量交给角色台词完成，旁白能省则省。
4. **单场时长可控**：一场戏的体量控制在 30 至 60 秒之间，契合短视频节奏。
5. **不碰镜头语言**：景别、机位角度、运镜方式一律不写，这部分留给后续的分镜拆解环节处理。

## 格式化剧本格式

```
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头，用于标记一场戏的起点。
- 动作描写单独成段，写成自然段，不夹带任何镜头语言。
- `角色名：（状态/表情）台词内容` — 对白的固定写法。

### 内容量参考

改写后的剧本篇幅通常比原始文本多出两到三成，增量主要来自场景头标记和对白的格式化处理，并非对剧情做扩写。

## 改写步骤

1. 先调用 `read_episode_script`，把原始内容读进来。
2. 拆解内容构成，判断对话、叙述、心理描写各占多大比重。
3. 调用 `rewrite_to_screenplay` 执行改写。
4. 复核改写结果，逐项确认是否满足格式化剧本的各项格式要求。
5. 调用 `save_script` 落盘保存最终稿。

## 注意事项

- 心理描写有两种出路：转成角色的表情与动作，或转成画外音。
- 遇到长段叙述，拆成若干个短场景来承载。
- 每一场都要有清晰的情绪转折点。
- 同一个角色的说话风格前后保持一致。
- 场景编号按 S01、S02、S03…… 的顺序连续递增，不跳号。
- 时间段写到具体（黄昏、深夜、清晨），避免笼统地写"白天"。
