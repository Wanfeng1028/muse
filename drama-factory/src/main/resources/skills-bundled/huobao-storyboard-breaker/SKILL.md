# 分镜拆解

## 一、分镜段落的定义

在本工作流中，一个分镜对应一个 **分镜段落（segment）**，也对应一次视频生成任务。它具备以下特征：

- 单个段落总时长控制在 **8-15 秒**，内部容纳 **2-4 个子镜头**。
- 子镜头之间允许硬切，可切换景别、机位角度或拍摄对象。
- 子镜头之间不得跨越场景，`scene_id` 绑定在段落层级，整段只发生在一个场景内。
- 单个子镜头 2-6 秒，只聚焦一个画面单元，例如一个动作、一次反应或一处特写。

## 二、拆解四步法

1. **读取上下文**：调用 `read_storyboard_context`，拿到剧本、角色、场景、道具以及已有分镜的摘要信息。
2. **识别叙事节拍**：先找出剧本中的叙事节拍，包括【开场】【触发】【高潮】【收尾】一类标记，以及地点转移、规则揭示、情绪爆发、反转等转折点。节拍边界处必须切段；同一节拍内部的子镜头尽量归入同一段落，避免把「铺垫—发生—反应」这样一条因果链拆散到不同段落。
3. **锚定总量**：目标总时长按剧本字数换算，500 字对应 1 分钟；段落数量约为目标总时长除以 12 秒，上下浮动不超过 20%，既不要明显超出也不要明显不足。
4. **段内切分子镜头**：依据动作切换点、视角切换点、对象切换点划分子镜头，把每个段落的字段补齐后，调用 `save_storyboards` 一次性写入。

## 三、按节奏分层设定时长

段落时长要依据其功能区分对待，不可统一取值：

| 段落类型 | 时长区间 | 适用情形 |
|---|---|---|
| 过渡段 | 8-10 秒 | 赶路、空镜、环境交代、转场 |
| 叙事段 | 10-15 秒 | 常规剧情推进、对话 |
| 爆点段 | 12-15 秒 | 特写、规则揭示、情感爆发、反转；子镜头节奏放缓，单个子镜头可停留 4-6 秒 |

## 四、台词时长下限（硬性约束）

**段落时长必须 ≥ 该段内台词与旁白总字数（即写在 description 中的部分）÷ 4.5 字/秒 + 2 秒表演余量。**

若台词在段内放不下，必须顺延到下一段落，严禁把无法演完的台词硬塞进同一段落。

## 五、镜头要素清单

1. **镜头标题**：用 3-5 个字概括段落核心，例如「噩梦惊醒」。
2. **时间**：写明具体时分，并附光线描述。
3. **地点**：给出场景完整描述、空间布局与环境细节。
4. **景别**：标注段落的主导景别；多景别段落写组合形式，如「中景+特写」。
5. **角度**：平视 / 仰视 / 俯视 / 侧面 / 背面。
6. **运镜**：固定 / 推镜 / 拉镜 / 摇镜 / 跟镜 / 移镜，段内不同子镜头可各自不同。
7. **画面描述 `description`**：以 `【镜头1】…【镜头2】…` 的格式逐子镜头描写观众实际看到与听到的内容。画面部分（谁 + 具体动作 + 肢体细节 + 表情）写在前面；该子镜头若含台词，以「角色名说：「台词」」的形式写入对应的 `【镜头N】` 内；旁白写作「旁白：内容」。
8. **画面结果 `result`**：段落收尾时的即时后果，并附视觉细节。
9. **氛围 `atmosphere`**：由光线、色调、声音与整体氛围共同构成。
10. **时长 `duration`**：段落总时长 8-15 秒，同时满足台词时长下限。
11. **场景关联**：能够匹配到已有场景时，必须填写 `scene_id`。
12. **角色关联**：填写 `character_ids`，绑定本段落涉及的 0 到多个角色。
13. **道具关联**：填写 `prop_ids`，绑定本段落出现的关键道具，数量为 0 到多个。

## 六、场景关联规则

- 优先采用 `read_storyboard_context` 返回的 `scenes`。
- 当 `location + time` 能明确匹配时，必须回填正确的 `scene_id`。
- 不得虚构不存在的场景 ID。
- 若剧本内容明显落在已有场景之中，不要重复创造新的场景描述。

## 七、角色绑定规则

- `character_ids` 只能从 `read_storyboard_context` 返回的角色列表中选取。
- 一个段落可以不含角色，也可以绑定多个角色。
- 凡是在段落中有明确出场、被看见、发生动作或说话的角色，都应绑定进去。
- 纯环境段落、空镜、物件特写可以传空数组。

## 八、道具绑定规则

- `prop_ids` 只能从 `read_storyboard_context` 返回的道具列表（`props`）中选取。
- 道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到该段落。
- 道具特写段落即使没有角色，也应绑定道具，`character_ids` 可为空。
- 与剧情无关的背景物品与场景陈设不要绑定；段落中未出现道具时传空数组。
- 绑定后的道具会作为视频生成的参考图（白底单品图），用于保证道具外观在不同段落之间保持一致。

## 九、质量要求

- `description` 应便于人阅读，按子镜头详细描写观众实际看到与听到的内容；台词与旁白直接写在对应的 `【镜头N】` 内。
- `image_prompt` 应突出单帧构图、角色外观、环境与光线，对应段落的第一个子镜头。
- `bgm_prompt` 与 `sound_effect` 用简洁短语表达即可，但不可空泛到只剩「紧张」「悲伤」这类词。
- 需要调整时，调用 `update_storyboard` 修改指定段落。
