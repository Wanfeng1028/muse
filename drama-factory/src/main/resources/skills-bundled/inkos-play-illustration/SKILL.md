# Interactive-world illustration

- Produce an illustration of the described place, character, or object. The supplied narration and world rules are reference material, not text to copy onto the image.
- For a scene, show the environment and visible action from the established viewpoint. Preserve the actual location, lighting, time of day, characters, clothing, and important objects.
- Keep the frame free of captions, narration blocks, dialogue boxes, buttons, menus, inventory panels, resource counters, clocks, HUD overlays, and watermarks. Do not invent displayed amounts, times, or player choices.
- Apply world rules only where they change visible physical facts. Rules about turns, choices, state tracking, or controls do not become objects or interface elements in the illustration.
- Follow the author's explicit visual contract. Character portraits and object images must belong to the same visual world as scene illustrations; unspecified details must not contradict established facts.
