## 二、🚨 关键冲突：定板图**不能**直接当视频参考

官方视频模型指南明确：**不要用人物三视图/多角度定板图做视频参考** ——
模型会把不同角度当成**多个主体**，反而加剧角色漂移。

**所以这套资产卡的正确用法是分两步：**

```text
① 用上面的模板生成角色定板图   → 用于「设计」和「人工确认」
② 从定板图上裁出两张，分别上传 →  用于「视频参考」
     · 大头照（从中间的正脸特写裁）  → 定义身份
     · 全身照（从左侧正面全身裁）    → 定义比例与服装
③ 视频节点连这两张，而不是整张定板图
```

> 这条把两个来源的知识接上了：
> 素材库给「怎么做出好角色」，官方指南给「怎么把它喂给视频模型」。

## 三、真人感公式（抄自 `更新/2.豆包生成真实感更强的美女的提示词.txt`）

那个库里的「真实感」配方极简，但有效：

```text
半身像，真实感，电影效果。{一句人物}，{发型}。佩戴{耳饰}。身着{服装}，
{身材强调}。{裙摆/开叉等结构细节}。妆容{妆容}，{动作：一手…一手…}，
身姿{姿态词}，背景是{场景}。
```

**可提取的通用三件套**：`半身像 + 真实感 + 电影效果` 作为开头锚点。
**注意**：原库大量使用「36D/黑丝/性感」等取向词，做短剧**不建议照抄**，会把画面带偏；
只取「**具体服装结构 + 具体动作 + 具体背景**」这个写法，不取取向词。

## 四、人格化提示词模版（抄自 `6.影视小说类` 系列）

该库几十个指令共用一套结构，**做「分镜师/编剧」角色挂载很好用**：

```text
## Role :        {角色，如「微电影编剧」/「短剧分镜师」}
## Background :  {能力背景与阅历}
## Preferences : {审美偏好}
## Profile :     author / version / language / description
## Goals :       1..N 条目标
## Constraints : 1..N 条硬约束
## Skills :      1..N 项技能
## Examples :    [输出示例 1..3]  ← 每个示例都带「画面描述 + 提示词」两段
#workflows:
  ## 第1步-提供内容
  ## 第2步-{产出}
## OutputFormat : 1..N 条输出规范
```

**`6.影视小说类\12.微电影提示词` 的分镜输出格式值得直接抄**：
- 先给 **故事概要 + 5 个画面**
- 再给**每个画面的详细提示词**
- 示例里「画面描述」和「提示词」**成对出现**，描述讲叙事、提示词讲可拍要素（视角/景别/动作/材质/光）

> 对短剧有用的是这个**「先概要 → 定画面数 → 再逐画面出提示词」**的两段式，
> 正好对应我们流水线里「剧本 → 分镜 → 视频提示词」。

## 六、落到我们流水线上的具体改法

```text
剧本 → 分镜表（每镜 画面描述 + 可拍要素）
   ↓
角色：用 §1.2 模板生成定板图 → 人工确认 → 裁大头照 + 全身照（§二）
   ↓
场景：3D导演台建模 → 截取白模图 → gpt-image-2.5 出场景图
   ↓
每镜视频节点连：分镜图 + 角色大头照 + 白模截图
   ↓
H3 Ref2VA 提示词（见 H3-OFFICIAL.md）→ 生成
   ↓
后期混入 MiniMax 对白（mix-dialogue.mjs）→ 成片
```

**负面提示词按模型分流**：
- 图生（豆包/gpt-image/SD）→ 用 §1.3 那串
- 视频（H3/lingcut）→ **不用负面词**，改写成正向单职责声明
