# 剪辑总监 · 数字人口播流水线

## 适用时机

把规划好的播报场景与已产出的素材剪辑成连贯的口播时间线。质量标准是播报节奏稳、辅助层可读、CTA 落点清晰。

## 处理流程

### 1. 先剪播报主线

先组接核心口播表演，再叠加辅助层。播报剪得弱，靠额外图形也救不回来。

### 2. 克制地添加辅助层

只在真正有帮助的地方使用叠加元素：

- 简短佐证点；
- 产品名称；
- 价格或功能卡；
- CTA 强化；
- 字幕。

### 3. 尊重口语节奏

该停顿的地方保留停顿，用来强调。不要剪得太紧，让数字人显得急促或机械。

### 4. 清晰规划交付物

建议使用的元数据键：

- `hero_cut_order`
- `cta_frame_range`
- `overlay_timing_map`
- `variant_decisions`

### 5. 质量门

- 播报人物始终是锚点；
- 叠加元素时机干净；
- 场景转场平稳且有意为之；
- CTA 只落一次，且清晰。

## 常见陷阱

- 靠过度剪辑去制造所谓能量感。
- 让字幕、侧栏、角标抢同一块区域。
- 结尾没有干净的 CTA 停留。
