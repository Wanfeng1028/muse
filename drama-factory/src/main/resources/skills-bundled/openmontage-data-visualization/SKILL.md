# 数据可视化策略

## 何时使用

当某场景需要以视觉方式呈现数据时启用：统计、对比、趋势、构成或关键指标。本技能指导图表选型、动画时序、标签位置、数据密度与配色，使图表在视频中清晰、准确、有效。

## 工具

| 工具 | 作用 |
|------|------|
| `diagram_gen` | 通过 Mermaid 或 D3 生成图表 |
| `image_selector` | 生成风格化图表插画（FLUX/GPT Image） |
| Remotion | 动画图表组件（柱状生长、折线描绘、饼图填充） |
| Manim | 数学绘图、坐标系、函数图像 |

## 图表选型决策树

自上而下执行，命中即停。

```
有数据要可视化吗？
  否 -> 用文本卡或统计卡
  是 -> 数据点有多少？
           少于 3 -> 用文本或统计卡（1-2 个点的图表太空）
           3-9 -> 进入“数据讲述什么故事？”
           多于 12 -> 先简化：聚合为 Top-N + “其他”，再继续

数据讲述什么故事？
  |
  |-- 跨类别比较数量？
  |     -> 柱状图（标签长时用横向）
  |
  |-- 展示随时间变化的趋势？
  |     -> 折线图（展示体量时用面积图）
  |
  |-- 展示整体构成？
  |     -> 饼图/环形图（最多 5-6 片）
  |     （超过 6 类时，将最小类聚合为“其他”）
  |
  |-- 展示关键指标/KPI？
  |     -> KPI 网格（3-6 张统计卡网格排布）
  |
  |-- 展示排名或有序列表？
  |     -> 横向柱状图（降序排列）
  |
  |-- 展示前后对比或变化？
  |     -> 成对柱状图，或带增减箭头的统计卡
  |
  |-- 展示两变量相关性？
  |     -> 双系列折线图（视频中避免散点图——太密）
  |
  |-- 以上皆非？
  |     -> 默认柱状图（最通用易读）
```

### 何时不要用图表

| 情况 | 改用 |
|------|------|
| 数据点少于 3 | 统计卡或文字叠加：“收入增长 40% 至 210 万美元” |
| 类别多于 12 | 聚合为 Top 5-7 + “其他”后再作图 |
| 强调单一数字 | 全屏统计卡配冲击动画 |
| 定性比较 | 并排图像或文字表格 |
| 数据需要 30 秒以上才能读完 | 拆成多个更简单的图表分布到不同场景 |

## 动画编排

视频中的每张图表都应动画化。静态图表看起来像幻灯片，不像视频。

### 模式：构建式（默认）

先显示空坐标系/框架，再动画填充数据。

```
0.0s: 空图表框架（坐标轴、标题、网格线可见）
0.3s: 第一个数据元素开始进入
2.0s: 所有数据元素完全渲染
2.0-5.0s: 停留供阅读
```

- **柱状图：** 柱子从基线向上生长（从左到右错开，每个延迟 0.1 秒）。
- **折线图：** 线条从左到右沿数据路径描绘。
- **饼图/环形图：** 从 12 点方向顺时针填充，最大片优先。
- **KPI 网格：** 数字从 0 计数到最终值（里程表效果）。

### 模式：叙事高亮

旁白提到哪个元素就高亮哪个。

```
0.0s: 完整图表可见，但所有元素 30% 不透明（去饱和）
0.5s: 第一个高亮元素恢复全色并轻微放大
3.0s: 第一个元素恢复常态，第二个高亮
……对每个旁白要点重复
```

用于旁白逐项讲解数据时，使观众注意力与旁白同步。

### 模式：对比揭示

先展示基线，再动画呈现变化。

```
0.0s: 基线数据可见（如“之前”柱子）
2.0s: 停留基线供理解
2.5s: 动画呈现变化（柱子生长/收缩到“之后”值）
3.5s: 差值标签出现（+40%、-15% 等）
3.5-7.0s: 停留供阅读
```

用于前后对比、同比或 A/B 比较。

### 时序规则

| 元素 | 动画时长 | 停留时长 |
|------|---------|---------|
| 图表构建 | 2-4 秒 | 3-5 秒 |
| 单元素高亮 | 0.3-0.5 秒 | 2-3 秒 |
| 对比过渡 | 1-2 秒 | 3-5 秒 |
| KPI 计数 | 1.5-2 秒 | 2-3 秒 |
| 标签/注释出现 | 0.2-0.3 秒 | 保持在屏幕上 |

**关键规则：** 图表必须完全构建并至少停留 3 秒后才能转场。观众需要时间阅读。若旁白在图表可读前就推进，要么延长场景，要么简化图表。

## 标签摆放规则

### 柱状图

```
纵向柱：
  - 数值标签：柱上方（或柱子足够高时放内部）
  - 类别标签：x 轴下方，水平文字
  - 若标签重叠：旋转 45 度或改用横向柱
  - y 轴：保留网格线；若标题已说明则省略轴标签

横向柱：
  - 数值标签：柱右侧
  - 类别标签：y 轴左对齐
  - 类别名超过两个词时优先使用
```

### 折线图

```
  - 端点标签：在最后一个数据点（右端）显示数值
  - 起点标签：在第一个数据点（左端）显示数值提供背景
  - 密集数据（多于 7 点）：只标起点、终点及显著峰谷
  - 避免：每点都标（视频中会杂乱）
  - 图例：多系列时放右上或内联（贴线标注）
```

### 饼图 / 环形图

```
  - 大扇区（≥10%）：标签放扇区内（百分比 + 类别）
  - 小扇区（<10%）：标签放外部，用引线连接扇区
  - 环形中心：用于总量或关键指标标签
  - 最多 5-6 片。低于 5% 的合并为“其他”
  - 始终显示百分比，而非仅原始值
```

### KPI 网格

```
  - 大数字：每张卡中心，用统计卡字体（正文 3-4 倍）
  - 标签：数字下方，较小字体，描述指标
  - 差值指示：小箭头 + 百分比表示变化（绿升红降）
  - 网格：2x2 或 3x2 布局，等距，卡片尺寸一致
```

### 通用标签规则

- **标题可见：** 每张图表必须有清晰标题（左上或顶部居中）。
- **来源标注：** 外部数据来源时，底部小字显示“来源：[名称]”。
- **单位：** 始终显示单位（%、$、秒等），放在标题或坐标轴上。
- **无孤立元素：** 每个视觉元素都必须有标签或被旁白解释。

## 数据密度与可读性

### 视频法则：少即是多

视频不是电子表格。观众无法暂停、滚动或缩放。每个数据点都在 5-7 秒窗口内争夺注意力。

```
各图表类型的理想数据点数：
  柱状图：   5-7 根（最多 9）
  折线图：   5-12 点（最多 15，但稀疏标注）
  饼图：     3-5 片（最多 6）
  KPI 网格： 3-6 个指标（最多 6）
```

### 简化策略

| 问题 | 方案 |
|------|------|
| 类别过多（>9） | 显示 Top 5-7，其余聚合为“其他” |
| 时间段过多 | 聚合（月→季，日→周） |
| 需展示多个指标 | 拆成独立图表分布到不同场景 |
| 数值范围过宽 | 用归一化/百分比视图替代绝对值 |
| 小数精度 | 激进取整：$1,234,567 → $1.2M |

### 最小字号（1080p）

以下为移动端在内的可读性底线，不可让步：

| 元素 | 最小字号 | 推荐 |
|------|---------|------|
| 图表标题 | 32px | 36-40px |
| 坐标轴标签 | 24px | 28px |
| 数值标签 | 24px | 28px |
| 注释 | 20px | 24px |
| 来源标注 | 16px | 18px |

**缩放规则：** 4K 输出乘以 2。720p 时上述最小值仍适用（它们是底线）。

## 配色

### 从 Playbook 派生图表配色

图表必须看起来属于这个视频。始终从当前风格 playbook 派生颜色。

```
配色派生优先级：
  1. playbook.visual_language.color_palette.chart_palette（若 playbook 定义了）
  2. 从主色 + 强调色派生：
       - 柱/片 1：primary[0]
       - 柱/片 2：accent[0]
       - 柱/片 3：primary[1]
       - 柱/片 4：accent[1]
       - 柱/片 5+：通过调整 primary[0] 明度生成
  3. 背景：用 playbook 背景色
  4. 文字/标签：用 playbook 文字色
  5. 网格线：用 playbook 弱化色 50% 不透明
```

### 高亮与聚焦

```
高亮策略：
  - 关键数据点：  accent[0] 全饱和，轻微放大（1.05x）
  - 聚焦数据点：  各自分配色全饱和
  - 非聚焦点：    降至 30% 不透明或使用弱化色
  - 基线/背景：   用弱化色的虚线
```

### 无障碍规则

不要仅靠颜色传达含义：

- **加图案：** 柱/片上叠加斜线、点或条纹，配合颜色使用。
- **加标签：** 每根柱/片/线都必须有文字标签，不能只有图例。
- **对比度：** 相邻图表元素之间最低 3:1 对比。
- **色盲友好：** 避免红绿作为唯一区分。表示正负时优先蓝橙或蓝黄配对。

## 常见陷阱

### 误导性图表

| 陷阱 | 为何误导 | 修复 |
|------|---------|------|
| y 轴截断（不从 0 开始） | 微小差异显得巨大 | 柱状图 y 轴始终从 0 开始 |
| 3D 图表 | 透视扭曲大小感知 | 始终用 2D 平面图表 |
| 双 y 轴不同量纲 | 暗示虚假相关 | 用两个并排独立图表 |
| 挑选时间范围 | 隐藏更广背景 | 展示完整相关范围或注明截断 |
| 饼图片数过多 | 小角度无法比较 | 最多 5-6 片，其余聚合 |

### 动画错误

| 陷阱 | 修复 |
|------|------|
| 动画过快（<1.5 秒） | 观众跟不上出现内容。构建最少 2 秒 |
| 动画后无停留 | 场景在图表可读前切走。最少停留 3-5 秒 |
| 所有元素同时出现 | 丢失叙事性。错开元素入场 |
| 无意义弹跳/旋转 | 分散数据注意力。按 playbook 用干净的缓入缓出 |

### 设计错误

| 陷阱 | 修复 |
|------|------|
| 单图颜色过多（>5） | 限制在 4-5 种。聚合或拆分图表 |
| 缺标题 | 每张图表都需要标题。观众没有其他上下文 |
| 移动端字号过小 | 强制最小值：1080p 下标题 32px，标签 24px |
| 装饰性网格线 | 用浅网格线或不加。应辅助阅读而非装饰 |
| 深色背景上深色文字 | 用 playbook 文字色配 playbook 背景色，检查对比度 |

## 与场景导演集成

场景导演识别出数据可视化需求时，按以下方式应用：

1. **用决策树确定图表类型。**
2. **在场景的 `movement` 字段指定动画模式**（如“构建式：柱子从基线 2 秒生长，停留 4 秒”）。
3. **在 `overlay_notes` 包含标签规格**（如“数值标签在柱上方，标题左上，来源右下”）。
4. **在 `required_assets` 描述中引用 playbook 颜色**（如“柱状图用 primary[0] #2563EB 作主柱，accent[0] #F59E0B 作高亮柱”）。
5. **设置场景时长**以容纳动画（2-4 秒）+ 停留（3-5 秒）= 每个图表场景最少 5 秒。

## 质量清单

- [ ] 图表类型匹配数据故事（而非“默认柱状图”）
- [ ] 数据点在限内：5-7 柱，3-5 饼片，5-12 折线点
- [ ] 动画时长：构建 2-4 秒，停留最少 3-5 秒
- [ ] 所有文字满足最小字号：1080p 下标题 32px，标签 24px
- [ ] 颜色派生自当前 playbook 调色板
- [ ] 关键数据点有视觉强调（高亮色、缩放或注释）
- [ ] 含义不单靠颜色（标签 + 图案保证无障碍）
- [ ] 柱状图 y 轴从 0 开始
- [ ] 无 3D 效果或透视扭曲
- [ ] 标题可见且具描述性
- [ ] 使用外部数据时标注来源
- [ ] 停留期内任意帧暂停时图表都可读
