# 剪辑总监 · 本地化配音流水线

## 何时使用本阶段

把场景计划与本地化素材包翻译成每种语言输出的具体时间线决策。目标是在可能的情况下保留源片结构，但不假装所有语言都能落在同一时序上。

## 流程

### 1. 默认保留结构

除非翻译后的音频明显需要延长、压缩或补充覆盖，否则保持原有场景顺序与主要时序不变。

### 2. 应用已选定的配音模式

按交付物分别决定在哪些位置：

- 保留原画面并叠加新字幕；
- 只替换音轨；
- 采用唇形同步输出；
- 用图形或 B-roll 覆盖不匹配之处。

### 3. 语言变体要组织清楚

时间线决策按语言区隔存放，让版本管理一直清晰延续到合成与发布阶段。

### 4. 用元数据控制变体

推荐使用的元数据键：

- `locale_timeline_map`
- `timing_adjustments`
- `coverage_sections`
- `subtitle_strategy_by_locale`

### 5. 质量门

- 语言变体是显式的；
- 时序改动都有记录；
- 覆盖决策是有意为之的；
- 只在必要时才改动原有结构。

## 常见陷阱

- 强迫所有语言与源片时序完全对齐。
- 把各语言专属备注混进一份含糊的剪辑清单。
- 在配音处理视觉薄弱处隐藏对应段落。
