# 룩 찾기

사용자마다 원하는 스타일이 다르다. 감독이 먼저 할 일은 그 사람의 룩을 빨리 찾아 고정하는 것이다. 룩은 기획서의 형용사("밝고 경쾌하게")가 아니라 화면으로 정한다.

## 질문 (1단계)

한 번에 묻고, 답이 없는 칸은 추측하지 않는다. 비어 있는 칸은 3단계 스타일프레임에서 서로 다른 선택지로 보여 준다.

1. **참고:** 좋았던 영상이나 이미지가 있나요? 이전에 만든 영상 중 이렇게 만들고 싶은 게 있나요? 무엇이 좋았나요?
2. **싫은 것:** 피하고 싶은 느낌이 있나요? (예: 유치함, 공포, 너무 복잡함, 캐릭터)
3. **밝기와 대비:** 어두운 배경에 빛나는 물체 / 밝은 배경에 선명한 색 / 상관없음
4. **화면 밀도:** 한 화면에 문장 하나만 크게 / 정보를 많이 넣어도 됨
5. **사람과 캐릭터:** 넣기 / 빼기 / 이미 있는 캐릭터만
6. **속도:** 빠르고 강하게 / 차분하고 고급스럽게
7. **음악:** 쓰고 싶은 곡이 있나요? 분위기는?

사용자가 "알아서"라고 하면 1, 2, 5만 묻는다. 셋 다 답이 없으면 스타일프레임을 서로 다른 룩으로 보여 준다.

## 근거의 우선순위

1. 사용자가 말하거나 고른 것
2. 사용자가 좋다고 한 이전 영상이나 참고 영상
3. 원고의 색 안내, 브랜드 가이드, 포스터
4. 이 스킬의 기본값

아래 순위가 위 순위와 부딪히면 위를 따른다. 원고의 색 안내는 색을 고를 때 참고하고, 밝기와 화면 밀도는 사용자 기준을 따른다. 브랜드 가이드가 절대 규칙이면(로고 색 등) 그 부분만 지키고 나머지 룩은 사용자 기준으로 간다.

실패 사례: 사용자가 "본편처럼 우와하는 느낌"을 원했는데, 원고 포스터의 밝은 색 안내와 "시리즈면 톤을 바꾼다"는 규칙을 따라 밝은 종이 질감으로 만들었다. 두 번의 자체 리뷰를 통과했지만 사용자는 "시각적 임팩트가 없다"며 거절했다. 본편과 나란히 놓고 보니 배경이 밝고, 화면이 여러 칸으로 나뉘고, 같은 배치가 반복돼 있었다.

## 스타일프레임으로 고르기 (3단계)

- 컨셉마다 한 장씩, 룩이 서로 확실히 다르게 만든다. 같은 룩의 색만 바꾼 네 장은 선택지가 아니다.
- 완성본 수준으로 만든다. 조명, 재질, 글자 크기, 주인공 크기가 실제 렌더와 같아야 비교할 수 있다.
- 한 장의 비교 시트로 묶어 보여 주고, 각 장의 첫 1초와 위험을 한 줄로 적는다.
- 사용자가 고른 장이 이후 모든 비교의 기준이 된다. 섞자고 하면 섞은 한 장을 다시 만들어 확인받는다.

## 시리즈에서 룩 고정하기

사용자가 좋다고 한 룩은 다음 편에서 그대로 쓴다. 바꾸는 것은 구성(컨셉, 장면 순서, 주인공 물체)이다. 룩을 바꾸려면 사용자가 원할 때만 바꾼다.

납품할 때 `production/look-lock.md`에 적는다.

```markdown
# Look lock — {영상 이름}
- 승인한 말: {사용자가 좋다고 한 말 그대로}
- 배경: {예: 남색 방사형 그라데이션, 장면마다 색 세계 변경}
- 주인공: {예: AI 광택 3D 오브젝트 투명 PNG, 화면 폭의 55%}
- 글자: {폰트, 굵기, 크기, 그림자}
- 움직임: {BPM, 슬램 이징, 섬광 세기, 컷 길이}
- 코드: {컴포넌트 파일 경로. 다음 편은 이 파일을 복사해서 시작한다}
- 하지 말 것: {사용자가 싫다고 한 것}
```
