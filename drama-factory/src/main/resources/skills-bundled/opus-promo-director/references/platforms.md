# 플랫폼 규격과 세로 안전 영역

2026-09-30에 확인한 값이다. 플랫폼 앱의 화면 배치는 바뀐다. 올리기 전에 앱의 미리보기로 한 번 본다.

## 납품 규격

| 비율 | 해상도 | 쓰는 곳 |
|---|---|---|
| 9:16 | 1080×1920 | 릴스, 쇼츠, 틱톡 |
| 16:9 | 1920×1080 | 유튜브, 웹, 행사장 상영 |
| 4:5 | 1080×1350 | 인스타·스레드 피드 |
| 1:1 | 1080×1080 | 정사각 피드 |

- 코덱은 H.264, 색 형식은 yuv420p, 30fps, 소리는 AAC.
- Remotion은 기본으로 yuvj420p(전체 범위 색)를 낸다. 일부 앱에서 색이 달라지므로 납품 전에 변환한다. `deliver.py`가 경고와 변환 명령을 보여 준다.
- 파일 이름에 한글을 써도 스크립트는 동작한다. 업로드할 사이트가 한글 이름을 깨뜨리면 영문 이름으로 바꾼다.

## 세로 안전 영역 (1080×1920)

글자, 로고, 행동 유도를 둘 수 있는 사각형이다. 바깥은 앱의 버튼, 설명 글, 계정 이름이 덮는다.

| 플랫폼 | 글자 영역 | 근거 |
|---|---|---|
| 인스타·페이스북 릴스 | x 65~1015, y 269~1248 | Meta는 위 14%, 아래 35%, 좌우 6%를 비우라고 안내하고 확인용 템플릿을 준다 ([Meta for Business](https://www.facebook.com/business/ads/facebook-instagram-reels-ads)) |
| 유튜브 쇼츠 | x 48~888, y 288~1248 | 유튜브는 일반 쇼츠의 픽셀 기준을 공개하지 않는다. 오른쪽 버튼과 아래 제목·설명 자리를 보수적으로 잡은 실무 값이다 |
| 틱톡 | x 90~900, y 150~1420 | 광고 형식마다 템플릿이 다르다(TikTok for Business). 보수적으로 잡은 값이다 |
| **세 곳 공통** | **x 90~888, y 288~1248** | 같은 파일을 세 곳에 올릴 때 |

- 공통 영역은 가로 798px, 세로 960px이다. 화면 위쪽 절반쯤이다.
- 큰 주인공 물체는 안전 영역 위쪽(y 288~800)에 두고, 제목과 정보는 그 아래(y 800~1248)에 둔다. 배경과 장식은 영역 밖으로 나가도 된다.
- 가로판을 축소해서 세로판을 만들지 않는다. 세로 전용 배치를 따로 만든다.
- 검사는 `scripts/safe_zone.py`로, 장면마다 글자가 가장 많이 보이는 프레임(마지막 카드가 들어온 직후, 사라지기 전)에서 한다. 컷 직후 프레임만 보면 나중에 들어오는 카드를 놓친다.
- Remotion에서는 키트의 `SAFE_ZONES`와 `SafeArea`가 같은 값을 쓴다.
