# 参与改进

欢迎提交有出处的镜头观察、工具修复和使用说明。先说明需要解决的实际问题，再保持变更范围尽量小。

## 镜头与声音记录

- 新镜头记录原作者、原帖和可回看的秒段，区分观察状态与建议实现。
- 声音记录区分信号候选、实际试听、用户确认与原创设计；不要为了通过工具校验把候选改成已确认。
- 不提交第三方原视频、截图、配乐、个人绝对路径、完整研究缓存或临时媒体直链。确需新增可分发素材时，先说明来源和授权。
- 不把某次客户端限制、某个媒体副本或某个工程参数写成普遍规则。

## 工具变更

使用 Python 3.11+ 与 README 中的依赖，运行：

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

维护输入不改写、默认输出不覆盖、失败不留下成功结果、实际 PTS 与声音候选身份等行为。新增测试用临时生成的素材，避免下载原作作为测试夹具。提交时注明哪些检查实际通过，哪些平台或声音结论未验证。

反馈问题时提供命令、Python / FFmpeg 版本、错误信息及最小可复现输入；分享日志或派生产物前检查其中的路径和元数据。

提交贡献即表示你有权提交这些内容，并同意按本仓库的 MIT 许可证分发。
