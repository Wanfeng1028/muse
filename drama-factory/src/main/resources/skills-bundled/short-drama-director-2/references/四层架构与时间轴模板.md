# 四层架构与时间轴模板

## 一、四层提示词架构

提示词分四层，各司其职；**修改时只调对应层，不用全部重写**：

| 层 | 职责 | 内容 |
|----|------|------|
| ① 全局层 | 锁定基础 | 场景、人物统一形象、影像风格（风格词别挤占表演指令） |
| ② 人物层 | 铺垫性格 | 双方底层性格、基础情绪基调 |
| ③ 时间轴层（核心） | 驱动表演 | 逐段标准公式（见下） |
| ④ 兜底层 | 补全细节 | 环境音、静止画面细节 |

## 二、时间轴层标准公式

```
[时间码] + 说话人 + 台词（含触发词） + 面部生理反应 + 音量/动作 + 话权切换 + 对方同步反馈
```

写法要点：
1. **台词含触发词**：台词中藏着戳对方痛点的词，它是后面抢话/卡顿的引信
2. **面部生理反应**：写生理词（眼眶泛红/吞咽困难/喉结滚动）或 AU 编码，禁止空泛情绪词（"很悲伤"）
3. **音量/动作**：抢话时压低音量；沉默时配呼吸声
4. **话权切换**：标注 插话/抢话/留白 及重叠时长
5. **对方同步反馈**：B 听到台词后的生理反应（情绪承接）

## 三、可复制空模板

```
【全局层】
场景：{地点/时间/氛围}。人物A：{外观+服装}；人物B：{外观+服装}。影像风格：{电影质感/纪录片/年代感…}，画面纯净无字幕，禁止AI塑料感，禁止过度磨皮。

【人物层】
A 底层性格：{性格底色}，基础情绪：{基调}。
B 底层性格：{性格底色}，基础情绪：{基调}。

【时间轴层】
段1（0.0-Xs）｜{情绪阶段名}
  A：台词「{内容}」——{面部生理反应}，{音量/动作}；B 同步反馈：{打断前的小动作/眼神变化}。
  话权切换：{插话/抢话/留白}——B 在 A 尾词未落时提前开口，声音重叠约0.2秒，压低音量。

段2（X-Ys）｜{情绪阶段名}
  B：台词「{内容}」——{言语不流畅类型：启动失败/重复短句/改口/沉默}，卡顿落在{转折词/人称/对方名字}上，{呼吸与口型同步}。
  A 同步反馈：{被戳中后的生理反应：眼眶泛红/吞咽困难}。
  话权切换：{抢话——B 听到戳中痛点的台词，立刻打断、重复否认}。

段3（Y-Zs）｜{情绪阶段名}
  A：沉默 {X} 秒，{吸气失败/喉咙堵塞}，{自我控制动作：移开视线/强忍泪水}；随后{关系目标：优先安抚对方}，声音{音量变化}。
  B 同步反馈：{观察到对方崩溃，语气放软}。
  话权切换：{不抢话，留出空白停顿消化情绪}。

【兜底层】
环境音：{雨声/街道/钟表…}。静止画面细节：{道具特写/光影变化}。

【约束】
禁止两人轮流念稿；禁止自动补全被打断的句子；杜绝机械重复口吃；口吃与卡顿须搭配呼吸与口型同步；面部清晰不扭曲，人体结构正常；同一角色形象全程一致。
```

## 四、实战示例——《她发现了那份文件》

```
【全局层】
深夜公寓客厅，暖黄台灯。人物A（女，35岁，米色针织衫）：妻子，形象全程一致；人物B（男，38岁，深灰衬衫）：丈夫，形象全程一致。影像风格：电影质感，自然光，画面纯净无字幕，禁止AI塑料感，禁止夸张表情，禁止背景音乐。

【人物层】
A 底层性格：理性克制、习惯照顾他人感受，基础情绪：疲惫中带着不安。
B 底层性格：温吞回避、不擅面对冲突，基础情绪：心虚强撑镇定。

【时间轴层】
段1（0.0-4s）｜试探
  A：台词「这个……这个是什么？」——声音发虚，尾音上扬，视线落在桌角文件上，手指无意识摩挲杯沿；B 同步反馈：肩膀一僵，喉结滚动。
  话权切换：留白——A 说完后停顿 1.5 秒，等 B 回答。

段2（4-9s）｜改口与逼问
  B：台词「没什么……就是，就是以前的一个合同，对，合同。」——话说一半自我修正改口，卡顿落在人称和"对"字上，眼睛快速眨动，不敢直视对方；A 同步反馈：眼眶微红，呼吸变浅。
  话权切换：抢话——A 听到"合同"二字，立刻打断重复质问：「合同？你上个月还说——」（尾音被自己咽回去）。

段3（9-15s）｜残酷真相与沉默
  B：台词「……其实，上个月我已经，已经辞职了。」——启动失败，喉咙堵塞，声音发颤，说到最后几近气声。
  A：长时间沉默 3 秒，吸气失败，肩膀缓缓塌下，眼泪在眼眶打转却强行移开视线看向窗外；随后刻意平复呼吸，转回头轻声说：「……没事，先吃饭吧。」——试图安抚对方，音量压到最轻。
  B 同步反馈：眼眶通红，低头攥紧裤缝，不再说话。
  话权切换：不抢话，留出空白停顿，两人之间只剩钟表声。

【兜底层】
环境音：墙上挂钟滴答声、窗外零星车流声。静止画面细节：台灯光晕在两人之间投下一道阴影；桌角文件的一角被风微微掀起。

【约束】
禁止两人轮流念稿；禁止自动补全被打断的句子；杜绝机械重复口吃；口吃与卡顿须搭配呼吸与口型同步；面部清晰不扭曲，人体结构正常；同一角色形象全程一致。
```

## 五、成片自检三要点

1. 人物声音是否存在**重叠**（有则真实，无则念稿）
2. 口吃、卡顿是否搭配**呼吸、口型同步**
3. 双方情绪能否**互相承接**（A 的情绪是 B 反应的触发词）
