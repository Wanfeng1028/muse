# card-prompt-box · 输入框下指令

一个通用输入框里逐字打出“把这段口播剪成竖屏短视频”，回车；三样生成物（成片、字幕、音效）依次浮现，各自飞约 0.7 秒进一个白色纸盒，全部进盒后**停一拍**再从容合盖，盖上出现一个勾。全屏卡，5.0 秒，1080×1920，30 fps，带合成音效。画面里没有任何平台或产品的样式、名字和图标。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 做法

- 场景：日光摄影棚，冷灰纸背景、顶光、大块柔和投影，一个钴蓝强调色。
- 输入框：打字节奏不均匀（按字速 `cps`，个别字多停一下），光标打字时常亮、停下来闪烁；回车时发送键按下、扩散一圈、输入框里跑一道“处理中”的光。
- 生成物：三张卡片从上到下扫描式出现，再沿弧线飞进盒子（`fly` = 0.7 s），飞行中有旋转、缩放和真实运动模糊；进盒时从前壁后面落下去，最后竖着露出上半截在盒口。
- 纸盒：真正的 3D（看向盒子的透视相机、盒子转 3/4 角度、按面剔除、主光从左上），盒盖是有厚度的板子绕后沿铰链转动；合盖用“先慢后加速”的曲线（不是一下拍上），合上时有挤出的空气、盒体轻微回弹。

## 适合场景

“一句话交给 AI”“提交需求 → 打包交付”“生成 → 归档”的流程示意；三样生成物的名字和小字都可以改。

## 主要参数（`src/build.py` 的 `PARAMS`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `text` | 把这段口播剪成竖屏短视频 | 逐字打出的指令 |
| `hint` | 描述你想要的视频… | 占位提示 |
| `items` | 成片 00:58 / 字幕 83 条 / 音效 12 个 | 三样生成物：[标签, 小字] |
| `cps` | 10 | 打字速度（字/秒） |
| `fly` | 0.7 s | 每样东西飞进盒子的时长 |
| `beat` | 0.4 s | 全部进盒后停一拍 |
| `close` | 0.55 s | 合盖时长 |
| `accent` | #2F5BFF | 强调色 |

## 声音

每个字一下 `typing_key`，回车加重键和点击；三颗音高依次升高的 `blip` + 一层 `shimmer` 表示生成；每样东西飞行一声 whoosh、落进盒子一声本条目合成的 `box_drop`（纸盒里的轻闷响 + 纸声）；停拍时几乎无声；合盖是本条目合成的 `box_close`（先有挤出的空气声，再是纸盒闷响和里面东西轻轻一晃），勾出现时 `pop_soft` + `pluck`。成片 −29.1 LUFS / 峰值 −10.0 dBTP。

## 重渲

```bash
cd library/card-prompt-box/src
python3 build.py stills --times 1.0 2.25 3.2 4.7
python3 build.py render --out <输出目录>
```

字体：思源黑体 Medium / Bold（`fonts/`）。
