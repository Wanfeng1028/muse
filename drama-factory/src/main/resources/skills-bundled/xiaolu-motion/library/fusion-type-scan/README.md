# fusion-type-scan · 活字扫描

真人口播身后的墙变成一整版金属活字：第一道扫描线自上而下把米色墙换成排满铅字的版面（字就是这条视频自己的文案，按阅读顺序排）；说到“完成后它会自己检查一遍”时，一道更亮的检查扫描线扫下来，扫到的活字升起、翻面、露出刚抛光的新字面，头顶那一行翻出金色的“自己检查一遍”。人物始终保持原片彩色在最前面。4.6 秒，1080×1920，30 fps，带原声。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 用了哪段素材

视频20 锁定母版 `plate_v2_video.mp4` 第 3600–3738 帧（v2 时钟 120.0–124.6 s），原话“（动效音效等）包装 完成后它会自己检查一遍”：前半句墙变成活字，后半句检查扫描。

## 做法

- `prep`：Vision 抠像 + 精修 + 干净背景（本段看到 40.7% 的墙），人物层是原片像素 + 掩膜 alpha，半透明边缘按已知墙色反解前景色，所以发丝压在深色金属上没有米色毛边。
- 活字版面：每块 118 px、间距 128 px，10 列 × 16 行；字面是凸起字形（阴影、肩部、渐变字面、斜边高光）。和人脸框（外扩 24 px）相交的位置放空铅（没有字的铅块，排版里真实存在），脸周围不会出现字。
- 扫描：检查扫描线附近的活字按“离扫描线的距离 + 所在列”错开触发，形成一道斜向的翻面波；翻面中的活字是透视下的 3D 块（绕水平轴转半圈，露出侧面），字只画在朝向镜头的那一面、按该面自己的四角映射，所以永远正向不镜像。
- 光：扫描线是墙上的一道亮线 + 光带，照亮经过的活字；它在人身后，辉光层会把人物区域抠掉，光不会落到人身上。

## 适合场景

“检查 / 扫描 / 审核 / 排版 / 整理”类口播，人物站在纯色墙前、头部相对稳定的镜头。

## 主要参数（`src/build.py` 的 `PARAMS` / `PLATE`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `PLATE.start` / `end` | 3600 / 3738 | 底片帧范围 |
| `text` / `text2` | 视频20 文案 | 墙上的字 / 翻面后露出的字（只取汉字） |
| `phrase` / `phrase_row` | 自己检查一遍 / 2 | 翻出金色短语的那一行 |
| `reveal` | [0.12, 1.0] s | 第一道扫描（墙变活字） |
| `scan` | [2.2, 3.9] s | 检查扫描 |
| `pitch` | 128 px | 活字间距 |

## 声音

原声 + 墙变活字时每一行一个干涩的金属 tick、检查扫描一道长 whoosh、每一行翻面一声 `clack`、金色短语出现时 `shimmer` + `pluck`。成片 −17.8 LUFS / 峰值 −2.0 dBTP。

## 重渲

```bash
cd library/fusion-type-scan/src
python3 build.py prep --plate <plate_v2_video.mp4> --voice <voice_master_48k.wav>
python3 build.py stills --times 0.6 2.6 3.3 4.4
python3 build.py render --out <输出目录>
```

## 核验（2026-09-27）

- 肤色：只取掩膜完全不透明（alpha = 255）的人脸像素和原片比，平均差 1.19 级，平均色差 +0.1 级。
- `python3 -m qa.pixel_qa`（9:16 档，23 帧）：PASS。同一段原片不加任何图形单独跑，也会偶尔把眼镜镜片认成“卡片边穿过人脸”（23 帧里 2 帧），属于素材本身的误报。
