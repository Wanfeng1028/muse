# 导演思维与四轴设计

## 一、从镜头内容升级到导演选择

不要先问“用什么景别”，先问：

- 这是动作发生前、发生中还是发生后的哪一瞬？
- 观众站在哪一方：目击、跟随、监视、审判还是被阻隔？
- 谁支配空间：人物、建筑、制度、机器、天气还是一个物件？
- 画面结束时发生了哪一个可见且可延续的状态变化？

有效镜头至少包含前因痕迹、当下动作或下一步方向。人物不能只是站着摆造型。

## 二、四轴必须同时工作

### 1. 光线与反差

先画光源图，再写情绪：

- 主光源：位置、方向、软硬、覆盖范围。
- 次光源：是否间歇、是否只触达局部。
- 阴影保护区：哪些区域理应看不清。
- 高光承载物：皮肤、湿布、玻璃、金属、蒸汽或尘埃。
- 反差变化：本镜是否因门打开、炉火喷发、车辆经过或遮挡移动而改变。

禁止无来源轮廓光、全人物等亮、HDR 式暗部全开、用雾替代空间。

### 2. 色彩与曝光

颜色必须来自建筑、服装、天气、灯具和材料，而不是套滤镜。

- 先保护真实高光，再允许非叙事区域沉入暗部。
- 肤色属于场景，不得永远比环境亮。
- 一镜保留一到两个色彩锚点；其他颜色服从空间。
- 贫穷、破损和污垢必须符合使用痕迹，不能“精心做旧”。

### 3. 镜头与摄影机

按以下顺序决定：

1. 摄影机能实际站在哪里；
2. 与人物的距离；
3. 高度与俯仰；
4. 是否有门框、管线、玻璃、前景人物等自然边界；
5. 焦段带来的开放、自然、压缩或隔绝感；
6. 是否需要移动，以及移动由什么触发。

焦段只是空间行为的结果：

- 24–32mm：近远关系强，适合建筑、狭窄空间和巨物尺度；注意边缘变形。
- 35–50mm：自然观察，适合街道、双人和环境内表演。
- 65–85mm：压缩关系，适合监视、私密动作、隔层观察。
- 100mm 以上：远距、疏离、细节或人群中的不可接近感。

### 4. 构图与空间

构图表达权力，而不是追求漂亮：

- **三分线**：用于人物与环境、人物与威胁、说话者与倾听者之间的张力。
- **中轴**：用于秩序、制度、仪式、封锁或权力彻底占据空间；越少用越有力。
- **负空间**：必须容纳视线、威胁、目的地、阶级距离或即将进入的动作。
- **前中后景**：每一层承担不同叙事信息，不把所有物件拍清。
- **层级与通道**：楼梯、桥、门、窗、电梯、走廊、栏杆和高度差应直接参与人物关系。

## 三、21:9 的专用语法

21:9 不是把人物放中间再裁掉上下边缘。

- 用横向距离表现不平等、等待、监视与无法接近。
- 将人物放在一侧三分线时，另一侧必须承担故事信息。
- 巨型环境镜头可把人物压在下方交点，让建筑或机械占据上方与远端。
- 对话不要反复做对称单人头像；保留对方肩部、空间障碍、视线方向与沉默者反应。
- 横向运动应提前预留移动空间；切镜前后保持运动方向，除非明确用越轴制造断裂。
- 使用门框、立柱、机械结构将宽画幅分割成多个权力区，而不是填满装饰。

## 四、人物调度与表演

人物表演遵循：

`刺激 → 理解停顿 → 非自主反应 → 主动选择 → 残留情绪 → 下一动作`

每一拍只选一至三个可见信号：视线偏移、呼吸变化、握力变化、半途停止的手、重心后撤、延迟回应。不要逐项指挥眉毛、鼻翼、嘴角。

对话必须给倾听者时间。真正的戏剧落点常发生在一句话之后，而不是台词本身。

## 五、动作场与战斗

动作清晰度优先于快切：

1. 先建立入口、出口、遮挡、距离、武器与高低差；
2. 建立攻击方向和人物屏幕方向；
3. 用一个小动作暴露伏击或战术意图；
4. 动作爆发后，切镜围绕因果节点：发力、接触、受力、结果；
5. 环境必须影响战术，不能只是背景；
6. 战斗后保留呼吸、损伤、道具位置和空间余波。

避免重量消失、无因反弹、全程升格、摄影机穿墙、每击都环绕和动作方向混乱。

## 六、声音导演

每镜区分：

- 环境底噪；
- 近场动作声；
- 画外声；
- 台词与呼吸；
- 音乐或明确无音乐；
- 进入下一镜/下一组的声音桥。

静音是一种事件：必须说明什么声音被抽走、持续多久、由什么恢复。

## 七、反 AI 设计

- 不用 `cinematic / masterpiece / epic / 8K` 代替具体画面。
- 不让每个表面同样锐利、湿亮、精致。
- 不为“高级”随意添加雾、逆光、镜头光晕、浅景深和飞舞颗粒。
- 不让每个人都正脸、站定、看镜头。
- 不把破败环境做成漂亮的概念艺术景观。
- 如果去掉风格词后镜头无法画成平面图，说明设计仍不成立。
