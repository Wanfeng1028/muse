# FeedFlow 设计注记（v1.12.0）

视觉逻辑：编辑室报纸。纸面底色、墨色正文、柿色单主色，细线分隔代替色块堆叠。
借鉴的是报纸编辑室与桌面 RSS 阅读器的排版范式（左栏目录、中栏清单、右栏正文；
标题衬线、序号与分数用等宽数字），不是照抄任何竞品界面。

- 颜色：纸 #FAFAF7、墨 #1C1A17、灰 #6B655A、线 #E7E2D6、柿 #C2410C、浅柿 #FBEDE6、米灰 #F3F0E8。纯色，无渐变。
- 字体：界面系统字体，阅读正文与大标题用宋体衬线；数字用等宽数字。
- 层级：品牌前 10px 柿色方块；导航激活态浅柿底加底部 2px 柿色线；订阅与文章选中态浅柿底加左侧 3px 柿色线；
  摘要序号衬线 20px 柿色；统计卡顶部内阴影 3px 柿色线。
- 去 AI 味自查：无紫渐变、无 Inter 独占、无居中英雄区、无三栏特性格、无 emoji 图标、
  无 Unleash/Empower/Seamless/Next-generation 类文案、无 Specimen 风衬线大标题。
- 实现：原 style.css 不动；design-v112.css 为覆盖层，base.html 在 style.css 之后引用；
  摘要/统计页内 style 用后代选择器提特异性覆盖。
- 已知：阅读器空态在 v1.14.0 已做成导览页（见下），不再是功能性提示；
  门面截图用已打开文章的阅读器与今日必读页，均为真实种子数据。
