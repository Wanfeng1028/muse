## 已知限制清单

- 锁定时间戳用墙钟，系统时钟大幅变动会影响锁定时长；
- 同一库文件多进程共享计数靠 SQLite 串行化写；
- 反代后同 IP 共享计数；
- 登出支持 GET；
- 会话 cookie 未设 Secure；
- pyproject.toml 的 version 字段仍为 0.1.0，与 CHANGELOG 版本号不一致，这是自早期起的既有遗留，本版未动。
