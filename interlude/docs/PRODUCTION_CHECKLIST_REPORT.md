## 7. 环境限制（诚实声明）

1. **Gradle daemon 在本沙箱不可用**（2026-10-13 多次验证：daemon 能启动但客户端
   dispatch 后 36ms 即 "Could not receive a message from the daemon"；回环 TCP 正常，
   非 OOM）。构建与测试改用 kotlinc 直编 + JUnit Console 验证。`build.gradle.kts`
   保留正确配置，供真实机器使用。
2. **Compose UI 在本沙箱无法编译为可运行二进制**：手动组装 kotlinc 2.1.0 +
   compose-compiler-plugin 2.1.0 时，插件在 JVM 后端 IR lowering 阶段崩溃
   （连最简 `@Composable fun Hello()` 都崩；属手工拼装编译器环境缺失组件，
   非项目代码问题——前端语义分析零错误）。因此**桌面 UI 未做截图视觉验收**，
   README 中的 UI 截图位暂用布局算法渲染图占位并明确标注，不伪造截图。
3. **Maven 在本沙箱不可用**（代理认证失败），Compose 依赖改用 curl 从
   Maven Central 直拉 jar（共 18 个）完成前端验证。
