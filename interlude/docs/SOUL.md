# 幕间 Interlude —— 灵魂一页纸

## 差异化命题（一句话）

**分支叙事的 linter**：独立游戏叙事设计师、互动小说作者、剧本杀作者写分支剧情时，
Twine 太简单（没有校验，分支一多就烂尾）、articy:draft 闭源又贵；
幕间是开源免费的"叙事代码审查员"——可视化分支编辑 + 叙事 DSL 双向同步，
像 linter 查代码一样查剧情：死路、不可达节点、变量未初始化、条件永假，
报错精确到行号。

## 技术含金量点

1. **叙事 DSL 解析器**：自研词法/语法解析，节点·分支·变量·条件一次表达，文本与可视化图双向同步。
2. **一致性校验引擎**：图可达性分析（死路/不可达）、变量数据流分析（未初始化使用）、条件可满足性检查（永假条件）。
3. **分支图层次化布局算法**：按叙事深度分层、减少边交叉，百节点依然可读。
4. **本地化管线**：叙事文本抽取 → 保留变量占位的回填，多语言版本不丢分支结构。

## 视觉概念

"剧本排练室"的质感：深墨底 + 暖纸黄的叙事文本 + 朱砂红的问题标记。
分支图不是冷冰冰的流程图——节点是"场景卡片"，问题节点像被导演用红笔圈出来。
字体：正文用衬线（剧本感），UI 标签用等宽（linter 感）。
去 AI 味：禁紫渐变、禁一切居中、禁三栏特性格、禁 emoji 图标。

## 命名理由：「幕间」

戏剧中幕与幕之间的间隙——演员换场、观众喘息的时间。
分支叙事的作者最需要的，正是这样一个"幕间"时刻：停下来，俯瞰全局，
看看哪条线走进了死胡同、哪个伏笔的变量断了线。
英文名 Interlude 同义。短、好记、有戏剧味，目标用户（叙事设计师/剧本杀作者）
一眼就有共鸣。
