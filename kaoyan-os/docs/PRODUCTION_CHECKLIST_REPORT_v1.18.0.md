# kaoyan-os v1.18.0 发版前 Definition of Done 对照报告

## 1. 背景

2026-10-27 深耕轮，轮换队列：上轮 botstalk OpenAgents 第 16 轮，本轮轮到 kaoyan-os。

核心交付：`apps/server/src/routes/stats.ts` 的 `GET /api/stats/heatmap` 的 `months` 参数由 `Number()` 改为正则 `/^-?\d+$/` 校验；非纯数字串（`1.0`、`0x2`、带空格、`+2`、空串）返回 `400`（错误体 `months 参数无效`）；范围 `1..6` 与缺省 `3` 不变；此前 `Number()` 口径下 `1.0` 与 `0x2` 会静默通过返回 `200`。
