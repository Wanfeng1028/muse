# 生产环境验收清单报告 v2.17.26

### 变更概述
本次版本变更针对 GET /api/transactions 接口新增了日期顺序校验逻辑。若传入的开始日期晚于结束日期，接口将明确返回 400 错误。此举填补了 v2.17.22 版本遗留的范围缺口，且未对其他接口、计算逻辑与分页产生任何影响。

### 验收证据
- **代码差异**：单个文件中的代码改动极为精简（约 3 行变更）。
- **单元测试**：新增 7 项针对性测试用例，连同现有相关日期校验测试，共计 16 项测试全部通过。
- **代码静态检查**：ruff check 与 ruff format 均无报错（clean）。
- **真实服务冒烟测试**：在 127.0.0.1:18291 端口启动 uvicorn 服务并使用隔离的数据库文件进行验证。测试证实颠倒日期区间返回 400 及明确中文提示，正常区间返回 200。冒烟测试完成后服务正常停止，端口已释放，测试数据库已清理删除。

### 已知限制
- 本轮变更未运行完整的测试套件（full test suite）。验证范围严格限定在新增测试用例以及相关的现有日期校验测试用例。

- **可观测性**：通过。针对参数错误返回了清晰的 400 状态码与明确的中文错误信息，方便调用方快速定位问题。
