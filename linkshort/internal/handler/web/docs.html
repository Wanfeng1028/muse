API 文档

短链 API

自托管短链服务的 HTTP 接口一览。

鉴权

管理 API 统一要求 API Key：请求头 X-API-Key 或查询参数 ?key=。

环境变量 LINKSHORT_ADMIN_KEY 为空时，本地开发免鉴权。

公开端点无需 Key：/、/docs、/metrics、/ui/*、/{slug} 的 GET/POST。

端点总览

方法 路径 鉴权 说明
GET/公开302 跳转到 /ui/
GET/docs公开本页：API 文档
GET/metrics公开Prometheus 指标（免限流）
GET/ui/*公开Web UI 静态页面
GET/api/health需要 API Key存活探针，进程活着即 200（免限流）
GET/api/readyz需要 API Key就绪探针，DB 连通才 200（免限流）
GET/api/meta需要 API Key服务元信息：短链前缀与开关状态
GET/api/backup/health需要 API Key备份健康：最近备份时间、完整性校验结果、过期判定；无备份/上次失败/过期时 status 为 degraded（HTTP 仍 200）
POST/api/links需要 API Key创建短链（自动/自定义短码，可设过期、限次、阅后即焚、密码）
POST/api/links/batch需要 API Key批量创建短链（最多 100 条；全部成功 201、部分成功 207、全部失败 400；逐项支持 password，密码只存 bcrypt 哈希）
GET/api/links需要 API Key链接列表，支持搜索、排序、分页、启用状态筛选（enabled=true/false，非法值 400）与阅后即焚筛选（burn=true/false，非法值 400）
GET/api/links/{id}需要 API Key单条短链详情
PATCH/api/links/{id}需要 API Key更新短链（标题、开关、过期、限次、密码）
DELETE/api/links/{id}需要 API Key删除短链（访问日志级联删除）
GET/api/links/{id}/qrcode.png需要 API Key短链二维码 PNG
GET/api/links/{id}/daily需要 API Key单条短链每日点击统计
GET/api/stats/overview需要 API Key统计总览：短链数、点击数
GET/api/stats/daily需要 API Key全站每日点击曲线
GET/api/stats/top-links需要 API Key点击最多的短链
GET/api/stats/top-referers需要 API Key点击来源 Referer 排行
POST/api/import需要 API KeyCSV 批量导入
GET/api/export.csv需要 API KeyCSV 导出
GET/{slug}公开短链跳转：正常 302；有密码时返回密码门页；已销毁/超限/过期返回 410
POST/{slug}公开密码解锁：密码正确 302 跳转，错误 401

限流

限流按 IP + API Key 双维度令牌桶。免限流端点：/metrics、/api/health、/api/readyz。
