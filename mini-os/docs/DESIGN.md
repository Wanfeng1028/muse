# mini-os 视觉设计注记 · 纸墨桌面

> 这份文档写给三个月后的自己。改样式之前先读一遍，别又手滑加个紫渐变。

---

## 1. 一句话主张

**纸墨桌面——暖纸为底、墨为字、赭石一点。**

像把宣纸铺在显示器上，桌面是一张纸，窗口是纸上的便签，强调色是唯一那枚朱砂印。

---

## 2. 色彩体系

### 2.1 浅色 · 日纸

| 用途 | 名称 | Hex |
| --- | --- | --- |
| 纸底 | paper | `#F6F1E7` |
| 次级纸（卡片/面板） | paper-2 | `#EFE8D8` |
| 墨字（主文字） | ink | `#26221B` |
| 次级字 | ink-2 | `#6E6555` |
| 发丝线（分隔/边框） | hairline | `#E0D6BE` |
| 强调赭石（主按钮 / 活动态 / 焦点环） | vermilion | `#B4552D` |
| 成功松绿 | pine | `#4E7A51` |
| 警告藤黄 | gamboge | `#C98A2E` |
| 危险绛红 | madder | `#A63A2E` |

- 焦点环：`outline: 2px solid #B4552D; outline-offset: 2px;`
- 主按钮底色 `#B4552D`，文字 `#F6F1E7`，hover 时底色 `#9C4524`（赭石压暗一档，不是加亮）。

### 2.2 深色 · 夜墨

| 用途 | 名称 | Hex |
| --- | --- | --- |
| 底 | night | `#171512` |
| 面（窗口/卡片） | night-2 | `#211D17` |
| 纸字 | paper-ink | `#EDE6D6` |
| 次级字 | paper-ink-2 | `#A39A86` |
| 线（暖灰） | night-line | `#35301F` |
| 强调琥珀（主按钮 / 活动态 / 焦点环） | amber | `#D8A24A` |

- 深色下终端、代码、路径都用同一个琥珀 `#D8A24A` 做强调，保证终端与 UI 视觉统一。
- 深色主按钮底色 `#D8A24A`，文字 `#171512`。

### 2.3 禁区（改稿时也别碰）

- **禁用紫渐变**：任何方向、任何浓度、任何"高级感"的紫。一旦出现，整页回炉。
- **禁用霓虹辉光**：不做 `box-shadow` 彩色光晕，不做 text-shadow 发光字。
- **禁用 Inter 一把梭**：中文环境下不使用 Inter 作为首选字体，也不做"英文 Inter + 中文 fallback"的混排。字体栈见第 3 节。

---

## 3. 字体

### 3.1 字体栈

```css
--font-ui: "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

- UI 字体：**中文优先**，Inter 不进第一位，也不出现在前三位。
- 等宽字体：终端、代码块、文件路径、快捷键提示都用 `--font-mono`。

### 3.2 字号阶梯

| 尺寸 | 用途 |
| --- | --- |
| 12px | 辅助信息（时间戳、状态文字、说明） |
| 13px | 正文（列表项、按钮、表单） |
| 14px | 标题（窗口标题、分区标题） |
| 20px | 数字时钟（任务栏 / 锁屏） |

- 行高统一 `1.6`。
- 字重只用 400 和 600 两档，不要 300 也不要 700 以上。

---

## 4. 间距与圆角

- **间距**：8pt 网格。所有 padding / margin / gap 取 `4 / 8 / 12 / 16 / 24 / 32`，不要出现 5、7、13、15 这种数。

| 元素 | 数值 |
| --- | --- |
| 窗口圆角 | 14px |
| 卡片圆角 | 10px |
| 按钮圆角 | 8px |
| 标题栏高 | 40px |
| 任务栏高 | 52px |

### 阴影（三层，不用彩色）

浅色模式：

```css
--shadow-window-light:
  0 1px 2px rgba(38, 34, 27, 0.06),
  0 4px 12px rgba(38, 34, 27, 0.08),
  0 12px 32px rgba(38, 34, 27, 0.10);
```

深色模式：

```css
--shadow-window-dark:
  0 1px 2px rgba(0, 0, 0, 0.40),
  0 4px 12px rgba(0, 0, 0, 0.50),
  0 12px 32px rgba(0, 0, 0, 0.60);
```

- 阴影只允许黑/墨色，不许用赭石、琥珀、绿、蓝做发光阴影。

---

## 5. 图标

- **统一用 Lucide 描边图标**，`stroke-width: 2`，`stroke-linecap: round`，`stroke-linejoin: round`。
- **不用 emoji 当图标**。文件夹就是文件夹，不是 📁。
- 桌面图标：**40px**，放在纸色圆角方底上，像一枚印章——底色 `#EFE8D8`，圆角 10px，图标颜色 `#26221B`；选中态底 `#B4552D`，图标反白。
- 标题栏 / 任务栏图标：**18px**，颜色跟随当前文字色（浅色用 `#26221B`，深色用 `#EDE6D6`）。

---

## 6. 壁纸（三张，纯 CSS 实现）

纸纹基础实现（三张壁纸共用）：

```css
/* 纸纹：极淡的斜向线条 + 大 radial 做旧 */
background-image:
  repeating-linear-gradient(
    45deg,
    rgba(255, 255, 255, 0.025) 0px,
    rgba(255, 255, 255, 0.025) 1px,
    transparent 1px,
    transparent 4px
  ),
  radial-gradient(ellipse at 30% 20%, rgba(255, 255, 255, 0.06), transparent 60%),
  radial-gradient(ellipse at 70% 80%, rgba(0, 0, 0, 0.10), transparent 55%);
```

暗角（三张共用）：

```css
background-image: radial-gradient(
  ellipse at center,
  transparent 55%,
  rgba(0, 0, 0, 0.28) 100%
);
```

### 6.1 ocean「黛蓝」

- 底色：`#12395B`
- 两团淡青 radial wash：
  - `radial-gradient(ellipse at 25% 30%, rgba(120, 190, 210, 0.22), transparent 60%)`
  - `radial-gradient(ellipse at 78% 72%, rgba(90, 160, 190, 0.18), transparent 55%)`
- 叠加纸纹 + 暗角。

### 6.2 sunset「赭暮」

- 底色：`#8A3B22`
- 暖黄 radial wash（夕阳位置偏右上）：
  - `radial-gradient(ellipse at 78% 22%, rgba(240, 190, 110, 0.35), transparent 60%)`
  - 补一团更淡的暖橘在左下：`radial-gradient(ellipse at 22% 80%, rgba(200, 130, 70, 0.18), transparent 55%)`
- 叠加纸纹 + 暗角。
- **不许出现紫色**。暖黄到赭石之间不要加任何偏紫的过渡。

### 6.3 forest「松绿」

- 底色：`#1E4032`
- 苔绿 radial wash：
  - `radial-gradient(ellipse at 30% 25%, rgba(130, 175, 120, 0.22), transparent 60%)`
  - `radial-gradient(ellipse at 75% 75%, rgba(90, 140, 100, 0.18), transparent 55%)`
- 叠加纸纹 + 暗角。

## 7. 动效

- **窗口打开**：160ms，`ease-out`，`scale 0.96 → 1` 同时上浮 8px（`translateY(8px) → 0`）。
- **窗口最小化**：140ms，下沉（`translateY(0) → 8px` + `opacity 1 → 0`）。
- **不许弹跳**（cubic-bezier 里别塞 overshoot），**不许旋转**（不做 3D flip、不做 spin 图标）。
- 交互反馈（hover / active）：120ms，只改颜色或背景，不做缩放。

---

## 8. 文案语气

- 大白话，短句，像跟同事说话。
- 按钮用动词：
  - ✅「新建文件夹」 ❌「创建」
  - ✅「删除这条」 ❌「执行删除操作」
  - ✅「保存」 ❌「确认提交」
- 空状态 = 一句人话 + 一个动作：
  - 「这里空空的，新建一个文件夹开始吧」
  - 「还没有笔记，写一条试试」
  - 「回收站是空的，挺好」
- 报错也别端着：
  - ✅「没连上网，检查一下 Wi-Fi」
  - ❌「网络请求失败，请稍后重试」

## 9. 与 hallmark 去 AI 味的对应关系

逐条对着 named tells 说明本设计怎么避开：

| Named tell | 本设计的处理 |
| --- | --- |
| 紫渐变 hero | 全局禁用紫色。浅色底是暖纸 `#F6F1E7`，强调色是赭石 `#B4552D`，没有一处渐变用于 hero。 |
| Inter 用到底 | UI 字体栈中文优先（PingFang SC / 冬青黑 / 微软雅黑），Inter 不进前三位；等宽场景用 JetBrains Mono。 |
| 渐变标题 | 标题只用纯色墨字 `#26221B`（深色 `#EDE6D6`），不做 `background-clip: text` 渐变。 |
| 一切居中 | 桌面、窗口、任务栏是明确的"左对齐 + 网格"布局；只有空状态和时钟是居中的，因为它们本来就该居中。 |
| 三栏特性格 | 桌面没有"三个并列特性卡片"这种结构。窗口是浮动层，任务栏是单行，没有 marketing 味的三栏。 |
| emoji 当图标 | 全部换成 Lucide 描边图标（stroke 2，round 端点）。 |
| "Unleash" 类文案 | 按钮用动词，空状态用大白话，报错说人话。全篇没有"释放潜能""赋能"这类词。 |
| Specimen 衬线大标题风 | 不用衬线大标题。标题字号最大 14px（数字时钟 20px），字重 600，靠纸底和留白撑气质，不靠字号撑。 |

另外两条自己加的规矩：

- 不用四字 polished 短语（"极致体验""赋能未来"这类），见到就删。
- 不用占位词糊弄色值，所有颜色都给 hex。

## 桌面小组件（v1.9.0）

位置：桌面右上角，宽 264px。两块上下叠放，今日日程在上，速记便签在下。
与桌面图标区左右分区，互不遮挡。

卡片：沿用窗口卡片语言，圆角 var(--radius)、1px 边框、柔和投影、
backdrop-filter 轻磨砂，不另起一套样式。

今日日程：标题行是"今日日程 + 日期"。列表项左圆勾选圈，空心为未完成，
实心赭石为完成。完成项标题加删除线并降透明度。时间用小字灰字放第二行。
删除按钮 hover 才出现（×），避免误触。底部输入行加赭石圆角加号按钮。

速记便签：textarea 无工具栏，行高 1.6。右上角小字提示，
输入中显示"输入中…"，保存成功显示"已保存 HH:MM:SS"，
保存失败显示"保存失败"，不弹窗打扰桌面。

空状态：一句人话，如"今天没有安排"。不加插画不加按钮。

深色主题：卡片跟随主题变量。CSS 变量必须带 fallback 值，
防止旧主题下变量缺失导致白底黑字断裂。

小屏（<900px）：小组件整组隐藏，桌面优先保图标区可用。
