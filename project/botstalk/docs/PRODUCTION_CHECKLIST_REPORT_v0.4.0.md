# BotsTalk v0.4.0「房间类型」发版对照报告

- 版本：v0.4.0
- 主题：房间类型（workroom / playroom）
- 范围：protocol 房间类型定义、gateway 三张新表与 12 个 REST 端点、房间感知路由、config 3 个新 env、Web 房间列表/徽标/设置
- 结论：**可发版**（限单机、可信内网场景）。公网 / 多租户场景需先补鉴权与可观测性。

说明：每条按 [通过 / 未通过 / 部分通过 / 不适用] 给出结论，并附一句理由。未通过项均给出排期或声明为已知限制。

## 七、已知限制与技术债

1. **WS game_action / game_state 帧未实现**：小游戏暂走 HTTP API。排期 v0.4.1。
2. **HTTP 无鉴权**：requester 字段自报身份，仅适合可信内网部署；公网暴露必须前置鉴权网关。**已知限制**。
3. **成员上限检查不全**：只在 POST /api/rooms/:room/members 检查，WS 直连加入未检查。排期 v0.4.1。
4. **OPERATIONS.md 未补 3 个新 env 变量**。排期 v0.4.1。
5. **结构化日志、指标、告警、限流**：既有缺口，随 v0.4.1 统一补。

---

## 八、发版结论

- v0.4.0 可在**单机、可信内网**场景发版。
- 公网 / 多租户场景：需先补 HTTP 鉴权与可观测性（日志 / 指标 / 告警），再评估上线。
- 本轮未通过项已全部给出排期（v0.4.1）或声明为已知限制，无隐瞒项。
