# 存疑评测对复核（EVAL_V09 六、3）

本文针对 `docs/EVAL_V09.md` 第六章第 3 节列出的 3 个存疑评测对，逐个分析命中原因，并给出处置建议。

分析所依据的检索原理：`parseNaturalQuery` 先做 filler 词剥离，把疑问词、语气词、通用动词等剔除，保留实词；随后用实词做 AND/OR 召回，再排序取 top-k。因此一个评测对稳不稳，关键看**剥离后剩下的实词是否唯一指向预期文档**，以及**语料里是否存在同样含这些实词、但语义不同的干扰文档**。

> 说明：下文涉及具体语料条数、词频、是否含干扰文档的判断，凡未在事实清单中给出确证的，一律标注"需实测验证"，不做编造。

---

## 1. v07-007「智能手机」→ html_01_smartphone.html

**质疑**：预期是否过于宽松？标题含"智能手机"的文档有多篇。

**检索原理层面为什么可能命中**：
- query 只有「智能手机」一个实词，`parseNaturalQuery` 剥离后大概率原样保留（它不是疑问词/语气词）。
- 召回阶段只有这一个实词，AND 与 OR 退化成同一个条件：语料中凡命中「智能手机」的文档都会被召回。
- 排序阶段若没有更强的区分信号（如标题精确匹配加权、BM25 词频/长度归一），则命中哪一篇很大程度取决于文档长度归一化和并列时的排序稳定性，而不是语义相关度。

**判断**：**偏"运气"**。
- 若语料中确有多篇标题或正文含「智能手机」，则单实词 query 无法把它们区分开，命中 `html_01_smartphone.html` 更像是排序副作用，而非"预期唯一正确"。
- 换种问法（例如「智能手机有哪些功能」「智能手机怎么选」）会引入新实词，命中结果可能改变，说明该评测对**不稳健**。

**结论**：**降级为"弱评测对"（只要求 top-3）**。
理由：单实词 query 本身区分度不足，用 top-1 断言过于苛刻且不可靠；改成要求预期文档进 top-3 更合理。
补充：若实测发现语料中"含智能手机"的文档其实只有这一篇，则可**保留**为正常评测对——这一点**需实测验证**（统计语料中含「智能手机」的文档数）。

## 2. v07-t1-01「申请信用卡需要什么条件」→ qa_01_creditcard.md

**质疑**：query 含"申请/需要/什么/条件"多个 filler 词，预期是否靠运气命中？

**检索原理层面为什么可能命中**：
- `parseNaturalQuery` 会剥离「什么」这类疑问词，以及「需要」这类通用动词/助词；「申请」「条件」更可能作为实词保留（它们对语义有贡献）。
- 剥离后剩下的实词大概率为「申请」「信用卡」「条件」（「信用卡」是核心名词，必然保留）。
- 召回时这三个词做 AND/OR：只要 `qa_01_creditcard.md` 同时覆盖「信用卡」和「条件/申请」相关表述，就能被稳定召回。
- 这里的关键是**「信用卡」这个实词区分度很高**——它不是泛词，语料中大概率只集中在信用卡相关文档上。因此即使 filler 剥离后只剩少数实词，核心名词仍在，召回方向基本锁定。

**判断**：**偏"稳健"**。
- 命中主要靠核心名词「信用卡」的强区分度，而不是靠"申请/需要/什么/条件"这些 filler 的偶然组合。
- 换种问法（例如「办信用卡要满足哪些要求」「信用卡申请资格」）只要仍含「信用卡」，大概率仍命中 `qa_01_creditcard.md`，说明稳健。

**结论**：**保留**。
说明：保留的前提是「信用卡」在语料中的区分度确实高、`qa_01_creditcard.md` 确实覆盖"申请条件"语义——这两点**需实测验证**（确认无其他同样讲信用卡申请条件的文档造成并列）。
若实测发现存在多篇信用卡申请条件文档导致 top-1 不稳定，再考虑降级为弱评测对。

## 3. v08-qa-03「你们的退货政策是什么样的」→ qa_03_return.md

**质疑**："你们的/什么样"被剥离后只剩"退货/政策"，是否有干扰文档也含这两个词？

**检索原理层面为什么可能命中**：
- `parseNaturalQuery` 会剥离「你们的」（人称/所属语气词）和「什么样的」（疑问结构），剩下实词「退货」「政策」。
- 召回时用「退货」「政策」做 AND/OR。若语料中只有 `qa_03_return.md` 同时含这两个词，则命中稳定；若还有别的文档也讲"退货政策"（如某篇订单/售后总览文档顺带提到退货政策），则可能产生并列或竞争。
- 由于只剩两个实词、且都是领域实词（非泛词），召回集合本身较小，区分度取决于**语料里到底有几篇含"退货+政策"**。

**判断**：**取决于语料，倾向"稳健"，但需实测确认无干扰**。
- 如果语料中"退货政策"主题文档唯一，则剥离后的实词仍精确指向 `qa_03_return.md`，命中稳健；换种问法（「退货规则是什么」「怎么退货」）只要保留「退货」，大概率仍命中。
- 如果存在含"退货""政策"的干扰文档，则命中可能靠排序运气，属于不稳健。

**结论**：**保留，但需实测验证干扰情况**。
- 实测项：统计语料中同时含「退货」与「政策」的文档数量。
  - 若仅 1 篇 → 保留。
  - 若 ≥ 2 篇 → 降级为"弱评测对"（只要求 top-3），或改写 query 增加区分实词（如「退货政策 几天内」）后保留。
