# 发版对照报告：serve 检索接口 limit 非法返回 400（docseek）

文件：`docseek/docs/PRODUCTION_CHECKLIST_REPORT_serve_limit_400.md`

## 改动摘要

- `src/service.cpp` 两处 limit 解析改为整串合法判定：缺参、空串仍取默认值（搜索 20、定位 5）；非数字、小于 1、大于 100 返回 400（limit 参数无效）。
- 未改动范围与默认值；未改动 q 缺失返回 400 的行为；未改动 title_boost / phrase_boost。
- Web UI 只发送合法整数，不受影响。
