## 改动要点

1. 根因（v07-024）：keywords=[安装,步骤] 在词袋打分下，干扰段落 0.845 压制主题段落 0.688；而「安装步骤」连续串在全语料中只出现在主题文档。文档级已有 phraseBoost，段落级缺失该加成。
2. 新增具名常量 `kCompoundPhraseBonus=0.25`（取值依据：足以覆盖该用例 0.157 的分差且不改变其余已通过用例的相对次序，见下）。
3. 新增 queryCompound 计算规则：关键词数量 >= 2、拼接结果非空、且拼接结果不同于引号短语时，视为复合短语。
4. 测试先红后绿：先新增失败用例，再实现加成使其通过。
5. 证伪记录：文档级融合方案（0.3×min-max 归一化）在真实评测上 55/56 未动，根因是归一化稀释，已还原。
