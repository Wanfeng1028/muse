# API 限流说明

**问：接口调用返回 429 是什么原因？**

答：这是触发了限流，按下面排查。

第一步，确认套餐额度：免费版每分钟 60 次、每天 1000 次；专业版每分钟 600 次、每天 10 万次。

第二步，查看响应头：X-RateLimit-Limit 是总额度，X-RateLimit-Remaining 是剩余，X-RateLimit-Reset 是重置时间戳。

第三步，定位突发：检查是否有循环里未加退避的请求，或前端重复提交。

第四步，加退避重试：遇到 429 后按指数退避，首次等 1 秒，之后 2、4、8 秒，最多重试 3 次。

第五步，申请提额：专业版可在控制台提交提额工单，说明业务场景与峰值 QPS，审核 2 个工作日。

第六步，兜底：批量任务放到凌晨低峰跑，或改用批量接口减少调用次数。
