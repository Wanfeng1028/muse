# 中英混排：BM25算法调参

"BM25算法调参"是典型的中英混排串。BM25 是英文缩写，算法和调参是中文词。切分时英文按空格与大小写边界切，中文按词典切，得到 BM25／算法／调参三个 token。

问题出在大小写上：用户可能输入 bm25、BM25、Bm25，索引必须统一转小写。另一类问题是英文与数字粘连，比如"BM25k1"要切成 BM25 和 k1，不能整体当一个词。

BM25 的两个参数是 k1 和 b，k1 通常取 1.2 到 2.0，b 通常取 0.75。中文短文档建议 k1=1.5、b=0.6，长文档 b 可提到 0.8。调参时用网格搜索在验证集上算 NDCG@10。

评测要点：文档里写"BM25 参数 k1 取 1.5"，查询用"bm25 调参"小写加中文，检查大小写归一化与中英混排切分是否生效，能否准确命中该文档而不是泛泛命中所有含"算法"的文档。
