# 多肉换盆：什么时候换、怎么换不伤根

多肉养一两年，土会板结，根系也长满盆。这时候就要换盆，但时机和方法不对，反而会伤到多肉。

## 换盆时机

春秋两季最合适，温度在十五到二十五度之间。夏天太热，冬天太冷，换盆后服盆慢，容易死。另外，刚买回来的多肉别急着换，先养两周适应环境。

## 换盆步骤

1. 提前三天断水，让土干燥，方便脱盆。
2. 把多肉倒扣，轻拍盆壁，连土一起取出来。
3. 抖掉旧土，剪掉干枯、发黑的根，保留健康白根。
4. 根部泡多菌灵十分钟，晾干半天。
5. 新盆底部垫陶粒，填新土，把多肉种进去。

## 换盆后养护

换完盆别马上浇水，放散光处缓五天，再沿盆边少量给水。两周后逐渐恢复正常光照。我去年秋天换盆的十二卷，按这个流程，一棵都没死。

- 花盆：比原来的大一号就行，别贪大。
- 旧土：直接扔掉，里面有虫卵和病菌。
- 修根：别修太狠，留三分之二。
