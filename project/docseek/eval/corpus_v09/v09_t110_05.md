# 用 Docker 在 NAS 上跑 qBittorrent 下载电影

群晖的套件中心里也有 Download Station，但功能比较弱，PT 站支持不好。我习惯用 qBittorrent，功能全，界面也顺手。这篇写一下怎么用 Docker 装。

## 准备工作

先在套件中心安装 Docker 套件（DSM 7 叫 Container Manager）。然后在 File Station 里建几个文件夹：`/docker/qbittorrent/config` 放配置，`/downloads` 放下载文件。注意权限，Docker 容器默认用 root 跑，但最好指定 PUID 和 PGID 为你的群晖用户，免得文件权限乱掉。

## 拉取镜像

打开 Container Manager，在注册表里搜 `linuxserver/qbittorrent`，下载 latest 标签。这个镜像维护得比较勤，更新及时。

## 配置容器

创建容器时，映射两个端口：8080 是 Web UI，6881 是 BT 端口。文件夹映射：把刚才建的 config 和 downloads 挂进去。环境变量加上 PUID=1026、PGID=100、TZ=Asia/Shanghai。网络模式选 bridge 就行，不需要 host。

## 设置 qBittorrent

浏览器打开 `http://NAS的IP:8080`，默认账号 admin，密码在容器日志里找，第一次启动会随机生成。进去后先把语言改成中文，然后在设置里把下载路径改成 `/downloads`。连接里把监听端口改成 6881，随机端口也行，但要在路由器里做端口映射，不然外网连不上做种。

## PT 站注意事项

如果玩 PT，一定要限制上传速度，别把家里上传带宽跑满，否则网页都打不开。qBittorrent 设置里有全局速度限制。另外记得开启 DHT 和 PeX 会影响 PT 站做种统计，PT 站一般要求关闭。

## 常见问题

- 下载没速度：检查端口映射，或者换个种子试试。
- Web UI 打不开：确认容器运行状态，看端口有没有冲突。
- 硬盘一直响：把做种数量限制一下，别同时做种几百个。
