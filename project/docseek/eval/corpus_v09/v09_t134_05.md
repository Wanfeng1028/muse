# 显示器接口全梳理：HDMI、DP、USB-C到底插哪个

新显示器到手，背面一排接口经常让人发懵。我第一台2K屏只有HDMI和DP，当时用笔记本的HDMI口接，结果只能跑2K 60Hz，想上144Hz死活不行。后来查说明书才知道，HDMI 2.0带宽有限，2K 144Hz得用DP 1.4或者HDMI 2.1。

## 先看带宽，再看版本号

HDMI 2.0大概能跑2K 144Hz 8bit，但开10bit或者HDR就不够。DP 1.4带宽更高，2K 165Hz 10bit没问题，4K 120Hz也能应付。HDMI 2.1和DP 2.0是新规格，4K高刷首选。买线时注意，很多便宜线只标“支持4K”，但没写刷新率，接上高刷屏只能跑60Hz，白瞎了显示器。

## USB-C一线连的隐藏条件

USB-C接笔记本很方便，一根线传画面加充电。但要注意两个参数：一是DP Alt Mode，二是供电功率。有些轻薄本的C口只支持视频输出，供电只有15W，接上显示器电量还是往下掉。要一线连，笔记本C口得支持PD充电，显示器这边供电至少65W，最好90W。另外显示器上的USB Hub速度也分USB 2.0和3.0，接移动硬盘前看清楚。

## 老设备怎么办

主机只有VGA或者DVI，可以买转接头，但转出来最高往往只有1080p 60Hz，而且模拟信号画质会糊。如果显卡有DP口，优先用DP转HDMI，比VGA转接靠谱得多。转接头别买太便宜的，我买过九块九的，用了一个月就闪屏。

- HDMI 2.0：2K 144Hz够用，10bit或HDR吃紧
- DP 1.4：2K高刷和4K 120Hz更稳
- USB-C：确认DP Alt Mode和PD供电功率
- 转接头：VGA转接上限低，优先DP转HDMI
