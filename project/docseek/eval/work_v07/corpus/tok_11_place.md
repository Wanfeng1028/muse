# 地名：杭州西湖断桥

"杭州西湖断桥"是地名套地名。杭州是市，西湖是景区，断桥是景点，三者是包含关系。用户搜"杭州"要能命中所有杭州相关文档，搜"西湖"要能命中西湖相关，搜"断桥"要能命中断桥相关。

切分时"杭州""西湖""断桥"三个词都要切出来，同时保留整串"杭州西湖断桥"作为长词。这叫层级地名索引。

类似结构还有"北京市海淀区中关村""广东省深圳市南山区""江苏省南京市玄武区"。每一级都要单独入索引，查询任一级都能召回。

易错点是同名异地：全国有多个"西湖"，杭州西湖、惠州西湖、颍州西湖。单纯搜"西湖"应全部召回，若用户搜"杭州西湖"则杭州的排第一。评测时构造三篇文档分别写三个西湖，查询"西湖"召回三篇，查询"杭州西湖"时杭州那篇分数最高。
