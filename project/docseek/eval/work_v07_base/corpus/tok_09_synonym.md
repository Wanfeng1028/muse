# 近义词：电脑、计算机、PC

"电脑""计算机""PC"三个词指的是同一类东西，但字面完全不同。用户搜"电脑维修"时，标题写"计算机维修"的文档必须也能命中，否则召回率大跌。

做法是维护同义词词典，把这三个词归到同一个 synonym group，索引时给每个 token 打上组 ID，查询时组内扩展。注意不要过度扩展："电脑"和"电视机"不是同义词，不能乱并。

另一组常见近义：出租车／的士／网约车，番茄／西红柿，土豆／马铃薯，自行车／单车／脚踏车。近义扩展要控制范围，一般只做 2 到 3 个词的组，组太大反而引入噪声。

评测构造三篇文档，分别只写"电脑""计算机""PC"，查询用其中任意一个，三篇都要被召回且分数接近。再构造一篇写"电视机"的干扰文档，查询"电脑"时它不应被召回。
