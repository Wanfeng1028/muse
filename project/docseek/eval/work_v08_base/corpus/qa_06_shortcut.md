# 快捷键常见问题

## Q1：Windows 常用快捷键有哪些？

Ctrl+C 复制，Ctrl+V 粘贴，Ctrl+X 剪切，Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+A 全选，Ctrl+S 保存，Ctrl+F 查找。Win+D 回桌面，Win+E 打开资源管理器，Win+L 锁屏，Win+Tab 任务视图。

## Q2：macOS 常用快捷键？

Cmd+C/V/X/Z/A/S/F 与 Windows 对应。Cmd+Q 退出，Cmd+W 关窗，Cmd+Tab 切换应用，Cmd+空格 聚焦搜索，Cmd+Shift+4 区域截图，Cmd+Option+Esc 强制退出。

## Q3：浏览器里有哪些好用的？

Ctrl+T 新标签，Ctrl+W 关标签，Ctrl+Shift+T 恢复刚关的标签，Ctrl+Shift+N 无痕窗口，F12 开发者工具，Ctrl+0 恢复 100% 缩放。

## Q4：Office 里有哪些？

Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+U 下划线，Alt+= 插入公式，F4 重复上一步操作，Ctrl+Enter 分页，Ctrl+Shift+方向键 选中到段落边缘。

## Q5：终端里的？

Ctrl+C 中断，Ctrl+D 退出，Ctrl+L 清屏，Ctrl+R 反向搜索历史，Tab 补全，!! 重复上一条命令，Ctrl+A/E 跳到行首行尾。

## Q6：能自定义吗？

能。Windows 用 AutoHotkey 或 PowerToys Keyboard Manager。macOS 用系统设置-键盘-快捷键，或 Karabiner。Linux 用桌面环境的快捷键设置或 xmodmap。

## Q7：记不住怎么办？

先挑 10 个高频的，贴在显示器边，用两周形成肌肉记忆，再换下一批。别一次背 50 个。
