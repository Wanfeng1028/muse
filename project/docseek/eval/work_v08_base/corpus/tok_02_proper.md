# 专有名词"文溯DocSeek"的切分

"文溯DocSeek"是一个中英混合的专有名词，如果按字切分，会变成"文""溯""Doc""Seek"四个碎片，查询"文溯"时反而命中不到完整词。

正确的处理方式是把"文溯DocSeek"整体作为一个词条入词典，同时建立别名索引：文溯、DocSeek、文溯DocSeek、docseek（小写）四种写法都指向同一个 doc_id。

用户搜"文溯"能命中，搜"DocSeek"能命中，搜"docseek"小写也能命中，搜"文溯 DocSeek"中间带空格还能命中。这叫同义词归并加大小写归一化。

反例是某检索引擎把"文溯"切成"文"和"溯"，用户搜"文溯"时因为"文"字太常见，排在几百条"文档""文章"之后，专有名词检索体验极差。评测时要专门构造这组查询验证召回位置。
