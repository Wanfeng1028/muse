# 游泳前热身和下水后的适应流程

我以前下水就游，结果小腿抽过两次筋。后来跟泳池的救生员聊，才知道热身不是随便甩甩胳膊。

## 下水前五分钟做什么

- 转肩：前后各绕十圈，把肩关节打开
- 转腰：双手叉腰，左右各转十次
- 压腿：弓步压大腿前侧，每边二十秒
- 活动脚踝：脚尖画圈，左右各十次

这些动作不费力，但能让肌肉提前进入状态。天冷的时候我会多加热身时间，泳池水温低于二十六度时尤其要注意。

## 下水后的适应

不要一下水就猛游。先在水里走两趟，让身体适应水温；再扶池边做几次深呼吸和吐泡泡；然后慢游五十米，让心率慢慢上来。我一般用一百米慢游当热身，之后再开始练动作或计时。

## 抽筋了怎么办

小腿抽筋时别慌，先吸一口气，仰面漂起来，用手抓住脚尖往身体方向拉，同时把膝盖伸直。缓解后慢慢靠边，上岸休息。如果反复抽筋，多半是热身不够或者前一天没休息好，别硬撑。
