# 换声区：怎么平稳过渡

换声区是美声学习的一道坎。从胸声往头声走的时候，很多人会突然破音，或者声音变虚。我当初练《我亲爱的》时，一到高音就卡住，后来专门花了一个月磨换声区。

## 找到自己的换声点

一般来说，男声换声点在小字一组的 e 到升 f 之间，女声在小字二组的 c 到 d 之间。但这个因人而异。用半音阶慢慢往上唱“a”，找到那个声音开始变吃力、音色开始变暗的地方，那就是你的换声点。

## 用“u”母音过渡

“u”母音最容易掩盖换声痕迹。在换声点附近唱“u”，嘴唇收圆，喉头保持低位，声音像从头顶后方出去。练的时候不要用力，用中弱音量。每天从换声点下方三个半音开始，往上滑到换声点上方三个半音，再滑下来。

## 混声不是真假声混合

很多人以为混声就是真假声各一半，其实不是。混声是共鸣比例的调整：换声点以下胸腔多，换声点以上头腔多，中间是渐变的。不要刻意去“混”，而是让气息和共鸣自然过渡。

## 练习建议

- 每天用“u”母音练换声区十分钟。
- 录下自己的声音，回听有没有突然变暗或变虚。
- 不要强行唱太高的音，换声区没解决，高音只会更糟。

换声区练好了，音域会拓宽，音色也会更统一。这是个慢活，急不得。
