# 宫保鸡丁的糊辣荔枝味，糖醋比例怎么定

宫保鸡丁的味型叫糊辣荔枝味，入口先酸后甜，回味带麻。糖醋比例是核心，我试过几个版本，最稳的是保宁醋15克、白糖12克、生抽10克、老抽3克、水淀粉8克、清水20克。醋比糖多，这是荔枝味和糖醋味的区别。

## 鸡丁的处理

鸡腿肉去骨切1.5厘米丁，比鸡胸嫩。用盐2克、料酒5克、水淀粉10克抓匀，最后封5克油。腌15分钟就够，久了肉质发死。

## 炒制顺序

1. 锅烧热，下干辣椒段和花椒，小火焙到辣椒变棕红
2. 下鸡丁，中火滑散到表面变白
3. 下葱段、姜片、蒜片，炒出香味
4. 倒碗汁，大火翻匀，收汁亮油
5. 最后下油酥花生米，翻两下出锅

花生米要最后放，早了会回软。干辣椒别炒黑，黑了整锅发苦。碗汁里的水淀粉静置会沉底，倒之前再搅一次。
