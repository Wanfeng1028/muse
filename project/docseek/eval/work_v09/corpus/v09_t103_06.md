# Python字典操作与遍历技巧

字典是键值对的集合，用花括号定义，比如`{"name": "张三", "age": 20}`。键必须是不可变类型，字符串和数字最常用。

## 增删改查

- 新增或修改：`d["key"] = value`，键存在就改，不存在就加
- 删除：`del d["key"]`或`d.pop("key")`
- 查询：`d.get("key")`比`d["key"]`安全，键不存在时返回`None`而不报错

## 遍历方式

遍历字典有三种常见写法：

1. `for key in d`只拿键
2. `for key, value in d.items()`同时拿键和值，最常用
3. `for value in d.values()`只拿值

如果要在遍历时修改字典，最好先复制一份，否则可能报`RuntimeError`。另外字典在Python 3.7以后保持插入顺序，所以遍历结果和插入顺序一致，这点比早期版本方便很多。
