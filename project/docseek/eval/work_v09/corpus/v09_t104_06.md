# DOM 操作：让页面跟着你的代码变

浏览器把 HTML 解析成一棵节点树，这棵树就是 DOM。JavaScript 通过操作 DOM 来改文字、换样式、加元素，页面因此变得可交互。

## 找到元素

最常用的是 document.querySelector，它接收 CSS 选择器，返回第一个匹配的元素。想选多个用 querySelectorAll，拿到的是一个类似数组的列表，要用 forEach 遍历。给元素加个 id 或 class，查找会方便很多。

## 改内容和改样式

- 改文字用 element.textContent = '新内容'，它只处理纯文本，安全。
- 改 HTML 结构用 innerHTML，能插入标签，但用户输入的内容别直接塞进去，有注入风险。
- 改样式用 element.style.color = 'red'，或者切换 class 更推荐。

## 加事件监听

想让按钮有反应，用 addEventListener 绑定 click 事件。回调函数里写你要做的事。比如：button.addEventListener('click', () => { title.textContent = '被点了'; });

调试时善用 console.log 把元素打印出来，确认拿到的是不是 null。拿不到元素，多半是脚本跑在元素生成之前，把 script 放到 body 末尾就好了。
