# 蓝牙音响TWS串联：双台组立体声怎么弄

买两台一样的蓝牙音响，串起来做立体声，声场会宽很多。但操作有几个坑。

## 前提条件

两台必须是同品牌同型号，固件版本最好一致。不同型号基本串不上，别浪费钱。另外，串联后手机只连其中一台，另一台靠无线同步。

## 串联步骤

1. 两台都开机，确认没连任何手机。
2. 同时长按两台机的蓝牙键，直到指示灯快闪。
3. 等待10到20秒，听到提示音，主机会慢闪。
4. 手机搜索主机名字，连接即可。

## 左右声道怎么分

串联成功后，通常先按蓝牙键的那台是左声道。如果反了，同时按音量加和减切换。有些品牌在App里能直接调。

## 常见问题

- 串联失败：先重置两台，再重来。
- 声音不同步：距离拉近，别超过3米。
- 只有一台响：检查是否误连了别的设备。
- 延迟变大：看视频时切回单台，串联会加20到30ms延迟。

## 值不值得

两台五百的音响串联，声场比一台一千的宽，但低频下潜和解析还是不如单台贵的。适合已经有一台，想再买一台组队的。从零开始，不如直接买一台更好的。
