# 半包、全包、清包，到底怎么选

第一次装修的人最容易在承包方式上纠结。我三种都了解过，说说区别和适合的人群。

## 清包：所有材料自己买

施工队只出人工，水泥、沙子、电线、水管、瓷砖全部你自己采购。优点是材料可控、总价可能最低；缺点是你要花大量时间跑建材市场，而且工人会抱怨材料不到位耽误工期。适合时间充裕、懂行的人。

## 半包：主材自己买，辅料施工方出

这是目前最多人选的。施工方负责水泥、沙子、腻子、电线、水管这些辅料和人工，你负责瓷砖、地板、洁具、橱柜、门、灯具这些主材。既能控制大头开支，又不用天天盯辅料。

## 全包：拎包入住式

装修公司包工包料，你只管付钱和验收。省心，但报价里水分大，材料品牌容易被替换。选全包一定要在合同里写清楚每个材料的品牌和型号，验收时逐项核对。

- 不管选哪种，报价单要逐项看清楚
- 增项超过合同总价5%要重新签字确认
- 别信口头承诺，全部写进合同

没有最好的方式，只有最适合你时间和预算的方式。
