# Python异常处理与try语句

程序运行中难免出错，比如除以零、文件不存在、类型不对。Python用异常机制处理这些情况，而不是让程序直接崩溃。

## try与except

基本结构是`try`块放可能出错的代码，`except`块捕获异常并处理：

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为零")
```

可以写多个`except`分别处理不同异常，也可以用一个`except`捕获所有异常，但那样会掩盖问题，不推荐。

## finally与else

- `finally`块无论是否出错都会执行，常用来释放资源
- `else`块在try没有出错时执行，容易和finally混淆

抛出异常用`raise`，比如参数不合法时主动`raise ValueError("参数不能为负")`。自定义异常可以继承`Exception`类，写一个空类体就行。捕获异常时尽量具体，不要一上来就写`except Exception`，那样调试时很难定位。
