# JavaScript 变量和函数：前端入门的第二道坎

学完 HTML 和 CSS，页面能看但不会动。想让按钮点击有反应，就得请出 JavaScript。入门阶段先把变量和函数这两块地基打牢。

## 用 let 和 const 声明变量

以前用 var，现在更推荐 let 和 const。let 声明的变量可以重新赋值，const 声明的不能改，适合存不会变的值。写代码时优先用 const，确实需要改再换成 let，能少踩很多作用域的坑。变量名用驼峰，比如 userName、totalPrice。

## 函数就是打包一段逻辑

函数把一段代码装进盒子，起个名字，需要时调用。写法有两种：函数声明和箭头函数。

- 函数声明：function greet(name) { return '你好 ' + name; }
- 箭头函数：const greet = (name) => '你好 ' + name;

箭头函数更短，但没有自己的 this，初学阶段先会用参数和返回值就行。调用时写 greet('小明')，括号里的值传给参数 name。

## 常见错误

忘了写 return，函数默认返回 undefined。调用时函数名后面忘了加括号，拿到的是函数本身而不是结果。控制台报 is not a function，先检查这两点。
