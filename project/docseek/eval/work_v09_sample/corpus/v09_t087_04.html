博客被搜索引擎收录太慢？我做了这几件事

新博客上线一个月，site 命令查收录，结果只有首页。文章写了不少，但搜索引擎好像根本不知道它们存在。折腾了一阵，总算把收录速度提上来了，记录一下做过的事。

提交 sitemap

Hugo 默认会生成 sitemap.xml，但很多人忘了去搜索引擎后台提交。我在 Google Search Console 和必应站长工具里都提交了 sitemap 地址，第二天就有文章开始被收录。

主动推送链接

百度的普通收录速度慢，我用了它的 API 推送接口，每次发布新文章就自动推一条 URL 过去。写了个小脚本挂在构建流程后面，省得每次手动提交。

  • sitemap 提交给 Google 和必应
  • 百度用 API 主动推送
  • 在文章里互相加内链
  • 把博客地址放到 GitHub 主页和社交资料里

内链和外链

我发现一个现象：被其他网站链接过的文章，收录明显更快。所以我在每篇文章末尾加了几篇相关文章的链接，形成内链网络。同时在一些技术社区回答问题的时候，偶尔贴一下自己博客的相关文章地址。

耐心等，别频繁改

一开始我每天改标题、改描述，结果收录更慢了。后来查资料才知道，频繁改动会让搜索引擎重新评估页面。定稿之后就别乱动，给它两三周时间。
