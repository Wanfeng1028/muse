# 从零开始写第一篇博客：给新手的建议

经常有人在群里问，想写博客但不知道从哪下手。我写这篇不是教程，就是说说我当初怎么迈出第一步的。

## 先选一个最简单的工具

新手最大的误区是一上来就折腾博客框架。我的建议是先用最简单的：如果只是想写，可以先在 GitHub 上开一个仓库，用 README 写；或者用现成的平台，注册就能写。等你写到二十篇，自然知道自己需要什么。

## 写什么

不用想太宏大，就写你最近解决的问题。比如你花了一下午搞定的一个报错，把过程记下来，对别人就是有用的。我最早的文章就是记录怎么在旧笔记本上装 Linux，现在看来很粗糙，但当时确实帮到了几个人。

## 第一篇不用完美

我的第一篇文章只有三百字，排版也乱。但那又怎样？发出去就是胜利。你可以在后面的文章里越写越好，但如果你一直在改第一篇，就永远发不出第二篇。

## 几个具体建议

- 标题写清楚，别用“随笔”这种模糊的词
- 段落短一点，手机上读起来不累
- 代码用代码块，别直接贴在正文里
- 发布前自己读一遍，改掉明显的错别字

## 坚持比技巧重要

写了半年之后我发现，写得好的文章往往是那些我真正动手做过的事。技巧可以慢慢学，但如果不开始写，什么都不会发生。
