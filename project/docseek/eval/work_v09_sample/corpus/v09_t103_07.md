# Python文件读写基础操作

用Python处理文件，核心是`open()`函数。它返回一个文件对象，用完必须关闭，否则可能丢失数据。

## 打开与关闭

传统写法是`f = open("data.txt", "r")`，操作完调用`f.close()`。但更推荐用`with`语句：

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
```

`with`块结束会自动关闭文件，不用担心忘记。`encoding`参数建议显式写成`utf-8`，不然在Windows上读中文可能乱码。

## 读写模式

- `"r"`只读，文件不存在会报错
- `"w"`只写，会清空原内容
- `"a"`追加，在文件末尾添加
- `"r+"`可读可写，指针在开头

读文件可以用`read()`一次读完，`readline()`读一行，或者`readlines()`读所有行返回列表。写文件用`write()`，注意它不会自动加换行符，需要自己写`\n`。
