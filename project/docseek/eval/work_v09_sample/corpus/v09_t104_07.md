# 用浏览器开发者工具排查前端问题

写前端离不开浏览器自带的开发者工具。按 F12 或者右键选“检查”就能打开。新手最该先熟悉三个面板：Elements、Console、Network。

## Elements 面板看结构

这里显示的是浏览器解析后的 DOM，不一定和你写的 HTML 源码完全一样。可以点开节点看它的样式，右侧 Styles 区会列出所有生效的 CSS 规则，被划掉的是没生效的。想临时试样式，直接在右侧改数值，页面会立刻变化，刷新就还原。

## Console 面板看报错

JavaScript 报错会红字显示在这里，点开能看文件和行号。常见的错误有：未定义变量、选择器返回 null、括号不匹配。也可以在 Console 里直接敲代码测试，比如输入 document.title 回车，就能看到当前页面标题。

## Network 面板看请求

- 刷新页面，这里会列出所有加载的资源：HTML、CSS、图片、接口。
- 状态码 404 表示文件没找到，500 表示服务器出错。
- 点开某个请求看 Headers 和 Response，能确认参数和返回数据。

排查顺序建议：先看 Console 有没有报错，再看 Network 有没有资源加载失败，最后回 Elements 检查结构和样式。
