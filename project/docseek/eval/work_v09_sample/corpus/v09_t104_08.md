# 前端学习路线：三个月能做出什么东西

很多人问前端要学多久，这个问题没有标准答案，但可以按产出倒推。下面是一条常见的三个月路线，每周投入十小时左右。

## 第一个月：静态页面

先用两周把 HTML 常用标签和 CSS 基础过一遍，能照着设计图写出一个静态的个人主页。再用两周学盒模型、Flex 布局和响应式，让页面在手机和电脑上都能看。这个阶段的产出是两到三个静态页面。

## 第二个月：加交互

- 学 JavaScript 基础：变量、函数、数组、对象、循环。
- 学 DOM 操作和事件，做出待办清单、计算器这类小工具。
- 学会用开发者工具调试，能自己看懂报错。

## 第三个月：做一个完整项目

把前面学的串起来，做一个带搜索、筛选、分页的小应用，数据可以先写死在文件里，后面再换成接口。做完部署到静态托管平台，把链接放进简历。

## 几个提醒

不要等学完再做项目，边学边做记得牢。遇到问题先自己查文档和搜索，实在卡住再问人。每天写一点，比周末突击十小时有效。
