# drama-factory 靶向范围发版对照报告：Usage ByRun Limit 参数收紧

## 1. 改动摘要
本次发版针对 `GET /api/usage/by-run` 接口的 `limit` 参数进行紧致校验。
- 在 `UsageController.byRun` 方法开头新增参数校验逻辑：当 `limit < 1` 或 `limit > 500` 时，抛出 `IllegalArgumentException("limit 参数非法")`，由全局异常处理器统一转换为 HTTP 400 响应。
- 当 `limit` 为非数字类型时，由 Spring 框架的类型转换机制直接返回 HTTP 400。
- 方法签名、默认值（20）、Service 层回落逻辑、前端恒发值均保持原样，未做任何改动。

## 2. 验收范围
### 2.1 单元/靶向测试
- 新增 `UsageByRunValidationTest` 测试类，共计 7 例测试用例：
  - `limit=0`、`limit=-1`、`limit=501`、`limit=abc` 均返回 400。
  - 无参调用（使用默认值）、`limit=1`、`limit=500` 均返回 200。
- 既有 `UsageControllerDeepTest` 与 `UsageService` 的 `byRun` 服务层测试运行正常，因 Service 层未改动，相关测试结果不受影响。

### 2.2 靶向合跑
- 本次改动仅涉及 `UsageController` 的入口校验层，靶向合跑范围锁定在 Controller 层及关联的全局异常处理器。

### 2.3 真实服务冒烟
- 隔离服务冒烟（18231 端口，复制库，开放模式，含本轮改动的重打 jar）：无参 200、limit=0 返回 400 且 message 为“limit 参数非法”、limit=501/abc 均 400、limit=1/500 均 200、requests 回归 limit=50 返回 200；7/7 通过，冒烟后服务已按端口查到的真实 java PID 停服、端口已复查关闭、隔离库留在批次目录。

## 4. 已知限制
- `GET /api/usage/by-day` 与 `GET /api/usage/summary` 接口的 `days` 参数目前仍沿用 Service 侧的静默处理口径（如超限截断或默认值），不在本轮收紧范围内。
- 全量测试套件本轮未跑（只跑靶向两类 17 例）；覆盖率数字不编造。
