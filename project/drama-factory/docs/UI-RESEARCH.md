## 二、四家视觉拆解

### 2.1 ChatGPT（图 1/2/3）

- **布局**：未登录=单列居中（内容最大宽约 768px）；已登录=左侧栏约 260px + 主区。顶栏极简。
- **背景/表面**：深色约 `#212121` 中性深灰（非纯黑、非暖）；浅色纯白 `#fff`，侧边栏 `#f9f9f9` 微灰。表面与背景几乎无差，全靠留白分层。
- **强调色**：无彩色强调。主按钮=黑底白字（浅色）/白底黑字（深色）；Voice 按钮同理。黑白灰三色走天下。
- **字体字号**：系统无衬线；问候 "What can I help with?" 约 32px、中字重；正文 16px；辅助 12–13px。
- **圆角**：composer 大圆角约 28px；按钮/chips 一律胶囊 999px。没有 6–8px 小圆角矩形按钮。
- **边框/阴影**：浅色 composer 一圈细灰边；几乎零阴影，扁平。
- **侧边栏**：图标+文字 14px：New chat（`#ececec` 胶囊底高亮）、Search chats、Images、Apps、Deep research；底部 See plans and pricing ↗、Settings、Help ›，分隔线后接登录引导卡。**导航项上没有任何快捷键 chips。**
- **输入框**：底部居中大圆角；工具 pills **内置在框内下排**（+ Attach、Search、Reason，图标+文字小 pills）；Voice 胶囊坐框内右侧。
- **空状态**：一句问候 + 输入框 + 一排建议 chips（Summarize text、Analyze data、Make a plan、Code、Get advice、More，描边 pills 配小彩色图标）。无 pretitle、无描述段落。
- **新对话/历史**：侧边栏顶部 New chat；历史按时间分组的纯文字列表。
- **快捷键提示**：界面上**不出现**。⌘K 未明示。
- **一句话灵魂**：把"选择"藏起来——默认零配置，一个输入框解决一切。

### 2.2 Claude（图 4/5）

- **布局**：深色=纯图标窄 rail 约 64px + 主区；浅色=文字侧边栏约 270px + 主区。
- **背景/表面**：深色暖炭约 `#262624`（暖，**非纯黑**）；浅色暖纸约 `#F5F4EE`（**非纯白**），侧边栏是更深一档的奶油色。暖底+无边框，靠明度微差分层。
- **强调色**：珊瑚橙约 `#D97757`，**全站只出现在三处**：新建 "+" 圆钮、发送圆钮、logo 星芒。其余全中性。
- **字体字号**：**回答正文用衬线体**（品牌签名，图 4/5 均清晰可见）；UI 用无衬线；正文 15–16px。
- **圆角**：composer 约 20–24px；用户消息气泡约 16px；小工具钮为圆角方形。
- **边框/阴影**：发丝边框，零阴影。
- **消息形态**：assistant 文字直接落在背景上（**无气泡**）；user 消息=深色小气泡+圆形头像；thinking 块=描边圆角盒可折叠；消息操作=无框小图标（复制/赞/踩）+ "Retry" 纯文字。
- **侧边栏**（浅色）："Claude" wordmark；New Chat 描边胶囊（珊瑚色字）；Projects；**Recents 小字分组头**；会话=气泡图标+截断标题，active 项有底色；底部用户邮箱 + Help & support。
- **输入框**：底部居中、最大宽约 768px；placeholder "How can I help you today?" / "Reply to Claude..."；模型选择器 "Sonnet 4.5 ⌄" 以**纯文字链**坐在框内右下；发送=珊瑚实心圆 + ↑。
- **免责声明**："Claude can make mistakes. Please double-check responses." 小字、低对比、不抢戏。
- **快捷键提示**：无 kbd chips。**无中英双语小字眉题。**
- **一句话灵魂**：纸感 + 衬线 + 一点珊瑚——"像在高级笔记本上写作"，克制到全站只剩一个彩色。

### 2.3 Grok（图 6/7）

- **布局**：单列居中，无侧边栏（未登录态）。极端极简。
- **背景/表面**：纯白 `#fff` / 纯黑 `#000`。**零强调色**，全单色。
- **字体字号**：无衬线；中央大 wordmark "Grok" 约 48px；正文 15–16px。
- **圆角**：composer **单行胶囊 999px**；按钮全胶囊。
- **边框/阴影**：composer 一圈细边；零阴影。
- **输入框**：单行胶囊；左回形针图标；**右端框内**：模型选择纯文字 "✈ Auto ⌄"、麦克风图标、实心圆语音钮（黑/白）配波形图标。
- **工具 pills**：输入框下方：DeepSearch、Imagine、Pick Personas ⌄、Personas ⌄（描边胶囊+小图标）。
- **顶栏**：左 logo mark；右设置齿轮（**无框裸图标**）+ Sign In 描边胶囊 + Sign up 实心胶囊。
- **空状态**：wordmark + 输入框 + pills + 底部小字法律声明。没有一句多余的话。
- **快捷键提示**：无。
- **一句话灵魂**：X 式的极简主义——黑白两色、一个胶囊输入框，没有任何"设计感设计"。

### 2.4 Gemini（图 8/9）

- **布局**：Mac App 无侧栏（可收起）；Web 版左侧纯图标窄 rail 约 64px（汉堡/新建/设置）。
- **背景/表面**：纯黑 `#000`；Mac App 底部有**极淡的蓝紫环境光**（ambient glow，非常克制，非霓虹）。
- **强调色**：只有三处彩色——四色 sparkle logo、蓝色 "Upgrade to Google AI Plus" 胶囊、"New" 蓝色小 badge；其余单色。
- **字体字号**：无衬线；问候 "Hi Ab, What's on your mind?" 约 40px、**细字重（300）**；Web 版 "Where should we start?" 约 28px 左对齐常规字重。
- **圆角**：composer 胶囊 999px；浮层菜单约 16px。
- **边框/阴影**：composer 深蓝灰底约 `#1e1f20` + 细边；工具浮层=深色+细边。
- **输入框**：底部全宽胶囊；左 "+"；右 "Fast" 模型纯文字 + 麦克风；"+" 点开**工具浮层菜单**（Upload files、Add from Drive、More uploads ›、Create image [New 蓝 badge]、Canvas、Deep research、More tools ›，图标+文字 14px）。
- **建议 chips**：深色 pills（Boost my day、Write anything、Help me learn）。
- **顶栏**：左 "Gemini" 字标；右 Upgrade 蓝胶囊 + 展开图标 + 头像。**无全局搜索条。**
- **快捷键提示**：无。**无中英双语小字眉题。**
- **一句话灵魂**：Google 式的"少即是多"——黑底上只留一个发光 sparkle 和一句细字问候。

## 三、四家共性：现代 AI 软件的 10 条语法

1. **极端克制**：全站 1 个强调色（Claude 珊瑚、Gemini 蓝）或 0 个（Grok 纯单色、ChatGPT 黑白灰）；其余全部中性。
2. **胶囊即正义**：composer 大圆角（20px→999px）、按钮/chips 一律胶囊；没有 6–8px 小圆角矩形主按钮。
3. **导航零 kbd**：四家没有任何一家在导航项上挂快捷键 chips。快捷键是隐性能力，不是装饰。
4. **零双语眉题**：没有任何 "Xxx · XXX" 中英小字 pretitle。标题就是标题。
5. **侧边栏二选一**：纯图标窄 rail（~64px，Claude 深色/Gemini）或图文栏（~260–270px，ChatGPT/Claude 浅色）；active 项=底色填充，无重边框。
6. **composer 是主角**：居中、最大宽约 768px、工具 pills/图标按钮**坐在框内**、发送=实心圆+箭头坐框内右下。
7. **消息区无卡片**：assistant 文字直接落背景；user 消息=低调小气泡；拒绝"卡片阵列"。
8. **三档字号**：问候 28–40px / 正文 15–16px / 辅助 12–13px；一档字体（Claude 另加衬线做品牌签名）。
9. **边框≈无**：发丝 1px 低对比边框或干脆无边框；阴影≈零；分层靠留白和明度微差。
10. **空状态一句话**：问候 + 输入框 + 几个 chips；不写段落式说明，不教用户怎么用。

## 四、我们的 AI 味逐条诊断（7 张截图逐张过）

> 格式：→→

**A1. 导航项右侧的 kbd 快捷键 chips（G H / G C / G S / G T / G F / G P）**
四家没有任何一家在导航项上挂快捷键 chips（ChatGPT 侧边栏是纯图标+文字；Claude 深色是纯图标 rail）。
我们把 6 个导航项每个都挂了两个字母 chips，侧边栏看起来像"快捷键说明书"而不是产品导航，是"功能堆砌"味。
改成：删掉导航项上的全部 kbd chips；快捷键只在 ⌘K 命令面板内部展示（命令面板内显示快捷键是 VS Code 式标准做法，保留）。

**A2. 中英双语 pretitle（"AI 工作区 · WORKSPACE"、"场记板 · CLAPPERBOARD"、"质检 · QUALITY CHECK"、"渲染队列 · RENDER QUEUE"）**
四家没有任何 eyebrow 小字，标题就是标题（"Where should we begin?"）。
我们每页一个中英双语小字眉题，是典型"设计稿感"AI 味——真产品不会给自己加英文翻译小字。
改成：删掉所有 pretitle，只留中文标题。

**A3. 卡片网格的均匀间距（storyboard 3 列等宽卡片、pipeline 统计卡片、tasks 任务卡片）**
四家几乎不用卡片阵列展示内容（Gemini 唯一的卡片是工具浮层）。Claude 暖底上几乎无边框，靠留白分层。
我们全站同样圆角、同样边框、同样间距的"卡片阵列"，是后台模板味。
改成：分镜改 filmstrip 式列表行（一镜一行，左镜号+中描述+右状态/操作）；pipeline 统计数字直接排布，去掉卡片框；任务卡片改列表行。

**A4. 徽标（badge）滥用**
四家在主界面几乎不用彩色徽标；状态用文字颜色或小圆点。
我们：storyboard 每卡 2 个徽标（全景/移镜头）、pipeline 表格"待提交 0 / 生成中 0 / 已完成 3 / 失败 0"四个徽标、qc 页"已通过"徽标、index 剧集"已过审"徽标。
改成：状态改"小圆点+文字"；删掉纯装饰性徽标（景别/运镜徽标并入描述行文字）。

**A5. 强调色出现太多次（#4a6fa5 降饱和蓝）**
Claude 的珊瑚全站只出现 3 处；Grok 零强调色。
我们的蓝出现在：发送按钮、刷新按钮、徽标、命令面板高亮、导航 active 态、文字链接——到处都是，等于没有重点。
改成：全站强调色只保留给"主要行动点"（发送、生成视频、生成成片）；刷新/次要按钮/链接全部中性化。

**A6. 页面标题区三件套（pretitle + 24px 大标题 + 一句描述）**
四家的新页面只有一句标题；说明文字藏进 placeholder 和空状态。
我们每页 "小字眉题+大标题+描述句" 三件套（A2 已覆盖眉题，这里指后两者）。
改成：删掉描述句（"AI 视频生成任务的实时状态。"这类）；标题从 24px 降到 20px。

**A7. 顶栏全局搜索条 + ⌘K 并存**
四家没有"顶栏搜索框+命令面板"双入口：ChatGPT 侧边栏 "Search chats" 即搜索入口；Gemini 顶栏只有字标。
我们顶栏放了一个"搜索页面、操作... Ctrl+K"搜索框，同时又有 ⌘K 面板——两个入口做一件事，是功能堆砌味。
改成：删掉顶栏搜索条；顶栏只放当前页标题/面包屑；搜索统一走 ⌘K。

**A8. 输入框形态（chat / workspace）**
四家 composer：大圆角（20px→999px），发送钮是**圆形、坐在输入框内部右下角**。
我们：小圆角矩形输入框 + 独立蓝色矩形"发送"按钮在右下角外——这是传统表单味，不是 AI 软件味。
改成：composer 改大圆角（≥20px）；发送改圆形实心钮，坐进输入框内部右下角；`Ctrl+Enter` kbd 提示删掉（四家不教这个）。

**A9. 等宽字体滥用**
四家只在真正需要处用等宽（时间码、代码）。
我们：pretitle、kbd、"EP01"、"REVIEWED" 徽标、"00:17" 全是等宽——"EP01"用等宽像服务器监控面板。
改成：等宽只留给时间码/时长；"EP01"→"第 1 集"纯文字；状态徽标本来也要删（A4）。

**A10. 左下角 "v5.1 · 去玩具化构建" 版本水印**
四家没有任何版本水印。这是开发痕迹外露，典型" demo 感"。
改成：删掉。

**A11. 暖炭底 + 高对比边框的"脏"感**
Claude 深色也是暖底（~#262624），但它几乎不用边框，用留白和明度微差分层。
我们的 #1c1917 暖炭本身没问题，但配了 #3a352f 高对比边框 + 大量卡片，整体显"脏"、显挤。
改成：边框色再降两档对比（或大面积去边框，卡片改"无框+微差底色"分层）。

**A12. AI 工作区右侧四卡片套娃（生产概览/项目/剧集/待质检）**
四家没有"控制台式"首页；但我们是 MES，生产概览有存在理由——AI 味不在分栏本身，在四个同样式卡片套娃。
改成：右侧改极简"状态行"列表（label 左、值右，一条细分隔线），去卡片化；项目/剧集管理收进一处入口。

**A13. 表格"操作"列的按钮工厂（pipeline：打开分镜板/查看任务/成片库 三个描边小按钮）**
四家的做法：行内只放一个主操作，其余 hover 才出现或收进 "···" 菜单。
改成：每行只留一个主操作按钮；次要操作 hover 显示或收进下拉菜单。

**A14. 对话配额提示条的写法（"对话会消耗你的 DeepSeek API 额度（微信 ChatAPI），请按需使用。"）**
四家把这类信息压到极小（Claude 的免责声明是小字低对比；ChatGPT 是页脚小字）。
我们的橙色高亮提示条横贯页面，视觉权重过高——像系统警告。
改成：改成输入框下方一行小字低对比提示（或只在第一次对话时出现一次）。

**A15. 命令面板本身**
我们的 ⌘K 面板（6 页面+5 操作）方向是对的——对标 ChatGPT 的 Search chats / Gemini 的工具菜单 / VS Code 式面板，保留。
微调：面板内分组标题不要双语（"页面/PAGES"→"页面"）；操作项去掉多余图标装饰，保持文字+快捷键两列。

## 六、给改版轮的一句话

四家的共同点不是"深色+侧边栏"，而是**"藏"**：藏快捷键、藏配置、藏说明、藏边框、藏彩色。
我们的 AI 味恰恰来自**"秀"**：秀快捷键、秀双语、秀徽标、秀卡片、秀版本号。
改版方向就八个字：**藏起装饰，露出内容**。
