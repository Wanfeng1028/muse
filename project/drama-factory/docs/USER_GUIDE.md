# drama-factory 用户手册（v1.0.0）

drama-factory 是一个 AI 短剧 **Harness**：你给一个自然语言目标，它规划并调度一群专用 Agent 干活——编剧 → 分镜 → 视频生成 → 剪辑 → 质检。软件的核心是**运行（Run）的全生命周期管理**。

## 一、核心概念

- **Run（一次运行）**：从目标到产物的一次完整执行，是操作与查看的基本单位。入口在侧边栏「运行」分组 → **运行列表**。
- **Agent 时间线**：Run 详情页里各 Agent 步骤按执行顺序的列表。每一步显示状态、耗时，可展开看输入/输出摘要和工具调用。
- **审批门**：质检 Agent 完成后默认停下（`harness.qc.manual-approval` 默认开），等你人工看过再「通过」或「打回」。
- **产物（Artifacts）**：Run 详情页底部的归档区，按集列出剧本、分镜、已生成的视频和成片，可预览、下载。
- **Agent 机队**：侧边栏「运行」分组 → **Agent 机队**，5 个专用 Agent 的提示词模板、选用模型与降级策略。

## 二、跑第一条 Run

1. 侧边栏点 **运行列表**，点右上 **新建运行**。
2. 在输入框写目标，例如「做一部 3 集短剧，题材都市情感」，点 **预览计划**。
3. 核对计划卡片（每集的集号 / 标题 / 大纲）。如果模型不可用，页面会提示「已用模板计划」——也能跑，只是大纲是通用的。
4. 点 **确认执行**，自动跳到运行详情页。
5. 在 **Agent 时间线**看进展：每步的状态圆点（灰=待执行 / 蓝=执行中 / 绿=成功 / 红=失败 / 琥珀=等审批），点步骤展开看输入输出摘要；点 **日志** 打开右侧抽屉看实时日志。
6. 状态变成 **等待审批** 时，页面顶部出现琥珀色横幅：看完质检结果，在输入框写备注（可空），点 **通过** 放行，点 **打回** 退回。
7. 全部步骤成功后，到页面底部 **产物** 区：按集查看剧本全文、分镜列表、每个视频的预览与下载、成片的预览与质检状态。

> 首次体验建议用 **mock** 通道跑通全链路（不花钱），再到 Agent 机队或设置里切换 qwen / agnes 真通道。

## 三、运行控制

在运行详情页顶部，按状态出现对应按钮：

| 状态 | 可用操作 |
|---|---|
| 运行中 | 暂停 / 取消 |
| 已暂停 | 继续 / 取消 |
| 等待审批 | 通过 / 打回 |
| 失败 / 已取消 | 重试该步（失败的步骤旁）/ 重跑（整条 Run 另起一条，目标可改）|

- **重试该步**：只重跑失败的那个 Agent 步骤，已成功的步骤保留。
- **重跑**：基于这次运行改参数另起一条，历史记录保留。
- **取消**：停止执行，排队中的视频任务会被标记为失败（原因"运行已取消"）。

## 四、Agent 机队

- 顶部 **视频通道** 卡片：当前通道高亮显示，点 mock / qwen / agnes 即切换，**立即生效**（对新发起的视频任务；已在跑的不受影响）。
- 每张 Agent 卡片：选用模型、降级策略说明；点 **编辑模板** 改提示词，保存后对**新 Run** 生效，已在跑的 Run 不受影响。

## 五、设置中心

侧边栏底部点 **设置**。

- **模型与 Key**：DeepSeek Key（编剧/对话）、DashScope Key（视频）、Agnes Key（降级通道）。已保存的 Key 显示为 `****` + 后 4 位；密码框**留空=保持原值**，填了才覆盖。
- 标 **需重启** 的字段改完要重启服务；通道、Key、审批门开关等改完即时生效。
- 配置存 `data/settings.json`（不会进 git），重启不丢。**优先级：环境变量 > settings.json**——如果某项在环境变量里设过，页面上改了也不生效，先检查环境变量。

## 六、成本

- 每个 Run 按真实数据统计 token 与费用，列在运行列表和详情页底部。
- 显示 **—** 表示未知（通道没返回用量），不是 0。mock 通道不产生费用。
- 我们不估算、不编造：拿不到真实数的，就诚实显示"—"。

## 七、FAQ

**Run 卡住了怎么办？**
先看时间线定位停在哪一步：视频生成步长时间"执行中"通常是通道拥堵；日志抽屉里看最新输出。能重试就点「重试该步」，不行就「取消」后换通道「重跑」。

**视频一直生成中？**
通道拥堵。去 Agent 机队把通道切到另一条，取消当前 Run 后重跑。

**审批打回后怎么办？**
打回后 Run 进入失败态。看打回备注，修正目标后用「重跑」另起一条（目标可改）。

**模板改错了能恢复吗？**
可以。Agent 机队里重新编辑模板保存即可；建议改前把原文复制存一份。

## 八、故障排查

- **Key 无效**：看失败步骤的日志抽屉，`errorMessage` 会指出鉴权/额度/参数问题；核对 Key 是否过期、通道是否选对。
- **队列拥堵**：视频步排队不动 → 换通道重跑（见上）。
- **磁盘满**：媒体文件在 `data/media`，产物视频占空间大；确认不用的可以删。日志在 `data/logs`。
- **服务起不来**：`GET /api/health` 返回 200 表示就绪；端口占用改 `PORT` 环境变量；Docker 方式看 `docker compose logs -f`。
