来源：X 帖子 lumxss（@bkdgiffug）《AI 短剧这波是真打起来了》推荐的 3 个开源 AI 短剧项目。评估日期 2026-10-20，浅克隆逐仓读源码与文档。处置原则与既往一致：只借功能与信息架构、不借 UI、不 fork；License 不允许直接收录的一律独立改写（rewritten 标注）；AGPL 只借鉴设计、不复制实现。

## 一、魔因漫创 moyin-creator（MemeCalculate/moyin-creator）

- **定位/栈**：桌面端 AI 影视生产工具（动漫/短剧），Electron + TypeScript，v0.2.3；主打 Seedance 2.0，剧本到成片一条龙、批量出活。
- **License**：AGPL-3.0 + 商业授权双许可（强 copyleft）。处置：只借鉴设计，不复制任何代码/文档，仓内无 SKILL.md、无独立提示词文件，无可收录资产。
- **核心功能**：
  - 五大板块流水线：剧本 → 角色 → 场景 → 导演 → S 级（Seedance 2.0），每步产出自动流入下一步；剧本解析后还有一道「AI 二次校准」再过一遍结构。
  - 剧本解析引擎：拆场景/分镜/对白，识别角色、场景、情绪、镜头语言，支持多集多幕。
  - 角色一致性系统：角色圣经（Character Bible）+ 6 层身份锚点 + 角色参考图绑定。
  - S 级多镜头：多分镜合并生成连贯叙事视频；@Image/@Video/@Audio 多模态引用自动收集（角色参考图、场景图、首帧图）；提示词三层融合（动作 + 镜头语言 + 对白唇形同步）；首帧图 N×N 网格拼接。
  - **提交前参数校验**：Seedance 2.0 约束自动校验（引用上限 ≤9 图 + ≤3 视频 + ≤3 音频，prompt ≤5000 字符），不合规不发出。
  - 批量生产：一键全流程 + 多任务并行队列 + 失败自动重试；多供应商调度，API Key 轮询负载均衡。
- **可借鉴点**：参数约束校验前置；多模态引用配额模型；角色圣经/身份锚点分层；Key 轮询与队列重试。
- **已集成**：无（仅设计借鉴，见文末启示 2/3/5）。**待办**：Seedance 类参数约束进 provider 描述符 validate；角色锚点分层模型设计。

## 二、waoowaoo（waooAI/waoowaoo）

- **定位/栈**：AI 图片与视频创作工作台 + 工业管线，Next.js + Prisma、Docker 自托管，v0.5.0-beta.1；右侧 Assistant 连续对话 + 画布组织素材；网文/故事可直接进管线转视频。
- **License**：Elastic License 2.0（非 OSI 开源，限制以托管服务形式提供）。处置：skill 与提示词一律独立改写后收录。
- **核心功能**：
  - creative-skills 六件套（src/lib/creative-skills）：创作核心（事实边界/范围/时长纪律/交付自检）、创作方向（项目级呈现政策：视觉/叙事/导演/剪辑/声音/资产六域统一）、脚本开发（按需求类型选访谈与评判标尺）、资产开发（从源文本筛选可复用资产并写最终图片提示词）、视频导演（状态连续性/物理表演/最少分段数/结构化镜头时长/参考身份）、音乐设计（配乐窗口 + 结构化 Composition Plan）。
  - 管线阶段（由 standards/prompt-canary 夹具反推）：story_to_script_clips（故事转剧本片段）、screenplay_conversion（剧本转换）、storyboard_panels（分镜板）、voice_analysis（声音分析）。
  - project-agent 系统提示词：定义创作助手的自主执行、工具使用与交付规范（src/lib/ai-prompts）。
  - **prompt-canary**：给核心提示词建固定输入/期望输出的金丝雀夹具，提示词改动可回归。
- **已集成**：6 个 creative skills 独立改写收录进官方 skill 库（waoowaoo-creative-core / -creative-direction / -script-development / -asset-development / -video-direction / -music-direction）；project-agent 系统提示词改写版存 prompt/waoowaoo/project-agent-system.md。
- **待办**：prompt-canary 机制落成剧坊提示词回归测试（见启示 4）；「项目级创作方向文档」可作剧坊项目级配置实体候选。

## 三、火宝短剧 huobao-drama（chatfire-AI/huobao-drama）

- **定位/栈**：新手友好的一站式 AI 短剧：一句话主题出整部剧；TypeScript 前后端 + backend agents/skills 架构，有桌面版编排入口。
- **License**：CC BY-NC-SA 4.0（非商业）。处置：skill 与提示词一律独立改写后收录。
- **核心功能**：
  - 极简主流程：创意 → 小说改写为格式化剧本 → 提取角色/场景/道具（专用工具去重落库） → 分镜拆解 → 提示词生成 → 批量出图/出视频 → 配音 → FFmpeg 单镜头合成与字幕 → 整集拼接导出。
  - **分镜段落**粒度定义：一段 = 一个视频生成任务（8–15 秒），段内可切子镜头（硬切），全程不跨场景、不闪回；段含 description / atmosphere / duration。
  - 四类「最终提示词」规范：角色 = 正脸特写 + 三视图（正/90°侧/背）设定图作形象锚点；场景 = 无人物广角建立镜头空镜（前/中/后景与出入口相对位置固定）作背景锚点；道具 = 白底单品产品摄影；视频 = 按时间分段、带 @ 引用锚点的生成提示词。
  - Agents 架构：skills 以 SKILL.md 形式外置（extractor / script-rewriter / storyboard-breaker / prompt-generator 四组），与剧坊 SKILL.md 外置路线完全同构；提示词四语版（zh/en/ja/ko）。
  - 风格预设、素材库、任务进度追踪、多厂商适配。
- **已集成**：7 个 skills 独立改写收录（huobao-extractor / -script-rewriter / -storyboard-breaker / -character-prompt / -scene-prompt / -prop-prompt / -video-prompt）；4 份中文提示词改写版存 prompt/huobao-drama/（extractor / script_rewriter / storyboard_breaker / prompt_generator）；新管线模板 novel-to-drama 的阶段划分主要来自它（见下）。
- **待办**：分镜段落粒度进 Shot 模型校验（启示 1）；四语提示词暂只收中文版。

## 五、对剧坊的启示（可执行结论）

1. **分镜粒度标准化**：采用「分镜段落 = 一次生成任务（8–15 秒、段内可切镜、不跨场景）」作为 Shot 模型与连续性校验（ShotContinuityChecker）的统一粒度；huobao 已验证这是兼顾模型能力与叙事连贯的甜点粒度。
2. **锚点资产先行冻结**：角色三视图锚点图、场景空镜锚点图、道具白底图在批量生成前先生成并冻结为「资产圣经」，下游所有镜头只引用锚点、不重绘（huobao 四类提示词 + moyin 角色圣经/6 层身份锚点殊途同归）；剧坊应把资产圣经做成项目级实体。
3. **Provider 参数约束前置校验**：把视频模型的硬约束（多模态引用数量上限、prompt 长度上限、时长/分辨率枚举）写进声明式 provider 描述符，提交前 validate 拦截（moyin 的 Seedance 2.0 校验），而不是等 API 报错再熔断。
4. **提示词金丝雀回归**：为 data/prompts 与核心 skill 提示词建立 canary 夹具（固定输入 → 期望输出结构），提示词迭代时自动回归并纳入 mvn test（waoowaoo standards/prompt-canary）；这是我们目前提示词管理最缺的一环。
5. **批量队列补齐 Key 池与重试记账**：三家共性是并行队列 + 失败重试；moyin 还做了 API Key 轮询负载均衡。剧坊任务队列应补「按 provider 的 Key 池轮询 + 失败重试策略」，且每次尝试都记进 CostLedger 成本台账，避免重试烧钱无账可查。
