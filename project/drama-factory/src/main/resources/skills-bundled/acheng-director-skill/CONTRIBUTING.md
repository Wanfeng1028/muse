# AC Director 贡献规则

当前发布采用“小而可审计”的贡献边界。提交贡献前必须确认：

1. 你有权提交代码、文字、数据或素材；没有复制未授权的 skill、付费课程、私有聊天、客户资料、模型权重或受限参考图。
2. 贡献中没有密钥、令牌、私人路径、个人数据或需要付费才能访问的内容。
3. 贡献保留来源、原许可证、修改说明和必要的第三方署名。
4. 贡献不会把真实媒体已生成、模型能力已验证或版权已取得写成未经证实的事实。
5. 每个提交使用 DCO 风格的 `Signed-off-by: 署名 <邮箱>`，表示提交者有权提交，并同意贡献按该文件实际适用的项目许可证发布。

贡献不会自动获得 AC Director、Acheng Director 或 Acheng 名称的商标权。若未来改用 CLA、商业授权或双许可证，新的规则只对之后明确接受的贡献生效；不要把未审查的贡献直接打进正式发布包。
