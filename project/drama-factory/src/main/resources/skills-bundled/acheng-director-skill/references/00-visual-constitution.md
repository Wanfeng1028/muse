# 00｜视觉总宪法：从世界结构到可见证据

## 适用边界与锁定顺序

本宪法约束摄影、结构、材质和连续性，不把所有媒介强制转为照片。写实片用表面与光路证明体积；赛璐璐用色块、接触轮廓和作画时序证明受力；水墨用墨色浓淡、飞白、遮挡与留白证明空间。艺术夸张可改变表现手段，不能无说明地改变角色身份、事件顺序和物体拓扑。

选择或迁移画风时读取 [媒介预设](01-style-presets.md)，将其呈现参数写入项目VisualBible，再按本宪法校验结构与连续性。

一帧的构建顺序为：叙事主语与决定性事件 → 地平线／观察位置 → 主形与承重 → 前中后景遮挡 → 主亮区及暗区 → 材质大分区 → 功能构件 → 焦点处纹理及粒子。若缩略图读不到主体和事件，退回主形层；不得继续叠颗粒补救。

每场输出一张 VisualBible：`medium`、`aspect_ratio`、`world_axes`、`key_source`、`source_position`、`source_size`、`receiver`、`shadow_direction`、`fill_source`、`palette`、`material_classes`、`focal_zone`、`support_zone`、`quiet_zone`、`allowed_light_events`。世界坐标光位不随反打相机翻转；“相机左侧光”只能是当前镜头对世界灯位的投影描述。

## 单一统治主光及完整光路

一个时刻指定一个支配视觉层级的主光事件，不等于现实只存在一盏灯。天空、墙面反弹、实景灯可提供辅助。每一处可见亮边、地面光斑、反射或体积光都必须能追溯到：

`发射源的位置与尺寸 → 窗孔／遮挡 → 有密度分布的介质 → 首个接收面 → 投影 → 反弹或反射 → 曝光限制`。

以机库为例：东墙 6 m 高检修灯经断梁间隙照入，油雾仅在断管附近可见，先照上平台外缘，再投向西侧地面；近处机甲胸甲接收到蓝白灯光，内侧胸板只收混凝土反弹。脚底有接触阴影，门背后没有无源亮边。反打机位到西侧时灯可出现在画面另一边，但灯的世界位置不变。

| 场景目的 | 主光／补光起点 | 具体布置 | 验收失败时只改 |
|---|---|---|---|
| 日常信息可读 | 2:1–3:1 | 宽窗光，桌面暖反弹保留双眼 | 补光强度 |
| 对话压力 | 4:1–6:1 | 单侧面光，鼻影不吞掉另一只眼 | 光源高度或尺寸 |
| 夜间对峙 | 8:1–12:1 | 后侧灯，背景门缝提供轮廓分离 | 暗侧最低可读亮度 |
| 爆点剪影 | 16:1 附近的创作起点 | 能量事件短暂接管主亮区，保留接触线 | 爆点面积与持续帧数 |

这些比值是照明设计起点，不是所有渲染器通用的像素亮度比。点源在适用距离可近似反平方衰减；太阳、面积灯近场和有遮挡空间不能机械套同一公式。爆炸接管主光必须登记起止帧和恢复路径；暗场对白不能被持续曝光抽动破坏。

## 材质响应：先区分，再精饰

| 材质 | 可观察响应 | 局部细节的归属 | 常见修复 |
|---|---|---|---|
| 皮肤 | 宽柔高光，耳缘或手指薄处轻微透光 | 近景鼻翼／眼下保留少量肌理 | 降低统一油亮，保留面部体块 |
| 毛发 | 成束走向和方向性高光 | 发束边缘的少量散丝 | 先合并发束，后补散丝 |
| 粗布 | 宽漫反射，纹理沿褶皱弯曲 | 袖口、肘部接触磨损 | 删平贴纹理，恢复折边厚度 |
| 皮革 | 柔和半光泽，弯折处局部压纹 | 握持区磨亮，接缝有有限接触影 | 缩窄湿润区，不把整件涂亮 |
| 涂装金属 | 漆面与裸露金属有不同高光宽度 | 踏擦边、碰撞口、热源附近氧化 | 先区分漆层／基材，再加磨损 |
| 拉丝钢 | 高光沿表面加工方向延伸 | 同一面内拉丝方向一致 | 删除随机全向亮纹 |
| 石／混凝土 | 大面吸光，断口厚度与骨料可读 | 裂纹从受力点扩展 | 降低均匀斑点，明确承重路径 |
| 水／玻璃 | 反射随视点和法线改变，厚处有透射差异 | 波纹、边缘、局部积水 | 恢复干湿边界和反射位置 |
| 纸／薄纱 | 局部透光、卷边与叠层 | 折角／拉扯接触点 | 把纹理限制在当前分辨率可见处 |

PBR 参数如 roughness 0.3 或 0.8 仅作为已声明渲染器中的起点，不能当成生成模型保证执行的硬数字。金属不一定都是窄亮高光，粗糙度和光源尺寸共同决定高光宽度；非金属 F0≈0.04 是常见近似，不能覆盖所有介质。描述视点可见结果比堆叠参数更重要。

## 暗部、色彩与信息密度

保留能解释身份、路面、接触、地标的暗部信息；非叙事角落可以趋近剪影。不能全局抬黑形成灰雾，也不能给所有边缘加同宽亮描线。“通透”指层次可辨，不指阴影具有玻璃透明度。

能量夜戏可以用亮核 10%、扩散边缘 30%、对比暗部 60%作为构图草案；这不是亮度守恒定律，也不是每张图强制像素配额。亮核集中于发射与接触线，弥散边缘随介质密度衰减，暗部维持人物轮廓。晴天、白底资产、水墨留白不强制套暗调。

建立 3–7 个主形群，一到两个焦点机制。焦点区保留眼睛／接触／标志物的高边缘对比；支撑区保留中尺度结构；静音区合并低频色面。远景先失去内部小形，再减低边缘对比，只有雾霾支持时再降低色度并偏向大气光色。不能把所有背景统一染蓝或全局模糊。

## 六类尺度证据与四种构图

百米／千米主体至少有两类独立证据，每条记 `type/detail/frame_location/depth_relation`。两个人站在脚边仍只算一种“基准物”证据。

| type | 证据方法 | 合格例 | 不合格例 |
|---|---|---|---|
| benchmark | 同深度可识别物 | 检修车停在脚踝基座旁，车门与脚趾同面 | 前景巨大人头与远方巨物 |
| circulation | 使用及运输流线 | 维护列车进入膝部检修舱，道路贯通腿间 | 无去向装饰灯点 |
| environment | 环境相互作用 | 翼下风压先压弯近树，继而把港池浪峰推开 | 脚下无接触的烟团 |
| atmosphere | 大气分层 | 云带切过胸口，头部对比弱于近足 | 全图均匀加雾 |
| modularity | 构造／生长模数 | 人尺寸舱门逐层重复到躯干，接缝尺度渐变 | 满身同尺寸微格 |
| occlusion | 遮挡／视差 | 前景桥墩掠过，巨物仍跨地平线并遮去远山 | 只写“高一千米” |

四种主构图：多边出框须留下轮廓转折；一轴完整须显示可辨截面及向远方延伸的另一轴；完整剪影须用云层／地平线／巨大空域证明体量；可居住剖深须显示层级交通和入口。选择一个主模式后才布细节。

五大分支：建筑先公共功能和荷载；巨型器物先运行、散热和维护接口；巨兽先姿态重心与地面反馈；宇宙恐怖先一条可见但不完全可解释的身体规则及环境后果；纯有机巨物仅在明确要求时禁用身体上的金属与已知物种比喻，以生长模数和无机外界参照证明尺度。原始细则见 [巨构手册](sources/colossal/field-guide.md)。

7:2:1 是大形／中形／细形视觉信息的诊断起点：大轮廓先读到，入口、肢体和功能构件其次，裂纹和颗粒只出现在焦点。不要按面积机械裁去 70% 画面。

八变量排错依次定位：构图模式、同深度基准、环境反馈、大气分层、模数密度、观察高度／距离、支撑荷载、系列差异。每次只动导致失败的一项。过浅景深和移轴式焦平面可能强化微缩感；深景深本身不是“玩具感”的充分原因。

## 摄影物理边界与最终检查

焦距必须附传感器／等效约定；透视主要由观察位置决定，不能说“50 mm 自动还原真实透视”。2.39:1 是画幅，不自动证明变形镜头；横向炫光、椭圆散景、胶片颗粒均按已选媒介启用。曝光时间关系为 `t = shutter_angle / (360 × fps)`；24 fps、180° 对应约 1/48 s。高速动作可减小快门角保留接触线，不能用“120fps”承诺未执行的生成规格。

交付前看四张证据：缩略图读主形、灰度图读明暗、局部读材质、连续帧读世界光向。尚无生成图时只记录计划，视觉结果保持 `unverified`。修复画面先冻结身份、场景、动作与镜头，只修有证据的失败层。
