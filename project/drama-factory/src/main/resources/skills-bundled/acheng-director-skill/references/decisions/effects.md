# 视效：让事件读得清楚

执行方式见 [115](../115-directed-decisions.md)。先读已批准的动作结果、时序、场景状态及效果 family，再按 [45](../45-vfx-sakuga-engine.md)、[46](../46-effect-families.md) 写原字段。OPTIMIZE 的冻结项保持不动。

## V1｜效果遮住接触或反应

- 本镜最需要看清的是接触点、面部反应还是破坏后的结果？找到它实际发生的时间窗与画面区域。
- 现有效果在哪里、何时遮住它？只调整 owner 范围内的密度、遮挡层次、光色或可调整的表现参数；不挪动已冻结的碰撞与过程。
- 调整后起因、反应与尾态是否仍有可见连接？如果必须改动作或摄影才能成立，将具体冲突退回主导演。

例：尘雾可保留在支撑背景处，同时让接触手与被挡兵刃可读；不能为露出接触点改成“没有命中”。

拟加闪光、反相或碎片强调时才读[冲击强调 Q20](../inquiries/effects.md#q20)，检查它是否遮住自己本该强调的接触证据。动画参考按[视觉库](../116-visual-reference-library.md)路由回已有术语库，不叠满全部作画效果。

## V2｜巨大只剩形容词

先从场景中找已有的固定尺度参照与深度关系，再检查运动、遮挡或时间上的另一类证据。两类证据要描述不同现象，不把两个近义“大”算两类。没有车辆或建筑就不临时发明它们；使用已存在的参照，或把证据缺口交主导演。

## V3｜风格化效果被机械写成写实物理

先确认用户的视觉规则及已设定能力。水墨、光学、变形不套能量流体全部字段；只采用所属 family 的因果与连续性要求。抽象形容词若承担关键事件，就补上可见变化；项目明确需要残影或悬浮时保留其设定，并说明发生范围与结束状态，不做全局词语禁令。

具体选择：[现场介质 Q23](../inquiries/effects.md#q23)检查来源和消退；[冲击波依据 Q24](../inquiries/effects.md#q24)检查设定是否支持；[既有天气作用 Q35](../inquiries/effects.md#q35)检查作用部位和留下的状态。没有对应事实就不用该效果，不为填表补齐固液气或新天气。新残留交 continuity，冻结项不变。
