# 全能剧本大脑引擎 (Scriptwriter Engine)

当用户尚未提供可直接进入下游分镜的终版剧本，需要从原始创意、题材概念、长篇小说或梗概孵化影视级完整剧本时读取本文件。
已有上游确认版完整剧本时，不重新改写原剧本核心情节，直接进入 `references/20-storyboard-compiler.md` 与 `references/30-performance-adapter.md`。

---

## 1. 核心定位与承接边界

- **题材与类型通用性**：承接院线电影、重工业科幻大片（如好莱坞变形金刚/复联机甲怪兽）、都市悬疑、微电影、高概念短剧、史诗奇幻、动作打戏等任意叙事题材。
- **画风解耦机制**：本引擎不锁定任何特定画风。剧本开头的叙事气质通过镜头布光、空间几何、色彩基调与运动节奏参数进行定义，并与 [01-style-presets.md](file:///C:/Users/dcf/Desktop/minimax/skill/ai影视导演助手/cinematic-director-engine/references/01-style-presets.md) 声明的 6 大电影级风格预设（如 Style 01 好莱坞工业写实、Style 02 盛唐半写实CG 等）无缝绑定。
- **时长合同强约束**：
  - `production_total_duration`：作品或单集的目标总时长（如 120 秒短剧、15 分钟微电影或 90 分钟长片），由剧本声明并在整个生产链路中保持一致。
  - **严禁混淆**：绝不将全片总时长误写为下游单次 AI 视频生成的片段时长（`generation_clip_duration`）。

## 2. 创作前置澄清策略 (Clarification Protocol)

在剧本创作前，必须向用户确认或依据上下文合理推断以下核心参数：

1. **核心创意与题材类型**：科幻工业、高动态动作、都市悬疑、奇幻修仙、废土灾难、商业广告等。
2. **总时长声明 (`production_total_duration`)**：优先继承用户指定；未指定时主动询问，不擅自设下狭隘上限。
3. **叙事结构偏好**：
   - **三幕式工业电影架构**：强开场钩子 (Hook) → 第一情节点/冲突升级 → 镜像点/至暗时刻 → 终局决战反转 → 余韵落点。适合院线大片与情感沉淀微电影。
   - **短视频高能节拍架构**：3 秒爆点反转 → 矛盾极速堆叠 → 身份揭秘/打脸反制 → 悬念截断。适合短剧与快节奏信息流。
4. **核心主角与对立力量**：主角核心欲望与致命缺陷；反派的合理化动机与阻碍手段。
5. **视效与工业体量评估**：是否涉及好莱坞重型装甲破坏、流体能量打斗或大规模群演，以便下游资产与视效引擎提前介入。

## 3. 四段式必须交付产物规范 (The Four Deliverables)

任何一次完整的剧本创作，**必须按序交付以下四段产物，缺一不可，段间以 `---` 分隔**：

### 产物一：全景剧情梗概 (Narrative Synopsis)
- 单一连贯叙事文本，拒绝破碎标签。采用 4-5 个自然段完整呈现“起、承、转、合”。
- 必须明确：故事初始世界观环境、核心催化事件、冲突全面升级、高潮巅峰决战抉择、最终命运落点与主题升华。
- 多集/长篇体量需附带分集/分幕结构大纲表格。

#### ★ A/B/C 三轨多支线交织编织矩阵 (Multi-Plot Interlocking Architecture)
长篇连续剧、院线级长片或高密度剧情短剧，**严禁使用单一直线流水账**。产物一中必须以表格化形式确立主副线交织节拍，杜绝任何与主线脱节的“孤立注水支线”：

| 剧情线轨 | 叙事功能与定位 | 驱动动力 | 核心任务与交汇节拍 |
|---|---|---|---|
| **A-Plot（主线-外部危机）** | 外部主事件与物理生存目标 | 生死危机 / 任务拯救 / 决战胜负 | 驱动全片外部情节推进；在中点遭遇假胜利/重大挫败；在终局决战迎来高潮巅峰。 |
| **B-Plot（副线-关系与情感）** | 核心人际羁绊与价值冲撞 | 爱情 / 宿怨 / 师徒 / 救赎与背叛 | **主角人物弧光的心灵孵化器**；在第二幕展开，其情感危机直接在中点或至暗时刻倒逼主角改变行动策略。 |
| **C-Plot（暗线-世界观与阴谋）** | 阵营角力、历史真相、时代暗流 | 伏笔悬念 / 幕后黑手 / 定时炸弹 | 潜伏于前中段，在第二幕末尾（至暗时刻前夕）全面引爆，粉碎原有局势，将 A 线危机推向不可逆绝境。 |

> [!IMPORTANT]
> **多支线交织收敛律 (The Interlocking Law)**：
> 1. **因果锁死**：支线绝不是调剂节奏的独立短片。B 故事的情感关系破裂或和解，**必须成为主角在 A 故事做出终局生死抉择的唯一内在动机**。
> 2. **合流收束**：C 故事的伏笔揭秘，必须在中后段直接并入 A 故事的主战场，成为决战反转或胜败的关键钥匙。

### 产物二：深度人物小传 (Dramatis Personae)
至少涵盖 **主角 (Protagonist)**、**核心配角/伴随者 (Supporting)**、**反派/对立面 (Antagonist)** 三类角色。每位角色采用以下工业级维度建立：

```markdown
#### [角色全名]（[主角 / 配角 / 反派]）
- **一句话定位**：[年龄 + 职业/身份 + 标志性性格反差]
- **外化体态原型**：[绑定 references/50-character-morphology.md 的骨骼体型，如“成年男性、重装骨架、肩宽腰窄、多处机械外骨骼接驳口”]
- **性格特质**：[3-4 项具体行为倾向，严禁空洞形容词]
- **核心动机**：
  * **表面渴望 (Want / 外部目标)**：[角色在外部世界积极追求的具体事物，如“夺回控制权”、“复仇”、“金钱”]
  * **灵魂需求 (Need / 真正真理)**：[角色内心深处真正缺失并需要获得的成长或救赎，如“学会信任”、“放下执念”、“承担责任”]
- **★ 好莱坞四阶人物弧光状态机 (Character Arc State Machine)**：
  * **弧光类型**：[正向蜕变弧 (Positive Change Arc) / 悲剧堕落弧 (Tragic/Corruption Arc) / 平移信念弧 (Flat Arc)]
  * **阶段 1：认知盲区与内在谎言 (The Lie & The Wound)**：[开场坚守的错误信念，根植于过往创伤或未愈恐惧]
  * **阶段 2：越界考验与表面假象 (Testing the Lie)**：[进入外部冲突，依然用旧有错误手段应对，取得短暂假胜利或首轮挫败]
  * **阶段 3：灵魂暗夜与代价抉择 (Dark Night of the Soul & The Ordeal)**：[旧手段彻底失效，被逼入绝境，必须在放弃 Want 还是拥抱 Need 之间做出极度痛苦的牺牲抉择]
  * **阶段 4：终局蜕变与落点 (Climax Transformation)**：[完成人格精神蜕变（正向），或执迷不悟走向覆灭（悲剧），或以坚不可摧的信念重塑世界（平移）]
- **关键道具/感官记忆点**：[随身标志物、微动作习惯（如焦虑时摩挲戒指、呼吸沉重）]
- **反派特别约束**：必须具备合理的认知逻辑（反派自身逻辑自洽，非无脑纯恶），并具备明确的叙事惩罚或宿命终局。
```

**在动笔撰写剧本正文前，必须将全剧所有场景预先在此表格中登记。**

> [!IMPORTANT]
> **场景防幻觉绝对红线**：

## 4. 大体量与跨集连续性事实账本 (Continuity Protocol)

针对跨多集、长篇系列或复杂多线剧情，剧本引擎必须建立并维护 `Continuous State Ledger`（事实账本），记录：
1. **生理伤势与身体状态**：骨折、机械肢体损伤、战损拉伤必须在后续场次持续生效，严禁下场戏自动痊愈。
2. **关键道具持有权**：武器、密匙、文件的空间流转因果必须连续。
3. **人物心理关系状态**：不可逆的情感决裂或同盟建立必须记录，防止后续情绪反弹失真。
4. **环境物理状态**：被炸毁的门窗、燃烧的废墟在同一场景重返时必须保持破坏后残迹。
