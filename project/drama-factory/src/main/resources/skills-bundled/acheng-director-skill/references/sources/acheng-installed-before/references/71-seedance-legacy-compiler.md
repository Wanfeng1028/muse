## 1. Seedance 2.0 语法架构与插槽映射

Seedance 2.0 对提示词的结构化排版有较强依赖，通常采用如下字段组装：

```text
[主体识别与状态] + [环境背景与景深] + [核心物理动态与发力链] + [摄影机运镜指令] + [光影与材质渲染风格] + [声音与音效提示]
```

### 参数控制与映射表：
- **运动幅度 (Motion Intensity)**：
  - 文戏微表情镜头：设置为 `2 - 3`（保持面部五官稳定，杜绝漂移）；
  - 对话与中景互动：设置为 `4 - 5`；
  - 高动态打戏/机甲对撞：设置为 `6 - 8`（激活强烈运动模糊与物理形变）。
- **画幅长宽比**：16:9 (横屏电影感) 或 9:16 (短剧坚屏)，依据项目设定声明。

(电影级质感，2.39:1 变形宽银幕)，[主体专有名词]在[场景空间名称]中，[起始姿态与目光方向]；随后[主体沿特定路径做出核心动作]，[受力接触点与物理反作用力]，地面激起碎屑与灰尘；摄影机[低角度仰拍向前平推跟运镜]，主体始终保持在画面中心；45度冷色强侧逆光勾勒人物边缘轮廓，暗部深邃通透无死黑，金属表面高反差拉丝反光。<背景伴随低沉金属撞击轰鸣与粗重呼吸声>。
