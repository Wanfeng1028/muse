# 关键帧生成 Ref

当剧本、分镜表和资产已获得用户确认/由用户提供，需要生成片段关键帧图时读取本文件。

## 目标

把确认后的资产和按 `generation_clip_duration` 切分的连续分镜，转化为 **GPT Image 2 关键帧指令**并生成对应图片。

关键帧由 agent 依据下文的**关键帧判定标准**，从每个片段的镜头列表中动态锁定 1 到多张最需要被可视化为静态图的镜头，作为该片段的视频生成锚点。

本阶段关键帧的视觉生成规则采用 cinematic 场景关键帧引擎：

- **画风、光影、色彩、材质上位约束**：`references/00-visual-contract.md`（固定画风 DNA、单一统治光、布光路由、质量门控）。
- **叙事/动作关键帧引擎**：`references/30-scene-keyframe-design.md`（叙事关键帧模式、动作关键帧相位选择、七层空间、电影摄影引擎、参考图职责分离、40 分质量审计）。
- **连续性与交接**：`references/40-continuity-and-handoff.md`（镜头状态机、可变与不可变、光位连续性、180 度轴线、场景地图）。
- **表演适配**：有 `expression_handoff` 时读取 `references/performance-adapter.md`（EX→shot 绑定、可见性、静态相位选择、12 项接口）。
- **GPT Image 2 编译**：`references/gpt-image-2-prompt-compiler.md`（generate/edit、参考图职责、不变量与改变项、quality/size 参数）。
- **每张关键帧建立 ShotSpec**（模板 `templates/shot-spec.yaml`）；同一场景多镜头连续时建立 VisualBible（模板 `templates/visual-bible.yaml`）。

**【强制】本阶段所有关键帧 Prompt 的画风段，必须一字不差使用 `references/00-visual-contract.md` 第 1 节固定画风 DNA，并与资产阶段全部资产图的画风段完全一致。**

## 关键帧数量决策原则

**关键帧不是"首/中/尾"三帧模板**：分镜阶段已经明确"不预先指定首/尾帧位置"，本阶段同样要求 agent **按片段实际信息量自行决策数量**，而不是每个片段都套用「首帧 + 中段 + 尾帧」三张的固定结构。

- **默认取值**：每个生成片段默认锁定 1 张关键帧；只有存在彼此独立、无法由同一静帧表达的空间/身份/道具/表演状态变化时才递增，通常控制在 1–3 张。若需要超过 3 个强制视觉锚点，优先回到 storyboard 缩短该生成片段，而不是向一次生成堆叠参考图。
- **典型分布**：
  - **常规日常/对话/单一事件片段** → 1 张（例如整个片段就是「主角走进房间→坐下→拿起茶杯→喝一口」，只需锁定"决定性瞬间"或"空间锚点"其一）。
  - **中等信息量片段** → 2 张（例如空间锚点建立 + 一次决定性瞬间；或一次情节转折 + 一次道具状态突变）。
  - **高信息量片段** → 3 张（例如同一片段内出现空间锚点建立 + 决定性瞬间 + 情节转折三条独立命中，且分别落在不同镜头）。
- **禁止套模板**：**不得**默认按「首帧 + 中段 + 尾帧」的三分法套用 3 张关键帧结构；**不得**仅因某镜头位于片段第一个或最后一个镜头就自动锁定。位置在首/尾本身不构成入选理由，必须该镜头独立命中下文判定标准之一才可锁定。
- **视频阶段的"首帧/中段锚点/尾帧"是时间锚点声明，不是关键帧数量指令**：`prompt.md` 中"首帧/中段锚点/尾帧"是视频生成阶段对**已锁定关键帧**如何在时间轴上定位的声明规则；不构成"关键帧生成阶段必须锁定首帧和尾帧"的要求。锁定 1 张时，该张在 `prompt.md` 阶段即作为该片段的"首帧"（若对应镜头不在 0 秒起点则作为对应时间点的中段锚点），无需另行补首/尾帧。

## 关键帧的定义

特指片段中**最能承担叙事、身份、空间与情绪锚定作用**的静态画面。它服务于两个下游目的：

1. **供 `image_to_video` 使用**：作为该片段视频生成的图片参考，锁定人物身份、道具状态、空间关系、光影基调。
2. **供分镜校审使用**：让用户在生视频前预审关键节点画面，降低返工成本。

## 关键帧判定标准（agent 自行锁定的依据）

对每个片段的镜头列表逐一评估，凡命中一条以上的镜头即为候选。默认 1 张；仅当多条独立判定标准分别落在不同镜头、且下游确需相应视觉状态时才递增。不得为凑数强行锁定，也不得套用“首中尾”三分模板。

- **决定性瞬间**：动作或情绪抵达顶点的一帧（打脸瞬间、拥抱定格、拔剑出鞘、跌倒着地、爆发怒吼的静止）。
- **情节转折点**：剧情走向被改写的镜头（发现秘密、身份揭示、道具易主、关键对白落定）。
- **身份/形象首次或再次亮相**：主要角色首次出场、换装/受伤/毁容后的形象再登场、反派身份揭示。
- **状态突变前后**：道具状态突变（怀表完整 → 被踩碎、信封未拆 → 展开）、人物物理状态突变（干净 → 湿透、清醒 → 昏迷、健康 → 出血）。
- **角色造型/配饰改变**：角色外形发生**动作性**去除或添加，导致识别特征即刻改变的镜头。典型举例：戴帽子 → 摘帽子、穿外套 → 脱外套、戴口罩 → 摘口罩、戴眼镜 → 摘眼镜、戴面具 → 揭面具、束发 → 散发、系围巾 → 解围巾、穿铠甲 → 卸铠甲。此类镜头承担"身份显露/隐藏""情绪松弛/戒备切换""身份伪装揭穿"等叙事功能，视觉上前后帧差异明显，是天然的关键帧候选；与「状态突变前后」的区别在于本条聚焦**角色主动改变自身造型/配饰**（服饰配饰的穿脱切换），而状态突变聚焦**被动的道具或身体伤情变化**（打碎、湿透、出血）。若一次镜头同时承担摘帽子（造型改变）+ 情绪释放（决定性瞬间），可视作双命中。
- **空间锚点建立**：新场景首个能完整交代空间结构、光影方向的镜头；跨场景切换后的落点镜头。
- **视角体系切换**：POV 与第三人称切换处的第一帧（在切换后需要视觉锚点建立空间关系）。
- **群像结构定格**：多个主要角色同时定位、站位关系被建立或重排的镜头。
- **叙事开合**：**位置本身不构成命中依据**——片段第一个镜头或最后一个镜头**只有在其独立命中上述任一功能**（决定性瞬间/情节转折/身份亮相/状态突变/造型改变/空间锚点/视角切换/群像定格/光影转折）时才可入选；**不得**仅因位于片段首尾、或"要给视频阶段留首帧尾帧"而自动锁定。若片段首尾镜头均未独立命中判定标准，锁定 1 张中段最强命中即可。
- **光影转折**（微电影向常用命中点）：整段情绪由光影承担的关键节点——夕阳落下的最后一道光、灯泡熄灭前后、色温从冷切到暖、逆光剪影建立、雨停后的第一道天光、蜡烛点燃的火苗定格。微电影 B4 章将"光影是第一叙事语言"作为核心美学，此类光影转折镜头往往比人物动作更能承担情绪落点，需优先锁定。

**逆向排除清单**：以下类型不适合作为关键帧，即使命中上述标准也应寻找相邻替代：

- 纯转场镜头、黑场、空白字幕、无可视主体的过渡帧。
- 极高动态模糊镜头（甩镜转场、冲刺跟拍中段），静帧无法稳定表现动作意图。
- 人物完整正脸完全不出现的 POV 镜头（除非该镜头本身就是关键道具特写）。

### 「位置」与「命中」的区分（避免套首中尾模板）

一句话概括：**不是"首/尾镜头不能选"，而是"选它必须因为它本身命中了判定标准，不能因为它位于首/尾"**。

**反例（错误：仅因位置入选）**

假设某个 `generation_clip_duration: 15s` 的示例片段含 5 个镜头（此处 15 秒只是演示数据，不是默认时长），agent 若按「首/中/尾」模板锁定 3 张关键帧就是错误：

| 镜头 | 内容 | 位置 | 独立命中 | 是否入选 |
|---|---|---|---|---|
| 镜头1（00:00-00:03） | 全景移镜：主角走进书店 | 片段第一个 | 空间锚点建立 ✅ | 入选（因命中，不因位置） |
| 镜头2（00:03-00:07） | 中景：主角环顾书架 | — | 无（过渡） | 不入选 |
| 镜头3（00:07-00:11） | 近景：主角伸手抽出一本书 | — | 决定性瞬间 ✅ | 入选 |
| 镜头4（00:11-00:14） | 特写：书页翻开，一张老照片滑落 | — | 情节转折 ✅ | 入选 |
| 镜头5（00:14-00:15） | 中景：主角低头看着照片，画面渐暗 | 片段最后一个 | 无（收束过渡） | **不入选** |

- **正确锁定**：镜头1、镜头3、镜头4 → 3 张（三条独立命中）。
- **错误示范**：镜头1 + 镜头3 + 镜头5，理由"要凑首中尾"——镜头 5 未独立命中任何判定标准，仅因位于片段末尾被入选，属于套模板行为，回炉。

**正例（正确：首/尾镜头恰好命中）**

| 镜头 | 内容 | 位置 | 独立命中 | 是否入选 |
|---|---|---|---|---|
| 镜头1（00:00-00:03） | 主角推开旧公寓木门，尘埃在斜光中飘动 | 片段第一个 | **空间锚点建立** ✅ | 入选 |
| 镜头2-4 | 走进/环视/靠近书架 | — | 无（过渡） | 不入选 |
| 镜头5（00:12-00:15） | 铁盒表面浮出光斑，盒内传出滴答声 | 片段最后一个 | **情节转折/悬念揭示** ✅ | 入选 |

- **正确锁定**：镜头1、镜头5 → 2 张。虽然它俩恰好位于片段首/尾，但入选理由是它们**独立命中了具体判定标准**，不是位置。

**判定口诀**：写映射表时，如果某行「命中判定标准」列只能写出「首帧/尾帧/开场/收束」这类位置词、写不出具体的判定标准名称（决定性瞬间/情节转折/空间锚点等），说明该镜头就是"仅因位置入选"，删掉它。

## 关键帧生成前的强制流程

1. **逐镜头命中评估**：agent 逐镜头读入 `storyboard.md` 中当前片段的镜头列表，对每个镜头逐条比对上文判定标准，输出「候选清单」——**每一条候选都必须写清具体命中的判定标准名称**，未命中任何标准的镜头一律不进入候选。
2. **数量决策**：**先看命中数、再看是否递增**。
   - 若整个片段仅有 1 个镜头命中判定标准 → 锁定 1 张（默认最常见情形）。
   - 若命中 2 个不同判定标准且分别落在不同镜头 → 锁定 2 张。
   - 若命中 3 条独立判定标准且分别落在不同镜头 → 最多锁定 3 张；若仍有更多必要状态，优先缩短 `generation_clip_duration` 并重新装箱镜头。
   - **禁止套模板**：不得为凑「首中尾」三张而把不达标的首镜头/尾镜头强行入选，也不得因担心视频阶段"缺首帧尾帧"而虚构命中理由。
3. **优先级取舍**（仅在候选超过默认取值上限时启用）：**短剧向**「决定性瞬间 > 情节转折 > 身份/状态突变 > 造型改变 > 空间锚点 > 光影转折 > 其它」；**微电影向**「光影转折 > 情节转折 > 决定性瞬间 > 状态突变 > 造型改变 > 空间锚点 > 其它」。候选不足默认取值时，宁少不凑数，可回落到 1 张。
4. **命名与映射**：按下文命名规则给出稳定文件名，并输出关键帧分镜映射表；映射表每一行的「命中判定标准」列必须写清具体命中标准，禁止留白或写"叙事开合首帧/尾帧"这类位置性理由。
5. **ShotSpec 建立**：每张锁定的关键帧按 `templates/shot-spec.yaml` 建立 ShotSpec——写清叙事时刻、镜头参数、主体位置/朝向/动作/接触点、主光与衔接。有 EX 映射时填满 12 项表演接口，并在 `performance_provenance.selected_phase` 中只选择 `state_in`、`leakage`、`control_action` 或 `residual` 之一；同一场景多镜头连续时建立或更新 VisualBible。
6. **参考图选择**：仅传入本次实际需要的角色/场景/道具资产图，动态编号 `[img0]`、`[img1]`……并按视觉合同第 9 节分配每张参考图的职责（identity/scene/props 等）。
7. **GPT Image 2 生图**：已有资产真值源时使用 edit 并实际传入参考图；无参考图的纯新建任务才使用 generate。按模型编译器生成指令并即时返回。

## 关键帧命名

关键帧名称直接继承全局 `shot_id`，避免章节、片段重新装箱后失去 EX 与分镜溯源：

```text
<shot_id>-KFxx.png
```

- `<shot_id>`：逐字继承 storyboard 的 `EPxx-Sxx-SHxxx` 或 `FILM-Sxx-SHxxx`，不得重编号。
- `KFxx`：同一镜头需要多个合法静态锚点时从 `KF01` 递增；通常一个镜头只需 `KF01`。

**示例：**

```text
EP01-S03-SH004-KF01.png
EP01-S05-SH008-KF01.png
FILM-S07-SH012-KF01.png
```

## 关键帧分镜映射表（必须在生图前先输出）

**示例 A：文戏表演片段（1 张关键帧）**

假设一个 8.6 秒生成片段中，只有“认出信封笔迹后的瞬时泄露”需要静态锚定：

```markdown
| 关键帧 | shot_id | 生成片段 | 绝对/相对时刻 | expression_beat_ids | selected_phase | 命中判定标准 | 画面截取规则 |
|---|---|---|---|---|---|---|---|
| EP01-S03-SH004-KF01 | EP01-S03-SH004 | CLIP-012 / 8.6s | 00:03:23.0 / 3.0s | [EX-S03-B04] | leakage | 决定性瞬间 | 截取呼吸停半拍、视线刚移回、下眼睑短促绷紧的稳定瞬间，不加入后续控制动作 |
```

> 注：该帧在视频阶段作为 3.0 秒的中段锚点，不需要额外补首帧或尾帧。

**示例 B：高信息量片段（3 张关键帧，仅当命中 3 条独立判定标准）**

假设一个生成片段分别命中「空间锚点建立」「道具首次亮相」「情节转折」：

```markdown
| 关键帧 | shot_id | 绝对/相对时刻 | EX IDs | selected_phase | 命中判定标准 | 分镜原文摘要 | 画面截取规则 |
|---|---|---|---|---|---|---|---|
| EP01-S01-SH001-KF01 | EP01-S01-SH001 | 00:00:00.0 / 0.0s | [] | null | 空间锚点建立 | 林远背对镜头推开旧公寓木门 | 人物、木门、斜光尘埃均已到位的稳定态 |
| EP01-S01-SH004-KF01 | EP01-S01-SH004 | 00:00:06.4 / 6.4s | [] | null | 道具首次亮相 | 林远 POV 俯看书架下层的铁盒 | 手持感停稳，铁盒、层板和手部前景清楚 |
| EP01-S01-SH005-KF01 | EP01-S01-SH005 | 00:00:09.1 / 9.1s | [] | null | 情节转折/悬念揭示 | 铁盒表面浮出光斑 | 光斑与铁盒微光清楚、无运动叠影 |
```

> 注：示例 B 的 3 张之所以合理，是因为**三个镜头各自独立命中三条不同判定标准**，而非"因为要有首帧和尾帧所以取 3 张"。若把 KF01 与 KF03 换成不承担独立命中的过渡镜头，即为错误示范。

映射表要点：

- 每张关键帧必须唯一对应 `storyboard.md` 中的一个全局 `shot_id`。
- 「命中判定标准」列**必须来自上文判定标准列表**，写清具体命中项名称；**禁止**写「首帧/尾帧」「叙事开始/结束」「片段开场/收束」等位置性理由。
- 「画面截取规则」写清取该镜头动作/状态到位后的**稳定态**（避免高动态模糊瞬间；动作关键帧的相位选择——蓄势、接触前、命中瞬间、冲击后分离——见 `references/30-scene-keyframe-design.md` 第 17 节），用词保持中性，不必套「起始/中段/落定」的格式化描述。
- **数量与必要视觉状态一致**：同一镜头命中多个标准但只需一个静态状态时合并；不同镜头存在不可替代状态时分别保留。不得按标准条目数机械凑图。

## 分镜绑定硬约束

- 每张关键帧必须绑定已确认的 `storyboard.md` 连续分镜片段，禁止脱离分镜表自由编写新剧情、新构图、新角色动作或新道具状态。
- 关键帧 Prompt 只能补充光影、构图、肢体细节、物理状态等不改变剧情结果的视觉细节；不得新增分镜表中不存在的角色、道具、场景、动作结果。
- 一批生成多张关键帧时，也必须分别列出每张关键帧的分镜映射，不能用一个笼统描述覆盖整批图片。
- 如果只有资产图但没有分镜表，不能直接根据资产图脑补关键帧；必须先补齐或确认分镜。

## 关键帧工具调用硬约束

- 关键帧生成默认使用 GPT Image 2 edit / I2I。
- 只要已有角色、场景、道具资产图，生成关键帧时必须将相关资产图作为工具参考图参数传入，不能只在 Prompt 文本中描述或编号。
- 不建议在已有资产图的情况下使用 `text_to_image` 生成关键帧。
- 每次生成前必须先列出本张关键帧实际传入的参考图清单：动态编号（`[img0]`、`[img1]`、`[img2]`...）、资产名称、URL / 本地路径、用途（identity / scene / props 等职责）。
- 生图 I2I Prompt 只能使用 `[img0]`、`[img1]`、`[img2]`... 引用输入图，不建议使用 `@图片`、`图1`、`参考图1` 等格式。
- 如果找不到必要资产图，必须停止关键帧生成并返回资产阶段补齐或向用户索取资产图，不能自行脑补。

## 缺资产处理

如果缺少必要角色脸部 / 服装、场景空间 / 光影或关键道具资产，停止当前关键帧任务，返回 `assets.md`。

如果缺少对应 `storyboard.md` 分镜原文、片段时间戳不连续、镜头内容缺失，停止当前关键帧任务，返回 `storyboard.md` 补齐或要求用户提供正确分镜。

## GPT Image 2 生图指令撰写规范

每张关键帧先建立 `image_request`，再按 `gpt-image-2-prompt-compiler.md` 的“目标 + 参考图职责 + 保留项 + 编辑项 + 空间/构图 + 单一表演相位 + 固定画风 + 排除项”编译，最终合并为一段连贯指令。

- **编辑目标**：直接说明当前关键帧要基于哪些 `[imgX]` 完成什么画面生成，明确来源图片、目标状态和作用范围。
- **保留项**：明确参考图中必须保持不变的主体身份、角色脸部特征、服装结构、场景空间、构图关系、透视角度、光影方向、材质细节和道具特征。不建议只写"保持不变""其他不变""参考原图"。有角色参考图时，按 `references/30-scene-keyframe-design.md` 第 7 节声明该图为 canonical identity source：保留脸、年龄、发型、物种特征、体型、服装结构、武器，不继承参考图的版式、标签、摄影棚背景、临时表情、镜头畸变或偶发色偏。
- **编辑项**：逐项写清需要新增、替换、重绘、重排或状态变化的对象。有 EX 节拍时表情只采用 `selected_phase` 的可见线索，不能把整个 `prompt_ready_zh` 跨相位塞进静帧。
- **空间线性描述**：按从背景到主体、从主体到局部、从主要编辑区域到次要编辑区域的顺序描述画面；每个区域写清位置、原参考内容、保留项、编辑动作、目标结果和视觉约束。场景空间按七层结构（前景遮挡 → 地面路径 → 主体动作 → 次级叙事 → 主地标 → 远景尺度 → 天空空气）组织。
- **多图约束**：若传入多张参考图，必须分别说明 `[img0]`、`[img1]`、`[img2]` 的用途和保留内容，不建议使用"同上""其余图片一样处理"等概括。
- **文字约束**：如关键帧涉及可见文字，必须逐条写清原文案与目标文案，所有文字用中文双引号 `""` 框定。
- **风格与质量约束**：写清整体风格、光线、色调、材质、阴影、真实度和融合要求，确保修改区域与参考图自然融合。**关键帧 Prompt 画风段必须与 `references/00-visual-contract.md` 第 1 节固定画风 DNA、`assets.md` 全资产统一锚点一字不差**；禁止简化为"电影风格""高级质感"等模糊写法，也不得擅自替换为其它画风。
- **画幅比例**：每张关键帧 Prompt 结尾必须以比值格式写清画幅比例，例如 `9:16` 或 `16:9`。

### 方向性物体空间关系规则

有些物体本身具有明确方向，关键帧生成时极易只出现物体但方向错误。凡画面涉及以下方向性物体，Prompt 必须写清空间关系：

- 手机屏幕、平板电脑、电脑显示器、画纸、镜子、书本、车门、武器、杯子把手。

必须补充：
- 物体朝向谁。
- 人物看向哪里。
- 手部如何接触物体。
- 观众能看到物体的哪一面。
- 物体与人物之间的距离。

**方向关系公式：**
`人物朝向 + 视线方向 + 物体朝向 + 手部动作 + 画面可见的物体面 + 物体与人物距离`

**稳定写法示例：人物看 iPad**
- 容易翻车：`一个人在医院用 iPad 看剧。`
- 稳定写法：`高预算电影视觉开发，精致克制的半写实动漫设计（固定画风 DNA 全段），医院病房里，一个年轻人靠坐在病床上，双手拿着一台平板电脑。平板屏幕朝向人物，屏幕背面朝向画面外侧，人物低头注视屏幕，中景侧面拍摄。`

**稳定写法示例：孩子画画**
- 容易翻车：`一个正面拍摄的画画小男孩。`
- 稳定写法：`高预算电影视觉开发，精致克制的半写实动漫设计（固定画风 DNA 全段），侧面拍摄一个小男孩坐在桌边画画，画纸平放在桌面上，画纸顶部朝向男孩，底部朝向画面下方。男孩低头看着画纸，右手握住彩色铅笔。`

注：这类关键帧不必强行展示屏幕内容、画纸内容或镜中内容；优先确保方向、视线、手部接触和画面可见面正确。

## Prompt 公式

按以下顺序写（对应 `references/30-scene-keyframe-design.md` 第 18 节编译顺序）：

```text
[固定画风 DNA]，保留[imgX]的必要角色/场景/道具特征不变；对[imgX]和其他输入图中的指定对象进行新增/替换/重绘/状态调整；叙事时刻与情绪；镜头（景别/机位/焦段/焦点）；按空间线性顺序描述背景、主体、局部和道具的最终画面；统治性主光与主亮区；空气介质与色板；材质；保持光影、透视、材质、边缘融合一致；连续性锁定项；画幅比例。
```

有结构化表演输入时，把公式中的“叙事时刻与情绪”替换为：`shot_id + expression_beat_ids + selected_phase + 该相位 visible_cues + exclusions`。`internal_state` 不进入 Prompt。

**内部推演的画面描述和生图 Prompt 仅用于调用生图工具，不输出给用户。** 面向用户只展示关键帧名称、命中的判定标准、简短剧情说明和生成的图片。

**生图 Prompt 推演示例（内部使用）：**
*(执行逻辑：选出场景全景图作为 `[img0]`，林远四宫格资产图作为 `[img1]`)*
高预算电影视觉开发，精致克制的半写实动漫设计，精致克制的半写实动漫面孔，真实三维体积经过高级二维动画审美提炼，2.5D 数字绘画与电影 CG 渲染融合，painterly realism，PBR-informed 材质分离，戏剧性明暗对照，受控体积光，干净明暗分组，平滑过渡，精炼边缘，分层空气透视，精致剧场级动画完成度，AAA 级影视美术品质。使用[img0]作为大厅 scene 真值源，保持旋转楼梯、地面、空间透视与世界光向；使用[img1]作为沈砚 identity 真值源，只继承脸、成年年龄表现、发型、体型和服装结构，不继承四宫格版式、摄影棚背景与中性表情。生成 EP01-S03-SH004 的关键帧，绑定 EX-S03-B04，`selected_phase: leakage`：中近景，沈砚位于画面左侧三分之一，身体仍朝向林晚，视线刚从她手中的信封移回她的脸，呼吸短暂停住，下眼睑短促绷紧，其余面部保持克制；不要加入之后压平嘴角的控制动作或浅呼吸残留。保持既定主光、接触阴影、人物身份和道具位置，画面无字幕、Logo、水印和无关人物，9:16。

## 构图规则

### 竖屏 `9:16`适用于短剧，适用于移动端场景

- 人脸和上半身必须在安全区内。
- 关键道具放在画面中部或下三分之一安全区。
- 双人对话保持左右空间关系。
- 避免文字、水印、Logo 和无意义符号。

### 横屏 `16:9`适用于pc端、电视电影等场景

- 使用三分法构图。
- 人物视线前方保留呼吸空间。
- 用前景 / 中景 / 远景建立纵深。
- 对话或对峙场景保持 180 度轴线（轴线定义与越轴规则见 `references/40-continuity-and-handoff.md` 第 6 节）。
- 重要元素不要贴边。
- 避免文字、水印、Logo 和无意义符号。

## 连续性检查

交接前检查（量化质量门控按 `references/00-visual-contract.md` 第 14 节执行）：

- 每张关键帧已列出关键帧分镜映射表，且能追溯到 `storyboard.md` 的集数、章节、片段、镜头编号和分镜原文。
- 每张关键帧严格遵循对应分镜，没有新增分镜表中不存在的剧情、角色、道具、场景或动作结果。
- 每张关键帧命中的判定标准来自本文件"关键帧判定标准"列表，不得自造。
- **关键帧数量与独立状态一致**：默认 1 张，通常不超过 3 张；超过时优先拆分生成片段。若映射表行数超过实际独立命中数，视为凑数套模板，必须回炉删减。
- 有 `expression_handoff` 时，每张关键帧的 EX ID、可见性结论和 `selected_phase` 已写入 ShotSpec；未使用相位仍由 Seedance 时间线负责，不得在静帧中叠加。
- 角色外观、发型、服装和身体状态在连续片段之间一致（与 CharacterBible/BodySpec 对齐）。
- 道具在正确人物手中或正确场景位置，状态突变前后能自洽。
- 场景光影、时间、天气和色温逻辑连续（与 SceneBible/VisualBible 的世界光向一致）。
- 人物脚底与地面接触真实，主光、投影、轮廓光、材质高光与体积光同向（视觉合同第 3 节）。

一片段/一章节的关键帧确认后，交接至 `prompt.md`；除非用户明确要求批量处理整集所有片段。
