# 超巨构尺度导演

把“很大的东西”转成一眼成立的**尺度事实**。先建立宏观形体、空间关系和世界事件，再分配细节、光、材质与氛围。不要用尺寸数字、密集纹理或微小人物单独冒充巨构感。

## 1. 判定任务类型

先选一个主分支；混合题材只设一个主分支，其余作为约束：

- **建筑 / 基础设施**：巨构、城市器官、纪念性空间、公共设施。
- **巨型器物**：机械、遗迹、雕塑、飞船、未知装置。
- **巨型生物 / 实体**：巨兽、神兽、外星生命、克苏鲁实体。
- **纯有机巨物**：用户明确要求完全陌生、完全生物性、不可借用现成物种时启用严格分支。

完成条件：用一句话写清“它是什么、凭什么巨大、在这一刻发生什么”。

## 2. 锁定灵魂、机制与决定性事件

每张图只锁定：

1. **一个治理轮廓**：缩略图下仍可辨认的主形；
2. **一个世界机制**：建筑如何被使用，器物如何运行，实体如何影响环境；
3. **一个决定性事件**：让尺度从静态尺寸变成故事的瞬间；
4. **一个情绪命题**：敬畏、召唤、庇护、压迫、陌生或希望等。

巨构先有“灵魂”，再有功能和纹理。事件必须改变空间中的光、物质、人流、天气或地形，而不是只加姿势与特效。

完成条件：四项可以各用一句话回答，且彼此不重复。

## 3. 建立尺度证据链

至少使用两类彼此独立的证据；三类通常最稳：

- **可识别基准**：人、列车、窗、门、桥跨、船、树、城区等。
- **使用与流线**：道路、梯道、维护层、公共活动、运输或迁徙。
- **环境互动**：压弯云层、截断河流、投下地形级阴影、改变浪场或风场。
- **大气纵深**：空气透视、雾层切片、散射衰减、跨尺度遮挡。
- **构造模数**：门洞、接缝、骨板、血管束、支撑与受力分区。
- **遮挡与视差**：前后层互相遮挡、跨越地平线、轮廓离框。

基准物应与主体处在可比较的深度关系。近处大人物、远处小建筑不是可靠的尺度证明。人物可提供尺度，但不得成为画面的英雄主角，除非用户明确要求。

完成条件：能指出每个证据在画面中的位置，并说明它不依赖另一证据也能成立。

## 4. 选择尺度构图模式

根据主形选择一种主模式，不机械套“裁掉建筑”：

- **多边出框**：主体从两至三边离开画框，适合压迫、接近与无法容纳感。
- **一轴完整、他轴无尽**：完整展示高度或截面，同时让长度、深度或翼展离框。
- **完整剪影 + 环境级留白**：让全身或全貌可读，再用地平线、天气与巨量空域证明尺度；适合巨兽与独特轮廓。
- **可居住剖深**：通过内外空间、层层通行和远近活动显示“建筑内部也是世界”。

保留足够安静区域，让主形呼吸。留白比例是构图结果，不是固定百分比。

完成条件：主模式与主体的治理轮廓互相加强，不靠填满画面制造“大”。

## 5. 选择相机，而不是迷信焦段

- **长焦压缩**：同深度基准与主体并置、层层轮廓叠压、远距离观察。
- **超广角纵深**：前景进入、空间穿行、从近处结构通向地平线。
- **高位 / 航拍**：揭示占地、路径、地貌代价；必须用天气、阴影或活动避免沙盘感。
- **平视远眺**：建立地平线级尺度与文明视角。

先确定观察者的位置、距离和视线高度，再决定镜头语言。避免靠近小物体后仰拍造成“近大远小”的假巨构。

完成条件：相机位置能够解释所有主要遮挡、透视和尺度基准。

## 6. 执行反碎层级

按**大形 → 中形 → 少量细形**工作：

- 大形约占视觉信息的七成：主轮廓、负空间、三到四块价值质量。
- 中形承担结构与叙事：入口、桥跨、肢体、器官区、公共流线。
- 细形只放在焦点、受力点、接触区和尺度基准附近。

这些比例是诊断启发，不是机械配额。远景降低细节和对比，不等于全图模糊；主体轮廓、决定性事件和关键尺度证据保持清楚。

完成条件：缩略图先读到主形和事件，放大后细节才提供第二层信息；不存在全画面均匀纹理地毯。

## 7. 统一光、材质、空气与物理

只设一个主导光事件，写清：

```text
source → path through medium → receiver → shadow / bounce response
```

- 光比服务尺度：大阴影面与受光面先分开，再在局部揭示材质。
- 材质服务因果：重量、受力、接缝、侵蚀、径流、磨损、湿度或生长方向可读。
- 大气只在介质支持时散射：雾、雨、尘、烟、潮气或云层；不要把体积光当装饰线。
- 空间越远，优先降低对比与细节；只有介质支持时才同时降低饱和。
- 建筑和巨物要有可信支撑、负载路径或生长逻辑；奇观不能悬空于解释之外。

完成条件：光源位置、阴影方向、材质响应和空气层次不互相矛盾。

## 8. 保留媒介，不强制写实

尺度方法独立于画风。摄影、电影概念图、水墨、丝网版画、赛璐璐、木版画、平面海报都可成立：

- 写实媒介主要用透视、空气、材质和光比证明尺度。
- 平面媒介主要用轮廓、裁切、面积对比、重复模数和负空间证明尺度。
- 写意媒介主要用气势、虚实、墨色或色面层级证明尺度。

不要自动添加 `8k`、`masterpiece`、`UE5`、CG 或摄影词。用户要求的媒介优先。

完成条件：尺度机制已翻译进媒介语言，而不是用另一种画风覆盖用户要求。

## 9. 分支规则

需要怪物、克苏鲁或纯有机细则时，读取 [references/field-guide.md](references/field-guide.md)。

- **克苏鲁实体**：陌生感来自不可完整解释的身体逻辑与环境后果，不来自满屏眼睛和触手。
- **纯有机巨物**：只有用户明确要求时，才禁止现成物种类比和身体上的无机材质；尺度参照优先使用建筑、车辆、船或基础设施。

## 10. 批量差异化

系列保持共同 DNA：媒介、色彩系统、时代规则或同一文明逻辑。每张至少改变三项：

- 治理轮廓；
- 世界机制 / 公共功能；
- 构图模式与留白方向；
- 相机位置与纵深组织；
- 尺度证据组合；
- 决定性事件；
- 环境互动。

人物、台阶、中央门洞、正中神光和红黑巨构不得成为每张的固定公式。

完成条件：去掉背景后，各张仍能由主体轮廓和机制区分，不能只是换景。

## 11. 输出结构

当用户要方向、提示词或重做方案时，按所需详细度输出以下模块：

1. 核心命题与决定性事件；
2. 主体轮廓与世界机制；
3. 尺度证据链；
4. 构图模式、相机与空间层次；
5. 光、材质、空气与物理；
6. 媒介翻译与反碎约束；
7. 批量时的差异矩阵。

提示词只写会改变画面的条件；避免质量标签、同义堆叠和负面词清单。模型专用语法交给对应适配层。

## 12. 最终验收

交付前逐项回答“是 / 否”：

- 缩略图下一眼先读到巨大的治理轮廓？
- 它有独立的灵魂、机制和事件，而非普通主体放大？
- 至少两类独立尺度证据成立？
- 基准物与主体的深度关系可比较？
- 构图不是近大远小的假尺度？
- 安静区、大形、中形和细形有明确层级？
- 主光路径、光比和阴影方向成立？
- 材质、受力、生长或环境互动有因果？
- 远景是逻辑简化，而不是全糊或全碎？
- 用户要求的媒介保持完整？

任一前三项为“否”，先重建主形、构图或尺度证据；不要通过追加细节修补。

## 边界与协作

- 世界观和社会机制不足时，交给 `$world-visual-development-director`。
- 整体审美、风格纯度和画面美感由 `$high-aesthetic-image-direction` 负责。
- 材质、光路、介质与干净画面可与 `$im2-clean-image` 组合。
- 本 Skill 不负责模型调用、资产归档或自动重试。实际生成时遵守当前路由、预检和生成资产归档门。
