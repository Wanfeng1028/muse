# v2.1 独立提示词交付修正

检查范围：当前SKILL入口、全部活动规范和模板、资产与H3编译出口、三套示例及其实际导出文件。历史sources层保留原文和哈希，不作为当前可提交提示词。

## 确认的问题与修复

| 实际问题 | 修复 |
|---|---|
| 旧入口偏重数据和脚本，没有面向使用者的完整指南 | 新增使用指南，说明自然语言调用、每阶段产物、模型模式、上传与复制步骤 |
| BodySpec保留M01/A–I等内部索引，缺乏统一最终输出约束 | 增加72号交付规范、模板展开描述与代码拦截；不臆造人格字母含义 |
| 文戏第二个独立片段只写同一桌子／不变光线，没有完整身份重建 | 编译器按本段角色与场景补prompt_description，并消费每镜state_description |
| 资产post-hook没有要求最终prompt，更没有可提交文件 | 要求实际prompt与引用策略；新增compile_assets，生成正文、上传清单和带哈希素材副本 |
| 图像参考关系没有上传编号与不继承范围 | 每项必须含image/file/role/subject/preserve/exclude；缺图或未绑定图号拒绝导出 |
| H3引用内容Subject与上传Picture来源难以分开 | 增加可选subjects及source_only来源项，遵循本机H3指南的内容／来源定义 |
| H3索引缺用户可读的每段上传说明 | 增加UPLOAD.md；正式文本保持规范三／六字段，不混入操作说明 |
| 冷档案只重定位视频参考图 | 同时归档并恢复asset_cards的参考图，恢复后资产图提示词可重新导出 |

规范保留H3合法的Picture／Subject／S说话人标签，原对白和屏幕文字按字面保留。阻止的是未展开的内部检索码，不是删除所有字母和数字。

## 验证证据

新增test_prompt_delivery.py五项公共交付合同测试；原有test_contracts.py五项回归保留。全部10项通过，覆盖独立第二段、代号和缺图阻断、绑定展开、合法引用、素材复制与冷档恢复重导出。

最终包检查比较每个导出prompt与当前数据编译结果，比较素材哈希，核对上传清单、文档链接、语法、原始来源完整性及三套生产数据。当前机器报告见[package-acceptance.json](package-acceptance.json)。原132条媒体未改变，不重复执行其已通过的媒体检测。

最终逐条内容检查覆盖3条图像正文和4段H3正文：人物／场景具体描述、当前状态、参考文件职责、左右位置、对白和声场。机甲与巨构参考的是构图灰模，身份来自完整文字；文戏T2VA不依赖任何未上传图。

## 实际边界

这是提示词规范和导出链路验收，不是付费生成验收。机器规则能拦截已知ID、常见身材／情绪／状态码、占位符和隐含前文语句，无法证明任何任意自然语言都绝无歧义；主导演仍须逐条独立阅读，不得宣称扫描可替代语义审查。真实脸部连续性、动作和画质仍需生成后检查。
