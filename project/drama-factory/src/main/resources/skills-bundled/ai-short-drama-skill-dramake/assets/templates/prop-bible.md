# 重复道具圣经

凡是出现两次以上、跨场景传递、参与关键动作或承载文字/Logo 的道具，先建立本文件和母版，再进入分镜与视频生成。

## 身份

- `prop_id`：
- 名称 / 剧情功能：
- 首次出现 / 预计重复场景：
- 所有者 / 使用者：
- 是否跨场景：是 / 否
- 是否承载精确文字、数字或 Logo：是 / 否

## 长期几何与材质锁

- 正面 / 背面 / 左侧 / 右侧 / 俯视 / 3/4 母版：
- 尺度参照与关键尺寸：
- 轮廓、比例、厚度与部件数量：
- 精确数量与内容物身份（盘子数、食物种类/数量、容器内外）：
- 正面/背面/顶部朝向标记与拿取侧：
- 材质、颜色、反射、磨损与接缝：
- 可动件、铰链、按钮、盖子、绑带与连接方式：
- 禁止变化：

使用用户选择并实测可靠的高保真图像生成/编辑路线（例如 GPT Image 类模型）制作中性光、干净背景、无戏剧透视的道具母版。母版通过后固定 `prop_id` 与文件，不在每个场景重新设计。

## 文字与图案分层

- 精确文字原文：
- 字体 / 字重 / 颜色 / 排版 / 方向：
- `text_plate_id` 与透明 PNG / 矢量母版：
- 在道具上的位置、尺寸、透视与遮挡：
- 视频策略：留白后期合成 / 已实测可用的参考纹理 / 不允许直接生成
- 合成后的验收帧：

几何母版与文字图层分开保存。视频模型只负责道具、动作、遮挡与光照；精确文字默认用同一 `text_plate_id` 后期跟踪合成，避免每帧重新生成导致变形或改字。
