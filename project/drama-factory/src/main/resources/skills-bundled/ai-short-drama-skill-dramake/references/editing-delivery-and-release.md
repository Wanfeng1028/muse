# 剪辑时间线、标准化与发布交付

“片段已生成”不是“影片已完成”。使用 [edit-timeline.csv](../assets/templates/edit-timeline.csv) 把已验收候选的真实可用区间落到时间线，并保留回到剧情段、任务和 QA 的来源链。

## 从候选到时间线

每个时间线事件记录源文件、`source_in/source_out`、`timeline_in/timeline_out`、速度、画幅变换、转场、音轨、字幕/艺术字 ID、调色和来源任务。只允许使用已验收候选或明确批准的偏差；不能把整条生成结果默认全用。

保留剪辑余量，但删除坏首尾帧、提示词余波、动作重复和静止拖尾。相邻事件检查动作阶段、屏幕方向、视线、声场和信息是否重复。转场必须服务时间、空间、动作或情绪变化。

## 交付标准化

进入正式拼接前，把代理文件或最终源统一到项目交付配置：

- 分辨率、像素比例、色彩空间/传递、帧率策略和音频采样率；
- 方向元数据与真实画面一致，禁止依赖播放器自动旋转；
- 变帧率素材先决定保留时间基还是转恒定帧率；
- 画幅转换使用批准的构图，不机械中心裁切；
- 字幕、艺术字、Logo 和 UI 使用独立可编辑层；
- 对白、环境、音乐和效果保持分轨，终混后再制作发布母版。

统一编码不等于无脑把所有素材降成同一个低规格。先确定剪辑工作格式和最终发布配置，再做最少必要转换。

## 可编辑交付

除成片外，至少保留：

- 项目内相对路径或可重定位媒体清单；
- 时间线事件与素材映射；
- 字幕文本、时间码、说话人和样式 ID；
- 音频 stem、响度目标和音乐授权信息；
- 封面、标题层、横竖版本和安全区；
- 模型/任务/候选/QA 来源链，不含密钥和临时签名地址。

可按用户剪辑软件生成导入包，但先输出服务商中立的时间线清单，避免项目被单一格式锁死。

## 发布前技术门

自动检查：媒体缺失、负时长/重叠、时间线空洞、分辨率/帧率/色彩不一致、静音或削波、响度越界、黑帧、冻结帧、重复尾部、字幕越界和封面安全区。

人工检查：冷观众理解、手机观看亮度、字幕可读性、音乐起伏与对白避让、第一帧钩子、最后一拍、循环播放接缝、横竖版本构图和平台压缩后的细节。平台上传成功不代表内容通过。
