# 空间地图、走位与世界状态

角色一致不等于场景连续。门、镜子、摩天轮舱、巨物、前后景和移动路线若没有稳定空间关系，镜头会出现瞬移、错误出口、复制物、尺度漂移和无意义运镜。高风险场景使用 [spatial-plan.csv](../assets/templates/spatial-plan.csv)。

## 先建空间锚点

每个地点定义少量命名锚点：入口、出口、中心、固定装置、危险边界、反射面、遮挡物、可移动道具停放点和可用机位区。锚点记录：

- 与地点原点或其他锚点的前后左右、高低、距离和连通关系；
- 固定/可移动、可占用主体、可见性和遮挡规则；
- 真实尺度参照，例如门高、座舱宽、角色肩高或地标尺寸；
- 状态 ID 和已批准参考。

不要求伪精确的三维坐标；相对关系必须足以判断“从哪里来、往哪里去、谁遮住谁、镜中应出现什么”。真实地点优先从已核实照片/视频建立锚点，不凭想象改造基础地理。

## 每段写走位状态

每个剧情段记录主体的 `start_anchor → path_anchors → end_anchor`、朝向、视线目标、接触道具、相机锚点、屏幕方向、进入状态和退出状态。动作提示词从这里编译，不在生成时临时发明位置。

路径必须解释设施使用原因：角色为什么进入、为何坐上设备、哪条信息或危险迫使它移动、完成后从何处离开。景观切换必须是选择或后果，不是素材展示。

## 镜面、巨物与异常空间

- 镜面建立反射拓扑：真实主体、反射主体、镜面法线、应出现/不得出现的对象和时延规则。
- 巨物至少用两个尺度锚：角色/门/车厢等熟悉物体 + 环境遮挡或透视消失；只写“巨大”不够。
- 重复单元要有差异规则：位置、状态、姿势、光照或破损不同，避免复制粘贴；角色/怪物数量单独锁定。
- 超现实空间可以违反现实，但必须先写唯一世界规则和可观察后果。规则不能为每个镜头临时变化。

## 空间反向检查

生成前从计划的退出状态倒推：

1. 终点是否能从起点沿连通路径到达；
2. 动作、世界向量、屏幕向量和机位是否一致；
3. 提示词开头是否与已验收父段实际尾部一致；
4. 遮挡、反射、出入口、道具接触和角色数量是否成立；
5. 下一段能否从本段终点无解释跳变地接续。

发现冲突先改走位或镜头，不靠负面词硬压。若镜头必须越轴，提供中性过渡、明确地标或可见转向。
