# 美感：让画面「高级」的规则

美感不是玄学，大部分是一些可以照做的规则。先守规则，熟练之后再有意识地打破。

## 1. 颜色

- **少。** 一个背景色、一个前景色、一个弱化色、**一个强调色**。强调色只给最重要的东西用，用得越少越有力。
- **60-30-10**：主色（通常是背景）占约 60%，辅色约 30%，强调色约 10%。
- **不要纯黑纯白。** 用带一点色调的深色和米白，比如：
  - 暖深色 `#0E0C0A`、冷深色 `#0B0D12`、中性深色 `#111114`
  - 米白 `#F5F2EA`、冷白 `#EEF1F5`、纸白 `#F3EFE6`
- **颜色要有语义，并且全片统一。** 比如「太阳」这个概念从头到尾都是橙色，观众不看字也认得出来。
- **渐变要选相邻的颜色**，并且用 oklch 插值，避免中间出现灰扑扑的过渡：`linear-gradient(in oklch, #FF8A3D, #FFD166)`。彩虹渐变几乎总是廉价的。
- **对比度**：正文和背景至少 4.5:1，大标题至少 3:1。
- **色温讲情绪**：冷色是理性、疏离、夜晚、科技；暖色是温度、人、回忆、希望。整部片子的色温变化，本身就是一条情绪曲线。

按情绪选配色的起点：

| 情绪 | 配色方向 |
|---|---|
| 冷静、科技 | 深蓝黑底，冷白字，一个青色或电光蓝强调 |
| 温暖、治愈 | 米白或暖灰底，深棕字，一个橙或杏色强调 |
| 高级、克制 | 近黑底，米白字，强调色是低饱和的金或红 |
| 活力、年轻 | 高饱和的撞色，但限制在两个主色加黑白 |
| 复古 | 褪色的黄、绿、橙，加颗粒和暗角 |
| 紧张、危险 | 黑底，红色强调，高对比 |

## 2. 构图

- **留白。** 高级感最直接的来源。主体占画面的比例宁小勿大，除非是故意的「满屏压迫感」。
- **对齐到网格。** 横屏常用 12 栏网格，页边距约为画面宽度的 5% 到 8%。所有元素的边缘要对齐到网格线或者彼此对齐。
- **三分法**：主体放在三分线的交点上，画面更有张力、更自然。
- **居中对称**：用于庄重、有力量、仪式感的时刻（片名、结论、产品亮相）。
- **视觉层级只有三级**：第一眼看什么，第二眼看什么，第三眼看什么。超过三级就是乱。
- **视觉重心要平衡**：左边一个大元素，右边就用几个小元素或者一段留白平衡。
- **视线引导**：用线条、人物视线、箭头、运动方向，把观众的眼睛引向主体。
- **安全区**：重要内容离画面边缘至少 5%；竖屏还要避开平台的遮挡区（见 `routing.md`）。

## 3. 质感：电影感来自「不完美」

太干净的画面像 PPT。叠一点质感，画面会立刻有「材料感」。模板的 `Texture` 组件提供颗粒和暗角。

| 质感 | 做法 | 强度建议 |
|---|---|---|
| 胶片颗粒 | SVG `feTurbulence` 噪声，每 2 帧换一次种子，`overlay` 叠加 | 若隐若现，暂停时能看到、播放时感觉不到 |
| 暗角 | 径向渐变，四角压暗 | 边缘压暗 20% 到 40% |
| 辉光 | 同一文字或图形叠加一两层模糊的副本（`drop-shadow` 或 `text-shadow`） | 只给发光的东西用 |
| 色差 | 画面复制出红、青两份，各偏移 1 到 3px，`screen` 混合 | 故障、复古、冲击时刻 |
| 扫描线 | 横向细条纹的重复渐变 | 复古屏幕、终端 |
| 网点 | 圆点图案或 `radial-gradient` 重复 | 拼贴、波普、印刷感 |
| 纸张纹理 | 纸张图片或噪声，`multiply` 叠加 | 拼贴、手绘、国风 |
| 漏光 | 大尺寸的橙红色径向渐变在画面边缘缓慢移动，`screen` 叠加 | 电影感、回忆、温暖 |
| 片门抖动 | 整个画面每帧随机偏移 0.5 到 1px | 老电影、胶片感 |
| 黑边 | 上下加黑条到 2.39:1 | 电影感 |

**质感是调味料。** 所有质感加起来，要让观众「感觉」到，而不是「看见」。

## 4. 纵深

- 前景、中景、背景分层，前景可以虚化（模糊 4 到 12px）、放大、半出画。
- 远处的东西更小、更暗、更蓝、更模糊。
- 阴影要统一光源方向。阴影宁淡勿重：大范围、低透明度的柔和阴影，比小而黑的阴影高级得多。

## 5. 一致性：视觉系统

把颜色、字体、字号、间距、圆角、阴影、动效曲线、质感参数全部写进 `theme.ts`，每个镜头只从这里取值。**一部片子看起来「专业」，主要是因为它的每个细节都遵守同一套规则。**

## 6. 高级感清单

- [ ] 颜色不超过 4 个，强调色只用在最重要的地方。
- [ ] 没有纯黑、纯白、默认蓝、饱和的纯红纯绿。
- [ ] 字体不超过两种，字重有对比，标题字距有讲究。
- [ ] 留白充足，元素对齐。
- [ ] 动画用缓出曲线，速度偏慢而干脆，没有线性动画。
- [ ] 有若隐若现的质感。
- [ ] 每个镜头只有一个主角。
- [ ] 所有细节遵守 `theme.ts`。

## 7. 廉价感的来源（看到就改）

默认字体、字体太多、纯色高饱和、彩虹渐变、阴影太黑太重、元素挤满画面、每个元素都在动、线性动画、弹跳过度、花哨转场（3D 立方体翻转、百叶窗）、到处是图标和 emoji、文字特效（描边加阴影加渐变加发光同时用）、所有东西都居中、没有留白、质感太重（颗粒糊成一片）。
