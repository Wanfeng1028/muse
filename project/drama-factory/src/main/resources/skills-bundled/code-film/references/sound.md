# 声音设计：音画为什么能配合得好

观众对声音的敏感度远超想象。同一段画面，换一套音效，质感能差一个档次。但你听不到声音，所以这里的做法是**用规则和数据保证正确**，再请用户用耳朵确认。

## 1. 架构：一张事件表驱动一切

音效事件写在 `storyboard.json` 每个镜头的 `events` 里，模板里的 `SfxTrack` 组件会自动把它们放到正确的帧上：

```json
"events": [
  { "at": 0,   "sfx": "whoosh", "align": "peak" },
  { "at": 12,  "sfx": "hit" },
  { "at": 90,  "sfx": "riser", "align": "end", "volume": 0.6 },
  { "at": 90,  "sfx": "boom" }
]
```

- `at`：镜头内的相对帧，也就是**画面事件发生的那一帧**（落定、撞击、揭示）。
- `align`：音效的哪个点对准 `at`。`start` 是音效开头，`peak` 是音效最响的那一刻，`end` 是音效结尾。不写时使用 manifest 里该音效的推荐值：whoosh 类对齐峰值，riser 和 reverse_swell 对齐结尾，boom、glitch、shimmer、drone 等对齐开头。
- `volume`：0 到 1，默认 0.8。
- `rate`：播放速度，默认 1。同一个音效反复出现时，给 0.94 到 1.06 的不同值，避免听起来像复读机。

画面动画里的关键帧，也应该从同一个常量取值（比如 `const LAND = 12`，动画和事件都用它），这样改一处，两边一起变。

## 2. 对齐规则：对准的是「峰值」，不是「开头」

这是新手最常犯的错误。

- **whoosh（呼啸）**：峰值在中间。要让峰值对准**运动速度最快的那一帧**（缓出动画一般在开头附近，缓入缓出在正中）。从动画开头开始播放，听起来会慢半拍。
- **riser（上扬蓄力）**：结尾对准揭示的那一帧，用 `"align": "end"`。它会提前几秒开始播放，跨到上一个镜头也没关系。
- **reverse_swell（反向吸入）**：同上，结尾对准撞击。
- **hit、tick、pop**：峰值几乎就在开头，对准落定帧即可。
- **boom**：冲击在开头，但混响会让能量峰值推后约 0.3 秒，所以它默认按开头对齐，让冲击瞬间对准揭示帧。

模板自带的音效库在 `public/sfx/manifest.json` 里记录了每个音效的时长和峰值时间，`SfxTrack` 会自动换算。你自己加的外部音效，要用 `synth_sfx.py --measure <文件>` 测出峰值，再补进 manifest。

## 3. 什么画面配什么声音

| 画面动作 | 音效 |
|---|---|
| 物体快速移动、飞入、甩镜头 | whoosh（快的用 whoosh_fast） |
| 落定、撞击、盖章、大字砸下 | hit |
| 最重要的揭示、片名、高潮 | boom 或 sub_drop，前面配 riser 或 reverse_swell |
| 文字逐字出现、UI 点击、数据跳动 | tick、click（不要每个字都配，一组配一两个） |
| 小元素弹出、气泡 | pop |
| 故障、干扰、切换失真 | glitch |
| 光、魔法、闪亮、希望 | shimmer |
| 铺底、空间感、紧张 | drone（环境底噪） |

**不是每个动作都要配声音。** 只给主角动作配，配角动作靠音乐带过去。一部 60 秒的片子，音效事件一般在 10 到 30 个之间。全片最好只用 **4 到 6 种**音效，形成统一的「声音系统」，就像视觉系统只用几种颜色一样。

## 4. 音乐的音量自动化

- **铺底音乐**默认音量 0.6 到 0.8。有旁白时压到 0.25 到 0.35（约减 8 到 12 dB），旁白之间的空隙可以回升。
- **淡入**：0.5 到 1.5 秒；**淡出**：1.5 到 3 秒，在乐句边界上。
- **高潮前抽空**：揭示前 0.5 到 2 秒把音乐压到很低甚至静音，揭示时和 boom 一起砸回来。
- 在 Remotion 里，音量可以写成帧的函数：

```tsx
<Audio
  src={staticFile('music/bgm.wav')}
  volume={(f) =>
    interpolate(f, [0, 30, 1500, 1530, 1560, 2600, 2700], [0, 0.8, 0.8, 0.05, 0.8, 0.8, 0], {
      extrapolateLeft: 'clamp', extrapolateRight: 'clamp',
    })
  }
/>
```

## 5. J 切和 L 切：让转场更顺

- **J 切**：下一个镜头的声音比画面**早 0.3 到 1 秒**进来。观众先听到，再看到，转场会显得很自然，还能制造期待。
- **L 切**：上一个镜头的声音**延续**到下一个镜头里。适合情绪的延续。
- 电影感的片子大量使用 J 切和 L 切；科普和宣传片在换段落时用 J 切特别好用。

## 6. 混音层级与响度

优先级从高到低：**旁白 > 关键音效 > 音乐 > 环境音。** 同一时刻只能有一个主角声音。

交付标准：
- 整体响度 **-14 LUFS**（抖音、B 站、YouTube 等平台的常见标准），真峰值不超过 **-1 dBTP**。
- 用 `scripts/finalize.py` 做两遍响度标准化，它会自动测量并校正。
- `scripts/qa_video.py` 会报告整体响度、峰值，以及异常的长静音。

## 7. 旁白

- 配音按句生成，每句一个文件，方便单独重做和调整间隔（见 `ai-assets.md`）。
- 句子之间留 0.3 到 0.8 秒的气口，段落之间留 1 到 1.5 秒。
- 旁白的开头一般在镜头切入后 0.2 到 0.5 秒，给眼睛一点时间先看画面。
- 旁白说到关键词的那一刻，画面上的关键元素要同时出现或高亮。

## 8. 素材来源

- **纯代码**：`python <skill>/scripts/synth_sfx.py --out public/sfx` 生成 13 种常用音效和 manifest（模板已经自带一份）。配乐用 `synth_music.py`。
- **外部音效库**：Pixabay、Freesound 等，注意授权协议，CC-BY 需要署名。
- **AI 音效**：如果用户有这类工具，描述要具体，比如「短促、干燥、低频的木质撞击声，0.3 秒」。

## 9. 声音自检

- [ ] 每个音效的对齐方式正确（whoosh 对峰值，riser 对结尾）。
- [ ] 主角动作有声音，配角动作没有抢戏的声音。
- [ ] 全片音效种类不超过 6 种，重复的音效有细微的速度变化。
- [ ] 有旁白时，音乐已经压低。
- [ ] 高潮前有抽空或蓄力。
- [ ] 整体响度约 -14 LUFS，没有削波。
- [ ] 请用户戴耳机听一遍，确认没有刺耳、太响或听不清的地方。
