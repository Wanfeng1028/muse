# 讲故事：片子的灵魂

代码能把任何画面做出来，但它回答不了「做什么画面」。这份文档讲的就是怎么回答这个问题。

## 1. 立意：一句话说清这部片子

动手前，必须能写出这样一句话：

> **关于【主体】，揭示【一个反常识的真相 / 一种被忽略的感受】，让观众最终【感受到 / 明白】【某件事】。**

例：
- 《我从未见过太阳》：一个知道太阳所有数据却从没见过它的 AI，发现人类也从没见过「此刻」的太阳，它是通过人认识光的。
- 科普「为什么天是蓝的」：天空的蓝，其实是阳光被空气「打散」后，蓝光跑得到处都是。
- 产品片：以前做这件事要 3 小时，现在只要一句话。

检验标准：
- **能在 30 个字以内说完。** 说不完，说明还没想清楚。
- **有张力。** 立意里最好有一个「但是」「原来」「其实」。平铺直叙的立意，拍出来就是平铺直叙的片子。
- **有落点。** 最后要落在观众身上：他感受到了什么、多懂了什么、想去做什么。

## 2. 创意从哪来：一套可以照着做的方法

创意不是等灵感。按下面的步骤，能力一般的人也能稳定地产出「不平庸」的点子。

### 2.1 先发散，至少 10 个角度

围绕主题，用下面这些「透镜」各想一个角度，写成一句话：

| 透镜 | 问自己 | 示例（主题：太阳） |
|---|---|---|
| 换视角 | 谁在讲？换一个不会说话的、非人的、意想不到的讲述者 | AI、一颗被晒过的被子、一株向日葵、一粒光子 |
| 反差 | 最懂的却没见过，最小的却最重要，冷数据背后是热感情 | 知道太阳全部数据，却没见过它 |
| 硬知识做支点 | 有没有一个真实但冷门的事实，能成为情感的转折 | 阳光到地球要 8 分 20 秒，人类看到的永远是过去的太阳 |
| 以小见大 | 用一个具体的人、一件具体的事，讲一个大主题 | 一个人每天凌晨去看日出，因为那是他和去世父亲的约定 |
| 以大见小 | 从宇宙尺度拉回到一个很小的动作 | 从 1.5 亿公里外，一路推到一只晒太阳的猫 |
| 反转 | 观众以为是 A，最后发现是 B | 以为在讲太阳，其实在讲思念 |
| 提问 | 开一个观众想知道答案的问题 | 如果太阳突然消失，我们要 8 分钟后才会知道 |
| 缺席 | 通过「没有」来表现「有」 | 全片不出现太阳，只出现被照亮的东西 |
| 拟人 / 物化 | 让抽象的东西有情绪，或让人变成物 | 太阳是一个每天准时上班、从不请假的打工人 |
| 倒过来 | 结局放开头，或者时间倒流 | 从日落倒放到日出 |
| 数字 | 有没有一个惊人的数字能当钩子 | 你这辈子大约看过 25000 次日出，记得几次？ |
| 对比 | 两个东西并排放，意义自己出来 | 左边是太阳的数据，右边是人类描述它的句子 |

### 2.2 砍掉最先想到的三个

最先冒出来的点子，所有人都会想到。把它们划掉，从剩下的里面挑。

### 2.3 用三个问题收敛

给剩下的每个角度打分（1 到 5 分）：
1. **意外吗？** 观众会不会「哦？」一下。
2. **成立吗？** 逻辑和情感都站得住，不是为了意外而意外。
3. **拍得出来吗？** 在现有工具下，每一句都能找到画面。

总分最高的，就是立意的候选。**陪跑模式下，把前两三个候选连同理由一起给用户挑。**

### 2.4 让立意和形式互相咬合

好片子的形式本身就在讲故事。问自己：**这个立意，用什么风格讲最「对」？**
- AI 没见过太阳 → 整部片子用字符画，因为 AI 眼里只有字符。
- 讲时间 → 画面里一直有一个在走的东西。
- 讲孤独 → 大量留白，一个很小的主体。
- 讲连接 → 线条、网络、汇聚的粒子。

形式和立意咬合时，观众会觉得「就该这样」；不咬合时，再精致也只是在炫技。

## 3. 结构：把立意铺成时间

选一个结构模板，按比例分配时长。

**起承转合**（诗意短片、情绪片首选）
- 起 20%：建立世界，给出一个状态。
- 承 30%：推进、加深这个状态，或者让主角去尝试。
- 转 25%：一个事实、一个发现、一个反转，改变了意义。
- 合 25%：新的理解，回到开头的意象，但意义已经变了。

**三幕**（有冲突的故事）
- 建立 25%：主角、世界、欲望。
- 对抗 50%：阻碍升级，中点出现转折。
- 解决 25%：高潮和新的平衡。

**问题 → 探索 → 答案 → 余韵**（科普、讲解）
- 问题 10% 到 15%：用一个具体、反常识的问题勾住人。
- 探索 50% 到 60%：逐层拆解，每一层都比上一层更深或更意外。
- 答案 15% 到 20%：一句话讲透。
- 余韵 10%：延伸、回扣开头，或者留一个新问题。

**痛点 → 转机 → 方案 → 愿景 → 行动**（产品、宣传）

**钩子 → 展开 → 高潮 → 回声**（短视频通用）

**列表式**（N 个事实、N 个理由）：按「意外程度」排序。**第二强的放第一个当钩子，最强的放最后。** 中间的按强度递增。

**环形结构**：结尾回到开头的画面或句子，意义已经变了。这是短片最稳的收尾方式。

**对照结构**：两条线并排或交替（过去和现在、数据和感受、人和 AI），在结尾交汇。

## 4. 情绪曲线

给每个段落标一个 0 到 10 的「张力值」，画出曲线。规则：
- **高潮放在全片 70% 到 85% 的位置。** 太早，后面会塌；太晚，来不及收。
- **高潮前要有一个低谷。** 蓄力的最好方法是先压下去，比如沉默、黑场、一个极简的画面。
- **结尾比高潮低，但比开头高或者更暖。** 观众要带着一点东西离开。
- **不要一条直线。** 哪怕是 15 秒的片子，也要有「起、压、爆、收」。
- **每 20 到 30 秒给一个新刺激**：新信息、新画面、新声音、新问题。

把张力值写进 `storyboard.json` 每个镜头的 `intensity` 字段，`check_storyboard.py` 会画出曲线并检查高潮位置。

## 5. 开头与结尾

**开头 3 秒决定观众走不走。** 可用的钩子：
- 一个反常的画面（黑屏上一个闪烁的光标）
- 一个问题（「你见过此刻的太阳吗？」）
- 一个惊人的数字（「1.5 亿公里」）
- 结论先行（先给结果，再讲怎么来的）
- 一个声音（先声夺人，画面后到）

不要用：Logo 开场、「大家好」、慢吞吞的淡入、交代背景的长镜头。

**结尾的几种方法**：
- **回声**：回到开头的意象或句子。
- **留白**：最后一句话之后，给 2 到 3 秒安静的画面。
- **一问**：把问题抛给观众（适合短视频平台，能引导评论）。
- **反转**：最后一个镜头改变了前面所有东西的意义。
- **行动号召**：产品片专用，要短、要具体。

最后一帧至少停留 1.5 到 2 秒，片名或落版至少 2 秒。

## 6. 文案怎么写

屏幕文字和旁白是片子的声音，质量标准比普通文章高得多，因为每个字都要占屏幕时间。

**基本规则**
- **一屏一句，一句一个意思。** 竖屏每行不超过约 12 到 15 个字，横屏不超过约 18 到 22 个字。
- **具体胜过抽象。** 「晒过的被子有太阳的味道」胜过「阳光带来温暖和幸福」。
- **名词和动词为主，少用形容词和副词。** 形容词是在替观众下结论，而观众只相信自己看到的。
- **展示，不要告诉。** 永远不要写「这太感人了」「这很震撼」，让画面和事实去感动人。
- **长短句交替。** 长句铺陈，短句收束。一个两三个字的短句，就是一次重拍。
- **排比用来推进**，三次最好，第三次要变一下。
- **不说教，不总结。** 结尾最忌讳「所以我们要珍惜……」。

**删改法**：写完之后，对每一句问：「删掉它，观众会损失什么？」答不上来就删。一般能删掉三分之一。

**禁用的空话**（出现一句删一句）：
「在这个快节奏的时代」「随着科技的发展」「让我们一起」「见证」「赋能」「不仅……更……」「开启新篇章」「无限可能」「匠心」「极致」「颠覆」「重新定义」「一起来看看吧」「你知道吗」（除非后面真的是一个惊人的事实）。

**旁白和屏幕文字的分工**
- 旁白不复述画面，画面不复述旁白。两者互补：旁白讲道理，画面给证据；或者旁白讲感受，画面给具体。
- 有旁白时，屏幕上只放关键词、数字和名字，不要把旁白整句贴上去（字幕除外）。
- 没有旁白时，屏幕文字就是旁白，要按阅读速度给足时间（见 `rhythm.md`）。

**语气要选定**：口语、诗意、冷静、幽默、紧张，整部片子保持一种。诗意片可以用短句、分行、留白；科普片要口语、准确、有画面感；产品片要短、要狠、要具体。

**事实必须准确。** 片子里出现的数字、年份、科学说法，写完后单独核对一遍。拿不准的换一种说法，或者标注「约」。

## 7. 让每一句都能被「画」出来

写完文案，逐句问：**这句话，屏幕上是什么？** 画不出来的句子，要么改，要么给它找一个视觉比喻。

把抽象的东西变成画面的方法：
- **比喻**：「信息过载」→ 一个人被越来越多的弹窗淹没。
- **尺度对比**：「1.5 亿公里」→ 光要跑 8 分钟；把太阳缩成一个篮球，地球只有一粒芝麻，远在 26 米外。
- **过程动画**：「光被散射」→ 一个光点撞到分子上，碎成很多个小光点飞向四面八方。
- **数据具象化**：「每天 3 亿条消息」→ 屏幕上的点多到变成一片海。
- **拟人**：让一个图形有情绪，比如犹豫、害怕、雀跃。
- **缺席**：不画它本身，画它留下的影子、痕迹、反应。
