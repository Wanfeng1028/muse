# 版式与配色（1080×1920，30fps）

## 画面网格（固定坐标，`Main.tsx` 已实现）
| 区域 | 位置 | 内容 |
|---|---|---|
| 平台顶部遮挡区 | y < 180 | 不放关键内容 |
| 进度条 | y = 200，x 60–1020 | 每个知识段一格（钩子不算），当前段随时间填充 |
| 章节标签 + 角标 | y ≈ 250 | 左边琥珀色 chip，右边头像 + @账号 |
| 大标题 | y = 322 | 108px / 900 粗；超过 7 字 96px，超过 9 字 84px；`titleParts` 可以分段上色 |
| **画面区** | x 60，y 548，960×700 | `scenes.tsx` 的场景组件都画在这里（组件内坐标从 0,0 起） |
| 字幕 | y ≈ 1290，居中 | 70px 白字黑描边，`[关键词]` 显示为黄色 #FFE14D |
| 平台文案区 | y > 1450 | 保持空白 |

## 配色（`ui.tsx` 的 `C`）
深色交易界面：bg `#0B0E11`、panel `#161A1E`、panel2 `#1E2329`、line `#2B3139`、text `#EAECEF`、sub `#848E9C`。
语义色：涨 / 好 `green #0ECB81`，跌 / 风险 `red #F6465D`，强调 `amber #F5B82E`，第二对比色 `blue #3D8BFD`，第三对比色 `purple #A78BFA`。
对比类视频给每个对象固定一个颜色（例如 现货 = 绿、合约 = 琥珀，或 美股 = 蓝、bStocks = 黄、合约 = 紫），整片保持一致，封面也用同一套。
要换主题色时，只改 `ui.tsx` 里的 `amber`，例如替交易所做推广时改成对方的品牌黄。

## 字体
Noto Sans SC（500 / 700 / 900）做中文，JetBrains Mono（700 / 800）做数字和行情。都来自 @fontsource，离线可用。

## 节奏
- 场景进场：从右侧滑入，带弹簧回弹（Panel）；出场：最后 7 帧向左淡出。
- 元素出现：`<Appear at={b(k)}>`（弹簧上浮）；强调用 `<Stamp>`（缩放落章）；数字用 `lin()` 做计数动画。
- 卡点规则：说到哪个词，哪个元素就出现。`useBeat(k, offset)` 返回第 k 句的起音帧。
