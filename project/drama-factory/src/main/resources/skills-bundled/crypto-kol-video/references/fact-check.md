# 核实与合规清单

## 先查官方
- 交易所规则（费率、强平线、清算费、杠杆档位、资金费率间隔、产品上线日期、可用地区）：优先看交易所官方帮助中心（FAQ）、公告、Academy，记录「页面更新日期」。
- 读不到官方页面时（地区 451、robots 拦截），**不要换别的手段去硬抓**。改用其他官方渠道或可信媒体，并告诉用户哪些数字没核实到。
- 第三方博客只用来找线索，数字要回到官方页面确认。

## 写稿时
- 能算的就算出来，并在稿里写清前提（「按全仓经典模式、借满杠杆、不计利息估算」）。
- 估算值画面要标注；口播不报没核实到的上限，比如「可以开杠杆」，不说具体倍数。
- 不编造统计（「90% 的人」）、不编造引言、不点名攻击个人。
- 用户脚本里有说法查不到依据时：改成能验证的表达，结论尽量不变，交付时逐条说明。
- 示例中做过的修改：
  - 「强平到安全线就停手」改为「强平线上资产还比负债多一成，还完借款和清算费还能剩一部分」。
  - 「125 倍」改为「一百倍以上」。
  - 把「止损离强平价的距离」当成减项算错了：多头止损在强平价上方，距离只会让你少亏。

## 画面和发布
- 风险提示必须有：「不构成投资建议」「费率和规则以官方为准」，涉及地区限制时写明（例如「美国用户不可用」）。
- 第三方 Logo 只用用户提供的官方原图；黑底的可以按亮度抠成透明，但不改形状、不重绘。
- 商业合作内容：提醒用户按平台规则标注广告或合作。
- 演示用的交易记录：写明「演示数据为虚构」。
