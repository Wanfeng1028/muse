# 道具与特写 —— 基底引用法 ★★

> 解决两个高频翻车：
> ① **所有信纸/道具长得一模一样**（因为都引用同一张图）
> ② **特写里的字看不清 / 写错字**（AI 画中文不可靠）

---

## 一、问题现象

### 现象 A：每封信都一样

一部片子里有 14 个「信纸特写」镜头，全都引用同一张图 `[楔子 A09] 纸面字迹`
→ 观众看到的是**同一封信**，剧情不成立。

### 现象 B：字看不清 / 写错

AI 生成中文的准确率很低。常见的错误做法是在提示词里写
「字迹虚化不可读」来**躲**——结果观众根本不知道信上写了什么，
**把问题藏起来而不是解决**。

---

## 二、解法：两步走

```
第 ① 步：生成一张「空白基底」道具图（无字、干净、材质正确）
第 ② 步：每一个需要内容的镜头，**引用这张基底**，单独生成
```

**为什么有效**：
- 基底保证了**材质/光线/颜色一致**（同一刀纸、同一盏灯）—— 这是剧组的真实感
- 每个镜头**单独生成**，所以内容各不相同
- 因为基底是**干净的空白纸**，模型有全部"注意力"去写那行字，**准确率大幅提升**

## 四、道具基底清单（一部古装片常需要）

| 道具 | 基底提示词要点 |
|---|---|
| **信纸 / 草纸** | 空白、纤维纹理、四边毛口、右下角焦黄、木桌 |
| **当票** | 空白票纸、朱红边框、一个空白的方形印位 |
| **账册 / 记录册** | 空白册页、线装、纸边卷曲 |
| **信封** | 空白信封、封口未拆、一张没写字的纸 |
| **长命锁** | 铜质、磨得发亮、正反面（**刻字镜头单独生成**）|
| **玉佩** | 青玉、莲花雕工、背面刻字（单独生成）|
| **灯油壶** | 粗陶、壶身刻字（单独生成）|
| **封泥** | 深褐封泥、裂纹、方形印记（刻字单独生成）|

**原则：基底只保证"材质"，内容全部单独生成。**

## 五、提示词模板

### 基底（第 ① 步）

```
【道具特写，俯拍/固定机位】<道具>平铺在<放置面>，完全空白，什么都没有。
<材质描述：颜色、纹理、磨损、缺口、污渍>。
★<道具>上绝对没有任何文字、笔画、墨点、印章或图案。
【电影感】浅景深；大面积暗部；单一侧面光源，光从<方向>打过来，
让<材质特征>清晰可见；背景只有<放置面>的边缘，其余压暗。
写实电影质感，<材质>必须真实，避免塑料感和平滑感。
```

### 带内容的镜头（第 ② 步）

```
【大特写，俯拍，固定机位】<道具>（<材质、颜色、纹理、四边毛口、右下角焦黄>，
全部严格参照 @图1）。
<道具>上用<工具>写着<横排/竖排>的<字体>，内容清楚可读：
「<要写的字>」——必须是<这几个字>，字迹清楚、笔画完整，
不要写成别的字、不要多字漏字、不要出现乱码或看不懂的笔画。
★这张图必须是单一的一幅完整画面，绝对不要多格拼贴、不要分割构图、
  不要角色表排版、不要重复出现同一个物体。
【电影感】……
```

## 六、★ 同一个道具出现在多个镜头怎么办

**要区分两类：**

| 情况 | 做法 |
|---|---|
| **同一件实体**出现在多个镜头 | **共用同一张图**（正确！不要"每张都不一样"）|
| **不同的信/不同的道具** | 各自单独生成 |

> **实测例子**：《《示例片名》》的 **D04（第三章）** 和 **N05（第十三章）**
> 都是「别让你儿子去修仙」—— 这是**同一封物理的信**（他写给儿子、后来烧掉的那封），
> **共用同一张图才是对的**。
>
> 一开始误以为"每封信都要不一样"，差点把它们做成两张不同的图。

## 七、AI 画中文的实战规则

1. **字要少**。一次最多 8–12 字，多了必错。
2. **字要写进提示词**，用「」括起来，并加一句「必须是这几个字」。
3. **加负面**：`不要写成别的字、不要多字漏字、不要出现乱码`。
4. **先做干净基底**（见上），成功率高很多。
5. **竖排比横排稳**（古风场景本来就竖排）。
6. **每张都要看图核对**（`read_image`），错了就重生成。**不要省这一步。**
7. 如果反复错 → 退而求其次：**让字只出现一半/被手挡住**，
   或者把关键信息交给**旁白**说出来。

---

## 八、避免「多格拼贴」

单物体特写很容易被画成**九宫格/角色表排版**。必须在提示词里加硬约束：

```
★这张图必须是单一的一幅完整画面，绝对不要多格拼贴、不要分割构图、
  不要角色表排版、不要九宫格或六宫格、不要重复出现同一个物体。
```

**踩过的坑**：
- H08 把「儿尽力了」写成了「变成诗。」
- L07 玉佩被画成六宫格
- P03 被画成四宫格
- S10 出现了两个老太太
- Q02 空信封格里出现了字

全部靠上面这条硬约束 + 单独重生成解决。
