## 一、★★ 黄金 3 秒与抖音节奏铁律（最高优先级）

> **来源**：抖音/红果运营实测（蝉妈妈）+ `short-drama-factory` 的 `golden-3s-hook-library.md`
>
> **核心结论**：**前 3 秒的完播率决定 90% 的算法推荐量。** 播放量不重要，**黄金 3 秒完播率才重要。**

### 1.1 前 3 秒必须用「冲突 / 悬念 / 痛点」切入

**严禁铺垫背景。** 原文：

> 「把开头的**背景铺垫全部删掉**，用冲突、悬念或痛点提问直接切入。」

**四条开头禁令**（`golden-3s-hook-library.md` 原文）：

1. ❌ 严禁"早晨起床拉窗帘"
2. ❌ 严禁"汽车在公路上行驶超过 2 秒"
3. ❌ 严禁"大段旁白交代时代背景"
4. ❌ 严禁"角色坐在咖啡厅无意义闲聊倒水"

### 1.2 ★ 30 秒 – 1 分钟是「死亡区」

> 前 3 秒留存好、**整体完播率断崖式下跌** → 问题**大概率出在 30 秒到 1 分钟之间的信息密度**：
> **剧情拖沓、转折太慢**。

**所以第一波冲突必须落在前 15–20 秒内**，不能拖到 30 秒后。

### 1.3 时长档位

| 类型 | 建议时长 |
|---|---|
| 剧情类短视频 | **30–60 秒** |
| 极短爆点 | 15–30 秒 |
| 超过 90 秒 | 必须有强情节支撑，否则完播断崖 |

### 1.4 ★ 预告式钩子：把高潮提到开头

**最强的钩子不是冲突本身，而是"结果"。**

```
00:00-00:03  角色立 flag（正经、自信）
00:03-00:05  ↓ 立刻切到"已经失败了"的画面
             画外音给出时间反差："……嗯，这是我上岗的第一天。"
             ↑ 观众 3 秒内就好奇：怎么垮的？
00:05-...    以下才是回答（倒叙）
```

**判据**：如果开场删掉后剧情不受影响，那段就是废铺垫。

### 1.5 数据诊断法（发布后）

拉数据漏斗定位问题环节：

```
前3秒完播率 → 整体完播率 → 互动率 → 转化率
```

| 现象 | 病因 |
|---|---|
| 前 3 秒完播率低 | 钩子太弱，重做开场 |
| 前 3 秒好、整体断崖 | **30秒-1分钟信息密度掉了** |
| 完播好、互动低 | 缺争议话题 / 选择题式结尾 / 强共鸣金句 |

## 二、★ 段缝衔接：解决「拼接生硬」的核心规程

> **病根：AI 视频模型每段零记忆。** 单段生成时没有前段的人物/场景/动作记忆，每段数据归零。
> **不补这条记忆链，段缝处必然跳切、动作断层、对白无气口。**

### 1.1 数据两类划分

| 类别 | 内容 | 处理 |
|---|---|---|
| **不变数据** | 角色资产图、场景资产图 | 全程固定，**每段重复投喂，一帧不改** |
| **可变数据** | 人物站位、姿态、人物互动、画面构图 | **每段同步更新** —— 段缝就是换挡点 |

### 1.2 段缝末态继承 **双保险（缺一不可）**

**保险①【接续状态】写具体末帧画面**

写"下一镜可以直接开拍的画面"：**谁 + 在哪 + 什么姿态 + 关键道具/互动状态**，一句话，画得出画面。

- ✅ `女主立于窗下侧身45°朝左，信件半展于右手，指尖停顿在纸缘；母亲在门口背身垂手`
- ❌ `角色动作与空间位置严格继承` ← **套话，模型继承不了任何东西**（机检会告警）

**保险② 段缝分镜参考图锁 —— 图锁比文字强**

> **每段生成前，按上一段结尾的人物状态绘制一张分镜参考图**，作为下一段首镜的画面依据。

- 只靠提示词容易反复抽卡、画面失控
- ⚠️ **禁用「上一段尾帧截图直接当下一段首帧硬拼」** —— 方法完全错误（画面跳切、动作粘连）

### 1.3 段缝换机位铁律

> **即便末态锁死，同机位直接拼接依旧有割裂感。**
> 段与段的接缝处**强制更换机位/景别**，把两段做成"两个不同镜头的剪辑关系"，
> 而不是"一个镜头被掐成两截"。

- **禁同机位硬接**：上段末镜是中景平视，下段首镜禁再起中景平视 —— **至少换视角、换景别其一**

**段缝六式选用表**

| 段缝场景 | 首选接缝式 |
|---|---|
| 连贯动作被拆段（挥拳→命中） | 动作连续切（中景起手 → 特写命中） |
| 情绪顶点收段 | 反应镜头切（切旁观者/对手微反应） |
| 段间爆点/转场 | 景别跳切 或 遮挡过渡切 |
| 追逐/位移跨段 | 动势匹配切 |
| **文戏慢段衔接** | **空镜过渡** |

### 1.4 空镜过渡三用法（段缝呼吸工具）

| 用法 | 做法 |
|---|---|
| ① 情绪空镜 + BGM | 段末情绪落地后切 1~2s 环境空镜，BGM 延续、**无人声** |
| ② 音效桥空镜（声先入） | 空镜画面 + **下一段声音先入**（J-cut），接缝感最低 |
| ③ 时空转场空镜 | 日夜交替 / 地点切换 / 时间流逝 |

**限额**：单集 ≤3 处、单处 1~2s。空镜**不得替代冲突**。

## 二、★ 镜头规格：解决「镜头连排、画面平」

### 2.1 每镜头三要素

```
[景别] · [视角+角度] · [运镜]
```
**镜行不写"跟随@谁"**（跟随目标属运镜策略，融进动作描述）

### 2.2 景别阶梯跃迁（硬规则）

> **连续镜头景别必须阶梯跃迁**：极微距特写 → 超广角中景 → 宏观全景 → 鸟瞰/过肩定格
> **禁相同景别 + 机位连排**

⚠️ **我们踩过**：《AI渡劫日记》第一幕 S02 与 S03 **都是中景平视、都是纯白背景** → 硬接，割裂感。

### 2.3 角度规则

- **中景/全景严禁 90° 侧面正拍** —— 必须 **30°~60° 斜角**
- 15s 高燃段：开局 0~1.5s 见肉、同运镜 ≤2s、以高潮定格收尾

### 2.4 在场名单与站位声明

- **在场名单**：同场景多镜的每一镜必须点名本镜**全部在场角色**（动作主角 + 静止配角全列）
- **站位声明**：每人一段括号四要素 —— **位置**（画面左/右/中）+ **依托物** + **朝向** + **姿态**
- **禁 ASCII 空间图/坐标表**
- **摆位必入画**：站位里摆了位的每个人，**必须在至少一个镜头出现**（正拍/焦外身影/全景/反应镜均算），
  给不了镜头就写明「段末离画/退场·去向」

## 三、★ 对白四查：解决「台词与口型/节奏不匹配」

### 3.1 语气位必写

**有台词的镜，必须写「角色（语气）："…"」** —— 语气是官方对白三要素之三（HOW THEY SOUND）。

- 语气按**四维**写：**情绪色 / 力度 / 音质 / 节奏**，**≤3 词**
- **禁空泛结果词**（开心/难过/生气）
- ⚠️ **声音词只进语气位，禁写进画面段** —— 写进画面段会被当视觉信息渲染成"一张冷笑的脸"

### 3.2 语速档与拆句

| 档 | 字/秒 |
|---|---|
| 标准 | 3.5~5 |
| 慢速 | <3.5 |
| 快速 | >5 |

- **台词时长 ≤ 该镜预算**（超时 = 🔴 P0，必须重构或拆镜）
- **单句 >24 字强制拆 2~3 镜（每镜 ≤18 字）**

⚠️ **我们踩过**：《AI渡劫日记》S06 台词 **44 字**，严重超标，必须拆镜。

### 3.3 金句后留反应镜

**金句/高潮台词后预留 0.3~0.8s 无对白反应镜头**（瞳孔骤缩 / 倒吸凉气 / 静场）。

### 3.4 文戏微表情六阶段

**触发 → 初识 → 压抑 → 泄露 → 破防 → 余韵**

## 四、★ 表情 FACS 化：解决「表情空泛、AI 味」

> **表演/表情位禁写"开心/难过/邪魅"等空泛情绪词**，一律落成**肌肉动作的画面语言**。

**四区写全 + 幅度词 + 起落秒数**

| 判据 | 写法 |
|---|---|
| **真笑** | 眼尾眯 + 眼下隆起 + 嘴角上提 |
| **假笑** | **只嘴角动、眼周零参与** |
| **惊讶 vs 恐惧** | 按**眉心是否拧住**区分 |
| **冷硬/宣判** | 显式写「双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压」 |

⚠️ 模型对年轻女性**默认甜笑**，不写肌肉动作就会甜笑。
⚠️ 「面无笑意、唇线平直」**已废止** —— 被禁词根（笑）等于画面词。

**零 FACS 标注进正文**：AU 编号、强度标记、English kernel 只留内部 QC 表。

## 五、★ 禁令失效三改法：解决「写了负面约束却照样出现」

> **视频模型对否定不敏感、对词根敏感** —— 被禁概念的**词根**哪怕挂着"不/禁"也照旧被渲染。

| 改法 | 做法 |
|---|---|
| ① **换词** | 被禁词根在提示词**任何位置零出现**，改正向描述<br>（道具→「实心哑光石质，玉面呈青玉原色」**零光效**；表情→「双唇抿紧、嘴角向下压」）|
| ② **主体优先** | 每段镜1第一个分句即人名/身体局部/「画面主体：」，**禁环境前置词开头** |
| ③ **触发器移除** | 道具不与灯火共现：只把玩/佩戴，**不靠近光源** |

⚠️ 实测：「举到油灯旁，火光从侧面照」→ 玉佩变成打火机点燃的一簇火。
⚠️ 「XX 不发光、不透光」→ 被禁词根 = 画面词，照样渲染。

## 六、★ 首镜锚定与具象化：解决「凭空多出一张脸」

**① 首镜锚定句只许一个具名主体**

- **禁「X 与 Y 同框」类并列主体句式** —— 实测「这只手与她的脸同框」出片**两张脸**
  （模型把并列名词 +「同框」读成画面里有两个主体）
- 身体部位一律以「她的/其 + 部位」从属出现

**② 指代词必须带归属**

- 「这只手 / 那张脸」无先行词 → 模型**自补一个主体**（补出一个头）
- 一律写「她的一只手 / 他的右手」

**③ 抽象形态·程度副词一律删**

- 成线/成串/成股/如注/轻蜷/微蜷 —— 模型**无法命名过程形态**
- 「漏雨成线砸在手背上」→「雨滴砸在手背上溅开」
- **判据一句话：这句里每个词都能画出来吗？画不出来的就是形容词。**

**④ 反光道具零光效描写**

- 不写 光斑/受光/照射/照在/亮起，只写材质本色
