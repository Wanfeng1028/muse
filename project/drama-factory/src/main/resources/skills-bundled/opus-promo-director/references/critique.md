# 감독 리뷰

사용자가 "별로다"라고 말하기 전에 그 판단을 먼저 한다. 첫 결과를 보여 주기 전과 큰 수정 뒤마다 한 번씩 돈다. 결과는 `production/review.md`에 회차별로 남긴다.

리뷰의 가장 큰 함정은 에이전트가 스스로 만든 기준으로 스스로를 채점하는 것이다. 기술 항목(첫 1초, 글자, 안전 영역)을 모두 통과한 편이 "임팩트가 없다"며 거절됐다. 그래서 리뷰는 사용자가 고른 기준과의 비교로 시작한다.

## 1. 증거 만들기

- **기준 비교 (필수):** `python scripts/review_sheet.py video.mp4 cmp.jpg --every 2.5 --compare 기준.mp4`. 기준은 사용자가 고른 스타일프레임 영상, 좋다고 한 이전 편, 참고 광고 중 하나다. 기준이 이미지뿐이면 같은 장면의 렌더 프레임을 옆에 붙인다.
- **컷 전후:** `python scripts/review_sheet.py video.mp4 cuts.jpg --around {컷 시각들} --span 6`. 컷 시각은 `production/shotlist.json`의 `startSec`에서 가져온다.
- **전체 흐름:** `--every 1` 또는 박자마다
- **세로 안전 영역:** `python scripts/safe_zone.py reels.mp4 safe.jpg --frames {장면마다 글자가 가장 많이 보이는 프레임}`
- **소리:** `python scripts/cue_check.py video.mp4 production/shotlist.json`, `python scripts/audio_check.py video.mp4`

정지 화면 하나로 움직임을 판단하지 않는다. 확인용 프레임을 코드의 위치값이나 추측으로 대신하지 않는다. 실제 렌더에서 뽑는다.

## 2. 비평 맡기기

가능하면 새 컨텍스트의 별도 에이전트에게 맡긴다. 제작 과정을 모르는 쪽이 더 냉정하다. 넘길 것은 위 증거 파일, 영상 목적 한 줄, 사용자가 룩에 대해 한 말 그대로, 아래 채점표뿐이다.

별도 에이전트를 쓸 수 없으면 직접 하되, 항목마다 "통과/실패"와 근거 프레임 번호로 답한다. "대체로 괜찮다"는 답으로 치지 않는다.

비평 요청문:
```
너는 이 홍보 영상을 처음 보는 까다로운 모션 디자이너다. 목적: {한 줄}.
사용자가 원한 룩: "{사용자가 한 말 그대로}". 비교 시트의 아래 줄(ref)이 사용자가 고른 기준이다.
첨부한 시트만 보고, 먼저 "기준보다 초라하거나 다른 점"을 밝기, 주인공 크기, 화면 밀도, 반복, 속도 순으로 적어라.
그다음 채점표 항목마다 통과/실패와 근거 프레임 번호를 적어라. 실패는 심각한 순서로 정렬하고,
각각 "시청자가 무엇을 느끼는지"와 "구체적으로 무엇을 바꾸면 되는지"를 한 줄씩 적어라. 칭찬은 쓰지 마라.
```

## 3. 채점표

| 항목 | 실패 신호 |
|---|---|
| 기준 대비 | 기준보다 어둡거나 밝기 방향이 다르다. 주인공이 작다. 화면이 여러 칸으로 나뉜다. 같은 배치가 3장면 넘게 반복된다. |
| 첫 1초 | 로고나 흔한 전경으로 시작한다. 첫 프레임에 결말이 다 보인다. |
| 이야기 | 궁금증, 답, 근거, 행동 유도 중 하나가 없다. 제품이나 행사가 답이 되는 순간에 나오지 않는다. |
| 화면 밀도 | 작은 글자 카드 여러 장이 한 화면에 오래 남는다. 문장 두 개가 동시에 경쟁한다. |
| 움직임 | 가까운 것과 먼 것이 같은 속도로 커진다. 전환마다 같은 방식이다. |
| 속도감 | 박자에서 벗어난 컷이 있다. 컷 직후 빈 화면이나 뿌연 화면이 1프레임이라도 있다. 뒤로 갈수록 컷이 짧아지지 않는다. |
| 배경 | 단색, 체크무늬, 평평한 격자가 있다. 깊이 층이 없다. |
| 글자 | 기본 폰트로 보인다. 휴대폰에서 읽히지 않는다. 화면 밖으로 잘린다. 물체에 가린다. |
| 브랜드 | 로고, 포스터, 앱 화면이 AI가 그린 가짜이거나 잘렸다. |
| 플랫폼 | 세로판 글자가 안전 영역(x 90~888, y 288~1248)을 벗어난다. |
| 엔딩 | 행동 유도 화면이 4초를 넘게 멈춰 있다. |
| 소리 | 최대 음량이 -0.5dBFS를 넘는다. 컷과 타격음이 어긋난다. |
| 샷 목록 | 샷 목록의 장면이 빠졌거나 자막이 다르다. 사실(날짜, 시간, 이름)이 원문과 다르다. |

## 4. 고치고 보고하기

- 기준 대비 실패가 있으면 그것부터 고친다. 수치 조정으로 안 되면 룩이 틀린 것이다. 사용자에게 비교 시트를 보여 주고 3단계로 돌아간다.
- 나머지는 심각한 것 2~3개를 고친 뒤 보여 준다.
- 고치지 못한 실패는 보고에 "남은 한계"로 적고, 고치는 방법과 예상 시간을 함께 적는다.
- 같은 방식으로 두 번 고쳤는데도 실패하면 방식을 바꾼다.
