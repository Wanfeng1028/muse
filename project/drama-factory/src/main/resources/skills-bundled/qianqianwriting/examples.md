# 爆款短剧范例库

基于 31 部爆款短剧剧本提取的真实格式范例和写作模式范例。

## 一、剧本格式范例

### 范例 A：标准格式（都市霸总类 —— 《闪婚老公是豪门》）

```
第一集：
1-1民政局内 日
△镜头拉近，结婚证被工作人员盖红章，随后结婚证递到司情与战北霆手上。
工作人员：恭喜。
司情（OS）：我竟然和一个只见过一面的陌生男人结婚了。
战北霆（把银行卡夹在手指上，递给司情，没有露脸）：这张卡你拿着，密码是6个6，里面的钱你随便花，我现在赶时间去美国出差，回来之后再联系你。
司情（接过银行卡，一脸惊愕站起来）：我钱够……
△没等司情说完，战北霆已经离开。
司情（看向战北霆的背影，话语变慢）：……够花。
```

**格式要点**: `△` 动作 + `角色名：对白` + `（OS）` 内心独白 + 场景标头简洁

### 范例 B：古装权谋格式（《绝色美人谋》）

```
第一集
1-1 宫殿 夜 内
人物：楚云歌 巫女
△画面由远及近，楚云歌靠坐在宫殿内的树下仪式台上，巫女拿着面具戴在楚云歌脸上
巫女vo：做完最后一次换脸术，你就可以新生了
△巫女在殿内起舞，（分镜）楚云歌的随着巫女的手左右摇摆
△闪回楚云歌在战场杀敌英勇场面
楚云歌vo：我本天启镇国将军，上阵杀敌无数。
```

**格式要点**: `vo` 画外音 + 闪回直接标注 + 古装场景描写简练

### 范例 C：男频逆袭格式（《北王刀》）

```
第一集
纯黑环境 夜内
人物：宁卓 黑衣人
▲独立射灯从上往下，宁卓在灯光正中蟒袍玉带，头戴乌纱翼扇冠，闭目，膝上横刀坐在红木大椅上，黑衣人蒙面行刺，一段打戏后，黑衣人见势不妙想跑，被宁卓拿住手腕，拽掉黑巾露出许杰的脸，宁卓陡然睁眼。
宁卓：抓住你了。
 二层客厅 日内
人物：宁卓 许杰 陈红梅
▲电视上放着猫和老鼠。
宁卓（坐在轮椅上抱住许杰的手傻笑）：嘿嘿嘿，大老鼠，抓住你了。
许杰（想挣脱，怒斥）：放手！
```

**格式要点**: 开场梦境→现实反转 + `▲` 动作标记 + 扮猪吃虎的反差

### 范例 D：纯文字叙述格式（《封总的复仇娇妻》）

```
1、
酒吧。  人物：林茵  封明洲  林富堂，詹美玲，配角等人
林茵握着一个空酒瓶朝包厢走，高跟鞋声急促，周围路过的人纷纷看向她。
林茵推开包厢门，径直走到正在与一个漂亮女人亲热的封明洲面前，挥起酒瓶砸了下去。
封明洲痛叫一声，众人也都吓了一跳，慌忙关了音乐。
封明洲："林茵你他妈疯了？！"
林茵："我很清醒。订婚的那天我就跟你说过，如果你敢出轨，我就敢给你开瓢！"
```

**格式要点**: 不用 `△`，纯文字叙述 + 对白用引号 `""` + 集数用阿拉伯数字

## 二、前置文档范例

### 范例 A：完整基本信息（《回到古代当太子》）

```
基本信息：
（类型）：穿越历史架空，废太子流，暴君流
（体裁）：竖屏微短剧
（故事亮点）：现代科技知识优势，一路碾压，装逼打脸
（剧情概括）：一个现代全能学霸996社畜，加班猝死，却穿越回了古代，
一个万国背景的大夏国，身份是即将被废的太子，他利用自己超前的眼光
和科学知识，力挽狂澜，带领积弱百年的大夏征途万里
（时长/集数）：1min/集，共100集
```

### 范例 B：详细人物小传（《神仙微信群》）

```
男主-杨辰
视觉年龄25岁，普通上班族一名。
外表：长相清秀
性格标签
#聪明机智：充满智慧，经常能用智慧化险为夷。
#冷静理智：遇事能冷静思考，周全处理，极少上头。
人物经历
苦逼上班族杨辰在结婚前一天被未婚妻和好兄弟绿还被公司开除后，
误入了神仙微信群，从此借神仙们发的红包一路高歌打脸！
```

### 范例 C：剧情节奏规划（《凤凰男的豪门贤妻》）

```
1-9集：通过生活琐事交代女主卑微的家庭地位，老公事业遇阻，小三登场，婚姻危机
10-13集：第一个小高潮，宴会上女主身份小范围暴露，与真正男主初相遇
14-16集：同学聚会打脸
23-24集：女主孩子生日风波，女主确认老公出轨
25-29集：婆婆卖孩子，女主心灰意冷
30-35集：女主离婚
39-45集：女主强势回归，打脸前夫
45-55集：全片大高潮，女主正式回归豪门
56-58集：前夫一家垂死挣扎
59-60集：女主和男主互通心意，结婚
61-65集：番外
```

## 三、3 种开场模式范例

### 模式 A：前世/惨剧闪回开场

**《招惹》第一集**：先用梦境展示杜景窗偷窥的惊恐画面，制造悬疑氛围，然后字幕"六个月前"切回过去，开始正叙。

**《云总你的小心肝重生了》第一集**：先展示女主被仇人折磨致死，在仇人怀里毒发身亡，然后猛然重生回三年前的高尔夫球场，第一个动作就是用球杆击中渣男裆部——爽感瞬间拉满。

**《绝色美人谋》第一集**：先展示女主被封诰命夫人时被妹妹从背后捅刀，再切回五年前开始复仇之路。

### 模式 B：当下冲突直入

**《无双》第一集**：男主大雨中赤手空拳走向数十名黑衣人，一场打戏后轻松碾压，身份立刻被揭示——绝对的力量感。

**《龙帝归来》第一集**：男主出狱归来，满怀期待去见前女友，结果发现前女友正在和害他入狱的仇人举行婚礼——冲突在第一秒就引爆。

**《封总的复仇娇妻》第一集**：女主拿着空酒瓶直冲包厢，二话不说砸在出轨未婚夫头上——角色性格一个动作就立住了。

### 模式 C：身份/系统觉醒

**《回到古代当太子》第一集**：加班猝死 → 穿越到古代太子身上 → 醒来发现身边躺着一个拿簪子要捅他的女人——穿越+危机+喜感三合一。

**《钓系娇娇》第一集**：女主正在解一个男人的扣子时系统觉醒，屏幕弹出穿书信息——修罗场四个男人的信息一次性展示，信息量炸裂。

**《神仙微信群》第一集**：外卖小哥被打劫后昏迷，梦游仙境醒来发现手机里真的多了一个神仙微信群——金手指获取过程简单直接。

## 四、集末悬念/反转范例

每集结尾必须有钩子，以下是从爆款中提取的典型手法：

### 1. 身份悬念型
```
△秘书从电梯门走向宋霜序和陈沛然
助理：宋小姐，贺总让我来接你。
△宋霜序微笑点头，陈沛然震惊
```
（观众好奇：贺总为什么要见她？她什么背景？）

### 2. 反转打脸型
```
苏凌天：极阴之体！
△苏凌天突然冲向林烟雨，扑倒在地。
林烟雨尖叫：啊！
```
（上一秒还在被嘲笑是废物，下一秒扑倒了女总裁）

### 3. 危机降临型
```
△手机响起，杨辰接听。
杨辰（惊）：什么？我马上到！
```
（到底发生了什么？观众必须看下一集）

### 4. 真相揭露型
```
经理：300万全部。
郑萋（OS）：他们从不愧疚，只是假装。
```
（观众和女主同时发现：渣男连女儿的教育基金都卷走了）

### 5. 情感钩子型
```
苏怀瑾：宁卓，我不想你是盖世英雄了。
▲宁卓抬手抚过苏怀瑾脑后长发。
宁卓：往后余生，换我护你。
```
（观众被感动的同时好奇：他会怎么保护她？）

## 五、反派写法范例

短剧反派必须"坏到家"，以下是爆款中反派的典型写法：

### 极致嚣张型（让观众恨到牙痒）
```
许杰：就算你现在不傻了，也不过是一个靠吃苏家软饭苟活的残废！
许杰：我就是要娶你老婆，光明正大地睡她，你又能拿我怎么样？！
```

### 伪善双面型（表面一套背后一套）
```
陈静：萧南，你别瞎说，当初你进监狱，就是老娘设计的！
```

### 恶毒亲人型（最扎心的背叛）
```
婆婆一巴掌扇向顾晓月：不生就和我儿子离婚！
陈颂：大人说话小孩子插什么嘴！
```

反派越过分 → 主角反击时观众越爽 → 完美的情绪杠杆。
