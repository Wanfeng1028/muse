# ShotFlow for Remotion · 镜头与卡点

把画面里“发生了什么”转成可重复渲染的镜头，把声音里“何时发生”转成可核对的时间轴。本技能沉淀了10条参考片的视觉观察和音轨测量；它们是可选的设计依据，不是固定模板，也不证明原作者用 Remotion 制作。

## 先选当前任务需要的工作

- **制作/改片**：直接推进已有工程。只补齐真正影响交付的受众、核心信息、画幅、时长和声音约束；可从上下文推断的，用明确假设继续。优先复用用户的真实展示组件与固定演示数据。
- **学参考片/复刻一镜**：只检查选中的参考及关键3–8秒，读取[参考取证](references/reference-study.md)。用户明确要求整批学习时才批量分析。
- **只要分镜/声音计划**：选取必要参考证据 → 分镜和声音用途 → 需要时编译cue；无需创建工程或渲染，明确标注素材是否已提供。
- **声音/卡点**：读取[音画工作流](references/audio-sync.md)，先确认可否实际听音，再选择信号测量、试听校准或原创声音设计。

本技能补充镜头设计，不替代官方 Remotion API 与工程规则。要编写 Remotion 代码时，若现有 `remotion-best-practices` 可用，按具体API读取相应规则。缺少它不会阻断本技能；从现有项目依赖与官方文档核验API，不为研究参考片自动创建应用或安装整套依赖。

## 从分镜到可交付的视频

### 1. 先确定这一镜要让人看懂什么

为重要镜头记下：信息目标、主对象及稳定ID、起/中/终状态、镜头焦点、主要动作时间、阅读停顿、声音角色。短片可以直接写在工作说明中；复杂片可参考[分镜示例](assets/shot-plan.example.md)。用户只要分镜时，交付分镜即可。

按用途从[镜头配方](references/shot-library.md)选择少量方法：对象连续变形、卡片汇聚归位、输入条展开成界面、阅读镜头、连接流程、几何描边接续等。不要把每一镜都做成打字机、弹簧或持续推近。

### 2. 保留对象身份，让动作有因果

先固定对象ID、坐标系与关键矩形，再插值位置、尺寸、圆角、透明度。指针到达、抓取、容器响应、结果落定各有明确事件。需要跨场景连续的对象放在共同父层，避免在切点卸载后重建而跳变。

父层控制镜头，子层控制内容。镜头移动连接两个阅读目标；结果出现后给足读懂的时间。多个对象共用节奏时允许短暂错峰，位置和随机分布保持确定性。

### 3. 用帧驱动实现，先验证代表性镜头

- 动画状态由 `useCurrentFrame()` / `useVideoConfig()` 决定；使用明确区间的 `interpolate` 与所需缓动。`spring`只用于需要弹性/落定感的动作。
- 同一进度驱动同一动作的多项属性。稳定ID、固定输入数据和有种子的随机数使任意帧可重现。不要用计时器、CSS自动动画、实时网络返回决定成片状态。
- 明确全片帧与`Sequence`局部帧；不要在多个层级重复扣除场景起点。`TransitionSeries`的重叠会缩短总时长，新增转场后重算后续声音位置。
- 制作或视觉修改时尽早启动 Remotion Studio，先验证一个代表性短镜头；已有明确样式或简单修改直接改。按改动选择预览与静帧检查，最终渲染/导出须由用户明确请求。已授权的渲染验证不额外制造用户审批点。

### 4. 音画对齐采用证据分级

**声音突起候选、周期候选、试听确认的拍点、原创设计的音效位置分别记录。** 当前工具不能听音时，继续视觉制作与信号分析，标记声音待试听；不要把本次环境限制写成永久能力限制，也不要把波峰命名成点击声/鼓点。

先选择驱动关系：配乐带动动作、动作决定音效，或旁白带动信息显露。只让关键落点与已选节奏对齐，阅读停顿、长句和持续移动可跨拍。工具与素材允许时，先试听原速，再对重点段减速；减速只用于检查，最终以原速验收。

需要数值辅助时，用 [音轨工具](references/audio-analysis-cli.md) 生成候选，再结合可听证据或用户选择定拍。用 [cue 表](references/audio-sync.md#cue-表与帧换算) 标记音效素材内部的起音/重音锚点，统一换算成工程帧。不要只把音频文件开头贴到动作上。

### 5. 看成片，按问题修

读取[渲染验收](references/render-qa.md)选择与改动相称的检查。连续性检查关键帧和前后几帧；节奏检查连续片段；音画结论需要可听的导出片。结构校验、静帧、可播放MP4和实际试听分别报告。

交付用户要求的工程/视频/分析，附简短说明：复用了哪些手法、实际渲染/查看/试听了什么、剩余限制。只交付技能时无需额外制造宣传片。制作请求应完成授权的渲染与修正，不停在建议清单。

## 随包工具与使用边界

所有路径以本技能目录为基准。脚本仅读取本地素材并写到显式输出目录，不联网上传、下载、安装软件或修改原视频。

- [scripts/sample_frames.py](scripts/sample_frames.py)：按目标时间找实际帧PTS并生成联系表；[用法](references/frame-sampling-cli.md)。
- [scripts/analyze_audio.py](scripts/analyze_audio.py)：原声道检查、声音突起/周期候选和低能量区间；[用法](references/audio-analysis-cli.md)。
- [scripts/compile_cues.py](scripts/compile_cues.py)：将已设计或已核对的音效锚点转换成帧位置；[示例输入](assets/cue-sheet.example.json)。不会把候选自动升级为已验证。

只在当前任务受益时运行工具。依赖缺失时先查现有运行时；按任务授权补齐必要依赖或报告具体限制，避免全局改环境。无需为了使用镜头配方重新下载原片。

十条原片的来源、时间段和已知边界见[参考目录](references/reference-catalog.md)。包内不附原片、品牌图形或配乐；用户制作的成片使用其内容及可用素材。参考风格不会授权发布、上传或改动线上业务。
