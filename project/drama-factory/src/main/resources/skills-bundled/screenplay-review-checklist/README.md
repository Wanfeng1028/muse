# 编剧审查清单 · Screenplay Review Checklist

一个给 AI Agent 用的「对抗式剧本 / 故事踩雷诊断」Skill。让模型拿一份 **37 条判据**的清单，对你的故事**只找茬、不夸奖、逐条给证据**，并在最后邀请作者反驳——把雷翻成承重墙。

> 核心立场：审查不是打分，是让作者产生「值得写下去」的冲动。

---

## 它能查什么

七层、37 条判据（🔴 致命 / 🟠 严重 / 🟡 提示 三级输出）：

| 层 | 内容 | 判据数 |
|---|---|---|
| A | 创意立意 | 5 |
| B | 人物 | 9 |
| C | 因果结构 | 9 |
| D | 空间 · 可拍摄性 | 5 |
| E | 语言 · 情绪 | 5 |
| F | 节奏 · 焦点 | 2 |
| G | 伦理 · 态度 | 2 |

另有 **R-01~R-07 形式适配规则**：识别长会话角色扮演（RP）导出、AI 共创等特殊形式下的合法手法，避免把「视角互换」「物件链含蓄承载」「扮演者隐藏关键人设」等**创作策略误判成缺陷**。

## 两种审查模式

- **A 直接审查**：模型直接对照清单输出分级报告，适合独立创作。
- **B 子 Agent 对抗式审查（推荐）**：作品若被任何 AI 参与过创作 / 评价，主模型会有一致性偏差；改由独立模型跑第一轮初判，主模型只做「证据核验 + 重新分级 + 成稿」，用行号逐条核到原文，剔除幻觉证据。

## 六步流程

1. 红灯检查点（强制询问审查模式，用户拍板）
2. 判定故事形式 → 注入对应形式适配规则
3. 按清单逐层审查
4. 子 Agent 初判（B 模式）→ 编辑核验
5. 按模板成稿（🔴🟠🟡 分级 + 未踩雷领域）
6. **邀请作者反驳**——这是本 Skill 的对话核心：作者说了算，把雷翻成承重墙。

## 安装

复制到任意 Agent 平台的 skills 目录即可：

```bash
# Claude Code
cp -r . ~/.claude/skills/screenplay-review-checklist/

# Minis（iOS）
cp -r . /var/minis/skills/screenplay-review-checklist/
```

本质是一份「说明书」：SKILL.md 是主流程，references/ 是判据与适配规则。任何 OpenAI 兼容模型都可以把 SKILL.md + references 拼进 system prompt 直接执行（详见 SKILL.md 第三步的跨环境说明）。

## 使用

直接对 Agent 说：

> 帮我审查这个剧本 / 这个故事有什么问题 / 帮我审审 / 编剧审查

或命中 `编剧审查清单` `审查剧本` `剧本诊断` `作品评估` `踩雷` 等触发词。
