# 真实演技对话提示词 — Seedance 对白表演生成器

将用户的**剧本/对白场景**（双方台词 + 情绪走向）转化为**带真实感表演编排的 Seedance 提示词**。

核心命题：AI 对白假，是因为默认"轮流念稿"。真人对话充满抢话、停顿、口吃、改口、声音重叠——**写对白提示词的本质 = 设计两个人物情绪在同一时间碰撞、拉扯、归于沉默。**

## 核心公式（时间轴层）

```
[时间码] + 说话人 + 台词（含触发词） + 面部生理反应 + 音量/动作 + 话权切换 + 对方同步反馈
```

**话权切换**是灵魂：提前插话 / 触发抢话 / 冷静修正 / 沉默留白（详见 references）。
**言语不流畅**按心理类型对号入座，卡顿落位在转折词/人称/对方名字上（详见 references）。

## 铁律

- **防翻车三件套**（写入每条对白提示词的约束段）：禁止轮流念稿 / 禁止自动补全被打断的句子 / 杜绝机械重复口吃。
- **话权与反馈必写**：每条对白必须包含"话权切换"和"对方同步反馈"两项，缺一不可。
- **卡顿落位**：口吃/停顿必须写在转折词、人称、对方名字上；均匀结巴 = 滑稽，禁止。
- **不询问界面参数**：画幅比例（16:9/9:16）、分辨率（720p/480p）、视频时长——即梦界面直接选，禁止写入提示词、禁止在问答中询问。提示词只写内容（场景/角色/表演/台词/声音/禁止项）。
- **时间戳相对化（多片段项目铁律）**：每个提示词是独立生成的视频文件——`[X-Y秒]` 一律从本片段第 1 秒（0s）起算，禁止用全片绝对时间；片段在全片的位置标注在提示词外（片段说明/文件名），不写入提示词正文。
- **参考图防火墙**：提示词中声明"参考图仅锁定外观，姿态/动作/机位/表情以正文为准"。
- **默认中文输出**：提示词默认中文——除非用户明确要求英文。
- **成片自检三要点**：① 人物声音是否存在重叠 ② 口吃/卡顿是否搭配呼吸与口型同步 ③ 双方情绪能否互相承接（A 的情绪是 B 反应的触发词）。
- **修改分层**：改场景改全局层、改人设改人物层、改表演改时间轴层、改氛围改兜底层——只动对应层，不重写全词。

## 持械对白戏：道具指向与视线一致性（2026-09-16 增补）

**症状**：人物手持枪械/工具对准某个目标，出片后"眼睛看 A、枪口指 B"，两者对不上。

**根因三条**（排查顺序）：
1. 提示词只写了"握着枪"，**没写道具指向哪里**——模型默认让道具自然下垂或随意朝向。
2. **视线落点与道具指向没有绑定到同一个空间锚点**——一个写"看向画外低处"，另一个写"枪口向下低垂"，两条指令各自为政。
3. 道具在画面里**没有可见的视觉锚**（长期在画外或仅露一角），模型无法自我校验，只能自由发挥。

**解决四招**：
| 招 | 写法 |
|----|------|
| 立空间锚点 | 全局层单列一行：`画面外低处地面上放着某物，位置在腰部以下、画框下缘之外；她的视线落点与枪口指向必须严格指向这同一个点` |
| 给道具可见的视觉锚 | 让道具进画：`画面右前景能看到枪管的一段与枪口，处于浅景深虚焦中，轮廓柔化但清楚指向画面外下方那个点`——虚焦枪口既当视觉锚，又不抢面部特写的焦点 |
| 每个点位变化都重写同步 | 道具放下/举起是两次新的"指向建立"：放下写"枪管与枪口从画面下缘退出镜头"，重新举起写"虚焦枪管与枪口回到画面右前景，双眼同步抬起重新锁定该点，视线与枪口再次严格对齐" |
| 约束段锁死 | `双眼视线必须与枪口指向严格一致，始终落在画面外同一个点上，视线不得看向别处、枪口不得左右偏移` + `画面中必须始终能看到前景虚焦的枪管与枪口（放下枪时除外）` |

**道具动作弧线当情绪节拍用**：放下道具 = 卸下防备/情绪让步，重新举起 = 重新武装自己/恢复立场。把"放下—举起"写进时间轴层，与台词节拍对齐（例：擦泪时放下枪 → 说台词时重新举起），道具就成了第二套表演语言。持长枪写"双手持枪、枪托贴肩窝"更可信，单手擦泪前必须先放枪。

## 唇部表演的防崩写法（2026-09-16 增补）

**症状**：写"抿嘴 / 咬紧牙关 / 嘴唇发抖"这类唇部小动作，出片后嘴部结构杂乱、多出一堆东西，难看。

**根因四条**：
1. **唇部是高密度几何区**（唇线、唇珠、人中、口角、牙齿、黏膜全挤在一小块），一旦被"压缩"，AI 极易多画唇线、露出牙齿、口角撕裂、双唇融成一块。
2. 中文的"抿"本质是**压缩动作**，模型会去挤压唇形几何，而不是压住情绪。
3. **特写放大误差**：嘴在画面里占比越大，唇部失误越显眼。
4. 缺少"不露齿 / 不露黏膜 / 不多余唇线"的**负向约束**。

**四招解决（按优先级）**：
| 招 | 做法 |
|----|------|
| ① 情绪移交上半脸（最强） | 让眉心、下眼睑、鼻翼、咬肌、下颌线、喉头承担 90% 的情绪，嘴只负责"自然闭合"。人物层先写一句"她的情绪主要由上半张脸与颈部承担，嘴部保持克制简洁"——这句一写，模型就不会拿嘴演戏 |
| ② 删掉一切压缩词 | "抿嘴"→"嘴唇自然闭合、唇形放松不受挤压"；"咬紧牙关"→"**咬肌收紧、下颌线绷住**"（用肌肉发力替代唇形变形） |
| ③ 只留低风险小幅动作 | 唇角极轻微向下、双唇松开一线；一律加"极轻微/很轻"限定幅度 |
| ④ 约束段写死 | `不做抿嘴、紧咬、挤压唇形等会让唇部结构变复杂的小动作；不露牙齿、不露牙龈、不露口腔内部；唇线轮廓清晰完整，不出现多余唇线、唇纹、褶皱或黏膜；双唇张合幅度小且自然` |

**替换词库**：
| 易崩（别用） | 稳妥（改用） |
|---|---|
| 嘴唇紧抿成一条线 | 嘴唇自然闭合，唇角极轻微向下 |
| 咬紧牙关 | 咬肌收紧，下颌线绷住 |
| 嘴唇发抖 | 双唇很轻地松开一点，颤动走喉部与呼吸 |
| 努力忍住泪水 | 下眼睑受挤发亮 + 眉心微蹙 + 喉头艰难吞咽 |
| 悲痛的嘴 / 嘴角抽搐 | 双唇自然松开一线，唇形始终干净 |
| 用力嘟嘴 / 撅起嘴唇（撒娇、要亲亲） | **双唇向前收拢成一个小小的圆形突起**——这是嘴唇的**前突**，不是向内的挤压；唇角自然、不压唇线 |

**前突 ≠ 压缩（2026-10-03 增补）**：上面禁的是"压缩型"唇部动作（抿、咬、压），
但剧本里确实会有**必需的唇部动作**——撒娇嘟嘴、要亲亲、吹气、学小孩。
这类动作的关键是**只让嘴唇向前突出，不让上下唇互相挤压**：写"双唇向前收拢成小型圆形突起"，
配合"不露牙齿、不露牙龈、唇角自然"的负向约束，出片稳定。
反例：写"嘴唇紧紧撅起来"、"用力嘟嘴"——模型会去做压缩，唇线立刻多出来一层。

**构图兜底**：嘴部特写时别把嘴唇在画面中的占比推到极限，或改用轻微侧脸——唇部越小，越不容易崩。

## POV / 单方出镜的对白戏（2026-09-29 增补）

**适用**：一方是"视点人物"（男友/我/镜头持有者），全程不出镜、只有画外音；另一方正常出镜对着镜头说话。常见于男友 POV、第一人称短剧、单人演双角。

**核心难点**：本 skill 的铁律要求每条对白都写"对方同步反馈"，但视点人物**没有脸可写**——不处理就会变成单口念台词。

**七条改写规则**：

| # | 规则 | 写法 |
|---|------|------|
| 1 | 视线锚死 | 出镜方的视线必须**全程落在镜头上**（＝看着视点人物），写进约束段，防止她眼神乱飘失去 POV |
| 2 | 同步反馈换载体 | 视点人物的反馈**只走两条通道**：① 画外音里的语气/换气/停顿/气音 ② 机位极轻微的晃动或微推。禁止写"他喉结滚动/肩膀一僵"这类可见反应 |
| 3 | 画外人物的性格不能省 | 看不到脸时念稿感更强，人物层必须给视点人物写底层性格与情绪基调，让语气有出处 |
| 4 | 画外音的空间感 | 写"声音位置在镜头后方、视点处，近讲人声质感，不抢画面"；出镜方声音则在画面前方形成距离差 |
| 5 | 留白要写更长 | 看不见表情，节奏全靠台词缝隙。沉默段比常规对白戏再拉长一点，并把"无声时她在做什么"写具体（理被角、收紧怀里、瞟镜头） |
| 6 | 机位纪律 | 全程不移动位置，构图变化**全部来自出镜方的动作**；允许一次"小到几乎看不出来"的微推（模拟视点人物的呼吸前倾），明确禁止变成明显推镜 |
| 7 | 身体不入镜要写死 | 约束段单列：视点人物的手、手臂、腿、肩、衣角全程不得入镜，他只能以声音存在 |
| 8 | 视点人物的"手部动作"怎么处理 | 剧本里他要按电梯／开门／递东西时，**不写他的手入镜**，改写成"镜头随他的视线下摇，画面里只看到被操作的东西（按钮面板／门把／杯口），物件发生动作＋一声对应的动作声（按键'咔哒'、门锁'咔'）"，手全程留在画外。这样既保住了"人不入镜"，又让他的动作有可见证据 |

**POV 结尾的"亲到镜头外"写法（2026-10-03）**：出镜方主动亲视点人物时，用**贴近—越界**两级动作：
先写"她的脸在画面里越来越大，嘴唇不断向镜头贴近"，再写"**整张嘴越过画框边缘、消失在画面之外**，
画面里只剩她的眼睛与鼻梁的一部分"，最后配一声**画外的轻吻气声**。
关键：① 越界后必须明确"画面里还剩什么"（剩下的部分要写具体，否则模型会把她整个人弹开或直接切空镜）；
② 亲吻声放在画外，是这一个动作唯一的证据；③ 约束段写死"结尾不出现她后退、不出画、不出现空场景"。

**话权设计的增益**：POV 视角下"打断"的笑点被放大——出镜方话尾未落、画外音一句秒回切掉，观众看不到打断者的脸，反而更利落。写这种"秒拒"时明确标注**声音重叠约 0.2 秒**，并禁止模型自动补全被打断的那半句。

**参考图防火墙补一句**：`参考图仅用于锁定出镜方外观与场景陈设，其姿态、动作、机位与表情以本提示词正文为准。`
