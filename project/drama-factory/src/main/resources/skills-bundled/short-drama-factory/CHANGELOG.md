## v4.3 体量与语速重校（2026-09-28）

> **起因**：实拍生视频实测 ≈ **15 秒 / 95 字**（6.33 字/s 触顶），而旧写作目标 5.0 / 校验下限 3.5 偏低，导致成稿只有标称时长的 40~50%（写薄）。
> **一度上调过头**：曾按「全片均值 = 局部上限 5.5 字/s」上调（体量 1050~1400 等），但那等于要求整集 ~90% 时间都在说话、寄不出动作/留白/转场，正是"为密度而堆台词"。
> **最终口径（当日回调）**：**95 字/15 秒是「连续对白时的局部上限」，不是全片均值**；全片对白时间占比宜 60~75%，其余留给动作/留白/转场 → **参考语速 4.5 字/s**；**E16 按 4.5 字/s 比对、容差放宽到 ±20%**（动作拍 1.5s）；体量改为**宽参考带**（只抓极端）：标准 480~850 / 长档 820~1400 / 漫剧 330~620 / 长档漫剧 660~1150；DLG_TARGET 参考中值 → 90s:400 / 120s:540 / 150s:670 / 180s:800 / 195s:870；**密度原则**：密度由戏定（攻防场说满、危机/动作场让画面说、转场余波可极简），防注水靠失衡阀 E19（连续对白≤95字）＋ E21（对白占比≤70%），不靠堆字数。
> **LOOP 3×5 分钟压测补丁（2026-09-29）**：自跑三轮 5 分钟（300 秒）剧本发现并修复 4 处规则错——① **E4 误杀行动型**（其开场是“反常动作”，不含嘴仗冲突词）→ 新增 `ACTION_SIGNALS`，行动型可用反常动作词；② **行动型动作拍权重偏低**（×2.5 抛不起 5 分钟）→ **×4.0**（混合 ×2.5）；③ **E1 参考带对行动型偏高**（×5.0~7.6 是对话型假设）→ **按形态微调（①5.0~7.6／混合4.2~6.5／②行动型3.5~5.5）**；④ **场景上限对长集太紧**（300 秒只准 3 场）→ **自定义时长时场景上限随集长放宽（≈每75秒1场）**。同步新增 T9 回归（行动型反常动作开场不应报 E4）。

> **同日增补**：① 体量改为**随【本集时长】动态推导的参考带**（时长×5.0~7.6 字/秒；超参考带**只提示、不拦**——用户可说“我这集 4 分钟”，不会拿短档去卡它；仅低于参考带 0.5 倍=极端空稿才 FAIL）；② 新增 **E22 台词用语/错别字**（常用误用对照表，如 竞然/迫不急待/按耐/走头无路/掉过钱…，**WARN 只提示不拦**）；③ 新增 `references/conflict-modes.md` **冲突形态五型**（①对话型/②行动坚持型/③身份错位型/④关系情感型/⑤规则谜题型；认型≠都放宽，**仅②放宽机检**），单集新增必填字段 `【冲突形态】`；配套机检适配（按五型问题清单）：**行动型 E9 对白行减半、E21 下限 10%、E16 动作拍权重 ×4.0s**（P0-1：否则行动型被标长报虚标/标短报降级两头夹）；**混合型中间档**（E9 8→6、E21 下限 15%，P1-1）；**E23 升 FAIL**（行动型无质疑者＝对手位缺失，P1-2）；**N13 堆动作对行动型/混合豁免**（P2-1）；缺口补齐——前三集节拍卡加**行动型变体**、台账回合表加**行动型登记语义**（前兆实据档/准备验证档）；懒加载矩阵模式 3 挂载该文件。
