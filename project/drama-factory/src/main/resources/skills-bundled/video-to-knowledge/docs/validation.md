## 平台差异与真实失败

- YouTube 匿名 yt-dlp + Node 路线成功；样本是 19秒历史公开短视频，不证明新视频挑战、长视频、区域限制或账号场景。
- B站先检查到 31分钟样本可取得格式，最终采用 90秒分P样本完成下载和解析；不把预检当全视频下载。
- 抖音使用已登录 Chrome 里的目标播放器，复用正常页面会话，不导出 Cookie。
- 小红书匿名样本没有取得媒体，搜索结果中也有图文。图文被明确拒绝，未伪造字幕。
  当前视频页面流以 EF4/EF5 分组，而不只是 h264/h265，masterUrl 还使用 HTTP。
  适配器枚举所有媒体流、将允许的 xhscdn.com 地址升级为 HTTPS，再于页内传输。
  成功文件 ffprobe 实测 HEVC+AAC。没有加入解密、验证码或付费绕过。
- ffmpeg 默认多线程 JPEG 编码在本机测试中失败，固定输出编码线程为 1 后通过；尾部采样预留帧边界。
