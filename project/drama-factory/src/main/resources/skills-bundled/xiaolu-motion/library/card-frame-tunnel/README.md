# card-frame-tunnel · 画框隧道

一层层嵌套的描金画框向深处排列，每层比上一层多转 5°；镜头向前推，画框一层层从镜头边擦过，最后停在最里层的画布上，金色标题“下一幕 / ACT II”聚焦出现。全屏卡，4.5 秒，1080×1920，30 fps，带合成音效。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 做法

- 画框按真实线脚做：外沿、珠串、凹弧、平面、S 形线脚、内衬、内沿七段，每段是四条梯形渐变，按“顶光最亮、左侧次之、右下最暗”分别打光；近处的画框才画珠串和四角的叶形雕饰（远处看不出来就不画）。有三种风格轮换：描金、黑漆描金边、浅金。
- 全部是矢量绘制，按 1/z 透视缩放，所以擦过镜头时放大到 6 倍也不糊；远处的画框逐渐融进暖红的雾里。
- 每隔一层有一盏黄铜画灯，灯光同时画进辉光层；空气里有浮尘。
- 推镜曲线：慢起步、长段高速、柔和落地；镜头的滚转和画框的累计转角对冲，保证最后停下时最里层画框是正的。高速段每帧 12 个子帧运动模糊。

## 适合场景

章节转场、“进入下一部分”“深入一层”、作品集/展览类内容的片头；最里层标题和小字可改。

## 主要参数（`src/build.py` 的 `PARAMS`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `title` / `sub` | 下一幕 / ACT II | 最里层画布上的字 |
| `frames` | 9 | 画框层数（含最里层） |
| `twist` | 5° | 相邻画框的转角 |
| `t_push` / `t_arrive` | 0.25 / 3.2 s | 开始推进、停在最里层 |
| `gold` / `wall` | — | 金色高光、深处底色 |

## 声音

每一层画框擦过镜头时一声左右交替的 whoosh（擦过时刻由组件按推镜曲线反解出来），底下一条随推进上扬的 riser 和一层低音垫（D/A），到达时一记轻冲击 + D5 钟声，标题出现时一层 `shimmer`。成片 −30.5 LUFS / 峰值 −16.4 dBTP。

## 重渲

```bash
cd library/card-frame-tunnel/src
python3 build.py stills --times 0.3 1.4 2.4 4.2
python3 build.py render --out <输出目录>
```

字体：思源宋体 Heavy、思源黑体 Medium（`fonts/`）。
