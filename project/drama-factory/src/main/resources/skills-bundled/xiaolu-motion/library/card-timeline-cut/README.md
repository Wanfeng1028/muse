# card-timeline-cut · 时间线剪口（波纹删除）

微距视角下的一条剪辑时间线：播放头扫到入点，一把钢刀片落下切开视频轨和音频轨（火花），播放头跳到出点再切一刀；中间片段被选中、抬起、翻转掉落，右边所有片段整体左移合拢，“咔”一声卡到位（波纹删除），总时长读数从 00:48 滚到 00:41。全屏卡，4.4 秒，1080×1920，30 fps，带合成音效。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 做法

- 时间线先平面画在一张 1600×820 的画布上（标尺、标题轨、带缩略图的视频轨、带波形的音频轨、播放头），再逐条按透视贴到屏幕上，得到一个向远处倾斜的平面；远端混入一张模糊版本，形成浅景深。
- 刀片是一把美工刀片（直背、长刃口磨斜面、刃口琥珀色高光），沿透视后的剪口斜线落下；每一刀在两条轨上各溅出一串火花，切口亮一下再暗下去，画面有 1–2 帧色散和轻微震动。
- 被删片段：选中红框 → 抬起 → 翻转掉落 → 淡出；右侧片段用 cubicOut 左移，到位后小弹簧回弹一下，接缝处闪一下光。
- 读数是固定字宽的里程表：数值下降时个位数往上滚，滚动期间和刚到位时是琥珀色。

## 适合场景

讲剪辑、删废话、“自动剪掉停顿 / 气口”、效率提升；数字和片段名可以改。

## 主要参数（`src/build.py` 的 `PARAMS`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `clip` / `audio` / `title` | 口播_A01.mov / 人声 / 标题 | 三条轨上的片段名 |
| `total0` | 48 | 剪前总长（秒） |
| `removed` | 7 | 删掉的秒数（也决定两刀的间距） |
| `label` / `sub` | 波纹删除 / RIPPLE DELETE | 顶部标题 |
| `amber` | #FFB23E | 播放头、刀光颜色 |

## 声音

本条目合成两个音效：`scissor_snip`（两片钢刃合拢：刃口摩擦声随合拢变亮，最后一下清脆的“嚓”和金属余振，同步点在合拢那一帧）和 `latch_click`（卡扣扣上：两下紧挨的咔嗒 + 低频体感）。另有播放头移动的 tick/whoosh、片段抬起的 pop 和下坠 whoosh、合拢滑动的 whoosh，读数每减 1 秒一个 tick，停住一声 `tock`；底下是剪辑室的低频底噪和很轻的 60 Hz 电流声。成片 −32.9 LUFS / 峰值 −8.8 dBTP。

## 重渲

```bash
cd library/card-timeline-cut/src
python3 build.py stills --times 0.6 1.0 2.2 3.8
python3 build.py render --out <输出目录>
```
