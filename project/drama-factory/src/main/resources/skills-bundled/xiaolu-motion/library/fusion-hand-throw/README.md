# fusion-hand-throw · 手势抛字

真人口播里每说到一个风格名，手一甩，这个词就从手的位置冒出来、跟着手走一小段，再顺着手的运动方向被抛出去，沿头部右侧飞上去贴在墙上：拼接、胶片、杂志、发布会，每个词的样式就是它说的那种风格（拼贴纸片、胶片框、杂志刊头、发布会幻灯）。手甩得最狠的那一下（“杂志”）抛得最远。人物像素不做任何改动，字不压脸、不压嘴、不进字幕带。4.5 秒，1080×1920，30 fps，带原声。

## 用了哪段素材，怎么找到的

- 先对视频20 锁定母版里所有真人片段做了一遍粗扫：人脸逐帧、手部姿态隔帧（Vision `VNDetectHumanHandPoseRequest`，每个进程 ≤ 300 帧）。按“同一只手、至少 5 个可信关节、连续多帧同向位移”找挥手动作。第一个候选（第 1760 帧）其实是检测结果在两只手之间跳变，并没有真的挥手；空着的那只手大多在画面左边缘外，Vision 很少认到。持麦的手全程能被稳定追踪。
- 最终选第 2550–2685 帧（v2 时钟 85.0–89.5 s），原话“比如拼接的、胶片的、杂志的、发布会的等等”：列举时持麦的手每说一个就往上一顿，“杂志”那一下最明显（第 2620–2625 帧，0.17 秒里上扬约 210 px，方向是远离脸的右上方）。
- 出手帧由组件自己从手部数据里找：取指根关节（MCP）连成的手背顶边，高斯平滑（σ = 1.2 帧，去掉单帧拟合跳变），在每个词开口前 0.35 s 到后 0.25 s 的窗口里找“向上（稍向外）速度”最大的那一帧。本段四次出手在 0.43 / 1.47 / 2.40 / 3.43 s（原片第 2563 / 2594 / 2622 / 2653 帧），峰值速度 839 / 552 / 1001 / 616 px/s。

## 做法

- 出手前 0.16 s：词在手背上方弹出（backOut 放大），逐帧跟着手的位置走（子帧之间对手的位置插值，所以跟手有真实运动模糊）。为避开字幕带，跟手时的高度不低于 y = 1370。
- 出手：沿二次贝塞尔飞 0.5 s，控制点放在起点和终点的右侧，所以路径贴着画面右边上升，不会穿过脸；飞行中旋转、放大到 1.0，出手点有一小簇光点。
- 贴住：四个词从上到下排在头部右侧（x ≈ 985，y 285–630，在所有帧的人脸框以右），落下时小回弹并出现贴墙的阴影。
- 每个词的样式：拼接 = 撕边牛皮纸 + 胶带；胶片 = 黑底齿孔胶片框；杂志 = 白底红色衬线刊头 + 黑色细线；发布会 = 深色玻璃幻灯片。

## 适合场景

口播里的列举、清单、“把 A 丢给 B”；任何能被 Vision 追到手的片段都能用，换片段时改 `PLATE`、`words`（每个词开口的时间）和 `slots`（贴在哪里）。

## 主要参数（`src/build.py` 的 `PARAMS` / `PLATE`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `PLATE.start` / `end` | 2550 / 2685 | 底片帧范围 |
| `words` | 拼接 0.54 s / 胶片 1.49 s / 杂志 2.50 s / 发布会 3.33 s | 词、开口时刻（本镜头内）、样式 collage / film / mag / keynote |
| `slots` | 右侧一列 4 个位置 | 每个词贴住的位置 [x, y, 旋转度] |
| `flight` | 0.5 s | 飞行时长 |
| `window` | [−0.35, 0.25] s | 在开口前后多大的窗口里找出手帧 |

## 声音

原声 + 每个词：在手上冒出一颗 `pop_soft`（音高依次升高）、出手一声 whoosh（音量和亮度随这一下甩手的速度变化）、贴墙一声本条目合成的 `tag_stick`（纸片拍在墙上）。成片 −16.5 LUFS / 峰值 −2.6 dBTP。

## 重渲

```bash
cd library/fusion-hand-throw/src
python3 build.py prep --plate <plate_v2_video.mp4> --voice <voice_master_48k.wav>   # 人脸 + 逐帧手部姿态 + 逐帧画面
python3 build.py stills --times 0.45 2.3 2.5 4.4                                     # 输出里带 timing：出手时刻和速度
python3 build.py render --out <输出目录>
```

## 核验（2026-09-27）

- 肤色：人物未做任何处理，人脸区域与原片平均差 1.0 级（重编码），平均色差 < 0.2 级。
- `python3 -m qa.pixel_qa`（9:16 档，23 帧）：PASS，无压脸、压嘴、字幕带、顶栏问题。
