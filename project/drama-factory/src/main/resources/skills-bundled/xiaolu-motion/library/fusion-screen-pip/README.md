# fusion-screen-pip · 穿进录屏

真人全屏口播缩进一个约 300×400 的圆角框（按人脸追踪取景，始终露出头和上半身），停一拍，然后飞进一个录屏界面，落在窗口右下角的主播小窗位；随后界面开始工作：素材加载进预览、任务逐项打勾、片段落到时间线上。人物像素只做缩放，不调色。4.0 秒，1080×1920，30 fps，带原声。界面是通用样式，没有任何产品名或平台名。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 用了哪段素材

视频20 锁定母版 `plate_v2_video.mp4` 第 3477–3597 帧（v2 时钟 115.9–119.9 s），原话“完成前三步之后 Agent会进行视频的剪辑”：前半句缩进圆角框，说到“Agent…”时飞进界面。

## 做法

- `prep`：Apple Vision 人脸（`VNDetectFaceLandmarksRequest`）逐帧给出人脸框和嘴唇框。
- 取景：由整段人脸框算出一个 3:4 的裁切（本段为 x 53、y 255、960×1280）：顶边取“最高的人脸框再往上半个脸高”和“让脸落在取景上 42%”两者中更高的那个，所以头发不会被切；宽度固定 960，覆盖整段人脸框（x 180–874）。
- 缩进：源裁切从整帧插值到 3:4 裁切，目标框按对数插值缩到 300×400，两者的宽高比始终一致（不拉伸），圆角和白边随之出现；背后的界面同时由虚到实。
- 飞入：二次贝塞尔弧线，飞行中轻微放大和倾斜，落位后小回弹，小窗位亮一圈；落位前预览区是虚化、压暗的占位画面，落位后“加载”成清晰的同一段画面。

## 适合场景

讲工具、演示操作、“我把它交给 AI 处理”这类从真人转到录屏的衔接；换成别的界面时，只需要改 `drawWindow()`。

## 主要参数（`src/build.py` 的 `PARAMS` / `PLATE`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `PLATE.start` / `end` | 3477 / 3597 | 底片帧范围 |
| `pip` | [300, 400] | 小窗尺寸（3:4） |
| `t_shrink` | [0.45, 1.15] s | 缩进圆角框 |
| `t_fly` | [1.38, 2.02] s | 飞进界面 |
| `title` / `tasks` | 口播剪辑 · 自动成片 / 识别口播…混音配乐 | 窗口标题、任务列表 |
| `accent` | #5B8CFF | 界面强调色 |

## 声音

原声 + 缩进时一声 whoosh、停住一颗 `pop_soft`、飞入一声快 whoosh、落位 `land`，任务打勾 `ui_click`、片段落位 `tick`。成片 −16.9 LUFS / 峰值 −1.8 dBTP。

## 重渲

```bash
cd library/fusion-screen-pip/src
python3 build.py prep --plate <plate_v2_video.mp4> --voice <voice_master_48k.wav>
python3 build.py stills --times 0.8 1.25 1.7 3.8
python3 build.py render --out <输出目录>
```
