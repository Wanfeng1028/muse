# fusion-word-behind · 字在人后

真人口播上，一个巨大的“开源”立在人和墙之间：说到这个词时它对焦落定，头部挡住两个字的内侧下半部分；随后镜头缓慢推近，墙、字、人按不同速度运动，形成轻微视差。人物保持原片颜色，没有调色、压暗或变黑白；字不压脸、不压嘴。4.67 秒，1080×1920，30 fps，带原声。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 用了哪段素材

视频20 锁定母版 `plate_v2_video.mp4` 第 1586–1726 帧（v2 时钟 52.867–57.533 s），原话“它其实就是一个开源的 动效库加音效库加风格包”；“开源”在 53.947 s，即本镜头 1.08 s。声音是同一时钟的 `voice_master_48k.wav` 对应段。

## 做法

1. `prep`：Apple Vision `VNGeneratePersonSegmentationRequest`（accurate，1512×2016 掩膜）逐帧抠像，每个进程最多 300 帧、每帧 autoreleasepool；掩膜精修（保留主体连通域、补小洞、掉帧用邻帧修补、按运动自适应的时间平滑）。
2. 干净背景：把没被人挡住的墙逐帧加权平均（本段看到 44.7% 的墙），其余用修补填上；它只用在人物边缘附近。
3. 三层：墙 = 原片，只把人物区域（外扩 24 px 羽化）换成干净背景；字；人 = 原片像素 + Vision 掩膜作 alpha。半透明边缘（发丝）用已知墙色反解出前景色 F = (C − (1−α)B)/α，所以发丝压在蓝字上没有米色毛边。
4. 视差：推镜到结束时墙 ×1.022、字 ×1.042、人 ×1.062，水平漂移 −6 / −13 / −20 px；字在墙上投一层柔和阴影。

## 适合场景

口播里的关键词、标题式强调、杂志封面感的“字在人后”；适合头部相对稳定、背景干净的镜头。换片段时，先按人脸位置决定字的高度（头顶以上的墙最好留出字的上半部分）。

## 主要参数（`src/build.py` 的 `PARAMS` / `PLATE`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `PLATE.start` / `end` | 1586 / 1726 | 底片帧范围 |
| `text` | 开源 | 人身后的词（建议 2 字） |
| `at` | 1.08 s | 字对焦落定的时刻（= 说出这个词的时刻） |
| `color` | #2448C9 | 字色（深发色在它前面对比清楚，米色墙上也醒目） |
| `size` / `y` / `gap` | 400 / 360 / 150 px | 字号、字面中心高度、两字之间留给头部的空隙 |
| `push` / `drift` | [1.022, 1.042, 1.062] / [−6, −13, −20] | 墙/字/人结束时的缩放和漂移 |

## 声音

原声 + 字落定时一个反向吸气收尾、轻冲击和一颗低音 `pluck`。成片 −16.5 LUFS / 峰值 −1.9 dBTP。

## 重渲

```bash
cd library/fusion-word-behind/src
python3 build.py prep --plate <plate_v2_video.mp4> --voice <voice_master_48k.wav>   # 约 1 分钟，峰值内存 < 1 GB
python3 build.py stills --times 0.2 0.9 1.4 4.5
python3 build.py render --out <输出目录>
```

中间文件（逐帧 PNG、掩膜后的人物、背景、人脸 JSON、原声片段）写在 `--work` / `$XM_WORK`（默认 `out/work`，已被 git 忽略），可随时删。编译 Vision 工具需要 Xcode 命令行工具（`swiftc`）。

## 核验（2026-09-27）

- 肤色：前几帧（无缩放）人脸内部与原片平均差 0.82 级；整段人脸平均色与原片相差 < 0.6 级。
- `python3 -m qa.pixel_qa`（9:16 档，每 0.2 s 采样 24 帧）：PASS，无压脸、压嘴、字幕带问题。
