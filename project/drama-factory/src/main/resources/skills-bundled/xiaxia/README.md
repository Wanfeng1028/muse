# 夏夏

夏夏是一个面向中文电影、动画、短剧与 AI 视频生产的导演分镜 Skill。它把已经确认的剧本转换成具有明确时长、摄影机位置、构图、光影、人物调度、动作因果和连续性的文本分镜，并可在需要时进一步编译为 Seedance 2.5 可执行任务。

## 作者与方法来源

**核心架构、工作流整合与实现：栾意 <luanyi824@outlook.com>。**

夏夏的核心架构包括剧本事实锁、时长预算、段落判型、生成组体系、导演分镜格式、Seedance 2.5 编译层与自动校验闭环。

**底层电影视觉方法来自造梦师开源项目。**

夏夏关于 Scene Master、摄影机观看位置、真实光源、构图、连续性和反 AI 清理的基础方法，基于并改编自 ZY / popopo-99 的《造梦师：AI时代电影视觉指南》（`zy-cinematic-realism`）：

<https://github.com/popopo-99/zy-cinematic-realism>

## 主要功能

- **剧本忠实转换**：锁定人物、原台词、动作责任、左右手、道具归属、事件顺序和结果，避免 AI 擅自改戏。
- **时长与生成组设计**：按照真实表演和动作耗时，将内容拆为 4–30 秒的连续生成组，自动维护总片时间。
- **导演级镜头设计**：明确摄影机能站在哪里，以及景别、焦段、构图、运动、视线、遮挡和镜尾变化。
- **电影构图与真实光影**：支持三分线、中轴、前中后景、负空间、21:9 横向权力关系和基于真实光源的曝光设计。
- **人物表演与对话覆盖**：设计刺激、理解、反应和选择，并在台词持续时切换听者、第三方或关键物件。
- **动作、战斗与 VFX 因果**：检查起手、发力、轨迹、接触、受力、反作用和结果，持续追踪魔法、机械、伤势和环境战损。
- **连续性控制**：维护人物位置、画面方向、轴线、服装、道具、伤势、空间拓扑、光源和声音桥。
- **Seedance 2.5 编译**：根据任务需要组织普通生成、视频编辑、视频延长和关键帧控制，并明确每份参考素材的职责。
- **自动验收**：使用 `scripts/validate_storyboard.py` 检查生成组时长、时间码、编号、必要字段和交付格式。
- **紧凑文本交付**：默认不展示分镜圣经、生成组地图和内部推理；每组明确要求不要 BGM、不要字幕。

## 使用方式

将整个 `xiaxia` 文件夹放入 Codex 的 skills 目录。提出分镜、镜头脚本、构图、人物调度、动作连续性或 Seedance 视频提示词需求时调用 `$xiaxia`。

示例：

```text
使用 $xiaxia，严格依据这份确认剧本，输出 21:9 完整导演分镜。保留全部台词与事件顺序，不改写剧情。
```
