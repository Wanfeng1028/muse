# 夏夏文本分镜格式

## 正式交付边界

正式输出直接从片名和生成组开始。不要输出分镜圣经、生成组地图、事实账本、资产总表、影调总表、路由记录、质量评分或思考过程。内部锁定仍须完成。

```markdown
# 《片名》完整导演分镜

总时长：05:00｜画幅：21:9

## 生成组 01｜本组 18s｜总片 00:00–00:18

本组任务：一句话说明本组唯一主要变化。

[分镜 001｜0–3s｜3s]：大远景 + 低机位 + 货运井底向上 + 28mm / f5.6 / 固定后轻仰

一个完整导演段落。

[分镜 002｜3–8s｜5s]：……

一个完整导演段落。

组尾连续性：只写下一组必须复现的可见/可听状态。

声音要求：不要 BGM；不要字幕；只保留剧情对白、环境声和动作音效。
```

## 生成组规则

- 每组 4–30 秒，标题写本组时长与总片区间。
- 本组时间码从 `0s` 开始，到本组时长结束；无空档、无重叠、无越界。
- `本组任务`只写唯一叙事变化，不复述整段剧情。
- 同一组只容纳同一地点、内外景和连续时段；按完整事件、台词、动作链与接缝拆分。
- `组尾连续性`只记录下一组实际需要的站位、朝向、手部、道具、伤势、未完成动作、光源和声音桥，不写主题分析。
- 每组最后必须逐字写声音要求；该行之后不再附加内容。

## 单镜标题

```markdown
[分镜 027｜0–3.5s｜3.5s]：中远景 + 平视 + 锅炉街入口斜向内看 + 40mm / f4 / 缓慢前移后停
```

标题依次包含：镜号、组内起止时间、镜头时长、景别、机位高度/角度、摄影机实际位置与拍摄方向、35mm等效焦段、光圈、唯一主要运镜。镜头不需要运镜时明确写固定。

## 单镜正文

每镜写成一个连贯、具体、可复制的导演段落，不拆成固定六栏。段落必须根据本镜需要自然覆盖：

1. **故事瞬间与前因痕迹**：人物正在完成什么，上一动作留下了什么，下一动作从哪里启动。
2. **空间与构图**：主体在21:9中的位置、负空间用途、前中后景职责、真实遮挡、人物/威胁/目的地关系；只选择一种主构图逻辑。
3. **摄影机**：可实际到达的观看位置、距离、高度、焦段产生的空间行为、焦点与景深、运动起点和停止位置。
4. **动作与表演**：动作责任人、必要左右手/支撑脚、动作顺序、视线目标、刺激后的可见反应。每镜只有一个主要动作或信息重心。
5. **光影与材质**：真实主光、次光及可达范围；阴影保留区；哪些皮肤、布、玻璃、金属、液体或尘汽得到高光；曝光与颜色来自哪里。
6. **声音**：只写推动剧情、确认材质/落点、触发反应或承担转场的对白、环境声和动作声。普通衣料、脚步、呼吸不必机械补齐。
7. **镜尾状态**：在段落最后自然落到下一镜可直接继承的可见状态，不使用“镜尾状态”标签也可以，但结果必须明确。

## 节奏与信息密度

- 每镜必须新增空间、位置、动作阶段、物件、说话策略、听者/第三方反应、危险变化、结果或下一镜入口之一。
- 单一眼神、回头、开门、拿放物件或即时反应通常 1–2.5 秒。
- 超过 4 秒的镜头须有长台词、持续走位、连续复杂表演、逐层空间揭示或至少两个因果相连的可见变化。
- 长台词可跨说话者、听者、第三方和关键物件画面连续播放；不得改词、截断或换说话人。
- 快切每镜只完成一个因果节点；长镜头内部必须持续改变人物位置、判断、光线、信息或动作状态。
- 不用空镜、慢动作、重复喘息、重复对视或无关微距填时长。

## 21:9、构图与光影

- 横向空间要承担阶级距离、威胁来向、人物路线、监视或不可接近性；人物放在一侧时，另一侧必须有叙事职责。
- 三分线用于关系与运动；中轴只用于制度、仪式、封锁和明确权力占据；框架、引导线、对角线和多层空间必须由真实门、梁、管道、街道、人物或机械形成。
- 摄影机立场优先：目击、跟随、监视、审判或被阻隔。不要无理由环绕、穿墙、漂浮、瞬间推拉或跨尺度变焦。
- 主光源必须真实存在。允许阴影看不清，不为人物统一补亮；高光只出现在受光且材质允许的位置。
- 风格来自空间、曝光、材质和表演，不来自“电影感、史诗、大片、8K、胶片”等标签。

## 动作与VFX

动作内部按以下因果检查，正文自然融合，不显示标签：

`支撑与起手 → 发力部位 → 轨迹 → 接触/落空 → 目标受力 → 攻击者反作用 → 可见结果`

魔法/VFX检查：

`源点 → 形态与方向 → 速度尺度 → 与介质接触 → 环境受光/受力 → 衰减或残留 → 下一镜持续状态`

切镜不得让人物重新起手、武器复位、能量颜色/方向改变、伤势消失或环境战损复原。同一攻击跨镜时，前后镜必须处在不同阶段。

## 对话

- 原台词逐字保留，标明唯一说话人。
- 先建立轴线和双方朝向；反打视线相向。
- 在关键词、命令、谎言、迟疑、判断变化和句尾切真正受到刺激的人。
- 台词可作为画外连续声音覆盖听者反应或第三方动作，但不能用字幕替代。
- 沉默者的反应必须由可见动作承担：视线、呼吸、握力、停手、重心、距离或延迟回答，不写作者心理解释。

## 禁止格式

- 不要在正式输出中出现分镜圣经或生成组地图。
- 不要每镜机械重复“画面内容、构图、光影、声音、Seedance执行、镜尾状态”等栏目。
- 不要使用JSON、固定镜头配额、每镜统一句序或无关负面词清单。
- 不要用抽象修辞代替可见关系，如“压住画面、承担命运重量、视觉重心被吞没”。
