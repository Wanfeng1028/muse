# 《门槛》校验示例

总时长：00:08｜画幅：21:9

## 生成组 01｜本组 8s｜总片 00:00–00:08

本组任务：人物穿过门槛并发现走廊里的异常。

[分镜 001｜0–3s｜3s]：中远景 + 平视 + 门外右侧斜向室内 + 40mm / f4 / 固定

门框占画面右侧三分线，人物从左侧阴天冷光里走到门槛，室内暗处留出通向走廊的负空间；摄影机隔着半开的门目击，不跟随。她右脚先越过门槛，门把只被室内一盏低位钨丝灯擦出窄高光；风声和鞋底由外向内靠近，走廊没有回应。她在第二步尚未落地时听见金属轻碰，身体停住，视线朝画外右侧。

[分镜 002｜3–8s｜5s]：近景 + 平视 + 门内左侧反拍人物与来路 + 65mm / f2.8 / 缓慢推近后停

人物落在右侧三分线，左侧半开的门保留来路，焦点从她握住门把的右手移到眼睛；门外冷光只切过半张脸，另一半留在室内深暗，低位钨丝灯在瞳孔和旧黄铜把手上形成小面积高光。她没有回头，只把门缓慢拉近，风声随门缝缩小而被压低，画外金属声再次响起；摄影机推到她决定不关门的位置停下，镜尾保持人物朝右、右手握门把、门半开。

组尾连续性：人物站在门内朝右，右手握住门把，门半开；室外风声已被压低，走廊金属声仍未见来源。

声音要求：不要 BGM；不要字幕；只保留剧情对白、环境声和动作音效。
