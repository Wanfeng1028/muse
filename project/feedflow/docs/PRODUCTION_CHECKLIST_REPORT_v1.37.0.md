# 发版对照报告：批量标已读 scope 参数收紧（feedflow v1.37.0）

| 验收项 | 结论 | 理由 |
| --- | --- | --- |
| 可靠性 | 改进 | 非法 scope 不再被静默当作 unread，批量标记的范围不会被误改，接口明确返回 400。 |
| 可观测性 | 无变化 | 本轮仅收紧输入校验与错误返回，未新增日志或指标埋点。 |
| 数据与状态 | 改进 | 被拒的非法请求不会改动任何文章状态，避免误标导致的数据不一致。 |
| 部署与运维 | 无变化 | 纯接口行为收紧，无数据迁移、配置或部署流程调整。 |
| 安全与健壮性 | 改进 | 非法输入返回 400“scope 非法”，与 GET /api/articles、POST /api/clusters/<id>/read 口径一致，消除隐式容错。 |
| 可维护性 | 改进 | 三处接口校验口径统一且合同测试已更新，降低后续维护与排错成本。 |
