## 变更摘要

POST /api/focus 的 startedAt 与 POST /api/import/focus 的 CSV started_at 列增加真实日历日期校验。新增 isRealCalendarDatePrefix helper，采用 Date.UTC 往返比对：2024-02-30、2023-02-29、2026-04-31 拒绝，2024-02-29 闰年通过。错误体文案一字未动。生产改动只在 apps/server/src/routes/focus.ts。新增测试 apps/server/tests/focus-startedat-calendar.test.ts，共 8 例。文档：CHANGELOG 新增 [1.27.0] 一节、docs/API.md 同步 3 处。本轮纯后端校验收紧，无 UI 改动、无数据库迁移、无新依赖、无新端点、无鉴权变更、无配置项变更。
