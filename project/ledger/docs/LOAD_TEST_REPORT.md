## 本轮发现并修复的真问题（压测 harness 侧，非产品）

1. 双重 BOM：生成器输出已带 BOM，测试/脚本又用 utf-8-sig 编码 → 表头 `\ufeff交易日期` 致映射 miss 500。修：统一只保留生成器的 BOM。
2. 子进程 PIPE 死锁：uvicorn stdout/stderr 接 PIPE 无人消费 → 缓冲区满阻塞 → 健康检查超时。修：重定向到 `data/loadtest-tmp/uvicorn.log`。
3. httpx 环境代理坑：本机 `NO_PROXY` 含 `[::1]`，httpx 解析 `URLPattern('all://*[::1]')` 抛 `InvalidURL: Invalid port: ':1]'`，导致任何默认 `httpx.Client()` 构造即失败（测试里因传了 transport 而幸免）。修：harness 内全部 `trust_env=False`。
4. 去重探针断言写错：重传响应的 `parsed` 为 0（全判重），应拿 `duplicates_skipped` 与首月 `parsed` 比。修后精确命中。
