# ledger 项目发版对照报告（PRODUCTION_CHECKLIST）— v2.17.20

> 本报告为**靶向范围发版对照**，针对 v2.17.20 单轮改动逐条对照 PRODUCTION_CHECKLIST 七条，非全量生产签核。

## 一、本轮改动概述

- **版本**：v2.17.20
- **改动内容**：`GET /api/statements/{batch_id}/items` 增加 `status` 参数校验：
  - 非法值返回 400，`detail` 为“status 参数非法”；
  - 合法值为 `preview`、`pending`、`auto`、`claimed`、`skipped`、`duplicate`；
  - `None` 或空串不过滤；
  - 不存在的批次先返回 404。
- **范围外事实**：无 schema 变更、无迁移、无新增环境变量、无 UI 改动（视觉验收不适用）。
