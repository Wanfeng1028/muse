# linkshort 项目发版对照报告 v1.26.0

- 文件：docs/PRODUCTION_CHECKLIST_REPORT_v1.26.0.md
- 性质：靶向发版对照报告（非全量生产签核）

## 版本与改动

- 版本：v1.26.0
- 改动：`GET /api/links/{id}/qrcode.png` 的 `size` 参数校验收紧——非数字值返回 400，错误体为 `{"error": "size 非法"}`；此前非数字值经默认值回落静默按 256 生成；缺参或空串仍默认 256；小于等于 0 仍返回 400（既有行为）；链接不存在仍先返回 404。

## 测试与检查

- 靶向测试：新增 `internal/handler/qrcode_size_validation_test.go` 4 例全绿（`size=abc` 返回 400、无参返回 200 且为 PNG、`size=256` 返回 200 且为 PNG、不存在的链接加 `size=abc` 返回 404）；既有二维码测试同跑通过。
- 全量套件：`go test ./... -race -count=1`，14 个包全部通过（handler 包耗时 243 秒，为最慢项）。
- 静态检查：`go vet ./...` 全洁；本轮 2 个改动文件 gofmt 全洁（新测试文件初版缺文末换行，经 `gofmt -w` 补齐后全洁）。
- 真实服务冒烟（18466 端口 `:memory:` 隔离库，冒烟后服务已停、端口复查已关）：健康检查 200；建链成功；`size=abc` 返回 400 且错误体逐字为 `{"error": "size 非法"}`；无参返回 200 且为 PNG（424 字节）；`size=256` 返回 200 且为 PNG（424 字节）；`size=0` 返回 400；不存在的链接加 `size=abc` 返回 404。

## 环境限制说明

本机当前环境下独立二进制以文件库启动时 sqlite ping 报 disk I/O error（文件库与系统临时目录均复现），故冒烟改用 `:memory:` 隔离库；冒烟验证的是端点行为本身，文件库启动路径未在本轮实测，列为已知限制；单元与全量测试中的文件库用例仍全绿。
