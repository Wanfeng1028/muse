
# linkshort v1.4.0 发版对照报告

- 版本：v1.4.0「密码保护短链」
- 日期：2026-10-16
- 结论：可发版

## 1. 可靠性
- [通过] 测试金字塔：单元（auth 3）+ 集成（store 4，含 v2→v3 真实迁移）+ 接口（handler 8，含门页 200/错码 401/对码 302/burn 联动），`go test ./... -race` 共 73 例全绿，v1.3 的 58 例无回归。
- [通过] 失败注入：v1.2 关库场景用例仍通过；本轮新增"创建时密码落库失败回滚整条短链"，用 store 层错误路径覆盖，不留半吊子链接。
- [通过] 重试/降级/幂等：密码设置走"先建链后设密码，失败回滚删链"；跳转语义与 v1.3 一致，重复 POST 只按一次校验结果处理，无副作用叠加。
- [通过] 迁移版本化：v2→v3 用 `PRAGMA user_version` 标记，`password_hash TEXT` 老库自动 ALTER，真实老库实测升级通过、数据不丢。
- [通过] 健康检查/就绪探针：v1.2 已有并保持可用，本轮未改动相关代码。

## 2. 可观测性
- [通过] 指标：新增 `linkshort_password_attempts_total{result="ok"|"fail"}`，真实服务冒烟确认计数随门页成功/失败增长。
- [通过] 日志：沿用 chi Logger，`request_id` 已有；密码明文不进日志（只在内存比对），响应只有 `has_password` 布尔。
- [未通过] 告警规则：本轮未新增 fail 走高告警。排期 v1.5：`linkshort_password_attempts_total{result="fail"}` 持续走高触发告警。
- [通过] 链路排查：错误 401 与限流 429 走独立状态码，日志/指标能区分"猜错"和"被限流"。

## 3. 数据
- [通过] 备份恢复：v1.3 已有备份恢复脚本并实测；哈希随库文件一起备份，恢复后密码继续有效。
- [通过] 敏感数据：密码只存 bcrypt 哈希（`links.password_hash`），明文不落库、不进响应、不进日志；保管与排障策略写进 OPERATIONS 3.6。
- [通过] 配置环境变量化：沿用既有方式，本轮无新增硬编码配置。
- [不适用] 多租户隔离：单用户设计，未引入 tenant 概念，无租户隔离需求。

## 4. 部署运维
- [通过] 一键部署：v1.2 已有 compose，本轮未改；新增依赖 `golang.org/x/crypto v0.31.0` 随 go.mod 一起构建。
- [通过] 镜像构建：Dockerfile 多阶段不变，本轮未新增系统依赖。
- [通过] 运维文档：OPERATIONS.md 本轮补 3.6 密码保护（存储/备份/遗失/排障/限流），与实现一致。

## 5. 安全
- [通过] 密码存储：bcrypt 哈希，cost 可调，明文不落库。
- [通过] XSS：门页服务端渲染并对输入做 HTML 转义，`docs/screenshots/password-gate-error.png` 实机验证无脚本注入。
- [通过] 信息泄露：密码错误只返回 401，不泄露目标 URL；响应只有 `has_password`，哈希永不外泄。
- [通过] 防爆破：密码错误尝试走全局 IP 限流（默认 20 RPS / burst 40），429 挡掉暴力猜解。
- [通过] 输入校验：密码长度 1~128 rune 上限，超限拒绝；校验在限次访问检查之前，防错误尝试耗尽次数。

## 6. 可维护性
- [通过] 文档同步：CHANGELOG、README（功能列表+截图）、OPERATIONS（3.6）本轮全部更新。
- [通过] 代码结构：新包 `internal/auth` 职责单一，bcrypt 与密码策略独立可测。
- [通过] 技术债登记：CSV 导入导出未带密码字段（有意为之，防明文进 CSV）；高并发 clicks 无分布式锁（v1.1 起已知，单连接串行写入缓解），两条均已记入 CHANGELOG 已知缺口。

## 7. 验收
- [通过] 真实服务冒烟：门页 200 / 错码 401 / 对码 302 / 点击计数 / burn 联动全过。
- [通过] 截图验收：5 张真实截图亲眼验收（`docs/screenshots/new.png`、`links.png`、`detail.png`、`password-gate.png`、`password-gate-error.png`）。
- [通过] 测试命令：`go test ./... -race` 73 例全绿。
- [通过] 发版结论：未通过项 0，排期 1 项（fail 走高告警规则 v1.5）。
