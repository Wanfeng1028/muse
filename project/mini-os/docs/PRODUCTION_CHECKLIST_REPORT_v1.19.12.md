# mini-os 发版对照报告：v1.19.12

## 改动摘要

本轮改动为 GET /api/fs 的 parent_id 参数收紧 + 6 例新测试 + 版本与文档同步。版本号由 1.19.11 同步至 1.19.12（Cargo.toml、Cargo.lock，无依赖变化）。

功能改动集中于 src/handlers.rs 的 list_fs：FsQuery.parent_id 由 Option<i64> 改为 Option<String>，函数内 trim 后 parse::<i64>()，仅非负整数放行；""、"abc"、"1.5"、"-1"、超 i64 上限一律返回 400 {"error": "parent_id 参数非法"}，与 fs/search 的 limit 收紧口径一致。不传 parent_id 仍查根目录；合法 id 查不到时返回 200 空数组，列表语义不变，不改成 404。

新增 tests/fs_parent_id_validation_test.rs，含 6 个用例：abc 400、1.5 400、-1 400、空串 400、999999 200 空数组、合法文件夹内含文件且无参根目录含该文件夹。
