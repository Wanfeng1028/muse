# mini-os 发版对照报告：v1.19.14

## 改动摘要

- **核心逻辑**：`src/handlers.rs` 中的 `create_fs` 路由（POST /api/fs）修改。当 `parentId` 为 `Some` 且 `parent` 为非空字符串时，返回 `400 {"error": "parent_id 与 parent 不能同时指定"}`（此前静默允许 `parentId` 生效并忽略 `parent`）。空字符串或仅包含空格的 `parent` 被视为未指定，保持原行为。
- **文档与版本**：`src/models.rs` 的文档注释已更新。Cargo.toml 和 Cargo.lock 版本同步至 1.19.14，无依赖变更。
- **测试代码**：新增 `tests/fs_create_parent_conflict_test.rs`（包含6个测试用例：两者均传返回400，一致返回400，仅传 parentId 返回201，仅传 parent path 返回201，空 parent 返回201，parentId 为 null 且传 path 返回201），已全部记录于 CHANGELOG。
