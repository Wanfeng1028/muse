# second-brain 界面设计注记（v0.21.0 起）

## 视觉逻辑：案头三色纸阶

第二大脑是一张案头，不是仪表盘。视线按纸色深浅走：左侧栏是最深的暖纸（索引抽屉），
中间列表是稍浅的纸（索引卡片），右侧编辑区是纯白纸（落笔处）。颜色只分轻重，
不抢内容；主操作、进行中的复习、选中的卡片用同一个深青标出，其余一律退后。

## 配色（全部纯色，无渐变）

- 纸阶：侧栏 #e9e2d2、列表底 #f6f2ea、卡片 #fffdf8、编辑区 #ffffff。
- 墨色：正文 #22241f、次要 #4c4a42、说明 #8a857a；边框 #e2dccf / #d5ccb8。
- 主色：深青 #0f766e（hover #0d655e、active #0a534c）；危险 #b91c1c、警告 #b45309。
- 趋势、热力、EF 分布、预测条统一收进深青色阶，不再各用各的蓝。

## 字阶与间距（左对齐，不居中）

- 侧栏分组标题 12px、弱色；导航 15px；列表标题 15px 粗体；列表正文 13px、行高 1.6；
  编辑标题 26px 粗体；编辑正文 16px、行高 1.8；说明文字 12px。
- 字体栈沿用系统无衬线，不引入新字体；编辑正文沿用等宽（沿用旧版，代码笔记可读）。
- 侧栏区块间距 20px；列表卡片内边距 14px；编辑区内层各段左右边距 40px，
  阅读列宽上限 780px（左对齐，不是居中版式）。

## 落地方式

- 本轮只加一层覆盖样式 `internal/web/static/design-v021.css`（在 style.css 之后加载），
  原样式表不动；index.html 加一行 link；sw.js 缓存清单补一行。
- 标签墙是本轮修掉的最大毛病，根因是实测发现的：标签渲染用 `.chip.tag-chip`，
  原样式表里根本没有这条规则，标签只能裸文字成墙；设计层把纸片式胶囊补齐，
  计数用深青粗体，选中态整片变深青。

## 刻意不用的东西（去 AI 味）

- 不用紫渐变 hero、不把 Inter 用到底、不一切居中、不做三栏特性格、
  不用 emoji 当图标、不用 Unleash / Empower / Seamless / Next-generation 类文案
  及中文四字 polished 短语、不用编号段落加衬线大标题的 Specimen 风。
- 本页文案与界面文案均不含上述写法；后续改版先对照本节再动手。

## 验收（2026-10-25，真服务 + 演示数据 55 篇）

- 截图：`docs/screenshots/second-brain-v021.png`（选中笔记的编辑态）、
  `docs/screenshots/second-brain-v021-stats.png`（复习统计态），均为真实数据，
  不是空状态、不是 loading 态；视口 1440x900 撑满，无大面积空白、无错位重叠。
- 已知保留：编辑区附件上传仍用浏览器原生文件框（未做自定义上传组件）；
  侧栏统计、导出、图谱入口在首屏下方，需滚动才可见（抽屉式侧栏的既有结构）。
