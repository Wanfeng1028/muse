# GET /api/review/digest n 参数校验收紧 生产检查清单报告

变更摘要
对 GET /api/review/digest 的 n 参数进行校验收紧，对齐此前 queue limit / forecast days / heatmap days 系列。缺失或空 n 取默认值 5；非整数（abc、1.5、1x）返回 400 且错误信息为 "n 参数非法"；n <= 0 钳制为 5；n > 200 钳制为 200。改动仅涉及 handler 层（internal/api/review.go，+14/-1 行）与新增测试文件 internal/api/review_digest_n_validation_test.go（2 个测试函数，8 个子测试）。无 UI 变更，不适用视觉验收。
