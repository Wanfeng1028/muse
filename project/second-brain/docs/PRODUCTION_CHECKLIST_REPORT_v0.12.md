- [通过] 健康检查+就绪探针+优雅关闭：沿用已有实现，本轮没改也没破坏。

## 2. 可观测性

- [通过] 结构化日志+request_id：关键操作（`note.created`/`review.graded`/`push.tick_result`）都打结构化日志，字段里带 `request_id`，报错能一路 grep 到根因。
- [通过] 关键指标暴露：本轮新增 `internal/metrics`，`GET /metrics` 暴露 6 个指标，含 HTTP 请求量、耗时 histogram、推送结果、评分次数、笔记数、到期复习数。冒烟验证指标值正确。
- [通过] 报错定位：request_id 全链路 + 429 响应里也带 `request_id`，从报错能定位到具体请求。
- [未通过] 基础告警：Prometheus 指标有了，但告警规则还没建，没人会在出问题时收到通知。排期 v0.13。
