# 生产级检查表对照报告 — second-brain v0.3.0

- 版本：v0.3.0
- 日期：2026-10-15
- 一句话结论：功能与测试在本版达标（68 个测试全过、go vet / gofmt 干净），但生产级基础仍有明显缺口（无结构化日志与 request_id、无指标与告警、无自动备份、无 docker-compose、无版本化迁移、无 E2E 与故障演练），本版定位为"可用但不完全生产就绪"，缺口已列入技术债与排期。

## 已知限制

- 单用户、无鉴权：服务没有登录和权限控制，谁能访问到端口谁就能读写数据，不要暴露到公网。
- 无自动备份：目前只能手动备份（停服复制数据库，或 `sqlite3 .backup`），忘记备份就会丢数据。
- 无 E2E 测试：68 个测试覆盖了单元和集成层，但没跑完整链路，跨模块问题可能漏。
- 无指标和告警：出问题时没有仪表盘和通知，只能靠翻日志，且日志不带 request_id，定位偏慢。
- 数据库无版本化迁移：升级版本时建表用 `CREATE TABLE IF NOT EXISTS`，字段变更需要手动处理，没有自动升级脚本。
- 无 docker-compose：只能用 Dockerfile 手动构建运行，没有一键部署。
- 更新需短暂停机：单实例 + SQLite，升级时要停服。
- 无故障演练记录：杀进程、磁盘满这些场景没实测过，恢复能力没有数据支撑。
