# 在手机/电脑上安装第二大脑

第二大脑可以像 App 一样装到桌面上。装完有图标、点开就是全屏，跟原生 App 差不多。

先把服务跑起来，默认地址是 `http://localhost:8080`。手机要连同一个 Wi-Fi，用 `http://<服务器IP>:8080`。

---

## 安装前确认

想看到"安装"提示、想用离线功能，浏览器有两个硬条件：

- 地址必须是 `https` 开头，**或者**是 `localhost`
- 局域网 IP（比如 `http://192.168.1.20:8080`）属于"不安全上下文"，**不算数**

说人话就是：

| 你访问的地址 | 能装吗 | 有安装横幅吗 | 能离线用吗 |
| --- | --- | --- | --- |
| `http://localhost:8080` | 能 | 能 | 能 |
| `https://你的域名` | 能 | 能 | 能 |
| `http://192.168.x.x:8080` | 只能手动加 | **不会弹** | **不能** |

第三条是很多人踩的坑：Service Worker 在局域网 IP 上根本注册不了，所以离线缓存、后台更新这些全都没有。你加到主屏幕的只是个"快捷方式"，打开还是得连服务器，断网就打不开。这不是 bug，是浏览器的安全规定。

想在家里局域网也用上完整 PWA，两个办法：

1. 给服务器配个 HTTPS 证书（自签的也行，但手机要手动信任）
2. 用内网穿透工具给个 https 域名

嫌麻烦就先手动加，能用就行。

## Android

用 Chrome 打开第二大脑。

**情况一：自动弹横幅**

页面底部会冒出一条"把第二大脑添加到主屏幕"，点它，再点"安装"。

**情况二：没弹横幅**

1. 点右上角**三个点**（菜单）
2. 点**"安装应用"**。如果没这一项，就点**"添加到主屏幕"**
3. 弹出确认框，点**"安装"**或**"添加"**

装完桌面会出现图标，名字是"第二大脑"。

注意：如果你的地址是 `http://192.168.x.x:8080`，你只会看到"添加到主屏幕"，不会看到"安装应用"。这是正常的，见上面那张表。

## iPhone / iPad

只能用 Safari。Chrome、微信内置浏览器都不行，别白费劲。

1. 用 **Safari** 打开第二大脑
2. 点屏幕**底部中间的分享按钮**（一个方框，里面有个向上的箭头）
3. 在弹出的列表里往下滑，点**"添加到主屏幕"**
4. 右上角点**"添加"**

回主屏幕就能看到图标了。图标用的是 180x180 的 PNG，苹果系统会自动处理圆角。

iOS 不会自动弹任何安装提示，永远都得手动加。这是苹果的规定，不是第二大脑的问题。

## 电脑（Chrome / Edge）

用 Chrome 或 Edge 打开第二大脑。

看地址栏**最右边**，会出现一个小小的安装图标——一个显示器带个向下箭头的样子。点它，再点"安装"。

找不到图标的话：

- Chrome：点右上角**三个点** → **"投放、保存和分享"** → **"安装页面为应用"**
- Edge：点右上角**三个点** → **"应用"** → **"将此站点作为应用安装"**

装完会开一个独立窗口，开始菜单和桌面都会多一个图标。

---

## 卸载

- **Android**：长按桌面图标 → 拖到"卸载" → 确认。或者 设置 → 应用 → 找到第二大脑 → 卸载
- **iPhone / iPad**：长按桌面图标 → "移除 App" → "删除 App"。注意别点成"从主屏幕移除"，那个只是藏起来，没删掉
- **电脑 Chrome**：地址栏输 `chrome://apps` → 找到第二大脑 → 右键 → **"从 Chrome 中移除"**
- **电脑 Edge**：地址栏输 `edge://apps` → 找到第二大脑 → 右键 → **"卸载"**

卸载只是删掉那个壳，服务器上的数据一点没动。重新装回来，数据还在。

## 常见问题

**Q：为什么我打开没看到任何安装提示？**

先看你地址栏开头是什么。如果是 `http://192.168.x.x` 这种局域网 IP，浏览器认为不安全，不会给你安装提示，也不会注册 Service Worker。这是浏览器的规矩，改不了。要么换成 `localhost`（只能在服务器本机用），要么配 HTTPS。

**Q：局域网 IP 到底能不能装？**

能"加"，但只能算个快捷方式。用浏览器菜单里的"添加到主屏幕"能加个图标出来，点开还是走浏览器。离线用不了，断网打不开。想要完整功能，必须 HTTPS。

**Q：iPhone 上为什么没有安装横幅？**

iOS 从来不给任何网站弹安装横幅，全都得手动"添加到主屏幕"。这是苹果的设计，不是第二大脑偷懒。照上面 iPhone 那节的三步做就行。

**Q：装完图标糊糊的，怎么办？**

先确认你装的时候用的是 Safari（iOS）或 Chrome（Android）。用微信、QQ 内置浏览器打开再"添加到主屏幕"，图标会变成网页截图，肯定糊。删掉重装一次，用对的浏览器。还糊的话，把手机系统升级一下，老系统对 PNG 图标的缩放处理比较差。

**Q：服务器更新了，我这边打开还是旧版？**

Service Worker 会缓存页面，这是它该干的事。正常情况下你关掉再打开一两次，它就自己更新了。要立刻更新：

- 手机：把 App 从后台任务里划掉，重新打开
- 电脑：关掉那个独立窗口，重新点图标打开
- 还不行：卸载重装一次

**Q：能收推送通知吗？**

能。从 v0.10 开始支持浏览器推送：每天到点后，浏览器会弹一条提醒，告诉你今天有几篇笔记要复习。

用法：打开第二大脑 → 左侧导航「推送设置」→ 找到「浏览器推送」区 → 点「开启浏览器推送」，按提示允许通知就行。

注意两点：
- 服务器要先配好 VAPID 密钥（`SB_VAPID_PUBLIC_KEY` / `SB_VAPID_PRIVATE_KEY` / `SB_VAPID_SUBJECT` 三个环境变量），没配的话页面会提示"服务器还没配好推送"。
- iPhone 上要用：系统得是 iOS 16.4 或更新，并且已经把第二大脑「添加到主屏幕」了，没装的话 Safari 收不到推送。

**Q：装完占多少空间？**

很小。PWA 就是个壳加缓存，几 MB 的事。真正占地方的是服务器上那个数据库，跟你手机没关系。

**Q：手机上装了，电脑上还要再装一次吗？**

要。每个设备各装各的。数据是同一份，都从服务器读，但图标、窗口这些是设备本地的。
