# 第二大脑 · 灵魂一页纸

版本：v0.2.0「主动复习引擎」

## 一句话差异化命题

市面笔记软件都是"只进不出"的仓库——写完就忘；第二大脑是"会主动推送旧笔记"的复习引擎，按艾宾浩斯遗忘曲线（SM-2）在你快要忘记时把笔记推回来。

## 解决的痛点

知识复利的前提是重复提取。写下来不等于记住，收藏不等于学会。只有在你快要忘的那一刻，把这条笔记重新翻出来，逼自己回忆一次，它才会真正长在脑子里。

现有方案都不管这件事：

- flomo / Notion / Obsidian：主打记录与整理，本身没有复习调度，写完就沉底。
- Obsidian 的间隔重复：靠插件拼凑，插件之间各管各的，没有统一的到期队列和调度。
- 通用背单词软件：为单词卡设计，套不到你自己的笔记上。

结果就是：笔记越攒越多，真正能被想起来用上的越来越少。

## 技术含金量

1. **SM-2 纯函数实现**
   SuperMemo SM-2 算法写成纯函数：输入（上次间隔、EF、自评档位）→ 输出（新间隔、新 EF、下次到期时间）。没有副作用、没有隐藏状态，给定输入必得同一输出，所以可以确定性单测。遗忘曲线的核心逻辑不依赖数据库、不依赖时间函数，测试里想造哪一天就造哪一天。

2. **复习队列 SQL 调度**
   到期优先：`due_at <= now()` 的笔记先排。
   同批到期内按遗忘风险排序：EF 越低、间隔越长的越靠前，先捞最可能忘的。
   调度逻辑落在一条可读的 SQL 查询里，不藏在应用层的循环里，方便解释、方便调优。

3. **留存统计**
   - streak：连续复习天数。
   - 7 日复习量：最近七天的复习条数。
   - 平均 EF：所有在复习笔记的难度系数均值，反映整体记忆负担。
   数字都是当场算出来的，不是拍脑袋估的。

4. **抽认卡复习流 UI**
   一条笔记就是一张卡，正面题、背面答，翻面、自评、进下一张。整个流程在一个页面里走完，不跳来跳去。

## 视觉概念

**卡片盒。**

- 卡片正面是"题目"：笔记标题 + 摘要。先只给你这点线索，逼自己回忆。
- 翻面是"答案"：笔记全文。想起来没有，自己心里有数。
- 卡片下方四档自评：忘记 / 困难 / 良好 / 简单。点哪一档，决定这张卡下次什么时候再见你。
- 四档按钮颜色：忘记灰/困难橙/良好蓝/简单绿
- 配色沿用现有体系：深蓝边栏 + 纸白内容区。深蓝是"盒"，纸白是"卡"。不加新色，不搞花活。

## 命名理由

复习引擎内部叫 **Review Engine**——它就是一个引擎，输入笔记和自评，输出下次到期时间，职责单一。

对外产品仍叫「第二大脑」。复习不是另起一个功能，而是"第二大脑"里"主动"那一半的体现：仓库是被动的，第二大脑是主动的。

## 不做（scope 外）

- 外部推送渠道（邮件 / 微信）：留到 v0.3。v0.2.0 只做站内复习页，先把调度和卡片流跑通。
- 多用户复习隔离：留待 tenant 落地。现在按单用户设计，队列和统计都不带用户维度。
