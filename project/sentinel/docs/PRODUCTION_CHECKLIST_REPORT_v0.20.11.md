# 发版对照报告 v0.20.11：快照列表 limit 非法返回 400（sentinel）

文件：`sentinel/docs/PRODUCTION_CHECKLIST_REPORT_v0.20.11.md`

## 变更摘要

- 改动：`handleListSnapshots` 的 `limit` 非空时，解析失败或小于 1 返回 400（limit 参数非法）；缺参/空串仍默认 50；大于等于 1 照旧采用，不新增上限钳制。
- 测试：新测试 `TestSnapshotListLimitValidation` 1/1 通过（5 个子断言：`abc`/`0`/`-1` 为 400、`2` 与无参为 200 且 items 长度 2）；既有 `TestSnapshotArchiveFullCycle`、`TestSnapshotListLimit` 同跑通过；`go vet` 全洁；`gofmt` 本轮文件全洁；handlers 包靶向测试 3/3 全绿。
- 无 UI 改动、无 schema 变更、无新环境变量、无新截图（无 UI 改动，视觉验收不适用）。
