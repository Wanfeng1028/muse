## 缺口（执行人逐项修，修完逐项复测）
1. 环境光层丢失：首页及所有深色页必须有肉眼可见的环境光（暖色左下、绿色右下、蓝色上方，
   按 photo-9 位置），PIL 四角采样须与平底色差 >10 个 RGB 单位且色相方向对，否则不算做完。
2. 首页大标题折行：9 个汉字在 43pt 下折两行，视觉上是断掉的标题；Medley 大字是一行到底。
   决断（不再问用户）：本标题改 38pt 一行（9×38=342pt < 350pt 内容宽，实测闭合），
   在 MEDLEY-COMPARISON.md 记为有意例外，理由是“一行完整标题比死守 43pt 更像 Medley”。
3. 卡片全是平的：表单卡、解读气泡、知识卡片均为单色平底 + 细线；Medley 卡片有玻璃质感、
   渐变、内高光和层次。微信内 backdrop-filter 受限处用分层渐变 + 边框逼近，并诚实注明。
4. 颜色只剩紫色星标：浅色页补彩色（图标、数字、洗色按 Medley 浅色屏来）；深色页除星标外，
   关键信息（价格、积分、状态）也要有 Medley 式的彩色层级，不许整页只剩白灰。
5. 图标糙：底栏细线轮廓图标改为有填充、有状态区分的图标；头像圈、按钮、分割线按 Medley 精度重做。
6. 密度和呼吸感：表单等高密行改为 Medley 的字号层级与行间距（大字、副文案、数字各就其位）。
7. 命盘页十二宫格子是均分方块，缺“盘”的整体感：宫格加盘感（环形/层次），星曜按类着色
   （主星、辅星、四化颜色区分，颜色取法在 MEDLEY-COMPARISON.md 注明来源）。
