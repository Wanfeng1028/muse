## 参照 0：设计师个人网站（抖音视频，2026-09-17）

来源：抖音号“表哥懂设计（AIGC版）”作品，Vibe Coding 自制设计师
个人网站，单页滚动 5 屏，顶部固定导航 5 项文艺命名。
可借手法：
- 巨型展示标题全部左对齐、顶天立地占半屏，每屏近乎满屏一句话。
- 中英混排：小字号英文章节编号 + 中文对照。
- 留白极大，栏目密度有张有弛，不全是等高卡片。
- 单一强调色克制使用，只点在关键处。
- 胶囊按钮 + 圆形箭头按钮。
- 卡片可点进详情（本站已有行为，保持）。
不可照搬：深色主题、作品集内容结构、5 屏单页结构、视频叙事。

## 参照 1：Awwwards 编辑排版合集

来源：https://www.awwwards.com/inspiration/editorial-layout
可借手法：
- 超大字号标题本身就是主视觉，不靠色块撑场面。
- 章节编号 + 细分割线做编辑式分段，代替处处加框。
- 非对称网格：主次内容占宽、留白宽度明显不同。
- 行距拉开，段落之间用空白而不是分割线分隔。

## 参照 2：即时设计小程序页面布局指南

来源：https://js.design/special/article/applet-page-layout.html
可借手法：
- 头部只做品牌识别 + 轻导航，不堆功能入口。
- 内容分区靠留白分层，不靠每个区都加底色卡片。
- 装饰元素克制，动效只用来吸引一次注意，不常驻喧宾夺主。

## 参照 3：字间留白排版方法（UISDC）

来源：https://www.uisdc.com/white-space-between-characters
可借手法：
- 展示性短句放大字间距，做成有呼吸感的字符面。
- 加粗无衬线做展示字，正文保持常规字重，形成字重对比。
- 开放空间 + 平面感：焦点周围留白，不贴边。

## 约束参照：微信小程序设计指南

## 本轮落点（对应关系，不新增功能；以实测代码为准）

- 字阶四档：展示 44pt / 章节 20pt / 正文 15pt / 小字 12pt。
- 章节眉：小字号英文编号 + 中文标题，眉与标题间距 4pt，
  标题到内容 12pt，章与章之间 40pt（大章）/ 28pt（小节）。
- 密度拉开：首页锚点卡 padding 由 16/12pt 放到 20/16pt、主星
  由 20pt 放到 22pt；运限双卡 padding 由 12/8pt 放到 14/10pt，
  介于锚点卡与 tiles 之间；tiles 纵向 padding 由 12pt 放到
  16pt、内容居中收敛；命盘页盘面与详情卡之间由 28pt 放到
  40pt，详情卡标题 20pt 高于大运/流年卡标题 16pt；解读页章眉
  由 16pt 放到 28pt，已解锁正文泡泡 padding 由 12pt 放到 16pt；
  我的页头卡名字由 20pt 放到 22pt 并加账号眉，服务卡 padding
  由 16pt 收紧到 12/16pt、间距由 12pt 收紧到 8pt、标题由 16pt
  收到 15pt。解读 chips 区、宫格几何、底栏、全部文案与功能
  均未动。

### 案例 1：即时设计《优秀的小程序页面布局应该长这样》

来源：https://js.design/special/article/applet-page-layout.html
文中以微笑咖啡、女性生活小帮手、活动类、赛事类小程序为例，
拆解头部、主体、悬浮按钮、推荐区四段式结构。
可借手法：
- 头部只做品牌识别（Logo + 标题 + 轻导航），另加一个克制的
  互动小组件（如榜单下拉）做点睛，不堆功能入口。
- 主体内容区核心信息优先，卡片承载信息但留足透气感，
  分页数据也不挤满屏。
- 悬浮按钮是主操作快捷入口，颜色与主题和谐，按下有反馈。
- 推荐区沉浸式融入界面，不用生硬的广告框打断阅读。
- 通用原则：用空白与色彩对比造视觉焦点；可试瀑布流、
  网格等非传统布局换新鲜感。
落到四页：
- 首页：头部已是品牌行 + 日期 + 一句话，本轮 hero 放大与
  章节眉分层与“头部轻、主体核心优先”一致；锚点卡即核心
  信息区，置顶且最大。
- 命盘页：盘面即核心信息区，一屏主角；盘下 40pt 留白即
  “用空白分层”，不用分割线。
- 解读页：长文段落之间用空白分隔（章眉 28pt），不用每段
  加框；已解锁正文 padding 放大，弱化框线感。
- 我的页：底栏沿用微信原生标签分页样式（自定义图标、
  文案、颜色），不自造导航；服务区卡片收紧后一屏可见更
  多任务入口。

### 案例 2：即时设计 8 个优质小程序 UI 模板

来源：https://js.design/special/article/applet-ui-design-templates.html
含出行旅游、电商家居、休闲生活等模板的版式描述。
可借手法：
- 出行旅游模板：留白足够供个性化发挥，配大圆角图标，
  整体现代、舒适。
- 电商家居模板：瀑布流卡片，提高屏幕利用率与层次清晰度。
- 休闲生活模板：现代极简，留白多。
- 单色调模板：去分割、大留白，空间感强、视线开阔，用留白
  减轻压迫感，营造轻松氛围。
落到四页：
- 首页 / 我的：去分割、大留白——我的服务区本就是无分割线
  卡片（s6 式），本轮再收紧卡片、拉开章间距，强化“留白
  分层”而非“分割线分层”。
- 命盘页：大圆角（盘面 20pt、宫格 16pt）与留白保持不动，
  盘式是传统制式，不改结构。
- 配色克制：模板多为单色调 + 中性底；本站强调色只用
  Gemini 蓝且只在关键处（胶囊、选中态），与单色克制一致。
- 不抄：电商瀑布流的商品结构、旅游模板的行程结构均不抄，
  本站双卡是命盘运限结构，不是商品流。

### 案例 3：墨刀 8 类常见场景页面结构拆解

来源：https://modao.cc/ad/blog/wechat-mini-program-design-resources-templates.html
含租房（154 页）、会议室预订、投票等小程序的结构拆解。
可借手法：
- 结构按用户任务排布，不是按功能堆砌：首页 = 核心业务
  入口 + 搜索/筛选 + 列表，用户端与供给端分开，通用组件统一。
- 轻量化框架 + 规范 + 场景适配，不为全功能牺牲主线。
- 关键动作一步直达（如投票一分钟创建），降低操作门槛。
落到四页：
- 首页：按用户任务排布（先看盘 → 再看运限 → 再读解读 →
  再用工具），不是功能平铺；本轮密度拉开正是强化任务主次
  （锚点卡最大、运限次之、功能最轻）。
- 我的页：服务按任务分组（会员 / 积分 / 邀请 / 档案 / 合盘 /
  海报 / 订单 / 设置 / 客服 / 关于），点卡即进分段，关键动作
  一步直达；卡片收紧后一屏可见更多任务入口。
- 命盘 / 解读：关键动作一步直达（宫位点选即详情、维度点选
  即解读）为已有行为，保持不动。
- 不抄：租房的房源结构、会议室的预订流程、投票的活动结构
  均不抄，只借“按任务排布”这一结构原则。

### 案例 4：微信小程序设计指南 + WeUI（约束参照）

来源：https://developers.weixin.qq.com/miniprogram/design/
来源：https://wechat-miniprogram.github.io/weui/docs/
只取约束，不取风格。

- 导航明确、来去自如；首页可用微信原生底部标签分页样式
  （自定义图标、文案、颜色）；次级页左上角返回。
- 常用字号 22 / 17 / 15 / 14 / 12pt 体系。
- WeUI 与微信原生视觉体验一致，统一用户感知。
落到四页：

- 每页重点唯一：首页 = 命盘锚点、命盘页 = 盘面、解读页 =

### 案例 5：卡片式设计思考（人人都是产品经理）

来源：https://www.woshipm.com/pd/3154475.html
可借手法：
- 标题在卡内还是卡外：独立模块或单一大标题放卡内；组合
  或延续性内容放卡外，做最外层主标题。
- 卡片与底色对比不宜太接近，否则边缘锐度下降、空间感弱。
- 长文章去卡片化保沉浸感；分区归纳，避免过多小块卡片
  导致拥挤凌乱。
落到四页：
- 首页：章节标题放卡外（今年运限 / 解读 / 功能均为卡外主
  标题），卡内只放内容；本轮章节眉强化了这一点。
- 解读：长文正文弱化卡片感（已解锁泡泡 padding 放大），
  行距保持 1.35 不动。
- 我的：服务卡与底色对比保持（白卡 on #f5f6f8 + 细线 +
  柔影），卡片归纳为任务入口但间距收紧防拥挤。
