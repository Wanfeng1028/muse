## 帖子核心主张（转述）

帖子主打一个开源工具 Toonflow，声称"两个钟头、120 块"就能做完一部 AI 短剧。
要点拆解：
1. 工作流：把小说/剧本丢进去，编剧 → 分镜 → 角色设计 → 出成片，AI 全流程包办
2. 技术亮点：画布可多层叠加、三层 Agent 分工、本地记忆加持、跑在自己电脑上
3. 成本：一条 2 分钟短剧"百来块"，对标"花几万请人拍"
4. 热度背书：帖文写"GitHub 已经 16.6k 星"（帖子录屏里仓库页实际显示 18.3k，数字前后不一）
5. 转化话术："做内容的趁早上手，早用一天，就比别人多抢一天的流量"
