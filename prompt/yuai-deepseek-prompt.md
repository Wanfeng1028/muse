## 第二次尝试（2026-10-20，下载视频逐帧抽帧路线）

为拿全 16 页，改走"下载 MP4 → ffmpeg 密集抽帧 → 逐帧转录"的技术路线，在下载这一步被抖音反爬全面挡住，逐项实测：

- 浏览器（Playwright + Chromium）打开视频页抓直链：本机 Chromium 无法经 egress 代理做 CONNECT 隧道（所有站点均 ERR_TUNNEL_CONNECTION_FAILED；同一代理 curl/python 正常），页面打不开。
- 分享页 SSR 数据（_ROUTER_DATA）：只有元信息，无视频地址（页面为前端渲染 SPA）。
- 官方接口 iesdouyin iteminfo / snssdk detail：返回 200 空体（请求被静默丢弃）。
- yt-dlp：要求"新鲜完整 cookie"，仅 ttwid 不够。
- ttwid 注册接口可通，但只发 ttwid 一个 cookie；f2 工具带 a_bogus 签名 + msToken 调详情接口仍回 403——缺经 JS 挑战（__ac_signature）验证的完整匿名会话，本机无浏览器能建立这种会话。
- Keenable fetch / Jina reader：只能拿到页面标题与元信息，拿不到视频文件；全网检索无该视频的转载或文字版。

结论：本机环境下无法匿名下载该视频，抽帧转录无法进行。覆盖范围维持第一次观看所得：第 1 页结构 + 分镜八/九片段，Word 第 2–16 页正文未获取。
