# 第二大脑-PWA 安装

这篇讲怎么把 second-brain 装到手机上，像装普通 App 一样用。装完之后桌面会有个图标，点开就是全屏，没有浏览器地址栏，断网也能打开已经缓存过的页面。

## 先搞清楚 PWA 是什么

PWA 就是网页应用。它靠两样东西工作：一个是 manifest 文件，告诉系统这个应用叫什么名字、图标长什么样、启动时显示什么颜色；另一个是 Service Worker，一段跑在后台的脚本，负责缓存文件和拦截网络请求。second-brain 已经把这两样都配好了，你不需要改代码，直接装就行。

## 前提条件

第一，得用 HTTPS 访问。localhost 是例外，本地开发时 http 也能装。生产环境必须是 https，否则浏览器不给注册 Service Worker。

第二，需要一个支持 PWA 的浏览器。安卓上用 Chrome、Edge、三星浏览器都行。iOS 上必须用 Safari，从 iOS 16.4 开始才支持添加到主屏幕后收到推送。

第三，Service Worker 要求页面在同源下运行。如果你的 second-brain 部署在子路径，比如 `https://example.com/brain/`，那 `manifest.webmanifest` 和 `sw.js` 的 served 路径也得对应 `/brain/` 前缀，路径别写错。

## 安卓安装步骤

1. 用 Chrome 打开你的 second-brain 地址。
2. 等页面加载完，右上角三个点菜单里会出现“安装应用”或者“添加到主屏幕”。有些机型会直接在底部弹一条横幅，点“安装”即可。
3. 弹出的对话框里确认名称，点“安装”。
4. 桌面会出现图标，点开就是独立窗口。

如果菜单里没有安装选项，检查三件事：是不是 HTTPS、manifest 有没有正确加载、Service Worker 有没有注册成功。打开 Chrome 开发者工具的 Application 面板，左边看 Manifest 和 Service Workers 两项，有报错会标红。

## iOS 安装步骤

iOS 没有自动弹窗，得手动加：

1. 用 Safari 打开地址。
2. 点底部中间的分享按钮。
3. 在弹出菜单里往下滑，找到“添加到主屏幕”。
4. 确认名称，点“添加”。

加完之后从桌面图标启动，才会走独立窗口模式。注意 iOS 上必须用 Safari 操作，Chrome for iOS 用的是 WebKit，但“添加到主屏幕”这个入口只有 Safari 有。

## 桌面端安装

Chrome 和 Edge 在地址栏右侧会显示一个安装图标，一个小显示器带加号的样子，点它就装。装完在开始菜单或者启动台里能找到，和普通应用一样。

## 配置说明

second-brain 的 manifest 源码在 `internal/web/static/manifest.webmanifest`，由 Go 服务以内嵌文件形式在 `GET /manifest.webmanifest` 上提供（不是项目根目录的 manifest.json）。关键字段这么几个：

- `name`：应用全名，安装对话框里显示这个。
- `short_name`：桌面图标下面显示的名字，太长会被截断，建议 12 个字符以内。
- `start_url`：启动时打开的地址，一般写 `"/"` 或者 `"/index.html"`。
- `display`：写 `"standalone"` 就没有浏览器 UI，写 `"fullscreen"` 连状态栏都隐藏。
- `theme_color`：状态栏和标题栏颜色。
- `background_color`：启动画面背景色。
- `icons`：图标数组，至少提供 192x192 和 512x512 两个尺寸，`purpose` 字段可以写 `"any"` 或 `"maskable"`。

Service Worker 文件叫 `sw.js`，注册代码通常在入口脚本里。缓存策略上，second-brain 用的是预缓存加运行时缓存：安装阶段把 HTML、CSS、JS 和图标塞进 Cache Storage，之后请求优先走缓存，网络请求失败时回退到缓存副本。

## 更新怎么处理

Service Worker 更新是异步的。浏览器发现 `sw.js` 内容变了，会在后台下载新版本，但不会立刻接管页面。等所有标签页都关掉再打开，新版本才生效。如果你想主动提示用户刷新，可以监听 `updatefound` 事件，在 `installing` 状态的 worker 变成 `installed` 时弹个提示条，让用户点一下刷新。

调试的时候可以在开发者工具 Application 面板里勾选“Update on reload”，这样每次刷新都会检查新版本，省得手动清缓存。

## 常见问题

装不上，先看控制台有没有报错。常见原因：manifest 路径 404、图标尺寸不对、`start_url` 不在 scope 范围内、HTTPS 证书有问题。

装完打开是白屏，多半是 `start_url` 指向的页面路径不对，或者 Service Worker 缓存了旧版本。在开发者工具里注销 Service Worker 再重新加载试试。

iOS 上收不到推送，确认系统版本是不是 16.4 以上，并且是从主屏幕图标启动的，Safari 标签页里不行。

桌面图标显示不对，检查 `icons` 数组里的 `src` 路径和 `sizes` 是否匹配实际文件。maskable 图标要留出安全边距，不然安卓上会被裁掉一圈。
