# second-brain v0.22.0 发版对照报告

## 改动范围
- 修改了 `internal/api/review_overdue.go` 中的 GET handler：当 `limit` 参数非空但解析失败时返回 400 状态码，文案为“limit 参数非法”。
- 更新了测试文件：新增了 8 个子用例用于验证 `limit` 参数的非法情况，并同步了原有 `limit=abc` 预期状态码，从默认 50 改为 400。

## 实测数字
- `go test ./...` 全量测试：822 个测试用例通过，0 个失败。
- `go vet` 检查：无问题。
- 靶向 `TestReviewOverdue` 的 8 个子用例均通过。

## 合同变更
- `limit=abc` 的处理逻辑从静默使用默认值 50 改为显式返回 400 状态码，已同步更新相关测试用例。
