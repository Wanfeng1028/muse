## v0.7 新增风险与已知限制

1. **iOS 无后台同步**：iOS Safari 不支持 Background Sync，离线队列只能在用户回到前台、页面重新激活时回放。影响：离线期间新建的笔记在 iOS 上延迟提交。缓解：`docs/PWA_OFFLINE_DESIGN.md` 说明；后续计划评估 Foreground Sync 兜底与提示。
2. **离线新建笔记回放产生新 id**：离线期间本地生成的临时 id 在回放时由服务端分配正式 id，客户端需做 id 映射；若同一笔记在两端并发编辑，按"服务端权威、最后写入胜出"处理，可能覆盖本地中间态。影响：极端并发下丢失一次本地编辑。计划：后续版本引入客户端可读的冲突提示。
3. **SW 缓存版本靠发版号**：`sw.js` 缓存清单与版本号随发版手工提升，若发版遗漏更新版本号，用户可能继续命中旧缓存。缓解：`pwa_test.go` 对缓存清单与文件一致性做回归；SW 更新走"提示条 + 用户点刷新"，非强制。计划：后续将版本号与构建产物绑定，减少手工步骤。
4. **局域网 HTTP 下 PWA 不可用**：Service Worker / PWA 安装要求安全上下文（HTTPS 或 localhost）。通过局域网 IP 以 HTTP 访问时，SW 不注册、不可安装、离线能力不可用。影响：内网 HTTP 场景降级为普通网页。缓解：`docs/PWA_INSTALL.md` 明确要求 HTTPS 或 localhost；后续计划补充内网自签证书指引。
5. **推送通知本版不支持**：v0.7 不含 Push，后续计划单独立项；不构成本版发版阻塞。
