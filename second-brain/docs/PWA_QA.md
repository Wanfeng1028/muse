# PWA 手工验收清单（v0.7）

适用范围：`second-brain` v0.7 发版前真机 / 真浏览器走查  
测试前置：已部署可访问的 HTTPS 站点；准备两个版本构建（旧版 `v0.7.0`、新版 `v0.7.1`）用于更新测试；准备一个可断网的桌面浏览器、一台 Android 设备、一台 iOS 设备。  
记录要求：每条执行后记录平台、浏览器版本、实际结果、截图/录屏、是否通过。

平台标注说明：桌面 = Chrome/Edge 桌面版；Android = Chrome Android；iOS = Safari iOS。

---

## A. 安装

### A1 桌面 Chrome 地址栏安装图标出现并可安装
- 平台：桌面
- 步骤：
  1. 使用 Chrome/Edge 打开站点首页。
  2. 等待页面完全加载，观察地址栏右侧是否出现安装图标。
  3. 点击安装图标，确认安装。
  4. 打开系统应用列表/启动台，启动已安装应用。
- 期望：地址栏出现安装图标；安装过程无报错；安装后可从系统独立窗口启动，且启动后进入应用首页而非普通浏览器标签页。

### A2 桌面安装后独立窗口显示与基本导航
- 平台：桌面
- 步骤：
  1. 从系统启动已安装的 second-brain 应用。
  2. 观察窗口是否无浏览器地址栏/书签栏。
  3. 点击侧边栏/底部导航中的「笔记」「搜索」「复习」入口各一次。
- 期望：应用以独立窗口运行，无浏览器地址栏；各导航入口可切换，页面无白屏、无 404。

### A3 Android Chrome 安装横幅出现并可安装
- 平台：Android
- 步骤：
  1. 使用 Chrome Android 打开站点首页。
  2. 首次访问后停留 30 秒以上，或进行两次页面跳转。
  3. 观察是否出现「添加到主屏幕」/安装横幅。
  4. 点击横幅并确认安装。
  5. 返回桌面，找到新安装图标并启动。
- 期望：出现安装横幅或菜单内「安装应用」入口；安装后桌面出现独立图标；启动后以 standalone 模式打开，无浏览器地址栏。

### A4 iOS Safari 手动添加到主屏幕三步
- 平台：iOS
- 步骤：
  1. 使用 Safari 打开站点首页。
  2. 点击底部「分享」按钮。
  3. 在分享面板中选择「添加到主屏幕」。
  4. 确认名称后点击「添加」。
  5. 返回主屏幕，点击新图标启动。
- 期望：分享面板中存在「添加到主屏幕」；添加后主屏幕出现图标；启动后以独立 Web App 形式打开，顶部无 Safari 地址栏。

### A5 iOS 添加到主屏幕后图标与启动页正常
- 平台：iOS
- 步骤：
  1. 完成 A4 后，观察主屏幕图标是否为应用图标而非网页截图。
  2. 冷启动该图标。
  3. 观察启动瞬间是否出现启动图/背景色，而非白屏闪烁。
- 期望：图标为配置的应用图标；冷启动无长时间白屏；启动后进入应用首页。

## B. 离线读

### B1 断网后刷新页面仍可用
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线打开应用并进入首页，等待 Service Worker 安装完成（可在 DevTools > Application > Service Workers 确认 activated）。
  2. 断开网络（桌面：DevTools Offline 或禁用网卡；移动端：开飞行模式或关 Wi-Fi/流量）。
  3. 刷新页面（移动端可杀掉标签页后重新从主屏幕图标启动）。
- 期望：页面仍可加载，不出现浏览器默认离线错误页；应用外壳、导航、样式正常显示。

### B2 离线打开笔记列表可读
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线状态下打开应用，进入笔记列表并滚动浏览至少 10 条笔记，确保列表数据已加载。
  2. 断网。
  3. 返回笔记列表页，或刷新后进入笔记列表。
  4. 点击其中 3 条不同笔记进入详情。
- 期望：笔记列表可显示此前已加载的条目；点击已缓存笔记可打开详情；正文、标题、更新时间可读；不出现空白页或无限加载。

### B3 离线打开最近访问过的笔记详情可读
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线状态下依次打开笔记 A、B、C 的详情页，每篇停留 2 秒以上。
  2. 断网。
  3. 通过历史记录/返回/列表再次打开 A、B、C。
- 期望：A、B、C 详情均可读；正文无缺失；代码块/图片等已缓存资源正常显示；未缓存图片可显示占位而非导致页面崩溃。

### B4 离线搜索行为明确且不崩溃
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线状态下进入搜索页，执行一次搜索「测试」，确认有结果。
  2. 断网。
  3. 在搜索框输入「测试」并提交。
  4. 再输入一个此前未搜索过的词「zzzz-not-exist」并提交。
- 期望：离线搜索不导致页面崩溃或白屏；若支持本地索引，则返回已缓存结果并标注「离线结果」；若不支持，则显示明确提示如「离线状态下暂不可搜索，请联网后重试」；不得无限转圈。

### B5 离线访问未缓存路由有明确降级
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线打开应用，但不要访问「设置」页。
  2. 断网。
  3. 直接在地址栏/应用内跳转到 `/settings`（或对应未缓存路由）。
- 期望：不出现浏览器默认离线错误页；应用显示统一离线提示页或返回首页；有「重试」按钮，联网后点击可恢复。

## C. 离线写

### C1 断网新建笔记提示入队
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线打开应用，进入笔记列表。
  2. 断网。
  3. 点击「新建笔记」，输入标题「离线新建测试」和正文「queue-1」。
  4. 点击保存。
- 期望：保存后界面提示「已离线保存，将在联网后同步」或类似入队提示；新笔记立即出现在列表中，并带有「待同步/离线」标记；无报错弹窗。

### C2 断网修改笔记提示入队
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在离线状态下打开一条已缓存笔记。
  2. 修改正文，追加「offline-edit」。
  3. 点击保存。
- 期望：提示已加入待同步队列；详情页显示修改后的内容；列表中的摘要/更新时间同步更新；带待同步标记。

### C3 断网删除笔记提示入队
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在离线状态下，对一条已缓存笔记执行删除。
  2. 在确认弹窗中确认删除。
- 期望：笔记从列表消失或显示「待删除」状态；提示已加入队列；不出现未捕获异常。

### C4 联网后自动回放新建/修改/删除
- 平台：桌面 / Android / iOS
- 步骤：
  1. 完成 C1、C2、C3，保持应用在前台或重新打开。
  2. 恢复网络。
  3. 观察队列状态与界面提示。
  4. 刷新页面并进入笔记列表。
- 期望：联网后自动开始回放；待同步标记消失；新建笔记存在于服务端；修改内容保留；被删除笔记不再出现；无重复笔记、无重复删除报错。

### C5 断网复习评分入队并在联网后回放
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线进入复习页，加载至少 1 张卡片。
  2. 断网。
  3. 对卡片进行评分（如「记得」「模糊」「忘记」）。
  4. 观察提示。
  5. 恢复网络，等待自动回放。
  6. 刷新后重新进入复习页，查看该卡片下次到期时间/复习记录。
- 期望：离线评分提示已入队；界面进入下一张或显示已记录；联网后队列回放成功；服务端复习记录与离线评分一致；无重复评分导致次数翻倍。

### C6 离线写数据一致性校验
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线新建笔记 N1，修改笔记 N2，删除笔记 N3。
  2. 记录操作前 N2 内容、N3 标题。
  3. 联网回放完成后，在另一台已登录设备或网页端打开同一账号。
  4. 对比 N1、N2、N3 状态。
- 期望：另一端点看到 N1 存在且内容一致；N2 为修改后内容；N3 已删除；无冲突副本、无丢失更新。

## D. 更新

### D1 发新版后提示条出现
- 平台：桌面 / Android / iOS
- 步骤：
  1. 设备打开旧版 `v0.7.0`，保持应用运行。
  2. 服务端部署新版 `v0.7.1`。
  3. 在应用中触发一次导航或等待轮询（不超过 60 秒）。
- 期望：页面出现「有新版本可用」提示条/弹窗；提示条不遮挡主要操作；有「刷新」按钮。

### D2 点击刷新后新版本生效
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在 D1 提示条出现后，点击「刷新」。
  2. 等待页面重新加载。
  3. 查看「关于/设置」中的版本号，或通过 DevTools 查看 Service Worker 版本。
- 期望：页面自动刷新或提示关闭后刷新；版本号变为 `v0.7.1`；刷新后原页面状态不丢失（如当前笔记草稿若已保存则仍在）；无重复提示条。

### D3 iOS 主屏幕应用更新后生效
- 平台：iOS
- 步骤：
  1. 从主屏幕图标启动旧版应用。
  2. 服务端发布新版。
  3. 完全退出应用（上滑关闭）。
  4. 重新从主屏幕图标启动。
- 期望：重新启动后加载新版；若仍为旧版，需在第二次启动后出现更新提示并可通过刷新生效；不得永久停留在旧版。

## E. 边界

### E1 队列回放中途断网可恢复
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线创建 5 条笔记，形成待同步队列。
  2. 恢复网络，观察开始回放。
  3. 在回放过程中（可通过 DevTools 限速或快速操作）再次断网。
  4. 等待 10 秒后再次恢复网络。
- 期望：回放中断后不丢队列；再次联网继续回放；最终 5 条笔记全部同步成功；无重复创建；界面待同步数量最终为 0。

### E2 服务端返回 4xx 时该条丢弃且不阻塞后续
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线创建一条笔记，标题或内容构造为服务端必然拒绝的非法值（如超长标题、非法字段，按实际校验规则准备）。
  2. 再离线创建一条正常笔记。
  3. 恢复网络，触发回放。
  4. 查看队列与提示。
- 期望：非法笔记回放失败后从队列移除或标记为失败并提示「同步失败，已丢弃/需手动处理」；正常笔记仍能成功同步；后续队列不被永久阻塞；控制台无未捕获异常。

### E3 5xx 或网络错误时保留队列并重试
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线创建 1 条正常笔记。
  2. 使用代理/DevTools 让同步接口返回 500。
  3. 恢复网络触发回放。
  4. 观察队列状态。
  5. 取消 500 模拟，再次触发回放。
- 期望：500 时该条保留在队列中，显示「同步失败，将重试」；不丢弃数据；取消故障后可自动或手动重试成功。

### E4 清缓存重装后数据从服务端恢复
- 平台：桌面 / Android / iOS
- 步骤：
  1. 确保所有离线操作已同步完成，待同步队列为 0。
  2. 清除站点数据：桌面 DevTools > Application > Clear site data；Android Chrome 站点设置清除存储；iOS 删除主屏幕图标并清除 Safari 数据。
  3. 重新访问站点或重新安装 PWA。
  4. 登录同一账号。
- 期望：应用可正常加载；笔记列表从服务端恢复；此前已同步的笔记可见；无因缓存清除导致的崩溃；重新安装后仍可再次出现安装入口（Android/桌面）。

### E5 离线状态下清缓存后打开提示明确
- 平台：桌面 / Android / iOS
- 步骤：
  1. 在线打开应用后断网。
  2. 清除站点数据（保持断网）。
  3. 刷新页面或从主屏幕启动。
- 期望：显示明确离线/需联网提示；不出现无限白屏；恢复网络后可正常加载。

### E6 多标签/多窗口同时离线写入不互相覆盖
- 平台：桌面 / Android
- 步骤：
  1. 打开两个应用窗口/标签，均处于离线状态。
  2. 在窗口 1 新建笔记「multi-1」。
  3. 在窗口 2 新建笔记「multi-2」。
  4. 恢复网络，等待两个窗口均完成回放。
  5. 刷新后查看列表。
- 期望：两条笔记均存在；无互相覆盖；队列状态最终一致；无重复创建。

### E7 长时间离线后首次联网回放不卡死
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线状态下连续创建/修改/删除共 20 条操作。
  2. 保持离线 10 分钟以上。
  3. 恢复网络。
  4. 观察回放过程与界面响应。
- 期望：回放期间界面可操作，不长时间无响应；最终队列清空；数据与服务端一致；无内存暴涨导致崩溃。

### E8 离线复习与离线笔记混合队列回放顺序合理
- 平台：桌面 / Android / iOS
- 步骤：
  1. 离线新建笔记 1 条。
  2. 离线对同一张复习卡评分 2 次（若允许）。
  3. 恢复网络。
  4. 查看笔记与复习记录。
- 期望：笔记同步成功；复习评分按操作顺序回放或按业务规则合并；最终复习次数/到期时间符合预期；无因顺序错乱导致数据异常。

## 发版前通过标准

- A 组全部通过，且至少在一台真实 Android、一台真实 iOS 上完成安装与启动验证。
- B 组全部通过，离线刷新不出现浏览器默认错误页。
- C 组全部通过，离线写入无数据丢失，联网后队列清空且数据一致。
- D 组全部通过，更新提示可见且刷新后版本号正确。
- E 组全部通过，4xx 丢弃、5xx 重试、中途断网恢复、清缓存重装均符合期望。
- 任一平台出现数据丢失、队列永久阻塞、白屏崩溃，视为发版阻塞。
