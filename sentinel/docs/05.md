# 哨兵-状态页主题定制

这篇说清楚怎么把哨兵自带的状态页换成你自己的样子。状态页就是那个打开浏览器能看到的页面，上面有服务列表、规则列表、实时 QPS 这些。

## 状态页长什么样由谁决定

哨兵的状态页是一份 HTML 模板加几段 CSS。模板在 `sentinel-dashboard` 模块里，启动之后由后端渲染再返回给浏览器。你要改外观，有两条路：

一条是直接改模板文件，改完重新打包部署，适合你要大改结构。

另一条是只覆盖 CSS，不动模板，适合你只想换颜色、换字体、换间距。

## 先找到模板文件

在仓库里，状态页相关的静态资源放在：

```
sentinel/sentinel-dashboard/src/main/resources/static/
```

模板文件放在：

```
sentinel/sentinel-dashboard/src/main/resources/templates/
```

`templates` 目录下的 `.html` 文件就是页面骨架，`static` 目录下是 CSS、JS、图片。你要换主题，重点动 `static` 里的 CSS。

## 配置项

哨兵状态页的可配置项不多，集中在 `application.properties`。下面这些是跟页面直接相关的：

```
server.port=8080
server.servlet.context-path=/
```

`server.port` 是状态页监听的端口，默认 `8080`。`server.servlet.context-path` 是访问前缀，默认是根路径。你把 `context-path` 改成 `/sentinel`，那访问地址就变成 `http://localhost:8080/sentinel`。

再往下是登录相关的：

```
sentinel.dashboard.auth.username=sentinel
sentinel.dashboard.auth.password=sentinel
```

这是默认账号密码，上线前必须改。改了之后打开状态页会先跳登录页，登录页本身也是模板渲染的，同样可以换主题。

还有一条跟页面刷新有关的：

```
sentinel.dashboard.retry.interval.ms=1000
```

这个控制状态页上数据多久刷一次。你调小一点，页面上数字跳得勤；调大一点，对后端压力小。

## 访问路径

启动 `sentinel-dashboard` 之后，常用路径如下：

- `/` 首页，也就是状态页主界面
- `/login` 登录页
- `/logout` 退出登录
- `/api/...` 一堆给前端调的后端接口

如果你只想看接口，不想看页面，直接访问 `/api` 开头的路径就行。注意这些接口要登录后才能访问。

## 改主题的具体做法

第一步，把 `static` 下的 CSS 文件复制一份，重命名成你自己的，比如 `theme-wanfeng.css`。

第二步，打开 `templates` 里对应的 HTML 文件，把引用 CSS 的那一行改掉：

```html
<link rel="stylesheet" href="/css/theme-wanfeng.css">
```

第三步，重新打包：

```
mvn -pl sentinel-dashboard -am clean package
```

第四步，启动：

```
java -jar sentinel-dashboard/target/sentinel-dashboard.jar
```

然后打开 `http://localhost:8080` 看效果。

## 改颜色和字体

CSS 里最常见的几个选择器：

- `body` 管全局背景和字体
- `.sidebar` 管左侧菜单
- `.content` 管右边主区域
- `.card` 管卡片

你要换背景色，改 `body` 里的 `background-color`。你要换字体，改 `body` 里的 `font-family`。你要让卡片圆角大一点，改 `.card` 里的 `border-radius`。

举个例子，把主背景换成浅灰：

```css
body {
  background-color: #f5f5f5;
  font-family: "Microsoft YaHei", sans-serif;
}
```

## 改标题和 logo

页面左上角那个标题文字，在 HTML 模板里，搜 `sentinel` 就能找到。把那段文字换成你自己的项目名。

logo 图片放在 `static` 下的 `img` 目录，你把图片替换掉，或者改 HTML 里 `img` 标签的 `src`。

## 注意事项

换主题别把功能搞坏。状态页上有一些按钮和表格，靠 CSS 类名定位，你把类名删了，JS 就找不到元素，页面会点不动。

上线前一定要改默认密码，不然谁都能打开你的状态页看数据。

如果你只想临时看效果，不想重新打包，可以改完之后用 `mvn spring-boot:run` 在 `sentinel-dashboard` 目录下直接跑，热部署会快一点。

改完记得清浏览器缓存，不然你看到的是旧的 CSS。
