# Sentinel 发版对照报告

## 一、改动摘要
- 接口：GET /api/monitors/{id}/checks
- 改动点：limit 参数越界处理由“钳制到合法范围”改为“返回 HTTP 400”。
- 非法口径：limit < 1 或 limit > 1000 视为非法，错误文案："limit 参数非法"。
- 保持不变：
  - 缺省 limit=100 行为不变。
  - 非数字 limit 返回 400 行为不变。
  - 资源不存在返回 404 行为不变。
  - store 层未改动。

## 二、验收范围
1. 靶向测试
- 旧“钳制”用例已改名并同步断言为越界返回 400。
- 既有非数字 limit 返回 400 用例不受影响。
- 既有合法 limit=10 返回 200 用例不受影响。
- 结果：靶向 3 组全绿（越界 400 同步测试、非数字 400、不存在 404）；go vet 全洁。

2. 真实服务冒烟
- 覆盖：缺省 limit=100、合法 limit=200、越界 limit=0 与 limit=1001、非数字 limit=abc、不存在 id 返回 404。
- 结果：靶向 3 组全绿（越界 400 同步测试、非数字 400、不存在 404）；go vet 全洁。

## 三、对照表
| 维度 | 结论 | 理由 |
| --- | --- | --- |
| 可靠性 | 通过 | 越界参数显式失败，避免隐蔽钳制带来的语义偏差。 |
| 可观测性 | 通过 | 非法请求返回明确 400 与文案，便于监控与排障。 |
| 数据 | 不适用 | 本轮仅改接口参数校验，store 层与数据结构未变。 |
| 部署 | 通过 | 变更集中在单接口参数处理，部署风险可控。 |
| 安全 | 通过 | 未新增权限面或敏感信息暴露，仅收紧非法输入处理。 |
| 可维护性 | 通过 | 错误语义更清晰，减少钳制逻辑造成的后续维护歧义。 |

## 四、已知限制
- handleStats 的 days 参数仍沿用钳制口径，不在本轮范围。
- handleListIncidents 的 page/pageSize 仍沿用钳制口径，不在本轮范围。
- 全量测试套件本轮未跑（只跑靶向 3 组）；冒烟库与二进制留在批次目录。
