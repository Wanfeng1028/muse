- 通过。队列状态机（pending→retrying→done / failed）、退避计算、去重有单元测试；入队→worker 扫描→投递有集成测试；投递失败注入测试已覆盖。本轮未动这块。

- 通过。指数退避 `base*2^(attempt-1)+jitter`，基数 60 秒，默认最多 8 次；失败落 failed 可手动重投；同一事件（monitor+url+event+payload）重复入队自动去重；策略已写进 CHANGELOG 与 README。本轮未动这块。
- 数据库迁移版本化（即使 SQLite），支持升级路径说明
- 通过。迁移已到 v5（`webhook_deliveries` 表）；老库自动补表/补列；升级说明在 OPERATIONS.md。本轮未动这块。

- 通过。`/healthz`、`/readyz` 已有；进程优雅关闭已有（关闭时 worker 停止、在途任务不被腰斩）。本轮未动这块。
