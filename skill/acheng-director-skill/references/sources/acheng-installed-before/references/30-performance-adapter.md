## 2. 动效五轨时序律与时间重叠窗口 (Five-Track Overlapping Dynamics)

真实的情感流露不是一瞬间五官同时乱动，而是遵循严格的**五轨生理传播物理时序**。在 10-15 秒镜头切片中，五轨呈现自然重叠交织推进：

```text
[第 1 轨: 眼神先动 (Gaze / Pupil)] ───────── (0.0s – 3.0s)
         │  (提前 1-2 秒重叠，目光率先变向/虚焦/瞳孔骤缩)
         ▼
[第 2 轨: 呼吸跟上 (Respiration / Throat)] ─── (2.0s – 5.0s)
         │  (呼吸骤停半拍 / 鼻息深吸 / 喉结微弱滑动吞咽)
         ▼
[第 3 轨: 肩膀承接 (Shoulder Mass)] ──────── (4.0s – 7.0s)
         │  (肩线微耸紧绷 / 肩胛骨沉落锁死 / 双肩微颤)
         ▼
[第 4 轨: 身体与手落动作 (Kinetic / Hands)] ── (6.0s – 10.0s)
         │  (身体重心后撤 / 五指攥紧枪柄 / 扶墙 / 跌坐)
         ▼
[第 5 轨: 声线与台词收尾 (Voice / Delivery)] ─ (9.0s – 12.0s)
         │  (声音沙哑发紧 / 尾音拖长带气音 / 字字压出牙缝)
         ▼
[落点定格 (Terminal Hold)] ───────────────── (12.0s – 15.0s)
            (画面自然定格在最后一轨状态，无突兀黑屏，无硬切跳变)
```

## 3. 高阶演员换挡与主导轨控制法则 (Advanced Acting Mechanics)

### 3.1 相邻镜头主导轨轮换机制 (Alternating Dominant Tracks) ★ 防多动抽搐
- **问题根源**：若连续三个镜头都写“瞳孔收缩”或“下颌咬紧”，AI 生成的视频角色会出现类似抽动症的假人感。
- **轮换铁律**：同一场戏相邻分镜必须强制切换“主导轨”：
  - **镜头 A (Shot 01)**：以【眼神轨】为主导（特写：目光由涣散到冰冷锁定，身体其余部分稳固）；
  - **镜头 B (Shot 02)**：以【呼吸与肩部轨】为主导（中景：胸口起伏突变，肩线沉落，目光保持稳定）；
  - **镜头 C (Shot 03)**：以【手部微动作与重心轨】为主导（近景：五指缓慢发力发白，手指轻抚刀柄）。

### 3.2 升档与降档换挡法则 (Gear Shift Dynamics)
- **降档类（失望克制、心如死灰）**：从“提着”沉到“落着”。眼神、呼吸、肩膀、重心四层同步向下沉潜，光芒熄灭、呼吸转浅、双肩垮落、身体后撤。
- **升档类（愤怒对抗、崩溃激烈）**：从“压着”到“爆燃”。呼吸从齿缝粗重拉扯、肩线骤然拔起前倾、青筋暴起、台词砸出。

### 3.3 复杂矛盾类拆开拍法则 (Contradiction Layering)
- 面对“嘴硬心软”、“又爱又恨”、“笑着流泪”等矛盾戏份：**主色上脸，底色只留一个破绽**（如嘴角微抿、尾音微颤或藏在袖内的指尖颤抖）。破绽轨道必须写在引导词最后，AI 视频大模型最容易精准执行。

### 3.4 特殊状态类物理支撑法则 (Physical Base for Special States)
- 醉态、病弱、梦魇、重伤濒死等非正常神志状态，**必须先写物理支撑基准**（如“身倚着立柱/手扶额角/手撑地表”），把身体接触点写进提示词第一句，彻底杜绝角色在镜头中诡异漂移！
