# GPT Image 2 图像提示词编译器

在生成或编辑角色、场景、道具资产图和叙事关键帧前读取本文件。目标模型固定为 `gpt-image-2`；视频时间线、音频和 Seedance 语法不得进入本编译器。

## 模型事实边界

- 把新图与编辑分开：无输入图时使用 generate；已有真值源时优先 edit，并实际传入所需参考图。
- 把 `quality`、`size`、输出格式作为生成参数，不把“8K”堆进画面描述。只使用当前接口实际暴露的合法尺寸；需要更高母版时记录后期交付目标，不伪装成提示词保证。
- 多图编辑时逐图声明职责、移植对象、目标位置与必须保持不变的内容。不要要求模型“融合所有参考图”。
- 迭代修改时重申不变量，只改变当前 1–3 项，避免身份、构图和光位随修复漂移。

官方依据需要复核时访问 OpenAI 的 [Image generation guide](https://developers.openai.com/api/docs/guides/image-generation) 与 [GPT Image prompting guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)。

## 生成请求头

在内部执行包中先建立：

```yaml
image_request:
  model: gpt-image-2
  operation: generate | edit
  purpose: character_asset | scene_asset | prop_asset | narrative_keyframe
  quality: low | medium | high
  size: ""
  input_images: []
```

`quality: low` 用于草稿与构图探索，`medium/high` 用于用户确认后的资产或关键帧。实际尺寸必须符合当前入口规则；画幅比来自生产合同，不能靠文字“竖屏/横屏”替代参数。

## 参考图职责

给每张输入图一个主职责：

| role | 继承内容 | 不继承内容 |
|---|---|---|
| `identity` | 脸、年龄、发型、体型、服装结构、武器 | 版式、摄影棚背景、临时表情、偶发色偏 |
| `scene` | 空间地图、地标、透视、材质、世界光向 | 临时人物、随机道具、无关文字 |
| `prop` | 尺寸、结构、磨损、开合和持握界面 | 原图背景与错误尺度 |
| `pose` | 重心、动作线、肢体关系 | 人脸、服装、物种和画风 |
| `composition` | 机位、景别、主体占比、前中后景 | 身份和临时光色 |
| `lighting` | 主光方向、主亮区、色温、阴影关系 | 身份、构图和场景结构 |

职责冲突时遵循主 Skill 的权威顺序。只传当前画面真正需要的参考图，减少竞争约束。

## 两条编译路径

### 资产真值源

角色资产只建立身份、比例、服装、武器和材质：中性站姿、中性可读神情、无遮挡，不消费 `expression_handoff`，不写剧情动作、伤情爆发或临时表情。场景资产不放剧情人物；道具资产清楚呈现结构、尺度与交互面。

按以下顺序编译：

```text
资产用途 -> 身份/结构定义 -> 视图或版式 -> 摄影棚/空场条件 ->
材质与尺度 -> 固定画风 DNA -> 必须排除项 -> size/quality 参数
```

已确认的资产更新只修改剧情要求的造型版本；不要借换装重设计脸和体型。

### 叙事关键帧

关键帧必须绑定 `shot_id`、ShotSpec、关键帧判定标准和实际输入资产。表演部分只读取 `performance_provenance.selected_phase` 及该相位可见线索；不要把 `state_in`、`leakage`、`control_action`、`residual` 全部写进同一静帧。

按以下顺序编译为一段连贯中文指令：

```text
目标与用途 -> [imgX] 职责 -> 必须保持 -> 本次改变 ->
镜头/构图/空间 -> 主体动作与接触点 -> 单一表演相位 ->
统治性主光与主亮区 -> 材质与固定画风 DNA -> 文字/比例/排除项
```

## 编译规则

1. 使用可见名词和动作，不使用“震撼、悲伤、电影感”代替画面。
2. 对方向性物体写清人物朝向、视线、物体正反面、手部接触和距离。
3. 对每张参考图写“保留什么、不继承什么、用于哪里”。
4. 对编辑任务明确“只改变什么”，并重申身份、场景、机位、光向和其余对象不变。
5. 文字必须逐字引用并说明只出现一次；不需要文字时明确无文字、Logo 和水印。
6. 固定中文画风段一字不差取自 `00-visual-contract.md`，不追加别的工作室或画风标签。
7. `exclusions` 转成具体可检查的限制，例如“眼睑保持自然开度”比“不要夸张”更明确；必要的禁止项仍保留在结尾。
8. 不把动作过程写成残影叠帧；高速动作关键帧选择蓄势、接触前、命中或分离后的一个稳定相位。

## 关键帧示例

```text
使用[img0]作为沈砚的 identity 真值源，只继承脸、成年年龄表现、发型、体型和深灰外套结构，不继承四宫格版式、摄影棚背景与中性表情；使用[img1]作为旧公寓 scene 真值源，保持书架、门框、空间透视和世界光向。生成 shot_id EP01-S03-SH04 的叙事关键帧：中近景，沈砚位于画面左侧三分之一，身体朝向林晚，右手尚未碰到信封；选取 EX-S03-B04 的 leakage 相位，呼吸短暂停住，视线刚从信封移回林晚，下眼睑短促绷紧，其余面部保持克制。保持同一场景主光、接触阴影和人物身份，使用视觉合同的固定中文画风 DNA。画面无字幕、Logo、水印和无关人物。
```

## 质量门禁

- `operation` 与是否传入参考图一致；
- 每张输入图职责唯一且可追踪；
- 资产图未被剧情表演污染；
- 关键帧绑定一个 `shot_id` 和一个 `selected_phase`；
- 身份、场景、道具、光位与既有 Bible 一致；
- 文字、手、武器、接触点、尺度和地面关系可检查；
- `size`/`quality` 在参数层明确，提示词没有虚构 8K 能力；
- 最终图仍符合 `00-visual-contract.md` 的统一质量门控。
