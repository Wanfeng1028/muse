# 巨构与巨物分支手册

只在需要选择分支、诊断失败或处理非建筑巨物时读取。

## 一、尺度证据组合

优先选择互补证据，不把同一事实写三遍。

| 目标 | 主证据 | 次证据 | 常见误判 |
|---|---|---|---|
| 文明级建筑 | 公共流线、城市/地貌占比 | 构造模数、空气层 | 只有小人和大台阶 |
| 巨型器物 | 维护层、接口、阴影范围 | 环境扰动、材料接缝 | 普通物品近距离拍摄 |
| 完整巨兽 | 地平线/天气互动 | 船、建筑、树林等基准 | 全身入画后像玩具 |
| 局部巨兽 | 身体跨越画框、皮肤曲率 | 环境接触、远处同体结构 | 只是一块无意义纹理 |
| 纯有机巨物 | 生长模数、血管/骨板尺度 | 无机参照物、环境挤压 | 用现成动物放大 |
| 克苏鲁实体 | 无法一次读完的身体因果 | 天气/潮汐/引力后果 | 眼睛触手数量竞赛 |

## 二、四种构图模式的适用条件

### 1. 多边出框

适合：逼近、遮天、压迫、建筑立面或巨大身体局部。

必须保留：一块可读的负空间、一个方向明确的轮廓转折、至少一个同深度参照。

失败信号：主体只是被裁坏；观众无法推断完整体量。

### 2. 一轴完整、他轴无尽

适合：长墙、垂直塔体、峡谷桥、翼展、蛇形或带状实体。

例：完整展示高度，让长度离框；完整展示截面，让深度伸向地平线。

失败信号：每个维度都被裁掉，主形无法辨认；或所有维度都完整，像商品展示。

### 3. 完整剪影 + 环境级留白

适合：轮廓独特的巨兽、雕像、飞行物、平面海报。

必须用地平线、云层、阴影、城市或环境后果补足尺度；不要靠“写着几公里高”。

失败信号：主体在空背景中孤立，像贴纸或玩具。

### 4. 可居住剖深

适合：城市器官、公共建筑、内外贯通的巨构。

用多层入口、维护层、交通、光井、功能分区和活动证明内部空间。

失败信号：所有层都同样清晰、同样亮，变成信息墙。

## 三、分支细则

### 建筑 / 基础设施

- 先定义公共功能或文明行为，再定义外形。
- 给建筑一条可信的主负载路径：基座、支撑、悬挑、拉索、拱、壳或地形承托。
- 人群作为使用证据，避免军事队列、宣传集会或单英雄朝圣成为默认。
- 入口、窗口、台阶与道路的尺寸应互相一致。
- 让建筑对雨、潮、风、沉降、侵蚀或时间作出反应。

### 巨型器物

- 明确它怎样启动、承压、散热、传输或维护。
- 让尺度基准接触器物：检修桥、车辆、码头、舱门、缆线或施工区。
- 保留一个可识别的功能接口，避免变成无意义的复杂形状。
- 未来感来自结构逻辑和新型使用方式，不来自均匀加机械碎件。

### 巨型生物 / 神话实体

- 先锁定整体姿态与重心，再设计表皮。
- 身体体量要对地面、水面、植被、云层或建筑产生相应反作用。
- 完整可见时，用环境级尺度和轮廓；局部可见时，用曲率、跨框连续性和接触后果。
- 已知动物可作为形态基础，但要重建身体结构与行为，避免普通动物等比放大。

### 克苏鲁 / 宇宙恐怖

- 设计一种观众能感知后果、却不能立即读完的身体规则。
- 用潮汐反常、云层弯折、影子错位、地貌生长或声波可视后果表现存在感。
- 将细部集中在一个“异常阅读区”，其余身体保留大块未知形。
- 陌生感来自尺度、因果和不完全可读，不来自腐烂滤镜或器官堆砌。

### 纯有机巨物（严格分支）

仅在用户明确要求“完全陌生、纯有机、不要现成物种”时启用：

- 主体身体只使用生物性组织：皮肤、角质、骨、毛、黏液、甲壳、血管、腺体等。
- 不用已知物种名称或物种类比定义主体；从生长方式、对称规则、支撑方式和感知器官开始。
- 身体上不混入金属、石材或机械零件。
- 尺度参照使用无机物：建筑、船、列车、车辆、桥梁、工业设施。
- 不把全身铺满孔洞、眼睛、触手和血管；保留大块安静组织面。

## 四、失败诊断与最小修复

### 看起来不够大

原因通常不是尺寸写小，而是没有空间证据。

最小修复顺序：

1. 重选构图模式；
2. 把基准物移到可比较的深度平面；
3. 添加环境级互动或公共流线；
4. 最后才调整表面模数。

### 画面太碎、太脏

原因：细节覆盖了所有区域，轮廓和价值质量被吃掉。

最小修复：合并成三到四块大价值质量；清空一块安静区；细节只留在焦点、结构转折和尺度基准附近。

### 像模型或玩具

原因：高位视角、过深景深、均匀锐度、微缩光、主体与环境无接触。

最小修复：降低观察高度或增加空气层；建立接触阴影、天气遮挡和真实使用痕迹；减少全图均匀清晰。

### 有小人但还是不大

原因：人物可能太近、深度不明，或人物只作装饰。

最小修复：让人物与门、道路、平台或维护层形成一条连续尺寸链，再与主体相连。

### 有雾但没有纵深

原因：全图均匀加雾或全局降低清晰度。

最小修复：让雾被不同深度的结构切开；前中远层依次调整对比和细节；保留主轮廓与事件的清晰锚点。

### 有体积光但光位不对

原因：只画了光束，没有来源、遮挡和接收面。

最小修复：先定位光源和遮挡边缘，再画介质中的路径，最后明确被照亮的材质与反弹区域。

### 物理结构悬空

原因：造型先于支撑、受力或生长逻辑。

最小修复：画出一条从主要质量到地形/基座的负载路径；有机体则明确骨架、肌肉牵引或浮力来源。

### 九张像一张换背景

原因：固定使用中央门洞、巨型阶梯、小人朝圣、单束神光。

最小修复：先为每张分配不同的治理轮廓、世界机制、构图模式和尺度证据组合，再设计环境与颜色。

## 五、提示词精简规则

把提示词写成画面因果，不写质量口号：

```text
主体与灵魂 → 决定性事件 → 治理轮廓 → 尺度证据 → 构图与相机
→ 光路与空气 → 材质/结构因果 → 媒介翻译 → 少量关键约束
```

删除：重复的巨大形容词、无法验证的精确尺寸、质量标签、引擎名、互相冲突的镜头词、长串同义负面词。

保留：真正改变轮廓、空间、事件、光路、物理或媒介的条件。
