## 1. 研究原則

平台規則、榜單、商業模式與熱門題材會變。遇到「現在、最新、今年、哪個平台、平台政策」時必須上網查，附檢索日期與直接來源。

資料分級：

- **A：** 官方平台、主管機關、正式標準、原始研究。
- **B：** 可信媒體、研究機構、上市公司或產業報告。
- **C：** 創作者復盤、社群討論、案例拆解。只用來形成假設。
- **Q：** 廣告、搬運文、無來源排行榜。不可當事實基礎。

不要把單一爆款當普遍公式，也不要以播放量反推因果。分清發布日期、事件日期、地區、付費／免費、真人／AI、App 內／社群漏斗。

## 2. 發行表面矩陣

| 表面 | 觀眾行為 | 故事設計重點 | 測試重點 |
|---|---|---|---|
| 抖音／快手／Shorts／TikTok／Reels | 滑動發現、低承諾 | 首幀衝突、單集可理解、快速 state change | 前幾秒停留、看完、重播、追蹤／下一集意圖 |
| 紅果等免費長連載表面 | 連續觀看、廣告支持 | micro-arc、穩定更新、長揭露梯、角色黏性 | 集間留存、連看深度、跳出集、完成 arc 比例 |
| ReelShort／DramaBox 類付費 App | 廣告獲客後 binge／付費解鎖 | 強 trope 承諾、密集 cliffhanger、付費點前價值累積 | 廣告到安裝、下一集、解鎖、付費留存 |
| Bilibili／YouTube 中長篇 | 主動點擊、可追系列 | 世界觀、角色弧、合輯價值、可搜尋包裝 | 點擊、平均觀看、章節掉點、訂閱／回訪 |

上表是工作模型，不是固定平台規格。集長與集數依當下平台和商業模式確認。

### 社群原生與 App 原生不可混寫

社群原生每集需要最低限度自足：第一次刷到第 7 集的人仍知道當前衝突。App 原生可以承受更緊密的連續場景，但必須在付費／廣告節點前先交付價值，不能只有斷點。

## 3. 題材機會判讀

不追求「全網最多人做」，而找：

```text
可辨識需求 × 供給仍有空隙 × 具體新鮮機制 × 本團隊的 AI 生產優勢
```

Opportunity Map 至少含：

| 欄位 | 說明 |
|---|---|
| 市場／平台／日期 | 防止跨市場誤用 |
| 已驗證引擎 | 觀眾熟悉的情感承諾 |
| 飽和訊號 | 同構標題、同一人物設定、素材成本激增 |
| 缺口 | 尚未被充分滿足的人群、情感、職業、形式 |
| AI 優勢 | 真人昂貴或難以穩定呈現的部分 |
| 原創變量 | 規則、代價、關係、敘事視角或世界 |
| 反例／風險 | 可能不成立的證據 |
| 驗證方式 | 最小 pilot 與成功／停止條件 |

### 可重用的研究組合

- 榜單／平台頁：看實際上架與類型語彙。
- 產業報告：看市場份額、題材變化與商業模式。
- 媒體專訪：看製作方的選題和發行邏輯。
- 觀眾評論：找「棄劇原因」而非只抄稱讚。
- 創作者復盤：形成成本和工作流假設，再用自己的 pilot 驗證。

## 4. Pilot 驗證

預設只投資 3–5 集：

1. 用兩種首幀／標題測同一故事承諾，不同包裝不改故事。
2. 第 1 集測 premise 可讀性與主角差距。
3. 第 2 集測觀眾是否接受表演、世界與第一個小回報。
4. 第 3 集測公開反轉後是否仍想追更，而非只想看一次打臉。
5. 若第 1 集點擊弱，先分辨包裝或概念；若點擊強、續看弱，先查故事／製作。

不要同時改題材、首幀、聲音、節奏和集長，否則無法知道因果。

### 測試單位

- **概念測試：** 同等製作品質下，比較不同 premise。
- **包裝測試：** 同一集只換 title／cover／首幀。
- **節奏測試：** 同素材做不同 cut，不改台詞與劇情。
- **形態測試：** 同一 scene 做仿真人與漫劇 style probe，比較可讀性與成本，不必做完整三集兩套。

## 5. 指標與診斷

使用平台實際提供的名稱；沒有平台基準時，不捏造「爆款門檻」。先建立自己的中位數與分位數。

| 指標訊號 | 可能問題 | 下一步 |
|---|---|---|
| 曝光有、停留低 | 首幀／題材承諾不清 | 改視覺衝突與一句話，不先重寫整季 |
| 首段好、turn 前跌 | 壓力段重複或解釋過多 | 提前選擇、刪背景、用行為呈現 |
| 完播好、下一集弱 | cliffhanger 假、角色無長期問題 | 增加不可逆 state change 與季問題 |
| 下一集好、三集後跌 | 重複打臉、揭露梯太平 | 升敵人、改代價、償還爽債後開更高階問題 |
| 故事留言好、畫面負評 | 生產一致性或表演 | 回 Asset／Voice／I2V 層，不改題材 |
| 點擊與追更好、付費弱 | 價值交付與付費點錯位 | 在付費前交付一個真 payoff，再開更大問題 |

追蹤最少包含：曝光或開播、首段停留、完成、下一集／追蹤、分享／收藏、集間留存；有商業漏斗再加安裝、解鎖、付費與回本。

一支作品只提供一個案例。至少三個不同作品在相近市場與表面出現同方向結果，才升級為預設 pattern；一旦平台或觀眾變化，重新驗證。
