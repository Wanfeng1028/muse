# 3D，以及 2D 与 3D 互转

## 1. 三个层级，能轻就轻

| 层级 | 做法 | 适合 | 代价 |
|---|---|---|---|
| CSS 3D | `perspective` 加 `rotateX/Y`、`translateZ` | 卡片翻转、文字立体入场、UI 倾斜展示、等距 | 几乎没有 |
| 2.5D 视差 | 前中后景分层，镜头移动时速度不同 | 纵深感、纸艺、拼贴、照片动起来 | 几乎没有 |
| 真 3D | Three.js（`@remotion/three` 加 `@react-three/fiber`） | 立体物体、材质、光照、相机环绕 | 渲染慢，调光费时 |

**能用 CSS 3D 或 2.5D 解决的，不要上真 3D。**

## 2. CSS 3D

```tsx
<div style={{perspective: 1200, perspectiveOrigin: '50% 40%'}}>
  <div style={{
    transformStyle: 'preserve-3d',
    transform: `rotateX(${mix(60, 0, t)}deg) translateZ(${mix(-400, 0, t)}px)`,
  }}>
    <Card />
  </div>
</div>
```

- `perspective` 的值越小，透视越夸张。800 到 1500 比较自然。
- **坑：父元素上的 `overflow: hidden`、`filter`、`opacity < 1`、`mix-blend-mode` 会让 `preserve-3d` 失效，子元素被压平。** 这些效果要加在不参与 3D 的外层或内层。
- 逐字 3D 翻转：每个字包一层 `display: inline-block`，`transform: rotateX(90deg)` 到 0，`transformOrigin: '50% 100%'`，错峰 2 到 3 帧。
- 等距视角：`transform: rotateX(60deg) rotateZ(-45deg)`。

## 3. 2.5D 视差

- 把一张图拆成前景、中景、背景三层（生图时可以直接分层生成，或者用抠图得到前景）。
- 镜头移动时：背景移动 0.3 到 0.5 倍，中景 1 倍，前景 1.3 到 1.6 倍。缩放同理。
- 前景可以加一点模糊，模拟景深。
- 照片动起来（Ken Burns 升级版）：分层之后，再加极慢的推和轻微的横移，静态照片立刻有了空间感。

## 4. 真 3D：在 Remotion 里用 Three.js

安装：

```bash
npm i three @react-three/fiber @remotion/three
npm i -D @types/three
```

`@remotion/three` 必须和 `remotion` 版本完全一致；`@react-three/fiber` 的大版本要匹配 React 的大版本（React 18 用 fiber 8，React 19 用 fiber 9）。

最小示例：

```tsx
import {ThreeCanvas} from '@remotion/three';
import {useCurrentFrame, useVideoConfig, interpolate} from 'remotion';

export const Orbit: React.FC = () => {
  const frame = useCurrentFrame();
  const {width, height} = useVideoConfig();
  const angle = interpolate(frame, [0, 150], [0, Math.PI / 2]);
  return (
    <ThreeCanvas width={width} height={height} camera={{fov: 35, position: [0, 1.5, 6]}}>
      <ambientLight intensity={0.4} />
      <directionalLight position={[3, 5, 2]} intensity={1.2} />
      <mesh rotation={[0, angle, 0]}>
        <boxGeometry args={[1.6, 1.6, 1.6]} />
        <meshStandardMaterial color="#FF8A3D" roughness={0.6} />
      </mesh>
    </ThreeCanvas>
  );
};
```

**规则：**
- **所有运动都由 `useCurrentFrame()` 算出来。不要用 fiber 的 `useFrame` 和时钟**，否则渲染结果不确定。
- 相机要动的时候，在场景里写一个组件，用 `useThree()` 拿到相机，根据帧号设置位置并 `lookAt`。
- 纹理、模型、字体都要等加载完成（`delayRender`），加载器的资源路径用 `staticFile()`。
- 渲染 3D 要指定 GL 后端：Windows 用 `--gl=angle`（模板的 `remotion.config.ts` 已设置），Linux 服务器一般用 `--gl=angle-egl` 或 `--gl=swangle`（软件渲染，慢但稳）。黑屏或报 WebGL 错误，首先怀疑这个。
- 3D 场景渲染慢，并发数调低（`--concurrency=2`），先用 `--scale=0.5` 出草稿。

### 灯光配方

- **三点布光**：主光（最亮，45 度斜上方）、补光（主光的 30% 到 50%，对侧）、轮廓光（从背后打，勾出边缘）。
- **柔和的产品光**：环境光 0.3 到 0.5，加一个大面积的方向光，再加一个很弱的背光。
- **戏剧光**：只有一个方向光，环境光很低，大面积阴影。

### 材质配方

| 质感 | 设置 |
|---|---|
| 粘土、哑光 | `meshStandardMaterial`，roughness 0.8 到 1，metalness 0，粉彩色 |
| 塑料、亮面 | roughness 0.2 到 0.4，metalness 0 |
| 金属 | roughness 0.2 到 0.4，metalness 1，需要环境贴图才好看 |
| 玻璃 | `meshPhysicalMaterial`，transmission 1，roughness 0 到 0.1，渲染很慢 |
| 低多边形 | `flatShading: true` |

### 3D 里的文字

- 把文字画到一个 `<canvas>` 上，作为 `CanvasTexture` 贴到平面上。最稳，中文没问题。
- 或者用 drei 的 `Text`（troika），需要显式指定字体文件路径（中文字体文件较大），并等待字体加载。
- 大段文字尽量放在 2D 层，叠在 3D 画面上面。

## 5. 2D 变 3D

1. **倾斜揭示**：先把 2D 画面作为 3D 空间里一块平面的贴图。开场时相机正对着它，画面看起来和 2D 完全一样。然后相机一转，观众突然发现「原来它在一个空间里」。
   - 纯 CSS 版：整个 2D 画面外包一层 `perspective`，从 `rotateX(0)` 转到 `rotateX(55deg) rotateZ(-20deg)`，同时缩小，画面「躺」进空间里。
2. **挤出成型**：把 SVG 图形（Logo、图标、文字轮廓）用 Three.js 的 `ExtrudeGeometry` 挤出厚度，厚度从 0 动画到目标值。开始时厚度为 0，就是一个平面图形。
3. **爆炸分层**：把一个 2D 界面拆成若干层（背景、卡片、按钮、文字），然后在 Z 轴上拉开，再转动视角。非常适合展示 UI 的结构。
4. **折叠成体**：一张平面卡片沿边折叠成一个立方体或盒子。

## 6. 3D 变 2D

1. **滑动变焦压平**：相机一边后退，一边收窄视角，同时让物体在画面里的大小保持不变。透视会被一点点「压扁」，最后看起来就是一张平面。保持大小不变的条件是：`距离 × tan(视角 ÷ 2)` 为常数。

   ```ts
   const k = d0 * Math.tan((fov0 * Math.PI) / 360);    // 起始距离和视角决定的常数
   const d = mix(d0, d0 * 20, t);                        // 相机后退到 20 倍距离
   const fov = (2 * Math.atan(k / d) * 180) / Math.PI;   // 同步收窄视角
   ```
2. **转正再切换**：相机转到正对平面的角度，这时透视画面和 2D 画面几乎一样，在这一帧硬切到 2D 场景。
3. **厚度归零**：挤出的厚度动画回 0，物体变回平面图形。
4. **定格成图**：3D 镜头最后一帧渲染成图片，作为下一个 2D 场景的第一个元素继续使用。

**无缝的关键：在两种表现方式看起来完全一样的那一帧切换。** 切换点前后各渲染一帧静帧对比，确认没有跳变。

## 7. 等距世界

- Three.js 里用正交相机（`OrthographicCamera`），相机位置在 `(d, d, d)` 方向并看向原点，就是标准的等距视角。
- 正交相机下物体远近大小不变，缩放用相机的 `zoom` 属性。
- 2D 做法见 `styles.md` 的等距部分。

## 8. 3D 自检

- [ ] 所有运动都由帧号驱动，同一帧渲染两次结果一样。
- [ ] 灯光有主次，物体有明暗面，不是一片平光。
- [ ] 资源都等加载完成，第一帧没有缺失的纹理。
- [ ] 2D 和 3D 的切换帧前后对比过，没有跳变。
- [ ] 用低分辨率确认镜头之后才全量渲染。
