# 纯代码：什么都没有，只能写代码的时候

没有配音、没有音乐、没有图片、没有 AI，只有代码。这不是劣势，**限制本身就是风格。** 很多最好看的动态设计，本来就是纯代码做的。

## 1. 心法：扬长避短

**代码天生擅长的**：文字、排版、几何图形、线条、数据图表、粒子、噪声、字符画、UI 界面、渐变、光效、精确的时间和节奏、无限的一致性。

**代码不擅长的**：真人、写实的场景和物体、复杂的角色动画、自然界的质感。

所以：**选择代码擅长的形式来讲故事，不要硬去模仿写实。** 想讲太阳，不要试图画一个逼真的太阳，而是用字符拼一个、用光点汇聚一个、用数据描述一个、用文字诉说一个。往往这样更有意思。

## 2. 画面从哪来

| 素材 | 做法 |
|---|---|
| 文字 | 最重要的素材。见 `typography.md` |
| 几何图形 | `div` 加圆角、`clip-path`、SVG 的 `circle`、`rect`、`path` |
| 图标、简单插画 | 手写 SVG 路径。保持线条风格统一，比如统一 2px 描边、圆角端点 |
| 数据图表 | SVG 或 `div` 手写，比例尺就是 `interpolate` |
| 光效 | 径向渐变、多层模糊、`screen` 混合 |
| 纹理 | SVG `feTurbulence` 噪声、重复渐变（条纹、网点、网格） |
| 粒子 | 带种子的随机数加噪声，数量多时用 canvas |
| 字符画 | 模板的 `Ascii` 组件 |
| UI 界面 | 用 HTML 和 CSS 直接写一个假界面，比截图更清晰、可以随意动 |
| 3D 基础形体 | Three.js 的几何体，粘土或低多边形风格 |
| 生成艺术 | 噪声场、流场、分形、网格变形、Voronoi |

**不要用 emoji 当素材。** 不同渲染环境的 emoji 字体不同，可能显示成方块或者风格不一致。

## 3. 声音从哪来：用代码合成

### 音效

```bash
python <skill>/scripts/synth_sfx.py --out public/sfx
```

会生成 13 种音效和 `manifest.json`（记录每个音效的时长和峰值时间）：

| 音效 | 合成方法 | 用途 |
|---|---|---|
| whoosh / whoosh_fast | 白噪声通过中心频率先升后降的带通滤波，音量先升后降，声像从左到右 | 运动、飞入、甩镜头 |
| hit | 短促的滤波噪声爆发加一个快速下滑的低频正弦 | 落定、撞击 |
| boom | 从 55Hz 滑到 30Hz 的正弦加低频噪声，长衰减，加混响 | 大揭示 |
| sub_drop | 从 90Hz 滑到 30Hz 的正弦 | 转折、下沉 |
| riser | 噪声的带通中心频率指数上升，音量渐强，结尾戛然而止 | 蓄力 |
| reverse_swell | 一个带混响的撞击声倒放 | 吸入、揭示前 |
| tick / click | 极短的正弦脉冲或噪声脉冲 | 文字、UI、计数 |
| pop | 快速下滑的正弦加短衰减 | 弹出、气泡 |
| glitch | 随机切片的方波、噪声和降采样 | 故障 |
| shimmer | 多个高频正弦随机闪烁，加混响 | 光、希望、魔法 |
| drone | 多个失谐的锯齿波经过低通，缓慢的音量起伏，可循环 | 铺底、紧张、空间感 |

这些音效已经预先生成在模板的 `public/sfx/` 里，新工程直接可用。需要不同的变体时，可以改参数重新生成（`--seed` 换随机种子）。

### 配乐

```bash
python <skill>/scripts/synth_music.py --mood melancholic --bpm 72 \
  --structure "intro:4,build:8,peak:8,break:2,peak:8,outro:4" \
  --out public/music/bgm.wav --fps 30
```

- `--mood`：`calm`（平静）、`hopeful`（希望）、`melancholic`（忧伤）、`tense`（紧张）、`epic`（宏大）、`tech`（科技）。不同情绪对应不同的和弦进行、默认速度和鼓的风格。
- `--structure`：段落名和小节数。段落名决定编配的密度：`intro`（只有铺底和零星的拨弦）、`build`（加入琶音，滤波器逐渐打开，后半段加入轻微的镲）、`peak`（全部乐器：铺底、琶音、低音、鼓）、`break`（只剩铺底，很安静）、`outro`（逐渐淡出）。
- 同时输出 `bgm.json`：每个段落的起止秒数和帧号，以及每拍帧数。**直接拿来排分镜，不需要再分析。**

**说实话**：合成配乐是一个「能用的底子」，情绪和结构是对的，但音色比不上真正的音乐。如果用户能提供音乐或者有音乐 AI，优先用那些。

### 不用音乐

纯音效加静默，对悬疑、极简、情绪浓度高的片子，反而更有力量。环境底噪（drone）加上几个关键时刻的音效，就能撑起一部片子。

## 4. 纯代码片型配方

**配方一：文字情绪短片**（30 到 90 秒）
- 结构：起承转合。
- 画面：深色背景，一种衬线或手写感字体，一句一屏，遮罩升起或模糊入场，停留充足。高潮处一个巨大的字或一句话。
- 质感：颗粒、暗角、偶尔的漏光。
- 声音：合成的 melancholic 或 calm 配乐，音效只用 3 到 4 种。

**配方二：字符动画**（15 到 90 秒）
- 结构：从空白终端开始，打字、解码、字符画出现、变化、汇聚。
- 画面：等宽字体，单色加一个强调色。
- 声音：tick、glitch、drone，tech 或 calm 配乐。

**配方三：几何 MG**（15 到 60 秒）
- 结构：钩子、展开、高潮、落版。
- 画面：几个基本图形（圆、方、线）和它们之间的变形、连锁反应，4 到 5 个颜色。
- 声音：pop、whoosh、hit，hopeful 或 tech 配乐。

**配方四：数据故事**（30 到 90 秒）
- 结构：一个惊人的数字、它意味着什么、拆解、对比、结论。
- 画面：数据新闻风格，逐步生长的图表，数字滚动，高亮重点。
- 声音：tick、hit，calm 配乐。

**配方五：生成艺术循环**（10 到 30 秒，可无缝循环）
- 画面：噪声场、流动的粒子、渐变光斑，所有周期都能整除总时长。
- 声音：drone 或 calm 配乐的铺底段落。

**配方六：假界面演示**（15 到 60 秒）
- 画面：用 HTML 和 CSS 写一个产品界面，虚拟摄像机推近操作细节，假的光标点击按钮，界面产生连锁反应。
- 声音：click、pop、whoosh，tech 配乐。

## 5. 纯代码片子的质量关键

- **字体决定一切。** 纯代码片子的大部分画面是字，务必下载好的字体放进工程（见 `typography.md`）。
- **质感对抗「塑料感」。** 纯代码画面天生太干净，一定要叠一点颗粒和暗角。
- **动作要有变化。** 没有照片和视频来提供丰富度，就要靠动作的多样性：不同镜头用不同的入场方式、不同的运动方向、不同的构图。
- **一个视觉母题贯穿全片**：一个圆、一条线、一个光标、一个颜色。它的变化就是故事。
