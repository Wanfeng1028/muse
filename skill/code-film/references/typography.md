# 文字动效：文字就是画面

在代码视频里，文字不是贴在画面上的说明，它本身就是画面的主角。PV、文字动效片、情绪片、很多科普片，大部分画面就是文字。

## 1. 字体

**全片最多两种字体，加一种等宽字体。** 字体选择决定了片子一半的气质。

免费可商用、效果好的选择（使用前确认最新授权）：

| 字体 | 气质 | 用途 |
|---|---|---|
| 思源黑体 / Noto Sans SC | 中性、现代、稳 | 万能正文和标题 |
| 思源宋体 / Noto Serif SC | 文学、电影、克制 | 情绪片、电影感标题 |
| 得意黑 Smiley Sans | 有个性的斜体，年轻、潮 | PV、潮流标题 |
| 霞鹜文楷 LXGW WenKai | 温柔、手写感、文艺 | 诗意片、读书类 |
| 阿里巴巴普惠体 | 现代、商业 | 产品宣传 |
| 站酷系列（快乐体、庆科黄油体等） | 活泼 | 轻松、年轻的片子，慎用 |
| Inter / Space Grotesk | 现代西文 | 西文标题和数字 |
| JetBrains Mono / IBM Plex Mono / 更纱黑体 Mono | 等宽 | 代码、终端、ASCII 字符画 |

**字体文件必须放进工程的 `public/fonts/`，在 `theme.ts` 里登记。** 不要依赖系统字体：渲染环境不同，系统字体可能不存在，中文会变成方块或者回退成难看的字体。

## 2. 字号、字距、行高

1920×1080 横屏参考：

| 层级 | 字号 | 用途 |
|---|---|---|
| 展示 | 160 到 320px | 一屏一个词、片名、巨大数字 |
| 标题 | 88 到 140px | 镜头主标题 |
| 正文 | 44 到 64px | 说明、句子 |
| 注释 | 28 到 36px | 来源、编号、装饰性小字 |

1080×1920 竖屏：正文不小于 48px，标题 96 到 160px。**手机上看的字，要比你在电脑上觉得合适的再大一号。**

- **层级之间的字号比例至少 1.5 倍**，差得越多越有张力。巨大的字配极小的字，是最有设计感的组合。
- **中文标题**可以把字间距拉开 5% 到 15%（`letterSpacing: '0.1em'`），马上显得讲究。
- **西文大标题**要把字间距收紧 2% 到 4%（`letterSpacing: '-0.03em'`）。
- 行高：中文正文 1.4 到 1.6，大标题 1.1 到 1.25。
- 数字用等宽数字（`fontVariantNumeric: 'tabular-nums'`），否则数字滚动时会左右抖。

## 3. 文字动效技法库

模板里已经实现的：`SplitText`（逐字或逐词，支持遮罩升起、模糊、淡入、缩放）、`Typewriter`（打字、删除、改写、光标）、`Decode`（乱码解码）。其他按下面的做法写。

| 技法 | 做法 | 适合 |
|---|---|---|
| **遮罩升起** | 每行或每字外层 `overflow: hidden`，内层从 `translateY(110%)` 到 0，错峰 2 到 3 帧 | 高级感的万能入场 |
| 模糊入场 | `blur(12px)` 到 0，加透明度 | 电影感、柔和 |
| **打字机** | 可见字数 = 已过时间 × 每秒字数；打字时光标常亮，停下后每 16 帧闪一次 | 叙事、AI、终端 |
| 打字、删除、改写 | 打出一句，退格删掉一部分，改写成另一句 | 反转、自我修正、幽默 |
| **乱码解码** | 每个字在「揭晓时间」前显示随机字符（每 2 帧换一次），之后显示正确字符，从左到右依次揭晓 | 科技、AI、悬疑 |
| 词语翻牌 | 句子不动，其中一个词像老虎机一样上下滚动换成另一个 | 对比、列举 |
| **节拍闪词** | 每拍换一个词，全屏大字，可以黑白反色交替 | PV、卡点、高潮 |
| **巨小对比** | 一个铺满画面的大字，旁边配极小的注释 | 设计感、海报感 |
| 排版快切 | 同一句话，每拍换一种排版（横、竖、斜、满屏、居左） | PV |
| 文字当窗口 | 文字镂空，透过字能看到后面的图像或视频（`background-clip: text`） | 片名、情绪 |
| 描边与实心 | `WebkitTextStroke` 描边字，某一刻填满变成实心 | 强调、节拍 |
| 滚动字带 | 一条或几条文字带无限横向滚动，可以倾斜 | PV、潮流、背景装饰 |
| 路径文字 | SVG `textPath`，改变 `startOffset` 让文字沿路径走 | 趣味、曲线 |
| 3D 翻转 | 每个字 `rotateX(90deg)` 到 0，父级加 `perspective` | 立体感入场 |
| 可变字体 | 改变字重轴 `fontVariationSettings: "'wght' 100"` 到 900 | 呼吸感、强调 |
| **笔画书写** | 用汉字笔顺数据（如 hanzi-writer-data 的 SVG 路径），按笔顺依次绘制描边 | 国风、教育、书法 |
| 粒子成字 | 把文字画到离屏 canvas，采样出像素点作为粒子的终点 | 汇聚、揭示 |
| 大字压屏 | 大字从 1.3 倍缩到 1 砸下，同时震屏、闪白、配 hit | 重音 |
| 高亮标记 | 关键词背后的色块从左往右扫出 | 科普、强调重点 |
| 数字滚动 | 数值从 0 缓出到目标值，格式化千分位 | 数据、成就 |
| 竖排 | `writingMode: 'vertical-rl'` | 国风、诗意 |

## 4. PV 风格的文字

日系动画 PV、音乐 PV、潮流宣传片常见的做法：
- 每拍甚至每半拍闪一个词，全屏大字。
- 黑白反色交替，或者只用一个强调色。
- 画面边角放装饰性小字：日期、坐标、编号、「REC」、版本号、条形码、刻度尺。它们不需要被读懂，只是营造信息密度和设计感。
- 条纹、网点、十字准星、边框等图形元素。
- 字体混排：粗黑体配细衬线、中文配西文、横排配竖排。
- 重要的词用巨大字号，配震屏和闪白。
- 节奏：先快速闪切一段，再突然停在一句话上，停留足够长，然后再爆发。

## 5. 字符动画（ASCII）

用字符拼出画面，适合 AI、终端、黑客、复古电脑、极简科技的题材。模板的 `Ascii` 组件已经实现了基础版。

**原理**：把画面划成网格，每一格算出一个亮度（0 到 1），按亮度从一串字符里取一个字符。

```ts
const ramp = ' .:-=+*#%@';     // 从暗到亮
const ch = ramp[Math.round(b * (ramp.length - 1))];
```

更细腻的字符串：`` ` .'`^",:;Il!i><~+_-?][}{1)(|\/tfjrxnuvczXYUJCLQ0OZmwqpdbkhao*#MW&8%B@$` ``

中文也能做字符画：按笔画多少排列汉字，比如 `　、一二三口日田国圆`，越复杂越「亮」。

**亮度从哪来：**
- **数学场**：距离场画圆、方、光晕（太阳就是「离中心越近越亮」加上辐射状的光芒），噪声场画云、火、水。纯代码，最稳定。
- **3D 投影**：把 3D 物体的点投影到网格上，按法线算亮度（经典的旋转甜甜圈 donut.c 就是这么做的）。
- **图片或视频**：把图像画到离屏 canvas，用 `getImageData` 采样每一格的平均亮度。图片必须等加载完成（用 `delayRender`）。

**关键细节：**
- 必须用**等宽字体**。字符宽高比大约 0.55 到 0.6，所以一格的高度约是宽度的 1.7 到 1.8 倍，计算时要考虑这个比例，否则画面会被拉扁。
- 横屏 1920 宽时，120 到 200 列效果最好；列数太少像马赛克，太多就看不出是字符了。
- 行数多时，每行拼成一个字符串，用 `<pre>` 渲染，速度很快。需要每个字不同颜色时，用 `<canvas>` 的 `fillText` 逐字画，不要生成几千个 `<span>`。
- 效果：数字雨（每一列有自己的下落速度和字符序列）、字符溶解、边缘用 `/ \ | -` 按方向画出线稿、从字符画慢慢过渡到真实画面（或者反过来）。

## 6. 文字的可读性检查

- 每段文字的停留时间够读完（`rhythm.md` 的公式）。
- 文字和背景的对比度足够：正文至少 4.5:1，大标题至少 3:1。浅色背景上的白字、图片上的字，要加暗色蒙版或阴影。
- 文字不能出现在竖屏的遮挡区里。
- 需要读的文字，停下来之后必须完全清晰：不能还在模糊、还在抖、还在运动模糊。
- 用 `npx remotion still` 渲染停留阶段的帧，确认没有溢出、换行错误、字体回退（中文变成方块或宋体）。
