# 可拍性、过稿与合规（课程 08）

> 来源：骏乐编剧机构·吴文尧《如何让你的剧本「更好过稿」并顺利落地？》（红果《短剧编剧第一课》08 期）。
> 用途：合规自检模式（`/合规审核` `/落地自检`）的权威文件；分集规划与单集撰写时的制作约束。与 `screenplay-compliance-rules.md`（平台红线 + 敏感词替换库）配套——那份管**词级替换**，本文件管**结构级可执行性**。

---

## 一、 三方都变了

| 变化 | 含义 | 对编剧的要求 |
|---|---|---|
| **用户变了** | 观众不再局限于早期三四线群体，覆盖更广年龄层与兴趣圈层，期待更多元 | 单一类型或固定套路越来越难满足所有人；制作方更关注**能否精准打动某一类目标受众** |
| **制作方变了** | 行业走出早期快速扩张、广撒网阶段。团队已摸索出相对清晰的内容方向，知道自己擅长什么、资源适配什么 | 不再「什么都试试看」，而是结合团队特点、平台策略、受众偏好，挑**匹配度高的剧本** |
| **平台变了** | 以红果短剧创作服务平台为代表的头部平台调整筛选机制：过去主要靠内部编审主观判断，正逐步过渡为**由市场制作方参与评估** | **「剧本能否落地」已成为重要的入选标准** |

---

## 二、 三类合规雷区（动笔前厘清创作边界）

> 「再好的创意，一旦踩了红线，就直接出局，侥幸上线也难以大爆。」
> 平台对剧本的合规要求已不仅限于「不低俗」，更关注**价值观导向、法律常识和公共影响**。

### 雷区 1：价值观与伦理

- 宣扬「替身文学」「强制爱无后果」等畸形婚恋观
- 主角通过违法手段达成目的却未受惩罚
- 对历史人物、民族形象进行戏谑化处理

### 雷区 2：政策与法律

- 涉及时政、宗教、民族等敏感议题
- 刑侦剧中出现「私自刑讯」「无证据定罪」等明显法律硬伤
- 对真实公共事件进行虚构演绎

### 雷区 3：表现尺度

- 过度血腥暴力
- 带有性暗示的镜头描写
- 包含对未成年人不良引导的情节（大尺度血腥恐怖、美化校园霸凌等）

> 词级替换与一票否决清单见 `screenplay-compliance-rules.md`；机检项 E10 覆盖一票否决类直观描写。

## 三、 内容评估四标准（通过合规初筛后，制作方怎么看）

> 核心问题：**这个故事能不能打动目标用户？能不能撑起 80～100 集的节奏？**

1. **前三集立住主线**：背景、主角身份、核心冲突、观众期待，要在极短时间内交代清楚。导演、演员、平台编辑可能**只看前几集**就决定是否继续。
2. **主线清晰、不跑偏**：整个故事围绕一个明确目标推进（复仇、逆袭、追爱），避免中途插入过多支线导致看点分散。
3. **人设有记忆点**：不需要完美，但要有鲜明标签——一句口头禅、一个标志性动作、一种特殊身份（「疯批美人」「忠犬保镖」），能让观众快速记住。
4. **节奏干净、信息密集**：每分钟都要有「看点」——情绪爆发、剧情反转或关键信息推进。避免大段抒情、无效对话或拖沓铺垫。

> **好剧本的一句话标准：一个卖点撑起一个故事，让观众一口气追完，并牢牢记住一个角色。**

> 参考案例（《不装了，霍总每天都想复婚》）：选题时就知道同类作品已很多，很容易被觉得没新意；剧本按成熟经验打磨。上线初期因同类扎堆成绩不起眼，但播出一段时间后，观众在同类剧中更愿意看这部，最终整体数据表现不错。

## 四、 可执行性：剧本落地三条

> 「我们经常遇到本子故事很好，但一看制作需求，就知道很难拍，这无形中就降低了剧本被选中的机会。」

### 1. 写剧本时，心中要有本「经济账」

**标准竖屏短剧的制作现实**：

- 拍摄周期通常只有 **7–10 天**
- 预算多在 **十几万到几十万元** 区间
- 团队规模有限，**日拍量很高**

**推论**：

- 每增加一个新场景，就可能增加一天拍摄时间。
- 每一场夜戏或外景，都意味着更高的协调成本与天气风险。

**应对建议**：构思阶段就考虑「能不能集中拍」——把多个室内戏合并到同一个宅子或办公室里，通过布景微调区分功能，既省成本又不影响剧情推进。

### 2. 谨慎使用高难度、特殊元素

动作戏、特效、群演本身不是问题，但**大量出现会显著拉高制作难度与不确定性**。

- 一场需要 100 个群演的街头冲突戏，听起来很燃，实际要考虑场地审批、人员调度、安全管控、天气影响。**如果不是推动主线的关键节点，建议删减或简化。**
- 水下、高空、飙车、爆破等高危镜头，**除非是故事的核心卖点**，否则很容易因安全或成本原因被调整甚至放弃。

> 反面案例：某以「水下考古」为背景的悬疑短剧，结构精巧、悬念迭起，但多达 1/3 的关键情节发生在深海或沉船内部，需要大量水下摄影棚和特技演员。多位编审都认可其创意，但最终因制作成本与风险完全不可控而放弃。
>
> 这就是只考虑了故事的「上限」（能有多酷），而忽略了制作的「底线」（最少需要多少钱和时间）。

### 3. 角色设计是评估可拍性的关键要素

> 「一个出色的角色设定往往比复杂的情节更能抓住观众。」「人物设计在于精，而不在于多。」

**核心原则：每个角色都必须「有用且有亮点」。**

新人三个常见陷阱：

- ❌ 人物重要但戏份稀少（角色浪费）
- ❌ 角色众多但功能重复（叙事冗余）
- ❌ 配角设定精彩却无后续（线索断裂）

**80 集主流短剧的量化配额（骏乐影视口径）**：

| 维度 | 建议 |
|---|---|
| 角色总量 | **核心人物 3–5 人，其余角色不超过 20 人** |
| 新角色引入 | 高潮集可引入不超过 2 个新角色；**日常集尽量不引入新角色** |
| 角色功能 | 每个配角至少承担「推动情节」「衬托主角」「提供关键信息」三项之一 |

**叙事连贯性**（降低观众理解成本）：

> 「短剧观众没有'回看'习惯，看不懂往往意味着直接弃剧。」

- 一个场景同时出现太多新角色，或频繁切换视角，观众难以建立清晰的人物图谱。
- 保持叙事连贯，避免观众在后续角色再出场时产生困惑。

**创作自查**：写完后，试着为剧本中**每个有名字的角色写一句话描述——「这个角色为什么必须存在？」** 如果答案模糊，重新审视其必要性。

**观众视角检验**：写完每集后，想象自己是第一次看的观众——能分清谁是谁吗？能理解他们为什么这样做吗？

> **限制催生创意**：有时正是「不能随便加角色」的限制，倒逼编剧写出更精妙的人物关系。弹性不是妥协，而是为导演、演员、制片人留出共创空间。

## 五、 交稿前的三步自查

成熟编剧通常遵循 **先看「内容」→ 再看「落地性」→ 最后看「完整度」** 的路径：

1. **检视故事内核**：抛开所有细节，用一句话说清故事核心，判断其是否足够独特、有吸引力且符合市场需求。**放下作者视角**，以读者角度检验自己能否迅速被吸引、理解卖点。
2. **落地性优化**（最关键）：拿着「放大镜」逐一检查场景、预算、审核等风险点，确保剧本符合短剧市场的制作标准。
3. **完整度检查**：快速通读全剧，检查主线是否清晰、节奏张弛有度、人物设定统一，确保「顺下来」没有逻辑硬伤；同时**避免大量抽象、内心化的对白，确保每句台词都能转化为演员的行动或表情**。

## 六、 三个写作病

### 病 1：缺乏「镜头化」思维，表达抽象难以拍摄

> **少写「心理」，多写「行为」。**

反例：写人物悲伤写成「他心碎了一地，仿佛整个世界都崩塌了，陷入无尽的绝望。」——导演和演员看了会很抓狂，因为不知道怎么拍、怎么演。

**改写对照（原文给的完整示例）**

| | 优化前（文学化、难拍摄） | 优化后（镜头化、可执行） |
|---|---|---|
| 环境 | 「林薇独坐于咖啡厅的幽僻角落，面前那杯咖啡早已凉透，丝丝冷意似她此刻的心绪。她静静地凝望着窗外，夜色如墨，而她的眼神，宛如被浓雾遮蔽的星辰，空洞而迷茫。」 | 「（林薇坐在角落，面前放着一杯凉了的咖啡。她望着窗外，眼神空洞）」 |
| 台词 | 「'所有'二字，何其轻巧，又怎能承载起这三年岁月的重量？……」 | 「（苦笑）'所有'这两个字真轻啊，轻到承载不起这三年的重量。」 |
| 情绪 | 依赖长 OS 描述内心 | 用可表演的外在行为传递——苦笑、流泪、沉默 |

**改写后**：台词更简洁自然，情绪通过可表演的外在行为传递，并在结尾巧妙抛出悬念（「医院？什么检验单？」），激发追看欲望。

原版存在的五个问题：缺乏镜头语言、内心独白冗长、信息密度过低、节奏拖沓、缺乏剧情张力。

### 病 2：陷入「上帝视角」，忽视观众的理解门槛

> 「剧本是'拍摄的蓝图'，不是'文学作品'。」

编剧熟知每个人物的前史、每个事件的因果，但**观众接收到的只有屏幕上按顺序播放的剧情**。这种视角错位常导致关键信息缺失、逻辑跳跃或情感转变生硬。

> 反例：编剧写「女主突然对男主冷淡」。问他为什么？他说「我在人物小传里交代过，她发现男主和前任还有联系」。但**剧本正文里既没交代「前任存在」，也没展现「发现过程」**。最终呈现的效果只能是人物行为突兀、情节逻辑断裂。

**铁律**：「编剧需要**从正文第一行开始**，就站在观众的认知起点去推进故事。关键信息应通过情节、对白或行为传递，而不能依赖任何剧本之外的『脑补』。」

（本 skill 红线 10；机检项 E13）

### 病 3：忽视「落地性」考量，脱离制作现实

> 「只要故事足够精彩，制作方总会想办法拍出来」——在当前短剧市场基本上是**一厢情愿**。

市场已告别为「天才创意」盲目烧钱的狂热期。制片方评估剧本时，首要考虑的往往不是「这个故事有多好」，而是「**这个故事我们能不能又好又快地拍出来**」。

> **「能被拍出来的故事，才有资格成为爆款故事。」**

编剧必须明白，短剧是「**戴着镣铐跳舞**」的艺术。真正的专业能力，体现在如何在有限的预算、周期和审查框架内最大化实现故事的魅力。

**动笔前应主动了解的行业常识**：一个常规剧组的单日拍摄量、常见场景的租赁成本、特效镜头的价格区间。「这不是让你变成制片人，而是让你成为一个懂得合作、理解现实的创作者。」

**每写一集都问**：导演怎么拍？演员怎么演？观众怎么看懂？

## 七、 落地性自查清单

**制作**

- [ ] 场景可集中拍摄（室内为主，布景微调区分功能）。
- [ ] 新场景数量可控，没有「每集一个新地方」。
- [ ] 夜戏、外景不是非必要的叙事手段。
- [ ] 无大群演场面（除非是主线关键节点）。
- [ ] 无水下、高空、飙车、爆破等高危镜头（除非是核心卖点）。
- [ ] 特效需求低、道具常见。

**角色**

- [ ] 核心人物 3～5 人，其余角色不超过 20 人。
- [ ] 日常集没有引入新角色；高潮集新角色不超过 2 个。
- [ ] 每个有名字的角色都能回答「为什么必须存在」。
- [ ] 每个配角至少承担「推动情节 / 衬托主角 / 提供关键信息」之一。
- [ ] 没有「重要但戏份少」「功能重复」「有设定无后续」的角色。

**内容**

- [ ] 前三集立住主线（背景 + 身份 + 核心冲突 + 期待）。
- [ ] 主线目标明确，支线没有喧宾夺主。
- [ ] 主角有可记忆的标签（口头禅 / 标志动作 / 特殊身份）。
- [ ] 每分钟都有看点，无大段抒情与无效对话。
- [ ] 每句台词都能转化为演员的行动或表情。

**合规**

- [ ] 无价值观与伦理风险（畸形婚恋观、违法手段得逞、戏谑化历史人物）。
- [ ] 无政策与法律硬伤（时政宗教民族敏感、刑讯、无证据定罪、真实公共事件虚构演绎）。
- [ ] 无表现尺度问题（过度血腥暴力、性暗示、未成年人不良引导）。
- [ ] 打脸对象是主要反派，不是随意龙套或弱群体。

**观众视角**

- [ ] 关键信息全部在正文里交代，不依赖小传或设定脑补。
- [ ] 第一次看的人能分清谁是谁、能理解他们为什么这么做。
