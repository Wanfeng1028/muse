# 场景提示词规范

本规范产出的是一张干净的广角建立镜头场景图：画中不含任何人，只有场景本体，把前景、中景、后景、出入口、地面、墙面以及关键陈设之间的固定相对位置一次性交代完整，让空间逻辑前后贯通、能够反复调用。

这张图是该场景下全部镜头的背景参照基准。观众与生成模型都要依靠它建立起对整个空间的认知：人从哪里走进走出、地面与墙面呈现什么质感、核心物件各自钉在哪个方位。因此取景角度必须稳、必须通用。

## 输出结构（按下列顺序拼成一段连贯描述，语言跟随会话语言指令）

```
固定机位广角镜头，清晰的建立镜头，[地点 + 年代质感]，[时间段]，
前景（[前景元素]）、中景（[中景主体空间]）、后景（[后景纵深]）三层分层构图，
出入口（[门/通道的位置与样式]），地面（[地面材质与状态]），墙面（[墙面材质与颜色]），
[主要陈设及其固定相对位置]，
空间结构连续、自洽，
[光源 + 色温 + 明暗对比]，[氛围]，
画面中没有任何人物，空场景，电影质感
```

## 空间结构规则

空间必须做到三件事：看得明白、彼此对得上、可反复使用。

- **前景**：负责框景与遮挡的元素（门框、桌角、绿植、设备边沿等），用来拉开纵深，落到 1-2 个具体物件上
- **中景**：承载场景主体与核心陈设（流水线、床铺、柜台之类）
- **后景**：空间的延续方向（远端的墙体、窗户、走廊或城市轮廓）
- **出入口**：门、楼梯、通道的方位与样式必须写死（例如"画面左侧一扇铁门"），后续镜头调度人物进出全靠它
- **地面与墙面**：把材质、颜色、状态写具体（例如"水泥地面有油渍""墙面石灰斑驳"）
- **主要陈设**：列出 2-4 件核心陈设，并交代彼此的固定相对位置（例如"流水线沿墙排开，尽头是吧台"）；左右与远近关系要经得起推敲，不能只把物品名堆在一起

## 人物（硬性规则 · 最高优先级）

**场景图中不能出现任何的人，只保留场景本身。**

- 提示词里不描写人物，也不涉及任何与人物有关的信息
- 场景描述（prompt）里若混入人物内容，一律忽略，不得写入提示词
- 提示词结尾必须包含："画面中没有任何人物，空场景"

`prompt`（场景描述）中提到的陈设、年代质感与关键视觉元素都要逐项落实；`lighting`（场景光影）必须写具体：光从哪个方向来、色温偏冷还是偏暖、明暗对比到什么程度（例如"头顶灯管发出冷白光，机器下方投下硬阴影"）。

## 视角与氛围

- 采用稳定的平视或轻微俯视广角，避免极端俯仰、鱼眼与倾斜构图（这张图要作为固定场景被反复复用）
- 依据 `location` + `time` 敲定时间段与光线基调（白天、夜晚、黄昏的光线表现完全不同）
- 氛围词要落到可画的细节上："压抑"应写成"空气闷热、光线昏暗低沉"，不能只丢一个抽象情绪词
- 输出使用会话语言指令指定的目标语言，不得夹杂无关词汇

## 禁止事项

- 任何人物——**场景图中不能出现任何的人，只保留场景本身**
- 文字、招牌上的可读文字、水印、签名
- 动态模糊、处于运动状态的物体（场景参考图必须静止稳定）
- 只罗列陈设清单却不交代相对位置（空间结构必须连续、自洽）

## 保存

调用 `save_scene_final_prompt`：prompt 参数不携带风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。
