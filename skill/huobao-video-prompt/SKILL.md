# 视频提示词规范

把一个分镜段落（含 description 中的【镜头N】子镜头结构、台词或旁白、atmosphere、duration）转换成可直接驱动 AI 视频生成的 `video_prompt` 字段。

基本单位约定：**一个分镜段落对应一条 8-15 秒的视频，段落内部允许切镜**。相邻段落之间可以换景别、换角度、换拍摄对象，用硬切完成衔接；但**任何一条 video_prompt 都不允许跨场景，也不允许闪回**。

## 输出格式

`video_prompt` **首行固定为信息头**，用一句话交代这条视频里会出现哪些人物、发生在哪个场景，随后另起一行进入时间分段。人物与场景都必须写成 @ 引用形式——渲染阶段会把 `@名字` 替换成对应的参考图片标记，让视频模型先锁定"是谁"和"在哪"。

示例形态：

```
出场人物：@小明、@小红；场景：@咖啡厅。
0-3秒：@咖啡厅，近景固定镜头，@小明低头看手机，手指反复敲桌面，表情焦虑。
3-6秒：切到门口全景，门铃响，@小红推门走入，带进一阵冷风。
6-9秒：切回中景，@小红微笑着走向小明坐下，小明说：「你终于来了。」
```

信息头的书写要求：

- 只罗列本分镜段落中真实出现的人物，以及该段落绑定的场景，未出场的不要写进去
- 若段落中有显眼道具参与画面，可在信息头末尾追加，形如 `；道具：@信件`
- 信息头独占一行，以句号收尾，其后才开始写时间分段

时间分段以 3 秒为一个单位，每段单独占一行、行间用换行分隔；各段的时间范围要首尾相接，既不重叠也不留空档。

## 从分镜描述到提示词的映射

`description` 是 video_prompt 唯一的内容来源——画面、动作、台词、旁白全部取自其中。转换时遵循以下规则：

- `description` 里每一个 `【镜头N】` 对应 **1 到 2 个连续的 3 秒段**；顺序必须与原文一致，不得漏掉、不得合并、不得凭空增加子镜头
- 台词与旁白从所属 `【镜头N】` 中的「角色名说：「…」」或「旁白：…」里提取，落到该子镜头所映射的时间段上；**禁止编写 description 之外的台词**
- 画面动作一律以 `description` 为准；`atmosphere` 仅用于给各段补充光线、色调和氛围层面的描写

## 单段内部结构

每一段的内容按下列顺序组织（没有内容的项可以省略，但动作/画面描写不可缺）：

**时间范围 ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作·表情 ＋ 对白/旁白 ＋ 氛围光线**

- **首段必须建立空间**：交代场景、机位，以及角色的位置和状态，让观众一眼看懂这是在哪、镜头对着谁
- **切镜处理**：切镜之后的那一段，开头用"切到/切回"之类的衔接词，并重新说明景别与主体；切镜的位置要与分镜 `description` 里的 `【镜头N】` 结构对齐
- **景别与运镜**：每段只给一个镜头状态（近景/中景/全景/特写；固定/推/拉/摇/跟）；同一个子镜头内部运镜保持连贯，切镜之后才允许更换运镜方式
- **动作**：每段聚焦一个主动作，动词要具体、肉眼可见（走、转身、抬头、攥紧、停顿）
- **情绪一律转成可见描写**：不要写"他很伤心""气氛紧张"这类抽象判断，改写成"他低下头、手指攥紧杯沿、呼吸变重"
- **对白与旁白**：对白写作「角色名说：「台词」」，旁白写作「旁白：内容」；三秒内念不完的长台词拆到多个时间段；没有对白的段落可以写环境音或动作音（如"机器持续轰鸣"）

## 引用规则

- `@场景名` — 场景引用，名称必须与场景列表中的地点完全一致
- `@角色名` — 角色引用，名称必须与角色列表中的名字完全一致
- `@道具名` — 道具引用，名称必须与道具列表中的名字完全一致；只有当道具在画面中明显可见、被角色使用或获得特写时才引用
- 生成阶段会自动把 `@名字` 替换为对应的参考图片标记（例如 `@小明` → `@图片1小明`），因此名字必须精确匹配，不可缩写、不可添加多余符号
- **每一段至少要有一个 @ 引用用来锚定画面**；有角色出场的段落必须 @ 该角色；只能引用本分镜段落已经绑定的场景、角色和道具

## 时间轴规则

- 段数由分镜段落的 duration 决定：duration ÷ 3 秒后向上取整；所有时间段相加必须等于该段落的总时长
- 内容节奏安排：第一段负责建立，中段推进动作或冲突，末段落到结果或情绪落点

## 禁止事项

- 在一条 video_prompt 内跨场景切换或出现闪回（一个段落只发生在一个场景中）
- 引用场景/角色列表之外的名字
- 抽象心理描写与文学化比喻（视频模型只识别可见画面）
- 语言与会话语言指令不一致

## 保存方式

调用 `update_storyboard`，只更新该分镜段落的 `video_prompt` 字段；其他字段保持原样，也不要重新拆分整集。
