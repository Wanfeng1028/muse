## 0. 一句话总纲

> **画面里不写情绪名词，只写「先…随后…接着…最后」的动作链；
> 台词不堆在声音块，按镜头嵌进时间轴。**

第一版《雨夜面馆》面瘫的根因就是违反了这两条：
写了「神情疲惫」（情绪名词）+ 单一定格动作 + 无时间轴 + **台词完全没进提示词**
→ 模型自己瞎编台词（生成了「爷爷，可以收留我们吗」）。

## 2. 治面瘫：失败模式 → 修正对照

| 失败 | 修正 |
|---|---|
| **Frozen mask 僵脸** | 加**眨眼预备、呼吸、细微下颌松开、部分恢复**（四味解药） |
| Generic emotion label 通用情绪标签 | 补视线、眼睑、眉、唇、下颌**与时机** |
| Rubber mouth 橡皮嘴 | 限制张口幅度、先定义嘴唇压缩、缩短顶点 |
| Doll eyes 娃娃眼 | 定义**视线目标**、下眼睑张力、眨眼时机、眼神光行为 |
| Symmetric synthetic smile 对称假笑 | **一侧嘴角先动**，对侧脸颊延迟 |
| Overacting 演过了 | 某一个通道降一级强度，并**延迟身体反应** |
| Emotion changes too abruptly | 加**中性基线 → 起始提示 → 余韵** |
| Identity drift 身份漂移 | 全程锁五官比例、年龄、皮肤质感、发际线、妆容 |
| 一眼假 | 主动写**可控的不完美**：可见毛孔 + 细小绒毛 + 自然油光 + 肤色不均 |
| 发丝出卖（像头盔） | 额前碎发、边缘飞发、发丝粗细不一、发尾自然分叉、逆光透发、风吹凌乱 |

**余韵（residue）绝对不能省**——不要结束在情绪顶点。

## 3. 微表情词表（原文用词，按部位）

### 眼周 / 眼睑 / 视线
`下眼睑收紧`、`上眼睑抬起，露出更多虹膜`、`脸颊上提，外眼角出现柔和细纹`、`眨眼变慢`、`眨眼预备`、
`视线短暂失焦`、`视线落在画面左侧的空凳堆上`、`视线低垂到手里的抹布`、`抬眼看向画外（近镜头）`、
`眼球有轻微红血丝`、`眼神光（catchlight）稳定`

### 眉部
`眉间收拢并下压`、`眉内侧微微上扬，形成浅浅的竖向张力`、`眉外侧拱起`、`眉间松了一瞬又收拢`

### 嘴部 / 唇部
`嘴唇压紧半秒后随下颌松开而分开`、`上唇抬起，法令纹加深`、`嘴角向一侧提起（不对称）`、
`嘴角向下垂`、`下唇上推`、`下巴出现轻微凹陷`、`嘴唇缩窄成一线的紧绷`、`唇缝微张，下颌未大幅下落`

### 鼻部 / 脸颊
`鼻梁皱起，上唇微微抬起`、`脸颊上提，外眼角出现柔和细纹`

### 下颌 / 呼吸 / 喉部
`细微下颌松开`、`一次长呼气`、`呼吸变浅`、`呼吸短暂停顿`、`吞咽一次`、`下巴绷紧`

### 手部 / 身体 / 肩
`手指攥紧抹布`、`右手虎口旧疤随握力绷起`、`肩膀微塌`、`扶着腰缓半拍`、`借转身惯性顺势抬手`

### 整体神态（慎用，容易变情绪标签）
`部分恢复`、`眼神短暂失焦`、`延迟反应`、`保留变化后的余韵`

## 4. 情绪递进写法

**通道顺序（直接当写作顺序）**：
```
视线/眼睑 → 眉 → 嘴/下颌 → 呼吸 → 头 → 肩 → 手 → 声音
```

**两套可套用句式**：

```
① 视线先[A]；随后眉[B]、下眼睑[C]；嘴唇压紧半秒后随下颌松开而分开[D]。
② 先[状态/动作] → 随后[变化] → 接着[泄露] → 最后[余韵]，不要停在顶点。
```

**情绪阶段（按需取用，别全塞）**：
`Baseline 日常 → Trigger 认出触发 → Resistance 维持原表情 → Leakage 呼吸/眼神泄露 →
Escalation 面部与身体升级 → Apex 顶点 → Residue 余韵`

**短对白镜头用六段**：`Baseline → Recognition → Resistance → Leakage → Apex → Residue`

**三轴（内部思考用，不写进提示词）**：
最难也最好看的表演 = `内在压力 5/5 + 外在幅度 1/5 + 自控 5/5`。

## 5. 镜头语言词表

**景别分层引导**：远景交代环境 → 中景交代动作 → 近景传递情绪 → 特写放大细节

**运镜 → 情绪**：
`推 = 放大情绪`｜`拉 = 孤独感/揭示信息`｜`跟 = 代入`｜`环绕 = 主角感`｜
`上摇 = 气势`｜`希区柯克变焦 = 心理冲击`｜`固定机位 = 克制/麻木`

**机位**：过肩 POV + 前景虚化 = **活人感**（摆脱机械展示感）

**焦段/景深**：`焦点保持在近侧眼睛`、`景深浅但双眼均可读`、`不做对焦搜索`

**光线必须写全**：key light 方向 + **软硬** + **色温** + **光比** + 阴影行为
> 例：`暖黄吊灯为唯一实用光源（约 3000K），光比大，颧骨与鼻梁有柔和过渡，眼窝留浅影，蒸汽让灯光出现体积感`

**环境**：写 **6~10 个相互支持的元素 + 1 个移动的环境细节**
> 例：`灶台余火未灭的暗红反光`、`墙上泛黄的价目表（不出现可辨识文字）`、
> `门外卷帘半落的街灯冷光斜切进来`、`蒸汽缓慢上升并在他面前飘散`

## 6. 真实感细节（去塑料感）

**皮肤**：`可见毛孔与粗糙纹理`、`额头与鼻翼有自然油光反射`、`肤色不均`、
`胡茬长短不一`、`鬓角有几根不服帖的白发`、`眼下浮肿`、`眼球有轻微红血丝`

**毛发**：`额前碎发`、`边缘飞发`、`发丝粗细不一`、`发尾自然分叉`、`逆光透发`、`局部虚焦`

**通用增强**：`手机原相机/未修图无滤镜`、`画面稳定不闪烁`、`光影细腻`

> ❌ 不要写：`完美无瑕`、`零毛孔`、`玻璃肌`、`皮肤光滑均匀` —— 这些=假人。

## 7. 对白 · 口型 · 音色（★ 第一版翻车的地方）

### 7.1 台词必须进提示词

**铁律 4**：对白要按时间点嵌进对应镜头；**【声音】块只描述声线/配乐/音效，绝不集中堆台词**。

```
镜头3
小满（怯生生，轻声，音量很小）：{我没有钱。}
她嘴唇微动，说话时眼神向一侧闪避，说完下唇轻轻收了一下。
```

无台词的镜头要**明确写保持沉默**（正向表达，别用"禁止说话"）：
```
【声音】环境音：雨声 + 锅内沸水声。人物保持沉默，嘴唇自然闭合。
```

> ⚠️ **不写台词 = 模型自己编**。第一版就是没写，结果模型让小女孩说了
> 一句剧本里根本没有的「爷爷，可以收留我们吗」。

### 7.2 音色锁定的三层做法

1. **角色声音档案**：每个角色固定一个 `voice_id`，全片不换（本次：老陈 `Gentle_Senior`、小满 `Soft_Girl`）
2. **用我们自己的配音**：MiniMax 生成 → 上传七牛 → 建音频节点 → **连到视频节点**
3. **提示词里写音色描述**作备份：`音色：58岁男性，中低音，语速慢，带一点沙哑`

**目的**：让模型**跟着我们的音频走**，而不是自己造声音和台词。

### 7.3 特殊符号规范（帮模型区分信息类型）

| 内容 | 符号 | 例 |
|---|---|---|
| 音乐 | `（）` | `（低沉钢琴单音）` |
| 音效 | `<>` | `<塑料凳叠放的闷响>` |
| **台词** | `{}` | `{我没有钱。}` |
| 字幕 | `【】` | 本次不用字幕 |

### 7.4 时长与对白量

`段时长 ≈ 对白句数 × 1.3s + 画面节拍数 × 0.8~1.5s`
15 秒视频对白控制在 **3~4 句**；密集场景拆段。
**LingCut 免费模型只支持 5/8/10/12 秒，对白建议 1~2 句。**

## 8. 标准提示词模板（LingCut 可直接投喂）

```
画面无任何字幕。

<地点><时间><风格>，<时长>，<画幅>，<整体基调>

镜头1（本镜第一优先级：<一句话说清这一拍最想让观众看到什么>）
<景别>，<机位>，<1 种运镜>。<场景交代>。<角色外貌关键词逐字重复>。
<具体动作过程：写到手/腿/头/肩背，标出幅度与速度>。
<光线：方向+软硬+色温+光比+阴影行为>。
<皮肤毛发的可控不完美>。
<同步音效：<>>

镜头2
<视线先变化>；随后<眉/下眼睑>；<唇/下颌>；<呼吸>。
<运镜绑定到某个动作节拍>。
<环境移动细节>。

镜头3
<角色>（<语气>，<音量>）：{<台词>}
<说话时的微表情与身体反应>。
<余韵：说完之后的反应，不要停在顶点>

【声音】<声音事件；无配乐/有配乐>。环境音：<>。人物保持沉默 / 台词已嵌入上文。
【参考】@图片1 <角色大头照，锁声音与妆造>，@图片2 <场景>
【约束】不要改变人物年龄与五官比例，不要出现多余人物，不要卡通化，不要生成文字或水印
【一致性】全片锁定面部比例、发际线、<特征记号>、<服装>

画面稳定不闪烁、光影细腻、电影质感
```

**注意**：
- **不要用人物三视图做视频参考**（官方实测：模型会把不同角度当成多个主体，反而加剧漂移）→ **大头照 + 全身照**
- 素材别用满上限，推荐 4~5 个（角色图 1~2 + 场景图 1 + 音视频 1~2）
- 精确秒数官方已不推荐用于通用场景，**改用「镜头N」**；只有口型同步/TTS 对齐才留 `0-X秒`

## 9. 生成前后自查清单

**生成前**
- [ ] 首句「画面无任何字幕。」有了吗？
- [ ] 这一镜的**唯一第一优先级**定了吗？
- [ ] 情绪是动作链，不是名词？（搜一遍有没有"很X""神情Y"）
- [ ] 通道错开了吗？（视线 → 眉 → 嘴/颌 → 呼吸 → 手）
- [ ] 台词嵌进对应镜头了吗？`{}` 标了吗？
- [ ] 无台词镜头写「保持沉默」了吗？
- [ ] 有呼吸 / 眨眼 / 吞咽 / 余韵吗？
- [ ] 光线写全软硬/色温/光比了吗？
- [ ] 环境有 6~10 个元素 + 1 个移动细节吗？
- [ ] 皮肤毛发写了「可控的不完美」吗？
- [ ] 负面词清理成正向表达了吗？
- [ ] 一致性锚（五官比例/发际线/记号/服装）写了吗？

**生成后**（每 0.5 秒抽帧检查）
- [ ] 人物是不是同一个人？（五官/年龄/服装/发型）
- [ ] 表情是"活"的吗？还是定格？
- [ ] 口型与我们的配音对得上吗？
- [ ] 有没有模型自己编的台词？
- [ ] 有没有多余字幕/水印/文字？
- [ ] 有没有多余人物（双胞胎）？
- [ ] 动作连贯吗？有没有跳变/形变崩坏？
- [ ] 运镜是否在节拍处停下？
