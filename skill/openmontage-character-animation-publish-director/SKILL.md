# 角色动画流水线 · 发布导演

## 目标

为最终角色动画交付物打包，附带诚实的元数据，并给出**以角色为主**的缩略图概念。

## 要求

- 说明实际的视觉处理方式：本地骨架角色动画、程序化特效、Remotion/HyperFrames 渲染，或混合方式。
- 挑选一帧能清晰读出主角情绪的画面作为海报帧。
- 若产物为样片，必须标注为样片。
- 若成片受某参考素材启发，需描述灵感来源，但不得声称是复制品。

## 输出

产出 `publish_log`，包含：

- 最终视频路径
- 缩略图/海报帧说明
- 标题备选
- 描述文案
- 各平台导出注意事项
- 局限说明或后续建议
