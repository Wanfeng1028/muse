# 口播视频增强策略

## 适用场景

当你需要决定如何增强口播素材时使用本技能：选择哪套面部/色彩/音频预设、添加哪些叠加元素、以及如何在增强效果与自然感之间取得平衡。

## 增强工具一览

| 工具 | 功能 | 推荐预设 |
|------|------|----------|
| `face_enhance` | 磨皮、锐化、色调校正 | `talking_head_standard` |
| `color_grade` | 电影感调色，支持强度控制 | `cinematic_warm` 强度 0.85 |
| `audio_enhance` | 响度标准化、降噪、均衡 | `clean_speech` |
| `code_snippet` | 将代码渲染为带样式的叠加图片 | `monokai` 主题 |
| `diagram_gen` | 生成框图/流程图作为叠加图片 | `dark` 主题 |
| `image_selector` | AI 生成插画（需要 API 密钥） | — |

## 增强处理链

按以下顺序执行，每一步均为可选，失败时自动跳过：

```
原始素材
  → 字幕烧录（video_compose）
  → 面部增强（face_enhance）
  → 调色（color_grade）
  → 音频增强（audio_enhance）
  → 最终编码（video_compose）
```

### 面部增强预设

| 预设 | 适用场景 |
|------|----------|
| `talking_head_standard` | 口播默认选项——磨皮 + 锐化 + 暖色调 |
| `soft_skin` | 摄像头素材毛孔明显时——温和磨皮 |
| `sharpen` | 画面偏软/模糊——增强边缘清晰度 |
| `brighten` | 画面偏暗/曝光不足——提亮暗部与中间调 |
| `denoise` | 噪点较多（低光、高 ISO）——时域降噪 |

### 调色配置

| 配置 | 风格 | 强度 |
|------|------|------|
| `cinematic_warm` | 暖色高光、提亮暗部、轻微增饱和 | 0.85 |
| `cinematic_cool` | 青色暗部、橙色高光 | 0.7 |
| `bright_clean` | 鲜艳、明亮、YouTube 风格 | 0.8 |
| `moody_dark` | 压暗黑场、降饱和——戏剧感 | 0.6 |
| `neutral` | 最小校正——仅做电平标准化 | 1.0 |

### 音频增强预设

| 预设 | 适用场景 | 目标响度 |
|------|----------|----------|
| `clean_speech` | 口播默认——完整处理链 | -16 LUFS |
| `voice_clarity` | 人声浑浊——提升 3kHz/5kHz 临场感 | -16 LUFS |
| `podcast` | 访谈/播客——更重的压缩 | -16 LUFS |
| `noise_reduce` | 嘈杂环境——激进 FFT 降噪 | -16 LUFS |
| `normalize_only` | 干净音源仅需响度匹配 | -16 LUFS |

## 叠加增强类型

| 类型 | 适用场景 | 工具 | 位置 |
|------|----------|------|------|
| **文字叠加** | 关键术语、数据、引用 | video_compose overlay | 上部或下三分之一 |
| **代码片段** | 技术内容、API 示例 | code_snippet → overlay | 画面侧边或全屏 |
| **图示** | 可视化解释概念 | diagram_gen → overlay | 画面侧边或全屏 |
| **下三分之一** | 讲者姓名、主题标签 | video_compose overlay | 画面底部 20% |

## 叠加密度指引

### 短视频（< 60 秒）
- 高密度：每 3-5 秒一个叠加
- 快速视觉切换，粗体文字
- 字幕**必须添加**（多数观众静音观看）

### 中视频（1-10 分钟）
- 中等密度：每 10-20 秒一个叠加
- 让讲者独立承载部分段落，不做视觉竞争

### 长视频（> 10 分钟）
- 低密度：每 30-60 秒一个叠加
- 仅在内容需要时增强（关键点、复杂话题）

## 位置规则

1. **绝不遮挡讲者面部**——眼睛、鼻子、嘴巴必须可见
2. **字幕放在底部 20%**——竖屏 margin_v: 50，横屏 margin_v: 40
3. **位置保持一致**——叠加元素一旦放在左侧就保持左侧
4. **文字叠加停留 2-5 秒**——足够阅读，又不至于显得卡住

## 增强决策流程

对脚本每个段落依次提问：

1. 讲者是否在解释视觉化内容？→ 添加图示（`diagram_gen`）
2. 是否有关键数据或引用？→ 添加文字叠加
3. 是否涉及代码或技术内容？→ 添加代码截图（`code_snippet`）
4. 讲者是否连续出镜超过 30 秒？→ 考虑 B-roll 或叠加
5. 是否是开头或结尾？→ 用粗体文字叠加关键信息

## 质量检查清单

- [ ] 面部增强看起来自然——没有过度磨皮或偏橙
- [ ] 调色可见但微妙——肤色健康
- [ ] 音频已标准化到目标 LUFS——全程音量一致
- [ ] 字幕在手机上可读，位置在面部下方
- [ ] 叠加元素有实际价值（不只是装饰）
- [ ] 增强密度与内容长度和平台匹配
