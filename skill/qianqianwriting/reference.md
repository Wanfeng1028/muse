# AI 编剧参考手册

## 一、救猫咪 15 节拍表（短剧适配版）

原版节拍表基于 110 分钟电影结构，以下为适配 AI 短剧的压缩版。

### 原版 15 拍 → 短剧对照

| # | 原版节拍 | 电影位置 | 短剧适配（1-3min） | 核心作用 |
|---|---------|---------|-------------------|---------|
| 1 | 开场画面 | 第1页 | 前1-2秒 | 用一个画面定基调（与终场画面形成对比） |
| 2 | 主题呈现 | 第5页 | 前5秒内 | 用一句台词或画外音暗示主题 |
| 3 | 铺垫 | 1-10页 | 5-15% | 展示主角"改变前"的状态 |
| 4 | 催化剂 | 第12页 | 10-15% | 打破平衡的事件（收到消息/遇见某人/发现秘密） |
| 5 | 争执 | 12-25页 | 15-20% | 主角犹豫是否接受挑战 |
| 6 | 第二幕衔接点 | 第25页 | 20-25% | 主角做出不可逆的决定，进入新世界 |
| 7 | B故事 | 第30页 | 穿插 | 副线（通常是感情线），短剧中可用闪回/旁白替代 |
| 8 | 娱乐游戏 | 30-55页 | 25-50% | 大前提的"兑现"——观众买票要看的核心场景 |
| 9 | 中点 | 第55页 | 50%处 | 假胜利或假失败，提高赌注 |
| 10 | 坏蛋逼近 | 55-75页 | 50-70% | 反派/困难加码，团队裂痕 |
| 11 | 一无所有 | 第75页 | 70-75% | 主角失去一切（伙伴/希望/工具） |
| 12 | 灵魂黑夜 | 75-85页 | 75-80% | 最低谷，主角独自面对绝望 |
| 13 | 第三幕衔接点 | 第85页 | 80-85% | 灵感/决心涌现，找到解决方案 |
| 14 | 结尾 | 85-110页 | 85-95% | 高潮对决，主角用新方法战胜困难 |
| 15 | 终场画面 | 第110页 | 最后2-3秒 | 与开场画面对比，展示变化 |

### 超短剧精简版（30-60秒，6拍）

将15拍压缩为6个核心节拍：

1. **钩子** = 开场画面 + 主题呈现（0-3秒）
2. **铺垫** = 铺垫 + 救猫咪时刻（3-10秒）
3. **催化剂** = 催化剂 + 争执（10-15秒）
4. **挣扎** = 娱乐游戏 + 坏蛋逼近（15-35秒）
5. **高潮** = 灵魂黑夜 + 结尾（35-50秒）
6. **终场** = 终场画面 + 情绪欠条（50-60秒）

### 连续剧节拍分配

多集短剧每集结尾必须设置"情绪欠条"，三种类型循环使用：

| 集数位置 | 推荐结尾类型 | 示例 |
|---------|------------|------|
| 第1集 | 对真相的欠账 | "原来那封信不是她写的……" |
| 第2集 | 对人物的欠账 | 主角做出牺牲，观众想看他翻盘 |
| 第3集 | 对关系的欠账 | 两人相认/误解加深，关系走向不明 |
| 高潮集 | 三种叠加 | 真相揭露 + 人物危机 + 关系反转 |

## 二、10 大故事类型速查（短剧适配）

基于《救猫咪》分类，标注短剧/漫剧适配度。

### 1. 鬼怪屋型 (Monster in the House)

- **公式**: 封闭空间 + 怪物/威胁 + 有罪之人
- **短剧适配**: ★★★★★（漫剧悬疑恐怖类首选）
- **短剧例**: 密室逃脱、废弃医院探险、诅咒老宅
- **关键**: "怪物"可以是人（杀手）、超自然（鬼魂）或系统（AI失控）

### 2. 金羊毛型 (Golden Fleece)

- **公式**: 主角上路 + 寻找目标 + 途中成长
- **短剧适配**: ★★★★（公路/冒险/奇幻类）
- **短剧例**: 穿越时空寻找解药、末日旅途、异世界冒险
- **关键**: 旅途本身比目标更重要，沿途遭遇推动角色成长

### 3. 如愿以偿型 (Out of the Bottle)

- **公式**: 普通人 + 获得超能力/实现愿望 + 代价
- **短剧适配**: ★★★★★（穿越/重生/金手指类爆款）
- **短剧例**: 重生回到高考前、获得读心术、一觉醒来变成CEO
- **关键**: 愿望实现后必须有代价，否则故事无张力

### 4. 麻烦家伙型 (Dude with a Problem)

- **公式**: 普通人 + 突发极端情况 + 被迫应对
- **短剧适配**: ★★★★★（逆袭/打脸/绝境求生类爆款）
- **短剧例**: 外卖小哥被卷入阴谋、普通女孩被豪门算计后反击
- **关键**: 主角越"普通"，观众代入感越强

### 5. 变迁仪式型 (Rites of Passage)

- **公式**: 人生困境 + 痛苦挣扎 + 接受/蜕变
- **短剧适配**: ★★★★（情感/治愈/成长类）
- **短剧例**: 失恋后重新出发、面对亲人离世、职场新人蜕变
- **关键**: 真实情感共鸣是核心，避免说教

### 6. 伙伴之情型 (Buddy Love)

- **公式**: 两个不完整的人 + 互补/冲突 + 最终成全
- **短剧适配**: ★★★★★（CP向/甜宠/兄弟情类）
- **短剧例**: 冤家变情侣、师徒组合、闺蜜共患难
- **关键**: 两人必须有明确的互补性和初始冲突

### 7. 推理侦探型 (Whydunit)

- **公式**: 谜团 + 调查 + 真相比表象更黑暗
- **短剧适配**: ★★★★（漫剧推理/悬疑类）
- **短剧例**: 谁是卧底、消失的邻居、匿名信的真相
- **关键**: 真相必须挑战观众的道德判断

### 8. 愚者成功型 (The Fool Triumphant)

- **公式**: 被低估的主角 + 强大的体制/对手 + 以弱胜强
- **短剧适配**: ★★★★★（爽文/逆袭类）
- **短剧例**: 被开除的员工创业打脸前公司、"废物"觉醒碾压全场
- **关键**: 主角的"愚"是伪装或被误解，观众享受"打脸"的爽感

### 9. 被制度化型 (Institutionalized)

- **公式**: 群体/组织 + 个体选择（加入/反抗/改变）
- **短剧适配**: ★★★（职场/校园/家族类）
- **短剧例**: 新人挑战职场潜规则、家族企业继承之争
- **关键**: 体制的诱惑和代价必须真实可感

### 10. 超级英雄型 (Superhero)

- **公式**: 特殊能力的主角 + 宿命/责任 + 对等的敌人
- **短剧适配**: ★★★★（漫剧战斗/异能类）
- **短剧例**: 觉醒异能的少年、守护结界的灵师
- **关键**: 能力越强，代价/弱点越大（否则无戏剧性）

## 三、镜头语言速查表

### 景别

| 景别 | 画面范围 | 适用场景 | AI描述示例 |
|------|---------|---------|-----------|
| 大远景 | 环境全貌 | 开场建立世界观 | "俯瞰整座雨中的城市，霓虹灯倒映在湿滑的街道上" |
| 远景 | 人物全身+大量环境 | 建立场景、过渡 | "一个身穿黑色风衣的男人独自站在空旷的火车站月台上" |
| 全景 | 人物全身 | 展示动作、人物关系 | "两人面对面站在巷口，相距三步，互相对视" |
| 中景 | 膝盖以上 | 对话、日常动作 | "女孩坐在书桌前，双手托腮，目光投向窗外" |
| 近景 | 胸部以上 | 对话特写、情绪表达 | "男人微微皱眉，嘴角紧绷，目光闪烁" |
| 特写 | 面部/物体 | 情感高潮、关键道具 | "一滴泪从眼角滑落，划过苍白的脸颊" |
| 大特写 | 局部细节 | 强调关键信息 | "手指颤抖着按下发送键，屏幕上显示'已读'" |

### 镜头类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 单人镜头 | 画面中只有一个人物 | 独白、内心活动、角色介绍 |
| 双人镜头 | 两个人物同框 | 对话、对峙、关系建立 |
| 过肩镜头 | 从一人肩膀后方拍另一人 | 对话场景的经典切换 |
| 同框镜头 | 多人物共同入画 | 群戏、团队场景 |
| 主观镜头 | 模拟角色视角 | 悬疑、恐怖、第一人称叙事 |
| 反应镜头 | 捕捉角色对事件的反应 | 反转后的震惊、听到消息后的表情 |

### 运镜方式

| 运镜 | 效果 | 适用场景 | AI描述关键词 |
|------|------|---------|------------|
| 推进 | 靠近主体，增强紧张感 | 揭露真相、情绪爆发 | "镜头缓缓推向他的脸" |
| 拉远 | 远离主体，揭示环境 | 孤独感、揭示全貌 | "镜头向后拉远，露出空无一人的广场" |
| 平摇 | 水平移动 | 环境介绍、跟随目光 | "镜头从左向右缓缓摇过书架" |
| 俯拍 | 从上方往下拍 | 渺小感、全局视角、压迫感 | "俯视角度，人物蜷缩在角落" |
| 仰拍 | 从下方往上拍 | 威严感、力量感 | "仰视角度，高楼直插云霄" |
| 跟踪 | 跟随人物移动 | 追逐、行走、紧张感 | "镜头跟随她快步穿过走廊" |
| 环绕 | 围绕主体旋转 | 情感高潮、仪式感 | "镜头360度环绕两人拥抱的画面" |
| 静止 | 固定不动 | 对话、凝视、留白 | "固定机位，人物缓缓走入画面" |

### 构图原则

| 原则 | 说明 |
|------|------|
| 三分法 | 主体放在画面1/3处，避免居中（除非刻意对称） |
| 引导线 | 利用道路、栏杆、光线引导观众视线 |
| 框中框 | 用门框、窗框、镜子等制造画中画效果 |
| 留白方向 | 人物面朝的方向留出空间 |
| 对角线 | 动态构图，增加画面张力 |

### 剪辑节奏原则

| 规则 | 说明 |
|------|------|
| 动接动 | 运动中的物体/人物，下一镜保持运动状态 |
| 静接静 | 静止画面接静止画面，保持节奏一致 |
| 大接大、小接小 | 全景接全景/中景，特写接特写/近景 |
| 不越轴 | 保持180度轴线，人物左右关系不变 |
| 三镜头法则 | 同一场景至少3个不同景别的镜头，避免单调 |

## 四、剧本写作金科玉律（短剧版）

源自《救猫咪》核心规则，适配短剧创作。

### 1. 救猫咪
在观众看到主角的前几秒内，让主角做一件让人喜欢他的事。短剧中可以极简：帮老人捡东西、喂流浪猫、对孩子微笑、在被欺负时默默忍受。

### 2. 泳池里的教皇
最有趣的场景不用太复杂——把一个不该出现的人放到一个不该出现的地方。反差即戏剧性。"外卖小哥走进董事会"比"CEO主持会议"有趣一万倍。

### 3. 铺垫与呼应
前面种下的细节，后面必须有回收。开头出现的红围巾，结尾必须再次出现并承载新含义。短剧虽短，也要有首尾呼应。

### 4. 让坏蛋坏到家
反派/障碍越强大，主角战胜后观众越爽。短剧中反派可以是人、制度、命运，但必须让观众"恨得牙痒痒"。

### 5. 不要双重神秘力量
一个剧本只能有一种超自然/特殊设定。如果主角能穿越，就不要再加读心术。规则越简单，观众越容易跟上。

### 6. 曲线公约
角色必须有弧线（变化）。开头的主角和结尾的主角必须不同。哪怕只有60秒，也要让观众感受到"他变了"。

### 7. 主角必须主动
主角必须自己做出关键选择，而不是被事件推着走。"他决定反击"比"别人帮他解决了"更有戏剧力。

- 所有 AIGC 作品必须取得备案编号方可上线
- 已上线内容须在2026年3月底前完成补审
- 片头须标注备案编号

1. 通过短剧版权中心完成实名认证与签约

4. 提交创作链路证明（AI对话截图、工程文件、时间戳）
5. 成片校验（字幕、逻辑、音画同步、合规性）

## 六、敏感词安全替代对照表

在编写分镜画面描述时，以下词汇容易被 AI 生成工具拦截。使用右侧替代写法。

### 暴力相关

| 敏感描述 | 安全替代 |
|---------|---------|
| 刀刺入身体 | 刀光一闪，对方捂住腰侧 |
| 鲜血喷涌 | 红色液体溅在地面 |
| 尸体 | 一动不动的身影 / 倒地的人 |
| 枪指着头 | 黑色金属物体对准前方 |
| 开枪射击 | 一声巨响，烟雾弥漫 |
| 掐住脖子 | 一只手按住对方肩膀，对方挣扎 |
| 殴打 | 激烈的肢体冲突 |
| 爆炸现场 | 浓烟和碎片飞散的场景 |
| 自杀/自残 | 站在边缘/独自望向远方（暗示处理） |

### 色情/裸露相关

| 敏感描述 | 安全替代 |
|---------|---------|
| 裸体 | 披着浴巾 / 被子盖到肩膀 |
| 亲密接触 | 两人额头相靠 / 十指交扣 |
| 性暗示场景 | 烛光摇曳中两个影子逐渐靠近（到此为止） |
| 暴露着装 | 时尚穿搭 / 修身礼服 |

### 政治/宗教相关

| 敏感描述 | 安全替代 |
|---------|---------|
| 具体政治人物 | 完全避免，使用虚构人物 |
| 国旗/国徽特写 | 改用虚构标志或避免出现 |
| 抗议/游行场面 | 人群聚集在广场（去政治化处理） |
| 宗教仪式 | 古老的仪式 / 传统仪式（模糊化处理） |

### 其他高危词

| 敏感描述 | 安全替代 |
|---------|---------|
| 毒品 | 可疑的粉末/不明液体 |
| 赌博 | 桌上的筹码和纸牌（不要出现赌场字样） |
| 香烟/吸烟 | 手指间夹着燃烧的东西（尽量避免） |
| 酒精/酗酒 | 杯中琥珀色液体 |
| 恐怖组织 | 神秘组织 / 地下势力 |

## 七、4 大爆款套路模板（基于 31 部爆款剧本提炼）

### 1. 身份反转型（占爆款 26%）

**公式**: 隐藏身份 → 受辱/被低估 → 身份暴露 → 打脸逆袭

**典型结构**:
- 第 1 集：主角以低姿态出场（赘婿/保姆/助理/乞丐），被众人鄙视
- 第 2-5 集：不断受辱，观众积累愤怒
- 第 6-10 集：第一次小范围暴露身份，打脸一小批人
- 中段：反复在"隐藏"和"暴露"之间拉扯
- 高潮：全面暴露，所有看不起主角的人跪地求饶
- 结局：主角功成名就 + 感情线收束

**代表作**: 《北王刀》《战尊出狱》《镇域明王》《闪婚老公是豪门》《凤凰男的豪门贤妻》

**关键技巧**:
- 反派必须足够嚣张，打脸才够爽
- 每次暴露只暴露一层，像剥洋葱一样层层递进
- 主角"装"的理由必须合理（保护某人/完成任务/试探对方）

### 2. 复仇回归型（占爆款 19%）

**公式**: 过去惨遭迫害 → 蛰伏蜕变 → 伪装身份回归 → 步步为营复仇

**典型结构**:
- 第 1 集：用闪回展示过去的惨剧（灭门/被害/被抛弃）
- 第 2-3 集：主角以新身份/新面貌回归
- 第 4-15 集：潜入仇人身边，一步步布局
- 中段：复仇过程中与某人产生感情纠葛
- 高潮：真相大白，仇人得到报应
- 结局：放下仇恨 + 感情归宿

**代表作**: 《假面玫瑰》《腹黑女佣》《绝色美人谋》《坠入春夜》《云总你的小心肝重生了》

**关键技巧**:
- 闪回的惨剧必须足够惨，观众才会支持复仇
- 复仇过程要"智取"而非"蛮干"，展示主角的智慧
- 感情线是复仇的软肋，制造"爱上仇人之子"的纠结

### 3. 穿越/金手指型（占爆款 10%）

**公式**: 普通人 → 获得超能力/穿越 → 利用优势碾压 → 登顶

**典型结构**:
- 第 1 集：主角是普通人/倒霉蛋，遭遇意外获得金手指
- 第 2-5 集：初次使用能力，小试牛刀
- 中段：能力不断升级，对手也不断升级
- 高潮：面对最强对手，能力达到巅峰
- 结局：称霸 + 感情线

**代表作**: 《回到古代当太子》《神仙微信群》《钓系娇娇小美人在修罗场求生》

**关键技巧**:
- 金手指的规则必须简单明确（一个就够，不要叠加）
- 每次使用能力都要有代价或限制，否则没有悬念
- "知识碾压"比"武力碾压"更有观赏性

### 4. 甜宠纠葛型（占爆款 13%）

**公式**: 误会/契约 → 暧昧升温 → 情敌/阻碍 → 揭秘/坦诚 → 在一起

**典型结构**:
- 第 1 集：男女主因意外/契约绑定在一起
- 第 2-10 集：朝夕相处，暧昧升温，男主暗中守护
- 中段：情敌出现/前任搅局/家族阻碍
- 高潮：误解最深时，真相揭露
- 结局：双向奔赴，甜蜜收场

**代表作**: 《戏精美人且会撩》《招惹》《江南时节》《好一个乖乖女》《过分野》

**关键技巧**:
- 男女主的"推拉"是核心——靠近了又躲开，躲开了又想靠近
- 男主的"冷面热心"比"直球表白"更有吸引力
- 女主不能是纯被动的，必须有自己的目标和主线

## 八、3 种高效开场模式（基于 31 部爆款验证）

### 模式 A：前世/惨剧闪回开场（45% 爆款使用）

先展示一个震撼的悲惨场景（死亡/灭门/背叛），再切回"之前"或"重生后"。利用倒叙制造强烈的悬念和情绪冲击。

**适用**: 复仇类、重生类、身份反转类

### 模式 B：当下冲突直入（39% 爆款使用）

第一秒就进入矛盾现场，毫无铺垫。观众被扔进冲突的正中心，被迫关注。

**适用**: 霸总类、逆袭类、甜宠类

### 模式 C：身份/系统觉醒（16% 爆款使用）

主角在第一集内完成身份转换（穿越/获得系统/重生觉醒），立刻进入新世界。

**适用**: 穿越类、金手指类、穿书类
