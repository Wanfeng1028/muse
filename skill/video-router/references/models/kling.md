# Kling: explicit storyboard and variant selection

Keep Kling 3.0 as a capability-specific or user-requested option, not a default justified by recency: its verified February 5, 2026 family launch falls outside this catalog’s April–October preference window. The separate Turbo variant’s exact release date was not independently established.

## Do not merge these names

Kling VIDEO 3.0, VIDEO 3.0 Omni, Standard, Pro and Turbo are not interchangeable endpoint names. Resolve the actual operation and tier using the provider schema. The generic Kling 3.0 record intentionally leaves endpoint IDs unresolved rather than inventing a universally valid alias. A specific Turbo Standard text-to-video endpoint is recorded separately.

1. Confirm that the user wants Kling or that a verified Kling capability fits the brief. Do not present an older launch as a recent release because a directory page was updated yesterday.
2. Separate a single shot from explicit multishot/storyboard generation. Define each shot’s duration, speaker, action, camera and recurring elements before choosing a schema.
3. Resolve the exact model family, tier and operation. Check duration, resolution, audio options and reference/element support on that endpoint. Do not carry Omni’s inputs into a VIDEO 3.0 endpoint automatically.
4. Use concrete performance and camera descriptions. Keep repeated entities consistently named across shots, and ensure the sum of shot durations satisfies the provider’s constraints.
5. Generate a representative draft; preserve the actual endpoint ID, mode, seed where available and job identifier. Confirm the model/version returned by the provider where exposed.
6. Review motion, speaker assignment, identity, cut boundaries, sound and technical delivery. A supported multishot option is not a guarantee of narrative or character consistency.

## Skills and fallbacks

Scenario, ChatCut and OpenMontage include useful Kling integrations, but each needs its own host runtime. The registry keeps them discoverable without treating them as direct fal clients. A missing endpoint or newly added tier is a **preflight gap**, not permission to guess an API name.

For a user who did not request Kling, recent compatible models receive the router’s recency preference. For an explicit Kling request, keep that constraint and report unsupported or unverified operations honestly.
