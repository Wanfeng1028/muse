# video20-a0-shots

Shared Python/PIL rendering code for the "A0" batch of video 20's shot library — the shots that are plain functions inside one file rather than their own folder, all driven by the same shot table and drawing kit.

## What this is

- `a0shots.py` (624 lines) — one function per shot: `s01` (shot 1), `s_insert` (a factory used for the 3 finished-clip-insert cutaways), `s03`, `s04`, `s05`, `s12` (plus its `s12_parts()` helper), `s17`, `s19`, `s20`. Shot 6 (大头贴开场/photo-booth-intro) is **not** in this file — see `library/photo-booth-intro/README.md`, it is generated by this repo's `components/ip_intro.js` instead.
- `a0common.py` — shared paths, the shot table, and small ffmpeg helpers. Imports `timeline.py` from `storyboard_v2/src` (read-only authority for frame mapping) rather than duplicating it.
- `a0lib.py` — the drawing primitives (verbatim, no personal paths). A0's own shots use it directly; it also contains the paper-subtitle-strip / keyword-pop / step-bar / PiP-frame primitives that are documented as reusable concepts under `../paper-craft-components/`.

## Environment variables

Two personal absolute paths were replaced with env vars (see the repo-level report for exact before/after diffs):

- `XM_VIDEO_PROJECT_ROOT` (`a0common.py`) — root of your own video-production working directory (holds `05_visual/storyboard_v2/...`). Defaults to `.`.
- `XM_STICKER_DIR` (`a0shots.py`) — your own transparent big-head sticker directory. Defaults to `assets/stickers`. Only used by `s20`'s closing wink-card flourish (`STICK / 'card-wink-blue.png'`); that asset itself isn't included (see `library/endcard-icons/README.md`).

## Notes

`a0lib.py` is duplicated verbatim under `../paper-craft-components/src/` for documentation purposes only — that's the canonical home for reading about the reusable primitives (paper subtitle strip, keyword pop, step bar, PiP frame, chapter tag) as concepts independent of which shot batch uses them. This copy is the one actually imported by `a0shots.py`/`a0common.py`.
