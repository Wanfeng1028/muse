# Export scope

The pipeline portion was originally assembled from an allowlist of reusable
skills, helper scripts, library sources, and template sources with fresh public
history. This update merges that public history into the existing public student
kit; it does not import the private production workspace's Git history.

The new short-form skill includes its instructions, generalized reference
worksheet, and validators. Personal reference-video filenames and the private
recording analysis were replaced with a reusable worksheet. Synthetic test data
was authored separately. No private recordings, transcripts, edit decisions,
credentials, or machine-specific settings were added.

The original repository's already-public video examples and shared brand assets
remain unchanged. This combined repository therefore includes existing media;
it is not a media-free export. New student media and projects are gitignored.
