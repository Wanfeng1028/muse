# PROMPT PACK: NO AFTER EFFECTS（Opus 5.5）— 索引笔记

原件：同目录 `no-after-effects-prompt-pack.pdf`（原样存档，6 页，Clawd Motion Lab 出品；来源为作者 X 帖子 @0xwhrrari 2026-10-19 所附 Google Drive 分享，21 万浏览）。
内容：一支 12 秒短片的完整提示词包——吉祥物 Clawd 本来是 AE 风格合成界面里的一张平面 PNG 图层，它把自己从屏幕上揭下来、弹出成 3D，跳着踩遍 Type/Rectangle/Pen/Glow 按钮、踩出四个关键帧、骑着播放头冲到结尾按下 Play，最后整个编辑器散架、只剩它的作品。界面、场景、声音全部由 Claude Opus 5.5 按提示词写成。

包的结构（全文都在 PDF 里，提示词标注为 copy-ready）：
- 第 1 页：规格（12.0s / 30fps / 1920x1080 / 360 帧 / 120 BPM、24 拍）与六条公式：界面用 HTML 真做（3 倍截图、每个按钮位置以 UI 像素记在 timeline.py 里，界面/3D/声音共用同一组数）、每个面板是独立薄板（可逐个亮起、按下、掉落）、合成画面是逐帧按播放头时间绘制的 canvas（关键帧逻辑跟真 AE 一样）、灯光不能进玻璃反射、用 contact sheet 和分段响度检查不用猜。
- 第 2 页：主提示词（390 词），结构 = BRAND 块（HERO/APP/RESULT/SET）+ FORMAT（HTML 做界面、canvas 做合成、Blender 做世界）+ BEATS（逐秒：平面图层敲屏→揭下弹出 3D→踩工具出标题/火花/笔触→踢 Glow 进合成→四跳踩关键帧→骑播放头→Play 后面板逐个断电掉落）+ CAMERA + LOOK + CHECKS（先出界面纹理与合成 contact sheet，再 18 张静帧，最后全量）。
- 第 3 页：3 条跟进提示词原文与前后对比图（火花太细/标题出界/字太小；灯光在玻璃面板里成大白块+身体发粉→对玻璃隐藏灯光、降高光、改身体色与曝光；全量后两处出画→只重渲相关帧段）。全量数据：4070 SUPER 约 1.47 秒/帧、360 帧 8.8 分钟、成片 9.6 MB。
- 第 4 页："改成自己的"（APP 换成 Premiere 风格、RESULT 换成预告片的示例 BRAND 块）+ 渲染流程（build_ui.py/render_ui.js 出 ui.png 与逐帧合成图，gpu.py 切 OptiX，CRF 17）。
- 第 5 页：逐帧命中表（每个时间点/帧号对应的画面与声音，全部落在拍子上）+ 3 个要点（像素即 API、把软件逻辑演出来、每次跳跃必须改变点什么）。
- 第 6 页：配音提示词（220 词，全 numpy 合成、无采样无人声；lo-fi 节拍在"弹出 3D"那一刻才落鼓）+ 每半秒响度自查结果（这次没需要声音跟进）。

值得借鉴进剧坊的点：HTML 做 UI 再截图当纹理的混合管线；timeline.py 单一事实源（像素布局+事件）被界面/场景/声音三方共读；"只重渲出错帧段"的增量返修；每次动作必须对画面产生改变的节拍纪律。
