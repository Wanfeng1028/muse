# 模板：正式剧本

工业成稿。场景标题 + 【画面N】 + 对白 / OS / VO。禁止把钩子卡的「画面： / 动作： / 台词： / 音效：」四字段直接当正文。

正文目标约 **6000 字**（建议 5500–6500，不含文首元数据、场景标题、人物 / 站位行、【】标注）。过短补场面与对白密度，过长先砍解释和重复镜头。

---

## 文首

```
# 《标题》

- 核心赛道：
- 一句话故事剧情：
- 核心立意：
- 主角：
- 主结构原型：
- 主叙事重心：
- 视觉形态：
- 成片形态：闭环短片 / 系列开篇
- 核心设定库引用：已应用《世界与角色设定集.md》
- 成稿格式：正式剧本
```

注：无需在此重复冗长的世界观与角色信息，正文创作默认全盘继承《世界与角色设定集.md》的设定。标题未定时可用核心意象暂代。

---

## 场景标题

```
1-Y 时段·内外，地点

人物：角色A、角色B
站位：简述角色在场景中的位置和站位关系。
```

- **1** = 本支五分钟作品（固定为 1）
- **Y** = 场次序号
- **时段** = 日 / 夜
- **内外** = 内 / 外
- 示例：`1-1 日内，礼堂`

站位只写位置关系，**不要写剧情、不要写角色接下来会做什么**。场次之间用 `---` 分隔。

---

## 画面

全片连续编号（不要每场从 1 重计）：

```
【画面1】
▲ 镜头指令 + 画面描述
```

镜头指令：`远景：` / `中景：` / `近景：` / `特写：` / `全景：` / `【镜头拉近】` / `【画面闪回】`

画面必须可拍。写「▲ 特写：橡胶手套把相册推进粉碎机」，不写「她内心充满矛盾」。闪回不得超过该场三分之一，写完必须回到当下。

---

## 对白与声音

```
角色名：台词内容
角色名（情绪）：台词内容
角色名OS：内心独白（不张嘴）
角色名VO：画外音 / 旁白
【音效】音效描述
【特效】特效描述
【字幕】屏幕文字
```

- 默认不加情绪括号。仅当不标注会丢失关键信息时才写 `角色名（愤怒）：`
- 一句台词只办一件事。禁止旁白复述画面已看见的事。
- 特效只在关键时刻标注。正文少用破折号「——」。

---

## 开场 30 秒怎么落到画面

| 钩子卡 | 成稿 |
|--------|------|
| 前 3 秒视听打断 | 开场第 1–2 个画面：镜头 + 【音效】立刻按住注意力 |
| 前 10 秒加压 / 误导 | 紧接着的画面与对白，让观众以为自己看懂了 |
| 前 30 秒揭底牌 | 开场场次结束前必须出现底牌镜头或台词 |

后 4.5 分钟按节拍换场。不要用时间码小标题（`### 00:00–00:30`）切正文。

---


## 完整示例（开场一场，格式示范）

学格式，不要抄情节。

```
# 《我不同意》

- 核心赛道：都市日常 / 家庭亲情（代际创伤）
- 一句话故事剧情：婚礼上母亲当众反对，全场以为她要发难新郎，她却走到女儿面前替她站出来。
- 核心立意：当众发难也可以是护短，亲情的刀口朝外才算站出来。
- 主角：婚礼上的母亲
- 主结构原型：关系错位揭底型
- 主叙事重心：角色向
- 视觉形态：AI 真人剧
- 成片形态：闭环短片
- 核心设定库引用：已应用《世界与角色设定集.md》
- 成稿格式：正式剧本

1-1 日内，礼堂

人物：司仪、母亲、新郎、新娘、宾客
站位：司仪与新人在台前；母亲在后排宾客席；宾客分坐两侧。

【画面1】
▲ 全景：礼堂花拱与烛光。司仪面向宾客。

司仪：有没有人反对。

【音效】椅子腿重重擦过地板

【画面2】
▲ 中景：后排，穿暗红色长辈礼服的母亲猛地站起。

母亲：我不同意！

---
```

---

## 篇幅

- 全片约 5 分钟，画面约 20–40 个，对白与画面描述目标约 8:2。
- 正文约 6000 字（5500–6500）。
- 闭环短片最后一场收在定格或黑场；系列开篇最后一场兑现承诺再挂钩。
- 不默认竖屏或横屏。用户指定画幅时按其写。
