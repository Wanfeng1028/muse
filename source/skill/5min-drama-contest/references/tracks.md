# 五赛道

先定赛道外壳，再定子分类。子分类可自拟，但必须能被该赛道容纳。开放赛道不限题材，考的是流派标签与叙事内核是否咬合。

---

## 赛道一　都市日常 / 都市言情 / 家庭亲情

聚焦都市日常、都市言情与家庭亲情。痛点来自生活质感：代际、婚姻、职场、旧怨，而不是魔法或末日。

**子分类（不限于此）：**

- 发疯文学 / 情绪代偿流：用极端、荒诞或“发疯”的行为逻辑，对抗职场/家庭压迫，给观众极致的情绪发泄。
- 时空错位弥补流：微科幻元素（如寄往过去的信），跨时空对话挽回遗憾，最终情感和解。
- 中年 / 职场重启危机：家庭与事业双重夹击，从失业或婚姻变故切入，写成年人的妥协与重建。
- 罗生门式家庭悬疑：亲情遗产或陈年旧怨，多重视角拆「现实矛盾」背后的隐情与执念。

**本赛道合格：** 情绪能被生活场景点燃；人物关系一眼可认。

**本赛道写歪：** 用玄幻奇观、战力、系统升级来救场；都市外壳里跑修仙。

**制作重心提示：** 亲情创伤常用强剧情向高压引爆；言情争议人设常用角色向；写实博弈常用剧情向。

## 赛道二　都市 / 玄幻脑洞

打破常规，讲最不合常理的假设。优秀脑洞不是无脑堆奇观，而是用新规则建立人物困境、剧情冲突，或视觉与概念上的反差爽感。

**子分类（不仅限于此）：**

- 抽象概念实体化：把日常痛点变成真实规则（如“贫穷”是一种会传染的病毒，或存在一家只收“嫉妒心”的当铺）。
- 现代高武 / 异能降临：极具现实感的都市与超自然规则剧烈碰撞，普通人用脑洞规则逆袭。
- 概念置换法则流：剥离传统金钱与权力，把寿命、情绪、遗忘当硬通货，展开荒诞智力博弈。
- 系统 / 修仙反套路：解构升级流，给主角鸡肋甚至厄运系统，看其如何用偏执变废为宝。

**本赛道合格：** 30 秒内观众能复述新规则；规则正在伤害或成全具体的人。

**本赛道写歪：** 只炫设定无人困境；奇观连发没有代价；把脑洞写成说明书。

**制作重心提示：** 规则改写、世界观撕裂走创意向；现代三观 vs 狂暴高武走角色向。

---

## 赛道三　古风 / 仙侠 / 神话二创

东方古风与志怪传说。优秀二创不是战力数值堆砌，而是找回东方骨相与气韵，用现代视角解构古卷里的宿命与执念。

**子分类（不仅限于此）：**

- 中式民俗微恐 / 规则怪谈：结合传统婚嫁、丧葬、傩戏等民俗元素，用未知的禁忌规则制造压迫感与智斗。
- 反派 / 边缘人物视角的史诗重构：剥夺传统主角光环，从小妖、反派或凡人视角重审浩劫。
- 大明 / 大宋背景下的东方志怪：封建王朝考据 + 太古神话，古典压迫感的悬疑探秘。
- 大道之争与哲思修仙：抛弃数值比拼，聚焦「求长生」与「保凡心」，用东方宿命感推剧情。

**本赛道合格：** 有骨相（礼、咒、债、名分、天命）；现代视角改的是意义，不是把古人写成网文打怪。

**本赛道写歪：** 只堆战力、副本、升级；神话人名 + 现代爽文逻辑，没有气韵。

**制作重心提示：** 史书夹层、血酬真相走剧情向；斩龙还债、剑鞘诅咒走角色向；荒庙画皮反猎走创意向。

## 赛道四　悬疑 / 科幻 / 末日

科幻环境下的逻辑博弈与废土生存。优秀作品不是特效堆砌或故弄玄虚，而是在秩序崩塌的边界，用硬核规则、信息差反转与偏执人设，撕开文明防线与人性深渊。

**子分类（不仅限于此）：**

- AI / 仿生人伦理刺杀：类似《黑镜》，探索缸中之脑、记忆转移或仿生人觉醒带来的身份认知崩塌。
- 极简规则怪谈：不依赖宏大世界观，全片只靠几条诡异的规则（如一张写满禁忌的纸条）推进求生逻辑。
- 极端气象与密室求生：天灾不是星际爆炸，而是「温度锁定」「微观坍缩」这类具体物理死局，靠知识找生机。
- 废土赛博与新阶层法则：辐射或异兽荒野上，围绕净水、庇护所权限的人性试炼与阶层跨越。

**本赛道合格：** 规则可复述、信息差可回看、人在极端里露出偏执或选择。

**本赛道写歪：** 只堆废土特效；悬念靠装神弄鬼；没有逻辑只有惊吓。

**制作重心提示：** 铁证悖论走剧情向；强迫症收尸人走角色向；精准温控收割走创意向。

---

## 赛道五　开放（流派标签 × 叙事内核）

不限具体题材或细分风格。评判核心：故事的叙事内核（创意、角色、剧情）是否与所选流派标签深度适配；开局能否迅速建立高级感并立住核心特质。

**子分类（不仅限于此）：**

- 信息差欺诈与多重反转：类似无限流剧本杀，极短篇幅内多方视角错位，完成三次以上认知颠覆。
- 黑色幽默与荒诞解构：用极度松弛、反常规的主角行为，消解宏大严肃背景，形成强反差喜剧质感。
- 沉浸式第一人称叙事：借鉴互动影游，强化镜头代入，把观众置于选择与道德困境中心。

**本赛道额外检查（不过则退回项目卡）：**

- 必须同时写出：流派标签 + 绑定的叙事内核（三者之一）。
- 「什么都沾一点」不合格。标签是黑色幽默，开场却端着史诗悲剧腔，算没咬合。
- 高级感来自适配，不来自题材冷门。
