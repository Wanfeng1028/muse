# Acheng Director 3.5.4｜简便操作指南

## 1. 解压与入口

1. 解压 `acheng-director-v3.5.4.zip` 到一个新目录。
2. 先看 `DELIVERY.md` 了解包内容，再看 `使用指南.md` 查完整规则。
3. 本包只生成生产数据和模型提示词，不会自动调用付费图像/视频模型，也不代表媒体已经生成。

## 2. 最快试用：直接复制示例

- H3 视频：打开 `examples/compiled/mecha/UPLOAD.md`，按槽位上传参考图，再复制同目录的 `MECHA_SEG01.h3.txt` 到 MiniMax H3。
- GPT Image：打开 `examples/compiled/images/mecha/UPLOAD.md`，按槽位上传参考图，再复制同目录的 `ASSET_01_MECHA.image.txt` 到 GPT Image 2/2.5。
- 没有参考图的文戏示例可直接使用；带 `.draft.txt` 的资产缺少依赖图，只能先补图后提交。

不要把 `DELIVERY_VIEW.md`、`production.json` 或 `audit.json` 整页粘贴给模型；它们是人类导航和机器合同。

## 3. 做自己的项目

从 `examples/*.production.json` 复制一份并修改项目事实，或从 `templates/` 创建新数据。每次修改 `production.json` 后，先审计再编译：

```powershell
python scripts/audit_storyboard_quality.py examples/01-mecha.production.json --report output/audit.json
python scripts/compile_h3.py examples/01-mecha.production.json --out output/h3
python scripts/compile_assets.py examples/01-mecha.production.json --out output/images
```

运行完整包检查：

```powershell
python scripts/validate_director_contract.py --report reports/package-acceptance.json
```

需要 Python 3.10+；只有 YAML 输入时才需要 PyYAML。

## 4. 3.5.4 的两个关键规则

- **风格锚定**：只有在项目根数据显式声明 `style_lock` 才启用 `STYLE_MOTHER`。风格参考必须放在资产上传槽位最后，只影响媒介、线条、阴影、色板和材质响应，不覆盖人物身份、场景结构、动作、姿态、相机或精确灯光。
- **打戏 H3**：战斗镜头必须写清轴线、出发点、目标点、身体/武器朝向、支点、结果方向，以及 `approach → commit → contact → recovery → reset`。慢动作只允许与有事实依据的 `contact` 接触阶段重叠；没有接触依据就关闭慢动作。

## 5. 结果怎么判断

- `PASS`：机器合同通过，不等于画面艺术质量通过。
- `ready-to-submit-not-generated`：提示词和输入齐全，但尚未生成媒体。
- `draft-missing-references`：缺真实参考图，不能直接提交。
- `UNVERIFIED`：没有真实媒体或人工画面/音频验收证据。

当前有效路线是 **v3.5.4**。`v3.6.0` 已移入包外的“偏离搁置”归档，不要安装或作为开发基线。
