# 103｜Module Authority v4 模块权属

4.0 继续以 data/module-registry.json 为七个专业模块的字段权属真值。编排器只生成节点、依赖、游标和产物索引；它不能把模块输出解释成新的生产字段，也不能让一个模块替另一个模块写字段。

节点的 owner 必须是登记的模块 ID 或明确的宿主执行适配器。节点的 allowed_write_paths 从登记读取，计划层只展示它，不执行越权写入。现有 director_dispatch.py 仍负责 3.5.4 的模块回包合并；4.0 提交器只管理外部产物和运行状态，两者不互相替代。

触发图可按用户意图、已有生产数据和显式特征增量生成：剧本、资产、H3、VFX 优化和完整制作不共用固定流水线。STYLE_MOTHER、combat timing、连续性账本和 H3 五模式仍由原合同及所属模块负责；编排器只记录节点是否需要这些模块及其验收回执。
