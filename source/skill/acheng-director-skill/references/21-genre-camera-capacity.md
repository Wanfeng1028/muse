# 21｜题材、叙事视点与片段容量

先决定观众在本镜头要知道、误解或等待什么，再选择景别、机位与运动。132库提供候选动作；导演必须解释为什么采用这一条以及幅度如何适配本项目。静态观察是合法选择，允许以构图参照绑定而不强行移动。

| 情境 | 主要可见信息 | 摄影与节奏起点 | 防止的损失 |
|---|---|---|---|
| 悬疑调查 | 线索出现、被谁看见、被怎样误读 | 受限视点、物证插镜、反应延迟 | 相机提前展示人物尚未取得的信息 |
| 恐怖 | 可行动空间、威胁缺口、声音方位 | 建立出口、保留负空间、改变一次安全边界 | 连续抖动掩盖空间或无因跳吓 |
| 喜剧 | 预期、偏差与反应 | 同框建立规则，停留让偏差显现，反应镜结算 | 切镜过快吃掉包袱或解释笑点 |
| 爱情/家庭 | 视线、距离、被允许的接近 | 平视、共享空间、细小调度改变关系 | 每句台词硬切特写、强迫同步微动作 |
| 社会纪实 | 人与环境的真实关系 | 尊重观察距离、保留劳动与环境时间 | 用炫技镜头制造未经证实的立场 |
| 武术近战 | 足位、接触、防线与后续权限 | 侧向中全景建立力链，必要时局部插镜 | 只拍拳头、漏掉应对和尾态 |
| 战争/追逐 | 目标、路线、掩体、资源与距离 | 先地理后局部，方向变化有过渡 | 每段换左右、弹药和路线自动恢复 |
| 巨物灾难 | 同深度基准、环境后果 | 地平线、前景视差、延迟反应 | 只用仰拍和数值宣称巨大 |
| 歌舞/音乐段落 | 音乐分句与身体动作的对应 | 按乐句安排运动与切点，保留群体队形 | 把参考音色误当音频直接复用 |
| 写意/实验动画 | 形体规则与媒介连续性 | 用色块、墨线、遮挡、节奏组织信息 | 强塞摄影PBR或把风格变化当剧情变化 |

每段4–15秒先列必须发生的事件与必须听完的对白，再安排镜头。对白时长根据实际语言、语速和停顿估计；已有录音以测得时长为准，不能用统一字数/秒冒充所有人的发声能力。保留反应与落定时间。

每镜一个主要运动和一个跟踪目标是默认起点。复合运动需要明确分相位路径；当身份、空间、多个攻防和多句对白同时竞争时，先去掉重复信息，再在合法事件节点拆段。禁止为塞进15秒删掉决定性结果。

容量检查问四件事：观众是否有时间认出主体；决定性变化是否看得见；声音是否能自然完成；尾态是否稳定到足以接下一段。数值时间闭合不代表感知容量合理。

装箱使用已有镜头边界求合法分区。镜头本身超15秒或尾段无法达到4秒时返回具体边界问题，由导演调整分镜；不能静默拆攻击、剪断台词或增加剧情。需要生成把手时单列生成区间与剪辑区间，再核对实际入口；当前pack不自动发明把手。
