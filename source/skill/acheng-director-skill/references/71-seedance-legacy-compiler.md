# 71｜Seedance 自然语言适配

继承同一 Production 与 ShotSpec，输出已确认角色、场所、镜头、局部时间线、攻防、表演、声音与连续尾态。这个文件是自然语言交接规范，不声明任何未核实的 Seedance 2.0 API 参数。

同样遵守[独立提示词合同](72-standalone-prompt-delivery.md)：逐段重述完整身份、场景和状态，内部身材／情绪／镜头ID必须展开。不能因为换了视频模型就只留下姓名或“沿用上一段”。

顺序：整体媒介 → 真实参考素材与职责 → 角色／场景锁 → 起幅 → 每拍动作、应对与结果 → 尾态 → 现场声 → 配乐政策 → 执行设置。参考素材只有实际存在才写平台标签；不继承旧模板“没图片也先写@图片1”的占位规则。

示例起幅：左侧维护机甲面朝右，右臂喷口已举至胸高；右侧防守机甲左盾斜朝左上，东墙检修灯光位不变。0–2秒，攻击者左足压地并前送右肩；2–4秒，喷口射流沿既定路径到盾缘，防守者转髋导偏；4–7秒，射流擦向混凝土表层，护臂回缩、后足制动，双方位置进入下一镜。

声音继承 inherit/no_bgm/specified_music；无配乐不是普遍默认。旧模板1–10“运动幅度”、固定3–5秒和120fps均不是本版执行参数。当前入口若有对应设置，记录实际字段名、来源与值；没有则只保留描述，不捏造接口。

H3 的 `<Subject N>`、`<d>` 和六字段不自动混入 Seedance。平台输入语法需执行前核实，通用交接包可先完成。完整旧动作素材保留在 [v5.1](sources/combat/Seedance打斗Prompt模板_v5.1_剧情锁定版.md)，保留其剧情锁与攻防密度方法，但旧字数限制不能倒逼缩短完整作品。
