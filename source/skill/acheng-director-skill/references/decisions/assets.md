# 资产：决定每张图给下游提供什么

执行方式见 [115](../115-directed-decisions.md)。实际依赖与批准规则以 [60](../60-assets-and-keyframes.md)、[61](../61-asset-dependency-production.md)、[62](../62-style-anchor.md)、[114](../114-reference-binding-delivery-v4.3.6.md) 为准。

## A1｜先制作哪张，后续如何使用

读取当前任务是资产生产还是仅 H3 编译、多资产风格策略和既有批准版本。H3-only 只盘点可用输入和缺项，不启动风格图。资产生产按现有 style_policy 先完成必要风格锚定，再沿 asset_plan.depends_on 制作。

| 图的主要用途 | 本次保留 | 不能自动继承 | 下游用途 |
|---|---|---|---|
| 风格母图 | 媒介、线条、色板、材质响应 | 人脸、服装身份、姿势、精确布局 | 适用资产图的最后风格槽；不强制每个 H3 上传 |
| 人物四视图 | 同一身份、比例、发型、服装 | 四个分身、板式、站姿、背景光位 | 人物／状态变体、关键帧；H3 中作为 Subject 的来源 |
| 服装／伤势状态图 | 当前批准的局部变化与身份 | 尚未发生或已失效的状态 | 仅在对应 Shot／帧窗使用 |
| 场景母图／补充视角 | 地标、入口、通行结构 | 源图人物、固定机位与不适用光位 | 场景重建、关键帧和场景 Subject |
| 道具／载具图 | 拓扑、材质、比例与可操作部位 | 原持有人、原摆放和未来破损 | 关键帧及相应用途的 Subject 来源 |
| 单幅关键帧 | 指定时刻的身份、状态与构图 | 整段冻结姿态、未来状态提前出现 | 首帧／尾帧／中间锚点，或有明确范围的构图参考 |
| 接触表／灰模 | 所声明的视点、相位和镜头规划 | 网格纹理、灰模脸作为身份 | Ref2VA 规划；首尾帧先制作并批准独立单帧 |
| 特效形态图 | 已批准形态、纹理、尺度提示 | 新增伤害、提前破坏、固定运动时间 | 关键帧或效果内容参考，过程仍由 vfx 定义 |

## A2｜关键帧需要哪些图

先读这一帧的 Shot、相位、人物、场景、可见道具与发生到此刻的状态。逐项问：当前已有哪份批准资产能证明它？把实际采用项填入卡片 references，同时写入 depends_on，编号从 1 连续排列；不要把完整图库都塞进去。

两个人物同框时，各自绑定自己的身份图；场景图只管空间；道具图只管物件。参考图不能解决的构图、握持、接触和遮挡写进独立 prompt。若脸清楚但手被遮住，不声称源图证明了握法。风格槽按原合同置后。


### 关键帧参考图组合决策核对问询门禁（Directed Keyframe Reference Inquiry Gate）

宿主 AI 模型在生成关键帧（Keyframe）提示词前，必须依据本镜具体剧情执行以下**自问自检**：
1. **场景关联问询**：本瞬间发生在哪个场景？是否已把前面生成的场景概念图绑定为参考图（如 `@图片2`）？
2. **角色多方问询**：画面中有哪几位主要角色同框？是否分别将各角色的纯粹四视图基准图作为独立槽位（如 `@图片3`、`@图片4`）引入以锁定五官和衣服？
3. **关键道具问询**：画面动作是否涉及核心武器碰撞或争夺宝物？是否将道具设计图作为独立槽位（如 `@图片5`）引入？
4. **风格母版问询**：是否在 `@图片1` 绑定了风格母图以统领画风？
5. **纯粹性与清洁度问询**：提示词中是否已用 `@图片1`~`@图片N` 明确指派职责，并强制添加了“无文字无水印”负向约束？
若有出场却未绑定对应参考图，必须立即补充并排定上传槽位，严禁让生图 AI 凭空猜测角色长相或场景！

若上游只有 .image.txt，则它仍是待生成指令；缺项留在草案和上传卡。生成真实图片、核对并批准后登记版本与哈希，再重编下游。不得将提示词文件或“通过”文字充当图片。

## A3｜场景换角度／局部修复

先判断改变是否会露出源图看不见的区域。不会时按 EDIT 保留结构；会时按 REBUILD 明确需重建的遮挡和表面，未知背面不得宣称已确认。moodboard 只供其批准用途，不自动升级成场景几何或 STYLE_MOTHER。场景支路返回建议，assets 验证后合并，shots 决定相机。

## A4｜向 H3 交接前

提供每份资产的真实文件、版本、对象、状态和用途；model 决定本段哪些作为直接输入、哪些只用于上游制作。对单帧、四视图、整张接触表明确说明区别。最终以每条资产提示词的上传卡核对实际文件和编号，再以每个 H3 Segment 的上传卡核对该段独立编号；两套编号不互相套用。

交接前检查新材质描述是否同时出现在七步第4/6步和完整 prompt，适用的身份/场景描述是否已提供给下游。文字资料条目不是图片；没有真实素材不能凭选中了库条目填入 references 或宣布风格锁通过。

## A5｜材质、光泽和画法没有真正落到物件上

先读批准媒介、当前物件材质/颜色/状态、实际光位和镜距。用[光源与表面区分 Q22](../inquiries/assets.md#q22)定位问题，再按[视觉与材质库](../116-visual-reference-library.md)选一个相关条目。依次填实：哪个部位 → 哪个已有光或画法 → 哪种可见响应 → 哪些身份/状态必须保持。

人物近景先保脸和手，衣料纹理只到当前可见尺度；场景先保地标与通行结构，再分主次表面；关键帧只描当前相位，不从材质库新增雨、汗、裂口或未来损坏。写实、赛璐璐、水墨使用各自适配句。新风格超出 style_lock 时回主导演裁决，局部补描述不重复整套风格审批。
