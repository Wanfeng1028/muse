## 2. 四维摄影物理学逆向矩阵 (The 4-Dimensional Cinematography Matrix)

对参考视频中的每一个动作瞬间，必须穿透表面像素，逆向还原以下四大物理学光学参数：

| 物理维度 | 工业光学物理量与参数范围 | 逆向提取规范与代表特征 |
|---|---|---|
| **维度一：相机几何 (Camera)** | **焦距 (Focal Length)**：`12mm` 超广角透视畸变 / `24-35mm` 广角环境交互 / `50mm` 人眼真实 / `85-200mm` 长焦空间压缩<br>**拍摄角度 (Angle)**：`仰视 (Low Angle)` / `俯视 (High Angle)` / `平视 (Eye-level)` / `荷兰角 (Dutch Tilt)`<br>**景别 (Shot Size)**：`ECU` / `CU` / `MCU` / `MS` / `WS` / `EWS` | 锁定镜头视角与空间形变，确定主体与背景的几何透视关系。 |
| **维度二：景深与虚化 (DOF & Bokeh)** | **光圈值 (Aperture)**：`f/1.2-f/1.8` 极浅景深 / `f/2.8-f/4.0` 经典人像电影景深 / `f/8.0-f/16` 全景深<br>**焦点转移 (Rack Focus)**：记录焦点从前景（如刀刃）向中景（面部）的平滑转移路径<br>**光斑散焦质感 (Bokeh Type)**：`奶油般化开 (Creamy)` / `旋焦 (Swirly)` / `放射状散焦 (Radial)` | 判定观众视线焦点落在武器接触点还是角色微表情上，严防背景过度假虚化。 |
| **维度三：构图与屏幕坐标 (Composition & Coordinates)** | **构图法则**：`三分法` / `黄金螺旋` / `对角线冲突` / `中心对称` / `负空间留白`<br>**主体占比 (Proportion)**：核心角色或接触点在画面的面积占比（如 45% 或 70%）<br>**二维相对坐标 (Coordinates)**：以画面左上角为 `(0, 0)`、右下角为 `(100, 100)`，标记打击交汇点的绝对屏幕落点（如 `击中点(50, 40)`） | 彻底消除 AI 生成时的人物站位漂移与肢体越界。 |
| **维度四：动态矢量与快门 (Dynamics & Shutter)** | **三维运动矢量 (Motion Vector)**：主体在空间中的位移方向（`x轴横移, y轴纵向, z轴纵深进退`）与摄影机复合运动（`Pan/Tilt/Dolly/Truck/Boom/Orbit`）<br>**快门速度感知 (Shutter Speed)**：`1/1000s 高速凝固 (子弹时间)` / `1/50s 电影标准 (自然运动模糊)` / `1/15s 慢门流光拖影`<br>**运动模糊轨迹 (Motion Blur Trails)**：刀刃与拳风的物理拖曳残留 | 精确掌控画面的速度感与停顿节奏，指导下游 1-3 帧冲击定格与残影生成。 |

## 3. 攻防力学与因果逻辑逆向法则

在解析动作时，拒绝“角色 A 暴打了角色 B”这类低级概括，严格落实**【一攻 ➔ 一应 ➔ 一果 ➔ 一续】**的硬核因果闭环：

1. **一攻（发起者与解剖目标）**：
   - 谁发起攻击？使用什么肢体或武器？发力链根源为何（脚掌蹬地、拧腰送髋、肩背发力）？
   - 精确打击目标点（如：`耳下神经丛`、`心窝中线`、`手腕桡骨受力点`、`膝关节韧带`）。
2. **一应（被攻击者真实力学响应）**：
   - 被攻击者处于何种初始状态（重心在前脚、正在后撤、腾空无受力点）？
   - 作出何种微米级应对：`半寸后仰避让`、`剑脊下压变向`、`贴地滑入肋下盲区`、`借前冲余势外旋卸力`。
3. **一果（碰撞力学与环境破坏）**：
   - 命中、格挡还是落空？
   - 人物生理反馈：受击处肌肉形变、后仰硬直、击飞翻滚离地。
   - 环境物理反作用力：接触点激波扩散、脚下积水爆起环形水冠、身旁混凝土墙震裂出蛛网纹并伴随碎石飞溅。
4. **一续（攻防权限转移与下一镜承接）**：
   - 交锋后谁占领了中线优势？谁失衡需要 0.3 秒重心回正？
   - 双方武器留在何处，如何直接引出下一拍的攻防回合。
