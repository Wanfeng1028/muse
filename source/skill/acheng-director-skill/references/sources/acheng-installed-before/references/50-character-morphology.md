# 通用角色体态与解剖设计引擎 (Universal Character Morphology Engine)

当需要设计或审计角色的人体骨骼比例、肌肉量感、男女老幼体态原型、重型外骨骼机甲结构或巨物异化生物体态时读取本文件。
本引擎将角色外形确立为一个涵盖年龄表征、骨架力学、体积分布、负载姿态与摄影机透视的严密工业系统，彻底杜绝孤立的口水形容词与解剖错乱。

---

## 1. 核心设计铁律 (Core Morphological Laws)

1. **先定骨架，后挂附着物**：
   - 必须先锁定核心骨骼比例与体态重心，再挂载服装、装甲板、武器、披风或机械外骨骼。
2. **体块连续性原则**：
   - 无论是真人解剖还是动力装甲，胸腔 (Ribcage)、腹部核心 (Abdomen)、骨盆 (Pelvis)、臀腿肌群必须保持结构性力学连续，严禁出现腹部断层或悬空漂浮。
3. **真实负载与重力下沉**：
   - 手持巨剑、重机枪或身着百公斤钛合金装甲的角色，肩胛骨必须有明显的下沉与前倾，斜方肌紧绷，脚掌触地受压下陷。
4. **摄影机透视校准**：
   - 仰拍使下肢拉长、头身比显得更高大；俯拍使头部变大、下肢压缩。在评估头身比时必须剔除镜头畸变与鞋跟高差。

## 2. 绝对安全与年龄分类门禁 (Safety & Age Gate)

在进行任何角色体态设计前，必须强制执行此门禁：
- **成年人 (Adult)**：允许展现成熟身体线条、战斗肌肉群、伤疤战损或性感曲线。
- **青少年/未成年人 (Youthful / Minor-coded)**：
  - 严禁任何性化描写、过度贴身暴露着装、病态夸张头身比或具有挑逗意味的镜头取向。
  - 只允许展现健康活泼、朝气蓬勃、实用日常服装与中性/防御性姿态。
- **年龄模糊 (Ambiguous)**：若用户提出模棱两可且带有成人暗示的描述，一律强制收敛并声明为“20岁以上成年体态”。

## 2. 测量基准与头身比计量规范 (Head Unit U Convention)

深度吸收盛唐 900 专属体系中的人体工业度量标准，使用 **`U`（头高单位，从头顶颅骨顶点至下颌尖端的垂直距离）** 作为统一比例衡量尺：
- **测量基线**：剔除动物耳、发髻发饰、王冠头盔、高跟鞋与悬浮底座，纯测量骨骼总高；
- **解剖标志链条 (Skeletal Landmark Chain)**：
  `颅顶 ➔ 锁骨凹陷 (1.3U) ➔ 胸骨剑突 (2.2U) ➔ 肚脐中线 (3.0U) ➔ 骨盆耻骨联合 (4.0U/身台中点) ➔ 膝关节间隙 (6.0U) ➔ 脚踝跟骨 (7.5-8.0U)`；
- **透视防伪校验**：任何坐姿、屈膝或前倾动作，必须按拉直后的骨骼链评估头身比，绝不按屏幕像素包围盒做粗暴换算。

## 4. 服装甲胄层叠与物理悬垂力学 (Costume Drape & Armor Physics)

彻底吸收盛唐 900 资产设计的服装层叠法则，角色的外挂装束必须严格遵循三层物理因果：
1. **内层透气紧身层 (Inner Layer)**：紧贴皮肤轮廓，吸收汗液，展现肩背与腰腹的起伏体块，防止外装走光；
2. **中层承重与防弹甲胄层 (Mid-Armor Layer)**：锁甲、钛合金防弹板、硬质护胸。必须有明确的尼龙卡扣、皮革束带与铆钉锚固在骨骼承重支撑点（肩峰、肋骨外侧、髂骨嵴），严禁悬空附着；
3. **外层飘带、披风与战术大衣 (Outer Drape)**：
   - 随身体运动与迎面强风产生空气动力学形变；
   - 材质物理属性分明：重装帆布/皮革因自重垂直下坠抗风，薄纱/真丝如水流在身后飘散撕裂。
4. **武器重心悬挂锁 (Weapon Rigging)**：
   - 刀鞘与枪套必须通过双点战术斜跨皮带固定在骨盆中线，拔出时有明确的出鞘导轨，防止武器在后背凭空吸附。
