# 资产设定 Ref

当已有剧本与分镜上下文并由用户确认/用户提供，需要设计角色、场景、道具或视觉基准资产时读取本文件。

## 目标

创建下游关键帧和视频生成所需的视觉 / 听觉锚点，保证角色、场景和道具一致。

本阶段**全面采用 cinematic 视觉体系**，具体引擎模块：

- **画风、光影、色彩、材质上位约束**：`references/00-visual-contract.md`（固定画风 DNA、单一统治光、色板、材质合同、灯光上下文切换、质量门控）。
- **成年女性角色体型**：`references/10-female-body-design.md`（A-I 原型库、头身比、骨架、体量分布、安全门、BodySpec 输出），模板 `templates/body-spec.yaml`。
- **角色资产图（四宫格资产表）**：`references/20-character-asset-design.md`（FACE truth-source、2×2 布局、摄影棚布光引擎、服装结构引擎、材质 LookDev、负面词），模板 `templates/character-bible.yaml`。
- **场景母图与空间架构**：`references/30-scene-keyframe-design.md`（七层空间、焦段路由、时间天气布光、色彩脚本、建筑世界构建），模板 `templates/scene-bible.yaml`。
- **跨阶段交接与连续性**：`references/40-continuity-and-handoff.md`（BodySpec→CharacterBible→SceneBible 传递字段）。
- **GPT Image 2 定向编译**：`references/gpt-image-2-prompt-compiler.md`（generate/edit 路由、参考图职责、不变量/改变项、质量与尺寸参数）。

**【强制】本阶段所有图像/视频 Prompt 的画风段，必须一字不差使用 `references/00-visual-contract.md` 第 1 节的固定画风 DNA（中文版或英文锚点），不得替换、简化或改写。画风不做澄清、不提供选项——本 skill 为固定 cinematic 风格生产链。** 资产阶段澄清的只是：角色体型原型、每个场景的时间/天气/主光气质（从视觉合同第 8 节布光路由选择）、色板（从视觉合同第 4 节推荐组合选择）。

## 澄清策略

资产阶段开始前，自行确认：

- 当前集 / 当前批次需要哪些角色、场景、道具。**清单来源**：角色取自 `scriptwriter.md` 产物二人物小传（含视觉方向、关键道具/记忆点字段）；场景取自 `scriptwriter.md` 产物三主要故事场景清单（含空间概念、情绪基调、叙事性关键陈设、常见时间/内外景字段）；关键道具取自小传"关键道具/记忆点"字段与主要故事场景的"叙事性关键陈设"字段。资产阶段不建议自行新增未登记的场景或道具，如需新增须先回填 `scriptwriter.md` 产物三。
- **画风**：固定为 `references/00-visual-contract.md` 的 cinematic 画风 DNA，无需澄清。**叙事光影气质**与剧本头 `镜头气质：` 的描述性参数对齐——它决定各场景默认的布光路由、色板、构图、机位运动与节奏选择。
- **角色 BodySpec（成年女性角色必填）**：按 `references/10-female-body-design.md` 先过年龄安全门，再从 A-I 原型库选择或混合（如 D70 + F30），锁定头身比、骨架、体量分布，输出 BodySpec。男性/其他角色不套用女性原型库，但需按同样颗粒度给出结构化体型描述（头身比、肩宽、胸廓、腰、骨盆、四肢、姿态）。
- **场景 SceneBible**：每个主要场景锁定空间轴线、主地标、时间、天气、主光家族、色板、固定锚点，输出 SceneBible。
- 资产图片画幅比例：角色资产图默认纵向 `3:4`（用户要求时可改 `9:16`）；场景资产图统一 `16:9` 横版，除非用户明确要求其它比例。
- 参考图用途：身份锁定、风格参考、构图参考、场景参考、道具参考或仅灵感参考（参考图职责分配见视觉合同第 9 节）。
- 是否需要角色高光台词视频：仅在项目确需锁定音色、口型或动态表演基准时制作，不依据 `production_total_duration` 机械触发；纯视觉资产任务无需额外生成视频。
- 哪些资产已存在并应复用。

所有角色、场景和道具静态图必须通过 `gpt-image-2-prompt-compiler.md` 编译。角色资产是真值源，不消费 `expression_handoff`，不把剧情中的临时表情、伤势爆发或动作相位固化进 CharacterBible。

## 资产完整性

### 角色资产

每个主要角色需要：

- 1 张 cinematic 四宫格角色资产图（标准布局见 `references/20-character-asset-design.md` 第 6 节）。
- 1 份 CharacterBible（模板 `templates/character-bible.yaml`）；成年女性角色另需 1 份 BodySpec（模板 `templates/body-spec.yaml`）。
- 工具可用时，1 条高光台词作为角色介绍视频。
- 需要时，补充标志性饰品或道具细节图。

**角色资产图标准（cinematic 四宫格资产表，替代旧横版三视图）：**

- 纵向 `3:4` 单张完整资产表（用户要求时可改 `9:16`），**不是四张分开的图**。
- 精确 2×2 不等高四宫格布局：上排两格约占总高度三分之一（面部身份验证），下排两格约占总高度三分之二（全身服装与轮廓展示）；面板间纤细中性灰分割线。
- **Panel 1：正面面部**，锁骨以上，正对镜头，五官完整无遮挡——此面板为 **FACE truth-source（面部真值源）**，必须直视镜头，五官左右对称，不得生成微侧脸、3/4 侧脸、低头、抬头或偏转视线。
- **Panel 2：纯侧面面部**，锁骨以上，面向画面右侧，与 Panel 1 保持完全一致的额头、鼻梁、鼻尖、嘴唇、下颌、年龄感和身份；不得变成三分之二侧脸。
- **Panel 3：全身正面**，从头顶到脚底完整入画，双脚稳定落地，展示完整正面服装结构、武器结构；不能裁切头顶、手臂、腿部或脚部；除非角色设定本身没有头或脚。
- **Panel 4：全身后侧 3/4 或完整背面**，从头顶到脚底完整入画，清楚展示背部发型、披风、盔甲、腰封、武器悬挂和服装后侧结构。
- 四格必须使用完全一致的角色身份、身体比例、服装结构、材质系统、背景、光位和调色；**同一光位，不得为每格重新布光**（摄影棚式单一侧后主光，相机右后约 45°、后上约 35°，见视觉合同第 7 节）。
- 背景：纯净克制的深暖灰至炭灰摄影棚背景，仅保留极轻微空间雾和地面分离，无场景、无家具、无建筑装饰。
- 四格中的面部必须与 FACE truth-source 100% 一致——**禁止为每个面板重新设计脸**。

高光台词视频（如用户需要）：

- 时长写入 `generation_clip_duration`，由当前表演节拍、镜头可读性和实际 Seedance 2.0 入口共同决定，不使用固定秒数。
- 使用角色资产图（Panel 1 或整表）作为参考。
- 角色必须说一句符合人设的台词。
- 输出音色描述：声线、年龄感、质感、情绪状态。

### 场景资产

每个主要场景需要：

- 1 份 SceneBible（模板 `templates/scene-bible.yaml`）：锁定空间轴线、主地标、时间、天气、主光家族、色板、材质状态、固定锚点与允许变化项。
- **必须完整生成 6 张独立静态图，少一张都不能视为该场景资产完成：**
  1. 全景氛围图（即 cinematic 场景母图 / establishing frame，七层空间架构见 `references/30-scene-keyframe-design.md` 第 8 节）。
  2. 中景图。
  3. 左侧视角图。
  4. 右侧视角图。
  5. 关键交互区特写。
  6. 反向视角图。
- 以上 6 张场景静态图必须统一使用 `16:9` 横版画幅，除非用户明确要求其它比例。
- 工具可用时，向用户询问是否需要补充 360 度纯净空镜环绕视频。

**场景六视图完成门槛：**
- 每个主要场景必须按上述 6 张清单逐张生成、逐张返回给用户，不能只生成全景氛围图后就停止。
- 第一张全景氛围图作为该场景的空间母版；后续中景、左侧、右侧、关键交互区特写、反向视角应优先使用全景氛围图作为 I2I 参考图补全。
- 每生成完一张场景图，必须立即展示给用户，并标注该图属于 6 张清单中的哪一项。
- 同一场景的 6 张图全部生成前，不得声称该场景资产完成，不得进入关键帧阶段。
- 如果某张图生成失败，必须按原视角重试或说明失败原因；不得用其他视角图片替代，也不得把 6 张需求缩减为 1 张。

**场景资产降级条款（仅在用户明示快进时启用）：**
- 触发条件：用户在资产阶段明确表达"太慢、跳过、快进、只要核心、不要这么多图、资源有限"等意图，**或** 该场景在分镜中仅出现于单一镜头且不涉及多视角切换。
- 降级后最小集合：`全景氛围图` + `中景图` + `反向视角图` 共 3 张（覆盖空间母版、常用叙事机位、反打镜头）。其余 3 张（左侧、右侧、关键交互区特写）可省略，并必须在场景资产验收表中标注 `已降级`。
- 仅当用户明示快进时允许降级；模型不得自行判断"图太多了"擅自跳过。
- 降级状态下，关键帧阶段如出现左侧 / 右侧 / 特写视角需求，必须先回到本阶段补齐对应视角后再继续，不能用其它视角硬替代。

场景图必须保持相同空间结构、固定物理锚点、光源方向、色温和材质逻辑。纯场景资产中不能出现人物。

**场景美学与质量约束（cinematic 版）：**
- 场景 Prompt 必须按 `references/30-scene-keyframe-design.md` 第 18 节"提示词编译顺序"组织：输出类型与画幅 → 参考图职责 → 叙事时刻 → 镜头（景别/机位/焦段/距离/焦点）→ 七层空间结构 → 场景功能/文化/时代/历史状态 → 统治性主光与主亮区 → 空气介质与体积光 → 色板 → 材质 → 固定画风 DNA → 连续性锁定 → 负面约束。
- 每张场景图都必须写清：主光源方向与高度（从视觉合同第 8 节布光路由选择）、dominant bright zone 位置、色温、明暗层次、材质反射、空间透视、前中后景（七层空间）关系，确保画面有明确视觉中心和可用作后续关键帧的稳定空间锚点。
- 必须加入明确的光影逻辑词，而不是只写"好看""高级""有质感"；禁止单独使用模糊质量词（"高级、漂亮、震撼、氛围感强"）作为约束，必须替换为具体的构图、光影、色彩、材质和空间描述。
- 场景图采用环境布光（非摄影棚灯）：一个统治性侧后/后上主光，主亮区、投影、轮廓、高光和体积光同向（视觉合同第 3 节）。

### 道具资产

关键道具需要：

- 正面、侧面、背面三视图。
- 当道具有重要纹理、发光、破损或象征意义时，补充材质细节卡（按视觉合同第 5 节材质合同写清粗糙度、高光宽度、边缘响应、透光和磨损规律）。

## Prompt 颗粒度

目标模型固定为 GPT Image 2。先建立 `image_request`（model / operation / purpose / quality / size / input_images），再按本节做视觉推演；`quality` 与 `size` 是参数，不用“8K、超高清”等词代替。

按三层推演：

1. 结构骨架：图片类型、版式、构图区。
2. 语义推演：哪些元素必须存在，为什么存在。
3. 细节填充：位置、形态、内容、材质、关系、视觉处理、光影、色彩、纹理。

**强制：全资产风格统一锚点（cinematic 固定画风）**

为了保证所有角色、场景和道具的视觉风格高度一致，在生成**所有静态资产图**的 Prompt 中必须加入全局风格限定词：

- **画风段（固定，一字不差）**：`references/00-visual-contract.md` 第 1 节固定画风 DNA——中文 Prompt 用固定中文画风表述，英文 Prompt/技术锚点用固定英文锚点。所有角色、场景、道具资产共享这一段，**一字不差，不得中途替换、省略或增补**。
- **光影气质段（按剧本头对齐）**：剧本头 `镜头气质：` 的描述性参数只影响资产的时间、天气、主光、色板和构图选择（视觉合同第 8 节布光路由 + 第 4 节色板），不影响画风段本身。例如“霓虹夜景与怀旧胶片——雨夜、局部暖灯、红绿蓝点缀”会路由到相应布光与色板，但画风段仍是同一固定 cinematic DNA。
- 资产阶段不得擅自切换画风路径，不得混用多种画风写法；用户要求其他画风时，明确告知本 skill 为固定 cinematic 风格生产链。

### 角色描述顺序（四宫格资产图）

按 `references/20-character-asset-design.md` 的工作流与以下顺序描述：

1. 参考图继承模块（有参考图时声明 FACE truth-source）或无参考图身份建立模块；
2. 2×2 四宫格布局声明与各面板内容；
3. 角色身份（年龄、性别、物种、文化视觉语言）与外貌（脸型、眼型、鼻梁、嘴唇、肤色、发型、发色、特殊标记）；
4. 半写实动漫脸标准模块（`20-character-asset-design.md` 第 8 节）；
5. 体型：成年女性按已锁定的 BodySpec 原文写入（原型/混合、头身比、骨架、体量分布）；其他角色按结构化体型描述；
6. 体态与姿势（默认 relaxed confident neutral stance）；
7. 服装按内层、外层、盔甲、腰部、四肢、鞋履、披挂、饰品、武器固定系统分层；
8. 面料、缝线、边缘工艺、磨损状态（材质 LookDev，`20` 模块第 11 节）;
9. 标志性饰品/特征；
10. 摄影棚布光（侧后主光、弱环境回填、深透暗部、四格同光位）；
11. 固定画风 DNA。

### 场景描述顺序

按以下顺序描述（对应 `30-scene-keyframe-design.md` 第 18 节编译顺序）：

- 物理空间结构（七层空间：前景遮挡层 → 地面路径层 → 主体动作层 → 次级叙事层 → 主地标层 → 远景尺度层 → 天空与空气层）；
- 固定锚点（主地标、不可移动参照物）；
- 前景 / 中景 / 远景；
- 功能分区与文化语法（屋顶、柱式、承重连接、人流路线、历史状态、尺度参照）；
- 主光源方向、高度和色温（布光路由选择）；
- dominant bright zone 位置；
- 空气介质与体积光依据；
- 主色板、暗部环境色、强调色；
- 材质反射特性（材质合同）；
- 氛围粒子或天气；
- 叙事性细节（环境叙事、生活痕迹）；
- 固定画风 DNA；
- 画幅比例 `16:9`。

## 设计方法论

### 角色视觉差异化策略
- **剪影差异**：较大的体型差异、发型体积感、肩宽比例。
- **色谱分配**：为核心角色分配互补或不重叠的标志色，并明确应用到服装主色、发色或标志性饰品上。
- **眼型细分**：区分桃花眼（含情）、柳叶眼（清冷）、瑞凤眼（高傲）、杏眼（纯真）等，人物特征可以与性格正相关，也可以通过负相关来增加记忆度。
- **视觉钩子**：增加机械义眼/独特首饰/特定疤痕/纹身。
- **成年女性体型差异化**：优先从 `10-female-body-design.md` 的 A-I 原型库中选择**不同原型或不同混合比**来拉开体型差异（如女主 D 标准女主型、女反派 G 成熟沙漏型、机动型配角 B 小型成年体），而不是所有女性共用同一体型。

### 场景空间与光影逻辑
- **物理锚点**：设定不可移动的巨型参照物（如大厅中央的喷泉），确保跨镜头生成时空间逻辑不崩塌。
- **主光源定义**：明确光源类型、方向（正侧光/顶光）、色温（暖橘/冷蓝），建立全剧视觉基调；同一地点同一时间的世界光向写入 SceneBible 并锁定（`40-continuity-and-handoff.md` 第 5 节）。
- **环境叙事**：通过细节暗示场景状态（如书桌上翻开的信件），还原剧本中的生活痕迹。

## 提示词(Prompt) 推演示例参考

**下方示例为同一项目（都市豪门题材，剧本头 `镜头气质：冷冽精密悬疑——低调冷灰、几何构图、缓慢推轨`）内跨资产的统一写法：示例 1-3 为苏家大厅场景资产，示例 4 为角色高光台词，示例 5 为场景 360 度环绕；所有 Prompt 的画风段一字不差使用固定 cinematic DNA，说明同一项目内所有角色/场景/道具资产共享同一画风锚点。**
- **禁止照抄「真人电影风格」「电影风格」这类模糊留白写法**；实际生成时画风段必须一字不差沿用 `references/00-visual-contract.md` 第 1 节固定画风 DNA。

### 参考图选择与动态编号
在进行 `I2I` (图生图) 操作时，为了确保生成的 Prompt 与工具接收的参考图完美对应，必须严格执行以下逻辑：

2. **过滤无关图**：**绝不**将与本次生成无关的资产图传入工具（例如：补全林远角色资产图时，绝不传入苏晴的资产图）。
3. **动态重新编号**：根据本次**实际挑选出并传入工具的参考图列表**，对其进行从 0 开始的重新动态编号（例如，本次只传入了 3 张图，它们就是 `[img0]`、`[img1]`、`[img2]`）。
4. **Prompt 对应引用**：在构建最终的 I2I 生图 Prompt 时，必须严格使用 `[img0]`、`[img1]`、`[img2]`... 指代对应图像特征，确保 Prompt 描述与工具接收的图片序列完全对齐。
5. **禁止格式**：生图阶段禁止使用 `@图片`、`图1`、`参考图1` 等格式引用输入图。`@图片` 仅可在视频生成工具明确要求时用于 I2V，不得用于 I2I 生图。

### I2I 生图指令撰写规范

每张待生成资产图先由 `gpt-image-2-prompt-compiler.md` 判断 `generate` 或 `edit`。编辑任务按"编辑目标 + 参考图职责 + 保留项 + 编辑项 + 空间线性描述 + 风格质量约束 + 画幅比例"组织，最终合并为一段连贯的话，不要把内部字段标题塞入最终 Prompt。

- **编辑目标**：直接说明当前资产图要基于哪个 `[imgX]` 执行补全、替换、新增、局部重绘、比例调整或属性修正，明确来源图片、目标状态和作用范围。
- **保留项**：明确参考图中不能改变的主体身份、角色脸部特征、服装结构、产品/道具结构、场景空间、构图关系、位置比例、透视角度、光影方向、材质细节和层级关系。禁止只写"保持不变""其他不变""参考原图"。
- **编辑项**：逐项写清当前图片中所有需要修改的对象和动作，如补全四宫格面板、替换背景、补齐场景视角、新增道具细节、修正服装结构、局部重绘等。
- **空间线性描述**：按从上到下、从左到右、从背景到主体、从主体到局部、从主要编辑区域到次要编辑区域的顺序描述；每个编辑区域写清位置、原图内容、保留项、编辑动作、目标结果和视觉约束。
- **多图约束**：若传入多张输入图，必须分别说明 `[img0]`、`[img1]`、`[img2]` 的用途和保留内容；若需要生成多张资产图，每张图都必须独立写完整 Prompt，不得使用"同上""其余图片一样处理"等概括。
- **文字约束**：如资产图涉及可见文字，必须逐条写清原文案与目标文案，所有文字用中文双引号 `""` 框定。
- **风格与质量约束**：写清整体风格、光线、色调、材质、阴影、真实度和融合要求，确保修改区域与参考图自然融合；**画风段一字不差使用固定 cinematic DNA**。
- **画幅比例**：每张资产图 Prompt 结尾必须以比值格式写清画幅比例，例如 `3:4`（角色资产图）、`16:9`（场景资产图）。
- **模型参数**：在 Prompt 外记录 `model: gpt-image-2`、`operation`、`quality` 和实际像素 `size`；需要高分辨率母版时按当前官方/宿主限制选择合法尺寸，8K 只记录为后期交付意图。

### 风格一致性目视验收（强制门禁）

交接前**必须逐张目视核对已生成的所有角色/场景/道具资产图**，判定是否与 `references/00-visual-contract.md` 的固定 cinematic 画风 DNA 一致：

- **判定方式**：直接看图，不看 Prompt 文本。同一项目内所有资产图应当在**画面质感、光影语言、色彩调性、材质表现**四个维度上呈现同一美学——半写实动漫面孔 + 真实三维骨相、2.5D 数字绘画与电影 CG 融合、单一统治光、深而通透的暗部、PBR 材质分离。
- **不通过判定（任一命中即回炉）**：
  1. 同一项目内出现**风格混杂**（例如角色是平涂日漫、场景是 3D 写实；或角色是真人照片质感、道具是卡通渲染）；
  2. 图片风格与固定 cinematic 画风 DNA **明显不匹配**（例如生成图为柔光治愈日系平涂，或塑料 3D 质感）；
  3. 同一角色在四宫格各面板与后续道具/关键道具细节图中**质感语言不统一**（如角色是半写实皮肤，佩戴的道具变成卡通材质）；
  4. 角色资产图四格出现**不同脸、不同比例、不同服装或不同光位**（违反 FACE truth-source 与四格同光位）；
  5. 场景图出现平光、多主光冲突、暗部死黑、无依据体积光等违反视觉合同光影条款的问题。
- **回炉动作**：命中不通过项时，**必须重做该资产图**；重做前先检查该图 Prompt 画风段是否与固定画风 DNA 一字不差，如已被替换、简化或省略，先修正画风段再重生；如画风段无误但生成结果仍偏移，可在画风段后追加更细的美学约束（如"戏剧性明暗对照、深而通透的暗部、受控体积光"的具体光影参数）后重生。**不得**因为"看起来还行"就跳过、也不得用其他风格图替代。
- **执行要求**：本轮所有资产必须收敛到**同一画风锚点**，跨资产肉眼看上去像是同一部剧的美术班底出品，才算通过。
