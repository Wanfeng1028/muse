# 喜剧可读性与动画化表演

本参考适用于动作喜剧、萌宠、拟人角色、动画/漫剧，以及“写实环境 + 动画演员式角色表演”的混合项目。它不要求所有项目变得夸张；先在内容配置中选择表演模式。

## 先有整集主线，再有局部笑点

60–120 秒喜剧不能只是一串互不相关的翻车。先写一条宏观因果链：

`触发事件 → 主角误解/欲望 → 可见目标 → 连续主动选择 → 代价升级 → 主反转 → 后果/回收`

每个局部笑点都必须至少完成一项：增加主角负担、暴露性格、改变信息、缩短时间、损害关系、关闭一条退路，或直接触发下一次选择。删除笑点后若主线状态完全不变，该笑点只是可替换填充，应重写或删掉。

主反转不是最后突然增加一个奖品、秘密或规则。记录：

`plant → protagonist_assumption → audience_assumption → escalation → reveal → consequence → callback`

规则、代价与反转线索必须在主角行动前可见或可听；可以让主角忽略、误解或过度自信，但不能故意不告诉观众后再惩罚角色。

## 触发事件要被经历，而不是硬讲

优先让角色在生活流中撞见活动、危险、机会或异常：路过听见广播、看到他人结果、闻到气味、收到具体物件、目睹正在发生的事件。工作人员说明可以确认规则，但不应承担全部开场世界观。

开场检查：

- 观众知道角色原本在做什么；
- 触发事件有可见/可听来源；
- 主角做出第一个不可逆行动；
- 10 秒内能说出“他/它为什么现在要做这件事”。

## 单个笑点的可读性合同

每个重点笑点写成：

`setup → visible_cause → audience_advantage → reaction_hold → payoff → story_consequence`

- **setup：**先交代人物、道具数量、空间和正常状态；
- **visible_cause：**观众看见谁做了什么导致结果，不能凭空弹出或靠台词补因果；
- **audience_advantage（观众信息优势）：**明确观众为什么比角色先知道；记录角色视线、遮挡和信息差；
- **reaction_hold：**结果后保留约 0.6–1.0 秒，让主角、搭档或背景人物完成反应；
- **payoff：**用动作、揭晓或短补刀确认笑点，不让观众自己猜“刚才是不是要笑”；
- **story_consequence：**笑点改变主线状态，并自然进入下一节拍。

视线逻辑必须成立。例如物体落到角色头顶，先证明角色正看向别处、物体轨迹位于视野盲区；若物体从正面飞过角色眼前，之后再让角色寻找就不可信。

重点笑点优先使用清楚的侧面、三分之四或俯拍建立轨迹。动作已经复杂时降低运镜复杂度；先看懂，才可能好笑。

## 背景人物是反应层，不是空场填充

营业场所、街道、活动和公共空间应有与情境相符的人流、工作人员与声音。选 1–3 位固定“反应角色”作为观众代理，记录其身份、位置和反应权限；其他背景人物保持自然活动，不抢主体。

反应顺序通常为：主动作落点 → 0.2–0.5 秒后反应角色看见/指认/忍笑 → 主角意识到 → 搭档补刀。背景反应不能早于因果，也不能用随机群演大笑替代笑点本身。

## 选择表演模式

为项目明确一种模式：

- **自然写实：**微表情、真实步态和克制动作；
- **加强写实：**真实解剖与摄影材质，放大时机、姿势、耳尾、眼神和反应；
- **动画演员混合：**写实世界/材质中，角色采用清楚的拟人姿势、anticipation、overshoot、settle、反应定格和受控 squash & stretch；
- **完整动画/漫剧：**遵循既定设计语法、表情库、变形边界和动作节奏。

不要把“真人环境 + 宠物”自动等同于普通动物行为。用户选择动画演员混合时，角色可以直立、叉腰、托腮、高频小跑、急刹、潜行、夸张定格和用耳尾形成清晰轮廓，只要这属于已锁定的运动语言。

## 动画夸张与物理 Bug 的边界

动画夸张主要作用于角色表演：姿势、表情、轮廓、节奏、短暂压缩/拉伸和次级毛发/布料运动。道具、食物、车辆、家具、容器、玻璃与人物交接仍服从连续性和接触物理。

允许：

- 角色动作前 0.2–0.4 秒蓄力，动作后过冲再回稳；
- 眼睛/瞳孔、耳朵、尾巴和脸颊产生可读的情绪变化；
- 身体为情绪短暂压缩/拉伸约 5%–12%，随后恢复已锁定比例；
- 被抓包后全身定格，仅眼珠或耳尖缓慢移动；
- 双脚直立或拟人手势，只要角色圣经明确允许。

仍然拒绝：

- 道具、食物、服装、肢体凭空出现、复制、消失或变种；
- 角色穿透桌面、玻璃、盒子或其他角色；
- 没有蓄力、路径或落点的瞬移/飞行；
- 用“卡通”掩盖餐盘翻面、数量跳变、错误方向或说话人错配。

## 为每个角色建立表演语言

角色圣经至少记录：

- `performance_mode` 与允许的拟人程度；
- 兴奋、自信、心虚、失败、愤怒、温柔的身体/脸/耳/尾表达；
- 标志性蓄力、过冲、回稳和反应定格；
- 允许的 squash/stretch 范围；
- 禁止姿势、普通动物限制和不可变解剖；
- 与其他角色的动作幅度对比。

15–30 秒生成段至少规划 3 个不同的表演状态。不能从头到尾保持同一站姿、同一脸和同一嘴型，即使对白正确也判为表演失败。

## 提示词编排

不要只写“夸张、可爱、像动画”。逐节拍写：

1. 表演前状态与轮廓；
2. 0.2–0.4 秒 anticipation；
3. 主动作、表情和耳尾同步；
4. 次级毛发/布料响应；
5. overshoot 与 settle；
6. 0.6–1.0 秒反应停顿；
7. 下一动作或退出状态。

每个节拍一个主表演动作。角色夸张时，摄像机保持可读；需要冲击时把快速推近、前景擦镜或轻微机位反应放在动作落点，不与复杂身体变形同时堆叠。

## 验收

静音看重点笑点并回答：

- 正常状态是什么？
- 谁的哪个动作导致了结果？
- 主角为什么没看见/没理解？
- 我在哪一帧知道该笑？
- 反应和揭晓是否停留足够久？
- 这个笑点怎样改变主线？

再检查表演：角色是否经历至少三个可区分状态？情绪是否从轮廓和动作读出？夸张是否有蓄力、过冲和回稳？真实道具是否仍保持数量、方向和物理？任一核心答案不清楚，退回分镜或提示词，不用对白、字幕、BGM 或群演笑声掩盖。
