# 角色、声线与参考素材锁

一致性不是“多塞参考图”，而是为每个维度指定唯一权威来源，并在验收后更新短期状态。

## 两层状态

- **长期母版：**脸/毛色、身体比例、服装结构、产品几何、固定道具、场景布局、声音身份和导演风格；
- **短期状态：**姿势、动作阶段、屏幕位置、湿度/伤势、道具朝向、情绪、声音相位和未完成动作。

长期母版控制“是谁/是什么”，已验收父段控制“此刻正处于什么状态”。

## 参考权威矩阵

每个素材只承担明确的主角色：身份、首帧、尾帧、产品、环境、动作、运镜、节奏、声音或风格。对每个目标维度只能有一个胜出素材；写清不得迁移的内容。没有控制任何维度的素材应移除。

不要从上传顺序、文件名或媒体类型猜权威。冲突时优先级为：用户明确要求 → 角色/产品母版 → 已验收短期状态 → 场景/风格参考 → 推断。

## 角色视觉锁

为常驻角色记录：

- 身份 ID 与母版图；
- 脸/眼睛/发型/毛色地图/身体比例/身高尺度；
- 服装构造：覆盖范围、材质、扣件、缝线、配饰数量；
- 惯用手、姿势与物种合适动作；
- 允许变化：褶皱、湿度、污渍、情绪；
- 禁止变化：脸型、毛色、肢体数、服装拓扑、产品几何。

每段都使用母版 + 当前已验收状态；只用尾帧会传播漂移。

## 表演母版

萌宠、喜剧和动画化角色另锁定：`performance_mode`、拟人程度、标志站姿、视线规则、耳/尾/眼/爪表情库、动作前预备、动作后过冲/回稳、允许的 squash/stretch 范围，以及禁止的人体结构或道具能力。至少制作 `平静 → 期待/自信 → 惊讶/失控 → 尴尬/掩饰 → 得意/回收` 五个姿势或表情母版。后续镜头可放大表演，不得随机切换成普通宠物行为或纯动漫材质。

每个重点笑点还要记录主角看得见什么、被什么遮挡、搭档何时看见、谁先反应。视线和信息差属于角色状态，必须像服装和道具一样跨镜头传递。

## 重复道具与文字母版

在分镜前盘点出现两次以上、跨场景、参与关键动作或承载文字/Logo 的道具。为每件建立 [prop-bible.md](../assets/templates/prop-bible.md) 和唯一 `prop_id`，使用用户选择并验证可靠的高保真图像模型（例如 GPT Image 类生成/编辑路线）制作中性光、低畸变的正/背/侧/俯视/3/4 母版，并锁定尺度、几何、部件数、材质、颜色、连接件和允许状态。秤、印章、手机、包装、头盔、工具、钥匙等不能在不同场景重新设计。

文字道具分成两套权威：道具几何母版控制外形、运动、遮挡和光照；`text_plate_id` 控制精确文字、数字、Logo、字体和排版。精确文字默认保存透明 PNG/矢量图并后期跟踪合成，不让视频模型每帧重画。即使某图像模型能正确出字，也先验收一张静态文字母版，再把它当纹理或后期图层，不能让后续镜头自由改写。

每次出现记录 `prop_id + state_id + text_plate_id`、所有者、朝向、开合/连接、完好/损坏、干湿/污渍与上一状态唯一变化。镜头开头、动作峰值和结尾均与权威视角比对；漂移的道具不能成为下一段参考。

## 声线锁

每个常驻说话人独立保存：

- `voice_id` 与经授权的 8–20 秒干净锚点；
- 语言、口音、发音表、听感年龄/性别呈现；
- 音色、音高中心/范围、语速、气息、强度范围；
- 情绪基线与允许变化；
- 麦克风/空间质感（与角色声线分开）；
- 禁止交叉绑定的其他角色。

参考音频先去静音、噪声和音乐并归一化。模型不支持声线参考时，优先统一外部配音，不靠每段随机原生声音碰运气。

## 声音一致性检查

同一角色跨段比较：

- ASR 字词、说话人和句序；
- 每秒字/音节的语速；
- 音高中心、范围、气息与情绪强度；
- 响度、空间混响和麦克风距离；
- 角色发音表中的专名与口头习惯；
- 人工 A/B 盲听是否像同一个人。

音高/响度等自动指标是告警信号，不单独决定身份；最终由人工听感与角色声线圣经共同验收。

## 漂移处理

发现身份/服装/声线漂移时：定位第一次出现的时间点，只保留之前可用范围；局部可编辑则编辑，系统性漂移则从母版重新锚定并缩短段落。漂移素材不得成为下一段父状态。
