# 参考资产图谱与分镜图方法

参考素材不是附件堆，而是一张有职责的生产图谱。故事、角色、场景、道具、动作、分镜图、视频和声音节点之间必须有明确依赖；下游只读取已连接、已批准的上游状态。

## 推荐图谱

`故事合同 → 角色/场景/道具母版 → 覆盖方案 → 冻结分镜图 → 视频段 → 验收尾帧/声音状态 → 下一段`

- 故事节点控制因果、节拍和终态，不控制角色长相。
- 角色母版控制身份、服装与表演边界，不控制场景构图。
- 场景母版控制布局、材质、光源与尺度，不自动加入角色。
- 道具母版控制几何、材质、部件和状态，不让视频重新设计。
- 动作参考只控制运动语言或接触阶段，不迁移演员、背景、服装或镜头。
- 分镜图控制某一时刻的站位和构图，不自动控制整段运动。
- 已验收尾帧只控制短期状态，不取代长期身份母版。

任何参考没有唯一职责、与另一参考争夺同一维度、或没有被下游实际使用时，删除它。

## 角色设定图

先生成独立、干净、可比较的角色设定图，而不是直接在剧情场景里“认角色”。推荐包含：

- 正面、侧面、背面和三分之四全身；
- 中性表情与项目需要的 4–6 个表演状态；
- 走、跑、停、回头、蹲伏、跳跃等物种/人体可行动作；
- 脸、手/爪、尾巴、服装扣件和身份标记细节；
- 一个与同伴或标准物体的尺度比较。

拼版中的多个姿势是同一个角色，不是多名角色。正式视频参考必须明确 `EXACT CAST COUNT`，并写明“不继承白底、排版、标签或多姿势复制”。角色发生换装、受潮、污渍或剧情变形时建立新的合法 `state_id`，不覆盖原母版。

## 场景与道具设定图

场景先做无角色空景和空间地图：入口/出口、可走路径、主光方向、危险来源、关键设施、尺度锚点。真实地点项目优先使用真实照片确定透视、材质和地方特征，再做受控异常化；不得凭空把地点变成通用 CG 布景。

重复道具使用中性光转面图，锁定正背面、厚度、部件数、连接件、尺寸参照和允许状态。剧情文字另做干净图层，视频只生成无字底板。

## 分镜图生成

每张分镜图从“已批准角色 + 已批准地点/道具 + 一个剧情时刻”派生。提示词只解决当前帧：

1. 谁在什么位置、朝向哪里；
2. 正在发生的单一可见动作；
3. 观众必须先看到的原因或信息；
4. 镜头高度、景别、焦段与主体占比；
5. 主光、环境材质和真实尺度；
6. 下一动作需要的构图余量；
7. 不得迁移的参考内容。

先生成一张构图母帧，验收身份、数量、站位、视线、道具和空间；只做必要的局部编辑。不要在母帧错误时继续生成一整套分镜。

## 从分镜图到视频

图像控制首状态，视频提示词负责时间：动作如何启动、镜头为何跟随、物理怎样响应、声音从哪里出现、最终落到什么状态。不要重复要求模型重新设计首帧已经锁定的脸、服装和场景。

需要多个内部镜头时，为每个子镜头写 `进入状态 → 主动作 → 镜头反应 → 可见结果 → 退出接口`。连续长镜头则使用地点地图、角色母版和一张准确首状态，不用一串互相竞争的分镜图。

## 引用编译检查

提交前输出参考清单，逐项记录：

`asset_id | media_type | controls | must_not_transfer | connected_to | approved_version`

再检查：提示词中的 Image/Video/Audio 编号与实际上传顺序一致；每个引用确实连接到当前任务；多姿势拼版不会增加角色数量；旧输出不会把漂移传播到新段；参考数量没有超过入口 schema；删除任一参考后若控制力不变，就永久删除该参考。
