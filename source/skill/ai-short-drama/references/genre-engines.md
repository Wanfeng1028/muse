## 1. 核心設計公式

```text
爆款候選 = 熟悉情緒承諾 × 權力／資訊差 × 升級跑道
           × 具體新鮮機制 × AI 可視化優勢 × 可連載生產性
```

### 七種不對稱

| 不對稱 | 觀眾知道、劇中人不知道的東西 |
|---|---|
| 身份 | 廢物其實是戰神、董事長、宗主、頂尖專家 |
| 資訊 | 重生者知道未來、主角握有證據、能聽見心聲 |
| 規則 | 主角理解系統／怪談規則，對手只看表面 |
| 資源 | 隱藏財富、人脈、空間、物資、傳承 |
| 能力 | 醫術、武力、鑑寶、技術、御獸、推演 |
| 道德 | 被污名者真正救過眾人，正派其實掠奪者 |
| 時間 | 倒數、重生、循環、預知有限窗口 |

至少選一個主不對稱。太多同時存在會讓主角像作者開作弊選單。

### 新鮮變量的六個入口

- **職業：** 把戰神換成冷門但可視化的能力，如災害鑑識、文物修復、無人機救援、殯葬科技。
- **規則：** 能力有冷卻、代價、誤判率、道德限制或只能救敵人。
- **關係：** 敵人是前世救命者、系統是失蹤家人、真正盟友以反派身份出場。
- **世界：** 改革開放、島嶼都市、太空站、動物社會、神話行政機關。
- **敘事視角：** 從反派助理、路人、系統、寵物或錯誤預言者看主角。
- **情緒：** 同一逆襲不只打臉，可轉成救贖、羞愧、失而復得、代際和解。

## 2. 華語男頻引擎

### 2.1 假廢物真強者／扮豬吃虎

- **承諾：** 所有人錯估主角；觀眾等待公開翻盤。
- **主牌：** 隱藏身份、能力或資源。
- **升級：** 私下小證明 → 公開技能 → 權力人物認可 → 真身份 → 為何隱藏。
- **必要限制：** 主角有不揭牌的真理由；不能只為拖集數挨罵。
- **適合新變量：** 特殊職業、低調保護某人、被迫簽保密契約、力量會傷及無辜。

### 2.2 戰神／王者歸來

- **承諾：** 被放逐者帶著壓倒性力量回到原點。
- **核心問題：** 他能打贏所有人，卻不能直接解決哪個情感／制度難題？
- **敵人階梯：** 地痞 → 家族 → 商會／門派 → 舊戰場黑手 → 制造流放的制度。
- **反例：** 每集換一個人嘲笑，再下跪；沒有新情報與代價。

### 2.3 系統／升級流

- **承諾：** 可見進度、任務、獎勵與規則解法。
- **必備：** 資源獲得條件、失敗代價、不可突破限制、系統真實目的。
- **升級：** 個人生存 → 關係選擇 → 組織競爭 → 系統來源 → 是否拒絕系統。
- **AI 優勢：** UI 世界、技能視覺化、跨時空任務；關鍵資訊仍以清楚聲畫呈現，不能依賴模型生成可讀小字。

### 2.4 修仙／廢靈根／傳承

- **承諾：** 被規則判定的廢物，用被忽視的路徑超越天才。
- **新鮮點：** 能力不是更大光束，而是新修煉經濟、御獸生態、功法代價、宗門勞動制度。
- **揭露：** 異常感知 → 低階破局 → 禁忌傳承 → 身世 → 世界規則是騙局。

### 2.5 鑑寶／醫武／技能權威

- **承諾：** 專業被羞辱，下一秒用可驗證結果翻盤。
- **硬規則：** 技能過程需具體、可拍、有證據；不能只靠配角喊「大師」。
- **風險：** 醫療、法律、投資等現實高風險領域不得輸出會被當真實建議的錯誤資訊。

### 2.6 末世重生／囤貨／領地建設

- **承諾：** 主角知道災難將至，提前積累資源並處理前世背叛。
- **跑道：** 準備倒數 → 首災驗證 → 據點 → 人性衝突 → 新秩序 → 災難真相。
- **必要壓力：** 資源有限、預知因蝴蝶效應失準、救誰會改寫未來。

## 3. 華語女頻與家庭引擎

### 3.1 重生復仇／改命

- **承諾：** 帶著記憶重來，拒絕重演被害人生。
- **能力：** 前世記憶是優勢，不是全知；一旦改變事件，後續資訊會貶值。
- **升級：** 避開第一個坑 → 收集證據 → 奪回資源 → 揭穿核心背叛 → 選擇新人生。
- **情感底座：** 復仇之外必有「這一世想保住什麼」。

### 3.2 真／假千金、家庭偏心、追悔莫及

- **承諾：** 被錯置或輕視的人奪回身份、尊嚴與選擇權。
- **爽債：** 每次偏心、奪功、污名都要有證據與回收期限。
- **避免：** 所有家人同時無腦；至少一個人有可理解但錯誤的利益／信念。
- **新鮮點：** 成年職場、銀髮家庭、遺產之外的文化／技術傳承、雙方都拒絕豪門。

### 3.3 馬甲／隱藏大佬／獨立女性

- **承諾：** 社會標籤與真實能力巨大落差。
- **揭露梯：** 小號成就 → 專業技能 → 業界關係 → 核心創辦人／作者 → 隱藏的犧牲。
- **必要主動性：** 主角做選擇與布局，不靠更強男人代打。

### 3.4 先婚後愛／閃婚／隱婚

- **承諾：** 高壓契約關係逐步變真；身份與信任雙重揭露。
- **micro-arcs：** 被迫合作 → 看見能力 → 共同秘密 → 信任破裂 → 主動選擇。
- **避免：** 把騷擾、控制或暴力包裝成浪漫；誤會必須來自利益／資訊，不來自一句話不肯說。

### 3.5 婚姻背叛／離婚逆襲／中年重啟

- **承諾：** 被消耗的人重新掌握資產、職業、關係與尊嚴。
- **優勢：** 適合現實共鳴與銀髮／家庭觀眾。
- **新鮮點：** 第二職涯、照護壓力、數位詐騙、家庭企業、地方文化產業。

### 3.6 萌寶／心聲／全家讀心

- **承諾：** 弱小角色握有真相，改寫家庭命運。
- **規則：** 誰能聽見、何時失效、能否撒謊、說出真相的代價。
- **風險：** 未成年人形象、聲音與安全需額外權利與內容審查。

## 4. AI 原生與跨圈引擎

### 4.1 規則怪談／有限解謎

- **承諾：** 清楚規則 + 有限時間 + 每次違規可視後果。
- **連載：** 表層規則 → 規則互相矛盾 → 制定者 → 主角也在規則內 → 逃出或改寫。
- **硬規則：** 解答可回溯，不靠最後臨時新增規則。

### 4.2 神話／歷史腦洞

- **承諾：** 熟悉文化角色置於全新制度或日常衝突。
- **AI 優勢：** 宏大場景、神獸、跨時代、非人角色。
- **風險：** 歷史人物、民族文化、英雄烈士與宗教內容須遵守當地法規與平台政策；避免歪曲冒犯。

### 4.3 動物／物件擬人荒誕劇

- **承諾：** 第一眼奇觀 + 人類可辨識情感 + 意外反轉。
- **引擎：** 救援報恩反轉、戀愛實境戲仿、職場階級、家庭倫理投射。
- **避免：** 只靠怪圖；角色仍需欲望、選擇、後果與連續關係。

### 4.4 高概念職場／產業逆襲

- **承諾：** 小人物用具體能力改變一個可理解的行業規則。
- **新鮮點：** 地方小店、供應鏈、遊戲開發、AI 創業、農業科技、文化修復。
- **優勢：** 能保留爽感，又比純豪門更有現實厚度與品牌合作空間。

## 5. 海外引擎

### 5.1 Billionaire / Secret Husband

- 入口：被迫婚姻、階級錯估、秘密財富、家族反對。
- 新鮮變量：職業能力、雙方各藏一層身份、契約目的不是金錢。
- 避免把文化本地化只做姓名翻譯；家庭、法律、職場與浪漫界線需本地化。

### 5.2 Werewolf / Alpha / Vampire

- 入口：被拒絕的 mate、隱藏血統、族群階級、命定與自由衝突。
- 視覺：變身、族群標記、領地與儀式適合 AI，但必鎖角色非人特徵。
- 新鮮變量：反命定、族群政治、照護／生態代價、非浪漫主線。

### 5.3 Revenge / Karma Payback / Girl Power

- 入口：公開羞辱、背叛、奪產、錯誤定罪。
- 必備：證據鏈、主角主動性、逐級回收，不以更有權勢的伴侶代替復仇。

### 5.4 Mafia / Forbidden Romance / Thriller

- 入口：危險關係、雙重身份、交易與背叛。
- 風險：不要美化現實犯罪方法、性暴力或控制；以角色選擇與後果維持張力。

## 6. 混搭與反同質規則

### 最多 1 主 + 2 輔

```text
主引擎：決定觀眾承諾與季問題
輔引擎 A：提供升級機制
輔引擎 B：提供情感或世界新鮮度
```

好例：`重生復仇（主） + 家族企業（升級） + 文物修復（新職業）`。

壞例：`重生 + 系統 + 穿越 + 戰神 + 神醫 + 首富 + 讀心`；主角沒有可受威脅的部分。
