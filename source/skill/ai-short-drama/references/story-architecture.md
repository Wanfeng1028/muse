## 1. Premise Contract

每案先填：

```text
Audience:
Surface / format:
Public identity:
Hidden truth or advantage:
Core injustice / pressure:
Immediate desire:
Irreversible season goal:
Audience promise:
Fresh mechanism:
AI-native visual promise:
Why the hero cannot reveal everything now:
Season question:
End transformation:
```

### 好 premise 的三種張力同時存在

- **外在：** 敵人、制度、災難或倒數。
- **人際：** 誰信／不信主角，誰會因真相受傷。
- **內在：** 主角的錯誤信念或代價，不因能力變強自動消失。

## 2. 四條階梯

### 2.1 Reveal Ladder

避免第一集把所有牌翻完：

| 層 | 典型揭露 | 效果 |
|---|---|---|
| R0 | 異常徵兆 | 讓觀眾知道他不是表面那樣 |
| R1 | 單一技能／記憶 | 贏第一次小局 |
| R2 | 資源／人脈 | 改變局部權力 |
| R3 | 組織地位／血統 | 全場重新站隊 |
| R4 | 隱藏目的／犧牲 | 重新解讀前面行為 |
| R5 | 世界／系統真相 | 改變季問題 |

不是每部都要六層。先設最大秘密，再反推可分割證據。

### 2.2 Antagonist Ladder

```text
E1 近身羞辱者：能立刻傷害日常
E2 守門人：掌握機會、名譽或資源
E3 組織權力：能改規則
E4 幕後對手：理解主角能力並主動反制
E5 鏡像敵人：與主角相似，但做出相反道德選擇
```

每次升級要改變問題類型，不只是把敵人數值變大。

### 2.3 Competence Ladder

- 看見問題
- 用有限能力解一局
- 主動設局
- 承擔他人／組織
- 放棄捷徑或改寫規則

### 2.4 Cost Ladder

- 隱藏的麻煩
- 關係代價
- 資源／名譽代價
- 身份暴露
- 核心價值抉擇

沒有 Cost Ladder 的外掛只會降低懸念。

## 3. 季與 micro-arc

### Pilot 3 集

| 集 | 功能 | 必須交付 |
|---|---|---|
| E1 | 證明 premise | 公開壓制 + 異常牌 + 不可逆事件 |
| E2 | 證明爽感 | 第一筆小債回收 + 更高風險 |
| E3 | 證明連載 | 第一次公開反轉 + 新敵人／真相層 |

### 每 3–5 集一個 micro-arc

```text
Setup debt → attempts → local payoff → consequence → higher-order question
```

micro-arc 結尾同時做到：關一扇門、開一扇更大的門。

### 30 集參考骨架

| 集數 | 功能 |
|---|---|
| 1–3 | Premise proof；第一個小爽點 |
| 4–6 | 局部勢力與第一盟友；R1 |
| 7–10 | 第一公開勝利；E1 結束、E2 登場 |
| 11–15 | 主角主動布局；代價首次傷及關係；R2 |
| 16–20 | 中點錯勝／身份逼近暴露；E3 |
| 21–24 | 反派學習並反制；主角失去原優勢 |
| 25–27 | R3／R4 重解前情；終局選擇形成 |
| 28–30 | 償還主要爽債、解 season question、保留下一季新問題 |

60 集不是把每格拉長一倍；要增加第二條角色弧、第二個制度層或中段世界轉向。

## 4. 單集 beat map

### 社群 discovery 版：30–60 秒

```text
0–3s   Cold open：視覺不公、異常結果或危機已發生
3–12s  Context under pressure：只補理解當下選擇所需資訊
12–35s Escalation：對手加碼，主角不能退
35–50s Turn + payoff/progress：權力／資訊／關係不可逆改變
最後 3–7s Cliffhanger + end image
```

### App／連載版：60–120 秒

```text
0–5s    重接上一集 + 新刺激，不完整重播
5–25s   新壓力與本集目標
25–65s  行動、阻礙、選擇
65–95s  Turn 與局部回收
最後 5–10s 新資訊／新危機／揭露門檻
```

秒數是起稿 heuristic。若台詞多、物理複雜或情緒需要停頓，減少事件，不把語速加到不可演。

### Scene 檢查

每場必須至少改變一項：

- 誰掌權
- 誰知道什麼
- 誰信任誰
- 誰擁有物／證據
- 目標或代價
- 空間與安全狀態

如果什麼都沒改，只是把小說旁白念完，刪掉或合併。

## 5. Cliffhanger 類型

1. **Recognition：** 權力人物認出主角，但稱呼尚未出口。
2. **Evidence：** 關鍵證據出現，尚未公開內容。
3. **Decision：** 主角做出不可逆選擇，尚未看到代價。
4. **Reversal：** 以為勝利，真正權力者進場。
5. **Deadline：** 災難／任務／婚約／審判倒數開始。
6. **Identity collision：** 兩個身份線即將相撞。
7. **Rule exception：** 已知規則第一次失效。
8. **Emotional truth：** 一句話讓前面關係全部重解。

### 假 cliffhanger

- 把一句正常台詞切一半
- 下一集第一秒證明毫無後果
- 每集都是「大人物剛到門口」
- 角色能一句話化解卻集體不說
- 重播上一集佔掉本集大半

## 6. 爽債與伏筆帳

### Payoff Debt

```text
Debt ID:
Opened episode:
Injustice / promise:
Audience expected payoff:
Due window:
Escalation beats:
Paid episode:
Payoff changes what:
```

原則：

- E1 開的至少一筆小債在 E2–E3 償還。
- 大債可以晚還，但途中必有證據、局部勝利或權力移動。
- 同一種羞辱最多重複一次；第三次必須改變形式或由主角主動設局。

### Foreshadow Ledger

- 每個伏筆必有 planted、reinforced、paid。
- 不為續集硬加從未出現的雙胞胎、秘寶或系統規則。
- 伏筆回收要改變角色選擇，不只是觀眾知道 trivia。

## 7. 角色與反派

### 主角五欄

```text
Wants：本集會主動追求什麼
Needs：長期要學會什麼
False belief：他相信但不完全正確的事
Power：能改局的資源／能力
Cost：使用 power 會失去什麼
```

### 反派五欄

```text
Goal：不以「欺負主角」為唯一人生目標
Leverage：現在能傷害什麼
Belief：為何覺得自己有理
Learning：看到主角哪張牌後會怎麼調整
Boundary：哪件事連他也不做，或何時跨過界
```

好反派會逼主角改策略；鏡像反派會逼主角回答「我有同樣力量，為何不成為他」。

## 8. 低質敘事反模式

- **只加集數不加狀態：** 多集結束後權力、資訊、關係都沒變。
- **爽點通膨：** 每次都靠更大頭銜，沒有更難選擇。
- **主角被動等認領：** 所有翻盤靠別人進場跪下。
- **反派失智：** 明知主角強仍用完全相同方式挑釁。
- **系統代寫人生：** 主角只接受任務，沒有價值選擇。
- **重生全知：** 改變前史後仍精準知道全部未來。
- **身份揭露即結局：** 沒有規劃身份之後的 season question。
- **情緒只有喊：** 用大聲台詞替代證據、行動與反應。
- **旁白解決一切：** 重要事件沒被演出。
- **懸念作弊：** 隱藏鏡頭已經拍到、角色已經知道的資訊。
