## 保留的边界

- 无内置自动转写、抠像、手部跟踪或基础剪辑功能。
- 通用 Gate C 选择器仍要求八种不同语义结构；结构不足的短片应在方案阶段说明并约定项目级审核策略，不扩写台词凑数。
- 原声内容和时间轴保留不等于二进制无损复制；代理与最终音频可能重新编码。
- 四秒合成输入用于 Gate A 安装自测；风格组件示例不是完整真人 A–D 验收。
- Linux 中文渲染需要可用中文字体；CI 已安装中文字体。可选 HyperFrames 使用的第三方资源受其自身条款约束。
- 手动测试夹具脚本沿用本机字体配置，不属于默认测试或正常 Skill 运行入口；其他平台按实际字体调整。
