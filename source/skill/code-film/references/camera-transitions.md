# 运镜与转场

## 1. 虚拟摄像机：推拉摇移的本质

科普片、讲解片那种推来推去的效果，做法是：

- 把所有内容摆在一张很大的**世界画布**上，用世界坐标（像素）定位。A 概念在左上，B 概念在右下，细节藏在某个元素的内部，尺寸很小。
- **摄像机**就是作用在整张画布上的平移、缩放、旋转。推 = 放大，拉 = 缩小，摇和移 = 平移。
- 模板的 `src/components/Camera.tsx` 已经实现：给它一组关键帧 `{frame, x, y, zoom, rotate}`，它负责插值。`x, y` 是镜头对准的世界坐标，`zoom` 是缩放倍数。

```tsx
<Camera keys={[
  {frame: 0,   x: 960,  y: 540, zoom: 1},      // 全景
  {frame: 45,  x: 1400, y: 380, zoom: 3},      // 推到细节 A
  {frame: 120, x: 1400, y: 380, zoom: 3},      // 停住讲解
  {frame: 170, x: 600,  y: 800, zoom: 2.2},    // 移到 B
]}>
  <World />   {/* 用绝对定位把所有内容摆在世界坐标里 */}
</Camera>
```

**聚焦到一个元素**：已知元素的中心 `(cx, cy)` 和尺寸 `(w, h)`，让它占画面约 60%：
`zoom = min(画面宽 × 0.6 ÷ w, 画面高 × 0.6 ÷ h)`，镜头对准 `(cx, cy)`。

### 两个很多人不知道的关键点

**缩放要按对数插值。** 从 1 倍推到 100 倍，如果线性插值，前半段几乎看不出变化，后半段突然冲过头。按对数插值，整个推进过程的速度感才是均匀的。模板的 `Camera` 已经这样做了（`logZoom`）。

**远距离移动，先拉远再平移再推近。** 两个位置距离很远时，直接平移会让观众晕，也看不清自己在哪。学 Google Earth 的做法：先拉远到能同时看到起点和终点，再平移，再推近。实现上就是在两个关键帧之间插一个「中间全景」关键帧。

### 相机的生命感

- **手持漂移**：用噪声让镜头轻微漂移 1 到 3px、旋转 0.1 到 0.3 度。电影感、纪录片感的镜头加一点，画面立刻不「死」。
- **撞击震屏**：大字砸下、boom 的那一刻震 4 到 12px，在 6 到 12 帧内衰减到 0。只给最重要的一两个时刻用。`Camera` 组件支持 `shake` 参数。
- **视差**：把画面分成前景、中景、背景三层，镜头移动时三层移动速度不同（前景 1.3 倍、中景 1 倍、背景 0.5 倍），不用 3D 就有纵深感。

### 运镜的含义

| 运镜 | 观众感受到的 |
|---|---|
| 推 | 聚焦、进入、情绪加强、「注意这里」 |
| 拉 | 揭示全貌、交代环境、孤独、结束 |
| 平移 | 跟随、并列、「下一个」 |
| 上摇 | 仰望、敬畏、希望 |
| 下摇 | 落地、回到现实、沉重 |
| 倾斜（荷兰角） | 不安、失衡 |
| 固定 | 冷静、客观、观察 |
| 甩 | 能量、时间跳跃、快速切换 |
| 变焦虚实切换 | 注意力转移（前景清晰变成背景清晰） |

**运镜要有理由。** 不知道为什么要动的时候，就别动，固定镜头加微动就好。

## 2. 转场：每一种都有意思

| 转场 | 含义 | 适合 | 时长 |
|---|---|---|---|
| **硬切** | 干脆、节奏、力量 | 所有片子的默认值，卡在拍上 | 0 |
| 叠化 | 时间流逝、情绪过渡、回忆 | 抒情段落 | 15 到 30 帧 |
| 渐黑 / 渐白 | 一章结束 / 闪回、梦、揭示 | 段落之间 | 10 到 20 帧 |
| **匹配剪辑** | A 的形状、位置、动作变成 B | 电影感和科普都好用，最高级 | 0 到 15 帧 |
| **缩放穿越** | 深入一层 | 科普最爱：推进细胞，里面是分子 | 15 到 30 帧 |
| 甩镜加运动模糊 | 快速切到同级的下一个 | 快节奏、列表 | 8 到 12 帧 |
| 遮罩擦除 | 揭示、对比、翻页 | 编辑风格、前后对比 | 10 到 20 帧 |
| 形状转场 | 一个圆或色块放大盖满画面，再缩小露出新画面 | MG、宣传片 | 12 到 20 帧 |
| 故障切 | 失真、干扰、科技感 | 故障风、赛博风 | 3 到 8 帧 |
| 闪白 | 爆点、拍照、冲击 | 高潮，配 boom 或 hit | 2 到 6 帧 |

### 规则

- **一部片子只用 2 到 3 种转场**，硬切是默认值。什么都用，只会显得乱。
- **转场发生在拍上。** 转场的中点或者完成点对准重拍。
- **运动连续**：上一个镜头的物体向右飞出，下一个镜头的物体就从左边以同样的速度进来。方向不连续会让观众觉得「跳」。
- **视线连续**：上一个镜头结束时观众看的位置，就是下一个镜头开始时主体出现的位置。这样观众的眼睛不用重新找，切换会非常顺。
- **匹配剪辑优先**：能找到两个镜头之间的形状、颜色、动作联系时，优先用匹配剪辑。比如圆变成太阳，太阳变成眼睛，眼睛变成屏幕上的光点。
- **声音先行**：换段落时，下一段的声音提前 0.3 到 1 秒进来（J 切），转场会顺很多。

### 实现

**硬切**：两个镜头首尾相接即可（模板默认行为）。

**官方转场**：`@remotion/transitions` 的 `TransitionSeries`。注意转场会让两个镜头重叠，总时长 = 各镜头时长之和 − 各转场时长之和。

```tsx
import {TransitionSeries, linearTiming, springTiming} from '@remotion/transitions';
import {fade} from '@remotion/transitions/fade';
import {wipe} from '@remotion/transitions/wipe';

<TransitionSeries>
  <TransitionSeries.Sequence durationInFrames={90}><SceneA /></TransitionSeries.Sequence>
  <TransitionSeries.Transition presentation={fade()} timing={linearTiming({durationInFrames: 15})} />
  <TransitionSeries.Sequence durationInFrames={90}><SceneB /></TransitionSeries.Sequence>
  <TransitionSeries.Transition presentation={wipe({direction: 'from-left'})} timing={springTiming({config: {damping: 200}})} />
  <TransitionSeries.Sequence durationInFrames={90}><SceneC /></TransitionSeries.Sequence>
</TransitionSeries>
```

可选的效果还有 `slide`、`flip`、`clockWipe`（都在 `@remotion/transitions/<名字>` 下）。在模板里使用时，把需要转场的一组镜头放进同一个场景组件里，用 `TransitionSeries` 组织，再在 `storyboard.json` 里作为一个镜头。

**匹配剪辑和缩放穿越**：把两个镜头做进同一个组件，共用一个元素。比如缩放穿越：镜头一路推进某个元素，当它放大到铺满画面时，它的内部就是下一个场景；此时可以硬切到下一个镜头，只要两边在切点那一帧的画面完全一样，观众就看不出来。

**无缝切换的通用技巧**：在两种表现方式**看起来完全一样的那一帧**切换。这招适用于匹配剪辑、缩放穿越、2D 与 3D 互转（见 `3d.md`）。

## 3. 不同片型的运镜和转场习惯

| 片型 | 运镜 | 转场 |
|---|---|---|
| 电影感、情绪片 | 固定或极慢的推，手持漂移 | 硬切、匹配剪辑、渐黑，偶尔叠化 |
| 科普讲解 | 虚拟摄像机，推拉穿越，全景和细节交替 | 缩放穿越、平移、硬切 |
| PV、文字动效 | 基本固定，靠文字本身和排版在动，偶尔震屏 | 硬切闪切、闪白、色块擦除 |
| 产品宣传 | 在界面上推拉，2.5D 倾斜，慢而稳 | 硬切、形状转场、匹配剪辑 |
| MG 动态设计 | 相机少动，图形在变形 | 形状转场、形变、匹配剪辑 |
| 数据可视化 | 缓慢推近重点数据，拉远看全局 | 数据图形本身的变形过渡 |

科普片要保持**空间连续**：推进代表深入细节，拉远代表回到全局，平移代表去看同一层级的下一个。这样观众脑子里有一张「地图」，不会迷路。
