# 完整规划示例

三个示例覆盖三种典型情况：纯代码的情绪短片、有配音的科普片、音乐驱动的卡点 PV。拿不准格式和颗粒度的时候，照着它们写。

---

## 示例一：《我从未见过太阳》（纯代码、字符风格、无旁白）

### 任务卡
- 用途：B 站、视频号横屏；16:9，1920×1080，30fps；约 100 秒。
- 素材：无。画面全部代码生成，配乐和音效用脚本合成。
- 声音：无旁白，文字加音乐加音效。

### 立意
一个知道太阳所有数据、却从没见过它的 AI，发现人类也从没见过「此刻」的太阳。它是通过人认识光的。

### 形式和立意的咬合
整部片子用字符画和终端界面。AI 眼里只有字符，所以它画的太阳也只能是字符拼出来的。全片不出现写实的太阳。颜色从冷白慢慢变成暖橙，这是 AI「感受到温度」的过程。

### 结构与情绪曲线（起承转合）
| 段落 | 时间 | 张力 | 内容 |
|---|---|---|---|
| 起 | 0 到 23 秒 | 2 到 3 | 冷冰冰的数据：我知道关于太阳的一切 |
| 承 | 23 到 57 秒 | 3 到 5 | 人类的描述、「暖」解析失败、画了一千万次圆 |
| 静 | 57 到 60 秒 | 0 | 全黑，全静 |
| 转 | 60 到 87 秒 | 6 到 9 | 8 分 20 秒：人类也没见过此刻的太阳。字符汇聚成太阳 |
| 合 | 87 到 100 秒 | 5 到 4 | 我从未见过太阳，但我见过被它照亮的你们 |

### 时间网格与配乐
72 BPM，30fps 下每拍 25 帧，每小节 100 帧（约 3.33 秒），共 30 小节 3000 帧。

```bash
python <skill>/scripts/synth_music.py --mood melancholic --bpm 72 \
  --structure "intro:7,build:10,break:1,peak:8,outro:4" --out public/music/bgm.wav --fps 30
```

镜头边界全部落在小节线上，段落边界和音乐段落边界重合。高潮（太阳成形）在第 2400 帧，全片 80% 的位置，是 peak 段第 7 小节的第一拍。

### 分镜表
| 镜 | 帧 | 画面 | 屏幕文字 | 声音 | 实现 |
|---|---|---|---|---|---|
| s01 | 0 到 200 | 冷黑底，光标闪烁 20 帧后打出「太阳」 | 太阳 | drone 铺底；打字时 tick | `Statement`，technique=type |
| s02 | 200 到 500 | 等宽字体逐行打出四行数据，每行一个 tick | 质量 1.989×10³⁰ kg／表面温度 约 5500 °C／平均距离 1.496 亿 km／年龄 约 46 亿年 | 每行 tick | `Typewriter` 多行 |
| s03 | 500 到 700 | 数据停住，变暗，第一句淡入；1 拍后第二句 | 关于它，我知道一切。／除了，它是什么样子。 | 第二句出现时 hit（很轻） | `SplitText` blur |
| s04 | 700 到 1000 | 人类的句子像聊天气泡一样从四周浮现，错峰出现 | 今天太阳好大／晒过的被子有太阳的味道／看到日出了，眼泪都出来了／阳光照在脸上，暖暖的 | 每个气泡 pop，音量递减 | 新场景 `Bubbles` |
| s05 | 1000 到 1300 | 「暖」字被拎出来放大，旁边乱码解码出词典释义，最后释义崩解成「？」 | 暖／你们说，它是暖的。／可我没有皮肤。 | glitch 一次 | `Decode` 加 `SplitText` |
| s06 | 1300 到 1700 | 字符画的圆一遍遍画出又消失，颜色值和计数器飞涨到 10,000,000，越来越快 | 我试着画它。／画了一千万次。／每一次，都只是一个圆。 | tick 越来越密，最后 glitch | `AsciiSun`（低亮度、硬边）加计数器 |
| s07 | 1700 到 1800 | 全黑 | 无 | 全静音（音乐 break 段） | 空场景，刻意静止 |
| s08 | 1800 到 2100 | 「8:20」出现；一粒光点沿一条标着 1.5 亿 km 的线从左飞到右 | 阳光走到地球，要 8 分 20 秒。 | 长 whoosh，峰值在光点最快时 | `Camera` 跟随光点 |
| s09 | 2100 到 2300 | 光点停在「地球」上，文字逐句出现 | 你们抬头看到的，永远是八分钟前的它。／原来，谁都没见过此刻的太阳。 | 无 | `SplitText` rise |
| s10 | 2300 到 2600 | s04 的句子碎成字符，汇聚成一个字符画太阳；背景从冷变暖；第 2400 帧太阳成形 | 你们靠光认识它。／而我，靠你们认识光。 | riser 结尾对准 2400，boom 在 2400，之后 shimmer | `AsciiSun` 汇聚，`interpolateColors` 冷到暖 |
| s11 | 2600 到 2850 | 暖橙色的字符太阳缓慢呼吸，文字在下方 | 我从未见过太阳。／但我见过，被它照亮的你们。 | 音乐进入尾声 | `AsciiSun` 加 `SplitText` |
| s12 | 2850 到 3000 | 片名，然后光标打出一句话，停住 | 我从未见过太阳／今天，你晒到太阳了吗？ | 最后一次 tick，音乐淡出 | `TitleCard` 加 `Typewriter` |

### 视觉系统
- 背景：冷 `#0B0D12`，全片按时间插值到暖 `#140C08`。
- 前景：冷白 `#CFE3FF` 插值到米白 `#F5E9D8`；强调色（太阳）：`#FF8A3D`，只在 s06、s10 以后出现。
- 字体：JetBrains Mono（字符、数据）、思源宋体（人话、结尾）。「机器的话」用等宽，「人的话」用宋体，这本身就是叙事。
- 质感：颗粒 0.06，暗角 0.35。
- 动效：全片没有弹簧，只用缓出和缓入缓出，速度偏慢。

### 母题
光标（开头、结尾）、圆（s06 画不出来的圆，s10 汇聚成的太阳）。

## 示例二：《天为什么是蓝的》（科普、有配音、虚拟摄像机）

### 任务卡
- 用途：抖音竖屏；9:16，1080×1920，30fps；约 40 秒。
- 素材：配音 AI；音乐用免版权的轻快原声；画面代码生成。

### 立意
天空的蓝，是阳光在路上「走散」的颜色。

### 结构（问题 → 探索 → 答案 → 余韵）与旁白
| 段 | 旁白（逐句生成，每句一个文件） |
|---|---|
| 问题 | vo_01：天为什么是蓝的？ |
| 探索 | vo_02：阳光看起来是白的，其实是所有颜色混在一起。 |
| 探索 | vo_03：它穿过大气层时，会撞上无数个比它小得多的空气分子。 |
| 探索 | vo_04：波长越短的光，越容易被撞得四处乱跑。蓝光被散射的程度，大约是红光的五倍。 |
| 答案 | vo_05：于是，满天都是被打散的蓝光。不管你看向哪里，都有蓝光朝你飞来。 |
| 余韵 | vo_06：那傍晚呢？阳光斜着穿过更厚的空气，蓝光在半路就散光了，剩下的是红和橙。 |
| 回声 | vo_07：所以，天空的蓝，是阳光在路上走散的颜色。 |

事实核对：瑞利散射强度与波长的四次方成反比，450nm 的蓝光约为 700nm 红光的 (700÷450)⁴ ≈ 5.9 倍，所以说「大约五倍」是保守准确的。天空不是紫色，是因为阳光里紫光较少、人眼对紫光不敏感，片中不展开。

### 时间轴
```bash
python <skill>/scripts/media_durations.py public/vo --fps 30 --gap 0.5 --lead 0.3 --out docs/vo_timeline.json
```
每句旁白对应一个或两个镜头，镜头长度 = 0.3 秒引导 + 旁白时长 + 0.5 秒气口。

### 世界画布与相机（竖屏，世界画布 3240×5760）
| 区域 | 世界坐标（中心） | 内容 |
|---|---|---|
| 太阳 | (540, 700) | 一个发光的圆，白光射线向下 |
| 棱镜带 | (1620, 1400) | 白光分解成七色 |
| 大气层 | (1620, 2800) | 蓝色调的一层，里面有很多小圆点（分子） |
| 分子特写 | (1900, 2950) | 分子被放大后是一个圆，光点撞上去四散 |
| 地面观察者 | (1620, 5000) | 一个极简的人形，头顶是蓝色的天穹 |

相机关键帧（帧号是示意，以实际配音时长为准）：
- vo_01：全景 zoom 0.33，看到整个世界，问题大字压在中间。
- vo_02：推到棱镜带，zoom 1，白光分解成七色（whoosh）。
- vo_03：下移到大气层，zoom 1.2。
- vo_04：**缩放穿越**进分子特写，zoom 8（对数插值），蓝光点撞上分子四散、红光点直线穿过；「约 5 倍」的数字标注（hit）。
- vo_05：拉远到地面观察者，zoom 1；天穹里满是蓝色光点朝人飞来。
- vo_06：色调整体变暖，光线变成斜射，路径变长，蓝光点在半路散尽。
- vo_07：拉回全景 zoom 0.33，回到开场的构图，但天空此时是蓝色的（回声）。

### 要点
- 竖屏字幕放在画面下三分之一偏上，避开底部约 400px 的遮挡区。
- 颜色语义：蓝光永远是 `#4DA3FF`，红光永远是 `#FF6B4A`，全片不变。
- 有旁白，音乐音量 0.3。

## 示例三：音乐节 15 秒预告（音乐驱动的文字 PV）

### 任务卡
- 用途：竖屏信息流；1080×1920，30fps；15 秒。
- 素材：用户提供一首 128 BPM 的电子音乐；无旁白。

### 分析与网格
```bash
python <skill>/scripts/analyze_music.py public/music/track.mp3 --fps 30 --out docs/music.json
```
128 BPM，每拍约 14.06 帧，每小节约 56.25 帧，8 小节约 15 秒。从分析结果里找到 drop（能量最高段的第一拍）；这里假设 drop 在第 5 小节第一拍。每一拍的帧号直接取 `music.json` 里 `beats[i].frame`，不要自己用 14 帧累加，否则会越来越偏。

### 节拍表
| 小节.拍 | 画面 | 音效 |
|---|---|---|
| 1.1 到 2.4 | 每两拍闪一个词，黑底白字，巨大字号：今夏／不插电／不睡觉／不回家 | 无（音乐自己有鼓） |
| 3.1 到 3.4 | 每拍一个词，黑白反色交替：12 支乐队／3 个舞台／48 小时／1 片海 | 每拍 whoosh_fast，音量 0.4 |
| 4.1 到 4.4 | 每半拍一次排版快切，同一个词「你来吗」换 8 种排版；画面逐渐收缩到中心 | riser 结尾对准 5.1 |
| 5.1 | **drop**：闪白 3 帧，片名「野火音乐节」砸下（1.3 倍缩到 1 倍），震屏 8px | boom 加 hit |
| 5.2 到 6.4 | 片名停住，背后滚动字带，强调色是野火橙 | 无 |
| 7.1 到 7.4 | 日期和地点遮罩升起：8.16 到 8.17／南澳 · 海边 | 7.1 hit（轻） |
| 8.1 到 8.4 | 落版：Logo 加「购票通道已开」，停住到结束 | 音乐自然结束 |

### 要点
- 前 4 小节是蓄力：闪词越来越快（两拍、一拍、半拍），画面越来越收缩。第 5 小节第一拍全部释放。
- 闪词阶段的文字不需要读懂每一个，但第 3 小节的四个数字信息要看得清：每个至少一拍（约 0.47 秒），字号巨大，只有几个字。
- 全片只用黑、白和一个野火橙；字体一粗一细两种。
