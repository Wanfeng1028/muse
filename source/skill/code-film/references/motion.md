# 动画手艺：让东西「动得高级」

## 1. 唯一的原理

画面上每个属性都是帧号的函数：

```tsx
const frame = useCurrentFrame();
const {fps} = useVideoConfig();
const t = progress(frame, 10, 16);            // 第 10 帧开始，16 帧内从 0 到 1（带缓出）
const y = mix(60, 0, t);                       // 位置
const opacity = t;                             // 透明度
const s = springAt(frame, fps, 10, springs.gentle);  // 弹簧，从第 10 帧开始
```

`progress`、`mix`、`springAt`、`springs`、`ease` 都在模板的 `src/lib/motion.ts` 里。**不要**用 CSS transition、CSS animation、`requestAnimationFrame`、`setTimeout`、`Math.random()`。随机数用 Remotion 的 `random('some-seed')`，同一个种子永远得到同一个值。

## 2. 缓动曲线：动画质感的一半

| 名称 | 贝塞尔参数 | 用途 |
|---|---|---|
| `ease.out`（expo 缓出） | 0.16, 1, 0.3, 1 | **入场的默认值**：快速进来，慢慢停下，干脆又优雅 |
| `ease.soft`（柔和缓出） | 0.33, 1, 0.68, 1 | 大元素、慢节奏的入场 |
| `ease.inOut` | 0.65, 0, 0.35, 1 | 相机运动、从一个位置到另一个位置 |
| `ease.in` | 0.7, 0, 0.84, 0 | **退场**：慢慢起步，快速离开 |
| 线性 | 无 | 只用于持续的漂移、旋转、微动、滚动字带 |

**入场用缓出，退场用缓入，移动用缓入缓出。** 全片统一用这几条曲线，不要每个元素一种。

## 3. 弹簧：给物体「重量」

| 预设 | 参数 | 感觉 |
|---|---|---|
| `springs.smooth` | damping 200 | 没有回弹，平滑到位。最常用，最安全 |
| `springs.gentle` | damping 20, stiffness 120 | 很轻微的回弹，有生命感 |
| `springs.bouncy` | damping 10, stiffness 140, mass 0.8 | 明显的弹跳，活泼、可爱。慎用 |
| `springs.heavy` | damping 30, stiffness 80, mass 2 | 沉重、缓慢，适合大物体落地 |

回弹太多会显得幼稚。高级感的片子，回弹幅度控制在 3% 到 8% 以内。

## 4. 让动画「像样」的动画原则

- **预备动作**：大动作之前先往反方向动一点。比如按钮被按下前先微微放大，文字飞出前先往后缩一点。
- **跟随与重叠**：一个物体的各个部分不要同时停下。标题落定后，副标题晚 3 帧落定；卡片停下后，里面的内容再晃一下才停。
- **错峰**：一组元素依次入场，间隔 2 到 6 帧。整组的总错峰时长不要超过 20 到 24 帧，否则最后一个等得太久。
- **弧线运动**：有机的东西沿弧线运动，不走直线。机械的、UI 的东西走直线。
- **挤压与拉伸**：快速运动时沿运动方向拉长一点、垂直方向压扁一点，落地时反过来。卡通、活泼的风格才用。
- **主次**：同一时刻只有一个主角在做大动作，其他元素要么不动，要么只做很小的动作。
- **夸张要统一**：要么全片都很克制，要么全片都很夸张，不要混。

## 5. 常用入场配方

| 配方 | 做法 | 气质 |
|---|---|---|
| 上浮淡入 | 位移 20 到 60px 加透明度 | 通用、安全 |
| 遮罩升起 | 外层 `overflow: hidden`，内层从 100% 位移到 0 | **高级感最强的文字入场** |
| 模糊入场 | `filter: blur(12px→0)` 加透明度，可以再加 1.05 到 1 的缩放 | 电影感、柔和、梦幻 |
| 缩放入场 | 0.9 到 1 加透明度（不要从 0 开始放大） | 卡片、图片 |
| 裁切揭示 | `clip-path: inset(0 100% 0 0)` 到 `inset(0 0 0 0)` | 干脆、编辑感 |
| 描边绘制 | SVG 的 `strokeDasharray` 和 `strokeDashoffset`，用 `@remotion/paths` 的 `evolvePath` | 线条、图表、手绘感 |
| 形状变形 | `@remotion/paths` 的 `interpolatePath`，两条路径的点数结构相近效果最好 | 一个图形变成另一个，匹配剪辑 |
| 色块擦出 | 一个色块扫过，扫过的地方露出内容 | 编辑感、PV |

退场就是入场倒过来，但更短、用缓入。

## 6. 微动：让停留的画面活着

- 整体缓慢放大 1.00 到 1.03（线性，贯穿整个停留阶段）。
- 用 `@remotion/noise` 的 `noise2D(seed, frame * 0.01, 0)` 让元素极轻微地漂移 1 到 3px。
- 背景的光斑、渐变、粒子缓慢流动。
- 胶片颗粒本身就是一种微动（模板的 `Texture` 组件）。

## 7. 粒子和生成类动画

- 每个粒子的属性由 `random(\`p-${i}-x\`)` 这类种子算出初始值，再由帧号算出当前位置。**不要**逐帧累加状态，要写成「初始值 + 速度 × 时间」这样的纯函数。
- 汇聚效果：每个粒子有一个起点和一个终点（比如文字轮廓上的点），用带缓动的进度在两者之间插值，再给每个粒子不同的延迟。
- 有机的流动用噪声场：粒子位置 = 起点 + 噪声(粒子编号, 时间) × 幅度。
- 粒子超过几百个时，用 `<canvas>` 画，不要生成几百个 DOM 元素。

## 8. 运动模糊

**为什么需要**：代码渲染的每一帧都是瞬间定格，快速运动的物体会像在「闪现」。真实摄像机的快门会记录一小段时间内的运动，形成拖影。

**三种做法，从准到省：**

1. **子帧采样（最真实）**：`@remotion/motion-blur` 的 `CameraMotionBlur`。

   ```tsx
   <CameraMotionBlur shutterAngle={180} samples={8}>
     <FastMovingThing />
   </CameraMotionBlur>
   ```
   快门角度 180 是电影标准。samples 越大越顺滑，但渲染时间也成倍增加。只包住需要的镜头，不要包全片。

2. **高帧率渲染再混合（后期做）**：按 60 或 120fps 渲染，再用 FFmpeg 把相邻帧混合、降回 30fps：
   ```bash
   ffmpeg -i in_120fps.mp4 -vf "tmix=frames=2,fps=30" out.mp4
   ```
   `frames=2` 大约相当于 180 度快门，`frames=4` 相当于 360 度。

3. **假模糊（最省）**：用这一帧和上一帧的位置算出速度，顺着运动方向加模糊或拉伸。速度越快越模糊，停下来就清晰。
   ```tsx
   const v = Math.abs(x(frame) - x(frame - 1));      // 像素每帧
   const blur = Math.min(v * 0.35, 24);
   // 水平运动：用 SVG 的 feGaussianBlur stdDeviation={`${blur} 0`} 做单方向模糊
   // 或者简单地沿运动方向拉伸：transform: scaleX(1 + v * 0.004)
   ```

**什么时候用**：快速飞过的物体、甩镜头、快速推拉、快速旋转。**要读的文字在停下来之后必须完全清晰。** 慢节奏的片子基本用不上。

## 9. 循环动画

无缝循环的关键：所有周期性运动的周期都能整除总时长。比如总长 120 帧，旋转就用 `frame / 120 * 360`，正弦波就用 `Math.sin(frame / 120 * Math.PI * 2 * n)`（n 是整数）。噪声循环可以在圆周上采样：`noise3D(seed, cos(θ) * r, sin(θ) * r, 0)`，其中 θ 随帧号走完一整圈。

## 10. 定格感（stop motion）

拼贴、手绘、纸艺风格常用「一拍二」甚至「一拍三」：画面每 2 到 3 帧才更新一次。

```tsx
const f = stepped(frame, 2);   // 0,0,2,2,4,4……
```

再给每次更新加一点随机的微小位移和旋转（用 `random(\`jitter-${f}\`)`），手工感立刻出来。

## 11. 不要这样做

- 线性的位移动画（除了持续漂移）。
- 从 `scale(0)` 放大入场（太卡通、太廉价），从 0.85 到 0.95 开始就够了。
- 所有元素同时入场、同时退场。
- 每个元素都用不同的曲线和时长。
- 大量元素同时加 `filter: blur`，渲染会非常慢。
- 在动画里读 DOM 尺寸（`getBoundingClientRect`），渲染时不稳定。需要文字尺寸就用固定字号估算，或者用 `@remotion/layout-utils` 的 `measureText`。
