# 风格库

## 怎么用这份文档

1. **风格服务于立意。** 先问「这个故事用什么风格讲最对」，再来这里找做法。风格和立意咬合，观众会觉得「就该这样」。
2. **一个主风格，最多再加一个点缀风格。** 比如「极简 + 一点胶片质感」「拼贴 + 一点故障」。三种以上混在一起就是乱。
3. 每种风格都按同样的格式写：**气质与适用 / 视觉 / 动效 / 转场 / 声音 / 实现要点 / 避坑**。选定之后，把视觉和动效部分翻译进 `theme.ts`。

### 题材到风格的快速对照

| 题材 | 可以先考虑 |
|---|---|
| 情绪短片、诗意 | 电影感、极简、字符、东方 |
| 科普讲解 | 扁平 MG、极简、数据新闻、等距 |
| 产品、App、科技 | 发布会、极简、瑞士网格、3D |
| PV、音乐、潮流 | PV 文字、野兽派、拼贴、故障、霓虹 |
| 品牌、文化、历史 | 杂志编辑、东方、复古、纸艺 |
| AI、黑客、编程 | 字符、故障、终端、霓虹 |
| 儿童、轻松、趣味 | 扁平 MG、手绘、纸艺、粘土 3D |
| 数据、报告、年度总结 | 数据新闻、瑞士网格、发布会 |

## 1. 极简

- **气质与适用**：克制、安静、高级、聚焦。情绪片、高端产品、观点表达。
- **视觉**：大面积留白，一两个颜色，一种字体，细字重或极粗字重二选一。每屏只有一个元素。
- **动效**：慢，缓出曲线，几乎没有回弹。运动幅度小，靠透明度、遮罩、缓慢的位移。
- **转场**：硬切、渐黑、匹配剪辑。
- **声音**：钢琴、氛围音乐，音效极少且轻。静默很重要。
- **实现要点**：每个镜头只做一件事，停留时间要足。质感只用非常轻的颗粒。
- **避坑**：极简不是空洞。每一屏都要有值得看的东西：一句好文案、一个精确的构图、一个意外的比例。

## 2. 瑞士国际主义 / 网格

- **气质与适用**：理性、秩序、信息清晰、现代。数据、报告、品牌、建筑、设计类。
- **视觉**：严格的网格，无衬线字体（粗细对比强烈），左对齐，大号数字，一个醒目的强调色（常见红色），细线分隔，编号。
- **动效**：元素沿网格线滑入，裁切揭示，线条生长，数字滚动。运动方向只有水平和垂直。
- **转场**：硬切、网格内的擦除、色块推移。
- **声音**：极简电子、打击乐，干净利落的 click 和 tick。
- **实现要点**：先在 `theme.ts` 里定义网格（栏数、栏宽、间距），所有元素的坐标都由网格计算。
- **避坑**：不要居中，不要装饰，不要斜线。

## 3. 拼贴

- **气质与适用**：手工感、趣味、复古、叛逆、多元。文化、音乐、潮流、历史、个人故事。
- **视觉**：剪下来的照片和图形（边缘不规则、带白边或撕纸边），纸张纹理，网点印刷感，胶带、订书钉、手写字，大小比例夸张，元素互相叠压，有明显的硬阴影。
- **动效**：**定格感**，每 2 到 3 帧才更新一次（`stepped(frame, 2)`），每次更新带一点随机的微小位移和旋转（0.5 到 2 度）。元素「啪」地贴上来，而不是滑进来。
- **转场**：新的纸片盖住画面、撕纸揭开、整页翻走。
- **声音**：纸张的沙沙声、剪刀、贴纸的啪嗒声，配 lo-fi 或复古音乐。
- **实现要点**：
  - 撕纸边：用一个带噪声的多边形做 `clip-path: polygon(...)`，顶点坐标用 `random()` 固定下来。
  - 白边：外层加 6 到 12px 的米白色 padding，再加硬阴影 `box-shadow: 6px 8px 0 rgba(0,0,0,0.25)`。
  - 网点照片：图片加 `grayscale` 和 `contrast`，上面叠一层圆点图案，`multiply` 混合。
  - 素材可以来自生图 AI（要求「白底、单独的物体」）或纯代码图形。
- **避坑**：乱中要有序。先定一个主视觉焦点和阅读顺序，再往周围堆元素。

## 4. 电影感

- **气质与适用**：沉浸、叙事、情绪浓度高。情绪短片、品牌故事、预告片。
- **视觉**：2.39:1 黑边（或者直接用宽画幅），24fps，调色统一（青橙、低饱和、暖褪色任选一种），衬线字体或细无衬线，字很小、很克制，暗角，颗粒，漏光。
- **动效**：极慢的推镜，手持漂移，模糊入场，长时间的停留。几乎没有弹性动画。
- **转场**：硬切为主，匹配剪辑、渐黑、J 切和 L 切。
- **声音**：配乐的动态范围大（安静处很安静），环境音，低频重击（boom）只在一两个时刻出现。
- **实现要点**：分镜要有景别变化（远、中、近、特写的对应物：全景、局部、极近的细节）。字幕放下方黑边里或画面下三分之一。
- **避坑**：不要花哨的文字动画，不要满屏的信息，不要欢快的转场。

## 5. PV 文字 / 动态排版

- **气质与适用**：节奏强、信息密、潮、燃。音乐 PV、宣传片、活动预告、个人介绍。
- **视觉**：大字，黑白加一个强调色，粗体和细体混排，中西文混排，装饰性小字（日期、编号、坐标、REC），条纹、准星、边框。
- **动效**：卡点闪词，排版快切，大字压屏，震屏，闪白，描边和实心切换，滚动字带。
- **转场**：闪切、闪白、色块擦除、黑白反色。
- **声音**：强节奏的音乐（电子、摇滚、J-pop），音效干脆（hit、glitch、whoosh_fast）。
- **实现要点**：音乐先行，按拍子排布每一个词。见 `typography.md` 第 4 节。
- **避坑**：闪得太久会累。快闪 4 到 8 拍后，要停在一句话上。

## 6. 故障 / 赛博

- **气质与适用**：科技、失控、数字世界、叛逆、紧张。AI、网络安全、游戏、电子音乐。
- **视觉**：RGB 色差分离，画面切片错位，扫描线，像素块，噪点，数字雨，高对比的青和品红。
- **动效**：切片横向错位（把画面切成若干横条，每条随机偏移），RGB 通道分别偏移，瞬间的反色，抖动。故障只持续 2 到 8 帧，然后恢复。
- **转场**：故障切：两个画面之间插入几帧故障。
- **声音**：glitch、数字噪声、比特压缩的音效、电子音乐。
- **实现要点**：故障的发生时刻和强度都用 `random(\`glitch-${frame}\`)` 决定，保证可重复。切片用多份画面副本加 `clip-path: inset(...)` 和 `translateX`。
- **避坑**：故障是标点，不是常态。一直故障，观众会累，也会觉得廉价。

## 7. 字符 / 终端 / ASCII

- **气质与适用**：AI、代码、复古电脑、极客、极简科技。
- **视觉**：等宽字体，单色（绿、琥珀、白）或只加一个强调色，黑底，光标，字符画。
- **动效**：打字机，乱码解码，字符画的亮度场随时间变化，数字雨，字符溶解。
- **转场**：清屏、光标闪烁后硬切、字符溶解、从字符画过渡到真实画面。
- **声音**：键盘声、tick、电流底噪、8bit 或极简电子音乐。
- **实现要点**：见 `typography.md` 第 5 节和模板的 `Ascii`、`Typewriter`、`Decode` 组件。
- **避坑**：字符太小、列数太多时就看不出是字符了。字符画要保留「字符感」。

## 8. 手绘 / 涂鸦

- **气质与适用**：亲切、轻松、手工、教育。科普、儿童、个人故事、白板讲解。
- **视觉**：不规则的线条，手写字体（霞鹜文楷等），纸张纹理，有限的马克笔配色，涂鸦式的箭头和圈画。
- **动效**：描边绘制（线条一笔一笔画出来），**线条抖动**（每 2 到 3 帧轻微变形一次，模拟手绘动画的「颤动」），定格感。
- **转场**：擦掉重画、翻页、镜头移到白板的另一块区域。
- **声音**：笔在纸上的摩擦声、轻快的原声乐器。
- **实现要点**：线条抖动可以用 SVG 的 `feTurbulence` 加 `feDisplacementMap`，每 2 帧换一次种子，位移强度 2 到 4。描边绘制用 `@remotion/paths` 的 `evolvePath`。
- **避坑**：抖动幅度要小，太大就变成故障了。

## 9. 扁平 MG

- **气质与适用**：清晰、友好、活泼。科普讲解、产品功能说明、流程演示、企业宣传。
- **视觉**：几何图形、扁平色块、简化的图标和人物，4 到 6 个颜色的和谐配色，圆角。
- **动效**：弹簧动画（`springs.gentle` 或 `bouncy`），形状变形，挤压拉伸，元素之间的连锁反应，路径动画。
- **转场**：形状放大盖满画面、形变过渡、镜头移动。
- **声音**：轻快的音乐，pop、whoosh、click，音效可以多一些、俏皮一些。
- **实现要点**：图形尽量用 SVG 组件自己画，方便变形和描边。一个动作引发下一个动作（因果链），比元素各自入场更有叙事性。
- **避坑**：颜色太多、弹跳太多、元素太多，会变成幼儿园风格。

## 10. 等距（Isometric）

- **气质与适用**：系统感、全局观、微缩世界。流程、架构、城市、产品生态、数据中心。
- **视觉**：30 度等距投影的立方体、建筑、设备，统一的光照（三个面三种明度），柔和的配色。
- **动效**：方块从下往上升起，线路流动，镜头在等距世界里平移和缩放。
- **转场**：镜头平移到另一个区域，拉远看全局。
- **声音**：轻电子、氛围音乐。
- **实现要点**：2D 做法是容器加 `transform: rotateX(60deg) rotateZ(-45deg)`；3D 做法是正交相机加旋转（见 `3d.md`）。
- **避坑**：所有物体的光照方向和投影角度必须一致。

## 11. 3D（低多边形、粘土、写实材质）

- **气质与适用**：体积感、质感、产品展示、空间叙事。
- **视觉**：低多边形（硬边、平面着色）、粘土风（高粗糙度、柔和的粉彩色、圆润的形状）、玻璃和金属（需要环境光照）。
- **动效**：相机环绕、物体旋转展示、爆炸分解视图、挤出成型。
- **转场**：相机穿越、2D 和 3D 互转（见 `3d.md`）。
- **实现要点**：见 `3d.md`。
- **避坑**：3D 渲染慢，先用低分辨率确认镜头。光照不好的 3D 比 2D 难看得多。

## 12. 复古（VHS、80 年代、像素）

- **气质与适用**：怀旧、趣味、游戏感。
- **视觉**：VHS：扫描线、色彩溢出、跟踪错误、时间码；80 年代合成波：紫粉渐变、网格地面、夕阳、霓虹字；像素：低分辨率、有限色板、像素字体。
- **动效**：像素风用阶跃动画（`stepped`），没有平滑插值；VHS 有横向抖动和偶尔的跟踪错误。
- **转场**：VHS 的倒带、雪花屏、像素化溶解。
- **声音**：合成器、8bit 芯片音乐、磁带噪声。
- **实现要点**：像素风先在小画布上画（比如 320×180），再用 `imageRendering: 'pixelated'` 放大到全尺寸。
- **避坑**：像素风要所有元素都在同一个像素网格上，混入平滑的元素会很怪。

## 13. 纸艺 / 剪纸

- **气质与适用**：温暖、手工、童话、层次感。故事、儿童、节日、文化。
- **视觉**：多层纸片叠加，每层有柔和的投影，纸张纹理，有限的配色，剪影。
- **动效**：层与层的视差，纸片翻起、折叠、弹出（立体书），定格感。
- **转场**：翻页、一层纸片推过来盖住画面。
- **声音**：纸张声、音乐盒、原声乐器。
- **实现要点**：每层是一个带 `drop-shadow` 的 SVG 形状，阴影偏移随层级增加。镜头移动时各层速度不同。
- **避坑**：阴影方向统一，层数不宜超过 5 到 6 层。

## 14. 数据新闻

- **气质与适用**：可信、清晰、有洞察。数据故事、报告、年度总结、社会议题。
- **视觉**：浅色或深色干净背景，衬线标题配无衬线正文，图表极简（去掉多余的网格线和边框），直接在数据上标注，一个强调色标出重点数据，其余用灰色。
- **动效**：图表逐步生长，重点数据被高亮、其他数据变灰，镜头推近关键数据点，数字滚动，一个图表变形成另一个图表。
- **转场**：图表本身的变形过渡，镜头移动。
- **声音**：克制的配乐，数字跳动时轻微的 tick。
- **实现要点**：数据先算好，存成 JSON；比例尺自己写（线性映射就是 `interpolate`）。**一张图只讲一个结论**，把结论写成标题。
- **避坑**：不要 3D 饼图，不要彩虹配色，不要一次展示所有数据。

## 15. 野兽派 / 粗野主义

- **气质与适用**：冲击力、反叛、态度、潮流。时尚、音乐、艺术、年轻品牌。
- **视觉**：巨大的粗体字，撞色或纯黑白，粗边框，系统字体般的「原始感」，故意的不对齐和溢出画面。
- **动效**：生硬、快速、没有缓动（或者极强的缓动），闪切，突然的巨大变化。
- **转场**：硬切、闪切。
- **声音**：强烈的节奏，噪音感的音效。
- **避坑**：野兽派是有意识的「打破规则」，需要非常强的排版功底。拿不准的时候不要选它。

## 16. 东方 / 国风

- **气质与适用**：意境、留白、诗意、文化。传统文化、诗词、茶、节气、国潮。
- **视觉**：宣纸纹理，水墨（可以用模糊加阈值模拟晕染），竖排文字，印章红作为唯一强调色，大量留白，衬线字体或书法字体，山水、云纹等意象。
- **动效**：慢，像墨在水里晕开（模糊半径和透明度同时变化），笔画书写，云雾缓慢飘动，镜头像展开卷轴一样平移。
- **转场**：墨晕、渐隐、卷轴展开、竖向的推移。
- **声音**：古琴、箫、琵琶、自然声（风、水、鸟），节奏慢。
- **实现要点**：笔画书写见 `typography.md`。水墨晕开：元素加大的模糊，再用 SVG `feColorMatrix` 提高对比度形成边缘。
- **避坑**：不要堆砌元素（祥云、灯笼、中国结全上），留白才是东方美学的核心。

## 17. 霓虹

- **气质与适用**：夜、都市、派对、电子、赛博。
- **视觉**：深色背景，发光的线条和文字（多层辉光），品红、青、紫、粉。
- **动效**：霓虹灯闪烁启动（几次不规则的明灭后常亮），光线沿路径流动，辉光呼吸。
- **转场**：灯灭再亮、光线扫过。
- **声音**：合成器、电子音乐、电流嗡嗡声。
- **实现要点**：辉光用两到三层 `text-shadow` 或 `drop-shadow`，半径依次增大（比如 4px、16px、40px），颜色相同、透明度递减。
- **避坑**：发光的东西不要太多，否则满屏都亮等于都不亮。

## 18. 发布会 / Keynote

- **气质与适用**：隆重、自信、高端、清晰。产品发布、年度总结、品牌大事件。
- **视觉**：深色渐变背景，巨大的数字和短语，产品主视觉居中，一句话一屏，高质量的产品图或截图。
- **动效**：平滑、稳重，模糊入场，缓慢推近产品，数字滚动，关键数字出现时的光效。
- **转场**：渐黑、叠化、匹配剪辑（产品从一个角度过渡到另一个角度）。
- **声音**：大气的电子或管弦配乐，boom 配合关键揭示。
- **实现要点**：一屏只讲一个卖点，用一个数字或一个短语。产品截图用虚拟摄像机展示细节。
- **避坑**：信息不要多，形容词不要多。

## 19. 渐变流体 / 抽象生成

- **气质与适用**：氛围、情绪、品牌背景、音乐可视化、无限循环的装饰视频。
- **视觉**：大面积柔和的网格渐变（多个模糊的彩色光斑叠加），流动的形状，噪声纹理。
- **动效**：光斑沿噪声轨迹缓慢漂移，颜色缓慢变化，随音乐能量呼吸。
- **转场**：颜色整体变化，叠化。
- **声音**：氛围音乐、Lo-fi。
- **实现要点**：几个大圆形 `div`，`filter: blur(80px 以上)`，位置由 `noise2D` 驱动。大模糊很耗性能，可以在较小的画布上画好再放大。
- **避坑**：颜色要选和谐的相邻色，饱和度不宜过高。

## 风格混搭规则

- 一个主风格定义 80% 的视觉，点缀风格只负责 20%（比如只在转场或高潮时出现）。
- 点缀风格要和主风格有共同点：同样的颜色、同样的质感、或者同样的节奏。
- 在 `theme.ts` 里只保留一套颜色和字体，点缀风格也必须用这套。
