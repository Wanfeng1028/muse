# 分镜套路（都来自实际出过片的视频，可以直接改用）

所有组件来自 `template/src/ui.tsx`：`Card` `Tab` `Pill` `Stamp` `Check` `Coin` `Appear` `pop()` `lin()` `useBeat()`。
示例实现见 `template/src/scenes.tsx`（爆仓 vs 止损），注释里说明了每个场景对应哪句口播。

| 套路 | 适合讲什么 | 做法 |
|---|---|---|
| **双卡对比 + 结果盖章** | 钩子：同样条件，两种做法，不同结果 | 上方一条走势线跌到强平线；下方左右两张持仓卡，数字随进度计数；在结果那句话落下 `Stamp`（「多亏 70U」「杠杆现货先爆了」） |
| **温度计 / 风险率标尺** | 保证金、风险率、强平线 | 竖向填充条或横向渐变标尺，用 `lin()` 驱动数值下降，碰线时闪红并盖「强平」；资金飞向「清算费 / 保险基金」盒子 |
| **公式块逐项点亮** | 「多亏 = 仓位价值 × 维持保证金率 − 手续费」 | 每一项是一个带边框的 span，念到哪一项就点亮哪一项 |
| **阶梯柱状图** | 5x/10x/20x/100x、每 8h / 每天 / 每年这类递进 | 每行：标签 + 增长条 + 数字，逐行在对应句出现，最大那行用红色，最后盖总结章 |
| **流程链** | 下单路径、资金流向（你 → 币安 → 券商 → 真股票） | 胶囊 + 渐变连线，用进度依次点亮 |
| **时段条** | 交易时间（盘前 / 盘中 / 盘后 / 夜盘） | 按时长比例分宽，「部分可用」的段用虚线框 |
| **周历高亮** | 7×24、周末也能交易 | 周一到周日七个格子依次点亮，周六日用强调色 |
| **对比表逐行点亮** | 优劣对比、一张表看懂 | 表头 + N 行，念到的行高亮、其余变暗；最后定格整表，方便观众截图 |
| **对比表逐列框选** | 「长期选 A，短线选 B」 | 对比表上加一个框，跟着口播移到对应列，下方弹出「→ A」结论卡 |
| **场景卡 2×2** | 「记住四个场景」 | 四张卡依次弹出，结论在对应句出现；最后一张「都别碰」盖红章 |
| **价格标尺分层** | 开仓价 / 正常止损 / 兜底止损 / 强平价 | 竖向标尺加多条水平线，每条线标注名字，配 ✓「走不到强平线」 |
| **AI 对话框** | AI 类教学（把文件发给 AI、提示词） | 文件卡飞入，提示词逐句点亮，关键维度用琥珀色标签 |
| **散开 → 收拢** | 结尾的「何必东奔西走，X 全都有」 | 三个标签先散开并旋转，再收拢到品牌 Logo 下 |

## 写法要点
- 一屏的信息量：一张主卡加 2–3 个辅助元素；第二阶段可以先淡出旧内容再换新内容（参考示例里的 `Risk` / `Why`）。
- 数字统一用 MONO 字体；涨绿跌红；风险用红边卡加 ⚠。
- 画面上的估算或口径说明，用 21–22px 灰色小字放在 y≈670 的脚注位置。
- 示意数据要标「示意」或「演示数据为虚构」；虚构的交易记录可以用脚本生成，再真实统计，保证画面数字能复现。
