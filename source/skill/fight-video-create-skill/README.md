# 战斗设计与动作分镜

给你的 AI 助手装上一套「打戏创作」能力：一句想法进去，出来的是有来龙去脉的战斗剧情、招招有据的动作设计，以及可以直接开拍的镜头分镜。

## 它能帮你做什么

- **战斗剧情**：谁和谁打、为什么打、怎么收场，包括转折与情绪落点。
- **动作设计**：招式、连招、攻防节奏、身体走位与受力反馈，动作不断链。
- **空间调度**：双方的走位、距离变化，以及场地和环境的利用。
- **动作分镜**：按镜头逐段拆解，标明每段画面内容与节奏。
- **特殊技能设计**：带触发条件的战斗技能，并给出使用边界与克制关系。
- **风格参照**：武侠、仙侠、玄幻、军阵、擂台、街头等多种场景与成熟案例。

它专注于战斗设计和分镜本身。AI 绘画与视频生成的提示词它不写，资料的收集整理也不归它管。

## 安装

直接把压缩包丢给智能体，让它安装这个技能就行。

开箱即用，不需要额外安装或配置任何东西。如果此前装过同名技能，保留一份即可。

## 怎么用

装好之后直接用大白话提需求就行。

> 帮我设计一段双刀对长枪的打戏。雨夜屋顶，30 秒，女方最后赢。

**说得越具体，结果越贴合。** 下面这几项讲清楚，出来的效果最好：

| 要素 | 举例 |
| --- | --- |
| 人物与关系 | 师姐对师弟、主将对刺客、三人围攻 |
| 武器与能力 | 双唐刀、长枪、水系法术 |
| 场地环境 | 雨夜屋顶、军阵中央、窄巷、悬崖边 |
| 想要的结果 | 谁赢、怎么赢、最想突出的一刻 |
| 时长与画幅 | 15 秒竖屏、60 秒横屏 |
| 结尾画面 | 收刀、雨停、镜头拉远 |

一开始想不到这么全也没关系，说个大概就行。它会先把细节补起来，再一项项和你确认。

## 使用小贴士

- 它每次只推进一个方案，会先讲清「为什么这么设计」，你点头之后才继续。
- 想看看某个技能实际打出来什么样，可以让它调出对应的效果动图。
- 不满意就直接提：「攻击太单调」「节奏再快一点」「换个场景」，它会重新匹配。
- 越早锁定关键设定（人物、武器、胜负），后面越不容易跑偏。
- 它会说明用了哪些资料、哪些属于全新设计，方便你判断和修改。
