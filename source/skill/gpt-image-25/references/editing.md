# 참조와 정밀 편집

## 입력 역할

실제 입력 순서 또는 사용자 라벨을 유지해 역할을 명시한다. 예: 이미지 1은 편집할 인물 원본, 이미지 2는 적용할 재킷, 이미지 3은 색감 참고. 이미지 3의 사람이나 물체까지 복제하지 않도록 적용 범위를 설명한다. 파일명만으로 내용이나 정체성을 추정하지 않는다.

참조 합성에는 가져올 요소, 배치 위치, 크기, 원근, 가림 관계와 조명 통합을 쓴다. 어떤 이미지가 장면의 기준인지 명확히 한다. 얼굴·신체·제품 형상·라벨·구도 등 실제로 중요한 항목을 보존 대상으로 지정한다.

## 변경과 보존

“X만 변경”과 “Y는 유지”를 분리한다. 국소 수정이면 주변 사물, 카메라 각도, 색온도, 대비·채도, 기존 도표 화살표 등 영향을 받기 쉬운 관련 항목을 구체화한다. 장면마다 무관한 긴 보존 목록을 덧붙이지 않는다.

| 작업 | 변경 | 보존·검수 |
| --- | --- | --- |
| 의상 교체 | 지정 의상, 몸에 맞는 주름과 음영 | 얼굴·체형·자세·머리·배경, 자연스러운 착용 |
| 물체 제거 | 지정 물체와 그 자리에 필요한 배경 복원 | 주변 물체·인물·구도, 손이나 배경의 파손 |
| 가구 교체 | 선택 가구의 모양·재질 | 방과 카메라, 주변 조명; 새 가구의 접촉 그림자는 자연스럽게 통합 |
| 이미지 속 번역 | 원래 글자를 번역문으로 대체 | 레이아웃·그림·연결 관계; 번역 누락·원문 잔존 확인 |
| 스타일 이전 | 참조의 매체·팔레트·질감 | 사용자가 요구한 새 주제와 구도 |
| 스케치 실사화 | 재질·조명·사실감 | 원래 배치·비례·원근, 임의 물체나 문구 추가 방지 |
| 제품 누끼 | 배경 제거 | 제품 형상·라벨·경계, 실제 알파 |

투명 출력 설정은 [설정 안내](settings.md)를 함께 적용한다. 텍스트 길이가 달라 레이아웃과 가독성이 충돌하면 둘 다 완벽히 보장하지 말고 글자 크기·줄바꿈 등 가능한 조정을 제시한다.

## 연속 편집과 캐릭터

직전 결과를 다음 입력으로 실제 전달한다. 도구가 이전 결과를 자동으로 기억한다고 가정하지 않는다. 한 번에 한 가지 수정 목적을 주고 핵심 보존 조건을 다시 쓴다. 새 장면마다 캐릭터 기준 이미지와 얼굴·의상·비례·색상 등 핵심 특징을 재사용한다.

누적 편집으로 정체성이나 라벨이 흐려지면 최근의 적합한 결과 또는 원본으로 돌아가 필요한 변경을 다시 적용한다. 오류가 있는 결과를 계속 기준 이미지로 삼지 않는다.

## 마스크와 픽셀 보존

마스크가 필요한 국소 편집은 사용하는 도구의 마스크 지원 여부와 [현재 마스크 API 문서](https://developers.openai.com/api/docs/guides/image-generation#edit-an-image-using-a-mask)를 확인한다. 문서에 없는 마스크 크기·형식·적용 규칙을 추정하지 않는다.

“나머지를 유지”는 모델에 주는 요구이며 픽셀 동일성 보증이 아니다. 특정 영역의 픽셀이 정확히 같아야 한다면 승인된 수정 영역을 원본 위에 합성하는 작업이 필요하다. 해당 편집 기능과 허용 범위가 있을 때만 수행하고, 결과 파일의 보존 영역을 비교한다. 생성만 한 결과를 픽셀 검증 완료라고 보고하지 않는다.
