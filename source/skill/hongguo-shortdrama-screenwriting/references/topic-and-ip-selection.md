# 选题与 IP 判断（课程 02 + 课程 10 微创新）

> 来源：白羊工作室·刘扬《揭秘题材与 IP 选择的底层逻辑》（红果《短剧编剧第一课》02 期）、燕北《网文作者转型实战指南》（10 期）。
> 用途：**选题门**的权威文件。立项第一步读本文件；判不过不许动笔。

---

## 一、 第一原则

> **题材本身没有高下与优劣之分。决定其生命力的，是情绪的普适性和创意的新鲜度。**

市场三阶段演进（用来判断一个题材处在什么生命周期）：

| 阶段 | 特征 | 拼什么 |
|---|---|---|
| 强情绪驱动（早期） | 脱胎于小说投流，贴近生活、节奏紧凑、人设鲜明 | 情绪张力 |
| 微创新过渡 | 单一模板泛滥，开始改身份、加「预知未来/特殊能力」 | 新鲜感 |
| 精品化多元（免费模式后） | 变现转向停留时长 + 广告分成，生活流、年代/历史题材兴起 | 质感与完成度 |

**理解成本铁律**：观众看不懂的设定活不下来。「系统」类设定因部分用户难以理解，业内常改成「透视眼」「修仙」等更具体的形态。

## 二、 常青题材 vs 脑洞设定

| | 常青型题材 | 脑洞设定题材 |
|---|---|---|
| 代表 | 都市情感、古装传奇、奇幻玄幻、家庭伦理 | 一眼抓人的强设定 |
| 优势 | 天然承载普世情绪，不依赖特殊设定 | 开篇抓人快、差异化明显 |
| 风险 | 容易同质化 | 第一部惊艳，同套路多了审美疲劳 |
| 拼什么 | **完成度**：情感真实、逻辑自洽、人物塑造有层次 | **差异化创新**：能否在已有设定上做出有效创新 |

热门题材的破法：「把新酒装进旧瓶」。市场上很多爆款都是对已有题材的再创作，关键在于两点——**有没有找到新的切入点**，以及**在剧情密度、节奏控制、人设立体度上是否做得比别人更扎实**。

## 三、 IP 改编 vs 原创

**IP 改编**：自带粉丝、内核经过市场验证、试错成本低；但赛道拥挤，原著粉对改编极敏感，两边都可能落空。

- 参考做法（《冒姓琅琊》）：坚持**充分尊重原著内核**——能从海量作品里脱颖而出，其内核必然有市场吸引力。保留约 **60% 核心剧情**，在叙事节奏上按短剧受众习惯调整。改编不是照搬，是一次精心设计的短剧再创作。

**原创**：不拥挤、不撞车，创作自由度高；但极度依赖编剧个人能力，且没有粉丝托底、没有市场数据验证。

- 参考做法（《我在天庭收破烂》）：用鲜明身份反差打破固有认知——「收破烂」×「天庭」。

## 四、 四条黄金准则（判断一个 IP 值不值得投）

### 准则 1：核心创新点 —— 人无我有，人有我优

两种主要创新形式：

- **梗的创新**：热门题材 × 网络热梗。例：《九个太阳，我们是九个外甥女》把「舅舅带外甥女」热梗融进都市传奇。
- **金手指的创新**：跳出常规设定。例：《重生五八，我靠拒绝系统发家致富》不做「绑系统做任务」，而做「拒绝系统」——主角面对道德绑架只要说「不」就获奖励，既新鲜又击中情绪共鸣点。

### 准则 2：情绪张力足、节奏快、矛盾冲突密集

- **强烈的情绪点**：自带清晰、鲜明、有穿透力的情绪内核。不需要复杂铺垫，但要足够直接真实，能让观众迅速产生「想看下去」的冲动。
- **节奏为王**：开篇即入戏，结尾留悬念。每一句台词、每一个镜头都要服务于推进剧情、强化情绪或制造张力，全程「无尿点」。
- **冲突密度**：遵循「平衡—打破—重建—再打破」的高频循环。每次冲突都推动人物关系或故事走向，而不是原地打转。

### 准则 3：视觉化程度高，场景易落地

要有鲜明视觉符号、典型场景或可具象化的设定。高难度视觉化要谨慎——原创妖兽带来建模渲染成本翻倍；湖面打斗仅威亚与搭景就极贵。新人优先选「场景简单、道具常见、特效需求低」的 IP。

### 准则 4：人设立得住，共鸣感强

> **好人设的黄金法则只有一条——代入感 > 脸谱化。**

能让观众追下去的不是完美无缺的「龙傲天/傻白甜」，而是有真实动机、成长弧光、甚至带点小缺陷的「活人」。融合传统文化、家国情怀等高价值题材时，人物更要「接地气」——宏大主题只有通过具象化的人物经历传递，才不会悬浮空洞。

## 五、 选题评估五问（选题门的执行清单）

拿到任何题材/IP，先**把模糊的「感觉」变成清晰的判断维度**：

1. 目标用户是谁？
2. 核心情绪共鸣点是否明确？
3. 视觉化落地难度高不高？
4. 有没有踩政策红线？
5. 有没有市场数据支撑？

五问里任意一个答不上来，先改题，不要动笔。

## 六、 选题三步法（怎么找到该写什么）

1. **扫榜，而非凭空想象**。红果短剧 App 的热播榜、飙升榜是最真实即时的市场反馈，背后是千万用户的点击与完播数据。养成每日观察的习惯。扫榜时不只看「什么在火」，更要问「**为何会火**」和「**趋势能持续多久**」。
2. **在模仿中建立手感**。选一部近期热门短剧，拆解开场节奏、冲突设置、台词密度，用自己的语言重写一集（**仅供学习，严禁投稿**）。
3. **选择能让你「写嗨」和让观众「看嗨」的题材**。再精准的市场判断也抵不过创作者内心的共鸣；读某个 IP 时若迅速产生画面感、情绪涌动、迫不及待想动笔，说明你与这个内核有化学反应。

**时机**：若某题材已经火了一个月才跟进，「等你上桌后菜已经不热了」。但剧情向、精品化内容不必盲目求快，核心在「稳」和「深」。

## 七、 微创新三法（避免同质化的突围路径）

新人**循序渐进**地使用，不要一上来就做高阶融合。

| 层级 | 方法 | 要点与示例 |
|---|---|---|
| 入门 | **人设创新**（最安全的突破口） | 调整角色身份或性格。某爆款女主做了三重差异化：新颖职业身份 + 「萌妹外表」×「干练强势」的反差 + 甜妹属性 |
| 进阶 | **背景创新** | 把场景从都市写字楼/高档公寓移到乡村、边陲小镇或特定行业。**要求对该环境有了解或做过调研**，避免细节失真削弱代入感 |
| 高阶 | **叙事视角与情绪逻辑创新** | 击中观众「未言之痛」。当多数作品还在走「隐忍—爆发—逆袭」时，调整角色的情绪反应方式。例：《穿越古代儿孙满堂》男主面对父母过度要求时不妥协也不说教，而是「放下包袱、不按常理出牌」——精准呼应现实中许多人「想说却不敢说」的挣扎 |

更高阶的元素融合（民俗、国学经典）或情怀升华上限极高，但要求严苛。**建议先掌握人设、背景等基础维度，积累 2–3 部成功作品后再尝试复杂融合。**

**（课程 10 补充的三条思路）** 形式创新（性转、时代背景互换）/ 题材融合（年代重生 + 东北方言 + 家庭群像 + 喜剧）/ 人设创新（打破非黑即白的扁平角色）。

> 创新不是颠覆，那样试错成本太高，微创新就很好。创新的目的是更好地抓住观众，而不是为了创新而创新。

## 八、 三大雷区（新人高频踩坑）

### 雷区 1：价值观导向偏差

敏感元素和价值观问题处理不当，会直接影响作品呈现并带来风险。「合规是底线，不是选项」——务必在**动笔前**厘清创作边界，优先选择积极正向、符合主流价值的叙事方向。细化清单见 `shooting-feasibility.md` §二。

### 雷区 2：人设脱离目标用户

男频题材里热衷律师、投行精英、海归博士等「高知」角色，却忽视了核心受众（尤其三四线市场观众）对这类身份的天然距离感。

**补救方式**：通过剧情把精英「落地」——让精英律师回乡为村民免费打官司，让金融才俊返乡创业种地。只有人物行为逻辑贴近真实生活，才能打破身份壁垒建立情感连接。

**更需警惕的是风格与画像的严重错位**：目标用户是三四线城市中年人，却塑造一个日系二次元男主——这种根本性偏差会让作品从源头失去触达目标受众的可能。

### 雷区 3：制作难度过高

动辄写百万大军攻城，或执意安排湖面打斗场景——视觉冲击强，但预算、技术、调度要求极高。**市场是否接受才是最终评判标准**：如果某创意在市场上已有多个同类项目失败的先例，那就是最真实的反馈信号。

## 九、 剧本命名

剧本名是**过稿的第一道关卡**——审核人员精力有限，一个抓眼的名字能让你的剧本在海量稿件中获得「被点开」的机会。

- IP 改编起名尽量**保留原著核心关键词**，降低用户认知成本（如《穿越古代儿孙满堂》直接沿用书名）。
- 原创起名要**抓卖点**：让审核一眼知道「讲的是什么、有什么看点」。
- 剧名应与内容基调和目标受众预期相契合；偏叙事/艺术表达的作品可保留一定调性，关键是整体协调，避免理解错位。

---

## 十、 能力闭环

选题能力不是与生俱来，而是靠 **观察 → 分析 → 创作 → 复盘** 的闭环积累出来的。定期观察榜单变化，深入拆解优质案例，才能从「旁观热闹」走向「掌握门道」。
