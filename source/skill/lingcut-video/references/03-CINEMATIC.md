# 电影感铁律（★ 每个镜头提示词必加）

> **建立原因（2026-10-02）**：用户验收《《示例片名》》第一章时指出
> **「画面太杂乱了，没有电影感」**。
>
> 病因：提示词把场景写得**太完整**（店铺、招牌、行人、道具全写上），
> 模型就**全画出来**，于是画面信息过载、主体被淹没、平均曝光 ——
> 结果像**电视剧截图**，不像**电影画面**。

---

## 一、核心原则：**做减法，不是做加法**

| ❌ 电视剧思维 | ✅ 电影思维 |
|---|---|
| 把场景写全（有什么写什么）| **只写画面里该有的 2–3 样东西** |
| 主体居中全景，看得清环境 | **主体占画面 1/3 以上，环境退成暗部/虚焦** |
| 均匀打光，人人看清 | **单一主光源，明确方向，大面积暗部** |
| 背景信息丰富（招牌/行人/杂物）| **背景只留 2–3 个可辨识元素，其余压成剪影** |
| 每个镜头都"讲清楚" | **留白比信息重要**（本片是电影，不是短视频）|

---

## 二、每个镜头提示词必须包含的 5 条

把这 5 条**固定加在提示词末尾**（放在台词之前）：

```
【电影感】浅景深虚化背景，只保留主体和最近一层环境；
主体占画面三分之一以上；大面积暗部留白；
单一主光源且方向明确，不要平均曝光；
背景只保留两三个可辨识元素，其余压暗成剪影。
```

### 逐条说明

| # | 条款 | 作用 |
|---|---|---|
| 1 | **浅景深虚化背景** | 把杂乱背景糊掉，视线锁在主体 |
| 2 | **只保留主体和最近一层环境** | 中间层和远景全部虚化/压暗 |
| 3 | **主体占画面 1/3 以上** | 防止人物变成"蚂蚁" |
| 4 | **大面积暗部留白** | 电影的黑是构图的一部分 |
| 5 | **单一主光源 + 明确方向** | 本片光源规定：油灯（暖黄）/ 天光（冷青）|
| 6 | **背景只留 2–3 个可辨识元素** | 其余压暗成剪影 |

---

## 三、本片的光影规范（写提示词时直接抄）

| 场景 | 主光 | 色调 | 关键 |
|---|---|---|---|
| **州城老街·清晨/白天** | 天光（冷青）+ 油灯（暖黄点）| 青灰冷调 + 暖黄点 | 冷调压住画面，只有油灯那一点暖 |
| **州城老街·夜** | 只有油灯 | 大面积黑 + 一点暖黄 | 黑要占 70% 以上 |
| **雪原雪原** | 月光/风灯（橘红）| 雪白 + 橘灯 | 白不是亮，是冷 |
| **停灵处** | 冷青光 | 死青 | 几乎无暖色 |

**通用禁项**：不要平均曝光、不要环境光把暗部提亮、不要多个光源打架。

## 四、镜头语言（本片专用）

| 项 | 规定 |
|---|---|
| **景别** | 大量**固定长镜**；浅景深；大量**背影与手部特写** |
| **运镜** | **克制**。缓慢推近 / 缓慢横移 / 缓慢上摇。**禁用快速环绕、甩镜、手持抖动** |
| **剪辑** | 慢。空镜 3–5 秒。**过渡即内容**（磨墨、走路、点灯）|
| **留白** | 前 3 分钟可以只是磨墨。**留白越长越好** |
| **禁用** | 夸张表情、快速剪辑、华丽运镜、多光源、满构图 |

## 五、改写示例（第一章 B02 摆摊陈设）

**❌ 改前**（杂乱）
```
老街街口的旧木桌，桌上一方旧砚台、半块老墨、一支狼毫笔、一盏油灯、
一叠泛黄信纸。天光未亮，油灯是主要光源。木纹与磨损质感清晰。
（→ 模型把整条街的招牌、行人、杂物全画出来）
```

**✅ 改后**（电影感）
```
[中景，固定机位略微俯视] 老街街口一张旧木桌，桌上一方旧砚台、一支秃笔、
一盏亮着的油灯。构图严格参照 @图1。
老人手从画面下方入画，把笔搁到砚台上。
【电影感】浅景深虚化背景，只保留桌面和最近一层街沿；
桌面占画面三分之二以上；大面积暗部留白；
唯一主光源是这盏油灯，暖黄光从右侧打来，街道其余部分沉入黑暗；
背景只保留两三个模糊的檐角剪影，不要招牌文字、不要行人、不要杂物。
无配乐，只有音效：木器轻磕声、纸张摩擦声。全程画面都在动，不要定格。
```

## 六、自检清单（出稿前逐条过）

- [ ] 提示词里**点的物件不超过 4 样**（其余用"不要出现"挡住）
- [ ] 有 **`浅景深`** / **`虚化背景`** 字样
- [ ] 有 **`主体占画面三分之一以上`** 字样
- [ ] 有 **`大面积暗部留白`** 字样
- [ ] 有 **`单一主光源 + 方向`** 描述
- [ ] 有 **`背景只保留两三个可辨识元素`** 字样
- [ ] **明确列出"不要出现"的东西**（招牌文字、行人、杂物、多余道具）
- [ ] 没有多光源打架的描述
- [ ] 运镜只有**缓慢推近/横移/上摇**，没有快速环绕/甩镜
