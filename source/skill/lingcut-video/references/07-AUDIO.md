# 配音 · 旁白 · 音效

> 声音决定片子"像不像电影"。
> **核心原则：不要音乐，可以有音效。** （BGM 交给用户在自己剪辑软件里加）

---

## 一、三条音轨的分工

| 轨 | 内容 | 怎么生成 |
|---|---|---|
| **对白** | 画内人物说话 | **走画布音频节点**（让视频模型跟着走）|
| **旁白** | 说书人叙述 | **LibTV TTS**，按章整条 |
| **音效** | 环境音 | **视频模型自带**，写在提示词的音效栏 |

---

## 二、对白：必须进提示词 + 必须标归属 ★★

### 2.1 台词写在提示词最后

```
[中景，双人，固定机位] <场景>。<人物外貌严格参照 @图1/@图2>。
<动作过程>。
【电影感】<五条>
无配乐，只有音效：说话声、极静的空气。
★台词（必须按照写下来的字，一字不差、清楚完整地说出来；
      用画面上这个人物自己的声音和语气，不要旁白腔）：
  <谁>说：「<台词1>」然后是——「<台词2>」
全程画面都在动，不要定格。
```

**★ 台词放在提示词的最后**（放前面会被动作描述冲淡）。

### 2.2 ★ 多人对话必须逐条标归属

**这是最容易出错的地方。** 实测踩坑：

分镜表写的是：
```
老先生抬眼：「老三又没回来？」
屠户瓮声瓮气：「捎话就行。说家里都好，他媳妇给他生了个闺女，等他回来起名。」
老先生不落笔，看着他。屠户别过脸：「……他知道就成。」
```

**错误写法**（把两句都给了一个人）：
```
★台词：屠户先问：「老三又没回来？」然后是——「捎话就行。说家里都好…」
        ↑↑↑ 错！「老三又没回来？」是老先生问的
```
结果：AI 把**全部台词都给了同一个人**，观众看到老先生自己问自己答。

**正确写法**（逐条标 ①②③④）：
```
★人物关系与说话对象必须正确：
① 是**坐着的老人**先缓缓抬眼看向站着的屠户，用很平的语气**问他**：「老三又没回来？」
② 是**站着的屠户**瓮声瓮气地**回答**（他低着头、肩膀微微耸动、手在围裙上搓）：
   「捎话就行。说家里都好，他媳妇给他生了个闺女，等他回来起名。」
③ 老人听完**没有落笔**，只是抬眼看着屠户（不说话）。
④ 屠户被看得不自在，**别过脸去**，声音低下来：「……他知道就成。」
★台词必须一字不差、按上面的顺序说出来；
  **问句和答句必须是不同的人说的**——坐着的老人只说第①句，
  站着的屠户只说第②和第④句，绝对不要把屠户的话安到老人嘴里。
  每个人用自己的人物声音：老人是苍老平静的男声，屠户是粗哑瓮声的中年男声。
```

**要点**：
- **每人一段，编号**
- 明确写**姿态**（坐/站、低头/抬眼、搓手/别过脸）
- 明确写**音色差异**
- 加一句**「不要把 X 的话安到 Y 嘴里」**

## 三、★ 声音性别 / 年龄必须指定（画面里没人时）

**问题**：如果镜头里**看不到说话的人**（大远景、背影、空镜），
模型无从判断该配什么声音 → **配错性别**。

**实测踩坑**：M08 是老阿妈的台词，画面写的是「不要出现人物面部」，
结果模型配了个**男声**。

**解法（两个一起做）**：

### ① 提示词里明确写

```
★这段台词必须是这位老阿妈（老阿妈，一位六七十岁的老年女性）自己说的——
  用苍老、沙哑、缓慢的老年女声，是老婆婆的嗓音，
  **绝不是男声、不是年轻女声、不是旁白朗读**。
```

### ② 画面里**放进那个人**（哪怕只是背影）

```
驿站门口站着一位满头白发的老阿妈（外貌严格参照 @图1 的老阿妈），
穿着厚棉袄，**背对着镜头**，刚刚把灯拨亮，双手还举在灯边。
```

**把人物放进画面（哪怕是背影/剪影），模型就能判断声音。**

## 四、旁白：LibTV TTS

走 `libtv-voice` skill。要点：

### 4.1 音色全片统一

**每个角色固定一个 voice_id / 音色描述，全片不换。**
**同一角色的多句台词必须一次生成**（分 N 次生成 F0 会漂 110Hz，像换人）。

### 4.2 音色描述的坑

| ❌ 写法 | 后果 |
|---|---|
| 「几乎听不见 / 收得很轻」| 生成**近静音** |
| 「说书人 / 讲故事」| 容易出**女声** |

✅ 正确做法：**把「男声 / 男中音」放在描述最前面**。

### 4.3 旁白的节奏

- **按章生成整条**（不要一句一句生成再拼，会不连贯）
- 旁白**不要铺满** —— 留白处让音乐和音效说话
- 每章的旁白长度 ≈ 该章时长的 **40~60%**

**实测分布**（《《示例片名》》第一卷）：
```
楔子    : 0:09 → 1:00  连续 51 秒（说书人铺满）
第一章  : 只有 5 处，很稀疏
```
**旁白密的地方，音乐必须让位；旁白空的地方，音乐才说话。**

## 五、音效：写在提示词里，不要音乐

### 5.1 标准写法

```
无配乐，只有音效：<具体音效列表>。
```

**音效要具体到"能听见什么"**：

| 场景 | 音效 |
|---|---|
| 室内写字 | 毛笔在纸上行走的沙沙声、轻微呼吸声 |
| 雪原 | 风声呼啸、火焰轻爆 |
| 街市清晨 | 街市初起的人声、远处一声鸡鸣 |
| 停灵处 | 屋檐滴水 |
| 对话 | 说话声、衣料摩擦声、极静的空气 |
| 金属 | 金属轻响、布料摩擦 |

### 5.2 ★ 不要写「配乐」

**用户明确要求**：「不用 BGM 我直接在剪辑软件上加」+「不要有音乐，可以有音效」。

所以每个提示词都写：
```
无配乐，只有音效：……
```

（只有特殊镜头才允许写「只有一声极低的鼓」这种单点音效。）

## 六、旁白混音

详见 `08-ASSEMBLY.md`。要点：

```bash
ffmpeg -y -i <chapter.mp4> -i <narration.wav> \
  -filter_complex "[1:a]apad=whole_dur=<视频秒数>[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -ar 32000 -ac 2 -shortest <out.mp4>
```

**也可以从旧成片里反向提取旁白**（如果旧成片已经有旁白）：
```bash
ffmpeg -y -i <旧成片.mp4> -vn -c:a pcm_s16le -ar 48000 -ac 2 <章名>_旁白.wav
```

**★ 改动镜头时长后，旁白会错位** —— 要在变化点插静音（见 `08-ASSEMBLY.md` 第五节）。

## 七、配乐（可选，用户自理）

**如果用户要你给建议**，见 `projects/<片名>/★剪辑工作台/配乐清单-*.txt` 的模板。

核心建议：
1. **整卷只要 4 首**，不要一首一首换
2. **主题旋律只出现 3 次**（多一次就废了）
3. **情绪最重的镜头（悬念/死亡）音乐要完全停** —— 别用音乐填它
4. **旁白说话时音乐退到 -30dB**，旁白一停立刻回来（这叫"让路"）
5. 曲与曲之间**不要硬切**，让上一首自然衰减完，**空 1-2 秒静默**
6. **静默也是配乐**
