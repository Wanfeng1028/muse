# Reference patterns: what strong product motion pieces do

A breakdown of the kinds of pieces this style comes from: product launches, ad-style demos and an
event promo. Each row is an archetype with the techniques worth taking. Take the grammar, never
anyone's footage, logos, characters or copy.

| Archetype | Format / look | Take this |
|---|---|---|
| **Dev-tool launch film** (~60s) | 16:9 dark, pixel cursor, sticky notes | **Rapid montage**: 0.1–0.3s cuts through tilted UI crops; the cursor clicks everything; checklist rows tick green; red "error" pills slam in; a week label types; "LIVE / DEPLOY" list; a two-line end ("Ship in minutes / not weeks") |
| **AI ordering demo** (~15s) | 16:9 light, off-white, glowing input | **Typed prompt** in a glowing input → a playful illustration moment → **carousel of real cards** on a bright field → phone mockup, tap the button, toast → black end card with a line-by-line story ("You were craving X. / Now it's on the way.") → logo |
| **Tool integration teaser** (~12s) | 16:9 cream, one sans, one rust accent | **Word-by-word line-mask headline**, last phrase in accent; the input **types** and sends; a brief card **snaps in with motion blur**; chips pop in sequence; a status pill Accept → Accepted with a cursor; a segmented control slides while a number counts; a dot resolves into the logo |
| **Data / insight product** (~35s) | 16:9 muted green, real email + web UI | **Camera over real UI**: push into an email and highlight one figure; side-by-side cards compute a gap; **a big red stat with a short caption** ("2.4M / a year, left on the table"); search typed → table filters → detail page; end line with a **highlighter swipe** on the key words |
| **Job-search agent story** (~45s) | 9:16 post + 16:9 film, dark, space + dot grids | **Number counters** ("26 → 437 applications sent"); a dot grid fills per item; "0 replies." over a shattered grid; a big-number backdrop; "Matched for you." UI; cards fan out; timed notifications stack ("While you sleep. 5:23 AM"); a sunrise gradient for the turn; logo with a typing underscore cursor |
| **Collaboration tool** (~23s) | white, design-tool comments | **Multiplayer cursors with name tags** drift in; comment threads pop; context menus open item by item; logo letters type in |
| **Multi-model chat app** (~17s) | white → dark, pills + windows | **A sentence with a swapping pill word** ("Chat with [A] → [B] → [every model]"); chat windows multiply into a grid; stacked "Your brand. / domain. / data." lines; a particle logo reveal (use sparingly) |
| **Big-platform assistant** (15–90s) | 16:9 soft sky gradient, floating windows | **Calm premium**: soft cloud gradient background; UI windows float with slow parallax; a mode toggle; a soft mascot shape; logo end |
| **Model update sting** (~3s) | 16:9 white | One UI moment, a slow push-in. Nothing else. |
| **Developer SDK film** (~60s) | 16:9 dark + orange glow | A glow **bloom transition**; chat bubbles stack; sidebar nav clicks; a product card with avatars; logo with a small character |
| **Conference promo** (~24s) | 1:1 purple/cream, bold editorial, hand-made | **Stop-motion jitter**: everything on twos/threes; date letters pop in jittery; **folding-paper / 3D box reveals**; a radial burst spins in steps; speaker cards on a conveyor (photo, name, role, company); sticker moments; a "DON'T MISS OUT" ticket; logo lockup |

## Patterns that repeat across the set
1. **Real UI, never invented**: real emails, dashboards, inputs. The camera moves over them.
2. **The cursor is the narrator**: it types, clicks, drags, hovers. Every state change has a cause.
3. **One idea per beat** (1–3s), stated in short kinetic type, then shown in UI.
4. **Numbers as heroes**: a counter, or a giant stat in the accent colour with a small caption.
5. **Swap words in a fixed sentence** to list features instead of bullet lists.
6. **End = one line + logo**, often on black or the brand colour, with a typing-cursor or
   letter-by-letter resolve.
7. **Two energies**: *calm premium* (soft background, slow parallax, gentle springs) and
   *jitter / hype* (on-twos timing, fast montage, snaps, shakes). This skill defaults to
   **simple + jitter**.
