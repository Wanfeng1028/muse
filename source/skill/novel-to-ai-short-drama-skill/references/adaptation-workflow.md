# 小说到 AI 短剧的改编工作流

## 一、原作事实与改编边界

先建立一份内部使用的事实账本：

| 类别 | 需要记录的内容 |
|---|---|
| 人物 | 身份、欲望、恐惧、当前认知、关系、说话习惯 |
| 事件 | 起因、行动、阻碍、结果、后果 |
| 秘密 | 谁知道、谁不知道、何时暴露 |
| 时空 | 地点、时间、前后顺序、移动关系 |
| 连续物 | 服装、伤势、道具、证据、环境状态 |
| 情绪 | 进入场景的状态、触发点、离开场景的状态 |

给素材分三类，最终说明中只需简要呈现重要取舍：

- **原文事实**：不得无故改变。
- **合理外化**：把原文已有心理或信息变成动作、对白、声音或道具证据。
- **改编新增**：为压缩、转场或可视化而增加的连接内容；不能反转原作人物动机和因果。

优先保留：核心因果、人物欲望、关系变化、关键伏笔、标志性动作/台词和不可替代的情绪峰值。优先压缩：重复说明、同功能配角、无结果的往返、仅提供氛围却不推进剧情的段落。合并人物或重排事件时，先检查秘密知情顺序、动机成立性和后续回收。

## 二、从故事段落提取本集引擎

用一句话写清本集：

> 当【触发事件】发生，主角为了【可见目标】采取【行动】，却遭遇【阻力】，导致【不可逆变化】，并留下【下一步问题】。

再锁定六个节拍：

1. 开场画面：第一帧或第一声提供异常、冲突、欲望或危机。
2. 最小定向：用最少信息回答“谁、在哪、现在要什么”。
3. 压力升级：阻力必须改变主角行为，不能只是重复争吵。
4. 转折：新信息、关系变化、选择或失败改变行动方向。
5. 高潮/释放：兑现本集承诺；纯悬念集也要提供阶段性变化。
6. 尾钩：从高潮的结果自然长出，不使用与本集无关的突发噱头。

每一场结束时至少改变一项：信息、权力、关系、风险、目标、位置或资源。没有变化的场景应删除、合并或改写。

## 三、时长设计

### 节拍比例

以下是默认起点，不是机械公式；悬疑、喜剧、情感戏可按类型调整：

| 区间 | 建议占比 | 主要任务 |
|---|---:|---|
| 钩子 | 0%–8% | 异常画面、冲突动作或高信息台词 |
| 定向 | 8%–22% | 建立人物、目标、场域 |
| 升级 | 22%–65% | 行动—阻碍—再行动 |
| 转折/高潮 | 65%–90% | 改变局势并兑现主情绪 |
| 余波/尾钩 | 90%–100% | 结果落地并提出下一问题 |

### 镜头规模参考

| 单集时长 | 常用场景数 | 常用镜头数 | 适合承载的内容 |
|---:|---:|---:|---|
| 15–30 秒 | 1 | 4–8 | 单一事件、单一反转或强概念 |
| 31–60 秒 | 1–2 | 8–14 | 一个完整冲突与一次明显变化 |
| 61–90 秒 | 1–3 | 12–20 | 冲突升级、转折和尾钩 |
| 91–180 秒 | 2–4 | 18–30 | 多节拍关系变化或完整小弧线 |

镜头数根据题材和生成方式调整。情感凝视可更少更长，动作或喜剧可更碎；不要为了达到数量硬切镜头。

### 台词时间估算

以实际表演为准，规划阶段可用以下中文口播速度估算：

- 克制或情绪停顿较多：约 2.5–3.2 字/秒。
- 日常清晰表达：约 3.3–4.2 字/秒。
- 争执、快节奏信息抛出：约 4.3–5.0 字/秒，但不宜整集维持。

对白秒数之外，另计演员反应、动作完成、观众理解信息的停顿和转场。环境声与配乐通常与画面并行，不重复计时；必须独占画面的声音段落才单独占时。

先做逐镜“时间码 + 持续秒数”，再核算：

`总时长 = Σ 每个镜头持续时间`

总和必须等于用户指定的目标成片时长。若超时，优先删重复信息和无变化反应；若不足，优先增加有意义的反应、悬念停顿或因果步骤，不注水。

## 四、文学语言的视听外化

按“抽象信息 → 可观察证据”转换：

| 小说表达 | 优先外化方式 |
|---|---|
| 她开始怀疑他 | 视线停在矛盾证据上；收回伸出的手；删掉未发出的消息 |
| 他非常愤怒 | 指节压白；杯中水震动；短促呼吸后改变行动 |
| 多年过去 | 同构图匹配剪辑；道具磨损；季节/日期/空间变化 |
| 他身份尊贵 | 他人让路、称谓变化、权限行为、空间中心位置 |
| 她想起往事 | 声音桥、闪回碎片、触发物特写；仅在确有必要时使用旁白 |

旁白只能承担画面和对白难以高效表达的主观层、时间跨度或叙事风格，不得用来解释观众刚刚看见的动作。

## 五、多集改编

多集前先制作全局地图：

- 每集：目标、阻力、核心变化、主导情绪、开场钩子、尾钩。
- 全剧：人物弧线、秘密揭示顺序、伏笔埋设与回收、关键道具流转、时间线。
- 每集都要有阶段性收益，不能连续多集只铺垫不变化。
- 尾钩必须由本集选择或结果产生；下一集开场应尽快兑现或有意义地改写该预期。

若用户只给单集时长而未明确多集需求，先按一集改编当前片段。若用户要求完整长篇改编，必须同时确认总集数或本次覆盖范围。
