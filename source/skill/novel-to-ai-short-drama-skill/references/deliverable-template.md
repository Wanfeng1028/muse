# 默认交付模板

根据用户要求删减字段，但不得删除时长核算。默认使用中文 Markdown。

## 一、改编规格

```markdown
【改编范围】原文第 X 段 / 第 X–X 章 / 用户提供片段
【集数】第 X 集，共 X 集（未知则不虚构）
【单集时长】XX 秒
【画幅】9:16 竖屏 / 用户指定
【类型与基调】……
【本集任务】一句话说明目标—阻力—变化
【主导情绪】……
```

## 二、改编取舍

只列影响理解的 3–6 条，不写长篇分析：

```markdown
- 保留：原作的核心事件/关系/标志性细节。
- 压缩：合并了哪些重复信息或场景，目的是什么。
- 外化：把哪段心理转成了什么动作、道具、对白或声音。
- 新增：若有连接戏，说明其不改变原作因果。
```

## 三、本集节拍与时长账本

```markdown
| 时间码 | 秒数 | 节拍 | 戏剧功能 | 情绪/信息变化 |
|---|---:|---|---|---|
| 00:00–00:05 | 5 | 开场钩子 | …… | …… |
| …… | …… | …… | …… | …… |
| 合计 | XX |  |  |  |
```

时间码必须连续、无重叠、无空洞，合计等于目标时长。

## 四、导演分镜台本

每个场景先写场景头与初始调度，再列逐镜台本：

```markdown
### 场 1｜地点｜日/夜｜内/外

【初始调度】人物位置、方向、关键道具、环境和光线。

| 镜号 | 时间码/秒 | 景别·机位 | 运镜 | 画面·调度·表演 | 台词/旁白 | 声音 | 转场·AI 生成备注 |
|---|---|---|---|---|---|---|---|
| 1-01 | 00:00–00:03 / 3s | …… | 固定/缓推…… | 主体做一个明确动作；写出反应落点 | 人物：台词 | 环境声/音效/音乐 | 与上一镜的连续性；生成风险或后期处理 |
```

书写约定：

- 景别与机位写具体，如“低机位中近景，人物居画面右侧”，不要只写“特写”。
- 运镜写起点、方向和终点；固定镜头直接写“固定”。
- 表演写动作节拍，不只写“愤怒”“震惊”。
- 台词保持角色口吻；停顿、抢话、画外音和口型需求需标明。
- 无对白也要写有效环境声、动作声或静默意图。
- 同一镜若存在复杂多人动作或多段摄影机运动，应拆镜。

## 五、连续性与 AI 生成锚点

```markdown
### 角色锚点
- 角色 A：外形、发型、服装、饰品、当前伤势/情绪基线。

### 场景锚点
- 场景 1：空间布局、主色、光向、天气、关键陈设。

### 道具账本
- 道具：初始位置 → 谁拿起 → 状态变化 → 结束位置。

### 后期注意
- 需要后期合成的文字、屏幕、慢动作、音效或转场。
```

## 六、交付校验

```markdown
【时长】逐镜合计 XX 秒 = 目标 XX 秒
【原作】核心因果与人物动机已保留；新增内容已说明
【连续性】轴线、视线、走位、服装、伤势与道具已核对
【AI 可生成性】复杂动作已拆分；文字/镜面/多人交互风险已标注
```

若用户只要精简剧本，可把第三、四部分合并为按时间码书写的分场剧本，并把关键镜头写入动作段；仍需保留规格、必要改编取舍与交付校验。
