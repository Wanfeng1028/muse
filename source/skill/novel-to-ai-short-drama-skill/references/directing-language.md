# 导演与 AI 镜头语言

## 一、每个镜头必须回答的问题

一个可执行镜头至少写清：

1. **拍什么**：主体、动作、关键道具和背景信息。
2. **从哪里拍**：景别、机位、角度、视线关系。
3. **是否以及如何运动**：固定、推、拉、摇、移、跟、弧绕、手持等。
4. **为何这样拍**：揭示信息、改变权力感、强调反应、制造距离或完成转场。
5. **演员怎么演**：可观察的动作节拍、眼神、停顿、呼吸、与道具/他人的互动。
6. **持续多久**：确定秒数，并与台词和动作量匹配。

避免只写“特写”“运镜”“有电影感”。镜头指令应使另一个创作者无需猜测就能复现视觉意图。

## 二、景别、机位与叙事功能

| 选择 | 常见功能 | 使用提醒 |
|---|---|---|
| 大远景/远景 | 建立环境、孤立或规模 | 竖屏中主体不能小到无法识别 |
| 全景 | 交代人物位置和完整动作 | 适合动作起点、走位和空间重置 |
| 中景 | 双人关系、上肢动作、对白 | 是竖屏叙事的稳健基础景别 |
| 中近景 | 表情与手部动作兼顾 | 适合多数情绪对白 |
| 近景 | 关键反应、决定、信息压力 | 先确保观众知道人物在看什么 |
| 大特写 | 证据、微表情、触发物 | 少而准；使用过多会失去强调作用 |
| 过肩 | 对峙、视线和权力关系 | 保持肩位、视线与轴线连续 |
| 主观镜头 | 强代入、发现信息 | 明确是谁的主观，之后给反应镜头 |
| 高/低机位 | 脆弱、压迫或权力变化 | 不要把角度当作固定人物标签 |

先用空间建立镜头让观众理解位置，再用关系镜头推进冲突，最后用反应或细节镜头完成信息落点。若故意不给空间信息制造悬念，应在揭示时偿还观众的理解成本。

## 三、运镜必须有动机

| 运镜 | 适合的叙事任务 |
|---|---|
| 固定 | 让表演、尴尬、压迫或信息自己发生 |
| 缓推 | 逼近认知、决定、威胁或微妙反应 |
| 拉远 | 揭示处境、孤立、关系破裂或更大后果 |
| 横摇/俯仰 | 跟随注意力、连接空间信息、完成揭示 |
| 横移/跟拍 | 陪伴行动、保持节奏、展示阻碍 |
| 弧绕 | 权力转换、关系重新站位、强烈主观波动 |
| 手持 | 失控、危险、贴身即时感 |
| 快摇/甩镜 | 突发信息、喜剧击点、强动作衔接 |
| 变焦/焦点转移 | 在同一构图内改变信息优先级 |

规则：

- 一个镜头通常只设一个主要运动。组合运镜必须能在给定秒数内完成，且确有叙事收益。
- 运动的起点与终点要明确，例如“从门锁大特写缓拉至门外两人中景”，而非“镜头拉开”。
- 关键反应常常比继续运动更重要。动作发生后保留 0.5–2 秒的反应落点，时长依情绪强度调整。
- 不因画面静止就默认加运镜。固定镜头中的走位、前后景遮挡和焦点变化同样能制造动态。

## 四、表演与场面调度

把情绪词拆成可表演的节拍：刺激 → 压住反应 → 身体泄露 → 做出选择。写“忍住眼泪”时，给出演员能执行的行为，如咽回话、避开视线、把皱掉的纸抚平后仍递出去。

调度应体现关系：

- 权力占优者可控制空间中心、门口、坐席或关键道具。
- 权力变化时，用站起、靠近、越过边界、夺回道具或换位表现。
- 亲密与疏离用距离、朝向、是否同框、是否共享前景表达。
- 重要信息出现时，安排“信息物 → 观看者 → 反应/行动”的可读链条。

多人场景先标明站位和视线对象。避免所有人同时做复杂动作或连续抢台词，否则 AI 生成与剪辑都难以维持清晰度。

## 五、轴线、视线与连续性

- 对话场景先建立人物轴线。越轴若非有意制造失衡，应插入中性正面、移动越轴或重新建立空间的镜头。
- 记录人物在画面左/右、移动方向、看向、入画/出画方向。相邻镜头保持可读的视线匹配。
- 接动作剪辑时，把动作拆在清晰节点；前镜结束姿态与后镜开始姿态一致。
- 逐镜保持角色脸部特征、发型、服装、饰品、伤势、手中物、环境光向与时间状态。
- 关键道具记录“持有者—位置—状态—变化原因”，避免凭空换手、破损复原或文字变化。

## 六、面向 AI 视频生成的镜头原子化

默认每个生成单元只包含一个主要动作和一个主要镜头意图。常用单镜 2–6 秒；静态情绪镜头可更长，快速插入镜头可更短。若一个镜头同时要求人物起身、转身、奔跑、抢物、说长台词并让摄影机环绕，应拆分。

每个镜头的 AI 备注优先记录：

- 角色稳定锚点：年龄感、脸型/关键特征、发型、服装层次、明显饰品。
- 场景稳定锚点：空间类型、主色、光向、时间、关键陈设和天气。
- 本镜变量：单一动作、表情变化、摄影机运动、画面内新增信息。
- 连续性约束：承接上一镜的站位、手持物、视线、动作起点和光线。
- 生成风险：多人手部接触、镜面、可读文字、复杂口型、快速形变、群演一致性等。

长对白优先拆成说话者镜头、倾听者反应和信息插入镜头，降低持续口型同步压力。对必须准确显示的手机、合同、牌匾等文字，建议作为后期合成层，不依赖一次生成正确。

## 七、声音与剪辑

声音字段至少区分对白/旁白、环境声、动作音效、音乐和有意义的静默。

- 用声音桥跨场可压缩时间并保持叙事连续。
- 强动作前后的瞬间静默可放大冲击，但必须计入镜头时长。
- 音效应对应具体可见动作；不要堆砌“震撼音效”。
- 转场写明触发逻辑：动作匹配、构图匹配、声音桥、遮挡切、硬切、叠化或闪回触发。
- AI 生成镜头与后期剪辑分开描述：生成时需要的视觉运动写在镜头栏，剪辑完成的速度变化、字幕、音效和合成写在后期栏。
