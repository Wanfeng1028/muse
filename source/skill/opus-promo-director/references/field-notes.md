# 현장 교훈

공식 스킬과 문서에 없는, 실제 제작에서 얻은 교훈만 적는다. 설치 방법과 기본 API 사용법은 공식 자료를 따른다. 시간 수치는 전용 GPU가 없는 Windows PC에서 관측한 예시다. 연출 수치(크기, 흐림, 이징)는 출발점이다. 프로젝트마다 톤에 맞게 바꾼다.

## 렌더가 실패할 때

- 브라우저 다운로드가 네트워크 문제로 막히면, 이미 설치된 Chrome이나 Chromium을 렌더러 브라우저로 지정한다.
- 브라우저 연결 시간 초과는 대개 일시적이다. 남아 있는 브라우저 프로세스를 정리하고 다시 돌린다.
- 동시 렌더링 수는 처음 5% 구간에서 1과 2의 속도를 재 보고 고른다. GPU 없는 Windows PC에서는 WebGL이 없는 장면도 2가 1보다 약 세 배 느렸다(분당 5% 대 15%). 60초 1080p 한 편이 1에서 약 6분 걸렸다.
- 렌더가 0.3~2fps로 느려지거나 `net::ERR_ABORTED`가 나면 남은 헤드리스 Chrome을 정리하고 동시 렌더링 수를 1로 다시 돌린다.
- 전체 렌더 중에는 확인용 정지 화면을 따로 뽑지 않는다. 동시에 돌리면 렌더가 중간에 실패했다.
- 번들을 한 번 만들어 두고 여러 장면의 정지 화면을 뽑으면 빠르다.
- 번들 명령이 출력 없이 끝나고 `index.html`이 없을 때가 있었다. 번들 뒤에 파일이 있는지 확인하고, 없으면 다시 번들한다.
- 커스텀 폰트는 로딩이 끝날 때까지 렌더를 지연시켜야 첫 프레임부터 적용된다.
- Remotion 출력은 yuvj420p다. 납품 전에 yuv420p로 변환한다(platforms.md). 변환이 끝나기 전에 파일을 읽거나 옮기면 moov atom이 없는 깨진 파일이 된다. 변환 프로세스가 끝났는지 확인한 뒤 복사한다.
- 시스템 ffmpeg가 권한 문제로 실행되지 않으면, Remotion이 설치한 복사본(`node_modules/@remotion/compositor-*/ffmpeg`)을 쓴다. 스크립트는 `--project`로 이 복사본을 찾는다. 이 복사본은 필터가 적어 `tile` 같은 필터를 쓸 수 없으니 시트는 스크립트로 만든다.

## 3D 텍스처와 카메라

- 이미지 텍스처는 이미지 로딩이 끝날 때까지 렌더를 지연시킨 뒤 만든다. 비동기 로더를 기다리지 않으면 빈 텍스처가 찍힌다.
- 카메라 위치, 바라보는 점, 화각을 매 프레임 현재 프레임 번호로 직접 계산해 적용한다. 그렇지 않으면 카메라가 기본 위치에 머문다.
- 항상 맨 앞에 보여야 하는 평면 이미지(마스코트)는 깊이 테스트를 끄고 렌더 순서를 높인다. 투명 가장자리는 alphaTest로 자른다.
- 돌아가는 카드가 주인공을 가리면 궤도 반지름을 키운다. 깊이감은 안개와 거리 차이로 준다.

## Blender

- 설치 없이 공식 포터블 버전을 풀어 백그라운드로 실행할 수 있다.
- 스타일 장면은 EEVEE(샘플 16 안팎, 레이트레이싱 끔)로 충분하다. 1080p 한 프레임에 약 7초, 180프레임에 약 20분 걸렸다.
- Cycles는 CPU에서 한 프레임에 40~70초 걸렸다. 떨어지는 책처럼 짧은 물체 한 컷에만 쓰고, HDRI 조명과 그림자만 받는 바닥판을 함께 쓴다.
- 합성할 컷은 투명 배경으로 렌더한다. 나중에 배경만 바꿔 달라는 요청이 오면 Blender를 다시 돌리지 않아도 된다.
- 일부 GPU에서 그림자가 무작위로 빠져 어두운 프레임이 섞였다. 그림자를 끄고, 밝기를 검사해 문제 프레임만 다시 렌더링했다.
- 세로 버전은 카메라를 따로 둔다(예: 가로 38mm, 세로 30mm). 설정을 바꾸는 코드는 카메라를 만든 뒤, 스크립트 끝에 둔다.
- 입체 글자는 두께와 모서리 깎기를 주고, 두꺼운 폰트 파일을 직접 불러온다.

## 입체 배경

- 층 구성: 장면별 그라데이션 → 먼 레이어(흐림 약 5px, 불투명도 0.85) → 가까운 레이어 → 한 번 지나가는 빛줄기(비스듬한 선형 그라데이션이 좌에서 우로 이동).
- 물체는 브랜드와 관련된 것으로 고르고, 제목을 가리지 않게 화면 가장자리에 배치한다.
- 어두운 톤은 카메라를 향해 날아오는 문서나 카드 터널로 만든다. 제목 뒤는 어둡게 눌러 대비를 확보한다.

## 전환과 속도감 수치

- 컷 순간: 크기 1.08 → 1.0(8프레임), 블러 5px → 0(3프레임).
- 섬광은 평소 컷에서 0.1~0.2, 3프레임으로 둔다. 0.45 섬광을 컷마다 블러와 겹치자 화면이 1~2프레임씩 회색으로 떴다. 0.3 이상은 가장 큰 공개 한 번에만 쓴다.
- 주인공 물체는 첫 프레임부터 불투명하게, 크기 1.45 → 1로 박는다. 투명도 0에서 페이드인하면 컷 직후 빈 화면이 보였다. 다음 물체로 바꿀 때도 교차 페이드 대신 박자에 맞춰 바꿔 끼운다.
- 장면 퇴장은 크기 1 → 1.07, 블러 4px 이하로 짧게. 1.18배와 12px 블러는 다음 장면 첫 프레임까지 뿌옇게 만들었다.
- 글자 등장: 크고 흐릿하게 시작해 박힌다(크기 1.6 → 1, 흐림 10px → 0, 글자마다 1프레임 간격). 2프레임 간격은 긴 한국어 제목에서 다 박히기 전에 장면이 끝났다.
- 이징: 빠르게 들어와 부드럽게 멈추는 곡선 bezier(0.16, 1, 0.3, 1). 튕기는 효과는 back 계열(강도 1.6~3).
- 박자 맥박: exp(-(frame % 한박자프레임) / 3.5)를 글자 빛이나 버튼 크기에 곱한다.
- 기능과 수치 소개에는 숫자 카운트업, 입체 블록 낙하, 원형으로 도는 카드가 잘 먹혔다.

## 마스코트 GIF

- GIF를 RGBA 프레임으로 나누고, 모든 프레임의 투명 영역을 합친 크기로 똑같이 자른다. 그래야 캐릭터가 떨리지 않는다.
- 뒤돌아서는 구간은 빼고, 정면 구간만 앞뒤로 반복해 필요한 길이를 채운다.
- 배경색이 캐릭터 안쪽 색과 비슷하면, 색 기준으로 지우지 말고 바깥 가장자리에서부터 채우기로 지운다.

## 깊이 지도 비행

평면 무한 줌(초록 창 안으로 계속 확대)은 "허접하다"는 평가를 받았다. 사진 확대처럼 보이고, 매번 같은 네모로 들어가고, 전환마다 속도가 끊겼기 때문이다. 아래 방법으로 고쳤다.

1. 같은 시간대와 빛으로 이어지는 공간 사진 3~4장을 생성한다(예: 외벽 → 실내 → 목적지). 카메라가 통과할 입구는 순수 초록(#00FF00)으로 채우게 한다.
2. 원본 사진을 참조로 넣어 깊이 지도를 만든다(prompts.md 참고). 초록 화면이 입구로 잘못 인식된 항목은 뺀다.
3. 건물 외벽처럼 평평해야 할 면은 평면에 맞춰 편다(깊이 d = a·u + b·v + c로 맞추기). 그래야 창문이 볼록하게 튀어나오지 않는다. 벽보다 가까운 나무와 하늘만 원래 깊이를 유지한다.
4. 깊이 구간별로 레이어를 나누고, 가려져 있던 빈 곳은 주변 픽셀로 채운다. 그래야 카메라가 움직일 때 구멍이 드러나지 않는다.
5. 깊이로 변형한 면 위로 곡선 경로를 따라 카메라를 날린다. 속도는 경로 길이 기준으로 맞춘다. 입구는 최고 속도로 통과하고, 이음매는 섬광과 흔들림으로 가린다.
6. 한계: 통과 직전 몇 프레임에서 문틀이 늘어나 보였다. 더 일찍 전환하거나, 가까운 전경 물체를 지나가게 하거나, 섬광을 앞당겨 가린다.
7. 정리 전후처럼 같은 공간의 변화는 같은 사진을 편집해 만든다. 카메라는 고정하고 한 가지만 바꾼다.

## 모션 코믹

- 만들어 둘 효과: 망점 오버레이, 방사형 집중선, 속도선, 다각형 컷(굵은 먹선 테두리, 튕겨 들어옴), 효과음 글자(2.6배 → 0.9 → 1, 이중 외곽선, 떨림), 폭발 모양, 자막 말풍선, 페이지 넘김.
- 컷을 한 박자에 하나씩 박고, 드롭 순간에 가장 큰 스플래시 컷을 둔다.
- 이미지 생성에는 사용량 한도가 있다. 30장 안팎에서 걸렸다. 컷 수를 미리 정하고 병렬로 묶어 생성한다. 한도에 걸리면 대체 컷을 쓰고 그 사실을 보고한다.

## 브랜드 이미지 합성

- 그림 속 책이나 화면의 네 꼭짓점을 찾아 실제 이미지를 원근 변형해 붙인다. 가장자리는 1px 미만으로 살짝 흐리게 한다.
- 손가락이 표지를 쥐고 있으면 피부색 마스크로 손을 골라 표지 위에 다시 얹는다. 마스크는 손 영역으로 제한한다.
- 표지 단독 컷은 원본 비율 그대로 넣는다. 틀에 맞춰 잘라내지 않고, 책장 두께와 그림자를 더해 실제 책처럼 보이게 한다.
- 장면 조명에 맞춰 밝기 그라데이션과 접촉 그림자를 넣는다.
