# 可选镜头配方

这些配方来自已观察参考片的视觉次序，用于选取表达手法。一次只选对当前信息有帮助的配方；不要求八种齐用，也不预设白底、紫色、弹簧运动等固定风格。

下列秒段用于在参考片中定位。属性名与实现方式是 Remotion 重建建议；可调参数是新作品的创作起点，不是反推出的原片工程值。需要精确复刻时，重新检查选中短段的实际帧时间。原作者使用的软件未确定。

## 1. 卡片从散布到叠合，再归位

**何时用：**表达收集资料、选择多项、上传附件、把零散信息整理成结果。

**起—中—终与锚点：**起点是可辨认的多张卡与接收容器；中段抓取一张主卡，其余卡向主卡聚拢并随之进入容器；终点展开为有序附件。保留卡片 ID、图像内容和数量；抓取点、主卡中心及容器入口是位置锚点。

**可调参数：**各状态的 `x/y/width/height/rotation`、叠放间距、遮挡次序、聚拢错峰、指针路径、容器增高时机、归位后的停留。深度感可用尺度、少量模糊与遮挡表达，近景卡不应长期挡住主动作。

**实现提示：**先记录散布、叠合、成行三套布局，让同一批对象在布局间插值；指针、对象和容器读取同一事件表。容器内容重排与外框变化分开调节。

**失败征兆：**卡片在进框瞬间换图或丢失；指针脱离被抓卡；先出现附件再播放“拖入”；归位后立即切走。

**验收：**逐段暂停仍能追踪同一批卡片，进框前后数量一致；指针接触关系合理；最终布局无遮挡，留够辨识结果的时间。

**证据：**[Washu 原帖](https://x.com/washukumar531/status/2101728344576299119)，约 7.6–10 秒：散布→聚拢叠放→进入输入框→四卡成行。单标签版本可参看 [Nils](https://x.com/nilseller/status/2100621731350344044) 约 3.1–4.9 秒的进入、高亮、loaded 状态。

## 2. 输入条扩成窗口，UI 分层建立

**何时用：**从一句需求进入生成应用、从搜索进入结果、从简要入口展开复杂工作区。

**起—中—终与锚点：**起点为输入条及一次明确提交；中段同一容器扩展为空窗口，之后出现导航、标题与内容；终点停在可读界面或聚焦下一操作。输入条中心、发送端或指定边缘可作锚点，应根据构图选一个稳定的连续关系。

**可调参数：**起终矩形、圆角、外框/阴影、文本退出时机、侧栏与内容组的入场偏移、遮罩边界、结果停留、下一次镜头聚焦点。

**实现提示：**外容器连续插值；内部拆成 `nav/header/content/emphasis` 等语义组。分组入场可以重叠，不必每层完全结束才开始下一层。保留提交→容器响应→结果的因果顺序。

**失败征兆：**输入条突然消失、无关联大窗同时出现；外框尚未扩开就露出内容；所有控件同时弹动；结果文字始终在运动中。

**验收：**起终状态能通过中间帧连接，内容不越过容器遮罩；第一次阅读时能理解“这次输入产生了这个界面”；结果阶段文字清楚。

**证据：**[Zaro 原帖](https://x.com/titouangillet_/status/2091458817053606310)，约 12–16 秒，尤其 13–15.5 秒空窗、侧栏、表头、列与卡片的出现顺序。辅助例：[Jerry / Lindy](https://x.com/Jerrythe2d/status/2101698229155054016) 约 18–23.5 秒，词间头像与白面板展开成内容页。

## 3. 按阅读目标移动镜头

**何时用：**界面信息较多，需要从整体进入输入、确认、金额、日期或一句重要回复；长文本的阅读区域超过当前画幅。

**起—中—终与锚点：**起点交代整体位置；中段推近目标并在需要时横移；终点让关键内容和操作端稳定可读。锚点是“此刻需要读的区域”，不是任意画面中心。

**可调参数：**目标矩形、镜头中心、`scale`、`transformOrigin`、路径拐点、移动与停留区间、文字显露速度、边缘安全区、是否需要轻微拖影。

**实现提示：**UI 保持自己的坐标系，统一父层负责镜头；输入文字、光标和局部控件独立按帧变化。先安排阅读停顿，再调整镜头曲线。模糊只在需要的移动阶段使用，不能盖住落定文字。

**失败征兆：**镜头一直漂移；到达时关键文字已过；文字跟着父子两层同时缩放；缩放中心跳变；只是放大整页却没有明确阅读对象。

**验收：**每次移动都能说明将注意力带向什么；落定后的目标完整且清楚；缩放前后 UI 元素相互位置稳定；独立播放与任意帧渲染结果一致。

**证据：**[Gemini 原帖](https://x.com/ShumoshitaLNQ/status/2101662884573098266) 约 2.5–5.3 秒，镜头沿输入框文字向右移动；[Muse](https://x.com/Muse/status/2097399178376671666) 约 58.5–63 秒聊天近景与横向阅读、64–67 秒聚焦日期；[Nils](https://x.com/nilseller/status/2100621731350344044) 约 5.3–8 秒。

## 4. 一次拖线操作展开为节点系统

**何时用：**解释工作流、节点编辑器、销售漏斗、自动化链路或多个页面之间的连接关系。

**起—中—终与锚点：**起点只突出源节点与目标节点；中段指针从源连接口拖出连线并落在目标；终点拉远，按关系扩展其余节点。源端口、拖线端点、目标端口与稳定的节点布局是锚点。

**可调参数：**节点矩形与端口坐标、线型与弯曲度、指针路径、拖线进度、接收反馈、后续节点错峰、镜头范围、全图停留。

**实现提示：**拖线端点和指针使用同一进度或路径采样；连接完成后固定端点，再扩展其余关系。节点与边在同一父坐标系内，镜头只移动该父层。

**失败征兆：**指针和线头分离；连线穿入节点中部；缩放时线与端口错位；全图一次拥入，无法理解连接顺序；为了卡点破坏依赖次序。

**验收：**近景可看懂一次实际连接，端点始终贴合；拉远前后拓扑一致；终点能读出主要流程方向，新增节点有视觉层级。

**证据：**[Commas 原帖](https://x.com/titouangillet_/status/2091143874202714619)，约 11–15 秒，12.5–13 秒拖线连接，13.5–15 秒拉远成五节点漏斗；[Cloudflare](https://x.com/titouangillet_/status/2098423993652887785) 约 13–21 秒可对照技术节点图的镜头组织。

## 5. SVG 几何与线条接续

**何时用：**两个概念共享圆、线、轮廓、中心或运动方向，需要在变化中保持连续感；适合简单图标、状态和产品几何特征。

**起—中—终与锚点：**起点先让形状 A 可识别；中段提取共同几何特征，例如把圆环退成一段短线；终点由该特征生长为形状 B，再按需填色。中心、线宽、线头、颜色及运动方向可承担连续锚点。

**可调参数：**圆弧角度、路径可见长度、起止端点、旋转、线宽、退场/生长的交接区间、填色时机、终态停留。参数先服务于轮廓识别，再考虑速度感。

**实现提示：**可组合描边显露、遮罩、几何参数与分段换形；拓扑不同的路径不必强行直接 morph。需要路径插值时先核对路径结构、方向与点序，避免中间帧自交。

**失败征兆：**两完整图标只在交叉淡化；线头突然跳到另一处；路径在中段翻转、自交；填色过早遮住描边动作；保留了颜色却丢失几何关联。

**验收：**查看交接前、中、后三帧能解释线条如何接上；无需字幕也能辨认起终形状；描边无意外尖角或空隙；填色后轮廓稳定。

**证据：**[Apple《Wonderful Tools》P2](https://www.bilibili.com/video/BV1VZ4y1d7BP/?p=2)，约 67–72 秒彩点→圆环→红色短线→心形描边→填实；约 6–11.2 秒还可观察转轮、Home 键、指纹、Face ID、勾选圆标的连续几何关系。

## 6. 按钮放大越过画幅，成为场景入口

**何时用：**一次操作将叙事带入更大的产品空间；按钮、胶囊或其他明确的交互对象可以提供遮挡和方向。

**起—中—终与锚点：**起点留出足够时间辨认并触发按钮；中段按钮放大，越过整个可见边界；终点在遮挡成立时交接下一场景，再让新场景清晰落定。按钮中心或操作点、扩张方向和填屏颜色是锚点。

**可调参数：**按钮初始矩形、缩放中心、覆盖画幅所需终值、圆角变化、交接帧、速度曲线、短暂 blur/残影、新场景显露方向与停留。

**实现提示：**先验证几何覆盖，再加速度和质感；以目标画幅计算最终范围，不能凭一个固定 `scale` 适配所有宽高比。跨场景时共享的是视觉连续关系，不要求原作真的只有一个图层。

**失败征兆：**角落提前漏出下场景；文字放大成像素噪点并停留太久；运动突停后硬切；新场景还没读清便继续推镜。

**验收：**交接帧四边覆盖充分，没有未设计的闪帧；低速回放与逐帧检查均连续；下一场景关键对象能及时识别。残影或失真应是有意选择，不是掩盖布局错误。

**证据：**[Cloudflare 原帖](https://x.com/titouangillet_/status/2098423993652887785)，约 9–13 秒，Start building 按钮越过画幅后进入控制点/节点局部。原片可见残影与块状失真，但其制作方法未被确认。

## 7. 等距品牌工位与输送流程

**何时用：**解释资料经过多个工具、品牌层或处理阶段；需要把抽象流水线变成可追踪的物体流转。

**起—中—终与锚点：**起点交代工位与输送路径；中段镜头进入一个关键处理工位，物体从输入进入、由输出接续；终点跟到下游或拉回全景。物体身份、工位底面、轨道中心线及统一投影方向是锚点。

**可调参数：**等距投影基向量、工位间距、物体路线与速度、入口出口遮挡、层级顺序、工位状态反馈、局部镜头与全景范围、品牌图形版本。

**实现提示：**简单镜头可先用 SVG、分层插画或确定性 2.5D 几何实现；只有真实透视变化、材质或体积光对当前表达必要时才升级 3D。前后遮挡应独立成层，让物体穿过工位时有连续关系。

**失败征兆：**物体穿墙、浮在输送带上或无故消失；各工位透视方向不同；品牌图形只是贴纸堆叠；镜头虽复杂却看不出处理前后变化。

**验收：**可追踪同一物体从上游到下游；遮挡符合空间关系；无需读全部标签也能理解流向；品牌元素用自己的内容替换后，镜头逻辑仍成立。

**证据：**[Bloom 原帖](https://x.com/titouangillet_/status/2098056651173675386)，约 28–32 秒：Attio→Bloom→Slack 等距输送工位，29.5–31 秒靠近中间工位，31.5 秒拉远可见后续工位。

## 8. 固定句式中轮换图标和功能词

**何时用：**用同一叙事语法展示多个能力、场景或收益，或在复杂 UI 段落之间让观众重新抓住主旨。

**起—中—终与锚点：**起点建立完整句式；中段保持公共词和基线，仅替换一个语义槽中的词组/图标；终点落在总结、下一案例或品牌。公共文本、基线、槽位边缘和统一图标尺度是锚点。

**可调参数：**槽位宽度、对齐方向、字体与字号、图标光学尺寸、替换次序、遮罩高度、入出方向、每句停留及换句间隙。槽位可以定宽，也可以受控重排；取决于文案长度和画幅。

**实现提示：**公共部分与可变部分拆开；按语义组入场，避免长句每次全部重打。需要自然文案时先改写句子再做版式，不为适配槽位生造表达。

**失败征兆：**每换一词整句抖动；图标和文字基线不齐；前后词同时露出导致无法读句；每种功能闪过太快；重复形式掩盖内容差异。

**验收：**公共结构稳定，可变内容一眼分辨；最长文案不裁切；各句能在目标播放速度下读完；拿掉动画后语句仍自然、含义完整。

**证据：**[Muse 原帖](https://x.com/Muse/status/2097399178376671666) 约 30–48 秒段内、48–53 秒及 68 秒以后反复使用 AI that … for you；[Jerry / Lindy](https://x.com/Jerrythe2d/status/2101698229155054016) 约 38–45.5 秒保持 With Lindy, you can 开头并轮换后文；[Washu](https://x.com/washukumar531/status/2101728344576299119) 约 0–3 秒可参看词间嵌入小画面。

## 使用这些配方时的共同取舍

先选需要表达的关系，再选镜头；一个清楚的镜头通常只需一种主关系。连续对象、阅读停顿和状态因果应在无音频预览中成立。加入声音后，按可用试听证据或明确的原创设计核对声音用途与实际起音，再安排拍点；未试听的初稿保留设计/候选身份。参考片附近的频谱峰不自动等于对应动作的原始音效。

原帖、时长、验证范围及可选本地缓存见 [reference-catalog.md](reference-catalog.md)。
