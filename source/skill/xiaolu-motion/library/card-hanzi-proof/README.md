# card-hanzi-proof · 汉字雨纠错

朱丝栏宣纸上，印刷汉字像雨一样分三层景深落下；雨慢下来，一列停成成语“再接再励”。红笔圈出错字“励”、划掉、在页边手写“厉”，错字掉落，正确字沿引线滑进原位变成铅字，打勾，盖一方“校”印，雨又轻轻落起来。全屏卡，4.5 秒，1080×1920，30 fps，带合成音效。

![thumb](thumb.jpg) · 预览：`preview.mp4`（202×360）

## 做法

- 纸：暖色宣纸、半分辨率的云纹（fbm 噪声）、纤维、淡朱色竖栏（朱丝栏）和双框。
- 雨：远、中、近三层（字号 34 / 62 / 150 px，远层轻微虚化、近层大幅虚化且只在画面两侧），每列一串字，字头最深、字尾渐淡；字来自 GB2312 一级字库 3755 字。整场雨用同一个“雨时钟”：正常速度 → 校对时降到 6% → 之后回到 30%，停下来的那一列也按这个时钟减速，所以它是真的“随雨落下再停住”。
- 校对：红笔圈、删除线、引线、页边手写字、勾，都用带压感变化的圆点笔刷逐段画出；手写字用霞鹜文楷，进位后换成思源宋体印刷体；校对区的雨会退开，页边保持干净。
- 印章：朱红方印、阴刻“校”字、不均匀的印泥压力。

## 适合场景

纠错、校对、“AI 帮你检查”“别再写错字”“细节决定成败”类主题；也可当作“慢下来、聚焦”的转场。成语、错字、正确字、印章字都能换。

## 主要参数（`src/build.py` 的 `PARAMS`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `text` | 再接再励 | 停下来的一列（含一个错字） |
| `wrong` | 3 | 错字在 `text` 里的序号（从 0 起） |
| `right` | 厉 | 正确的字 |
| `seal` | 校 | 印章字（1 字） |
| `t_settle` | 1.35 s | 这一列停稳的时间，其余节拍都跟着它走 |
| `paper` / `ink` / `red` | — | 纸色、墨色、朱批红 |

## 声音

雨声是底层：每一滴是一个几毫秒的高频“嗒”，密度和音量跟着同一个雨时钟变化（慢下来时几乎安静），加一点纸面沙沙声；本条目合成的 `pen_scratch`（带纤维颗粒感的笔划声，长度 = 笔画时长）用在圈、删、引线、写字、打勾；错字掉落一声低 whoosh，正确字飞入 `enter`、落位 `land` + 一颗 `pluck`，盖章 `stamp`。成片 −27.7 LUFS / 峰值 −12.5 dBTP。

## 重渲

```bash
cd library/card-hanzi-proof/src
python3 build.py stills --times 0.9 2.05 2.95 4.2
python3 build.py render --out <输出目录>
```

字体：思源宋体 Bold / Heavy、霞鹜文楷 Medium（`fonts/`）。渲染前检查 3755 个雨字 + 成语 + 正确字 + 印章字全部在字库里。

## 文件

`src/hanzi_proof.js`（组件）、`src/sound.py`（笔划声 + 雨声底 + 音效表）、`src/build.py`、`src/shotkit.py`（各条目共用，见 card-movable-type 的说明）。

## QA 说明

雨字本身会穿过画面下方的字幕带（74–86% 高），这是背景纹理；成语、校对红笔、印章都在字幕带以上。
