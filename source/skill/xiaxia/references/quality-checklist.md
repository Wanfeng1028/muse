# 夏夏交付前检查

## 原文与完整性

- [ ] 已逐项核对人物、原台词、动作责任人、左右手、道具归属、事件顺序与结果，没有擅自改写。
- [ ] 剧本中的每个必要事件、反应、对白和转场都能在某一镜找到，不靠字幕补叙事。
- [ ] 总时长等于所有生成组之和；每组 4–30 秒；组内时间码从 0 开始连续覆盖，无空档、重叠或越界。
- [ ] 台词按正常表演速度可说完，停顿、听者反应、不可并发动作和转场留有真实时间。
- [ ] 没有用重复走路、喘息、空镜、慢动作或重复对视填时长。

## 镜头信息与剪辑

- [ ] 每镜至少新增一种信息或改变一种状态；超过 4 秒的镜头内部持续发生可见变化。
- [ ] 每镜只有一个主要视觉中心、主要动作或判断重心，不把整场戏塞进一镜。
- [ ] 镜头景别有邻接逻辑；特写改变判断，不是随机眼睛、手、衣角或装饰微距。
- [ ] 对话已建立轴线和双方态度；关键词、命令、迟疑或判断变化处切到真正受到刺激的人。
- [ ] 长台词可跨说话者、听者、第三方和关键物件连续播放，但原文未改词、截断或换人。

## 空间、动作与连续性

- [ ] 人物、入口、出口、威胁、目的地和摄影机位置可在平面图中成立。
- [ ] 21:9 左右区域、负空间、遮挡和高度差承担阶级、距离、路线或危险，而非空洞装饰。
- [ ] 对话视线、180 度轴线、人物左右、运动方向和出入画方向连续；越轴有中性镜或可见过渡。
- [ ] 动作场先交代地形、距离、武器和运动方向，再进入快速切分。
- [ ] 攻击和机械动作具备支撑、发力、轨迹、接触/落空、受力、反作用和可见结果；切镜后不重新起手或复位。
- [ ] 组尾连续性与下一组第一镜相符：站位、朝向、手部、道具、伤势、战损、光源和声音桥没有无因重置。

## 构图、光影与质感

- [ ] 摄影机有可实际到达的观看位置与明确立场；焦段解释空间，不代替机位。
- [ ] 三分线、中轴、框架、引导线或多层空间由真实实体支撑，并有戏剧理由。
- [ ] 每个重要光源都有来源、方向和覆盖范围；阴影允许保留，不为漂亮均匀补亮人物。
- [ ] 高光只落在受光且材质允许的皮肤、布、玻璃、金属、液体或尘汽上。
- [ ] 没有无来源轮廓光、彩色雾、HDR 暗部、广告皮肤、全画面统一锐度或概念艺术式贫穷。
- [ ] 删除“电影感、高级、史诗、8K、大片、胶片”等词后，镜头仍然具体、可画、可拍、可生成。

## 魔法、特效与声音

- [ ] 魔法/VFX写清源点、方向、尺度、速度、介质反馈、环境受光/受力、衰减与残留。
- [ ] 能量形态、颜色、旋转方向、蓄能量和破损跨镜连续。
- [ ] 声音只承担剧情、材质、动作落点、人物反应或转场，不机械罗列所有衣料、脚步和呼吸。
- [ ] 每组最后逐字写：`声音要求：不要 BGM；不要字幕；只保留剧情对白、环境声和动作音效。`

## Seedance 执行边界

- [ ] 一条任务只属于普通生成、视频编辑、视频延长或关键帧控制之一。
- [ ] 只引用真实存在且可读取的 @Image/@Video/@Audio；每份素材有唯一主要职责和不继承范围。
- [ ] 画幅、时长、分辨率、帧率、声音开关等页面/API参数没有与镜头提示正文混写。
- [ ] 时间线描述的是可见变化与摄影机意图，不是抽象主题或堆砌风格词。
- [ ] 未把第三方教程、缓存数据或旧界面限制冒充当前官方能力。

## 输出边界

- [ ] 正式交付只含片名、总时长、生成组和镜头正文；没有分镜圣经、生成组地图、事实账本、路由记录或质量评分。
- [ ] 每镜是紧凑完整的导演段落，不机械重复六个固定栏目，也没有为规范而拖沓。
