# Skill 源码与安装版维护

本仓库是公开发布源。安装目录是运行副本；个人凭据、账号选择、代理、私有核心及其配置留在本机。修复应先合并到发布工作区，再测试、发布和安装，不执行双向自动覆盖。

## 只读差异检查

```bash
python3 scripts/compare_installed_skills.py
# 自定义安装根，可重复 --local-root；插件位置必须显式提供
python3 scripts/compare_installed_skills.py --local-root "$HOME/.agents/skills"
```

脚本只对 Git 已跟踪的公开 Skill 文件做哈希比较，不调用 Skill、不读取密钥、不写入或同步。支持根软链接，不跟随内部软链接。未安装、缺失、不同和一致分别报告；不按修改时间推断新旧，也不枚举安装版额外文件或运行产物。Grok MCP 实现及外部执行器需另按下文核对，不能由入口相同推断完整插件相同。

## 合并与安装

1. 从远端最新 main 建独立工作区，核对 public / installed / private 三类来源。
2. 保留公开许可证、来源说明、环境变量和安全门禁；只迁移明确授权发布的通用增量。
3. 更新或安装前，把受影响文件备份到本机 work/，记录路径、哈希和 Git 提交。安装前再次核对基线；发生并发变更时停止覆盖该文件。
4. 运行受影响模块的离线测试与必要集成验证，日志不得含凭据或私人内容。
5. 推送后回读远端提交，再核对安装版。新增插件代码可能需要下一次会话重新加载；不擅自中断当前任务。

## 有意保留的不同发布链

- X 文章草稿上传器：公开版本与独立私有 Ailu 集成有不同运行时和信任契约。私有版本号较大不代表可整包公开；不复制私有仓库绑定、签名/来源清单、运行时包或授权数据。公开版只承诺自己的 README 能力。
- ASR：公开执行器通过环境变量注入配置，本机可以有目录外执行器和钥匙串适配。检查调用目标后比较，不以 Skill 目录缺文件判定未安装；不迁移个人应用标识、Token 或计费配置。
- 企微官方 CLI：公开版的可配置 helper 与本机私有 helper 可以不同，不把本机路径写入公开代码。
- Grok：插件 MCP、授权策略文件与 Skill 入口一起核对；个人 .mcp.json 代理与登录态配置不覆盖。
- 系统和插件缓存由各自安装机制管理。没有本机独立入口的公开 Skill 不自动安装或删除。
