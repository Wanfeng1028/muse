# 星命盘 —— 微信小程序

> Slogan：你的命盘，一眼看懂。
> 定位：传统文化学习 + 娱乐参考工具。全部解读带“仅供学习与娱乐参考”声明，不做改运/化解类服务。

## 结构

- `client/`：小程序端（Taro 4 + React 18 + TypeScript，UI 以 UIDesign app/medley 设计系统为基）
- `cloudfunctions/`：微信云开发云函数（登录、命盘历史、会员、订单、积分、邀请、AI 代理、配置）
- `docs/`：云数据库结构、接口约定、上架清单等文档
- `ATTRIBUTION.md`：引擎与数据集来源标注

## 架构（2026-11-01 用户亲定变更）

- 后端直接走微信云开发，不再部署日本服务器（无独立域名、无 Docker/Caddy）。
- AI 主力走云开发自带模型（对话 token 做解盘/问答，生图 token 做海报背景与每日运势配图）；BotsRouter（api.botsarena.tech/v1）为备用，仅在云开发额度不足或模型不可用时切换。
- 云开发环境 ID（envId）由用户稍后提供，开发先用占位，不阻塞。
- AppID、商户号、广告位 ID、全部密钥一律走配置占位，绝不进仓库。

## 用户侧待办（不阻塞开发，完整清单见四期上架包）

- 小程序账号 + AppID；云开发环境 ID（envId）；微信支付商户号；类目审核；小程序备案（如主体在内地）；流量主开通（累计 UV ≥ 1000 后）。

## 开发分期

- 一期：引擎移植 + 排盘 + 命盘图 + 基础解读 + UI 全套
- 二期：账号（微信登录）+ 会员 + 微信支付 + 积分 + 邀请
- 三期：AI 解盘/问答 + 广告位 + 分享海报 + 历史/合盘
- 四期：上架包（隐私、协议、审核材料、提交清单、压测）
