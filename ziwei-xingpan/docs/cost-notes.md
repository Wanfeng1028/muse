# 成本说明（紫微星盘）

> 本说明只写已确认的计价机制与可查的单价来源；凡控制台才能看到
> 的实时单价，一律标注“以控制台为准”，不编造数字。

## 1. 成本构成

| 环节 | 计价方 | 机制 |
|---|---|---|
| 云开发云函数、数据库、存储 | 微信云开发（CloudBase） | 按云开发计费规则（以控制台账单为准）；本项目无自建服务器成本 |
| AI 对话（主力） | 用户已有云开发会员内含对话 token | 额度内消耗资源点/ token；超出后按控制台规则计费或降级 |
| AI 生图（主力） | 用户已有云开发会员内含生图 token | 同上；生图结果缓存复用，重复请求不重复计费 |
| AI 对话/生图（备用） | BotsRouter（api.botsarena.tech/v1） | 仅在主力额度不足或不可用时调用；按 BotsRouter 站内模型单价计费 |
| 微信支付 | 微信支付 | 按微信支付费率（以商户后台为准）；本项目订单金额即会员价，无额外加价 |
| 流量主广告 | 微信流量主 | 收入侧：UV 达标开通后按微信分成规则结算（未达标前收入为 0） |

## 2. 省成本的关键设计（已落地）

- 同一命盘 AI 解读按盘 hash 缓存：命中不调模型、不扣积分。
- 生图按提示词 / 日期 + 盘 hash 缓存：命中直接返回云存储 fileID。
- 额度阈值降级：当日 CloudBase 用量达配置阈值（种子默认 85%）
  时自动切换备用通道并标注 degraded，避免主力额度打爆后静默失败。
- Pro 每月 AI 免费额度 20 次、Max 不限次：额度计数以 quotaLogs
  为准（openid + kind + monthKey），不是估算。

## 3. 上线前必须在控制台核对的单价（未核对前不得对外报价）

- CloudBase 会员内含对话/生图 token 的剩余额度与超出单价。
- BotsRouter 备用对话模型（种子默认 deepseek-v4.1-flash）的站内单价；
  备用生图模型在种子里故意留空，填入前不得宣称备用生图可用。
- 微信支付费率与云开发资源包价格（以各控制台账单页为准）。

## 4. 收入侧（PLAN 价目，不含税费与渠道费推导）

- Pro ¥18/月、连续包月 ¥15/月；Max ¥38/月、连续包月 ¥32/月。
- 积分兑换（7 天 Pro 300 积分、30 天 Pro 1500 积分）不产生现金收入，
  属于获客与留存成本，需在运营报表中与付费会员分开统计。
