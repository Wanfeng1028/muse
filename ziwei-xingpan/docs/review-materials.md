# 提审材料（紫微星盘）

## 1. 产品定位陈述（申报口径）

- 产品名：紫微星盘；Slogan：你的命盘，一眼看懂。
- 类目申报方向：传统文化 + 娱乐参考工具。排盘引擎在小程序本地
  运行，解读措辞去确定性（不说“必破财”，说“财帛宫承压，需留意
  开支”）；每处解读下方固定免责声明：“内容源自传统紫微斗数文化，
  仅供学习与娱乐参考，不构成人生决策建议”。
- 明确不做：不卖改运、法事、化解、转运物；不作确定性断言；不向
  未成年人提供付费解读（见未成年人保护说明）。

## 2. 功能与页面清单（送审截图按此表逐屏截取，不要用旧版截图）

| 页面 | 截图要点 |
|---|---|
| 首页（出生信息） | 姓名/性别/生日/时辰/出生地 + 手动时间校正（可撤销） |
| 命盘图 | 12 宫命盘图 + 大运 + 流年/流月 + 保存按钮 |
| 解读 | 格局判断 + 13 维解读 + AI 解盘/问答区 + 免责声明 |
| 知识 | 星曜、宫位、四化、格局科普（自写文本） |
| 我的 | 会员中心、积分中心、邀请中心、命盘历史、合盘对照、分享海报、订单、设置、反馈、关于/隐私/条款 |
